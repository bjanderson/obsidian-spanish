## Explanation

You've seen how *ser* + past participle builds a formal passive. There's a
much more common everyday way to say the same kind of thing: the
**passive *se***. Instead of naming who did something, you just put *se*
in front of the verb and let the thing being acted on drive the whole
sentence — the way a "For Sale" sign says *Se vende* (For sale) instead of
spelling out who's doing the selling.

## Key Points / Conjugation / Rules

- **The formula**: *se* + [verb, 3rd person] + [the thing being acted on].
  The verb **agrees in number** with that thing, exactly like a subject
  would: *Se vende la casa* (singular *casa* → singular *vende*); *Se
  venden las casas* (plural *casas* → plural *venden*).
- This pattern works with **inanimate objects only** — things, not people.
  Signs, listings, and everyday announcements use it constantly: *Se
  alquila apartamento* (Apartment for rent); *Se buscan empleados* (Staff
  wanted); *Se necesitan voluntarios* (Volunteers needed).
- Even though the thing being acted on functions like a subject
  grammatically (it controls the verb's number), it usually comes **after**
  the verb, especially in signs and short announcements: *Se venden
  frutas* reads more naturally than *Frutas se venden*, though both are
  grammatical.
- The passive *se* only works with **transitive verbs** — verbs that
  normally take a direct object, like *vender*, *alquilar*, *buscar*,
  *necesitar*. This is the everyday cousin of the *ser* + participle
  passive from the previous lesson, expressing the same idea in the
  register Spanish speakers actually use out loud.

## Examples

| Spanish                             | English                              | Notes                             |
| ---------------------------------------- | -------------------------------------- | ---------------------------------------- |
| Se vende esta casa.                       | This house is for sale.                   | singular verb, singular object                |
| Se venden estas casas.                    | These houses are for sale.                  | plural verb, plural object                      |
| Se alquila apartamento amueblado.         | Furnished apartment for rent.                 | singular verb, singular object                    |
| Se buscan empleados con experiencia.      | Employees with experience wanted.               | plural verb, plural object                          |
| Se necesita ayuda en la cocina.           | Help is needed in the kitchen.                    | singular verb, singular object                        |
| Se aceptan tarjetas de crédito.           | Credit cards are accepted.                          | plural verb, plural object                              |

## Common Mistakes

- Forgetting number agreement: *Se vende casas* is wrong — the verb must
  match the plural object: *Se venden casas.*
- Using this pattern with a specific person as the object: passive *se*
  doesn't work for a direct person the way *ser* + participle can — for
  people, a different construction (accidental/impersonal *se* or *ser*
  passive) is called for instead.
- Assuming the object always comes right after the verb: word order is
  flexible here, but the default, most natural order in signs and
  announcements puts the object after: *Se venden casas*, not *Casas se
  venden.*
- Treating this as interchangeable with the impersonal *se* from the next
  lesson: passive *se* has a grammatical subject that controls verb
  agreement; impersonal *se* (next lesson) doesn't work the same way and
  stays singular regardless.
