## Explanation

Think about the English sentence "If I were rich, I would travel the
world." You're not describing something realistic — you're imagining a
version of right now that isn't true. Spanish has a dedicated pattern for
exactly this: pairing the imperfect subjunctive you already know with the
conditional tense, to talk about a present that's imaginary, unlikely, or
flatly contrary to fact.

## Key Points / Conjugation / Rules

- **The pattern**: *si* + **imperfect subjunctive** → **conditional**. The
  *si* clause sets up the unreal premise, and the conditional describes
  what would follow: *Si tuviera más dinero, viajaría por el mundo* (If I
  had more money, I would travel the world).
- This pattern is for the **present or general** unreal — not something
  that already happened and is over (that's the next lesson, with the
  pluperfect subjunctive). *Si fuera rico* imagines an alternate present,
  not something in the past.
- **Never use the present indicative or the conditional inside the *si*
  clause** in this pattern — only the imperfect subjunctive goes there:
  *Si tendría tiempo* is wrong; *Si tuviera tiempo* is correct.
- The order can flip with no change in meaning: *Si fuera tú, no lo
  haría* and *No lo haría si fuera tú* both work — just add a comma after
  the *si* clause when it comes first.
- A common, especially useful version of this pattern: *si fuera tú* (if I
  were you) — Spanish's version of English's "if I were you," used
  constantly for giving advice: *Si fuera tú, hablaría con ella* (If I
  were you, I would talk to her).

## Examples

| Spanish                                                | English                                                | Notes                       |
| --------------------------------------------------------- | --------------------------------------------------------- | --------------------------------- |
| Si tuviera más dinero, viajaría por el mundo.               | If I had more money, I would travel the world.               | imperfect subjunctive → conditional  |
| Si fuera tú, hablaría con ella hoy mismo.                    | If I were you, I would talk to her today.                       | *si fuera tú*, advice                  |
| Si supiéramos la respuesta, te la diríamos.                  | If we knew the answer, we would tell it to you.                   | imperfect subjunctive → conditional      |
| Si pudieras vivir en cualquier país, ¿cuál elegirías?         | If you could live in any country, which would you choose?          | imperfect subjunctive → conditional        |
| Si no lloviera tanto, saldríamos a caminar.                  | If it weren't raining so much, we would go for a walk.               | imperfect subjunctive → conditional          |
| Si tuvieras que elegir, ¿qué harías?                         | If you had to choose, what would you do?                              | imperfect subjunctive → conditional            |

## Common Mistakes

- Using the present indicative inside the *si* clause: *Si tengo más
  dinero, viajaría* mixes patterns — for an unreal premise, the *si* clause
  needs the imperfect subjunctive: *Si tuviera más dinero, viajaría.*
- Using the conditional inside the *si* clause: *Si tendría tiempo, iría*
  is wrong — the conditional belongs in the result clause only: *Si
  tuviera tiempo, iría.*
- Confusing this pattern with the real/possible conditional from the
  previous lesson: if the situation is genuinely likely, use *si* + present
  indicative instead — this pattern is specifically for something unreal
  or unlikely right now.
- Reaching for the pluperfect subjunctive when the situation is still
  ongoing: *Si hubiera tenido más dinero, viajaría* mixes past and present
  — for a present unreal situation, stick with the imperfect subjunctive:
  *Si tuviera más dinero, viajaría.*
