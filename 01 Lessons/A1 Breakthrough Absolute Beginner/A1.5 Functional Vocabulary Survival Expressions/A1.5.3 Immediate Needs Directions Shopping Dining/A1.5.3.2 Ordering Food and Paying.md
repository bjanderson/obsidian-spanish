## Explanation

A restaurant visit in Spanish follows a predictable script, and knowing the
fixed phrases for each step makes the whole interaction much smoother than
translating on the fly. It usually starts with the waiter asking _¿Qué va a
pedir?_ or _¿Qué le gustaría?_ ("What would you like?"), and you respond with
_Quiero..._ or the slightly softer _Me gustaría..._ ("I would like...") — see
[[A1.5.3.1 Expressing Basic Needs]] for more on _quiero_.

_Para mí_ ("for me") is useful when ordering as part of a group, pointing to
what's yours in the order: _Para mí, la sopa_ ("For me, the soup"). If you need
a recommendation, _¿Qué me recomienda?_ ("What do you recommend?") is the
standard phrase — note it uses _usted_ conjugation, since you're speaking to
someone providing a service, not a friend (see
[[A1.5.1.3 Pragmatics Tu vs Usted]]).

When you're finished, _La cuenta, por favor_ ("The check, please") is the
universal way to ask for the bill — short, direct, and always polite with
_por favor_ attached. You might also hear or use _¿Me trae la cuenta?_ ("Could
you bring me the check?"), a slightly more formal phrasing using _traer_
("to bring"). To ask whether the tip is included, _¿Está incluida la propina?_
covers a genuinely useful detail, since tipping customs vary by country.

## Key Points / Conjugation / Rules

| Phrase                       | Meaning                              | Notes                              |
| ---------------------------------- | -------------------------------------------- | ------------------------------------------ |
| ¿Qué va a pedir? / ¿Qué le gustaría? | What would you like?                      | server asking for your order               |
| Quiero... / Me gustaría...        | I want... / I would like...                | *me gustaría* is slightly more polite       |
| Para mí...                        | For me...                                    | pointing to your item in a group order      |
| ¿Qué me recomienda?               | What do you recommend?                       | *usted* form — service context              |
| La cuenta, por favor.             | The check, please.                           | standard way to ask for the bill            |
| ¿Me trae la cuenta?               | Could you bring me the check?                | slightly more formal phrasing               |
| ¿Está incluida la propina?        | Is the tip included?                         | useful — tipping customs vary by country    |

- _Me gustaría_ is a softer, more polite alternative to _quiero_ — useful when
  ordering from a server.
- _Para mí_ marks which item is yours when several people are ordering together.
- _¿Qué me recomienda?_ uses the formal _usted_ conjugation, matching the
  service-interaction context from [[A1.5.1.3 Pragmatics Tu vs Usted]].

## Examples

| Spanish                                        | English                                    | Notes                              |
| ------------------------------------------------------ | -------------------------------------------------- | ------------------------------------------ |
| Buenas tardes, ¿qué le gustaría tomar?                 | Good afternoon, what would you like to drink?      | server opening the order                   |
| Para mí, el pollo con arroz, por favor.                | For me, the chicken with rice, please.             | *para mí* in a group order                  |
| ¿Qué me recomienda de postre?                          | What do you recommend for dessert?                 | asking for a recommendation                |
| ¿Me trae más agua, por favor?                          | Could you bring me more water, please?             | polite request mid-meal                    |
| La cuenta, por favor. ¿Está incluida la propina?       | The check, please. Is the tip included?            | closing the meal                            |
| Quisiera la mesa cerca de la ventana.                  | I would like the table near the window.            | *quisiera*, another polite "I would like"  |

## Common Mistakes

- Asking for the check with _tú_-conjugated phrasing in a formal restaurant
  setting — the service-interaction default is _usted_, per
  [[A1.5.1.3 Pragmatics Tu vs Usted]].
- Forgetting _por favor_ when making a request — Spanish restaurant requests
  almost always include it, even short ones like _La cuenta, por favor_.
- Assuming tipping customs are the same everywhere — asking _¿Está incluida la
  propina?_ avoids an awkward surprise, since this varies by country.
