## Explanation

You've already got *-AR* verbs down from
[[A1.3.3.1 AR Conjugation Endings]] — good news, *-ER* verbs work exactly the same
way, just with a different set of endings. Verbs like *comer* (to eat), *beber* (to
drink), and *leer* (to read) all belong to this group.

Same process as before: strip the *-er* off the infinitive to find the stem, then add
the ending for whoever's doing the action. *Comer* becomes *com-*, and adding *-o*
gives you *como* ("I eat"). The endings themselves look a little different from
*-AR* verbs — notice they lean on *-e* instead of *-a* — but the logic is identical.

A quick way to keep the two patterns straight: *-AR* endings mostly use *a* (*-o,
-as, -a, -amos, -an*), while *-ER* endings mostly use *e* (*-o, -es, -e, -emos,
-en*). The *yo* form is the only one that looks the same across both groups.

## Key Points / Conjugation / Rules

| Subject           | Ending | *comer*  |
| ------------------ | ------ | -------- |
| yo                  | -o     | como     |
| tú                  | -es    | comes    |
| él / ella / usted   | -e     | come     |
| nosotros            | -emos  | comemos  |
| ellos / ustedes     | -en    | comen    |

- Drop the *-er* from the infinitive to get the stem, then add the matching ending.
- These endings work for any regular *-ER* verb: *beber → bebo, bebes, bebe...*;
  *leer → leo, lees, lee...*
- The *yo* ending, *-o*, is the same for *-AR* and *-ER* verbs — only the other five
  forms differ.

## Examples

| Spanish                       | English                      | Notes                    |
| ---------------------------------- | ----------------------------------- | -------------------------------- |
| Como frutas todos los días.         | I eat fruit every day.              | *comer*, *yo*                    |
| ¿Bebes café por la mañana?          | Do you drink coffee in the morning? | *beber*, *tú*                    |
| Él lee el periódico.                | He reads the newspaper.             | *leer*, *él*                     |
| Aprendemos español juntos.          | We learn Spanish together.          | *aprender*, *nosotros*           |
| Mis hijos corren en el parque.      | My kids run in the park.            | *correr*, *ellos*                |
| ¿Comprendes la lección?             | Do you understand the lesson?       | *comprender*, *tú*               |

## Common Mistakes

- Using *-AR* endings on an *-ER* verb by mistake — *como*, not *coma*, for "I eat"
  from *comer*.
- Forgetting that the *tú* ending is *-es*, not *-as*, for this group: *comes*, not
  *comas*.
- Confusing *leer* ("to read") with *leer*'s stem-vowel spelling — it keeps the
  double *e* (*leo, lees, lee*) since the *-er* is simply removed.
