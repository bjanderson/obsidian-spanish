## Explanation

You now know the regular endings for *-AR, -ER,* and *-IR* verbs. Stem-changing verbs
use those exact same endings — the only twist is that the stem itself shifts in four
of the six forms. Think of *querer* (to want): the ending pattern is completely
regular *-ER* endings, but the *e* in the middle of the stem flips to *ie* whenever
that syllable gets the stress. *Quiero* ("I want"), not *quero*.

Here's the pattern to watch for, sometimes nicknamed the "boot verbs" because if you
circle the four forms that change, they form a boot shape on the conjugation chart:
*yo, tú, él/ella/usted,* and *ellos/ustedes* change, while *nosotros* stays regular.
That's because *nosotros* puts the stress somewhere else in the word, so the vowel
never needs to shift.

There are three flavors of this shift you'll run into constantly: *e → ie* (*querer
→ quiero*), *o → ue* (*poder → puedo*), and *e → i* (*pedir → pido*). Different verbs
fall into different groups, and there's no shortcut for knowing which — you'll build
up a feel for it the more Spanish you hear and use.

## Key Points / Conjugation / Rules

**e → ie** — *querer* (to want)

| Subject           | Form     |
| ------------------ | -------- |
| yo                  | quiero   |
| tú                  | quieres  |
| él / ella / usted   | quiere   |
| nosotros            | queremos |
| ellos / ustedes     | quieren  |

**o → ue** — *poder* (to be able to)

| Subject           | Form    |
| ------------------ | ------- |
| yo                  | puedo   |
| tú                  | puedes  |
| él / ella / usted   | puede   |
| nosotros            | podemos |
| ellos / ustedes     | pueden  |

**e → i** — *pedir* (to ask for)

| Subject           | Form    |
| ------------------ | ------- |
| yo                  | pido    |
| tú                  | pides   |
| él / ella / usted   | pide    |
| nosotros            | pedimos |
| ellos / ustedes     | piden   |

- The stem changes in every form except *nosotros* — that form keeps the plain
  vowel because the stress falls elsewhere.
- The regular *-AR/-ER/-IR* endings still apply on top of the changed stem.
- Other common *e → ie* verbs: *pensar, entender, empezar*. Other common *o → ue*
  verbs: *volver, dormir, encontrar*. Other common *e → i* verbs: *servir, repetir,
  seguir*.

## Examples

| Spanish                         | English                          | Notes                    |
| -------------------------------------- | ---------------------------------------- | -------------------------------- |
| Quiero un café.                         | I want a coffee.                          | *querer*, *e→ie*                 |
| ¿Puedes ayudarme?                       | Can you help me?                          | *poder*, *o→ue*                  |
| Ella pide la cuenta.                    | She asks for the check.                   | *pedir*, *e→i*                   |
| Pensamos viajar en julio.               | We're planning to travel in July.         | *pensar*, *nosotros*, no change  |
| Mis amigos vuelven mañana.              | My friends are coming back tomorrow.      | *volver*, *ellos*, *o→ue*        |
| ¿Entiendes la pregunta?                 | Do you understand the question?           | *entender*, *tú*, *e→ie*         |

## Common Mistakes

- Applying the stem change to *nosotros* — it should stay *queremos*, *podemos*,
  *pedimos*, not *quieremos* or *puedemos*.
- Guessing which pattern a verb follows instead of learning it with the verb — the
  stem-change type isn't predictable from spelling alone.
- Forgetting the regular ending on top of the changed stem — it's *quiero*, not
  *quier*.
