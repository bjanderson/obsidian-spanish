## Explanation

Spanish has 5 vowels: *a, e, i, o, u*. Each one has exactly one sound, no matter
where it appears in a word. This is different from English, where a vowel letter
can sound several different ways depending on the word.

- **a** — like the "a" in "father"
- **e** — like the "e" in "bed"
- **i** — like the "ee" in "see"
- **o** — like the "o" in "note"
- **u** — like the "oo" in "food"

Because each vowel has only one sound, Spanish spelling is very predictable once
you know these 5 sounds — a written vowel always tells you exactly how to say it.

## Key Points / Conjugation / Rules

- Spanish vowels each have one consistent sound, unlike English vowels.
- *a* = "ah", *e* = "eh", *i* = "ee", *o* = "oh", *u* = "oo".
- A vowel's sound never changes based on stress or position in a word.

## Examples

| Spanish | English | Notes                                  |
| ------- | ------- | --------------------------------------- |
| casa    | house   | *a* sounds like "ah", as in "father".   |
| mesa    | table   | *e* sounds like "eh", as in "bed".      |
| isla    | island  | *i* sounds like "ee", as in "see".      |
| oso     | bear    | *o* sounds like "oh", as in "note".     |
| luna    | moon    | *u* sounds like "oo", as in "food".     |
