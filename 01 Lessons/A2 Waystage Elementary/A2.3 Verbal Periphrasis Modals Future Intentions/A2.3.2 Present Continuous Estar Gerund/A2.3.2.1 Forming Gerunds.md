## Explanation

The present progressive is one of the easiest structures for English speakers to pick
up, because it works almost exactly like English "-ing." It describes something
happening right now: "I'm eating," "she's reading."

In Spanish, this is built from two pieces:

1. *Estar*, conjugated in the present tense to match the subject.
2. The main verb changed into its **gerund** form (*el gerundio*) — the Spanish
   equivalent of "-ing."

## Key Points / Conjugation / Rules

**Present tense of _estar_:**

| Subject                | Conjugation |
| ------------------------ | ----------- |
| yo                       | estoy       |
| tú                       | estás       |
| usted / él / ella        | está        |
| nosotros / nosotras      | estamos     |
| ustedes / ellos / ellas  | están       |

**Forming the regular gerund:**

- **-ar verbs**: drop *-ar*, add **-ando** → *hablar* → *hablando*
- **-er verbs**: drop *-er*, add **-iendo** → *comer* → *comiendo*
- **-ir verbs**: drop *-ir*, add **-iendo** → *vivir* → *viviendo*

Formula: **[conjugated _estar_] + [gerund]**

- The gerund itself never changes form for the subject — only *estar* does.
- Spanish speakers use the present progressive less often than English speakers do.
  Where English reaches for "-ing," Spanish often just uses the simple present tense:
  *¿Qué haces?* ("What are you doing?") is present tense, not progressive, but is
  understood the same way in context.
- Avoid the present progressive with verbs of motion like *ir* and *venir*. Instead of
  *Estoy yendo a la tienda*, Spanish speakers say *Voy a la tienda* ("I'm going to the
  store") using the simple present.

## Examples

| Spanish                             | English                          | Notes                                |
| -------------------------------------- | ----------------------------------- | --------------------------------------- |
| Estoy hablando por teléfono.           | I am talking on the phone.          | *-ar* verb, *yo* form                |
| ¿Qué estás comiendo?                   | What are you eating?                | *-er* verb, *tú* form question       |
| Marta está viviendo en Bogotá.         | Marta is living in Bogotá.          | *-ir* verb, *ella* form               |
| Estamos buscando las llaves.           | We're looking for the keys.         | *-ar* verb, *nosotros* form           |
| Mis papás están trabajando hoy.        | My parents are working today.       | *-ar* verb, *ellos* form              |
| Estoy tratando de aprender español.    | I'm trying to learn Spanish.        | *estar + tratando de + infinitive*    |

## Common Mistakes

- Conjugating the main verb instead of using the gerund: *Estoy habla* is wrong;
  it must be *Estoy hablando*.
- Mixing up *-ando* and *-iendo*: *-ar* verbs always take *-ando*; *-er* and *-ir*
  verbs always take *-iendo* (regular verbs only — irregular gerunds are covered in
  the next lesson).
- Reaching for the present progressive out of habit from English when the simple
  present sounds more natural in Spanish, especially for ongoing states or routines.
- Using the present progressive with *ir* or *venir* — use the simple present instead.
