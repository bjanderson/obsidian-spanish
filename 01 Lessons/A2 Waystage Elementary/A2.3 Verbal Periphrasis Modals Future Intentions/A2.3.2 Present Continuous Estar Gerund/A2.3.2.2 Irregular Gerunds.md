## Explanation

Most verbs form the gerund the regular way (*-ando* / *-iendo*), but two groups of
verbs change shape to keep their pronunciation smooth or to reflect a vowel change
that also shows up elsewhere in their conjugation. Both groups are common, high-
frequency verbs, so it's worth learning them as a set rather than one at a time.

## Key Points / Conjugation / Rules

**Group 1 — Stem-changing _-ir_ verbs:** these change their stem vowel (*e → i* or
*o → u*) in the gerund, the same kind of change you may have already seen in their
preterite conjugation.

| Infinitive | Gerund     | English    |
| ------------ | ------------ | ------------ |
| decir        | diciendo     | saying       |
| pedir        | pidiendo     | asking for   |
| seguir       | siguiendo    | following    |
| dormir       | durmiendo    | sleeping     |
| morir        | muriendo     | dying        |

**Group 2 — Verbs with a vowel before the ending:** when the verb stem ends in a
vowel, the regular *-iendo* would create an awkward three-vowel cluster, so Spanish
swaps the *i* for a *y*.

| Infinitive | Gerund       | English    |
| ------------ | -------------- | ------------ |
| leer         | leyendo        | reading      |
| oír          | oyendo         | hearing      |
| construir    | construyendo   | building     |
| destruir     | destruyendo    | destroying   |
| incluir      | incluyendo     | including    |
| traer        | trayendo       | bringing     |

- These irregular gerunds still combine with *estar* the same way regular ones do:
  **[conjugated _estar_] + [irregular gerund]**.
- The stem-changing group (Group 1) matches the same *e→i* or *o→u* pattern many of
  these verbs already show in the *usted/él/ella* and *ustedes/ellos/ellas* preterite
  forms — if you know *durmió*, *durmiendo* follows the same logic.

## Examples

| Spanish                              | English                        | Notes                                  |
| --------------------------------------- | --------------------------------- | ------------------------------------------ |
| El bebé está durmiendo ahora.           | The baby is sleeping right now.   | Group 1, *o→u* stem change             |
| ¿Qué estás diciendo?                    | What are you saying?              | Group 1, *e→i* stem change             |
| Estoy leyendo una novela.               | I'm reading a novel.              | Group 2, vowel-stem *y* insertion      |
| Están construyendo un edificio nuevo.   | They're building a new building.  | Group 2, vowel-stem *y* insertion      |
| Marta está siguiendo las instrucciones. | Marta is following the instructions. | Group 1, *e→i* stem change          |
| Estamos oyendo un ruido extraño.        | We're hearing a strange noise.    | Group 2, vowel-stem *y* insertion      |

## Common Mistakes

- Writing *diciendo* as *deciendo*, keeping the regular stem instead of applying the
  *e→i* change.
- Writing *leendo* instead of *leyendo* — forgetting the *y* that breaks up the vowel
  cluster.
- Assuming every *-ir* verb is regular. Only some *-ir* verbs stem-change; regular
  ones like *vivir* just take plain *-iendo* (*viviendo*).
