## Explanation

Spanish has two common ways to say someone has to (or should) do something, and they
carry slightly different weight. *Tener que* + infinitive expresses a real obligation —
something you have to do, often because of an outside requirement like work or a
schedule. *Deber* + infinitive is softer — closer to "should" than "have to" — a
recommendation or moral expectation rather than a hard requirement.

## Key Points / Conjugation / Rules

**_Tener que_ + infinitive** (strong obligation, "have to"):

| Subject               | Conjugation of _tener_ |
| ----------------------- | ------------------------- |
| yo                      | tengo                     |
| tú                      | tienes                    |
| usted / él / ella       | tiene                     |
| nosotros / nosotras     | tenemos                   |
| ustedes / ellos / ellas | tienen                    |

- Formula: **[conjugated _tener_] + que + [infinitive]**
- *Tengo que trabajar mañana.* (I have to work tomorrow.)
- The *que* here doesn't translate as "what" or "that" — it's just a fixed part of the
  formula, not a separate word to think about.

**_Deber_ + infinitive** (softer obligation, "should"):

| Subject               | Conjugation of _deber_ |
| ----------------------- | ------------------------- |
| yo                      | debo                      |
| tú                      | debes                     |
| usted / él / ella       | debe                      |
| nosotros / nosotras     | debemos                   |
| ustedes / ellos / ellas | deben                     |

- Formula: **[conjugated _deber_] + [infinitive]** — no *que* needed here.
- *Debo estudiar más.* (I should study more.)

**Days of the week with obligation:** Spanish uses the definite article (*el, la*)
when naming a specific day an obligation falls on: *Tengo que trabajar el lunes.* (I
have to work on Monday.)

## Examples

| Spanish                                | English                              | Notes                              |
| ------------------------------------------ | --------------------------------------- | -------------------------------------- |
| Tengo que terminar este proyecto hoy.      | I have to finish this project today.    | strong obligation, *yo* form        |
| ¿Tienes que trabajar el sábado?            | Do you have to work on Saturday?        | question with day + definite article |
| Marta tiene que llamar al médico.          | Marta has to call the doctor.           | *al* contraction, *ella* form       |
| Debemos llegar temprano a la reunión.      | We should arrive early to the meeting.  | softer obligation, *nosotros* form  |
| Deberías comer algo antes de salir.        | You should eat something before leaving. | conditional-flavored *deber* form   |
| Los estudiantes deben entregar la tarea.   | The students should turn in the homework. | *ellos* form, general recommendation |

## Common Mistakes

- Dropping the *que* after *tener*: *Tengo trabajar* is wrong — it must be *Tengo que
  trabajar*.
- Adding *que* after *deber*: *Debo que estudiar* is wrong — *deber* takes the
  infinitive directly, with no *que*.
- Treating *tener que* and *deber* as interchangeable. *Tener que* signals a real
  requirement; *deber* is closer to advice or a mild expectation.
