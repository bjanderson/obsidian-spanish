## Explanation

*Poder* + infinitive is how Spanish expresses "can" or "to be able to" — whether
that's physical ability, permission, or simply circumstances allowing something to
happen. It works the same way as *querer* (to want) and *tener que* (to have to):
conjugate the modal verb, then add the main verb in the infinitive.

## Key Points / Conjugation / Rules

**Present tense of _poder_** (stem-changing: *o → ue*, except *nosotros*):

| Subject               | Conjugation |
| ----------------------- | ------------- |
| yo                      | puedo         |
| tú                      | puedes        |
| usted / él / ella       | puede         |
| nosotros / nosotras     | podemos       |
| ustedes / ellos / ellas | pueden        |

- Formula: **[conjugated _poder_] + [infinitive]**
- *¿Puedo confirmar la reserva?* can mean "Can I confirm the reservation?" (asking
  about ability/possibility) or "May I confirm the reservation?" (asking permission)
  — context decides which.
- The subject pronoun is usually dropped, since the *poder* conjugation already shows
  who's involved: *Puedo estudiar* (not *Yo puedo estudiar*), unless you need it for
  clarity or emphasis.

## Examples

| Spanish                                     | English                                | Notes                              |
| ----------------------------------------------- | ------------------------------------------ | -------------------------------------- |
| ¿Puedes trabajar el sábado?                     | Can you work on Saturday?                  | *tú* form, day + no article for habitual pattern |
| No puedo salir hoy, tengo mucho trabajo.        | I can't go out today, I have a lot of work. | negation with *no* before *puedo*   |
| ¿Me puedes ayudar a buscar las llaves?          | Can you help me look for the keys?         | *ayudar a* + infinitive construction |
| Marta no puede venir a la fiesta.               | Marta can't come to the party.             | *ella* form                         |
| ¿Podemos hablar un momento?                     | Can we talk for a moment?                  | *nosotros* form, polite request     |
| Quiero trabajar los sábados, pero no puedo.     | I want to work on Saturdays, but I can't.  | contrast with *querer*              |

## Common Mistakes

- Forgetting the stem change: writing *podo* instead of *puedo* for *yo*.
- Applying the *o→ue* change to *nosotros*: it stays *podemos*, not *puedemos*.
- Confusing *poder* (ability/possibility) with *saber* (knowing how to do something,
  like a skill). *Puedo nadar* can mean "I'm physically able to swim right now"; *Sé
  nadar* means "I know how to swim" as a skill.
