## Explanation

*Ir a* + infinitive is the go-to structure for plans that already feel decided — things
you or someone else intends to do soon. Time expressions are what usually trigger it:
words and phrases that point at "later today," "tomorrow," or "this coming week" pull
the sentence toward *ir a*, rather than the simple future tense (which you'll meet
later and which leans more toward guesses, promises, or distant/formal plans).

These time expressions can go at the start or end of the sentence — both are natural.

## Key Points / Conjugation / Rules

**Common near-future time expressions:**

| Spanish             | English                  |
| -------------------- | ------------------------- |
| hoy                  | today                     |
| esta noche           | tonight                   |
| mañana               | tomorrow                  |
| pasado mañana        | the day after tomorrow    |
| esta semana          | this week                 |
| este fin de semana   | this weekend              |
| la próxima semana    | next week                 |
| el próximo mes       | next month                |
| más tarde            | later                     |
| en un rato           | in a little while         |
| dentro de poco       | soon / shortly            |

- Placement is flexible: *Mañana voy a viajar* and *Voy a viajar mañana* both work.
- These expressions pair naturally with *ir a* because they describe near, already-decided
  plans — the same logic as English "going to."
- Some of these (*esta semana*, *el próximo mes*) can also pair with the simple future
  tense for more distant or less certain plans — the time expression itself doesn't
  force *ir a*, but it's the most common natural pairing at this stage.

## Examples

| Spanish                                             | English                                     | Notes                                  |
| ----------------------------------------------------- | --------------------------------------------- | ---------------------------------------- |
| Esta noche voy a cenar con mi familia.                | Tonight I'm going to have dinner with my family. | time expression at the start           |
| Vamos a limpiar la casa este fin de semana.           | We're going to clean the house this weekend.   | time expression at the end             |
| Mi hermano va a graduarse el próximo mes.             | My brother is going to graduate next month.    | *él* form with future month            |
| ¿Vas a salir mañana por la noche?                     | Are you going to go out tomorrow night?        | combined time expression               |
| Voy a llamarte en un rato.                            | I'm going to call you in a little while.       | attached object pronoun *-te*          |
| Van a mudarse la próxima semana.                      | They're going to move next week.               | *ellos* form                           |

## Common Mistakes

- Placing the time expression correctly is flexible, but forgetting it entirely makes
  a near-future statement sound vague — include it when the timing matters to the
  conversation.
- Confusing *pasado mañana* ("day after tomorrow") with *el mes pasado* ("last month")
  — *pasado* changes meaning depending on word order and context.
- Using *en* instead of *dentro de* for "in [amount of time]": *dentro de poco* (soon),
  not *en poco*.
