## Explanation

Booking a room, checking in, and sorting out the details of a stay are essential
travel skills. This lesson covers the vocabulary and phrases you need to make a hotel
reservation, check in and out, and handle common logistics during your stay.

## Key Points / Conjugation / Rules

**Making a reservation:**

| Spanish                        | English            |
| ----------------------------------- | ---------------------- |
| la reservación / la reserva          | reservation              |
| reservar                             | to reserve/book           |
| la habitación                        | room                     |
| sencilla / doble                     | single / double (room)     |
| disponible                           | available                |
| ¿Tiene habitaciones disponibles?     | Do you have rooms available? |

**Checking in and out:**

| Spanish                        | English            |
| ----------------------------------- | ---------------------- |
| registrarse / hacer el check-in      | to check in               |
| la recepción                         | front desk               |
| el/la recepcionista                  | receptionist              |
| la llave                             | key                       |
| la hora de salida                    | checkout time             |
| dejar la habitación                  | to check out (leave room)  |

**Travel logistics:**

| Spanish                        | English            |
| ----------------------------------- | ---------------------- |
| el equipaje                          | luggage                  |
| la maleta                            | suitcase                 |
| el itinerario                        | itinerary                |
| confirmar                            | to confirm                |
| cancelar                             | to cancel                 |
| incluido/a                           | included                 |

- Use *tener* + noun to ask about availability: *¿Tiene habitaciones disponibles?*
  (Do you have rooms available?) — same pattern as other *tener* questions you already
  know.
- *Reservación* and *reserva* both mean "reservation" — *reserva* is more common
  across Latin America generally, *reservación* is common in Mexico specifically;
  both are understood everywhere.
- To ask for something at the front desk, use polite requests: *¿Podría darme otra
  toalla?* (Could you give me another towel?) or *Necesito...* (I need...).
- *Incluido* must agree in gender/number with what it describes: *el desayuno está
  incluido* (breakfast is included), *las toallas están incluidas* (the towels are
  included).

## Examples

| Spanish                                    | English                              | Notes                    |
| --------------------------------------------- | ------------------------------------------ | ------------------------------ |
| Quiero reservar una habitación doble.         | I'd like to book a double room.              | *reservar*, *doble*             |
| ¿A qué hora es el check-out?                  | What time is checkout?                       | common phrase                   |
| Tengo una reservación a nombre de García.     | I have a reservation under the name García.  | *reservación*, *a nombre de*    |
| ¿El desayuno está incluido?                   | Is breakfast included?                        | *incluido*, agreement           |
| Perdí la llave de mi habitación.              | I lost my room key.                           | *llave*, past                   |
| Necesito confirmar mi reservación para mañana. | I need to confirm my reservation for tomorrow. | *confirmar*                    |

## Common Mistakes

- Forgetting gender/number agreement on *incluido*: *el desayuno está incluida* is
  wrong — *desayuno* is masculine, so it must be *incluido*.
- Using *cuarto* and *habitación* as if only one is correct — both mean "room" and are
  used interchangeably in most countries, though *habitación* is slightly more formal
  and common in hotel contexts specifically.
- Saying *hacer una reservación* without the personal touch of stating your name — most
  hotel interactions expect you to give a name: *a nombre de...*.
- Mixing up *dejar la habitación* (to check out/leave the room) with *dejar de* + verb
  (to stop doing something) — same verb, different structure and meaning.
