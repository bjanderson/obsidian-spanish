## Explanation

Once you can describe how you feel (see [[A2.4.6.1 Body Parts and Symptoms]]), the
next step is handling the actual visit — booking an appointment, explaining your
symptoms to the doctor, understanding their instructions, and then following up at
the pharmacy.

These conversations follow a predictable shape almost everywhere in Latin America:
you request an appointment (_pedir una cita_), the doctor asks what's wrong (_¿Qué
le pasa?_) and examines you, then gives instructions and maybe a prescription (_una
receta_). At the pharmacy, you either fill that prescription or ask the pharmacist
directly for something (_¿Tiene algo para...?_) — in many Latin American countries,
pharmacists can recommend over-the-counter treatment for minor issues without a
doctor's visit.

## Key Points / Conjugation / Rules

- _Pedir/sacar una cita_ — to make an appointment. _Necesito sacar una cita con el
  médico._
- _¿Qué le pasa?_ / _¿Qué tiene?_ — "What's wrong?" (formal _usted_, as a doctor
  would ask a patient).
- _Desde hace_ + time — how long a symptom has lasted: _Tengo tos desde hace tres
  días_ ("I've had a cough for three days").
- _Recetar_ (to prescribe) / _la receta_ (the prescription): _El médico me recetó
  un jarabe._
- Instructions often use the command form or _tener que_: _Tome esta pastilla cada
  ocho horas_ (command) or _Tiene que descansar_ ("You have to rest").
- At the pharmacy: _¿Tiene algo para...?_ ("Do you have something for...?"), _¿Se
  necesita receta para esto?_ ("Is a prescription needed for this?").
- Common items: _la pastilla_ (pill), _el jarabe_ (syrup), _la inyección_
  (injection), _la venda_ (bandage), _las gotas_ (drops).

## Examples

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Necesito sacar una cita con el médico para mañana. | I need to make an appointment with the doctor for tomorrow. | |
| Doctor, tengo dolor de garganta desde hace cuatro días. | Doctor, I've had a sore throat for four days. | _Desde hace_ + duration. |
| El médico me recetó unas pastillas para la fiebre. | The doctor prescribed me some pills for the fever. | |
| Tiene que tomar esta medicina cada ocho horas. | You have to take this medicine every eight hours. | Formal _usted_ instruction. |
| ¿Tiene algo para el dolor de cabeza? | Do you have something for a headache? | Common pharmacy phrase. |
| ¿Se necesita receta para este jarabe? | Is a prescription needed for this syrup? | |
| El farmacéutico me recomendó unas gotas para los ojos. | The pharmacist recommended some eye drops for me. | |
| Después de la consulta, fui a la farmacia por la receta. | After the appointment, I went to the pharmacy for the prescription. | |
