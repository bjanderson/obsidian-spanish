## Explanation

You probably already know the core family words — *madre, padre, hermano, hermana*.
This lesson fills out the rest of the family tree: grandparents, cousins, in-laws, and
step-family. Family is a huge part of everyday conversation in Spanish-speaking
cultures, so these words come up constantly once you get past small talk.

Most of these words follow a simple pattern: change the ending to switch gender
(*abuelo* → *abuela*), or add a prefix like *bis-* (great-) to go back a generation.
Once you see the pattern, the whole extended family tree is easy to build from just a
handful of new words.

## Key Points / Conjugation / Rules

**Grandparents and great-grandparents:**

| Spanish            | English            |
| -------------------- | -------------------- |
| el abuelo / la abuela | grandfather / grandmother |
| los abuelos           | grandparents           |
| el bisabuelo / la bisabuela | great-grandfather / great-grandmother |
| el nieto / la nieta   | grandson / granddaughter |

**Aunts, uncles, and cousins:**

| Spanish          | English         |
| ------------------ | ----------------- |
| el tío / la tía     | uncle / aunt       |
| el primo / la prima | cousin (m/f)       |
| el sobrino / la sobrina | nephew / niece |

**In-laws (add _-político/-a_ or use a dedicated word):**

| Spanish              | English            |
| ---------------------- | ---------------------- |
| el suegro / la suegra   | father-in-law / mother-in-law |
| el yerno / la nuera     | son-in-law / daughter-in-law |
| el cuñado / la cuñada   | brother-in-law / sister-in-law |

**Step-family (use _-astro/-astra_):**

| Spanish                | English            |
| ------------------------- | ---------------------- |
| el padrastro / la madrastra | stepfather / stepmother |
| el hermanastro / la hermanastra | stepbrother / stepsister |
| el hijastro / la hijastra | stepson / stepdaughter |

- *Bis-* means "great-" — *bisabuelo* (great-grandfather), *bisnieto*
  (great-grandson). Add another *bis-* for "great-great" (*tatarabuelo*, less common).
- In-law words aren't built the same way in Spanish as in English (there's no single
  "-in-law" suffix) — each relationship has its own dedicated word, so these are worth
  memorizing individually.
- *-astro/-astra* marks step-family. It has a slightly negative connotation
  historically (from an old sense of "false" or "inferior"), but it's the standard,
  neutral term in everyday modern use.
- *Los abuelos*, *los tíos*, *los primos* — the masculine plural covers a mixed-gender
  group, same rule as elsewhere in Spanish grammar (*los tíos* can mean "aunts and
  uncles" together, not only "uncles").

## Examples

| Spanish                                       | English                                | Notes                      |
| ---------------------------------------------- | ----------------------------------------- | ------------------------------- |
| Mi abuela vive con mis padres.                  | My grandmother lives with my parents.       | *abuela*                       |
| Tengo tres primos por parte de mi mamá.         | I have three cousins on my mom's side.      | *primos*, *por parte de*        |
| Mi suegra viene a cenar el domingo.             | My mother-in-law is coming for dinner Sunday. | *suegra*                    |
| Mi hermanastro y yo nos llevamos muy bien.      | My stepbrother and I get along really well. | *hermanastro*                 |
| Mis sobrinos son muy traviesos.                 | My nephews/nieces are very mischievous.      | *sobrinos*, mixed group        |
| Mi bisabuelo llegó a México hace cien años.     | My great-grandfather arrived in Mexico a hundred years ago. | *bisabuelo*, *a México* |

## Common Mistakes

- Using *tío/tía* only for actual aunts/uncles — in casual speech across Latin
  America, close family friends are sometimes called *tío/tía* out of affection, but
  don't assume every *tío* mentioned is a blood relative without context.
- Forgetting that *-astro/-astra* only applies to step-relationships through marriage,
  not to half-siblings — a half-brother/sister (same one parent) is *medio hermano* /
  *media hermana*, not *hermanastro/hermanastra*.
- Mixing up *yerno* (son-in-law) and *nuera* (daughter-in-law) — they aren't
  gender-matched to the in-law's side the way English speakers might expect; *yerno*
  is always male, *nuera* always female, regardless of whose child they married.
- Saying *tío-en-ley* or other literal "in-law" translations — Spanish doesn't build
  in-law terms with a suffix, each relationship has its own word.
