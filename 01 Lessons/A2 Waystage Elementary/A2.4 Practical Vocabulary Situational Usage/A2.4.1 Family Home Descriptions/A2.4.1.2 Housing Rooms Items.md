## Explanation

Talking about where you live and what's inside your home comes up constantly —
describing your apartment to a new friend, following directions around someone else's
house, or shopping for furniture. This lesson covers three layers: the type of home
itself, the rooms inside it, and the everyday items that fill those rooms.

## Key Points / Conjugation / Rules

**Types of housing:**

| Spanish              | English            |
| ----------------------- | ---------------------- |
| la casa                 | house                   |
| el apartamento / el departamento | apartment (*departamento* common in Mexico/southern cone) |
| el edificio              | building                |
| el condominio            | condo                   |
| el estudio               | studio apartment        |

**Rooms of the house:**

| Spanish              | English            |
| ----------------------- | ---------------------- |
| la sala / la sala de estar | living room          |
| la cocina                | kitchen                |
| el comedor               | dining room             |
| la recámara / el dormitorio | bedroom              |
| el baño                  | bathroom                |
| el patio                 | patio/yard              |
| el garaje                | garage                  |

**Parts of a room:**

| Spanish       | English      |
| --------------- | -------------- |
| la ventana      | window          |
| la puerta       | door            |
| el piso         | floor           |
| el techo        | ceiling         |
| la pared        | wall            |
| la escalera     | staircase       |
| el interruptor  | light switch    |

**Furniture and domestic items:**

| Spanish       | English      |
| --------------- | -------------- |
| la mesa         | table           |
| la silla        | chair           |
| el sofá         | sofa, couch     |
| la cama         | bed             |
| el escritorio   | desk            |
| la cómoda       | dresser         |
| el espejo       | mirror          |
| la lámpara      | lamp            |
| las cortinas    | curtains        |

- *Departamento* and *apartamento* both mean "apartment" — usage varies by country;
  either is understood everywhere, but *departamento* is more common in Mexico and the
  Southern Cone.
- *Recámara* and *dormitorio* both mean "bedroom" — *recámara* is especially common in
  Mexico, *dormitorio* is more broadly neutral across the region.
- Furniture words vary more by country than most vocabulary: *el ropero* (wardrobe) is
  called *el armario* in some countries, and *el tapete* (rug) is *la alfombra*
  elsewhere. Both forms are worth recognizing even if you settle on one to use.
- Use *estar* to say where something is located: *La cama está en la recámara* (The
  bed is in the bedroom) — location uses *estar*, not *ser*.

## Examples

| Spanish                                    | English                              | Notes                    |
| --------------------------------------------- | ----------------------------------------- | ----------------------------- |
| Vivo en un apartamento pequeño.               | I live in a small apartment.                | *apartamento*                |
| La sala tiene un sofá y dos sillones.         | The living room has a sofa and two armchairs. | *sala*, furniture           |
| Mi cama está cerca de la ventana.             | My bed is near the window.                  | *estar*, location            |
| ¿Dónde está el interruptor de la cocina?      | Where's the kitchen light switch?           | *estar*, *del* not used (de la) |
| El comedor está al lado de la cocina.         | The dining room is next to the kitchen.      | *al lado de*                 |
| Compramos una cómoda nueva para la recámara.  | We bought a new dresser for the bedroom.     | *recámara*                   |

## Common Mistakes

- Confusing *piso* (floor, as in flooring) with *piso* meaning "apartment" in Spain —
  in Latin American Spanish, stick to *apartamento/departamento*; *piso* here means
  the floor you walk on.
- Mixing up *casa* and *hogar* — *casa* is the physical house/building, *hogar* is
  "home" in the emotional sense (a *hogar* can exist without being a *casa*, like a
  found family). Use *casa* for the building itself.
- Using *ser* instead of *estar* to say where something is: *La mesa es en la cocina*
  is wrong — location always takes *estar*: *La mesa está en la cocina*.
- Assuming furniture vocabulary is identical everywhere — if a word sounds unfamiliar
  to someone from a different country, it's often just regional variation, not a
  mistake.
