## Explanation

Talking about the weather is small talk in any language, and Spanish has its own
particular way of doing it. Unlike English, where "it is" covers almost everything
weather-related, Spanish splits weather expressions across three different verbs —
*hacer*, *estar*, and *haber* — depending on the type of weather. Once you learn which
verb goes with which kind of weather, the pattern is very consistent.

## Key Points / Conjugation / Rules

**_Hacer_ — for general atmospheric conditions (literally "it makes"):**

| Spanish            | English            |
| ---------------------- | ---------------------- |
| Hace calor.             | It's hot.                |
| Hace frío.              | It's cold.               |
| Hace sol.               | It's sunny.              |
| Hace viento.            | It's windy.              |
| Hace buen tiempo.       | The weather is nice.      |
| Hace mal tiempo.        | The weather is bad.       |

**_Estar_ — for ongoing conditions/actions (like a gerund, "-ing"):**

| Spanish            | English            |
| ---------------------- | ---------------------- |
| Está lloviendo.         | It's raining.            |
| Está nevando.           | It's snowing.            |
| Está nublado.           | It's cloudy.              |
| Está despejado.         | It's clear (sky).         |

**_Haber_ — for weather that "exists" (always the impersonal _hay_ form):**

| Spanish            | English            |
| ---------------------- | ---------------------- |
| Hay niebla.             | It's foggy. (There is fog.) |
| Hay tormenta.           | There's a storm.          |
| Hay nubes.              | It's cloudy. (There are clouds.) |

- *Hacer* is used for the biggest category: temperature, sun, and wind — things that
  feel like ongoing atmospheric traits rather than one-time events.
- *Estar* pairs with weather that's actively happening right now, matching its normal
  use with the gerund (*-ando/-iendo*) for actions in progress.
- *Haber* always stays in its impersonal third-person singular form *hay* for weather
  — never conjugate it to match a plural noun (*hay nubes*, not *han nubes*).
- Use *mucho* with *hacer* weather nouns for emphasis (*Hace mucho calor*), but *muy*
  with *estar* + adjective (*Está muy nublado*) — the same *mucho/muy* split that
  applies elsewhere with *hacer* vs. *estar*.
- To ask about the weather: *¿Qué tiempo hace?* (What's the weather like?) is the
  standard question.

## Examples

| Spanish                                    | English                              | Notes                    |
| --------------------------------------------- | ------------------------------------------ | ------------------------------ |
| Hace mucho calor hoy.                         | It's very hot today.                        | *hacer*, *mucho*                |
| ¿Qué tiempo hace en tu ciudad?                | What's the weather like in your city?        | *hacer*, question                |
| Está lloviendo desde la mañana.               | It's been raining since morning.             | *estar*, gerund                 |
| Hay mucha niebla en la carretera.             | There's a lot of fog on the highway.          | *haber*, *hay*                  |
| Va a hacer frío este fin de semana.           | It's going to be cold this weekend.           | *ir a* + *hacer*                |
| El cielo está muy nublado esta tarde.         | The sky is very cloudy this afternoon.        | *estar*, *muy*                  |

## Common Mistakes

- Using *estar* for general atmospheric conditions: *Está calor* is wrong — heat/cold/
  sun/wind use *hacer*: *Hace calor*.
- Using *mucho* with an *estar* + adjective weather expression: *Está mucho nublado*
  is wrong — use *muy*: *Está muy nublado*.
- Conjugating *haber* to agree with a plural noun: *Han nubes* is wrong — *haber*
  stays as *hay* regardless of what follows: *Hay nubes*.
- Translating "it is" too literally with *ser*: Spanish never uses *ser* for weather
  conditions — *Es lluvia* is wrong for "it's raining"; use *Está lloviendo*.
