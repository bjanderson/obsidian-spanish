## Explanation

Now that you know what direct object pronouns are, the next question is
where they go in the sentence. Spanish handles this differently from
English — instead of coming after the verb like in English ("I see it"),
the pronoun usually comes *before* the conjugated verb.

When there's just one conjugated verb, the rule is simple: pronoun first,
verb second. *Lo veo* ("I see it"), not *veo lo*. *La conozco* ("I know
her"), not *conozco la*.

Things get more flexible when there are two verbs together — a conjugated
verb plus an infinitive. In that case, you have two equally correct options:
put the pronoun before the conjugated verb, or attach it directly to the end
of the infinitive. *La quiero ver* and *Quiero verla* both mean "I want to
see it" — same meaning, just a different position for the pronoun. Native
speakers use both interchangeably, so pick whichever feels more natural.

The same flexibility applies to a conjugated verb + gerund (the *-ndo* form):
you can say *Lo estoy leyendo* or *Estoy leyéndolo* ("I am reading it") —
notice the accent mark that gets added when the pronoun attaches to the
gerund, to keep the stress in the same place.

## Key Points / Conjugation / Rules

| Structure                          | Pronoun Placement                              | Example                       |
| ------------------------------------- | -------------------------------------------------- | ---------------------------------- |
| Single conjugated verb                 | before the verb                                     | *Lo veo.*                          |
| Conjugated verb + infinitive           | before the conjugated verb, OR attached to infinitive | *La quiero ver.* / *Quiero verla.* |
| Conjugated verb + gerund               | before the conjugated verb, OR attached to gerund   | *Lo estoy leyendo.* / *Estoy leyéndolo.* |

- With only one conjugated verb, the pronoun **must** go before it — there's
  no flexibility here.
- With a conjugated verb + infinitive or gerund, both placements are
  correct and mean the same thing — this is a stylistic choice, not a rule
  with a right answer.
- When a pronoun attaches to a gerund, add a written accent to keep the
  original stress: *leyendo → leyéndolo*, *escribiendo → escribiéndolo*.
- When a pronoun attaches to an infinitive, no accent is needed —
  *verla*, *conocerlo*, *comprarlos* stay as written.

## Examples

| Spanish                              | English                        | Notes                          |
| ---------------------------------------- | ----------------------------------- | ----------------------------------- |
| La conozco desde hace años.              | I've known her for years.           | single verb, pronoun before          |
| ¿Quieres verla esta noche?               | Do you want to see it tonight?      | infinitive, pronoun attached         |
| La quiero ver esta noche.                | I want to see it tonight.            | infinitive, pronoun before conjugated verb |
| Estoy escribiéndolo ahora mismo.         | I'm writing it right now.           | gerund, pronoun attached + accent    |
| Lo estoy escribiendo ahora mismo.        | I'm writing it right now.           | gerund, pronoun before               |
| Los necesito para mañana.                | I need them for tomorrow.           | single verb, pronoun before          |

## Common Mistakes

- Placing the pronoun after a single conjugated verb — *Veo la* is wrong; it
  must be *La veo*.
- Forgetting the accent when attaching a pronoun to a gerund — *leyendolo*
  should be *leyéndolo*.
- Splitting the two-verb combination incorrectly — the pronoun attaches to
  the infinitive/gerund itself, not floating somewhere else in the sentence.
