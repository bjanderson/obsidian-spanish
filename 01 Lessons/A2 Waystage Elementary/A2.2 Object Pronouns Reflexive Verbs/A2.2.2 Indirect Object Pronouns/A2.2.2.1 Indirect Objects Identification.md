## Explanation

You already know the direct object — the thing the verb acts on directly. The
indirect object is different: it's the person *to* or *for* whom the action
happens. In *Le di el libro a Juan* ("I gave the book to Juan"), *el libro*
is what got given (direct object), and *Juan* is who received it (indirect
object).

A quick trick for spotting an indirect object: ask "to whom?" or "for whom?"
after the verb. *Le escribí una carta* ("I wrote a letter to him/her") — who
did I write it to? *Le* answers that.

Here are the indirect object pronouns:

| Pronoun | Meaning              |
| -------- | ------------------------ |
| me       | to/for me                 |
| te       | to/for you (informal)     |
| le       | to/for him/her/usted      |
| nos      | to/for us                 |
| les      | to/for them/ustedes       |

Notice something important: unlike direct object pronouns, *le* and *les*
**don't change for gender** — the same *le* works for "to him," "to her," and
"to usted." Only *les* changes to show plural.

Just like direct objects, indirect object pronouns go before a single
conjugated verb (*Le escribo*), and can go either before the conjugated verb
or attached to an infinitive/gerund when there are two verbs (*Le quiero
escribir* / *Quiero escribirle*).

## Key Points / Conjugation / Rules

- An indirect object answers "to whom?" or "for whom?" — the recipient or
  beneficiary of the action, not the thing being acted on.
- Indirect object pronouns: *me, te, le, nos, les* — note there's no
  masculine/feminine split for *le*/*les*, unlike *lo/la* and *los/las*.
- Placement follows the same rules as direct object pronouns: before a
  single conjugated verb, or before/attached with a conjugated verb +
  infinitive or gerund.
- Many verbs of giving, telling, and communicating (*dar, decir, escribir,
  contar*) naturally take an indirect object — anything with a sender and a
  receiver.

## Examples

| Spanish                          | English                              | Notes                    |
| ------------------------------------ | ------------------------------------------- | ------------------------------ |
| Le di el libro a Juan.               | I gave the book to Juan.                    | *le*, indirect object            |
| ¿Me puedes explicar esto?            | Can you explain this to me?                 | *me*, indirect object            |
| Les escribí un mensaje.              | I wrote them a message.                     | *les*, indirect object            |
| Nos mandaron una invitación.         | They sent us an invitation.                 | *nos*, indirect object            |
| Le compré un regalo a mi mamá.       | I bought my mom a gift.                     | *le*, indirect object, benefactive |
| ¿Te dijo la verdad?                  | Did he/she tell you the truth?              | *te*, indirect object            |

## Common Mistakes

- Confusing indirect and direct objects — in *Le di el libro*, *el libro* is
  the direct object (*lo* would replace it), and *Juan* is the indirect
  object (*le* replaces it). Don't use *lo* for the person here.
- Trying to make *le* or *les* agree with gender — they only change for
  number, never gender.
- Using a direct object pronoun (*lo/la*) where an indirect one (*le*) is
  needed — verbs like *decir* and *dar* take an indirect object for the
  person, since the thing said/given is the direct object.
