## Explanation

A whole group of common, high-frequency verbs swap out their entire stem in
the preterite — not just the ending. *Tener* (to have) doesn't build on
*ten-*; it builds on a new stem, *tuv-*. *Estar* (to be) builds on *estuv-*,
and *poder* (to be able to) builds on *pud-*. Once you have the new stem, all
six of these verbs share exactly the same set of endings.

Take *tener*: swap in the stem *tuv-*, then add *-e* for *yo* (*tuve*, "I
had"), *-iste* for *tú* (*tuviste*), and so on. Notice something important:
none of these endings carry a written accent, unlike the regular preterite
*yo*/*él* forms (*hablé*, *comió*). That's actually a clue you're dealing with
one of these irregular-stem verbs.

Here are the six most common verbs in this group and their new stems:

- *tener* → *tuv-* (*tuve*, "I had")
- *estar* → *estuv-* (*estuve*, "I was")
- *poder* → *pud-* (*pude*, "I was able to")
- *poner* → *pus-* (*puse*, "I put")
- *venir* → *vin-* (*vine*, "I came")
- *hacer* → *hic-* (*hice*, "I did/made" — note the *c* becomes *z* only in
  the *él/ella/usted* form: *hizo*, to keep the "s" sound)

## Key Points / Conjugation / Rules

| Subject             | Ending | *tener*  | *estar*    | *poder*  |
| -------------------- | ------ | -------- | ---------- | -------- |
| yo                    | -e     | tuve     | estuve     | pude     |
| tú                    | -iste  | tuviste  | estuviste  | pudiste  |
| él / ella / usted     | -o     | tuvo     | estuvo     | pudo     |
| nosotros              | -imos  | tuvimos  | estuvimos  | pudimos  |
| ellos / ustedes       | -ieron | tuvieron | estuvieron | pudieron |

- These verbs replace their stem entirely, then use one shared set of endings:
  *-e, -iste, -o, -imos, -ieron*.
- None of these endings carry a written accent — that's a giveaway you're in
  this irregular group, not the regular preterite pattern.
- *Poner* → *pus-*, *venir* → *vin-*, and *hacer* → *hic-* follow the exact
  same ending pattern: *puse*, *vine*, *hice*.
- *Hacer*'s *él/ella/usted* form is *hizo*, not *hico* — the spelling changes
  to keep the "s" sound consistent.

## Examples

| Spanish                                | English                             | Notes                    |
| ---------------------------------------- | -------------------------------------- | --------------------------- |
| Tuve mucho trabajo esta semana.          | I had a lot of work this week.         | *tener*, *yo*                |
| ¿Estuviste en la reunión ayer?           | Were you at the meeting yesterday?     | *estar*, *tú*                |
| Ella no pudo terminar el examen a tiempo. | She couldn't finish the exam on time.  | *poder*, *ella*              |
| Pusimos las maletas en el carro.         | We put the suitcases in the car.       | *poner*, *nosotros*          |
| Mis amigos vinieron a visitarme.         | My friends came to visit me.           | *venir*, *ellos*             |
| Hizo mucho frío anoche.                  | It was very cold last night.           | *hacer*, impersonal weather use |

## Common Mistakes

- Adding a written accent to these forms — *tuve*, *estuvo*, *pudiste* never
  carry an accent mark.
- Trying to build these from the regular stem (*ten-*, *pod-*, *ven-*) instead
  of memorizing the irregular stem (*tuv-*, *pud-*, *vin-*).
- Writing *hico* instead of *hizo* for "he/she did" — the *c* becomes *z*
  before *o* to preserve the sound.
