## Explanation

You already know that the imperfect paints the background and the preterite
delivers the main event. There's one pattern that uses this contrast in a
very specific, very common way: the interrupted action.

The formula is: **imperfect verb + *cuando* + preterite verb**. The imperfect
half describes something that was already in progress; the preterite half is
the sudden event that cuts into it. *Estaba durmiendo cuando sonó el
teléfono* ("I was sleeping when the phone rang") — the sleeping was ongoing
(imperfect), and the ringing is the one moment that broke into it
(preterite).

You can flip the order of the two halves without changing which tense goes
where: *Cuando sonó el teléfono, estaba durmiendo* means the same thing —
*sonó* is still preterite, *estaba durmiendo* is still imperfect, no matter
which clause comes first.

*Mientras* ("while") works similarly but usually pairs two imperfect verbs
happening at the same time, rather than one interrupting the other:
*Mientras cocinaba, escuchaba música* ("While I was cooking, I was listening
to music") — both actions are ongoing and parallel, not one cutting into the
other. If a *mientras* sentence has a sudden, one-time event in it, that part
still switches to the preterite: *Mientras cocinaba, sonó el teléfono*
("While I was cooking, the phone rang").

## Key Points / Conjugation / Rules

| Pattern                                   | Formula                              | Meaning                                |
| -------------------------------------------- | ---------------------------------------- | ------------------------------------------ |
| Interrupted action                            | imperfect + *cuando* + preterite         | one event cuts into an ongoing action       |
| Two parallel ongoing actions                  | imperfect + *mientras* + imperfect       | both actions happening at the same time     |
| An event during an ongoing background action  | imperfect + *mientras* + preterite       | the ongoing action is the setting; the event interrupts |

- *Cuando* is almost always followed by the preterite when it introduces the
  interrupting event — even if it comes first in the sentence.
- Word order (which clause comes first) never changes which verb takes which
  tense — only the meaning/relationship between the two clauses does.
- *Mientras* defaults to pairing two imperfects for parallel actions, but
  takes a preterite in the second clause if that clause is a one-time
  interrupting event rather than an ongoing one.

## Examples

| Spanish                                          | English                                     | Notes                       |
| ----------------------------------------------------- | ---------------------------------------------- | -------------------------------- |
| Estaba durmiendo cuando sonó el teléfono.             | I was sleeping when the phone rang.            | imperfect + *cuando* + preterite  |
| Cuando llegué a la fiesta, todos bailaban.            | When I arrived at the party, everyone was dancing. | preterite first, then imperfect |
| Mientras cocinaba, escuchaba música.                  | While I was cooking, I was listening to music. | two parallel imperfects           |
| Mientras cocinaba, sonó el teléfono.                  | While I was cooking, the phone rang.           | imperfect + *mientras* + preterite |
| Caminábamos por el parque cuando empezó a llover.     | We were walking through the park when it started to rain. | imperfect + *cuando* + preterite |
| Juan estaba en el ejército cuando conoció a María.    | Juan was in the Army when he met Maria.        | imperfect + *cuando* + preterite  |

## Common Mistakes

- Putting both verbs in the preterite — *Estuve durmiendo cuando sonó el
  teléfono* loses the "already in progress" meaning of the sleeping.
- Putting both verbs in the imperfect for a true interruption — *Estaba
  durmiendo cuando sonaba el teléfono* wrongly makes the ringing sound
  ongoing/repeated instead of a single event.
- Assuming *mientras* always takes two imperfects — it switches to preterite
  in the second clause when that action is a one-time interrupting event.
