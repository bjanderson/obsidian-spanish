## Explanation

When a pronoun follows a preposition — *for me, with you, about him* — Spanish
uses a special set of pronouns instead of the subject pronouns you're used
to. Most of them look identical to subject pronouns, but *yo* and *tú* change
shape entirely, and the word *con* (with) has its own two special
contractions you'll use constantly.

## Key Points / Conjugation / Rules

- After most prepositions (*para, de, a, en, sin...*), use this set:

| Subject          | After a preposition |
| --------------------- | -------------------------- |
| yo                     | mí                            |
| tú                     | ti                             |
| él/ella/usted          | él/ella/usted                    |
| nosotros/nosotras      | nosotros/nosotras                  |
| ellos/ellas/ustedes    | ellos/ellas/ustedes                  |

- Only **mí** and **ti** are different from the subject pronouns — everything
  else stays the same. Note *mí* carries an accent to distinguish it from
  *mi* (my); *ti* never carries an accent.
- **Con** (with) has two irregular contractions that replace *con mí* and
  *con ti* entirely: **conmigo** (with me) and **contigo** (with you). You
  can't say *con mí* or *con ti* — Spanish always uses the fused forms.
- Everything else after *con* stays regular: *con él, con nosotros, con
  ustedes.*
- A few short prepositions are exceptions and pair with the **subject**
  pronouns *yo* and *tú* instead of *mí/ti* — the most common is **entre**
  (between): *entre tú y yo* (between you and me), not *entre ti y mí.*

## Examples

| Spanish                                  | English                              | Notes                       |
| ---------------------------------------------- | ----------------------------------------- | ---------------------------------- |
| Este regalo es para mí.                         | This gift is for me.                        | *para* + *mí*                        |
| ¿Es este mensaje para ti?                       | Is this message for you?                     | *para* + *ti*                          |
| Hablaron de él toda la noche.                   | They talked about him all night.              | *de* + *él*                              |
| ¿Quieres venir conmigo?                         | Do you want to come with me?                   | *con* + *mí* → *conmigo*                   |
| Sí, voy contigo.                                | Yes, I'll go with you.                          | *con* + *ti* → *contigo*                     |
| Este secreto queda entre tú y yo.               | This secret stays between you and me.            | *entre* + subject pronouns, exception         |

## Common Mistakes

- Using *yo* or *tú* directly after a preposition: *Es para yo* is wrong —
  it must be *Es para mí.*
- Trying to say *con mí* or *con ti*: these don't exist in Spanish — the
  fused forms *conmigo* and *contigo* are mandatory.
- Dropping the accent on *mí*: *Es para mi* (no accent) looks like "my" —
  the accent on *mí* is what marks it as the pronoun, not the possessive.
- Using *mí/ti* after *entre*: *entre ti y mí* is a common mistake — this
  particular preposition takes the subject pronouns instead: *entre tú y
  yo.*
