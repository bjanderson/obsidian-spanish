## Explanation

[[B1.2.2.1 Present Subjunctive Stems|Two lessons ago]], you learned that most verbs
build their subjunctive stem from the *yo* form of the present indicative. Six very
common verbs break that rule completely — their subjunctive forms have to be
memorized as a standalone set. The mnemonic **DISHES** covers them all: **D**ar,
**I**r, **S**er, **H**aber, **E**star, **S**aber.

## Key Points / Conjugation / Rules

**Dar (to give):**

| Subject             | Form  |
| --------------------- | ------- |
| yo                    | dé      |
| tú                    | des     |
| él/ella/usted          | dé      |
| nosotros/nosotras      | demos   |
| ellos/ellas/ustedes    | den     |

**Ir (to go):**

| Subject             | Form    |
| --------------------- | --------- |
| yo                    | vaya      |
| tú                    | vayas     |
| él/ella/usted          | vaya      |
| nosotros/nosotras      | vayamos   |
| ellos/ellas/ustedes    | vayan     |

**Ser (to be):**

| Subject             | Form   |
| --------------------- | -------- |
| yo                    | sea      |
| tú                    | seas     |
| él/ella/usted          | sea      |
| nosotros/nosotras      | seamos   |
| ellos/ellas/ustedes    | sean     |

**Haber (to have, auxiliary):**

| Subject             | Form    |
| --------------------- | --------- |
| yo                    | haya      |
| tú                    | hayas     |
| él/ella/usted          | haya      |
| nosotros/nosotras      | hayamos   |
| ellos/ellas/ustedes    | hayan     |

**Estar (to be):**

| Subject             | Form    |
| --------------------- | --------- |
| yo                    | esté      |
| tú                    | estés     |
| él/ella/usted          | esté      |
| nosotros/nosotras      | estemos   |
| ellos/ellas/ustedes    | estén     |

**Saber (to know):**

| Subject             | Form    |
| --------------------- | --------- |
| yo                    | sepa      |
| tú                    | sepas     |
| él/ella/usted          | sepa      |
| nosotros/nosotras      | sepamos   |
| ellos/ellas/ustedes    | sepan     |

- Notice that *dé* carries a written accent — this distinguishes it from *de* (the
  preposition "of/from"). *Des* has no accent; it just looks unusual because it's not
  a familiar verb ending.
- *Estar*'s forms carry accents on every ending except *nosotros* — the same accent
  pattern you've seen elsewhere (like the future tense) marking stress on the last
  syllable.
- These six don't relate to each other by any shared pattern — there's no shortcut,
  they're simply memorized as a set of six, which is exactly why the DISHES mnemonic
  exists.
- Despite being irregular, they still follow the *que* + subordinate-clause mechanics
  from [[B1.2.1.2 Main Clause Que Subordinate Structure|earlier]] — only the stem and
  ending are different, not the sentence structure.

## Examples

| Spanish                                    | English                              | Notes                    |
| --------------------------------------------- | ------------------------------------------- | ------------------------------ |
| Espero que me des una respuesta pronto.       | I hope you give me an answer soon.            | *dar*                          |
| Quiero que vayas a la reunión.                | I want you to go to the meeting.               | *ir*                            |
| Dudo que sea tan fácil.                       | I doubt it's that easy.                        | *ser*                           |
| Espero que no haya problemas.                 | I hope there aren't any problems.               | *haber*, impersonal              |
| Quiero que estés cómodo.                      | I want you to be comfortable.                   | *estar*                         |
| Espero que sepas la respuesta.                | I hope you know the answer.                     | *saber*                         |

## Common Mistakes

- Trying to derive these stems from the *yo* form like regular verbs: *ir*'s *yo*
  form is *voy*, but the subjunctive stem is *vay-*, not *voy-* — this verb simply
  doesn't follow the shortcut.
- Dropping the accent on *dé*: without it, *de* just means the preposition "of," which
  changes the sentence's meaning entirely.
- Confusing *ser* and *estar*'s subjunctive forms since both mean "to be" in English —
  they're conjugated completely differently (*sea* vs. *esté*) and still follow the
  same *ser*/*estar* usage rules you already know.
- Assuming *haber*'s subjunctive form is used for possession — like in the indicative,
  *haber* here is either the impersonal "there be" (*haya*) or the auxiliary for
  perfect tenses, never "to have" in the sense of owning something.
