## Explanation

Good news: only a small, fixed group of verbs breaks the [[B1.3.1.1 Regular Conditional Endings|regular conditional pattern]]
you just learned, and if you've studied the future tense, you already know
exactly which ones. The **conditional uses the same irregular stems as the
future tense** — so if you memorized *tendr-, pondr-, har-* for the future,
you already have the conditional's irregular stems too. Only the endings
change.

## Key Points / Conjugation / Rules

- These 8 verbs replace their infinitive with an irregular stem before adding
  the regular conditional endings (*-ía, -ías, -ía, -íamos, -ían*):

| Infinitive | Stem   | Example (yo) |
| -------------- | -------- | --------------- |
| decir          | dir-     | diría             |
| hacer          | har-     | haría             |
| poder          | podr-    | podría            |
| poner          | pondr-   | pondría           |
| querer         | querr-   | querría           |
| saber          | sabr-    | sabría            |
| salir          | saldr-   | saldría           |
| tener          | tendr-   | tendría           |

- The **endings never change** — even for irregular verbs, you still add
  *-ía, -ías, -ía, -íamos, -ían*. Only the stem is different.
- These are the exact same irregular stems you already learned for the future
  tense — if a verb is irregular in the future, it's irregular in the
  conditional too, using the same shortened stem.
- Many other common verbs share these patterns as compounds: *mantener*
  (to maintain) behaves like *tener* (→ *mantendría*), *proponer* (to
  propose) behaves like *poner* (→ *propondría*), and so on.

## Examples

| Spanish                                     | English                               | Notes                          |
| --------------------------------------------- | ---------------------------------------- | --------------------------------- |
| Yo diría que tienes razón.                    | I would say that you're right.             | *decir* → *dir-*                     |
| ¿Qué harías tú en mi lugar?                   | What would you do in my place?              | *hacer* → *har-*                      |
| Ella podría ayudarte mañana.                  | She could help you tomorrow.                | *poder* → *podr-*, "could"              |
| Pondríamos la mesa si llegaran a tiempo.      | We would set the table if they arrived on time. | *poner* → *pondr-*, *nosotros*           |
| Ellos tendrían que estudiar más.              | They would have to study more.               | *tener* → *tendr-*                         |
| No sabría qué decirte.                        | I wouldn't know what to tell you.             | *saber* → *sabr-*                            |

## Common Mistakes

- Adding the irregular stem to the regular endings incorrectly, like writing
  *tenería* instead of *tendría* — the *-er* is dropped entirely and replaced
  by *-dr-*, it isn't just tacked on.
- Forgetting that the endings themselves never change: even irregular verbs
  use *-ía, -ías, -ía, -íamos, -ían* — there's no separate ending set for
  irregular stems.
- Assuming a verb's future-tense irregularity doesn't carry over: if you
  already know *tendré* (future), you already know the conditional stem too
  — *tendría*, not *tenería*.
- Confusing *podría* (conditional, "could/would be able to") with *puede*
  (present, "can/is able to") — the conditional softens the meaning into a
  polite possibility.
