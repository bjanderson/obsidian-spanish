## Explanation

You've been seeing hints of this rule already — *Dime, Ponte, Tráigalo*. Now
let's make it explicit: when a command involves an object pronoun (*lo, la,
me, te, se...*), **where that pronoun goes depends entirely on whether the
command is affirmative or negative**. This one rule applies across every
command form you've learned — *tú*, *usted*, and *ustedes* alike.

## Key Points / Conjugation / Rules

- **Affirmative commands:** the pronoun **attaches to the end** of the verb,
  becoming one word: *Cómelo* (Eat it), *Tráigalo* (Bring it).
- **Negative commands:** the pronoun goes **before** the verb, as its own
  word: *No lo comas* (Don't eat it), *No lo traiga* (Don't bring it).
- When you attach a pronoun to a command of **two or more syllables**, you
  usually need to add a **written accent** to keep the stress on the same
  syllable it had before attachment: *pon* → *ponlo* (one syllable, no
  accent needed) vs. *escribe* → *escríbelo* (accent added to preserve the
  original stress on *-cri-*).
- When a command needs **two pronouns** (an indirect object and a direct
  object together), the order is always **indirect before direct**: *Dile*
  (tell him/her) + *lo* (it) → *Díselo* (tell it to him/her) — note *le*
  changes to *se* before *lo/la/los/las*, the same rule you'll see again with
  regular object pronouns.
- This rule is identical across every command type you've learned — *tú*
  affirmative, *tú* negative, *usted* affirmative/negative, and *ustedes*
  affirmative/negative all follow the same attach-vs-precede pattern.

## Examples

| Spanish             | English               | Notes                    |
| ----------------------- | --------------------------- | ------------------------------ |
| Cómelo antes de que se enfríe. | Eat it before it gets cold.    | affirmative *tú*, attached           |
| No lo comas todavía.     | Don't eat it yet.              | negative *tú*, precedes                |
| Tráigalo mañana, por favor. | Bring it tomorrow, please.    | affirmative *usted*, attached          |
| No lo traiga hoy.        | Don't bring it today.           | negative *usted*, precedes               |
| Escríbelo en la pizarra. | Write it on the board.           | affirmative *tú*, accent added             |
| Díselo a tu hermano.     | Tell it to your brother.          | double pronoun, *le* → *se*                  |

## Common Mistakes

- Attaching the pronoun in a negative command: *No cómelo* is wrong — it
  needs to precede the verb instead: *No lo comas.*
- Placing the pronoun before an affirmative command: *Lo come* isn't a
  command at all — the affirmative command requires attachment: *Cómelo.*
- Forgetting the accent when attaching to a multi-syllable command:
  *Escribelo* (no accent) shifts the stress incorrectly — it must be
  *Escríbelo.*
- Using *le* instead of *se* before another pronoun: *Dile-lo* isn't valid
  Spanish — *le* becomes *se* whenever it's followed by *lo, la, los,* or
  *las*: *Díselo.*
