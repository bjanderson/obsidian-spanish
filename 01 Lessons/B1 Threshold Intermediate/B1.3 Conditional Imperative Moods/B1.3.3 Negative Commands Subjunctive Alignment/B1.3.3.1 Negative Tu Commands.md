## Explanation

Here's a twist worth knowing early: **telling someone NOT to do something in
the tú form uses a completely different pattern** than [[B1.3.2.1 Informal Affirmative Tu Commands|telling them TO do it]].
The affirmative form came from the present indicative — the negative form
comes from the **present subjunctive** *tú* form instead, the exact same
conjugation you already learned back in [[B1.2.2.1 Present Subjunctive Stems|the subjunctive unit]].

## Key Points / Conjugation / Rules

- Negative *tú* commands = **"no" + present subjunctive *tú* form**:

| Infinitive          | Negative tú command |
| ------------------------ | ------------------------ |
| hablar (to speak)        | no hables                  |
| comer (to eat)           | no comas                     |
| escribir (to write)      | no escribas                    |

- Because this comes from the subjunctive, it reuses the **subjunctive
  stem-change and irregularity rules** you already know: the [[B1.2.2.3 Irregular Subjunctive Stems DISHES|DISHES verbs]]
  keep their irregular stems here too — *no vayas* (ir), *no seas* (ser), *no
  estés* (estar), *no sepas* (saber), *no des* (dar).
- The 8 verbs that are irregular in the **affirmative** *tú* command
  ([[B1.3.2.2 Irregular Tu Commands|ven, di, sal, haz, ten, ve, pon, sé]]) do
  **not** carry that irregularity into the negative — instead, they follow
  the regular yo-form-based subjunctive pattern: *no digas* (not *no dis*),
  *no hagas* (not *no haz*), *no vengas* (not *no ven*).
- Pronoun placement flips too: in affirmative commands pronouns attach to
  the end, but in negative commands they go **before** the verb: *Cómelo*
  (Eat it) vs. *No lo comas* (Don't eat it).

## Examples

| Spanish                | English                | Notes                |
| --------------------------- | --------------------------- | ------------------------- |
| No hables tan alto.          | Don't speak so loudly.        | *hablar* → *no hables*         |
| No comas tan rápido.         | Don't eat so fast.             | *comer* → *no comas*             |
| No escribas con lápiz.       | Don't write in pencil.          | *escribir* → *no escribas*         |
| No vayas solo, es peligroso. | Don't go alone, it's dangerous. | *ir* → *no vayas*                    |
| No digas eso, por favor.     | Don't say that, please.          | *decir* → *no digas*                   |
| No hagas ruido, están dormidos. | Don't make noise, they're asleep. | *hacer* → *no hagas*                  |

## Common Mistakes

- Using the irregular affirmative form and just adding *no* in front: *No
  ven* (from *ven*) is wrong — the negative uses the subjunctive stem
  instead: *No vengas.*
- Using the present indicative instead of the subjunctive: *No hablas* is
  wrong — it needs the subjunctive form, *No hables.*
- Forgetting stem-change/irregularity carryover from the subjunctive: *No
  pongas* (correct, from *pongo* → *ponga* → *pongas*) is often mis-remembered
  as *No pones* — that's the indicative, not the command.
- Attaching a pronoun to the end of a negative command: *No cómelo* is
  wrong — pronouns move in front of negative commands: *No lo comas.*
