## Explanation

This is the easiest command rule in the whole unit: **negative formal
commands use the exact same form as [[B1.3.2.3 Formal Usted Ustedes Commands|affirmative formal commands]]**
— you just add *no* in front. Unlike the *tú* form, where affirmative and
negative commands come from two completely different patterns, *usted* and
*ustedes* commands never change shape.

## Key Points / Conjugation / Rules

- Formal commands (both *usted* and *ustedes*) are always the present
  subjunctive form — this doesn't change between affirmative and negative:

| Infinitive          | Affirmative usted | Negative usted |
| ------------------------ | ---------------------- | -------------------- |
| hablar (to speak)        | hable                     | no hable                |
| comer (to eat)           | coma                       | no coma                   |
| escribir (to write)      | escriba                     | no escriba                  |

- Since it's the same subjunctive form either way, every irregularity you
  learned for the affirmative — including the [[B1.2.2.3 Irregular Subjunctive Stems DISHES|DISHES]]
  irregulars — carries straight over to the negative: *no vaya/no vayan*
  (ir), *no sea/no sean* (ser), *no esté/no estén* (estar), *no dé/no den*
  (dar).
- This is genuinely simpler than the *tú* commands you just covered — for
  formal commands, there's only **one form to learn per verb**, used for
  both "do this" and "don't do this."
- Pronoun placement still follows the standard rule: attached for
  affirmative, in front for negative — *Tráigalo* (Bring it) vs. *No lo
  traiga* (Don't bring it).

## Examples

| Spanish                       | English                         | Notes                     |
| ---------------------------------- | ------------------------------------ | ------------------------------ |
| No hable tan rápido, por favor.     | Don't speak so fast, please.           | *hablar*, negative *usted*        |
| No coman con la boca abierta.       | Don't eat with your mouth open.         | *comer*, negative *ustedes*         |
| No escriba con lápiz aquí.          | Don't write in pencil here.              | *escribir*, negative *usted*          |
| No vaya solo, es peligroso.         | Don't go alone, it's dangerous.          | *ir*, negative *usted*                  |
| No se preocupen, todo está bien.    | Don't worry, everything's fine.          | *preocuparse*, negative *ustedes*         |
| No sean tan duros con él.           | Don't be so hard on him.                  | *ser*, negative *ustedes*                   |

## Common Mistakes

- Trying to invent a separate negative formal form: unlike *tú* commands,
  there's nothing extra to learn — *hable* and *no hable* use the identical
  verb form.
- Confusing formal negative commands with informal ones: *No hables* (tú) vs.
  *No hable* (usted) look almost identical but end differently — match the
  ending to who you're addressing.
- Forgetting the irregular subjunctive stem carries over: *No vaya* is
  correct; a regularized form like *no ir-a* doesn't exist.
- Placing the pronoun in the wrong spot: *No tráigalo* is wrong for a
  negative command — pronouns move in front: *No lo traiga.*
