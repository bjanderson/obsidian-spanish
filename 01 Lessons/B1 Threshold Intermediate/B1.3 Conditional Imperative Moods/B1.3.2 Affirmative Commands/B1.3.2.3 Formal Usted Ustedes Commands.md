## Explanation

You've covered informal commands for *tú*. Now let's cover the formal
versions — for *usted* (one person you address respectfully) and *ustedes*
(a group). Here's the good news: you don't need to learn a new pattern at
all. Formal commands use the exact same forms as the [[B1.2.2.1 Present Subjunctive Stems|present subjunctive]]
you already know — the *usted* and *ustedes* conjugations you learned there
work directly as commands here.

## Key Points / Conjugation / Rules

- Formal commands = the **present subjunctive** form for *usted* or
  *ustedes* — no new conjugation to memorize, just a new use for a pattern
  you already have.

| Infinitive          | Usted command | Ustedes command |
| ------------------------ | ------------------ | -------------------- |
| hablar (to speak)        | hable                 | hablen                  |
| comer (to eat)           | coma                   | coman                     |
| escribir (to write)      | escriba                | escriban                    |

- This applies to **both affirmative and negative** — unlike *tú* commands,
  which have separate affirmative and negative forms, formal commands just
  add *no* in front for the negative: *Hable* (Speak) vs. *No hable* (Don't
  speak).
- Irregular-subjunctive verbs keep their irregular stems here too, since
  these commands ARE the subjunctive: *ir* → *vaya/vayan*, *ser* → *sea/sean*,
  *estar* → *esté/estén*, *saber* → *sepa/sepan*, *dar* → *dé/den* — the same
  [[B1.2.2.3 Irregular Subjunctive Stems DISHES|DISHES]] irregulars you
  already memorized.
- Use *usted* commands for one person you're addressing respectfully —
  strangers, elders, authority figures, formal service contexts. Use
  *ustedes* for a group, in any register — in Latin America, *ustedes* is
  the only plural "you" in everyday use, formal or informal.

## Examples

| Spanish                                 | English                            | Notes                       |
| -------------------------------------------- | -------------------------------------- | ---------------------------------- |
| Hable más despacio, por favor.               | Speak more slowly, please.               | *hablar*, *usted*                     |
| Coman despacio, hay tiempo.                  | Eat slowly, there's time.                 | *comer*, *ustedes*                      |
| Escriba su nombre aquí, por favor.           | Write your name here, please.              | *escribir*, *usted*                       |
| Vengan temprano mañana.                      | Come early tomorrow.                        | *venir*, *ustedes*                          |
| No hable tan rápido, no lo entiendo.          | Don't speak so fast, I don't understand you. | negative, *usted*                             |
| Tengan cuidado al cruzar la calle.           | Be careful crossing the street.             | *tener*, *ustedes*                              |

## Common Mistakes

- Using the *tú* command form with someone you should address formally:
  *Habla más despacio* to a stranger sounds too casual — use *Hable más
  despacio* instead.
- Forgetting that formal commands double as negatives with just *no* in
  front: unlike *tú* commands, there's no separate negative conjugation to
  learn here — *Hable* / *No hable* use the identical verb form.
- Dropping the irregular subjunctive stem: *Vaya* (from *ir*) is correct;
  *vaye* or a regularized form is not — formal commands inherit every
  subjunctive irregularity you already learned.
- Assuming *ustedes* is only for formal groups: in Latin American Spanish,
  *ustedes* is used for any group, formal or informal — there's no separate
  informal plural "you" the way there is with *tú* vs. *usted*.
