## Explanation

Now you're moving into a whole new mood: the **imperative**, used for giving
commands, instructions, and direct requests. In English, tone and context do
this work — "Sit down" can be a command or a suggestion depending on how you
say it. In Spanish, the verb form itself makes it unmistakably a command. This
lesson covers the form you'll use constantly: the informal **tú** command, for
talking to friends, family, or anyone you'd normally address informally.

## Key Points / Conjugation / Rules

- For regular verbs, the affirmative *tú* command is identical to the **he/she
  (él/ella) form of the present indicative** — the same form you already
  know from everyday conjugation.
- Some people find it easier to think of it as: take the regular *tú* present
  form and **drop the final -s**: *hablas* → *habla*, *comes* → *come*,
  *escribes* → *escribe*.

| Infinitive         | Tú present (indicative) | Tú command (affirmative) |
| ---------------------- | -------------------------- | ---------------------------- |
| hablar (to speak)      | hablas                      | habla                          |
| comer (to eat)         | comes                       | come                            |
| escribir (to write)    | escribes                    | escribe                          |

- This form is used **only for affirmative commands** — telling someone *to*
  do something. Negative commands ("don't do that") use a completely
  different form, covered in a later lesson.
- The imperative has **no *yo* form** — you can't command yourself, so there's
  no first-person version of this pattern.

## Examples

| Spanish             | English            | Notes             |
| ----------------------- | ---------------------- | ---------------------- |
| Habla más despacio.      | Speak more slowly.       | *hablar*                  |
| Come tus verduras.       | Eat your vegetables.      | *comer*                    |
| Escribe tu nombre aquí.  | Write your name here.      | *escribir*                   |
| Estudia para el examen.  | Study for the exam.        | *estudiar*                     |
| Llama a tu mamá.         | Call your mom.              | *llamar*, personal *a*           |
| Camina más rápido.       | Walk faster.                  | *caminar*                          |

## Common Mistakes

- Using the *yo* or infinitive form instead of the command form: *Hablar más
  despacio* isn't a command — it needs the true command form, *Habla más
  despacio.*
- Adding an *-s* to the command form out of habit from the *tú* present
  tense: the *-s* is exactly what gets dropped to form the command —
  *hablas* becomes *habla*, not *hablas*.
- Using this affirmative form for a negative command: *Habla* means "speak,"
  but "don't speak" needs a completely different form (*No hables*) — never
  just add *no* in front of the affirmative command.
- Forgetting the personal *a* before a specific person as the object of the
  command: *Llama tu mamá* is missing it — it should be *Llama a tu mamá.*
