## Explanation

Just like most tenses you've learned, the [[B1.3.2.1 Informal Affirmative Tu Commands|regular tú command pattern]]
has a short list of exceptions. Only 8 verbs break the pattern for
affirmative *tú* commands, and they're all extremely common — which means
you'll use these irregular forms constantly, so they're worth memorizing as
their own set.

## Key Points / Conjugation / Rules

- These 8 verbs have a special, shortened affirmative *tú* command that
  doesn't come from the regular él/ella-present-indicative pattern:

| Infinitive       | Tú command | English   |
| --------------------- | -------------- | ------------- |
| decir (to say/tell)    | di               | say/tell         |
| hacer (to do/make)     | haz              | do/make           |
| ir (to go)             | ve               | go                  |
| poner (to put)         | pon              | put                   |
| salir (to leave)       | sal              | leave                   |
| ser (to be)            | sé               | be                        |
| tener (to have)        | ten              | have                        |
| venir (to come)        | ven              | come                          |

- These are all **one-syllable** commands — short and easy to remember once
  you've seen them a few times.
- Watch out for two look-alikes: *sé* (command from *ser*) carries an accent
  to distinguish it from *se* (the reflexive/impersonal pronoun); *ve*
  (command from *ir*) is spelled the same as *ve* (he/she sees, from *ver*) —
  context tells them apart.
- Everything else about these commands works the same as regular ones: no
  *yo* form, and they're for **affirmative** commands only — the negative
  versions use a completely different pattern.

## Examples

| Spanish             | English              | Notes            |
| ----------------------- | ------------------------ | -------------------- |
| Ven aquí un momento.     | Come here for a moment.    | *venir* → *ven*         |
| Di la verdad.            | Tell the truth.             | *decir* → *di*            |
| Sal de mi cuarto.        | Get out of my room.          | *salir* → *sal*             |
| Haz la tarea ahora.      | Do your homework now.         | *hacer* → *haz*               |
| Ten paciencia, por favor. | Have patience, please.         | *tener* → *ten*                 |
| Ve a la tienda por leche. | Go to the store for milk.       | *ir* → *ve*                       |
| Pon el libro en la mesa. | Put the book on the table.       | *poner* → *pon*                     |
| Sé amable con tu hermana. | Be kind to your sister.           | *ser* → *sé*                          |

## Common Mistakes

- Using the regular pattern instead of the irregular form: *Tenes paciencia*
  or *Hace la tarea* aren't correct commands — the irregular short forms
  (*ten, haz*) replace the regular pattern entirely.
- Dropping the accent on *sé*: without it, *se* just looks like the
  reflexive pronoun, which changes the meaning of the sentence completely.
- Confusing *ve* (command, "go") with *ve* (present tense, "he/she sees"):
  context — usually the sentence being a direct instruction — makes the
  difference clear.
- Forgetting that these are affirmative-only forms: *No sal, no haz, no ven*
  are all wrong — negative commands for these same verbs take a different
  shape entirely, covered in a later lesson.
