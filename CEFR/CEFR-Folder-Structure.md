This is the folder structure to be used when generating content. This structure should be used as a pattern rather than a strict rule. The actual file/folder structure may change over time, but it should always follow this pattern. This pattern should also be used for `03 Attachments` and `04 Flashcards`.

The Anki flashcard file path should follow this pattern also.

Obsidian tags can't contain spaces or periods, so each segment of the tag is
sanitized: every space and every period becomes a hyphen.

- e.g. #anki/Spanish/A1-Breakthrough-Absolute-Beginner/A1-1-Phonetics-Pronunciation-Orthography/A1-1-1-Vowels-Consonants-and-Accent-Marks/A1-1-1-2-Pure-Vowel-Sounds
