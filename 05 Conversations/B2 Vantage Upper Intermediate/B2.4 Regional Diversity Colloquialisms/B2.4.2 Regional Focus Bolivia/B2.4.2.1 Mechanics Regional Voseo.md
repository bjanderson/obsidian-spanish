# Mechanics of Regional Voseo — Conversational Sentences

## Asking Questions with Vos

Used to ask an informal question, the vos equivalent of ¿tú...?

| Spanish | English | Notes |
| ------- | ------- | ----- |
| ¿Vos hablás inglés? | Do you speak English? | -ar verb, present tense |
| ¿Vos querés salir esta noche? | Do you want to go out tonight? | No stem change with vos |
| ¿De dónde sos vos? | Where are you from? | Ser is also irregular with vos: sos |
| ¿Vos tenés hermanos? | Do you have siblings? | Tener with vos: tenés |

## Making Statements with Vos

Used for everyday informal statements about the listener.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Vos sabés mucho de historia. | You know a lot about history. | Saber with vos: sabés |
| Vos siempre llegás temprano. | You always arrive early. | Regular -ar present |
| Vos cocinás muy bien. | You cook really well. | Simple statement, no address word needed |
| Vos podés quedarte si querés. | You can stay if you want. | Poder with vos: podés, no stem change |

## Giving Commands with Vos

Used to tell someone to do something, informally.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| ¡Vení acá un momento! | Come here a moment! | Venir command with vos: vení |
| ¡Hablá con ella, no conmigo! | Talk to her, not to me! | Regular -ar command |
| ¡Comé antes de que se enfríe! | Eat before it gets cold! | Regular -er command |
| ¡Escribime cuando llegués! | Text/write me when you arrive! | Command + attached object pronoun |

## Talking About Vos and Tú Together

Used to describe or explain the coexistence of vos and tú in Bolivia.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Acá usamos vos y tú, depende de la persona. | Here we use both vos and tú, it depends on the person. | Reflects real Bolivian usage |
| Con mis amigos uso vos, pero con mi jefe uso usted. | With my friends I use vos, but with my boss I use usted. | Register shift by relationship |
| Mi abuela todavía dice tú, pero los jóvenes usamos más vos. | My grandmother still says tú, but young people use vos more. | Generational variation |
