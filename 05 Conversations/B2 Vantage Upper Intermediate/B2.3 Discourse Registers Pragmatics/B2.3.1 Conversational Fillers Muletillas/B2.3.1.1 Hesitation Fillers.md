# Hesitation Fillers — Conversational Sentences

## Buying Time to Think

Everyday sentences using *este* to pause mid-thought.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Quiero pedir... este... una hamburguesa sin queso.   | I want to order... um... a burger without cheese.         | *este*, hesitation                  |
| Necesito hablar con... este... el gerente, creo.     | I need to talk to... um... the manager, I think.            | *este*, hesitation                    |
| Vamos a llegar en... este... unos veinte minutos.    | We'll arrive in... um... about twenty minutes.                | *este*, hesitation                      |

## Softening a Response with Bueno

Everyday sentences using *bueno* to ease into an answer or transition.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Bueno, la verdad no sé qué pensar.                   | Well, honestly I don't know what to think.                | *bueno*, softening               |
| Bueno, vamos a intentarlo de otra manera.            | Well, let's try it a different way.                         | *bueno*, transition                |
| ¿Vienes a la fiesta? Bueno, tal vez.                 | Are you coming to the party? Well, maybe.                     | *bueno*, hedged response             |

## Rephrasing with O Sea

Everyday sentences clarifying or restating something more casually.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| No tengo dinero, o sea, ando bien corto este mes.    | I don't have money, I mean, I'm really short this month. | *o sea*, casual rephrasing         |
| Trabajo desde casa, o sea, no salgo mucho.           | I work from home, I mean, I don't go out much.               | *o sea*, casual rephrasing            |
| Llegó tarde otra vez, o sea, típico de él.           | He was late again, I mean, typical of him.                     | *o sea*, casual rephrasing               |

## Restating More Precisely with Es Decir

Everyday sentences using the slightly more formal *es decir* to clarify.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Estudio por las noches, es decir, después del trabajo.  | I study at night, that is, after work.                     | *es decir*, precise restatement       |
| El proyecto se retrasó, es decir, no vamos a terminar hoy. | The project got delayed, in other words, we won't finish today. | *es decir*, precise restatement |
| Cambié de trabajo, es decir, ya no trabajo con ellos.    | I changed jobs, that is, I no longer work with them.          | *es decir*, precise restatement         |

## Using Que Yo Sepa and Que Yo Recuerde

Everyday sentences hedging an answer with limited knowledge or memory.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Que yo sepa, la tienda cierra a las nueve.           | As far as I know, the store closes at nine.                | *que yo sepa*, fixed expression      |
| Que yo recuerde, nunca hablamos de ese tema.         | As far as I remember, we never talked about that topic.       | *que yo recuerde*, fixed expression    |
