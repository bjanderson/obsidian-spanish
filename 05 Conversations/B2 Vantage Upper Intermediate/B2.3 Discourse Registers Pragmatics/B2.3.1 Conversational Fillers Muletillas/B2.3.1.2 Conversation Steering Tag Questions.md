# Conversation Steering and Tag Questions — Conversational Sentences

## Confirming Something with Verdad

Everyday sentences checking that the listener agrees.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Vives cerca del centro, ¿verdad?                     | You live near downtown, right?                            | *¿verdad?*, universal tag           |
| Ya conoces a mi hermana, ¿verdad?                    | You already know my sister, right?                          | *¿verdad?*, universal tag             |
| Vas a venir a la fiesta, ¿verdad?                    | You're coming to the party, right?                            | *¿verdad?*, universal tag               |

## Casual Check-Ins with No

Everyday casual sentences using the more informal tag.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Está rico este café, ¿no?                            | This coffee is good, isn't it?                            | *¿no?*, casual tag                  |
| Va a llover hoy, ¿no?                                | It's going to rain today, isn't it?                          | *¿no?*, casual tag                    |
| Ese examen estuvo difícil, ¿no?                      | That exam was hard, wasn't it?                                 | *¿no?*, casual tag                      |

## Confirming with Cierto

Everyday sentences using this regional alternative to *¿verdad?*.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Ya terminaste el reporte, ¿cierto?                   | You already finished the report, right?                       | *¿cierto?*, regional alternative     |
| Nos vemos mañana a las diez, ¿cierto?                | We're meeting tomorrow at ten, right?                            | *¿cierto?*, regional alternative       |
| Trabajas desde casa, ¿cierto?                        | You work from home, right?                                        | *¿cierto?*, regional alternative         |

## Checking In with Ya

Everyday sentences confirming readiness, understanding, or completion.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Te espero en la entrada, ¿ya?                        | I'll wait for you at the entrance, okay?                       | *¿ya?*, checking in                   |
| Nos vemos a las siete, ¿ya?                          | We'll meet at seven, okay?                                       | *¿ya?*, checking in                     |
| ¿Ya quedó claro cómo funciona?                       | Is it clear now how it works?                                      | *¿ya?*, checking understanding            |

## Tags after Negative Statements

Everyday sentences showing tags work the same after positive or negative statements.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| No vienes a la reunión, ¿verdad?                     | You're not coming to the meeting, right?                       | *¿verdad?* after negative statement    |
| Esto no está bien, ¿no?                              | This isn't right, is it?                                          | *¿no?* after negative statement          |
