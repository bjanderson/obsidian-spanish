# Unreal Present Conditionals (Si + Imperfect Subjunctive) — Conversational Sentences

## Imagining a Different Life

Everyday sentences imagining a hypothetical version of your life right now.

| Spanish                                            | English                                            | Notes                       |
| ---------------------------------------------------- | ------------------------------------------------------- | --------------------------------- |
| Si tuviera más dinero, viajaría por el mundo.        | If I had more money, I would travel the world.              | imperfect subjunctive → conditional  |
| Si viviéramos en otra ciudad, sería muy diferente.   | If we lived in another city, it would be very different.       | imperfect subjunctive → conditional    |
| Si trabajara menos, tendría más tiempo libre.        | If I worked less, I would have more free time.                   | imperfect subjunctive → conditional      |

## Giving Advice with Si Fuera Tú

Common everyday advice using "if I were you."

| Spanish                                            | English                                            | Notes                       |
| ---------------------------------------------------- | ------------------------------------------------------- | --------------------------------- |
| Si fuera tú, hablaría con ella hoy mismo.            | If I were you, I would talk to her today.                    | *si fuera tú*, advice                 |
| Si fuera tú, no aceptaría esa oferta.                | If I were you, I wouldn't accept that offer.                   | *si fuera tú*, advice                   |
| Si fuera tú, pediría más tiempo para decidir.        | If I were you, I would ask for more time to decide.               | *si fuera tú*, advice                     |

## Asking Hypothetical Questions

Common conversational questions imagining a different scenario.

| Spanish                                            | English                                            | Notes                       |
| ---------------------------------------------------- | ------------------------------------------------------- | --------------------------------- |
| Si pudieras vivir en cualquier país, ¿cuál elegirías? | If you could live in any country, which would you choose? | imperfect subjunctive → conditional  |
| Si tuvieras que elegir, ¿qué harías?                 | If you had to choose, what would you do?                       | imperfect subjunctive → conditional    |
| Si ganaras la lotería, ¿qué comprarías primero?      | If you won the lottery, what would you buy first?                | imperfect subjunctive → conditional      |

## Describing How Things Would Be Different

Everyday sentences contrasting reality with a hypothetical alternative.

| Spanish                                            | English                                            | Notes                       |
| ---------------------------------------------------- | ------------------------------------------------------- | --------------------------------- |
| Si no lloviera tanto, saldríamos a caminar.          | If it weren't raining so much, we would go for a walk.          | imperfect subjunctive → conditional  |
| Si supiéramos la respuesta, te la diríamos.          | If we knew the answer, we would tell it to you.                   | imperfect subjunctive → conditional    |
| Si tuviéramos más espacio, adoptaríamos un perro.    | If we had more space, we would adopt a dog.                         | imperfect subjunctive → conditional      |

## Casual Back-and-Forth

Everyday exchanges built on this hypothetical pattern.

| Spanish                                            | English                                            | Notes                       |

| ¿Qué harías si tuvieras un mes libre?                | What would you do if you had a free month?                       | question form                         |
