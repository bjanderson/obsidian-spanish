# Real/Possible Conditionals (Si + Present Indicative) — Conversational Sentences

## Making Everyday Plans

Common sentences about realistic plans depending on a condition.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Si terminamos temprano, vamos al cine.               | If we finish early, we'll go to the movies.              | present → present                  |
| Si tienes tiempo el sábado, quedamos para comer.     | If you have time on Saturday, let's meet up to eat.        | present → present                    |
| Si llueve mañana, cambiamos el plan.                 | If it rains tomorrow, we'll change the plan.                  | present → present                      |

## Talking about Habits and Routines

Common sentences about what usually happens under a certain condition.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Si hace frío, uso chaqueta.                          | If it's cold, I wear a jacket.                            | present → present, habitual         |
| Si tengo tiempo libre, leo un rato.                  | If I have free time, I read for a while.                    | present → present, habitual           |
| Si el tráfico está pesado, tomo el metro.            | If traffic is heavy, I take the subway.                       | present → present, habitual             |

## Giving Instructions or Advice

Common sentences using a command in the result clause.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Si tienes dudas, pregúntame sin pena.                | If you have questions, ask me without hesitation.          | present → command                   |
| Si necesitas ayuda, avísame.                         | If you need help, let me know.                              | present → command                     |
| Si llegas tarde, llámame antes.                      | If you're going to be late, call me beforehand.               | present → command                       |

## Warning About Consequences

Common sentences using the future to describe a likely outcome.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Si no estudias, no aprobarás el examen.              | If you don't study, you won't pass the exam.                 | present → future                     |
| Si sigues así, te vas a cansar.                      | If you keep this up, you're going to get tired.                | present → future (ir a)                |
| Si no salimos ya, llegaremos tarde.                  | If we don't leave now, we'll arrive late.                        | present → future                         |

## Everyday Back-and-Forth

Casual conversational exchanges built on this pattern.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| ¿Vienes si te invito?                                | Will you come if I invite you?                              | question form                       |
| Te espero si me avisas con tiempo.                   | I'll wait for you if you let me know ahead of time.            | result clause first                   |
