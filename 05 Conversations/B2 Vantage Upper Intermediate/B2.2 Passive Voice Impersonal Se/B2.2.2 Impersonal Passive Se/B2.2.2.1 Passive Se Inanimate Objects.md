# Passive Se with Singular and Plural Inanimate Objects — Conversational Sentences

## Real Estate Signs and Listings

Everyday sentences you'd see on signs or listings for property.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Se vende esta casa.                                  | This house is for sale.                                   | singular verb, singular object     |
| Se venden estos terrenos.                            | These lots are for sale.                                    | plural verb, plural object           |
| Se alquila apartamento cerca del centro.             | Apartment for rent near downtown.                             | singular verb, singular object         |

## Comparing Singular and Plural Objects

Pairs showing the same structure with a singular vs. plural object.

| Spanish                                            | English                                        | Notes                    |
| ---------------------------------------------------- | --------------------------------------------------- | ------------------------------ |
| Se vende una bicicleta. → Se venden dos bicicletas.  | A bike is for sale. → Two bikes are for sale.               | singular vs. plural object            |
| Se necesita un mesero. → Se necesitan tres meseros.  | One waiter is needed. → Three waiters are needed.             | singular vs. plural object              |
