# Doctor and Pharmacy Interaction Phrases — Conversational Sentences

## Making an appointment

Common phrases for booking a doctor's visit.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Necesito sacar una cita con el médico. | I need to make an appointment with the doctor. | |
| ¿Tiene alguna cita disponible para esta semana? | Do you have any appointments available this week? | |
| Quisiera cambiar mi cita para el viernes. | I'd like to change my appointment to Friday. | |
| Llamé para confirmar mi cita de mañana. | I called to confirm my appointment for tomorrow. | |

## Describing symptoms to the doctor

Sentences that use _desde hace_ and formal _usted_ register.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Doctor, tengo dolor de garganta desde hace tres días. | Doctor, I've had a sore throat for three days. | _Desde hace_ + duration. |
| Me duele mucho el estómago y tengo náuseas. | My stomach hurts a lot and I feel nauseous. | |
| No he podido dormir bien por la tos. | I haven't been able to sleep well because of the cough. | |
| ¿Qué le pasa? — Tengo fiebre y me duele todo el cuerpo. | "What's wrong?" — "I have a fever and my whole body hurts." | Classic doctor's opening question. |

## Understanding the doctor's instructions

Instructions using commands and _tener que_.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Tome esta medicina cada ocho horas. | Take this medicine every eight hours. | Formal command. |
| Tiene que descansar y tomar mucha agua. | You have to rest and drink a lot of water. | |
| Le voy a recetar un antibiótico. | I'm going to prescribe you an antibiotic. | |
| Si no mejora en dos días, vuelva a la clínica. | If you don't improve in two days, come back to the clinic. | |

## At the pharmacy

Everyday exchanges with the pharmacist.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| ¿Tiene algo para el dolor de cabeza? | Do you have something for a headache? | |
| ¿Se necesita receta para este jarabe? | Is a prescription needed for this syrup? | |
| Vengo a recoger una receta a nombre de Ana López. | I'm here to pick up a prescription under the name Ana López. | |
| El farmacéutico me recomendó unas pastillas más baratas. | The pharmacist recommended some cheaper pills to me. | |
