# Body Parts and Common Symptoms/Illness Vocabulary — Conversational Sentences

## Saying something hurts (_doler_)

The most common way to describe pain, matching the body part to the verb form.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Me duele mucho la cabeza. | My head hurts a lot. | |
| ¿Te duele el estómago? | Does your stomach hurt? | |
| Nos duelen los pies de tanto caminar. | Our feet hurt from all the walking. | Plural body part → plural verb. |
| Le duele la espalda desde ayer. | His/her back has hurt since yesterday. | |

## Naming everyday symptoms with _tener_

Common illness symptoms expressed with _tener_ + noun.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Tengo fiebre y no me siento bien. | I have a fever and I don't feel well. | |
| Mi hijo tiene tos desde la semana pasada. | My son has had a cough since last week. | |
| ¿Tienes náuseas o solo estás cansado? | Do you feel nauseous or are you just tired? | |
| Tenemos gripe, así que no vamos a salir. | We have the flu, so we're not going out. | |

## Describing being sick with _estar_

_Estar_ + adjective for temporary states of illness.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Estoy resfriada y prefiero quedarme en casa. | I have a cold and I'd rather stay home. | |
| ¿Estás mareado? Siéntate un momento. | Are you dizzy? Sit down for a moment. | |
| Mi papá está enfermo, así que no fue a trabajar. | My dad is sick, so he didn't go to work. | |
| Estábamos muy cansados después del viaje. | We were very tired after the trip. | |

## Talking about body parts in everyday routines

Sentences using the definite article for body parts, not a possessive.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Me lavo las manos antes de cocinar. | I wash my hands before cooking. | Definite article, not "mis manos." |
| Se cepilla los dientes dos veces al día. | He/she brushes his/her teeth twice a day. | |
| Me corté el dedo con el cuchillo. | I cut my finger with the knife. | |
| Levanté la mano para hacer una pregunta. | I raised my hand to ask a question. | |
