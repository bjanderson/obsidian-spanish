# Expressing Weather — Conversational Sentences

## Small Talk About the Weather

The most common way weather comes up in everyday conversation.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| ¡Qué calor hace hoy!                     | It's so hot today!                        | *hacer*, exclamation       |
| ¿Qué tiempo hace allá?                   | What's the weather like there?             | *hacer*, question          |
| Hace un frío horrible esta semana.       | It's terribly cold this week.              | *hacer*                    |
| Por fin hace buen tiempo.                | The weather's finally nice.                | *hacer*                    |

## Describing What's Happening Right Now

Using *estar* for weather in progress.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Está lloviendo bastante fuerte.          | It's raining pretty hard.                  | *estar*, gerund            |
| Todavía está nevando allá arriba.        | It's still snowing up there.               | *estar*, gerund            |
| Está nublado, pero no va a llover.       | It's cloudy, but it's not going to rain.    | *estar*                    |
| Ya está despejado, podemos salir.        | It's clear now, we can go out.             | *estar*                    |

## Talking About Fog, Storms, and Clouds

Using *hay* for weather phenomena that "exist."

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Hay mucha niebla, maneja con cuidado.    | There's a lot of fog, drive carefully.      | *hay*                      |
| Dicen que va a haber tormenta esta noche. | They say there's going to be a storm tonight. | *va a haber*             |
| Hay nubes, pero no parece que va a llover. | There are clouds, but it doesn't look like it'll rain. | *hay*              |
| No había ni una nube en el cielo.        | There wasn't a single cloud in the sky.      | *haber*, past               |

## Making Plans Around the Weather

Everyday sentences where weather affects a decision.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Si hace sol, vamos a la playa.           | If it's sunny, we'll go to the beach.      | *hacer*, conditional       |
| No salgas, está lloviendo muy fuerte.    | Don't go out, it's raining really hard.     | *estar*, command            |
| Llevo abrigo porque va a hacer frío.     | I'm bringing a coat because it's going to be cold. | *ir a* + *hacer*    |
| Cancelaron el partido por la tormenta.   | They canceled the game because of the storm. | *tormenta*, noun            |

## Asking About the Forecast

Common questions about upcoming weather.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| ¿Va a hacer calor este fin de semana?    | Is it going to be hot this weekend?         | *ir a* + *hacer*, question |
| ¿Crees que va a llover mañana?           | Do you think it'll rain tomorrow?           | *llover*, question         |
| ¿Cómo está el clima en la montaña?       | What's the weather like in the mountains?    | *estar*, question          |
| ¿Sigue nevando allá?                     | Is it still snowing there?                   | *seguir* + gerund           |
