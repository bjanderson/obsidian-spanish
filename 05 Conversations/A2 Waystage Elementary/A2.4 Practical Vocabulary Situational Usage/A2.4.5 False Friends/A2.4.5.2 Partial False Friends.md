# High-Frequency False Friends: Partial and Tricky Overlaps — Conversational Sentences

## Describing current situations vs. correcting a statement

Contrasting _actualmente_ (currently) with _de hecho_ (actually).

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Actualmente vivo con mis padres mientras ahorro dinero. | I currently live with my parents while I save money. | _Actualmente_ = currently. |
| Actualmente no trabajo, pero estoy buscando empleo. | I'm currently not working, but I'm looking for a job. | |
| De hecho, ya terminé ese proyecto la semana pasada. | Actually, I already finished that project last week. | _De hecho_ = actually. |
| En realidad, no me gustó tanto la película. | Actually, I didn't like the movie that much. | Alternative for "actually." |

## Fulfilling dreams vs. becoming aware

Contrasting _realizar_ (to carry out) with _darse cuenta de_ (to realize).

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Después de años de trabajo, realizó su sueño de tener su propia empresa. | After years of work, he fulfilled his dream of having his own company. | _Realizar_ = to fulfill/carry out. |
| Vamos a realizar el proyecto el próximo mes. | We're going to carry out the project next month. | |
| Me di cuenta de que había olvidado mi cartera. | I realized I had forgotten my wallet. | _Darse cuenta de_ = to realize (become aware). |
| ¿Te diste cuenta de que ya son las diez? | Did you realize it's already ten o'clock? | |

## Helping customers vs. attending events

Contrasting _atender_ (to attend to/assist) with _asistir_ (to attend).

| Spanish | English | Notes |
| ------- | ------- | ----- |
| La doctora atendió a cinco pacientes esta mañana. | The doctor attended to five patients this morning. | _Atender_ = to attend to, assist. |
| Necesito que alguien me atienda en esta tienda. | I need someone to help me in this store. | |
| Voy a asistir a la conferencia de mi universidad. | I'm going to attend my university's conference. | _Asistir a_ = to attend (an event). |
| No pudimos asistir a la boda por el mal tiempo. | We couldn't attend the wedding because of bad weather. | |

## Introducing people vs. helping someone

Contrasting _presentar_ (to introduce) with _ayudar_ (to assist).

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Quiero presentarte a mi mejor amiga. | I want to introduce you to my best friend. | _Presentar_ = to introduce (a person). |
| Me presentaron a todos los invitados en la fiesta. | They introduced me to all the guests at the party. | |
| ¿Me puedes ayudar a cargar estas cajas? | Can you help me carry these boxes? | _Ayudar_ = to help/assist. |
| Siempre ayudo a mi vecina con las compras. | I always help my neighbor with the groceries. | |

## Talking calmly vs. arguing

Contrasting _hablar sobre_ (to discuss neutrally) with _discutir_ (to argue).

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Prefiero hablar sobre esto en persona, no por mensaje. | I'd rather discuss this in person, not by text. | Neutral discussion. |
| Vamos a conversar sobre los planes para el viaje. | Let's discuss the plans for the trip. | |
| Mis padres siempre discuten por el mismo tema. | My parents always argue about the same topic. | _Discutir_ implies conflict here. |
| No quiero discutir contigo enfrente de todos. | I don't want to argue with you in front of everyone. | |
