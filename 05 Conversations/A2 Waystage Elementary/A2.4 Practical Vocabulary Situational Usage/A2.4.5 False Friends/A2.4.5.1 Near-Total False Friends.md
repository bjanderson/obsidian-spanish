# High-Frequency False Friends: Near-Total Mismatches — Conversational Sentences

## Announcing pregnancy or personal news

Everyday sentences that use _embarazada_ correctly, never as "embarrassed."

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Mi cuñada está embarazada de cinco meses. | My sister-in-law is five months pregnant. | _Embarazada_ = pregnant. |
| ¿Ya sabes si tu amiga está embarazada? | Do you already know if your friend is pregnant? | |
| Me sentí muy avergonzado cuando me equivoqué. | I felt very embarrassed when I made a mistake. | The real word for "embarrassed" here. |
| Qué pena, me da vergüenza hablar en público. | How embarrassing, I feel embarrassed speaking in public. | Alternative for embarrassment: _dar vergüenza_. |

## Talking about success and exits

Common ways _éxito_ and _salida_ come up in daily conversation.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| El restaurante nuevo ha sido un gran éxito. | The new restaurant has been a big success. | |
| Espero que tengas mucho éxito en tu entrevista. | I hope you have a lot of success in your interview. | |
| ¿Dónde está la salida de emergencia? | Where is the emergency exit? | _Salida_ = exit, not _éxito_. |
| Nos vemos en la salida del cine. | See you at the exit of the movie theater. | |

## Kitchen and bathroom vocabulary

Sentences that keep _sopa/jabón_ and _pastel/pie_ straight.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| ¿Quieres sopa de tomate o de pollo? | Do you want tomato soup or chicken soup? | |
| Se me acabó el jabón para lavar los platos. | I ran out of soap for washing dishes. | |
| Hice un pastel de manzana para el cumpleaños. | I made an apple pie for the birthday. | |
| Me duele mucho el pie izquierdo. | My left foot hurts a lot. | _Pie_ = foot, not the dessert. |

## Organizing papers, books, and clothes

Sentences that distinguish _carpeta/librería_ and _ropa/cuerda_ from their English lookalikes.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Deja los recibos en esa carpeta amarilla. | Leave the receipts in that yellow folder. | |
| La alfombra de la sala es muy suave. | The rug in the living room is very soft. | |
| Voy a la librería a comprar un diccionario. | I'm going to the bookstore to buy a dictionary. | |
| Tengo que sacar un libro de la biblioteca. | I have to check out a book from the library. | |
| Toda mi ropa de invierno está en esa maleta. | All my winter clothes are in that suitcase. | |

## Everyday annoyances

Natural uses of _molestar_ for ordinary bother, not the serious English sense.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Perdón, ¿te molesto si abro la ventana? | Sorry, does it bother you if I open the window? | Polite, common phrase. |
| El ruido de la calle me molesta mucho. | The noise from the street bothers me a lot. | |
| No quiero molestarte, pero necesito ayuda. | I don't want to bother you, but I need help. | |
| A mi perro le molestan los truenos. | Thunder bothers my dog. | |
