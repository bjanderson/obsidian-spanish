# Redundant Indirect Object Usage — Conversational Sentences

## Giving Things with a Named Recipient

*Dar* almost always keeps the pronoun even when the person is named.

| Spanish                                | English                              | Notes                    |
| ----------------------------------------- | ------------------------------------------- | ------------------------------ |
| Le di las llaves a mi hermano.            | I gave the keys to my brother.              | redundant *le* + named recipient |
| Le dieron un premio a la maestra.         | They gave the teacher an award.             | redundant *le* + named recipient |
| Les dimos las gracias a los invitados.    | We thanked the guests.                      | redundant *les* + named recipients |
| ¿Le diste tu opinión a tu jefe?           | Did you give your boss your opinion?        | redundant *le* + named recipient |

## Telling or Explaining with a Named Recipient

*Decir* and *contar* follow the same pattern in everyday storytelling.

| Spanish                                | English                              | Notes                    |
| ----------------------------------------- | ------------------------------------------- | ------------------------------ |
| Le dije la verdad a mi mamá.              | I told my mom the truth.                    | redundant *le* + named recipient |
| Le conté todo a mi mejor amiga.           | I told my best friend everything.           | redundant *le* + named recipient |
| Les expliqué el problema a mis colegas.   | I explained the problem to my colleagues.   | redundant *les* + named recipients |
| ¿Le contaste el secreto a alguien?        | Did you tell anyone the secret?             | redundant *le* + named recipient |

## Buying or Lending with a Named Recipient

*Comprar* and *prestar* both keep the pronoun with a stated recipient.

| Spanish                                | English                              | Notes                    |
| ----------------------------------------- | ------------------------------------------- | ------------------------------ |
| Le compré un pastel a mi hija.            | I bought my daughter a cake.                | redundant *le* + named recipient |
| Le presté dinero a mi primo.              | I lent my cousin money.                     | redundant *le* + named recipient |
| Les compramos entradas a los niños.       | We bought the kids tickets.                 | redundant *les* + named recipients |
| ¿Le prestaste tu carro a tu amigo?        | Did you lend your car to your friend?       | redundant *le* + named recipient |

## Sending and Returning with a Named Recipient

*Enviar/mandar* and *devolver* are two more verbs that need the redundant pronoun.

| Spanish                                | English                              | Notes                    |
| ----------------------------------------- | ------------------------------------------- | ------------------------------ |
| Le mandé un mensaje a mi hermana.         | I sent my sister a message.                 | redundant *le* + named recipient |
| Le devolví el dinero a mi amigo.          | I paid my friend back the money.            | redundant *le* + named recipient |
| Les enviamos fotos a nuestros papás.      | We sent our parents photos.                 | redundant *les* + named recipients |
| ¿Le devolviste la llave a la casera?      | Did you return the key to the landlady?     | redundant *le* + named recipient |

## Dropping the Named Recipient (Pronoun Alone Still Works)

The pronoun by itself is enough once the recipient is understood from context.

| Spanish                                | English                              | Notes                    |
| ----------------------------------------- | ------------------------------------------- | ------------------------------ |
| Le di el regalo ayer.                     | I gave him/her the gift yesterday.          | *le* alone, recipient dropped   |
| Les conté la noticia esta mañana.         | I told them the news this morning.          | *les* alone, recipient dropped  |
| Le presté mi cuaderno.                    | I lent him/her my notebook.                 | *le* alone, recipient dropped   |
| ¿Le devolviste el libro?                  | Did you return the book to him/her?         | *le* alone, recipient dropped   |
