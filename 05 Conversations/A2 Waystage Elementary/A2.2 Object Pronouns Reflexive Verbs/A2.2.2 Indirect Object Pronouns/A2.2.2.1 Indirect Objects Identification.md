# Indirect Objects Identification — Conversational Sentences

## Giving Something to Someone

*Dar* is the classic indirect-object verb — there's always a giver, a thing given, and a receiver.

| Spanish                              | English                              | Notes                    |
| ----------------------------------------- | ------------------------------------------- | ------------------------------ |
| Le di mi número de teléfono.              | I gave him/her my phone number.             | *le*, indirect object            |
| ¿Les diste las instrucciones?             | Did you give them the instructions?         | *les*, indirect object            |
| Nos dieron un descuento en la tienda.     | They gave us a discount at the store.       | *nos*, indirect object            |
| Te doy mi opinión si quieres.             | I'll give you my opinion if you want.       | *te*, indirect object            |

## Explaining or Telling Someone Something

*Decir*, *explicar*, and *contar* all work the same way — someone receives the information.

| Spanish                                | English                              | Notes                    |
| ------------------------------------------ | ------------------------------------------- | ------------------------------ |
| ¿Me puedes explicar cómo funciona?         | Can you explain to me how it works?         | *me*, indirect object            |
| Le conté todo lo que pasó.                 | I told him/her everything that happened.    | *le*, indirect object            |
| Les dije la verdad desde el principio.     | I told them the truth from the start.       | *les*, indirect object            |
| ¿Nos vas a contar el final?                | Are you going to tell us the ending?        | *nos*, indirect object            |

## Writing or Sending Something to Someone

Common when talking about messages, letters, and packages.

| Spanish                                | English                              | Notes                    |
| ------------------------------------------ | ------------------------------------------- | ------------------------------ |
| Le escribí un correo esta mañana.          | I wrote him/her an email this morning.      | *le*, indirect object            |
| ¿Te mandaron el paquete todavía?           | Did they send you the package already?      | *te*, indirect object            |
| Nos enviaron la información por correo.    | They sent us the information by mail.       | *nos*, indirect object            |
| Les escribo cada semana.                   | I write to them every week.                 | *les*, indirect object            |

## Buying or Doing Something for Someone

The "benefactive" use — doing something *for* someone's benefit.

| Spanish                                | English                              | Notes                    |
| ------------------------------------------ | ------------------------------------------- | ------------------------------ |
| Le compré flores por su cumpleaños.        | I bought him/her flowers for his/her birthday. | *le*, benefactive             |
| ¿Nos puedes preparar algo de comer?        | Can you make us something to eat?           | *nos*, benefactive               |
| Les organicé una sorpresa.                 | I organized a surprise for them.            | *les*, benefactive               |
| Te reservé una mesa para las ocho.         | I reserved a table for you for eight o'clock. | *te*, benefactive              |

## Distinguishing the Direct Object from the Indirect Object

Practicing the "what" (direct) vs. "to/for whom" (indirect) distinction in one sentence.

| Spanish                                    | English                                | Notes                       |
| ------------------------------------------------ | -------------------------------------------- | -------------------------------- |
| Le di el libro a mi hermano.                     | I gave the book to my brother.               | *el libro* direct, *le* indirect  |
| Les mandé las fotos a mis padres.                | I sent the photos to my parents.             | *las fotos* direct, *les* indirect|
| Me prestaron el carro para el fin de semana.     | They lent me the car for the weekend.        | *el carro* direct, *me* indirect  |
| Te devolví la mochila ayer.                      | I returned the backpack to you yesterday.    | *la mochila* direct, *te* indirect|
