# Direct Object Placement — Conversational Sentences

## Single Verb, Pronoun Always First

The simplest and most common pattern in daily speech.

| Spanish                          | English                          | Notes                    |
| ------------------------------------ | ------------------------------------- | ------------------------------ |
| La conozco desde hace años.          | I've known her for years.             | single verb, pronoun before      |
| Los necesito para mañana.            | I need them for tomorrow.             | single verb, pronoun before      |
| ¿Me escuchas bien?                   | Can you hear me well?                 | single verb, pronoun before      |
| Nos esperan en la entrada.           | They're waiting for us at the entrance. | single verb, pronoun before    |

## Two Verbs: Pronoun Before the Conjugated Verb

One valid option when a conjugated verb is followed by an infinitive.

| Spanish                              | English                              | Notes                    |
| ----------------------------------------- | ------------------------------------------- | ------------------------------ |
| La quiero ver esta noche.                 | I want to see it tonight.                   | pronoun before conjugated verb   |
| Los puedo ayudar mañana.                  | I can help them tomorrow.                   | pronoun before conjugated verb   |
| Te voy a llamar en un rato.               | I'm going to call you in a bit.             | pronoun before conjugated verb   |
| Lo debo terminar hoy.                     | I have to finish it today.                  | pronoun before conjugated verb   |

## Two Verbs: Pronoun Attached to the Infinitive

The equally correct alternative placement.

| Spanish                              | English                              | Notes                    |
| ----------------------------------------- | ------------------------------------------- | ------------------------------ |
| ¿Quieres verla esta noche?                | Do you want to see it tonight?              | pronoun attached to infinitive   |
| Podemos ayudarlos mañana.                 | We can help them tomorrow.                  | pronoun attached to infinitive   |
| Voy a llamarte en un rato.                | I'm going to call you in a bit.             | pronoun attached to infinitive   |
| Debo terminarlo hoy.                      | I have to finish it today.                  | pronoun attached to infinitive   |

## Gerund Constructions (Estar + -ndo)

Common when describing what's happening right now.

| Spanish                                | English                              | Notes                    |
| ------------------------------------------ | ------------------------------------------- | -------------------------------- |
| Lo estoy leyendo ahora mismo.              | I'm reading it right now.                   | pronoun before *estoy*             |
| Estoy leyéndolo ahora mismo.               | I'm reading it right now.                   | pronoun attached, accent added     |
| La estamos esperando afuera.               | We're waiting for her outside.              | pronoun before *estamos*           |
| Estamos esperándola afuera.                | We're waiting for her outside.              | pronoun attached, accent added     |

## Mixing Both Options Naturally in Conversation

Real speech often switches between the two placements without any pattern.

| Spanish                                | English                              | Notes                    |
| ------------------------------------------ | ------------------------------------------- | -------------------------------- |
| ¿Me puedes ayudar? — Claro, te ayudo ahora. | Can you help me? — Sure, I'll help you now. | mixed placements in one exchange |
| Quiero probarlo, pero no lo puedo comprar todavía. | I want to try it, but I can't buy it yet. | one attached, one before          |
| Voy a explicarlo despacio.                 | I'm going to explain it slowly.             | pronoun attached to infinitive     |
| Está preparándolo para la cena.            | He/she is preparing it for dinner.          | pronoun attached to gerund         |
