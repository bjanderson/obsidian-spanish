# Physical and Circumstantial Ability (Poder) — Conversational Sentences

## Asking for Help

*Poder* used to politely ask someone for a favor.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| ¿Me puedes ayudar con esto? | Can you help me with this? | common favor-asking phrase |
| ¿Puedes pasarme la sal? | Can you pass me the salt? | everyday request |
| ¿Podrías cerrar la ventana? | Could you close the window? | softer, conditional-flavored request |
| ¿Puedes explicarme cómo funciona? | Can you explain to me how it works? | request for clarification |

## Declining or Explaining You Can't

*Poder* in the negative, common when turning down a plan or explaining a limit.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| No puedo salir hoy, tengo mucho que hacer. | I can't go out today, I have a lot to do. | polite excuse |
| Lo siento, no puedo ayudarte ahora mismo. | Sorry, I can't help you right now. | apologetic decline |
| No podemos ir a la fiesta este fin de semana. | We can't go to the party this weekend. | *nosotros* form |
| Ella no puede venir porque está enferma. | She can't come because she's sick. | reason-giving |

## Making Suggestions or Requests

*Poder* used to propose something politely.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| ¿Podemos hablar un momento? | Can we talk for a moment? | polite request to talk |
| ¿Podemos empezar la reunión? | Can we start the meeting? | group suggestion |
| Si quieres, podemos ir juntos. | If you want, we can go together. | offering a plan |
| ¿Puedo hacer una pregunta? | Can I ask a question? | classroom/meeting phrase |

## Talking About What Is or Isn't Possible

General statements about ability or circumstance, not tied to a request.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Con esta lluvia, no podemos salir a caminar. | With this rain, we can't go out for a walk. | circumstantial ability |
| Puedo trabajar desde casa los viernes. | I can work from home on Fridays. | schedule/permission |
| Mis papás no pueden viajar este año. | My parents can't travel this year. | *ellos* form |
| Quiero ir contigo, pero no puedo. | I want to go with you, but I can't. | contrast with *querer* |
