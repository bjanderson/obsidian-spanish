# Key Consonant Differences — Conversational Sentences

Natural sentences a Spanish speaker would actually say, chosen to give
practice with the consonants that don't map directly onto English sounds.

## Silent h and soft c/g

Common phrases where *h* must stay silent and *c*/*g* soften before *e*
or *i* — two of the easiest habits to get wrong out of English instinct.

| Spanish             | English              | Notes                                            |
| -------------------- | --------------------- | --------------------------------------------------- |
| Hola, ¿cómo estás?   | Hi, how are you?      | *h* in *hola* is silent — the word starts on the vowel. |
| Hace calor hoy.      | It's hot today.       | Both *h* letters stay silent.                       |
| Hay mucha gente aquí. | There are a lot of people here. | *g* before *e* is the throaty *j* sound, not hard "g." |
| Es un día especial.  | It's a special day.   | *c* before *i* is a soft "s," not "k."              |
| Necesito hacer algo.  | I need to do something. | *c* before *e/i* is soft; the *h* in *hacer* is silent. |

## The throaty j sound

Everyday words and phrases built around *j*, always the same harsh, throaty
sound no matter which vowel follows it.

| Spanish              | English             | Notes                                        |
| --------------------- | -------------------- | ----------------------------------------------- |
| Trabajo todos los días. | I work every day.  | *j* is throaty, never like English "j."         |
| Quiero un jugo de naranja. | I want an orange juice. | *j* in *jugo* stays harsh and throaty.        |
| Es un viaje largo.    | It's a long trip.    | *j* in *viaje* keeps the same throaty sound.    |
| Hoy es jueves.        | Today is Thursday.   | *j* in *jueves* is throaty; *h* in *hoy* is silent. |
| No tengo mucho dinero. | I don't have much money. | Contrast: no *j* here — use to hear the difference from surrounding words. |

## Single r vs. rolled rr

Pairs and phrases that put the single tap *r* and the trilled *rr* right
next to each other, since the contrast carries real meaning.

| Spanish                  | English                | Notes                                              |
| -------------------------- | ------------------------ | ----------------------------------------------------- |
| Tengo un perro pero no tengo gato. | I have a dog but I don't have a cat. | *perro* (trill) vs. *pero* (tap) in the same sentence. |
| El carro es caro.         | The car is expensive.    | *carro* (trill) vs. *caro* (tap) — same contrast again. |
| Quiero un poco de arroz.  | I want a little rice.    | *rr* in *arroz* is a full trill.                    |
| Voy a correr mañana.      | I'm going to run tomorrow. | *rr* in *correr* trills; the *r* at the start of *run* concept doesn't apply here but note the double *r* spelling. |
| Prefiero el carro rojo.   | I prefer the red car.    | Single tap *r* in *prefiero* and *rojo* vs. the trill in *carro*. |

## The ñ sound

Short exchanges that use *ñ*, a distinct letter from plain *n* — mixing them
up changes the word entirely.

| Spanish                | English              | Notes                                          |
| ------------------------ | ---------------------- | -------------------------------------------------- |
| ¿Cuántos años tienes?    | How old are you?       | *años* uses *ñ* ("ny"), not plain *n*.             |
| Mañana tengo una reunión. | Tomorrow I have a meeting. | *mañana* and *reunión* both carry the *ñ* sound.   |
| Vivo aquí desde niño.    | I've lived here since I was a kid. | *niño* — mixing up *ñ* and *n* changes the word.  |
| Es una señora amable.    | She's a kind woman.    | *señora* keeps the "ny" sound clear.               |
| El baño está cerca.      | The bathroom is nearby. | *baño* with *ñ* sounds nothing like *bano* would.  |
