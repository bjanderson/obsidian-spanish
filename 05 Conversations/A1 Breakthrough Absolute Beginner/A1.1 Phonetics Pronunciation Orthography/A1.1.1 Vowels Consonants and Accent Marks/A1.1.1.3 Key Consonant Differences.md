# Key Consonant Differences — Conversational Sentences

Natural sentences a Spanish speaker would actually say, using this lesson's point,
grouped by the pattern each sentence follows.

## *Seseo* — c and z sounding like "s"

Everyday sentences that lean on the c/z-as-"s" merger, the neutral Latin American standard.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Gracias por todo. | Thanks for everything. | *Gracias* — the *c* before *ia* sounds like "s," not "th." |
| ¿Cuánto cuesta esto? | How much does this cost? | *Cuesta* has a hard "k" sound (*c* before *u*); compare to the soft *c* in *gracias*. |
| Voy a hacer las compras. | I'm going to do the shopping. | *Hacer* has a soft *c* (like "s"); *compras* has a hard *c* (like "k"). |
| La película empieza a las cinco. | The movie starts at five. | Three soft *c*'s in a row — *película*, *empieza* (with a *z*), and *cinco* — all sound like "s." |
| No tengo dinero en efectivo. | I don't have cash. | *Efectivo* — the *c* before *i* sounds like "s." |

## G and J — the hard/soft *g* split and the *jota* sound

Common sentences where *g* switches sound based on the vowel after it, and *j* stays constant.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Trabajo en una oficina grande. | I work in a big office. | *Trabajo* uses the *jota* sound; *grande* uses the hard "g" (before *r*). |
| Mi hijo juega videojuegos. | My son plays video games. | *Juega* and *videojuegos* both use the *jota* sound, regardless of the vowel after the *j*. |
| Voy a la agencia de viajes. | I'm going to the travel agency. | *Agencia* — the *g* before *e* sounds like *jota*, not like a hard "g." |
| Es un chico muy inteligente. | He's a very smart guy. | *Inteligente* — the *g* before *e* softens to the *jota* sound. |
| Llegamos tarde otra vez. | We arrived late again. | *Llegamos* keeps the hard "g" sound because it's followed by *a*. |

## R vs. RR — the tap-versus-trill distinction

Sentences that only make sense with the correct *r* sound — mixing them up can change the meaning.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Quiero un perro pequeño. | I want a small dog. | *Perro* needs the rolled trill — *pero* (but) would completely change the sentence. |
| ¿Cuánto cuesta el carro? | How much does the car cost? | *Carro* uses the trill; compare to the soft tap in *cuesta*. |
| Es muy caro para mí. | It's too expensive for me. | *Caro* uses the soft tap — a single *r* between vowels. |
| Nos vemos el jueves. | See you Thursday. | *Jueves* uses the soft tap, even though it's a common everyday word. |
| Corre todos los días. | He runs every day. | *Corre* uses the trill because it's spelled with a double *rr*. |

## Ñ as its own distinct sound

Everyday phrases where *ñ* can't be swapped for *n* without changing the word.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Mañana tengo una reunión. | Tomorrow I have a meeting. | *Mañana* — the *ñ* is a nasal "ny" sound, not a plain *n*. |
| Ella cumple años el sábado. | She has a birthday on Saturday. | *Años* — mixing up *ñ* and *n* here would turn "years" into *anos*. |
| El baño está ocupado. | The bathroom is occupied. | *Baño* keeps the same distinct *ñ* sound in everyday vocabulary. |
| Tiene el pelo castaño. | He has brown hair. | *Castaño* — the *ñ* sound stays the same even at the end of a longer word. |
