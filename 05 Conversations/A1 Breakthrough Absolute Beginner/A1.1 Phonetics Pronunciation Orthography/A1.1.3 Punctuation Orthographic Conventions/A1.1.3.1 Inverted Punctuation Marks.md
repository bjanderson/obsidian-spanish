# Inverted Punctuation Marks — Conversational Sentences

Natural sentences a Spanish speaker would actually write, using this lesson's point,
grouped by the pattern each sentence follows.

## Whole-sentence questions

The entire sentence is the question, so *¿* opens it and *?* closes it.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| ¿Qué haces? | What are you doing? | Common opener in a text message. |
| ¿A qué hora llegas? | What time are you arriving? | *a* attaches to *qué hora*, not omitted. |
| ¿Ya comiste? | Have you eaten yet? | Informal, no subject pronoun needed. |
| ¿Me puedes ayudar? | Can you help me? | *me* placed before the conjugated verb. |
| ¿Tienes planes para el fin de semana? | Do you have plans for the weekend? | Neutral register, works in most contexts. |

## Whole-sentence exclamations

The entire sentence is the exclamation, so *¡* opens it and *!* closes it.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| ¡Qué bueno! | That's great! | Very common casual reaction. |
| ¡No lo puedo creer! | I can't believe it! | *lo* refers to something already mentioned. |
| ¡Feliz cumpleaños! | Happy birthday! | Fixed greeting phrase. |
| ¡Cuídate mucho! | Take good care of yourself! | Common way to end a conversation. |
| ¡Qué gusto verte! | So good to see you! | Common greeting between friends. |

## Partial question or exclamation after a lead-in

Only the interrogative or exclamatory part gets bracketed; the lead-in stays outside,
separated by a comma.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Oye, ¿tienes un minuto? | Hey, do you have a minute? | *Oye* is outside the question. |
| Perdón, ¿sabes dónde queda el baño? | Excuse me, do you know where the bathroom is? | *Perdón* is outside the question. |
| Bueno, ¡nos vemos mañana! | Okay, see you tomorrow! | *Bueno* is outside the exclamation. |
| Mira, ¡qué lindo perrito! | Look, what a cute little dog! | *Mira* is outside the exclamation. |
| A ver, ¿qué opinas tú? | Let's see, what do you think? | *A ver* is outside the question. |

## Exclamatory questions

A question asked with strong surprise or emotion carries both marks at each end,
nested in either order.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| ¡¿En serio?! | Seriously?! | Very common reaction to surprising news. |
| ¿¡Qué dices!? | What are you saying?! | Order of marks can flip; both are correct. |
| ¡¿Ganamos?! | We won?! | Short, high-energy reaction. |
| ¿¡Ya llegaste!? | You're already here?! | Surprise at unexpectedly fast arrival. |

## Two clauses in one message, each with its own marks

Casual texting often stacks a statement, a question, and an exclamation in one line,
each keeping its own punctuation.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Ya salí de trabajar, ¿dónde nos vemos? | I'm off work now, where should we meet? | Statement + separate question. |
| No sabía nada de esto, ¡qué locura! | I had no idea about this, how crazy! | Statement + separate exclamation. |
| Todavía no llego, ¿me esperas? | I'm not there yet, can you wait for me? | Statement + separate question. |
| Se me olvidó por completo, ¡perdón! | I totally forgot, sorry! | Statement + separate exclamation. |
