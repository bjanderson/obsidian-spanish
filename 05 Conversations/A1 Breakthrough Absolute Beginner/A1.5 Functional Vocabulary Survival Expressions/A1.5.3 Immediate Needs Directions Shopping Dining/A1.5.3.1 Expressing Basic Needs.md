# Expressing Basic Needs — Conversational Sentences

## Stating a Genuine Need with Necesito

Requests that carry real urgency or requirement.

| Spanish                          | English                          | Notes                       |
| --------------------------------------- | -------------------------------------- | ------------------------------------ |
| Necesito un médico, es urgente.        | I need a doctor, it's urgent.          | *necesito* + noun                     |
| Necesito llegar al aeropuerto rápido.  | I need to get to the airport quickly.  | *necesito* + infinitive               |
| Necesito descansar un momento.         | I need to rest for a moment.           | *necesito* + infinitive               |
| Necesito hablar con el gerente.        | I need to speak with the manager.      | *necesito* + infinitive               |

## Making Everyday Requests with Quiero

Casual wants that come up constantly in daily life.

| Spanish                            | English                              | Notes                          |
| -------------------------------------------- | -------------------------------------------- | -------------------------------------- |
| Quiero un vaso de agua, por favor.          | I want a glass of water, please.            | *quiero* + noun, everyday request       |
| Quiero probar ese plato.                    | I want to try that dish.                     | *quiero* + infinitive                   |
| Quiero cambiar mi reservación.              | I want to change my reservation.             | *quiero* + infinitive                   |
| Quiero descansar antes de salir.            | I want to rest before going out.             | *quiero* + infinitive                   |

## Asking Where Something Is

Locating a specific, known place or thing.

| Spanish                                | English                                | Notes                          |
| -------------------------------------------------- | -------------------------------------------------- | -------------------------------------- |
| ¿Dónde está el baño, por favor?                   | Where's the bathroom, please?                      | *dónde está*                            |
| ¿Dónde está la salida?                            | Where's the exit?                                   | *dónde está*                            |
| ¿Dónde está mi maleta?                            | Where's my suitcase?                                | *dónde está*                            |
| ¿Sabe dónde está la parada del bus?               | Do you know where the bus stop is?                  | *dónde está* inside a bigger question   |

## Asking Whether Something Exists Nearby

Checking availability before knowing a specific location.

| Spanish                                | English                                | Notes                          |
| -------------------------------------------------- | -------------------------------------------------- | -------------------------------------- |
| ¿Hay un cajero automático cerca?                  | Is there an ATM nearby?                            | *hay*                                   |
| ¿Hay wifi en este lugar?                          | Is there wifi at this place?                        | *hay*                                   |
| ¿Hay algo vegetariano en el menú?                 | Is there anything vegetarian on the menu?           | *hay*                                   |
| ¿Hay espacio para uno más?                        | Is there room for one more?                          | *hay*                                   |

## Making Polite Requests with Puedo

Softer requests for permission or a small favor.

| Spanish                                | English                                | Notes                          |
| -------------------------------------------------- | -------------------------------------------------- | -------------------------------------- |
| ¿Puedo usar el baño?                              | Can I use the bathroom?                            | *puedo*, permission                     |
| ¿Puedo sentarme aquí?                             | Can I sit here?                                     | *puedo*, permission                     |
| ¿Puedo pedirte un favor?                          | Can I ask you a favor?                              | *puedo*, polite request                 |
| ¿Puedo pagar con tarjeta o solo efectivo?         | Can I pay with card or only cash?                    | *puedo*, practical request              |
