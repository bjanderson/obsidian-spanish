# Cardinal Numbers (0–100+) — Conversational Sentences

## Talking About Age

Everyday sentences using numbers to state or ask age.

| Spanish                          | English                          | Notes                       |
| --------------------------------------- | -------------------------------------- | ------------------------------------ |
| Tengo veintinueve años.                | I'm twenty-nine years old.             | fused 16-29 form                      |
| Mi hermano tiene treinta y cuatro años.| My brother is thirty-four years old.   | 30+ pattern                           |
| ¿Cuántos años tienes?                  | How old are you?                       | asking age                            |
| Mi abuela tiene ochenta y dos años.    | My grandmother is eighty-two years old.| 30+ pattern                           |

## Talking About Prices

Numbers used constantly when shopping or discussing money.

| Spanish                              | English                              | Notes                          |
| -------------------------------------------- | -------------------------------------------- | -------------------------------------- |
| Cuesta cincuenta pesos.                     | It costs fifty pesos.                       | decade word                            |
| Son sesenta y ocho dólares en total.        | It's sixty-eight dollars total.             | 30+ pattern                             |
| Este vale cien dólares.                     | This one is worth one hundred dollars.      | *cien* alone                            |
| El descuento es de treinta por ciento.      | The discount is thirty percent.             | decade word                             |

## Counting People and Things

Quantities that come up in daily conversation.

| Spanish                                | English                                | Notes                         |
| -------------------------------------------------- | -------------------------------------------------- | -------------------------------------- |
| Éramos veintidós en la fiesta.                    | There were twenty-two of us at the party.          | fused 16-29 form                       |
| Compramos treinta y una sillas.                   | We bought thirty-one chairs.                        | *una* before feminine noun              |
| Hay cuarenta y cinco mensajes sin leer.           | There are forty-five unread messages.               | 30+ pattern                             |
| Faltan diecisiete personas por confirmar.         | Seventeen people still need to confirm.             | fused 16-29 form                        |

## Phone Numbers and Codes

Numbers said digit by digit or in small groups, common in real speech.

| Spanish                                | English                                    | Notes                              |
| -------------------------------------------------- | ------------------------------------------------- | ------------------------------------------- |
| Mi número es cero, nueve, ocho, siete...           | My number is zero, nine, eight, seven...           | digit-by-digit                              |
| El código postal es cero, cuatro, uno, cero.        | The zip code is zero, four, one, zero.             | digit-by-digit                              |
| Marca el noventa y uno primero.                    | Dial ninety-one first.                              | 30+ pattern used as a code                  |
| La clave tiene cinco números.                      | The code has five digits.                           | using a number to describe quantity          |

## Floors, Rooms, and Addresses

Numbers past 100 in everyday location contexts.

| Spanish                                 | English                                  | Notes                             |
| ---------------------------------------------------- | -------------------------------------------------- | -------------------------------------------- |
| Vivo en el piso ciento veinte.                       | I live on floor one hundred twenty.                | *ciento* past 100                            |
| El hotel tiene ciento cincuenta habitaciones.        | The hotel has one hundred fifty rooms.             | *ciento* past 100                            |
| Mi casa es la número cien.                           | My house is number one hundred.                    | *cien* alone                                  |
| Estamos en el cuarto ciento uno.                     | We're in room one hundred one.                      | *ciento uno*                                  |
