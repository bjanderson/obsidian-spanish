# ER Conjugation Endings — Conversational Sentences

## Talking About Meals and Drinks

Everyday *yo* form statements about eating and drinking.

| Spanish                     | English                    | Notes             |
| -------------------------------- | -------------------------------- | ------------------------ |
| Como cereal en la mañana.         | I eat cereal in the morning.     | *comer*, *yo*             |
| Bebo mucha agua.                  | I drink a lot of water.          | *beber*, *yo*             |
| No como carne.                    | I don't eat meat.                | *comer*, negative         |
| Bebo café sin azúcar.             | I drink coffee without sugar.    | *beber*, *yo*             |

## Asking a Friend About Habits

*Tú* form questions.

| Spanish                    | English                     | Notes            |
| -------------------------------- | -------------------------------- | ------------------------ |
| ¿Qué comes normalmente?           | What do you normally eat?        | *comer*, *tú*             |
| ¿Lees mucho?                      | Do you read a lot?               | *leer*, *tú*              |
| ¿Comprendes el problema?          | Do you understand the problem?   | *comprender*, *tú*        |
| ¿Corres por las mañanas?          | Do you run in the mornings?      | *correr*, *tú*            |

## Describing What Someone Else Does

*Él/ella* form.

| Spanish                    | English                    | Notes             |
| --------------------------------- | --------------------------------- | ------------------------ |
| Mi abuela lee todas las noches.    | My grandma reads every night.     | *leer*, *ella*            |
| Mi hijo bebe mucha leche.          | My son drinks a lot of milk.      | *beber*, *él*             |
| Ella vende ropa en línea.          | She sells clothes online.         | *vender*, *ella*          |
| Él aprende rápido.                 | He learns fast.                   | *aprender*, *él*          |

## Talking About What We Do Together

*Nosotros* form.

| Spanish                       | English                       | Notes             |
| ------------------------------------ | -------------------------------------- | ------------------------ |
| Comemos juntos los domingos.          | We eat together on Sundays.            | *comer*, *nosotros*      |
| Aprendemos mucho en esta clase.       | We learn a lot in this class.          | *aprender*, *nosotros*   |
| Corremos en el parque los sábados.    | We run in the park on Saturdays.       | *correr*, *nosotros*     |
| Debemos llegar temprano.              | We should arrive early.                | *deber*, *nosotros*      |

## Talking About What Other People Do

*Ellos/ustedes* form.

| Spanish                    | English                      | Notes            |
| --------------------------------- | ------------------------------------ | ------------------------ |
| Mis padres leen el periódico.      | My parents read the newspaper.       | *leer*, *ellos*           |
| Mis hijos corren mucho.            | My kids run a lot.                   | *correr*, *ellos*         |
| ¿Ustedes venden esta casa?         | Are you (all) selling this house?    | *vender*, *ustedes*       |
| Ellos comen muy tarde.             | They eat very late.                  | *comer*, *ellos*          |
