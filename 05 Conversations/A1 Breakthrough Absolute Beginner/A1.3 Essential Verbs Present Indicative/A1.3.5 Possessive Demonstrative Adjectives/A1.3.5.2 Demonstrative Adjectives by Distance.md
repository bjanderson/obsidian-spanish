# Demonstrative Adjectives by Distance — Conversational Sentences

## Talking About Things Right Here with Este/Esta

Pointing at something close to you.

| Spanish                     | English                       | Notes             |
| ---------------------------------- | -------------------------------------- | ------------------------- |
| Este café está muy caliente.        | This coffee is very hot.               | *este*, masculine          |
| Esta silla es muy cómoda.           | This chair is very comfortable.        | *esta*, feminine           |
| ¿Puedes ayudarme con esto?          | Can you help me with this?             | neuter *esto*              |
| Estos zapatos me quedan perfectos.  | These shoes fit me perfectly.          | *estos*, masculine plural  |

## Talking About Things Near the Listener with Ese/Esa

Pointing at something closer to the other person.

| Spanish                     | English                        | Notes            |
| ---------------------------------- | -------------------------------------- | ------------------------- |
| ¿Me pasas ese libro?                | Can you pass me that book?             | *ese*, near listener       |
| Esa camisa te queda muy bien.       | That shirt looks great on you.         | *esa*, feminine            |
| No me gusta ese plan.               | I don't like that plan.                | *ese*, masculine             |
| ¿Cuánto cuestan esos zapatos?       | How much do those shoes cost?          | *esos*, masculine plural   |

## Talking About Things Far Away with Aquel/Aquella

Pointing at something distant from both speaker and listener.

| Spanish                            | English                             | Notes              |
| ------------------------------------------ | ---------------------------------------------- | -------------------------- |
| Aquel restaurante es excelente.             | That restaurant over there is excellent.        | *aquel*, distant            |
| Aquella tienda vende ropa muy barata.       | That store over there sells very cheap clothes. | *aquella*, distant           |
| ¿Ves aquellas montañas?                     | Do you see those mountains over there?          | *aquellas*, distant plural   |
| En aquel entonces, todo era diferente.      | Back then, everything was different.            | idiomatic time expression    |

## Choosing Between an Object without Repeating It

Dropping the noun once it's clear from context.

| Spanish                       | English                      | Notes             |
| ------------------------------------ | -------------------------------------- | ------------------------- |
| ¿Quieres este o ese?                  | Do you want this one or that one?      | dropped noun               |
| Prefiero esta, no esa.                | I prefer this one, not that one.       | dropped noun, feminine     |
| No quiero ninguno de esos.            | I don't want any of those.             | dropped noun, plural       |
| Me gusta más aquel.                   | I like that one over there better.     | dropped noun, distant      |

## Asking What Something Is

Using the neuter forms for unidentified things or ideas.

| Spanish                    | English                     | Notes             |
| --------------------------------- | -------------------------------------- | ------------------------- |
| ¿Qué es esto?                      | What is this?                          | neuter *esto*               |
| No entiendo eso.                   | I don't understand that.               | neuter *eso*                |
| Eso no tiene sentido.              | That doesn't make sense.               | neuter *eso*, idea          |
| Quiero hablar de eso más tarde.    | I want to talk about that later.       | neuter *eso*, topic         |
