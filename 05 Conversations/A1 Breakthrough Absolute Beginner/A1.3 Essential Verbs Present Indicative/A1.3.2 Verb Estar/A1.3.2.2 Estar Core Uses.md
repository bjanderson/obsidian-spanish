# Estar Core Uses — Conversational Sentences

## Asking Where Things Are

Everyday questions about location.

| Spanish                        | English                        | Notes                     |
| ----------------------------------- | ------------------------------------ | -------------------------------- |
| ¿Dónde está el baño?                 | Where is the bathroom?               | very common question             |
| El supermercado está cerca de aquí.  | The supermarket is near here.        | *cerca de*                       |
| Mi casa está lejos del centro.       | My house is far from downtown.       | *lejos de* + *del* contraction   |
| ¿Dónde están mis lentes?             | Where are my glasses?                | plural subject                   |

## Checking If Something Exists with Hay

Asking whether something is available, before knowing where it is.

| Spanish                       | English                      | Notes                    |
| ---------------------------------- | ----------------------------------- | ------------------------------- |
| ¿Hay wifi aquí?                     | Is there wifi here?                 | existence question              |
| Sí, hay wifi gratis.                | Yes, there's free wifi.             | existence confirmed             |
| ¿Hay una farmacia cerca?            | Is there a pharmacy nearby?         | existence question              |
| No, no hay ninguna farmacia aquí.   | No, there's no pharmacy here.       | negative existence              |

## Talking About Feelings and Conditions

Common ways to describe how someone feels in the moment.

| Spanish                    | English                     | Notes                  |
| -------------------------------- | ---------------------------------- | ----------------------------- |
| Estoy un poco enfermo.            | I'm a little sick.                 | temporary physical state      |
| ¿Estás bien?                      | Are you okay?                      | common check-in               |
| Está de mal humor hoy.            | She's in a bad mood today.         | temporary emotional state     |
| Estamos emocionados por el viaje. | We're excited about the trip.      | plural emotional state        |

## Describing Food and Drinks Right Now

Using *estar* for taste, temperature, and freshness in the moment.

| Spanish                    | English                    | Notes                  |
| -------------------------------- | --------------------------------- | ----------------------------- |
| Esta pizza está riquísima.        | This pizza is really tasty.       | food, this serving            |
| El café está frío.                | The coffee is cold.                | temperature                    |
| Las fresas están muy dulces hoy.  | The strawberries are very sweet today. | how they taste today      |
| ¿Cómo está la sopa?               | How's the soup?                    | asking for a taste opinion     |

## Locating Things with Prepositions

Combining *estar* with common prepositions of place.

| Spanish                        | English                        | Notes                    |
| ------------------------------------ | ------------------------------------- | -------------------------------- |
| El perro está debajo de la mesa.      | The dog is under the table.           | *debajo de*                      |
| La tienda está entre el banco y el parque. | The store is between the bank and the park. | *entre*                    |
| El gato está encima de la cama.       | The cat is on top of the bed.         | *encima de*                      |
| Estamos al lado del hotel.            | We're next to the hotel.              | *al lado de* + *del* contraction |
