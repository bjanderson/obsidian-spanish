# Standard Gender Endings — Conversational Sentences

Natural sentences a Spanish speaker would actually say, using this lesson's point,
grouped by the pattern each sentence follows.

## Asking where a common -o/-a object is

Everyday objects with the standard endings, paired with their article.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| ¿Dónde está el libro? | Where is the book? | *el libro*, *-o* → masculine. |
| La mesa está en la cocina. | The table is in the kitchen. | *la mesa*, *-a* → feminine. |
| ¿Tienes el carro hoy? | Do you have the car today? | *el carro*, *-o* → masculine. |
| Deja la mochila aquí. | Leave the backpack here. | *la mochila*, *-a* → feminine. |

## Talking about places using -dad/-ción words

Common feminine nouns from the *-dad*/*-ción* family come up constantly in
everyday talk about places and information.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Esta ciudad es enorme. | This city is huge. | *la ciudad*, *-dad* → feminine. |
| Necesito más información. | I need more information. | *la información*, *-ción* → feminine. |
| La libertad es importante para mí. | Freedom is important to me. | *la libertad*, *-tad* → feminine. |
| ¿Cuál es la dirección? | What's the address? | *la dirección*, *-ción* → feminine. |

## Describing a color using an -or word

*-or*-ending nouns like *color* and *amor* show up in casual descriptions.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Me encanta ese color. | I love that color. | *el color*, *-or* → masculine. |
| Es un amor de persona. | She's a sweetheart. | *el amor*, *-or* → masculine, idiomatic. |
| ¿Cuál es tu color favorito? | What's your favorite color? | *el color* again in a common question. |

## Learning a new word together with its article

The habit of pairing a new noun with *el/la* shows up naturally when
someone explains or corrects vocabulary.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Se dice "el problema", no "la problema". | It's "el problema," not "la problema." | Corrective, teaching context. |
| ¿Es "el mapa" o "la mapa"? | Is it "el mapa" or "la mapa"? | Common learner question. |
| Aprendí la palabra con su artículo. | I learned the word with its article. | Reinforces the study habit from the lesson. |
