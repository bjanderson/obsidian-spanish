# Pluralization Rules — Conversational Sentences

Natural sentences a Spanish speaker would actually say, using this lesson's point,
grouped by the pattern each sentence follows.

## Talking about more than one everyday object (vowel-ending nouns)

Vowel-ending nouns just add *-s*, and this pattern is everywhere in daily
speech.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Las casas del barrio son bonitas. | The houses in the neighborhood are pretty. | *casa* → *casas*. |
| Compré unos libros nuevos. | I bought some new books. | *libro* → *libros*. |
| Los coches están afuera. | The cars are outside. | *coche* → *coches*. |

## Talking about consonant-ending nouns

Consonant-ending nouns need *-es*, which shows up constantly with words
like *ciudad, papel,* and *reloj*.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Visitamos varias ciudades. | We visited several cities. | *ciudad* → *ciudades*. |
| ¿Dónde están los papeles? | Where are the papers? | *papel* → *papeles*. |
| Tengo dos relojes. | I have two watches. | *reloj* → *relojes*. |

## Talking about -z nouns that switch to -c

*Lápiz* and *vez* are common words that shift *z* to *c* before *-es*.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Necesito más lápices. | I need more pencils. | *lápiz* → *lápices*. |
| Lo he hecho muchas veces. | I've done it many times. | *vez* → *veces*. |
| Esta es la última vez, ¿de acuerdo? | This is the last time, okay? | Singular *vez* for contrast. |

## Mentioning people whose plural shifts the accent

Words like *joven* and *nación* shift their written accent in the plural
to keep the original stress.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Hay muchos jóvenes en la fiesta. | There are a lot of young people at the party. | *joven* → *jóvenes*, accent added. |
| Varias naciones firmaron el acuerdo. | Several nations signed the agreement. | *nación* → *naciones*, accent dropped. |
