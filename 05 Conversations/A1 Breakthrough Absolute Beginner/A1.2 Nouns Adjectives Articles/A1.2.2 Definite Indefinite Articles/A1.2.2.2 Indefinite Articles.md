# Indefinite Articles — Conversational Sentences

Natural sentences a Spanish speaker would actually say, using this lesson's point,
grouped by the pattern each sentence follows.

## Introducing something for the first time

*Un/una* introduces a new, unspecified thing into the conversation.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Tengo un perro nuevo. | I have a new dog. | *un* (masc. sing.). |
| Compré una camisa ayer. | I bought a shirt yesterday. | *una* (fem. sing.). |
| Vi un carro increíble. | I saw an amazing car. | *un* (masc. sing.). |
| Necesito una respuesta pronto. | I need an answer soon. | *una* (fem. sing.). |

## Talking about "some" of something plural

*Unos/unas* covers an unspecified small quantity.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Hay unos mensajes para ti. | There are some messages for you. | *unos* (masc. plural). |
| Tengo unas dudas sobre esto. | I have some doubts about this. | *unas* (fem. plural). |
| Compramos unos regalos. | We bought some gifts. | *unos* (masc. plural). |
| Vinieron unas amigas mías. | Some friends of mine came over. | *unas* (fem. plural). |

## Estimating a quantity with unos/unas

*Unos/unas* also means "about" or "approximately" before a number.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Llego en unos cinco minutos. | I'll arrive in about five minutes. | Approximation with a number. |
| Cuesta unos veinte dólares. | It costs about twenty dollars. | Approximation with a number. |
| Había unas cien personas. | There were about a hundred people. | Approximation with a number. |
