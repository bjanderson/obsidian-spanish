# Hace, Desde, and Desde Hace for Elapsed Time — Conversational Sentences

## Saying how long ago something happened

*Hace* + time + preterite verb, for a finished event in the past.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Nos conocimos hace un año, en una fiesta. | We met a year ago, at a party. | *hace* + preterite |
| Compré este carro hace seis meses. | I bought this car six months ago. | *hace* + preterite |
| Renuncié a mi trabajo hace dos semanas. | I quit my job two weeks ago. | *hace* + preterite |
| Mis padres se casaron hace treinta años. | My parents got married thirty years ago. | *hace* + preterite |
| Terminé la universidad hace poco. | I finished college not long ago. | *hace poco*, vague duration |

## Asking and saying since when something started

*Desde* + present tense, pointing to a specific starting moment.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| ¿Desde cuándo vives en esta ciudad? | Since when have you lived in this city? | question form |
| Vivo aquí desde el año pasado. | I've lived here since last year. | *desde* + point in time |
| Ella no me habla desde la discusión. | She hasn't spoken to me since the argument. | *desde* + event |
| Estamos juntos desde el 2015. | We've been together since 2015. | *desde* + year |
| No como carne desde que era niño. | I haven't eaten meat since I was a kid. | *desde que* + clause |

## Talking about how long something has been going on

*Desde hace* + present tense, focused on duration rather than a start point.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Estudio inglés desde hace tres años. | I've been studying English for three years. | *desde hace* + present |
| Vivimos en este apartamento desde hace poco. | We've been living in this apartment for a little while. | *desde hace poco* |
| Mi abuela vive sola desde hace mucho tiempo. | My grandmother has lived alone for a long time. | *desde hace mucho tiempo* |
| No hablamos desde hace varias semanas. | We haven't talked in several weeks. | *desde hace*, negation |
| Trabajamos juntos desde hace cinco años. | We've worked together for five years. | *desde hace* + present |

## Expressing duration with the flipped hace... que structure

*Hace* + time + *que* + present tense — the same duration meaning, different word order.

| Spanish | English | Notes |
| ------- | ------- | ----- |
| Hace tres años que estudio inglés. | I've been studying English for three years. | same meaning as *desde hace* version |
| Hace mucho tiempo que no la veo. | I haven't seen her in a long time. | negation |
| Hace un mes que no llueve. | It hasn't rained in a month. | impersonal subject |
| Hace dos horas que te espero. | I've been waiting for you for two hours. | ongoing action |
| ¿Hace cuánto tiempo que trabajas aquí? | How long have you worked here? | question form |
