# Auxiliary Haber Present — Conversational Sentences

## Asking If Someone Has Done Something

Common questions using the present perfect to check on a completed action.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| ¿Has comido algo hoy?                    | Have you eaten anything today?              | *has*, question             |
| ¿Ya has terminado la tarea?              | Have you finished the homework yet?          | *has*, *ya*                  |
| ¿Han llegado tus papás?                  | Have your parents arrived?                    | *han*, question               |
| ¿Ha llamado alguien mientras no estaba?  | Has anyone called while I was out?            | *ha*, impersonal subject      |

## Reporting What You've Done

Everyday statements about recent, present-relevant actions.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| He terminado el proyecto por fin.        | I've finally finished the project.           | *he*                        |
| Hemos hablado de esto varias veces.      | We've talked about this several times.        | *hemos*                     |
| Ella ha estudiado mucho para el examen.  | She's studied a lot for the exam.             | *ha*                        |
| Todavía no he decidido qué hacer.        | I still haven't decided what to do.           | *he*, negation               |

## Talking About Recent Changes

Using the present perfect for things that just happened or changed.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Han subido los precios otra vez.         | Prices have gone up again.                   | *han*                       |
| Se ha mudado a otra ciudad.              | He's moved to another city.                    | reflexive + *ha*             |
| Hemos cambiado de opinión.               | We've changed our minds.                       | *hemos*                     |
| Ha empezado a llover.                    | It's started raining.                          | *ha*, impersonal              |

## Using Object Pronouns With Haber

Practicing the correct pronoun placement before *haber*.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| ¿Lo has visto por aquí?                  | Have you seen him/it around here?             | *lo* before *has*             |
| Ya la he leído dos veces.                | I've already read it twice.                    | *la* before *he*              |
| No los hemos probado todavía.            | We haven't tried them yet.                     | *los* before *hemos*, negation |
| Se lo he explicado tres veces.           | I've explained it to him/her three times.       | double pronoun before *he*    |

## Clarifying With "Todavía" and "Ya"

Common time markers that pair naturally with the present perfect.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Todavía no hemos comido.                 | We haven't eaten yet.                          | *todavía no*                  |
| Ya he leído ese libro.                   | I've already read that book.                    | *ya*                         |
| ¿Ya has hablado con ella?                | Have you already talked to her?                 | *ya*, question                |
| Aún no ha llegado el correo.             | The mail still hasn't arrived.                   | *aún no*                     |
