# Irregular Conditional Stems — Conversational Sentences

## Softening Opinions with Diría and Podría

Common everyday hedging using *decir* and *poder*.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Yo diría que es buena idea.              | I would say it's a good idea.                   | *decir* → *dir-*             |
| Diría que tienes razón.                  | I would say you're right.                        | *decir* → *dir-*               |
| Podría ser, pero no estoy seguro.        | It could be, but I'm not sure.                    | *poder* → *podr-*                 |
| ¿Podrías ayudarme un momento?            | Could you help me for a moment?                   | *poder* → *podr-*, polite request   |

## Talking About What You Would Have To Do

Everyday obligations using *tener*.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Tendría que estudiar más para aprobar.   | I would have to study more to pass.             | *tener* → *tendr-*              |
| Tendríamos que salir temprano.           | We would have to leave early.                    | *tener* → *tendr-*, *nosotros*      |
| ¿Tendrías tiempo para ayudarme mañana?   | Would you have time to help me tomorrow?          | *tener* → *tendr-*                    |
| Ella tendría que pedir permiso primero.  | She would have to ask permission first.            | *tener* → *tendr-*                      |

## Making Plans and Setting Things Up

Everyday planning using *poner*, *hacer*, and *salir*.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Pondría la mesa antes de que llegaran.   | I would set the table before they arrived.       | *poner* → *pondr-*             |
| ¿Qué harías tú en esta situación?        | What would you do in this situation?              | *hacer* → *har-*                  |
| Saldríamos temprano si pudiéramos.       | We would leave early if we could.                 | *salir* → *saldr-*, *nosotros*       |
| Haríamos una fiesta si tuviéramos tiempo. | We would throw a party if we had time.            | *hacer* → *har-*, *nosotros*           |

## Expressing Uncertainty with Saber

Everyday hedged statements about what you know or don't know.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No sabría decirte con seguridad.         | I couldn't tell you for sure.                    | *saber* → *sabr-*              |
| ¿Sabrías cómo llegar a su casa?          | Would you know how to get to their house?          | *saber* → *sabr-*                 |
| Nadie sabría la respuesta correcta.      | Nobody would know the right answer.                | *saber* → *sabr-*, third person      |
| No sabríamos qué hacer sin ti.           | We wouldn't know what to do without you.            | *saber* → *sabr-*, *nosotros*          |

## Combining Multiple Irregular Stems in One Conversation

Realistic sentences mixing several irregular conditional verbs.

| Spanish                                              | English                                       | Notes                |
| ----------------------------------------------------------- | ---------------------------------------------------- | ------------------------ |
| Tendría que preguntarle, pero no sabría qué decir.           | I would have to ask him/her, but I wouldn't know what to say. | *tener* + *saber*            |
| Querría ayudarte, pero no podría llegar a tiempo.            | I would want to help you, but I couldn't get there on time.   | *querer* + *poder*             |
| Haríamos el viaje si tuviéramos más dinero.                  | We would take the trip if we had more money.                    | *hacer* + *tener*                |
