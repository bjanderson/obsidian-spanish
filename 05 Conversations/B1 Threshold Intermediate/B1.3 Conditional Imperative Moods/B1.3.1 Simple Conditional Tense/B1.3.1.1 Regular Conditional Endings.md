# Regular Conditional Endings — Conversational Sentences

## Talking About What You Would Do

Everyday statements about hypothetical actions.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Yo hablaría con él si tuviera la oportunidad. | I would talk to him if I had the chance.     | *hablar*, *yo*                |
| Estudiaría más si tuviera más tiempo libre.   | I would study more if I had more free time.   | *estudiar*, *yo*                |
| Trabajaría desde casa si pudiera.             | I would work from home if I could.             | *trabajar*, *yo*                  |
| Viajaría a Perú el próximo año.               | I would travel to Peru next year.               | *viajar*, *yo*                      |

## Asking What Someone Would Do

Casual questions about hypothetical choices.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| ¿Comerías eso si tuvieras hambre?        | Would you eat that if you were hungry?          | *comer*, *tú*                 |
| ¿Vivirías en otro país algún día?        | Would you live in another country someday?       | *vivir*, *tú*                    |
| ¿Comprarías esa casa si tuvieras el dinero? | Would you buy that house if you had the money? | *comprar*, *tú*                    |
| ¿Cambiarías algo de tu vida?             | Would you change something about your life?       | *cambiar*, *tú*                      |

## Talking About What Others Would Do

Describing hypothetical actions for other people.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Ella viviría feliz en cualquier lugar.   | She would live happily anywhere.                | *vivir*, *ella*               |
| Mis padres ayudarían sin dudarlo.        | My parents would help without hesitating.          | *ayudar*, plural                 |
| Mi jefe entendería la situación.         | My boss would understand the situation.             | *entender*, third person            |
| Los niños jugarían todo el día si pudieran. | The kids would play all day if they could.        | *jugar*, plural                       |

## Talking About What We Would Do Together

Everyday "we would" statements.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Viajaríamos juntos si tuviéramos vacaciones. | We would travel together if we had vacation time. | *viajar*, *nosotros*         |
| Comeríamos afuera más seguido.           | We would eat out more often.                     | *comer*, *nosotros*             |
| Ayudaríamos con mucho gusto.             | We would gladly help.                            | *ayudar*, *nosotros*               |
| Nos mudaríamos a otra ciudad si pudiéramos. | We would move to another city if we could.       | *mudarse*, *nosotros*                |

## Polite and Softened Statements

Using the conditional to soften opinions and statements in everyday speech.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Opinaría que es una buena idea.          | I would say/think that it's a good idea.          | *opinar*, softened opinion    |
| Preferiría no hablar de eso ahora.       | I'd rather not talk about that right now.         | *preferir*, softened preference  |
| Recomendaría este restaurante.           | I would recommend this restaurant.               | *recomendar*, softened opinion    |
| Sugeriría que lo pensaras un poco más.   | I would suggest you think about it a little more. | *sugerir*, softened suggestion      |
