# Formal Usted/Ustedes Commands — Conversational Sentences

## Polite Requests to Strangers and Authority Figures

Everyday formal requests using *usted*.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Disculpe, espere un momento, por favor.  | Excuse me, please wait a moment.                | *esperar*, *usted*             |
| Firme aquí, por favor.                   | Sign here, please.                               | *firmar*, *usted*                 |
| Tome asiento, por favor.                 | Have a seat, please.                              | *tomar*, *usted*                    |
| Pase por aquí, por favor.                | Come this way, please.                            | *pasar*, *usted*                      |

## Instructions in Professional or Service Settings

Common commands you'd hear from a doctor, waiter, or official.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Respire profundo, por favor.             | Breathe deeply, please.                         | *respirar*, *usted*, doctor's office |
| Llene este formulario.                   | Fill out this form.                              | *llenar*, *usted*                     |
| Traiga su identificación.                | Bring your ID.                                    | *traer*, *usted*                        |
| Elija una opción del menú.               | Choose an option from the menu.                    | *elegir*, *usted*                         |

## Addressing a Group Politely with Ustedes

Everyday commands to a group, formal or informal.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Pasen adelante, por favor.               | Come on in, please.                             | *pasar*, *ustedes*             |
| Tomen sus asientos.                      | Take your seats.                                 | *tomar*, *ustedes*                |
| Sigan las instrucciones con cuidado.     | Follow the instructions carefully.                | *seguir*, *ustedes*                 |
| Guarden silencio, por favor.             | Please be quiet.                                  | *guardar*, *ustedes*                  |

## Negative Formal Commands

Everyday formal instructions telling someone not to do something.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No se preocupe, todo está bien.          | Don't worry, everything's fine.                 | *preocuparse*, *usted*         |
| No hablen todos al mismo tiempo.         | Don't all speak at the same time.                | *hablar*, *ustedes*               |
| No se levante todavía.                   | Don't get up yet.                                 | *levantarse*, *usted*               |
| No lleguen tarde mañana.                 | Don't arrive late tomorrow.                        | *llegar*, *ustedes*                   |

## Formal Commands Using Irregular Subjunctive Stems

Common formal commands from the DISHES irregular set.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Vaya con cuidado.                        | Go carefully.                                    | *ir* → *vaya*, *usted*         |
| Sea paciente, por favor.                 | Be patient, please.                               | *ser* → *sea*, *usted*            |
| Esté atento a los cambios.               | Be alert to changes.                              | *estar* → *esté*, *usted*           |
| Sepan que estamos aquí para ayudar.      | Know that we're here to help.                      | *saber* → *sepan*, *ustedes*          |
