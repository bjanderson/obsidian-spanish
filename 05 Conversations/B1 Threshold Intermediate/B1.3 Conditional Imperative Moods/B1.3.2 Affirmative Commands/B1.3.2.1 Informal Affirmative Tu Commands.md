# Informal Affirmative Tú Commands — Conversational Sentences

## Everyday Instructions Between Friends and Family

Common commands you'd give someone you know well.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Habla más despacio, por favor.           | Speak more slowly, please.                      | *hablar*                     |
| Espera un momento.                       | Wait a moment.                                   | *esperar*                       |
| Escucha esto, es importante.             | Listen to this, it's important.                  | *escuchar*                         |
| Camina conmigo un rato.                  | Walk with me for a bit.                          | *caminar*                           |

## Giving Advice as a Command

Casual advice phrased as a direct instruction.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Descansa un poco, te ves cansado.        | Rest a bit, you look tired.                      | *descansar*                    |
| Estudia más para el próximo examen.      | Study more for the next exam.                     | *estudiar*                        |
| Habla con ella antes de que sea tarde.   | Talk to her before it's too late.                  | *hablar*                             |
| Confía en mí, todo va a salir bien.      | Trust me, everything is going to work out.          | *confiar*                              |

## Kitchen and Household Instructions

Everyday commands around the house.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Lava los platos cuando termines.         | Wash the dishes when you're done.                | *lavar*                        |
| Cierra la puerta, hace frío.             | Close the door, it's cold.                        | *cerrar*                          |
| Abre la ventana un poco.                 | Open the window a little.                          | *abrir*                             |
| Limpia tu cuarto antes de salir.         | Clean your room before you leave.                   | *limpiar*                             |

## Calling and Contacting Someone

Common commands involving communication.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Llama a tu papá cuando llegues.          | Call your dad when you arrive.                    | *llamar*, personal *a*         |
| Manda un mensaje cuando estés listo.     | Send a message when you're ready.                  | *mandar*                           |
| Contesta el teléfono, por favor.         | Answer the phone, please.                           | *contestar*                          |
| Escribe pronto, extraño tus noticias.    | Write soon, I miss your news.                        | *escribir*                             |

## Encouragement and Motivation

Everyday encouraging commands.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Intenta de nuevo, tú puedes.             | Try again, you can do it.                        | *intentar*                    |
| Cree en ti mismo.                        | Believe in yourself.                              | *creer*                          |
| Disfruta el momento.                     | Enjoy the moment.                                  | *disfrutar*                        |
