# Negative Formal Commands — Conversational Sentences

## Polite Requests Not to Do Something

Everyday negative requests using *usted*.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No se preocupe, yo me encargo.           | Don't worry, I'll take care of it.              | *preocuparse*, *usted*         |
| No hable tan fuerte, por favor.          | Please don't speak so loudly.                    | *hablar*, *usted*                 |
| No se levante todavía, el doctor dice que espere. | Don't get up yet, the doctor says to wait.   | *levantarse*, *usted*               |
| No firme sin leer primero.               | Don't sign without reading first.                  | *firmar*, *usted*                     |

## Instructions in Professional Settings

Common negative commands from a doctor, official, or service worker.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No coma nada antes del examen.           | Don't eat anything before the exam.              | *comer*, *usted*                |
| No tome este medicamento con alcohol.    | Don't take this medication with alcohol.          | *tomar*, *usted*                  |
| No maneje si se siente cansado.          | Don't drive if you feel tired.                     | *manejar*, *usted*                  |
| No traiga más de un acompañante.         | Don't bring more than one companion.                | *traer*, *usted*                      |

## Group Instructions with Ustedes

Common negative commands for a group, formal or informal.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No hablen todos al mismo tiempo, por favor. | Please don't all talk at the same time.       | *hablar*, *ustedes*               |
| No dejen sus cosas aquí.                 | Don't leave your things here.                     | *dejar*, *ustedes*                  |
| No corran por los pasillos.              | Don't run in the hallways.                         | *correr*, *ustedes*                   |
| No usen sus teléfonos durante la clase.  | Don't use your phones during class.                 | *usar*, *ustedes*                       |

## Negative Formal Commands with Irregular Stems

Common negative formal commands from the DISHES irregular set.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No vaya solo a esa zona de noche.        | Don't go to that area alone at night.            | *ir* → *no vaya*, *usted*      |
| No sean tan negativos.                   | Don't be so negative.                             | *ser* → *no sean*, *ustedes*      |
| No estén nerviosos, todo va a salir bien. | Don't be nervous, everything will be fine.        | *estar* → *no estén*, *ustedes*     |
| No dé su contraseña a nadie.             | Don't give your password to anyone.                | *dar* → *no dé*, *usted*              |

## Contrasting Affirmative and Negative Formal Commands

Pairs showing that the verb form stays identical, only "no" changes it.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Hable más despacio.                      | Speak more slowly.                              | affirmative, *usted*           |
| No hable tan rápido.                     | Don't speak so fast.                             | negative, *usted*                 |
| Vengan temprano.                         | Come early.                                       | affirmative, *ustedes*              |
| No vengan tarde.                         | Don't come late.                                  | negative, *ustedes*                   |
