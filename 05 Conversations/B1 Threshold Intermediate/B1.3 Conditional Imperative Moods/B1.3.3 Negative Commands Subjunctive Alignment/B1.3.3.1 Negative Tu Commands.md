# Negative Tú Commands — Conversational Sentences

## Everyday "Don't" Instructions

Common negative commands between friends and family.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No hables tan alto, hay gente durmiendo. | Don't talk so loudly, people are sleeping. | *hablar* → *no hables*        |
| No comas tan rápido, te va a doler el estómago. | Don't eat so fast, your stomach will hurt. | *comer* → *no comas*           |
| No llegues tarde otra vez.               | Don't be late again.                             | *llegar* → *no llegues*          |
| No te preocupes tanto.                   | Don't worry so much.                              | *preocuparse* → *no te preocupes*  |

## Warning Someone Not to Do Something

Everyday warnings using negative commands.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No toques eso, está caliente.            | Don't touch that, it's hot.                     | *tocar* → *no toques*          |
| No abras esa puerta.                     | Don't open that door.                            | *abrir* → *no abras*             |
| No cruces la calle todavía.              | Don't cross the street yet.                       | *cruzar* → *no cruces*             |
| No corras, puedes caerte.                | Don't run, you could fall.                         | *correr* → *no corras*               |

## Advice Phrased as a Negative Command

Everyday advice about what not to do.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No pierdas la paciencia con ellos.       | Don't lose your patience with them.              | *perder* → *no pierdas*         |
| No te rindas ahora, ya casi terminas.    | Don't give up now, you're almost done.            | *rendirse* → *no te rindas*        |
| No te compares con los demás.            | Don't compare yourself to others.                  | *compararse* → *no te compares*      |
| No dejes las cosas para después.         | Don't leave things for later.                       | *dejar* → *no dejes*                   |

## Negative Commands with Irregular Subjunctive Stems

Common negative commands using the DISHES irregulars.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No vayas sin avisarme primero.           | Don't go without letting me know first.          | *ir* → *no vayas*             |
| No seas tan duro contigo mismo.          | Don't be so hard on yourself.                     | *ser* → *no seas*                |
| No estés triste, todo va a mejorar.      | Don't be sad, everything will get better.          | *estar* → *no estés*               |
| No le des tanta importancia.             | Don't give it so much importance.                    | *dar* → *no des*, idiomatic            |

## Negative Commands with the Irregular-Affirmative Verbs

Showing how these verbs use a completely different pattern here.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No digas nada todavía.                   | Don't say anything yet.                          | *decir* → *no digas*, not *no dis*  |
| No hagas eso otra vez.                   | Don't do that again.                              | *hacer* → *no hagas*, not *no haz*    |
| No pongas la mochila ahí.                | Don't put the backpack there.                      | *poner* → *no pongas*, not *no pon*     |
| No vengas si no quieres.                 | Don't come if you don't want to.                    | *venir* → *no vengas*, not *no ven*       |
