# Command Pronoun Attachment Rules — Conversational Sentences

## Attaching Pronouns to Affirmative Tú Commands

Everyday commands with a pronoun attached at the end.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Cómelo mientras está caliente.           | Eat it while it's hot.                          | *comer* + *lo*                 |
| Llámame cuando llegues.                  | Call me when you arrive.                         | *llamar* + *me*                  |
| Ayúdame con esto, por favor.             | Help me with this, please.                        | *ayudar* + *me*, accent added       |
| Espérame, ya casi salgo.                 | Wait for me, I'm almost out the door.               | *esperar* + *me*, accent added        |

## Moving Pronouns Before Negative Tú Commands

Common negative commands with the pronoun placed before the verb.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No lo toques, está mojado.               | Don't touch it, it's wet.                        | *tocar* + *lo*, precedes       |
| No me esperes, llegaré tarde.            | Don't wait for me, I'll arrive late.               | *esperar* + *me*, precedes       |
| No la dejes sola.                        | Don't leave her alone.                             | *dejar* + *la*, precedes           |
| No los pierdas, son importantes.         | Don't lose them, they're important.                 | *perder* + *los*, precedes           |

## Formal Commands with Attached and Preceding Pronouns

Everyday formal commands, both affirmative and negative.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Tráigalo cuando pueda.                   | Bring it whenever you can.                       | affirmative *usted*, attached    |
| No lo traiga hoy, no hay espacio.        | Don't bring it today, there's no room.            | negative *usted*, precedes         |
| Explíquemelo otra vez, por favor.        | Explain it to me again, please.                    | affirmative *usted*, double pronoun  |
| No me lo explique tan rápido.            | Don't explain it to me so fast.                     | negative *usted*, precedes             |

## Double Pronouns: Le/Les Becoming Se

Common everyday phrases using the indirect+direct pronoun combo.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Díselo antes de que se entere por otro lado. | Tell it to him/her before they find out another way. | *decir* + *le* → *se* + *lo*  |
| Dáselo cuando lo veas.                   | Give it to him/her when you see him/her.           | *dar* + *le* → *se* + *lo*        |
| Pídeselo con confianza.                  | Ask him/her for it with confidence.                 | *pedir* + *le* → *se* + *lo*         |
| Cuéntaselo tal como pasó.                | Tell it to him/her just as it happened.              | *contar* + *le* → *se* + *lo*          |

## Attached Accents in Everyday Speech

Common commands showing when a written accent is (or isn't) needed.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Ponlo en la mesa.                        | Put it on the table.                             | one syllable, no accent needed  |
| Dilo en voz alta.                        | Say it out loud.                                  | one syllable, no accent needed    |
| Escríbelo antes de que se te olvide.     | Write it down before you forget.                    | multi-syllable, accent added         |
| Levántate, ya es tarde.                  | Get up, it's already late.                          | reflexive, accent added               |
