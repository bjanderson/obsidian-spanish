# Pero vs. Sino vs. Sino Que — Conversational Sentences

## Everyday Pero After Positive Statements

Common everyday contrasts using the general-purpose "but."

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Me gusta cocinar, pero no tengo mucho tiempo. | I like cooking, but I don't have much time. | *pero*, positive statement     |
| El plan suena bien, pero es caro.        | The plan sounds good, but it's expensive.       | *pero*, positive statement        |
| Quiero ir, pero tengo que trabajar.      | I want to go, but I have to work.                | *pero*, positive statement          |
| Es buena idea, pero necesitamos más tiempo. | It's a good idea, but we need more time.       | *pero*, positive statement            |

## Everyday Sino Replacing a Negated Thing

Common everyday corrections and preferences.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No quiero café, sino té.                 | I don't want coffee, but tea instead.            | *sino*, no new verb             |
| Ese no es mi carro, sino el de mi hermano. | That's not my car, but my brother's.            | *sino*, no new verb               |
| No es difícil, sino diferente.           | It's not difficult, but different.                | *sino*, no new verb                 |
| No trabaja los lunes, sino los martes.   | He/she doesn't work on Mondays, but Tuesdays.      | *sino*, no new verb                   |

## Everyday Sino Que with a New Conjugated Verb

Common everyday corrections where the second half has its own action.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No fuimos al cine, sino que nos quedamos en casa. | We didn't go to the movies, but instead we stayed home. | *sino que*, new verb   |
| No llamó, sino que mandó un mensaje.     | He/she didn't call, but instead sent a message.    | *sino que*, new verb              |
| No lo hice a propósito, sino que fue un accidente. | I didn't do it on purpose, but rather it was an accident. | *sino que*, new verb        |
| No se rindió, sino que siguió intentando. | He/she didn't give up, but instead kept trying.     | *sino que*, new verb                |

## Distinguishing Sino and Sino Que in the Same Conversation

Pairs showing the difference depending on whether a new verb appears.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No quiero pizza, sino pasta.             | I don't want pizza, but pasta instead.           | *sino*, noun, no new verb       |
| No quiero pizza, sino que prefiero pasta. | I don't want pizza, but rather I prefer pasta.  | *sino que*, new verb              |
| No es tímido, sino reservado.            | He's not shy, but reserved.                       | *sino*, adjective, no new verb      |
| No es tímido, sino que le cuesta confiar en la gente. | He's not shy, but rather he finds it hard to trust people. | *sino que*, new verb  |

## Everyday Corrections in Conversation

Realistic back-and-forth using pero, sino, and sino que together.

| Spanish                                              | English                                       | Notes                |
| ----------------------------------------------------------- | ----------------------------------------------------- | ------------------------ |
| No estoy enojado, sino cansado, pero mañana estaré mejor.     | I'm not angry, but tired, but tomorrow I'll be better.  | *sino* + *pero*             |
| No perdimos el partido, sino que empatamos, pero fue un buen juego. | We didn't lose the game, but instead we tied, but it was a good game. | *sino que* + *pero*  |
