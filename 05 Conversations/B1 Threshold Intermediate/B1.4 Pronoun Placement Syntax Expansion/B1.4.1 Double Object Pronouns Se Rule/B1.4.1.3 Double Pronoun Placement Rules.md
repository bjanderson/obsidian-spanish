# Double Pronoun Placement Rules — Conversational Sentences

## Conjugated Verbs in Everyday Speech

Common everyday sentences with the pronoun pair before a conjugated verb.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Se lo di sin pensarlo dos veces.         | I gave it to him without thinking twice.         | conjugated verb                |
| Nos lo explicaron muy bien.              | They explained it to us really well.               | conjugated verb                   |
| Te la mandamos ayer por la tarde.        | We sent it to you yesterday afternoon.              | conjugated verb                     |
| Se los devolví la semana pasada.         | I returned them to him/her last week.                | conjugated verb                       |

## Talking About Future Plans with Infinitives

Everyday plans involving an infinitive, showing both placement options.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Voy a dárselo en cuanto llegue.          | I'm going to give it to him as soon as I arrive.  | attached to infinitive         |
| Se lo voy a dar en cuanto llegue.        | I'm going to give it to him as soon as I arrive.  | before conjugated verb, same meaning |
| Tengo que devolvérselo mañana.           | I have to return it to him/her tomorrow.           | attached to infinitive               |
| Se lo tengo que devolver mañana.         | I have to return it to him/her tomorrow.            | before conjugated verb, same meaning     |

## Describing What You're Doing Right Now

Everyday actions in progress, using the gerund.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Estoy explicándoselo con calma.          | I'm calmly explaining it to him/her.             | gerund, attached                |
| Le estoy mostrando el proyecto ahora mismo. | I'm showing him/her the project right now.      | single pronoun, before verb          |
| Estamos preparándoselo para su cumpleaños. | We're preparing it for him/her for his/her birthday. | gerund, attached, *nosotros*           |
| Se lo estoy contando poco a poco.        | I'm telling it to him/her little by little.        | before conjugated verb, same meaning     |

## Giving Instructions with Commands

Everyday affirmative and negative commands using both pronouns.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Dáselo antes de que se vaya.             | Give it to him/her before he/she leaves.          | affirmative command, attached  |
| No se lo des hasta que termine.          | Don't give it to him/her until he/she finishes.    | negative command, precedes       |
| Explícaselo con paciencia.               | Explain it to him/her patiently.                    | affirmative command, attached      |
| No se lo digas todavía, es una sorpresa. | Don't tell it to him/her yet, it's a surprise.       | negative command, precedes           |

## Everyday Choices Between the Two Placements

Pairs showing both correct options mean exactly the same thing.

| Spanish                                | English                              | Notes                |
| -------------------------------------------- | -------------------------------------------- | ------------------------ |
| Quiero mostrártelo cuanto antes.              | I want to show it to you as soon as possible.  | attached to infinitive       |
| Te lo quiero mostrar cuanto antes.            | I want to show it to you as soon as possible.  | before conjugated verb          |
| Va a explicárnoslo mañana.                    | He/she is going to explain it to us tomorrow.  | attached to infinitive            |
| Nos lo va a explicar mañana.                  | He/she is going to explain it to us tomorrow.  | before conjugated verb              |
