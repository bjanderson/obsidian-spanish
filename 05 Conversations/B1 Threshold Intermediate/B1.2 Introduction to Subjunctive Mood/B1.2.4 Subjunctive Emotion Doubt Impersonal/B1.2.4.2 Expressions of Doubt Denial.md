# Expressions of Doubt/Denial — Conversational Sentences

## Stating Belief with Creo Que (Indicative)

Everyday statements of belief or certainty.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Creo que va a llover hoy.                | I think it's going to rain today.               | *creer que*, indicative        |
| Creo que él tiene razón.                 | I think he's right.                              | *creer que*, indicative        |
| Creemos que es una buena idea.           | We think it's a good idea.                       | *creer que*, *nosotros*          |
| Creo que ya lo sabes.                    | I think you already know it.                     | *creer que*, indicative           |

## Expressing Doubt with No Creo Que and Dudar Que

Common ways to say you're not sure something is true.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| No creo que llegue a tiempo.             | I don't think he'll arrive on time.             | *no creer que*, subjunctive      |
| Dudo que eso sea verdad.                 | I doubt that's true.                             | *dudar que*                        |
| No creo que sea tan difícil.             | I don't think it's that difficult.               | *no creer que*, subjunctive        |
| Dudamos que tengan razón.                | We doubt they're right.                           | *dudar que*, *nosotros*              |

## Using Parecer to Guess or Doubt

Common everyday phrases for how something appears to be.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Parece que va a nevar.                   | It looks like it's going to snow.               | *parecer que*, indicative       |
| No parece que le importe mucho.          | It doesn't seem like he/she cares much.          | *no parecer que*, subjunctive     |
| Parece que están de acuerdo.             | It seems like they agree.                        | *parecer que*, indicative         |
| No parece que vaya a cambiar de opinión. | It doesn't seem like he/she's going to change his/her mind. | *no parecer que*, subjunctive |

## Denying Something with Negar Que

Everyday denials.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Niego que haya sido mi culpa.            | I deny that it was my fault.                    | *negar que*                  |
| Niega que lo sepa.                       | He/she denies knowing it.                        | *negar que*, third person        |
| Nunca negamos que hayamos cometido un error. | We never deny that we've made a mistake.       | *negar que*, *nosotros*             |
| Niegan que el problema exista.           | They deny that the problem exists.               | *negar que*, plural                  |

## Certainty vs. Doubt in the Same Conversation

Pairs showing the flip between indicative and subjunctive depending on certainty.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Creo que ella viene mañana.              | I think she's coming tomorrow.                   | certainty → indicative         |
| No creo que ella venga mañana.           | I don't think she's coming tomorrow.              | doubt → subjunctive               |
| Parece que el plan va a funcionar.       | It looks like the plan is going to work.           | certainty → indicative               |
| No parece que el plan vaya a funcionar.  | It doesn't seem like the plan is going to work.    | doubt → subjunctive                    |
