# Present Subjunctive Stems — Conversational Sentences

## Using -Go Verbs in the Subjunctive

Everyday sentences where the *-go* irregularity carries into the subjunctive.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Quiero que tengas más paciencia.         | I want you to have more patience.             | *tener* → *tengo* → *teng-*  |
| Espero que hagas la tarea hoy.           | I hope you do your homework today.             | *hacer* → *hago* → *hag-*    |
| Prefiero que salgas temprano.            | I'd rather you leave early.                    | *salir* → *salgo* → *salg-*  |
| Quiero que pongas la mesa.               | I want you to set the table.                    | *poner* → *pongo* → *pong-*  |

## Using Stem-Changing Verbs in the Subjunctive

Everyday sentences with *e→ie*, *o→ue*, and *e→i* verbs.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Espero que pienses en una solución.      | I hope you think of a solution.                | *pensar* → *pienso* → *piens-* |
| Quiero que puedas venir a la boda.       | I want you to be able to come to the wedding.   | *poder* → *puedo* → *pued-*   |
| Dudo que pidan más tiempo.               | I doubt they'll ask for more time.               | *pedir* → *pido* → *pid-*     |
| Espero que duermas bien esta noche.      | I hope you sleep well tonight.                   | *dormir* → *duermo* → *duerm-* |

## Using Spelling-Change Verbs

Everyday examples with -car, -gar, -zar verbs whose spelling shifts.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Espero que busques trabajo pronto.       | I hope you look for a job soon.               | *buscar* → *busque*         |
| Quiero que pagues la cuenta a tiempo.    | I want you to pay the bill on time.             | *pagar* → *pague*           |
| Dudo que empieces temprano.              | I doubt you'll start early.                      | *empezar* → *empiece*        |
| Espero que llegues antes de que empiece.  | I hope you arrive before it starts.              | *llegar* → *llegue*, *empezar* → *empiece* |

## Reminding Yourself How to Build the Stem

Casual, self-talk style sentences reinforcing the yo-form trick.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| A ver... yo conozco, entonces es conozca. | Let's see... I know (conocer), so it's "conozca." | thinking-aloud pattern |
| Yo tengo, entonces el subjuntivo es tenga. | I have (tengo), so the subjunctive is "tenga." | self-correction pattern |
| Como digo "yo hago," el subjuntivo es haga. | Since I say "yo hago," the subjunctive is "haga." | self-correction pattern |
| Si la forma yo es pongo, el subjuntivo es ponga. | If the yo form is "pongo," the subjunctive is "ponga." | self-correction pattern |

## Talking About What You Hope Others Will Do

Everyday sentences that put the stem-derivation rule into practical use.

| Spanish                              | English                            | Notes                |
| ---------------------------------------- | ---------------------------------------- | ------------------------ |
| Espero que conozcas a mi familia pronto. | I hope you meet my family soon.                | *conocer* → *conozco* → *conozc-* |
| Quiero que vengas a mi graduación.       | I want you to come to my graduation.             | *venir* → *vengo* → *veng-*   |
| Ojalá que oigas buenas noticias.         | I hope you hear good news.                       | *oír* → *oigo* → *oig-*        |
| Prefiero que traigas el paraguas.        | I'd rather you bring the umbrella.                | *traer* → *traigo* → *traig-*  |
