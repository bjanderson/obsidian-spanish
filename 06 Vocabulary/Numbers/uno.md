# uno

## Meaning

*Uno* is the number "one." On its own — counting, or standing in for a noun already
mentioned — it keeps its full form: *Tengo uno* ("I have one"). Right before a
masculine singular noun, it shortens (apocopates) to [[un-una|un]], the same way
*bueno* shortens to *buen*: *un libro* ("one/a book"), not *uno libro*. Before a
feminine singular noun it becomes [[un-una|una]] instead: *una casa* ("one/a
house").

*Uno* is also used impersonally, like English "one" or "you" in general statements:
*Uno nunca sabe* ("One never knows"/"You never know").

## Full Paradigm

| Gender / Number   | Form  |
| -------------------- | ------- |
| Standalone / before a feminine noun | uno (standalone) / una (before a noun) |
| Before a masculine noun               | un      |

## Examples

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Solo me queda uno.                          | I only have one left.                    | standalone                         |
| Necesito un boleto para el tren.            | I need one ticket for the train.         | apocopated, before masc. noun      |
| Quiero una manzana, por favor.              | I want one apple, please.                | feminine form, before fem. noun     |
| Uno nunca sabe qué va a pasar.              | You never know what's going to happen.   | impersonal use                     |
| ¿Cuántos hermanos tienes? — Tengo uno.       | How many siblings do you have? — I have one. | standalone, question and answer |
