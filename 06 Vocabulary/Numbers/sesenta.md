# sesenta

## Meaning

*Sesenta* is the number "sixty." It's invariable.

## Examples

| Spanish                                | English                                  | Notes                        |
| ------------------------------------------ | --------------------------------------------- | --------------------------------- |
| Una hora tiene sesenta minutos.             | An hour has sixty minutes.                      | quantity                           |
| Mi abuela tiene sesenta años.               | My grandmother is sixty years old.              | age expression                     |
| El límite de velocidad es sesenta kilómetros por hora. | The speed limit is sixty kilometers per hour. | quantity              |
| Compramos sesenta entradas para el equipo.  | We bought sixty tickets for the team.           | quantity                           |
| Ahorró sesenta dólares esta semana.         | She saved sixty dollars this week.              | quantity                           |
