# salvo

## Meaning

*Salvo* means "except" or "except for" — it introduces an exception to a general
statement. Followed by *que* + subjunctive, it means "except that"/"unless." Near-synonym
[[excepto]], essentially interchangeable, though *salvo* is slightly more common in
writing/formal registers.

## Examples

| Spanish                                           | English                                       | Notes                        |
| ---------------------------------------------------- | ------------------------------------------------ | ----------------------------- |
| Todos vinieron a la fiesta, salvo Marcos.             | Everyone came to the party, except Marcos.        | basic exception               |
| Trabajamos todos los días, salvo los domingos.        | We work every day, except Sundays.                | exception, time expression    |
| Iré a la reunión, salvo que llueva mucho.             | I'll go to the meeting, unless it rains a lot.    | *salvo que* + subjunctive     |
| No hay nada que hacer, salvo esperar.                 | There's nothing to do except wait.                | *salvo* + infinitive          |
| Salvo error u omisión, el total es correcto.          | Except for any error or omission, the total is correct. | fixed/formal expression |
