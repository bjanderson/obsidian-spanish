# excepto

## Meaning

*Excepto* means "except" or "except for," introducing an exception to a general
statement — essentially interchangeable with [[salvo]]. Followed by *que* + subjunctive
it can also mean "except that"/"unless," though this pattern is less common than with
*salvo*.

## Examples

| Spanish                                          | English                                     | Notes                        |
| ---------------------------------------------------- | ------------------------------------------------ | ----------------------------- |
| Todos los estudiantes aprobaron, excepto uno.         | All the students passed, except one.              | basic exception               |
| La tienda abre todos los días excepto los lunes.      | The store is open every day except Mondays.       | exception, time expression    |
| No como mariscos, excepto camarones.                  | I don't eat seafood, except shrimp.               | exception, food                |
| Excepto por el clima, el viaje fue perfecto.          | Except for the weather, the trip was perfect.     | *excepto por*                 |
| Iremos todos, excepto que surja algún problema.       | We'll all go, unless some problem comes up.       | *excepto que* + subjunctive   |

## Related Vocabulary

- [[salvo]] — an essentially interchangeable near-synonym for "except."
