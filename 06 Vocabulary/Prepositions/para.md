# para

## Meaning

*Para* is invariant and points forward — to a purpose, a recipient, a deadline, or a
destination. Learners often confuse it with [[por]] — the short version: *para*
looks forward to a purpose or destination, *por* looks back at a cause or reason
(see B1.4.2.1 for the full contrast).

## Core Uses

| Use                    | Pattern                    | Example                            | English                          |
| -------------------------- | ------------------------------ | --------------------------------------- | ------------------------------------- |
| Purpose (in order to)          | para + [infinitive]              | Estudio para aprender.                   | I study in order to learn.              |
| Recipient                        | para + [person]                    | Este regalo es para ti.                  | This gift is for you.                    |
| Deadline                           | para + [time]                       | Necesito el informe para el lunes.       | I need the report by Monday.             |
| Destination                          | ir + para + [place]                   | Salimos para Cochabamba.                 | We're leaving for Cochabamba.            |
| Opinion/standard                      | para + [person], [statement]           | Para mí, es la mejor opción.             | For me, it's the best option.            |

## Examples

| Spanish                                        | English                                | Notes                        |
| ------------------------------------------------- | -------------------------------------------- | --------------------------------- |
| Trabajo para vivir, no vivo para trabajar.          | I work to live, I don't live to work.        | purpose                            |

| La tarea es para mañana.                              | The homework is due tomorrow.                | deadline                            |

| Para ser tan joven, sabe mucho.                          | For being so young, he knows a lot.          | comparison against a standard       |
