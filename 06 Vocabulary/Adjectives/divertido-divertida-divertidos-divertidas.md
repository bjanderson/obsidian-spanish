# divertido / divertida / divertidos / divertidas

## Meaning

*Divertido* means "fun" or "entertaining" — describes something enjoyable
(*ser divertido*) or, with *estar*, feeling amused in the moment. Agrees in
gender and number: *divertido*, *divertida*, *divertidos*, *divertidas*.

## Full Paradigm

| Gender / Number    | Form       |
| ------------------- | ---------- |
| Masculine singular   | divertido  |
| Feminine singular    | divertida  |
| Masculine plural     | divertidos |
| Feminine plural      | divertidas |

## Examples

| Spanish                                | English                             | Notes                      |
| ----------------------------------------- | -------------------------------------- | ------------------------------ |
| El juego es muy divertido.                  | The game is very fun.                   | masculine singular, ser          |
| La fiesta estuvo divertida anoche.          | The party was fun last night.           | feminine singular, estar (preterite) |
| Los cursos de baile son divertidos.         | The dance classes are fun.              | masculine plural                  |
| Las bromas de mi hermana son divertidas.    | My sister's jokes are fun.              | feminine plural                    |
| ¿No fue divertido el viaje?                | Wasn't the trip fun?                    | question, negation                 |
