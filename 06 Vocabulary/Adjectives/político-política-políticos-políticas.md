# político / política / políticos / políticas

## Meaning

*Político* means "political." It agrees in gender and number: *político*,
*política*, *políticos*, *políticas*. As a noun, *el político* / *la
política* can mean "the politician," while *la política* alone also means
"politics" or "policy."

## Full Paradigm

| Gender / Number     | Form       |
| --------------------- | ---------- |
| Masculine singular      | político   |
| Feminine singular       | política   |
| Masculine plural        | políticos  |
| Feminine plural         | políticas  |
