# varios / varias

## Meaning

*Varios* and *varias* mean "several" or "various." They agree in gender —
*varios* masculine, *varias* feminine — and, as this determiner, only appear
in the plural: *varios libros* ("several books"), *varias opciones* ("several
options").

## Full Paradigm

| Gender    | Form   |
| --------- | ------ |
| Masculine | varios |
| Feminine  | varias |

## Examples

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Compré varios libros nuevos.                | I bought several new books.              | masculine                          |
| Hay varias opciones disponibles.            | There are several options available.     | feminine                           |
| Lo intenté varias veces.                    | I tried it several times.                | feminine, common phrase             |
| Varios estudiantes llegaron tarde.          | Several students arrived late.           | masculine, subject position         |
| No encontré varias de las piezas.           | I couldn't find several of the pieces.   | feminine, negation                  |
