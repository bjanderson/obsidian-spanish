# popular

## Meaning

*Popular* means "popular" — well-liked or widely used. It has the same form
for masculine and feminine, changing only for number: *popular*, *populares*.

## Full Paradigm

| Number     | Form      |
| ----------- | --------- |
| Singular     | popular   |
| Plural       | populares |

## Examples

| Spanish                                             | English                                      | Notes           |
| ------------------------------------------------------ | ------------------------------------------------ | ------------------ |

| ¿Es popular el nuevo profesor?                          | Is the new teacher popular?                        | question            |
