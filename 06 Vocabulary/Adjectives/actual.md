# actual

## Meaning

*Actual* means "current" or "present-day" — not "actual" in the English
sense of "real." Watch for this false friend. It has the same form for
masculine and feminine — it only changes for number: *actual*, *actuales*.

## Full Paradigm

| Number     | Form      |
| ----------- | --------- |
| Singular     | actual    |
| Plural       | actuales  |

## Examples

| Spanish                              | English                                  | Notes                       |
| --------------------------------------------- | ------------------------------------------------- | --------------------------------- |
| El presidente actual cumple dos años en el cargo. | The current president has been in office two years. | masculine singular          |
| Los precios actuales subieron.                   | Current prices went up.                            | masculine plural              |
| ¿Cuál es tu dirección actual?                    | What is your current address?                      | feminine singular, question   |
| No refleja la moda actual.                       | It doesn't reflect current fashion.                | negation                     |
| Analizaron las tendencias actuales del mercado.  | They analyzed current market trends.               | feminine plural                |
