# libre

## Meaning

*Libre* means "free" — unrestricted or available, not tied down.
It has the same form for masculine and feminine — it only changes for
number: *libre*, *libres*.

## Full Paradigm

| Number     | Form     |
| ----------- | -------- |
| Singular     | libre    |
| Plural       | libres   |

## Examples

| Spanish                              | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| El asiento está libre.                           | The seat is free.                             | singular                          |
| Los animales viven libres en la selva.           | The animals live free in the jungle.          | plural                            |
| ¿Está libre esta mesa?                           | Is this table free?                           | question                          |
| No me siento libre para decidir.                 | I don't feel free to decide.                  | negation                          |
| Buscamos tiempo libre para descansar.            | We look for free time to rest.                | singular, collocation "tiempo libre" |

## Related Vocabulary

- [[tiempo]] — often paired with *libre* in the phrase *tiempo libre*, "free time."
