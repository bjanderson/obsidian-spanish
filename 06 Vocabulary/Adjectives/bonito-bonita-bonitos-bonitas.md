# bonito / bonita / bonitos / bonitas

## Meaning

*Bonito* means "pretty" or "nice-looking." It agrees in gender and number: *bonito*,
*bonita*, *bonitos*, *bonitas*.

## Full Paradigm

| Gender / Number    | Form     |
| ------------------- | -------- |
| Masculine singular   | bonito   |
| Feminine singular    | bonita   |
| Masculine plural     | bonitos  |
| Feminine plural      | bonitas  |

## Examples

| Spanish                                | English                             | Notes                     |
| --------------------------------------------- | -------------------------------------------- | -------------------------------- |
| Ese vestido es muy bonito.                       | That dress is very pretty.                    | masculine singular                 |
| La casa está muy bonita hoy.                     | The house looks very pretty today.            | feminine singular                  |
| ¿No son bonitos estos globos?                    | Aren't these balloons pretty?                 | masculine plural, question          |
| Compró unas flores bonitas para la fiesta.       | She bought some pretty flowers for the party. | feminine plural                    |
| No encontró nada bonito en la tienda.            | She didn't find anything pretty at the store. | negation, masculine singular         |
