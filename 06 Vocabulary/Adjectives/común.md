# común

## Meaning

*Común* means "common" — shared by many, or ordinary/frequent. It has the
same form for masculine and feminine, and only changes for number. Note the
accent drops in the plural: *común* → *comunes*.

## Full Paradigm

| Number     | Form     |
| ----------- | -------- |
| Singular     | común    |
| Plural       | comunes  |

## Examples

| Spanish                                              | English                                          | Notes                    |
| ----------------------------------------------------- | ---------------------------------------------------- | --------------------------- |
| Este apellido es muy común en la región.               | This last name is very common in the region.          | singular                    |
| Tenemos un objetivo común.                             | We have a common goal.                                 | singular                    |
| ¿Es común que llueva tanto aquí?                       | Is it common for it to rain this much here?            | question                    |
| Esos errores no son tan comunes como parece.           | Those mistakes aren't as common as it seems.           | plural, negation            |
| Comparten varios intereses comunes.                    | They share several common interests.                   | plural                      |
