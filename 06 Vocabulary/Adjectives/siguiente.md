# siguiente

## Meaning

*Siguiente* means "next" or "following." It has the same form for
masculine and feminine — it only changes for number: *siguiente*,
*siguientes*.

## Full Paradigm

| Number     | Form          |
| ----------- | ------------- |
| Singular     | siguiente     |
| Plural       | siguientes    |

## Examples

| Spanish                                | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| Nos vemos la semana siguiente.                   | We'll see each other the following week.      | feminine singular                  |
| ¿Cuál es el paso siguiente?                      | What's the next step?                         | question                          |
| No hay clase el día siguiente.                   | There's no class the next day.                | negation                          |
| Los siguientes participantes deben esperar aquí. | The next participants must wait here.         | masculine plural                   |
| Revisamos las páginas siguientes del libro.      | We reviewed the following pages of the book.  | feminine plural                    |

## Related Vocabulary

- [[último]] — the last item in a sequence, contrasting with *siguiente*.
