# azul

## Meaning

*Azul* means "blue." It has the same form for masculine and feminine — it
only changes for number: *azul*, *azules*.

## Full Paradigm

| Number     | Form    |
| ----------- | ------- |
| Singular     | azul    |
| Plural       | azules  |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El cielo es azul.                                | The sky is blue.                           | masculine singular                 |
| Tiene los ojos azules.                           | He has blue eyes.                          | masculine plural                   |
| ¿Te gusta el color azul?                         | Do you like the color blue?                | question                          |
