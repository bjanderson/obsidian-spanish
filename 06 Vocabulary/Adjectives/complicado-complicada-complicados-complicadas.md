# complicado / complicada / complicados / complicadas

## Meaning

*Complicado* means "complicated" or "difficult to deal with." It started as
the past participle of *complicar* ("to complicate") and is now used
freely as a regular adjective. It also appears in the idiom *estar
complicado* ("to be in a tough spot"). It agrees in gender and number:
*complicado*, *complicada*, *complicados*, *complicadas*.

## Full Paradigm

| Gender / Number    | Form         |
| ------------------- | ------------ |
| Masculine singular   | complicado   |
| Feminine singular    | complicada   |
| Masculine plural     | complicados  |
| Feminine plural      | complicadas  |
