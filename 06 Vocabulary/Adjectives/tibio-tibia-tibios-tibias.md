# tibio / tibia / tibios / tibias

## Meaning

*Tibio* means "lukewarm" — between hot and cold. It agrees in gender and
number: *tibio*, *tibia*, *tibios*, *tibias*.

## Full Paradigm

| Gender / Number    | Form   |
| ------------------- | ------ |
| Masculine singular   | tibio  |
| Feminine singular    | tibia  |
| Masculine plural     | tibios |
| Feminine plural      | tibias |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El café está tibio.                              | The coffee is lukewarm.                    | masculine singular                 |
| El agua estaba tibia.                            | The water was lukewarm.                    | feminine singular                  |
| ¿Prefieres el té tibio?                          | Do you prefer the tea lukewarm?            | masculine singular, question       |
| No sirvieron platos tibios.                      | They didn't serve lukewarm dishes.         | masculine plural, negation         |
| Las tardes tibias de primavera invitan a caminar. | Mild spring afternoons invite you to walk. | feminine plural                    |
