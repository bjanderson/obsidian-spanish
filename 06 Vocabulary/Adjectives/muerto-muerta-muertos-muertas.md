# muerto / muerta / muertos / muertas

## Meaning

*Muerto* means "dead," used with *estar* for the state of being dead. It's
also the irregular past participle of *morir* ("to die"), so it appears
in perfect tenses: *ha muerto* ("has died"). It agrees in gender and
number: *muerto*, *muerta*, *muertos*, *muertas*.

## Full Paradigm

| Gender / Number    | Form     |
| ------------------- | -------- |
| Masculine singular   | muerto   |
| Feminine singular    | muerta   |
| Masculine plural     | muertos  |
| Feminine plural      | muertas  |
