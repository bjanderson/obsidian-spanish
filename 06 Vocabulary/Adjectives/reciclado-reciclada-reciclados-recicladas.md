# reciclado / reciclada / reciclados / recicladas

## Meaning

*Reciclado* means "recycled." It's the past participle of the verb
*reciclar* ("to recycle") used as an adjective, so it agrees in gender and
number with the noun it describes: *reciclado*, *reciclada*, *reciclados*,
*recicladas*.

## Full Paradigm

| Gender / Number    | Form        |
| ------------------- | ----------- |
| Masculine singular   | reciclado   |
| Feminine singular    | reciclada   |
| Masculine plural     | reciclados  |
| Feminine plural      | recicladas  |
