# primero / primera / primeros / primeras

## Meaning

*Primero* means "first." It agrees in gender and number: *primero*,
*primera*, *primeros*, *primeras*. Before a masculine singular noun, it
shortens to *primer* (*el primer día*, "the first day").

## Full Paradigm

| Gender / Number     | Form      |
| --------------------- | --------- |
| Masculine singular      | primero   |
| Feminine singular       | primera   |
| Masculine plural        | primeros  |
| Feminine plural         | primeras  |

## Examples

| Spanish                                | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| Fue mi primer trabajo.                           | It was my first job.                          | masculine singular, apocope (before noun) |
| ¿Es esta tu primera vez aquí?                    | Is this your first time here?                 | feminine singular, question         |
| No fueron los primeros en llegar.                | They weren't the first to arrive.             | masculine plural, negation          |
| Las primeras semanas fueron difíciles.           | The first weeks were difficult.               | feminine plural                     |
| Ganó el primero de los tres partidos.            | He won the first of the three matches.        | masculine singular, after "el"      |
