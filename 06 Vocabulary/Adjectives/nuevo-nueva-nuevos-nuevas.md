# nuevo / nueva / nuevos / nuevas

## Meaning

*Nuevo* means "new." It agrees in gender and number with the noun it
describes: *nuevo*, *nueva*, *nuevos*, *nuevas*. Placed before a noun it
often means "another/different" (*un nuevo problema*, "a different
problem"); after the noun, it means "brand-new" (*un carro nuevo*, "a
brand-new car").

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | nuevo   |
| Feminine singular    | nueva   |
| Masculine plural     | nuevos  |
| Feminine plural      | nuevas  |

| Spanish                                    | English                                | Notes                       |

| ¿Ya viste su nuevo carro?                             | Have you seen his new car yet?                   | masculine singular, before noun     |
| No me gustan los zapatos nuevos.                      | I don't like the new shoes.                      | masculine plural, negation          |

| Surgió un nuevo problema con el proyecto.             | A new (different) problem came up with the project. | masculine singular, before noun  |
