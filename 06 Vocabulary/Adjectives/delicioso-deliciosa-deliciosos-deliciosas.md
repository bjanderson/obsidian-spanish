# delicioso / deliciosa / deliciosos / deliciosas

## Meaning

*Delicioso* means "delicious" — describing food or drink that tastes
excellent. It agrees in gender and number: *delicioso*, *deliciosa*,
*deliciosos*, *deliciosas*.

## Full Paradigm

| Gender / Number    | Form       |
| ------------------- | ---------- |
| Masculine singular   | delicioso  |
| Feminine singular    | deliciosa  |
| Masculine plural     | deliciosos |
| Feminine plural      | deliciosas |

## Examples

| Spanish                                          | English                                    | Notes                       |
| ------------------------------------------------- | -------------------------------------------- | ---------------------------------- |
| El postre está delicioso.                          | The dessert is delicious.                    | masculine singular                 |
| La sopa de la abuela está deliciosa.               | Grandma's soup is delicious.                 | feminine singular                  |
| ¿Está delicioso el plato del chef?                 | Is the chef's dish delicious?                | masculine singular, question, *del* |
| Los tacos no estuvieron tan deliciosos como esperaba. | The tacos weren't as delicious as I expected. | masculine plural, negation         |
| Preparó unas galletas deliciosas para la fiesta.   | She made some delicious cookies for the party. | feminine plural                    |
