# claro / clara / claros / claras

## Meaning

*Claro* means "clear" — an idea, explanation, or sky that isn't confusing or
cloudy. With colors it means "light-colored" (*azul claro*, "light blue").
It agrees in gender and number: *claro*, *clara*, *claros*, *claras*.

## Full Paradigm

| Gender / Number    | Form   |
| ------------------- | ------ |
| Masculine singular   | claro  |
| Feminine singular    | clara  |
| Masculine plural     | claros |
| Feminine plural      | claras |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El cielo está claro hoy.                         | The sky is clear today.                    | masculine singular                 |
| La explicación fue clara.                        | The explanation was clear.                 | feminine singular                  |
| ¿Te quedaron claras las instrucciones?           | Were the instructions clear to you?        | feminine plural, question          |

| Me gustan los colores claros.                    | I like light colors.                       | masculine plural                   |
