# seco / seca / secos / secas

## Meaning

*Seco* means "dry" — free of moisture. It agrees in gender and number:
*seco*, *seca*, *secos*, *secas*.

## Full Paradigm

| Gender / Number    | Form  |
| ------------------- | ----- |
| Masculine singular   | seco  |
| Feminine singular    | seca  |
| Masculine plural     | secos |
| Feminine plural      | secas |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El clima es seco.                                | The climate is dry.                        | masculine singular                 |
| La ropa ya está seca.                            | The clothes are already dry.               | feminine singular                  |
| ¿Está seco el pasto?                             | Is the grass dry?                          | masculine singular, question       |
| No fue un verano seco.                           | It wasn't a dry summer.                    | masculine singular, negation       |
| Guardamos las hojas secas.                       | We saved the dry leaves.                   | feminine plural                    |
