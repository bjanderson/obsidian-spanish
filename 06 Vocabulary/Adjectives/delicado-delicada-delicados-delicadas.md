# delicado / delicada / delicados / delicadas

## Meaning

*Delicado* means "delicate, fragile" — physically fragile, or figuratively
sensitive/tricky (*un tema delicado*, "a delicate topic"). It agrees in
gender and number: *delicado*, *delicada*, *delicados*, *delicadas*.

## Full Paradigm

| Gender / Number    | Form        |
| ------------------- | ----------- |
| Masculine singular   | delicado    |
| Feminine singular    | delicada    |
| Masculine plural     | delicados   |
| Feminine plural      | delicadas   |

## Examples

| Spanish                                | English                             | Notes                     |
| ------------------------------------------ | -------------------------------------- | -------------------------- |
| El jarrón es muy delicado.                 | The vase is very delicate.             | masculine singular           |
| Es una situación delicada.                 | It's a delicate situation.             | feminine singular             |
| Los cristales son delicados.               | The glasses are delicate.              | masculine plural               |
| Sus manos son delicadas.                   | Her hands are delicate.                | feminine plural                 |
| No es tan delicado como parece.            | It isn't as delicate as it seems.      | negation                        |
