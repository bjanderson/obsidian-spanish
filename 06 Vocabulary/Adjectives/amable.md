# amable

## Meaning

*Amable* means "kind, nice, considerate" — describing someone friendly and courteous.
It has the same form for masculine and feminine — it only changes for number:
*amable*, *amables*. Commonly paired with *ser* + *con* (kind *to/with* someone):
*ser amable con alguien*.

## Full Paradigm

| Number     | Form     |
| ----------- | -------- |
| Singular     | amable   |
| Plural       | amables  |
