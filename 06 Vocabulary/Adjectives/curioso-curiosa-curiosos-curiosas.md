# curioso / curiosa / curiosos / curiosas

## Meaning

*Curioso* means "curious" — either inquisitive (a personality trait, *ser
curioso*) or "strange/odd" (*es curioso que...*, "it's curious that..."). Agrees
in gender and number: *curioso*, *curiosa*, *curiosos*, *curiosas*.

## Full Paradigm

| Gender / Number    | Form     |
| ------------------- | -------- |
| Masculine singular   | curioso  |
| Feminine singular    | curiosa  |
| Masculine plural     | curiosos |
| Feminine plural      | curiosas |

## Examples

| Spanish                                    | English                                | Notes                |
| -------------------------------------------- | ----------------------------------------- | ------------------------ |
| El niño es muy curioso.                        | The boy is very curious.                   | masculine singular         |
| Es curiosa esa coincidencia.                   | That coincidence is curious.               | feminine singular           |
| Son curiosos los hábitos de esta especie.       | This species' habits are curious.          | masculine plural             |
| Sus preguntas son curiosas pero inteligentes.   | Her questions are curious but smart.       | feminine plural               |
| ¿No eres curioso?                              | Aren't you curious?                        | question, negation            |
