# caliente

## Meaning

*Caliente* means "hot" — for temperature of things, not weather (use
*hace calor* for hot weather). It has the same form for masculine and
feminine — it only changes for number: *caliente*, *calientes*.

## Full Paradigm

| Number     | Form       |
| ----------- | ---------- |
| Singular     | caliente   |
| Plural       | calientes  |

## Examples

| Spanish                              | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| El café está caliente.                           | The coffee is hot.                            | singular                          |
| Las bebidas calientes ayudan con el frío.        | Hot drinks help with the cold.                | plural                            |
| ¿Está caliente el agua?                          | Is the water hot?                             | question                          |
| No sirvieron la sopa caliente.                   | They didn't serve the soup hot.               | negation                          |
| Sintió el aire caliente del desierto.            | She felt the hot desert air.                  | singular, del contraction         |
