# tranquilo / tranquila / tranquilos / tranquilas

## Meaning

*Tranquilo* means "calm" or "quiet" — a personality trait (*ser tranquilo*) or
a momentary state (*estar tranquilo*). Also common as a stand-alone command:
*¡Tranquilo!* ("Relax!/Take it easy!"). Agrees in gender and number:
*tranquilo*, *tranquila*, *tranquilos*, *tranquilas*.

## Full Paradigm

| Gender / Number    | Form        |
| ------------------- | ----------- |
| Masculine singular   | tranquilo   |
| Feminine singular    | tranquila   |
| Masculine plural     | tranquilos  |
| Feminine plural      | tranquilas  |

## Examples

| Spanish                                  | English                                 | Notes             |
| --------------------------------------------- | -------------------------------------------- | ---------------------- |
| Este barrio es muy tranquilo.                   | This neighborhood is very calm.                | masculine singular        |
| Ya está tranquila después del susto.            | She's calm now after the scare.                | feminine singular, "del susto" |
| Los perros se quedaron tranquilos.              | The dogs stayed calm.                          | masculine plural             |
| Las aguas del lago están tranquilas.            | The lake's waters are calm.                    | feminine plural, "del lago"    |
| ¡Tranquilo, no pasa nada!                       | Relax, it's nothing!                           | imperative/idiom               |
