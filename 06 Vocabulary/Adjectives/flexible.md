# flexible

## Meaning

*Flexible* means "flexible" — physically bendable, or figuratively
adaptable (*un horario flexible*, "a flexible schedule"). It has the same
form for masculine and feminine — it only changes for number: *flexible*,
*flexibles*.

## Full Paradigm

| Number     | Form        |
| ----------- | ----------- |
| Singular     | flexible    |
| Plural       | flexibles   |

## Examples

| Spanish                                    | English                                | Notes                     |
