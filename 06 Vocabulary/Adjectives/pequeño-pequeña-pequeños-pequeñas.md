# pequeño / pequeña / pequeños / pequeñas

## Meaning

*Pequeño* means "small." It agrees in gender and number: *pequeño*,
*pequeña*, *pequeños*, *pequeñas*. It can also refer to a young child when
used as a noun (*el pequeño*, "the little one").

## Full Paradigm

| Gender / Number     | Form       |
| --------------------- | ---------- |
| Masculine singular      | pequeño    |
| Feminine singular       | pequeña    |
| Masculine plural        | pequeños   |
| Feminine plural         | pequeñas   |
