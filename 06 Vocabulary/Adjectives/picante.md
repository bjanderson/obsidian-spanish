# picante

## Meaning

*Picante* means "spicy" — describing chili heat, not temperature (use
*caliente* for that meaning). It has the same form for masculine and
feminine — it only changes for number: *picante*, *picantes*.

## Full Paradigm

| Number     | Form       |
| ----------- | ---------- |
| Singular     | picante    |
| Plural       | picantes   |

## Examples

| Spanish                                     | English                              | Notes                       |
| ---------------------------------------------- | -------------------------------------- | --------------------------------- |
| La salsa está picante.                          | The sauce is spicy.                    | singular                          |
| ¿Es picante este plato?                         | Is this dish spicy?                    | question                          |
| La comida no estaba tan picante como pensé.     | The food wasn't as spicy as I thought. | negation                          |
| Los tacos picantes son mis favoritos.           | Spicy tacos are my favorite.           | plural                            |
| Prefiero las salsas picantes a las suaves.      | I prefer spicy sauces to mild ones.    | plural                            |

## Related Vocabulary

- [[caliente]] — a common point of confusion for learners: *picante* describes chili heat/spiciness, while *caliente* describes literal temperature.
