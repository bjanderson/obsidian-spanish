# extraño / extraña / extraños / extrañas

## Meaning

*Extraño* means "strange" or "unfamiliar" — something that feels out of
place or hard to explain. As a noun it can also mean "stranger," but this
file covers the adjective use. It agrees in gender and number: *extraño*,
*extraña*, *extraños*, *extrañas*.

## Full Paradigm

| Gender / Number     | Form     |
| -------------------- | -------- |
| Masculine singular    | extraño  |
| Feminine singular     | extraña  |
| Masculine plural      | extraños |
| Feminine plural       | extrañas |
