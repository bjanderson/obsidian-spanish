# peligroso / peligrosa / peligrosos / peligrosas

## Meaning

*Peligroso* means "dangerous." It agrees in gender and number:
*peligroso*, *peligrosa*, *peligrosos*, *peligrosas*.

## Full Paradigm

| Gender / Number    | Form         |
| ------------------- | ------------ |
| Masculine singular   | peligroso    |
| Feminine singular    | peligrosa    |
| Masculine plural     | peligrosos   |
| Feminine plural      | peligrosas   |

## Examples

| Spanish                                    | English                                 | Notes                     |
| ---------------------------------------------- | -------------------------------------------- | -------------------------- |
| Ese barrio es peligroso de noche.              | That neighborhood is dangerous at night.      | masculine singular            |
| La carretera está peligrosa por el hielo.      | The road is dangerous because of the ice.     | feminine singular              |
| Son animales peligrosos.                       | They're dangerous animals.                    | masculine plural                 |
| Las curvas son peligrosas aquí.                | The curves are dangerous here.                | feminine plural                   |
| ¿Es peligroso nadar aquí?                      | Is it dangerous to swim here?                 | question                          |
