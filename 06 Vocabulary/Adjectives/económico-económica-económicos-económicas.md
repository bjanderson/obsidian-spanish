# económico / económica / económicos / económicas

## Meaning

*Económico* means "economic," and can also mean "affordable/inexpensive."
It agrees in gender and number: *económico*, *económica*, *económicos*,
*económicas*.

## Full Paradigm

| Gender / Number      | Form        |
| ---------------------- | ----------- |
| Masculine singular       | económico   |
| Feminine singular        | económica   |
| Masculine plural         | económicos  |
| Feminine plural          | económicas  |

## Examples

| Spanish                                     | English                                 | Notes                       |
| ------------------------------------------------ | ------------------------------------------------ | --------------------------------- |
| El país atraviesa una crisis económica.            | The country is going through an economic crisis.  | feminine singular                  |
| ¿Es económico este hotel?                          | Is this hotel affordable?                          | question, "affordable" sense        |
| No fue una decisión económica.                     | It wasn't an economical decision.                  | negation                          |

| Buscamos opciones económicas para el viaje.        | We're looking for affordable options for the trip. | feminine plural                    |
