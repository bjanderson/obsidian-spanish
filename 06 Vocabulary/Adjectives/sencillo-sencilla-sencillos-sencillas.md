# sencillo / sencilla / sencillos / sencillas

## Meaning

*Sencillo* means "simple" or "uncomplicated" — either describing a task or
thing as easy to do/understand, or describing a person as down-to-earth,
without pretension. It agrees in gender and number: *sencillo*, *sencilla*,
*sencillos*, *sencillas*.

## Full Paradigm

| Gender / Number    | Form      |
| ------------------- | --------- |
| Masculine singular   | sencillo  |
| Feminine singular    | sencilla  |
| Masculine plural     | sencillos |
| Feminine plural      | sencillas |

## Examples

| Spanish                                          | English                                    | Notes                       |
| ------------------------------------------------- | -------------------------------------------- | ---------------------------------- |
| El plan es sencillo.                               | The plan is simple.                          | masculine singular                 |
| La receta de mi tía es sencilla.                   | My aunt's recipe is simple.                  | feminine singular                  |
| ¿Es sencillo aprender a nadar?                     | Is it simple to learn to swim?               | masculine singular, question       |
