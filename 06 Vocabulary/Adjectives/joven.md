# joven

## Meaning

*Joven* means "young." It has the same form for masculine and feminine —
it only changes for number: *joven*, *jóvenes*. Note the written accent
appears in the plural (*jóvenes*) because the stress stays on the same
syllable while the word gains a syllable.

## Full Paradigm

| Number     | Form     |
| ----------- | -------- |
| Singular     | joven    |
| Plural       | jóvenes  |
