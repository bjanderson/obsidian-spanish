# reciente

## Meaning

*Reciente* means "recent" — something that happened or appeared not long
ago. It has the same form for masculine and feminine — it only changes for
number: *reciente*, *recientes*.

## Full Paradigm

| Number     | Form        |
| ----------- | ----------- |
| Singular     | reciente    |
| Plural       | recientes   |
