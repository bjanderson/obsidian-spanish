# brillante

## Meaning

*Brillante* means "bright" or "shiny" — light reflecting off a surface (*una
superficie brillante*, "a shiny surface") or a strong light source itself
(*una luz brillante*, "a bright light"). It also works figuratively for a
person's intellect or performance (*un estudiante brillante*, "a brilliant
student"). It has the same form for masculine and feminine — it only
changes for number: *brillante*, *brillantes*.

## Full Paradigm

| Number   | Form        |
| -------- | ----------- |
| Singular | brillante   |
| Plural   | brillantes  |
