# amplio / amplia / amplios / amplias

## Meaning

*Amplio* means "wide" or "broad/spacious." It agrees in gender and
number: *amplio*, *amplia*, *amplios*, *amplias*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | amplio  |
| Feminine singular    | amplia  |
| Masculine plural     | amplios |
| Feminine plural      | amplias |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El salón es amplio.                              | The living room is spacious.               | masculine singular                 |
| La avenida es amplia.                            | The avenue is wide.                        | feminine singular                  |
| ¿Es amplio el departamento?                      | Is the apartment spacious?                 | masculine singular, question       |
| No hicieron cambios amplios.                     | They didn't make broad changes.            | masculine plural, negation         |
| Tienen vistas amplias desde la terraza.          | They have wide views from the terrace.     | feminine plural                    |
