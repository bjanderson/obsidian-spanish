# algunos / algunas

## Meaning

*Algunos* and *algunas* mean "some" or "a few" — they point to an unspecified
number of things or people out of a larger group: *algunos estudiantes*
("some students"), *algunas veces* ("some times"/"sometimes").

The singular forms are *alguno*/*alguna* ("some," referring to one unspecified
item), and *alguno* shortens (apocopates) to *algún* right before a masculine
singular noun, the same way [[un-una|un]] shortens from *uno*: *algún día*
("some day"), not *alguno día*. *Alguna* never shortens.

## Full Paradigm

| Gender / Number   | Form       |
| -------------------- | ------------ |
| Masculine singular      | algún / alguno |
| Feminine singular        | alguna       |
| Masculine plural           | algunos      |
| Feminine plural              | algunas      |

## Examples

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Algunos vecinos ya se fueron.               | Some neighbors already left.             | masculine plural                   |
| Algunas personas prefieren el café.         | Some people prefer coffee.               | feminine plural                    |
| ¿Tienes algún consejo para mí?              | Do you have any advice for me?           | apocopated, masculine singular, question |
| Alguna vez tienes que decidirte.            | At some point you have to decide.        | feminine singular                  |
| Vinieron algunos amigos a visitarme.        | Some friends came to visit me.           | masculine plural                   |
