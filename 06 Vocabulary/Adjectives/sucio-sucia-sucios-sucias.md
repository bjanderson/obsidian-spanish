# sucio / sucia / sucios / sucias

## Meaning

*Sucio* means "dirty" or "filthy." It agrees in gender and number:
*sucio*, *sucia*, *sucios*, *sucias*.

## Full Paradigm

| Gender / Number    | Form   |
| ------------------- | ------ |
| Masculine singular   | sucio  |
| Feminine singular    | sucia  |
| Masculine plural     | sucios |
| Feminine plural      | sucias |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El piso está sucio.                              | The floor is dirty.                        | masculine singular                 |
| La camisa está sucia de barro.                   | The shirt is dirty with mud.               | feminine singular                  |
| ¿Por qué están sucios tus zapatos?               | Why are your shoes dirty?                  | masculine plural, question         |
| No me gustan las toallas sucias.                 | I don't like dirty towels.                 | feminine plural                    |
| No dejes el carro tan sucio.                     | Don't leave the car so dirty.              | masculine singular, negative command |
