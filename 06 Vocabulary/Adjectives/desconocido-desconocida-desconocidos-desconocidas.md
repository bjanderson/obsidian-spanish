# desconocido / desconocida / desconocidos / desconocidas

## Meaning

*Desconocido* means "unknown" — the opposite of *conocido*, formed with the
negative prefix *des-*. It also works as a noun meaning "stranger." Agrees in
gender and number: *desconocido*, *desconocida*, *desconocidos*, *desconocidas*.

## Full Paradigm

| Gender / Number    | Form         |
| ------------------- | ------------ |
| Masculine singular   | desconocido  |
| Feminine singular    | desconocida  |
| Masculine plural     | desconocidos |
| Feminine plural      | desconocidas |

## Examples

| Spanish                                             | English                                   | Notes                |
| --------------------------------------------------- | ------------------------------------------ | ------------------------ |
| El autor del libro es desconocido.                    | The book's author is unknown.               | masculine singular, "del libro" |
| La causa del incendio sigue siendo desconocida.        | The cause of the fire is still unknown.     | feminine singular, "del incendio" |
| Llegaron dos hombres desconocidos al pueblo.           | Two unknown men arrived in town.            | masculine plural, "al pueblo" |
| Esas plantas son desconocidas en esta zona.            | Those plants are unknown in this area.      | feminine plural            |
| No es desconocido para nosotros.                       | He's not unknown to us.                     | negation                   |
