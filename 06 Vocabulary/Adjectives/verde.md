# verde

## Meaning

*Verde* means "green." It has the same form for masculine and feminine —
it only changes for number: *verde*, *verdes*. With fruit, it also means
"unripe" — a common secondary sense.

## Full Paradigm

| Number     | Form    |
| ----------- | ------- |
| Singular     | verde   |
| Plural       | verdes  |
