# dormido / dormida / dormidos / dormidas

## Meaning

*Dormido* means "asleep." Used with *estar* to describe the state of
sleeping — not the action of falling asleep, which uses the reflexive verb
*dormirse*. It agrees in gender and number: *dormido*, *dormida*,
*dormidos*, *dormidas*.

## Full Paradigm

| Gender / Number    | Form      |
| ------------------- | --------- |
| Masculine singular   | dormido   |
| Feminine singular    | dormida   |
| Masculine plural     | dormidos  |
| Feminine plural      | dormidas  |

## Examples

| Spanish                                       | English                              | Notes                     |
| ---------------------------------------------- | ------------------------------------- | -------------------------- |
| El bebé está dormido en su cuna.               | The baby is asleep in his crib.       | masculine singular          |
| Mi hermana está dormida en el sofá.            | My sister is asleep on the couch.     | feminine singular            |
| Los gatos están dormidos todo el día.          | The cats are asleep all day.          | masculine plural              |
| ¿Están dormidas las niñas?                     | Are the girls asleep?                 | feminine plural, question     |
| No está dormido todavía.                       | He isn't asleep yet.                  | negation                      |
