# profundo / profunda / profundos / profundas

## Meaning

*Profundo* means "deep" — physically (*el mar profundo*) or figuratively
(*un cambio profundo*, "a deep/major change"). It agrees in gender and
number: *profundo*, *profunda*, *profundos*, *profundas*.

## Full Paradigm

| Gender / Number    | Form      |
| ------------------- | --------- |
| Masculine singular   | profundo  |
| Feminine singular    | profunda  |
| Masculine plural     | profundos |
| Feminine plural      | profundas |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El lago es profundo.                             | The lake is deep.                          | masculine singular                 |
| La herida era profunda.                          | The wound was deep.                        | feminine singular                  |
| ¿Es profundo el mar aquí?                        | Is the sea deep here?                      | masculine singular, question       |
| No fue un cambio profundo.                       | It wasn't a deep change.                   | masculine singular, negation       |
| Sintieron emociones profundas.                   | They felt deep emotions.                   | feminine plural                    |
