# viejo / vieja / viejos / viejas

## Meaning

*Viejo* means "old" — for people, objects, or things that have existed a
long time. It agrees in gender and number: *viejo*, *vieja*, *viejos*,
*viejas*.

## Full Paradigm

| Gender / Number    | Form   |
| ------------------- | ------ |
| Masculine singular   | viejo  |
| Feminine singular    | vieja  |
| Masculine plural     | viejos |
| Feminine plural      | viejas |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El edificio es viejo.                            | The building is old.                       | masculine singular                 |
| La foto es vieja.                                | The photo is old.                          | feminine singular                  |
| ¿Es viejo ese carro?                             | Is that car old?                           | masculine singular, question       |
| No es tan viejo el puente.                       | The bridge isn't that old.                 | masculine singular, negation       |
| Visitamos las ruinas viejas del pueblo.          | We visited the town's old ruins.           | feminine plural, del contraction   |
