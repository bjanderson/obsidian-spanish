# ligero / ligera / ligeros / ligeras

## Meaning

*Ligero* means "light" by weight, or "light" as in a light meal (*una
cena ligera*). It agrees in gender and number: *ligero*, *ligera*,
*ligeros*, *ligeras*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | ligero  |
| Feminine singular    | ligera  |
| Masculine plural     | ligeros |
| Feminine plural      | ligeras |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El abrigo es ligero.                             | The coat is light.                         | masculine singular                 |
| La mochila está ligera.                          | The backpack is light.                     | feminine singular                  |
