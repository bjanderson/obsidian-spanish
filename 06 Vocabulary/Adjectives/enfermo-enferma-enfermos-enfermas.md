# enfermo / enferma / enfermos / enfermas

## Meaning

*Enfermo* means "sick, ill." Used with *estar* for a temporary illness.
It agrees in gender and number: *enfermo*, *enferma*, *enfermos*,
*enfermas*.

## Full Paradigm

| Gender / Number    | Form      |
| ------------------- | --------- |
| Masculine singular   | enfermo   |
| Feminine singular    | enferma   |
| Masculine plural     | enfermos  |
| Feminine plural      | enfermas  |

## Examples

| Spanish                                    | English                             | Notes                     |
| --------------------------------------------- | -------------------------------------- | -------------------------- |
| Mi hijo está enfermo con gripe.               | My son is sick with the flu.           | masculine singular           |
| Ella está enferma desde ayer.                 | She's been sick since yesterday.       | feminine singular             |
| Los trabajadores están enfermos esta semana.  | The workers are sick this week.        | masculine plural               |
| ¿Todavía están enfermas las gemelas?          | Are the twins still sick?              | feminine plural, question      |
| No está enfermo, solo cansado.                | He isn't sick, just tired.             | negation                       |
