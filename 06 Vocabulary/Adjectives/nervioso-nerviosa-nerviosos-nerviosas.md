# nervioso / nerviosa / nerviosos / nerviosas

## Meaning

*Nervioso* means "nervous" — usually a temporary state (*estar nervioso*),
though it can describe a nervous personality with *ser*. Agrees in gender and
number: *nervioso*, *nerviosa*, *nerviosos*, *nerviosas*.

## Full Paradigm

| Gender / Number    | Form       |
| ------------------- | ---------- |
| Masculine singular   | nervioso   |
| Feminine singular    | nerviosa   |
| Masculine plural     | nerviosos  |
| Feminine plural      | nerviosas  |
