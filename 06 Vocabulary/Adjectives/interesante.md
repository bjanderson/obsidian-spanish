# interesante

## Meaning

*Interesante* means "interesting." It has the same form for masculine and
feminine — it only changes for number: *interesante*, *interesantes*.

## Full Paradigm

| Number     | Form           |
| ----------- | -------------- |
| Singular     | interesante    |
| Plural       | interesantes   |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El libro es interesante.                         | The book is interesting.                   | singular                          |
| Los documentales son interesantes.               | The documentaries are interesting.         | plural                            |
| ¿Te parece interesante la propuesta?             | Does the proposal seem interesting to you? | question                          |
| No fue un tema interesante.                      | It wasn't an interesting topic.            | negation                          |
| Tuvimos conversaciones interesantes.             | We had interesting conversations.          | plural                            |
