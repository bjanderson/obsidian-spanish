# humano / humana / humanos / humanas

## Meaning

*Humano* means "human." It agrees in gender and number: *humano*,
*humana*, *humanos*, *humanas*. As a noun (*el humano* / *el ser humano*),
it means "human being."

## Full Paradigm

| Gender / Number    | Form     |
| ------------------- | -------- |
| Masculine singular   | humano   |
| Feminine singular    | humana   |
| Masculine plural     | humanos  |
| Feminine plural      | humanas  |

## Examples

| Spanish                                | English                                | Notes                       |
| --------------------------------------------- | ---------------------------------------------- | --------------------------------- |
| Es un error humano.                              | It's a human error.                              | masculine singular                 |
| ¿Es esa una reacción humana normal?              | Is that a normal human reaction?                 | feminine singular, question         |
