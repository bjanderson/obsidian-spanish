# rosado / rosada / rosados / rosadas

## Meaning

*Rosado* means "pink." It agrees in gender and number: *rosado*,
*rosada*, *rosados*, *rosadas*. It's also the word for "rosé" wine.

## Full Paradigm

| Gender / Number    | Form     |
| ------------------- | -------- |
| Masculine singular   | rosado   |
| Feminine singular    | rosada   |
| Masculine plural     | rosados  |
| Feminine plural      | rosadas  |

## Examples

| Spanish                              | English                              | Notes                       |

| El vestido es rosado.                            | The dress is pink.                            | masculine singular                 |
| La habitación de la bebé es rosada.              | The baby's room is pink.                      | feminine singular                  |
| ¿Prefieres el vino rosado o el tinto?            | Do you prefer rosé or red wine?               | masculine singular, question       |
| No me gustan los zapatos rosados.                | I don't like pink shoes.                      | masculine plural, negation         |
