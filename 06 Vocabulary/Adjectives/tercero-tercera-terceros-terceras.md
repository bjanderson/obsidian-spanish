# tercero / tercera / terceros / terceras

## Meaning

*Tercero* means "third." It agrees in gender and number with the noun it
describes: *tercero*, *tercera*, *terceros*, *terceras*. Like *primero*, it
shortens (apocopates) to *tercer* right before a masculine singular noun: *el
tercer piso* ("the third floor"), not *el tercero piso*.

## Full Paradigm

| Gender / Number     | Form      |
| --------------------- | --------- |
| Masculine singular      | tercero   |
| Feminine singular       | tercera   |
| Masculine plural        | terceros  |
| Feminine plural         | terceras  |
| Before masc. sing. noun | tercer (apocope) |
