# aburrido / aburrida / aburridos / aburridas

## Meaning

*Aburrido* is a classic *ser*/*estar* contrast word: with *ser* it means
"boring" (*la clase es aburrida*, "the class is boring"); with *estar* it means
"bored" (*estoy aburrido*, "I'm bored"). Agrees in gender and number:
*aburrido*, *aburrida*, *aburridos*, *aburridas*.

## Full Paradigm

| Gender / Number    | Form      |
| ------------------- | --------- |
| Masculine singular   | aburrido  |
| Feminine singular    | aburrida  |
| Masculine plural     | aburridos |
| Feminine plural      | aburridas |
