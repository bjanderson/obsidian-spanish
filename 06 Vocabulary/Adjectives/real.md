# real

## Meaning

*Real* means "real" — genuine, actually existing, not imagined or fake. It
has the same form for masculine and feminine — it only changes for number:
*real*, *reales*.

## Full Paradigm

| Number     | Form    |
| ----------- | ------- |
| Singular     | real    |
| Plural       | reales  |

## Examples

| Spanish                              | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| La historia es real.                             | The story is real.                            | masculine singular                 |
| Vimos animales reales, no de peluche.            | We saw real animals, not stuffed ones.        | masculine plural                   |
| ¿Es real esta oferta?                            | Is this offer real?                           | feminine singular, question        |
| No es real lo que dijo.                          | What he said isn't real.                      | negation                          |
| Compartieron experiencias reales.                | They shared real experiences.                 | feminine plural                    |
