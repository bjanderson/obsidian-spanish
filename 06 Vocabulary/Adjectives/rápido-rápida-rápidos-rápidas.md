# rápido / rápida / rápidos / rápidas

## Meaning

*Rápido* means "fast" or "quick." It agrees in gender and number:
*rápido*, *rápida*, *rápidos*, *rápidas*.

## Full Paradigm

| Gender / Number    | Form     |
| ------------------- | -------- |
| Masculine singular   | rápido   |
| Feminine singular    | rápida   |
| Masculine plural     | rápidos  |
| Feminine plural      | rápidas  |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El carro es rápido.                              | The car is fast.                           | masculine singular                 |
| La conexión es rápida.                           | The connection is fast.                    | feminine singular                  |
| ¿Es rápido el tren?                              | Is the train fast?                         | masculine singular, question       |
| No fueron respuestas rápidas.                    | They weren't fast answers.                 | feminine plural, negation          |
| Tomaron las decisiones más rápidas posibles.     | They made the fastest decisions possible.  | feminine plural                    |
