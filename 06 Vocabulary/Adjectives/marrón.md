# marrón

## Meaning

*Marrón* means "brown." It has the same form for masculine and feminine —
it only changes for number: *marrón*, *marrones*. Note the plural drops
the written accent, since *marrones* is naturally stressed on the same
syllable without one.

## Full Paradigm

| Number     | Form      |
| ----------- | --------- |
| Singular     | marrón    |
| Plural       | marrones  |
