# limpio / limpia / limpios / limpias

## Meaning

*Limpio* means "clean." It agrees in gender and number: *limpio*,
*limpia*, *limpios*, *limpias*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | limpio  |
| Feminine singular    | limpia  |
| Masculine plural     | limpios |
| Feminine plural      | limpias |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El cuarto está limpio.                           | The room is clean.                         | masculine singular                 |
| La cocina quedó limpia.                          | The kitchen ended up clean.                | feminine singular                  |
| ¿Están limpios los platos?                       | Are the dishes clean?                      | masculine plural, question         |
| No dejaron limpio el baño.                       | They didn't leave the bathroom clean.      | masculine singular, negation       |
| Prefiero las toallas limpias.                    | I prefer clean towels.                     | feminine plural                    |
