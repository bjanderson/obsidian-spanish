# sincero / sincera / sinceros / sinceras

## Meaning

*Sincero* means "sincere, honest, genuine" — describing someone who says what they
truly think without pretending. It agrees in gender and number: *sincero*, *sincera*,
*sinceros*, *sinceras*. Usually paired with *ser* for a lasting character trait.

## Full Paradigm

| Gender / Number    | Form      |
| ------------------ | --------- |
| Masculine singular  | sincero   |
| Feminine singular   | sincera   |
| Masculine plural    | sinceros  |
| Feminine plural     | sinceras  |
