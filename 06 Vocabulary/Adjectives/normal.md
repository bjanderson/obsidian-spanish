# normal

## Meaning

*Normal* means "normal" or "usual." It has the same form for masculine and
feminine — it only changes for number: *normal*, *normales*.

## Full Paradigm

| Number   | Form     |
| -------- | -------- |
| Singular | normal   |
| Plural   | normales |

## Examples

| Spanish                                       | English                                | Notes                      |
| ------------------------------------------------ | ----------------------------------------- | ----------------------------- |
| Es normal sentir nervios antes del examen.        | It's normal to feel nervous before the exam. | singular                   |
| ¿Es normal que duela un poco?                     | Is it normal for it to hurt a little?      | question                   |
| No fue un día normal en la oficina.               | It wasn't a normal day at the office.      | negation                   |
| Los precios normales subieron este mes.           | Normal prices went up this month.          | plural                     |
| Son horarios normales para un restaurante.        | Those are normal hours for a restaurant.   | plural                     |
