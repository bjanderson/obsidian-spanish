# frío / fría / fríos / frías

## Meaning

*Frío* means "cold." As an adjective it agrees in gender and number:
*frío*, *fría*, *fríos*, *frías*. (The unrelated noun *el frío*, "the
cold," is invariable and not covered by this paradigm.)

## Full Paradigm

| Gender / Number    | Form  |
| ------------------- | ----- |
| Masculine singular   | frío  |
| Feminine singular    | fría  |
| Masculine plural     | fríos |
| Feminine plural      | frías |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El clima es frío.                                | The climate is cold.                       | masculine singular                 |
| El agua está fría.                               | The water is cold.                         | feminine singular                  |
| ¿Están frías las bebidas?                        | Are the drinks cold?                       | feminine plural, question          |
| No fue un invierno frío.                         | It wasn't a cold winter.                   | masculine singular, negation       |
| Sintieron las manos frías.                       | They felt their hands go cold.             | feminine plural                    |
