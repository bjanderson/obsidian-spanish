# grosero / grosera / groseros / groseras

## Meaning

*Grosero* means "rude, crude, vulgar" — describing impolite behavior or language.
It agrees in gender and number: *grosero*, *grosera*, *groseros*, *groseras*.

## Full Paradigm

| Gender / Number    | Form       |
| ------------------ | ---------- |
| Masculine singular  | grosero    |
| Feminine singular   | grosera    |
| Masculine plural    | groseros   |
| Feminine plural     | groseras   |
