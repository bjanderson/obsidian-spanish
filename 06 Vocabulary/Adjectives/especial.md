# especial

## Meaning

*Especial* means "special." It has the same form for masculine and
feminine — it only changes for number: *especial*, *especiales*.

## Full Paradigm

| Number     | Form         |
| ----------- | ------------ |
| Singular     | especial     |
| Plural       | especiales   |

## Examples

| Spanish                                | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| Hoy es un día especial.                          | Today is a special day.                       | masculine singular                 |
| ¿Tiene esta receta algún ingrediente especial?   | Does this recipe have any special ingredient? | question                          |
| No fue nada especial.                            | It wasn't anything special.                   | negation                          |
| Preparamos platos especiales para la fiesta.     | We made special dishes for the party.         | masculine plural                   |
| Recibió una atención especial en el hospital.    | She received special care at the hospital.    | feminine singular                  |
