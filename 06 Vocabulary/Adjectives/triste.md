# triste

## Meaning

*Triste* means "sad." It has the same form for masculine and feminine —
it only changes for number: *triste*, *tristes*.

## Full Paradigm

| Number     | Form     |
| ----------- | -------- |
| Singular     | triste   |
| Plural       | tristes  |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| Está triste por la noticia.                      | She's sad about the news.                  | singular                          |
| Los vecinos se veían tristes.                    | The neighbors looked sad.                  | plural                            |
| ¿Por qué estás triste?                           | Why are you sad?                           | question                          |
| No fue un final triste.                          | It wasn't a sad ending.                    | negation                          |
| Escribió una canción triste.                     | She wrote a sad song.                      | singular                          |
