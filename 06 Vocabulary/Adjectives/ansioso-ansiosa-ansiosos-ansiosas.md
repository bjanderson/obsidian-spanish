# ansioso / ansiosa / ansiosos / ansiosas

## Meaning

*Ansioso* means "anxious" — describing worry or eager anticipation. *Ansioso
por/de + infinitivo* means "eager to." Agrees in gender and number: *ansioso*,
*ansiosa*, *ansiosos*, *ansiosas*.

## Full Paradigm

| Gender / Number    | Form      |
| ------------------- | --------- |
| Masculine singular   | ansioso   |
| Feminine singular    | ansiosa   |
| Masculine plural     | ansiosos  |
| Feminine plural      | ansiosas  |

## Examples

| Spanish                                            | English                                    | Notes                |
| -------------------------------------------------------- | ------------------------------------------------ | ------------------------ |
| Estoy ansioso por los resultados.                            | I'm anxious about the results.                       | masculine singular         |
| Está ansiosa por ver a su familia.                           | She's eager to see her family.                       | feminine singular, "ansiosa por" + personal *a* |
| Los pasajeros estaban ansiosos por el retraso.                | The passengers were anxious about the delay.         | masculine plural              |
| Las madres estaban ansiosas esperando noticias.               | The mothers were anxious waiting for news.           | feminine plural                 |
| No estés tan ansioso.                                        | Don't be so anxious.                                 | negative command                 |
