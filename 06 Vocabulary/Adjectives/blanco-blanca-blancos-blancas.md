# blanco / blanca / blancos / blancas

## Meaning

*Blanco* means "white." It agrees in gender and number: *blanco*,
*blanca*, *blancos*, *blancas*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | blanco  |
| Feminine singular    | blanca  |
| Masculine plural     | blancos |
| Feminine plural      | blancas |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El vestido es blanco.                            | The dress is white.                        | masculine singular                 |
| La casa tiene una pared blanca.                  | The house has a white wall.                | feminine singular                  |
| ¿Tienes una camisa blanca?                       | Do you have a white shirt?                 | feminine singular, question        |
| No me gustan los zapatos blancos.                | I don't like white shoes.                  | masculine plural, negation         |
| Las flores blancas huelen bien.                  | The white flowers smell nice.              | feminine plural                    |
