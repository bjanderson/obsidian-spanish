# feliz

## Meaning

*Feliz* means "happy." It has the same form for masculine and feminine —
it only changes for number, with a spelling change: *feliz*, *felices*.

## Full Paradigm

| Number     | Form     |
| ----------- | -------- |
| Singular     | feliz    |
| Plural       | felices  |

## Examples

| Spanish                              | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| Estoy feliz con el resultado.                    | I'm happy with the result.                    | singular                          |
| Se ven felices los niños.                        | The children look happy.                      | plural                            |
| ¿Eres feliz en tu trabajo?                       | Are you happy at your job?                    | question                          |
| No me siento feliz hoy.                          | I don't feel happy today.                     | negation                          |
| Fue un día feliz para toda la familia.           | It was a happy day for the whole family.      | singular                          |
