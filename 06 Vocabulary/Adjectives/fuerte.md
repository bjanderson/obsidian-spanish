# fuerte

## Meaning

*Fuerte* means "strong" — physically, emotionally, or in intensity
(*un olor fuerte*, "a strong smell"). It has the same form for masculine
and feminine — it only changes for number: *fuerte*, *fuertes*.

## Full Paradigm

| Number     | Form     |
| ----------- | -------- |
| Singular     | fuerte   |
| Plural       | fuertes  |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El viento es fuerte hoy.                         | The wind is strong today.                  | singular                          |
| Tiene brazos fuertes.                            | He has strong arms.                        | plural                            |
| ¿Es fuerte el café?                              | Is the coffee strong?                      | question                          |
| No fue un dolor fuerte.                          | It wasn't a strong pain.                   | negation                          |
| Sintió un olor fuerte en la cocina.              | She smelled a strong odor in the kitchen.  | singular                          |
