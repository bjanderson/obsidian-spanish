# dulce

## Meaning

*Dulce* means "sweet" — for taste, and figuratively for a gentle, kind
personality (*una persona dulce*, "a sweet/gentle person"). It has the same
form for masculine and feminine — it only changes for number: *dulce*,
*dulces*.

## Full Paradigm

| Number     | Form    |
| ----------- | ------- |
| Singular     | dulce   |
| Plural       | dulces  |
