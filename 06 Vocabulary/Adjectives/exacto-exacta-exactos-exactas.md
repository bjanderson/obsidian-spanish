# exacto / exacta / exactos / exactas

## Meaning

*Exacto* means "exact" or "precise." It agrees in gender and number:
*exacto*, *exacta*, *exactos*, *exactas*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | exacto  |
| Feminine singular    | exacta  |
| Masculine plural     | exactos |
| Feminine plural      | exactas |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El resultado fue exacto.                         | The result was exact.                      | masculine singular                 |
| La hora exacta era la una.                       | The exact time was one o'clock.            | feminine singular                  |
| ¿Es exacto ese número?                           | Is that number exact?                      | masculine singular, question       |
| No fueron cifras exactas.                        | They weren't exact figures.                | feminine plural, negation          |
| Necesitamos datos exactos para el informe.       | We need exact data for the report.         | masculine plural                   |
