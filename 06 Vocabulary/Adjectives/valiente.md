# valiente

## Meaning

*Valiente* means "brave, courageous." It has the same form for masculine
and feminine — it only changes for number: *valiente*, *valientes*.

## Full Paradigm

| Number     | Form        |
| ----------- | ----------- |
| Singular     | valiente    |
| Plural       | valientes   |

## Examples

| Spanish                                    | English                              | Notes                     |
| ---------------------------------------------- | ---------------------------------------- | -------------------------- |
| El bombero es muy valiente.                    | The firefighter is very brave.            | singular                     |
| Es una mujer valiente.                         | She's a brave woman.                      | singular                     |
| Los soldados fueron valientes.                 | The soldiers were brave.                  | plural                        |
| ¿Eres valiente?                                | Are you brave?                            | question                      |
| No fue nada valiente esa decisión.             | That decision wasn't brave at all.        | negation                      |
