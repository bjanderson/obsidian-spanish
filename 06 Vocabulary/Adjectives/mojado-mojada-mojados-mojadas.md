# mojado / mojada / mojados / mojadas

## Meaning

*Mojado* means "wet." It agrees in gender and number: *mojado*,
*mojada*, *mojados*, *mojadas*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | mojado  |
| Feminine singular    | mojada  |
| Masculine plural     | mojados |
| Feminine plural      | mojadas |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El piso está mojado.                             | The floor is wet.                          | masculine singular                 |
| La toalla está mojada.                           | The towel is wet.                          | feminine singular                  |
| ¿Están mojados los zapatos?                      | Are the shoes wet?                         | masculine plural, question         |
| No dejes la ropa mojada ahí.                     | Don't leave the wet clothes there.         | feminine singular, negation        |
| Sus manos estaban mojadas.                       | Her hands were wet.                        | feminine plural                    |
