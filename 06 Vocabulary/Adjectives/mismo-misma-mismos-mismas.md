# mismo / misma / mismos / mismas

## Meaning

*Mismo* agrees in gender and number with the noun it describes: *mismo*,
*misma*, *mismos*, *mismas*. Before or after a noun, it means "same": *el
mismo día* ("the same day"). Right after a subject pronoun, it intensifies it
to mean "-self": *yo mismo* ("I myself"), *ellas mismas* ("they themselves").
The neuter form *lo mismo* means "the same thing."

## Full Paradigm

| Gender / Number   | Form    |
| ------------------ | ------- |
| Masculine singular | mismo   |
| Feminine singular  | misma   |
| Masculine plural   | mismos  |
| Feminine plural    | mismas  |

## Examples

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Vivimos en la misma ciudad.                 | We live in the same city.                | feminine singular, "same"           |
| Yo mismo lo vi.                             | I saw it myself.                         | masculine, emphatic "-self"         |
| Compramos los mismos libros.                | We bought the same books.                | masculine plural, "same"            |
| Ellas mismas prepararon la comida.          | They themselves prepared the food.       | feminine plural, emphatic "-self"   |
| ¿Quieres lo mismo de siempre?               | Do you want the usual (the same thing)?  | question, neuter                    |
