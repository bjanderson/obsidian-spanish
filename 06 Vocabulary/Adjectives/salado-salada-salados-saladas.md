# salado / salada / salados / saladas

## Meaning

*Salado* means "salty." It agrees in gender and number: *salado*,
*salada*, *salados*, *saladas*. Colloquially, in everyday speech in
several Latin American countries it can also mean "unlucky" — a secondary
sense distinct from the taste meaning.

## Full Paradigm

| Gender / Number    | Form     |
| ------------------- | -------- |
| Masculine singular   | salado   |
| Feminine singular    | salada   |
| Masculine plural     | salados  |
| Feminine plural      | saladas  |

## Examples

| Spanish                                  | English                              | Notes                       |
| ----------------------------------------- | -------------------------------------- | --------------------------------- |
| El agua del mar es salada.                 | Seawater is salty.                     | feminine singular, *del* contraction |
| El queso está muy salado.                  | The cheese is very salty.              | masculine singular                 |
| ¿Está salada la sopa?                      | Is the soup salty?                     | feminine singular, question        |
| No compres esos snacks salados.            | Don't buy those salty snacks.          | masculine plural, negation         |
