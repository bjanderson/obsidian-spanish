# ancho / ancha / anchos / anchas

## Meaning

*Ancho* means "wide." It agrees in gender and number: *ancho*, *ancha*,
*anchos*, *anchas*.

## Full Paradigm

| Gender / Number    | Form   |
| ------------------- | ------ |
| Masculine singular   | ancho  |
| Feminine singular    | ancha  |
| Masculine plural     | anchos |
| Feminine plural      | anchas |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El río es ancho.                                 | The river is wide.                         | masculine singular                 |
| La puerta es ancha.                              | The door is wide.                          | feminine singular                  |
| ¿Es ancha la calle?                              | Is the street wide?                        | feminine singular, question        |
| No es tan ancho el pasillo.                      | The hallway isn't that wide.               | masculine singular, negation       |
| Compramos cinturones anchos.                     | We bought wide belts.                      | masculine plural                   |
