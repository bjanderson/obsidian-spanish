# cuánto / cuánta / cuántos / cuántas

## Meaning

*Cuánto* (accented) is the interrogative/exclamative "how much" or "how
many" — used in direct and indirect questions (*¿Cuánto cuesta?*, "How much
does it cost?") and in exclamations (*¡Cuánta gente!*, "So many people!").
It agrees in gender and number with the noun it modifies: *cuánto*,
*cuánta*, *cuántos*, *cuántas*.

Don't confuse it with unaccented *cuanto*, a relative word used outside
questions and exclamations to mean "as much as" (*Come cuanto quieras*,
"Eat as much as you want") — the written accent is the only thing that
tells the two apart, and only *cuánto* is interrogative/exclamative. This
puts *cuánto* in the same interrogative cluster as [[cómo]] and [[quién]]
— all three always carry the accent when used to ask or exclaim.

## Full Paradigm

| Gender / Number    | Form     |
| ------------------- | -------- |
| Masculine singular   | cuánto   |
| Feminine singular    | cuánta   |
| Masculine plural     | cuántos  |
| Feminine plural      | cuántas  |

## Examples

| --------------------------------------------- | ---------------------------------------------- | -------------------------------- |
| ¿Cuánto dinero necesitas?                      | How much money do you need?                      | masculine singular, question       |
| ¡Cuánta paciencia tienes!                      | You have so much patience!                       | feminine singular, exclamation      |
| ¿Cuántos hermanos tienes?                      | How many siblings do you have?                   | masculine plural, question         |
