# rojo / roja / rojos / rojas

## Meaning

*Rojo* means "red." It agrees in gender and number: *rojo*, *roja*,
*rojos*, *rojas*.

## Full Paradigm

| Gender / Number    | Form  |
| ------------------- | ----- |
| Masculine singular   | rojo  |
| Feminine singular    | roja  |
| Masculine plural     | rojos |
| Feminine plural      | rojas |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El semáforo está rojo.                           | The traffic light is red.                  | masculine singular                 |
| La manzana es roja.                              | The apple is red.                          | feminine singular                  |
| ¿Tienes un vestido rojo?                         | Do you have a red dress?                   | masculine singular, question       |
| No me gustan los labios rojos.                   | I don't like red lipstick.                 | masculine plural, negation         |
| Las rosas rojas son mis favoritas.               | Red roses are my favorites.                | feminine plural                    |
