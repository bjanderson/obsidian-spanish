# corto / corta / cortos / cortas

## Meaning

*Corto* means "short" — for length or duration, not height (use *bajo*
for a short person). It agrees in gender and number: *corto*, *corta*,
*cortos*, *cortas*.

## Full Paradigm

| Gender / Number    | Form   |
| ------------------- | ------ |
| Masculine singular   | corto  |
| Feminine singular    | corta  |
| Masculine plural     | cortos |
| Feminine plural      | cortas |
