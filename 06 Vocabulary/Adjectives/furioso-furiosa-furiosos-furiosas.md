# furioso / furiosa / furiosos / furiosas

## Meaning

*Furioso* means "furious" — a stronger degree of anger than *enojado*, always
with *estar*. Agrees in gender and number: *furioso*, *furiosa*, *furiosos*,
*furiosas*.

## Full Paradigm

| Gender / Number    | Form      |
| ------------------- | --------- |
| Masculine singular   | furioso   |
| Feminine singular    | furiosa   |
| Masculine plural     | furiosos  |
| Feminine plural      | furiosas  |

## Examples

| Spanish                                       | English                                | Notes           |
| -------------------------------------------------- | ------------------------------------------ | -------------------- |
| Mi papá estaba furioso por el choque.                 | My dad was furious about the crash.          | masculine singular      |
| Ella está furiosa con el jefe.                        | She's furious with her boss.                 | feminine singular          |
| Los clientes estaban furiosos por la demora.           | The customers were furious about the delay.  | masculine plural              |
| Las fanáticas quedaron furiosas con el resultado.      | The fans were left furious with the result.  | feminine plural                 |
| No te pongas furioso.                                 | Don't get furious.                           | negative command                 |
