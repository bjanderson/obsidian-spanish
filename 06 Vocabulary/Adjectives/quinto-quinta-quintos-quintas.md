# quinto / quinta / quintos / quintas

## Meaning

*Quinto* means "fifth." It agrees in gender and number with the noun it
describes: *quinto*, *quinta*, *quintos*, *quintas*. Unlike *primero* and
*tercero*, it does **not** shorten before a masculine singular noun: *el quinto
piso* ("the fifth floor"), never *el quint piso*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | quinto  |
| Feminine singular    | quinta  |
| Masculine plural     | quintos |
| Feminine plural      | quintas |

## Examples

| Spanish                                | English                                  | Notes                        |
| ------------------------------------------ | --------------------------------------------- | --------------------------------- |
| Es mi quinto intento.                       | It's my fifth attempt.                          | masculine singular                  |
| Vive en el quinto piso.                     | He lives on the fifth floor.                    | masculine singular, no apocope      |
| Es la quinta vez que viajamos a México.     | It's the fifth time we've traveled to Mexico.   | feminine singular                   |
| Terminaron en quinto lugar.                 | They finished in fifth place.                   | masculine singular                  |
| Las quintas ediciones del libro se agotaron. | The fifth editions of the book sold out.       | feminine plural                     |
