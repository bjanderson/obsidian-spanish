# amarillo / amarilla / amarillos / amarillas

## Meaning

*Amarillo* means "yellow." It agrees in gender and number: *amarillo*,
*amarilla*, *amarillos*, *amarillas*.

## Full Paradigm

| Gender / Number    | Form       |
| ------------------- | ---------- |
| Masculine singular   | amarillo   |
| Feminine singular    | amarilla   |
| Masculine plural     | amarillos  |
| Feminine plural      | amarillas  |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El sol se ve amarillo.                           | The sun looks yellow.                      | masculine singular                 |
| La flor es amarilla.                             | The flower is yellow.                      | feminine singular                  |
| ¿Tienes un paraguas amarillo?                    | Do you have a yellow umbrella?             | masculine singular, question       |
| No me gustan los taxis amarillos acá.            | I don't like the yellow taxis here.        | masculine plural, negation         |
| Las páginas amarillas del libro estaban gastadas. | The book's yellow pages were worn out.    | feminine plural, del contraction   |
