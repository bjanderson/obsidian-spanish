# ácido / ácida / ácidos / ácidas

## Meaning

*Ácido* means "sour" or "acidic" — a sharp, tart taste like lemon or unripe
fruit, and also the scientific sense of an acid. It agrees in gender and
number: *ácido*, *ácida*, *ácidos*, *ácidas*.

## Full Paradigm

| Gender / Number     | Form   |
| -------------------- | ------ |
| Masculine singular    | ácido  |
| Feminine singular     | ácida  |
| Masculine plural      | ácidos |
| Feminine plural       | ácidas |

## Examples

| Spanish                                          | English                                     | Notes                    |
| ----------------------------------------------- | -------------------------------------------- | ------------------------- |
| Este limón está muy ácido.                       | This lemon is very sour.                     | masculine singular         |
| La salsa quedó demasiado ácida.                  | The sauce turned out too sour.               | feminine singular          |
| ¿No te parecen ácidos estos duraznos?            | Don't these peaches seem sour to you?        | masculine plural, question |
| Las manzanas verdes no siempre son tan ácidas.   | Green apples aren't always that sour.        | feminine plural, negation  |
| El jugo de naranja natural es más ácido que el de caja. | Fresh orange juice is more acidic than boxed juice. | comparative use     |
