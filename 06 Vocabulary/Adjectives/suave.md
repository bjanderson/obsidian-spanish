# suave

## Meaning

*Suave* means "soft, smooth, gentle" — of texture, sound, or manner. It
has the same form for masculine and feminine — it only changes for
number: *suave*, *suaves*.

## Full Paradigm

| Number     | Form     |
| ----------- | -------- |
| Singular     | suave    |
| Plural       | suaves   |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------- | ----------------------------------- | ----------------------------- |

| Tiene una voz suave.                     | She has a gentle voice.             | singular                       |
| Los colores son suaves.                  | The colors are soft/muted.          | plural                          |
