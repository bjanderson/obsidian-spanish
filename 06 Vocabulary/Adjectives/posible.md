# posible

## Meaning

*Posible* means "possible." It has the same form for masculine and
feminine — it only changes for number: *posible*, *posibles*.

## Full Paradigm

| Number     | Form        |
| ----------- | ----------- |
| Singular     | posible     |
| Plural       | posibles    |

## Examples

| Spanish                                | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| Es posible terminar hoy.                         | It's possible to finish today.                | masculine singular                 |
| ¿Es posible cambiar la fecha?                    | Is it possible to change the date?            | question                          |
| No es posible llegar a tiempo.                   | It isn't possible to arrive on time.          | negation                          |
| Estudiamos todas las soluciones posibles.        | We studied all the possible solutions.        | feminine plural                    |
| Buscamos los mejores resultados posibles.        | We're looking for the best possible results.  | masculine plural                   |
