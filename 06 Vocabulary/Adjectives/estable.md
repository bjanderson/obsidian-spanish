# estable

## Meaning

*Estable* means "stable" — physically steady, or figuratively secure
(*un trabajo estable*, "a stable job"). It has the same form for
masculine and feminine — it only changes for number: *estable*,
*estables*.

## Full Paradigm

| Number     | Form       |
| ----------- | ---------- |
| Singular     | estable    |
| Plural       | estables   |

| Spanish                                    | English                                | Notes                     |
