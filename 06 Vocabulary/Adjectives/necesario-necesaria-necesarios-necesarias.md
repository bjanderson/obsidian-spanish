# necesario / necesaria / necesarios / necesarias

## Meaning

*Necesario* means "necessary" — required for something to happen. It
agrees in gender and number: *necesario*, *necesaria*, *necesarios*,
*necesarias*.

## Full Paradigm

| Gender / Number    | Form        |
| ------------------- | ----------- |
| Masculine singular   | necesario   |
| Feminine singular    | necesaria   |
| Masculine plural     | necesarios  |
| Feminine plural      | necesarias  |

## Examples

| Spanish                              | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| Es necesario terminar el proyecto hoy.           | It's necessary to finish the project today.   | masculine singular, impersonal     |
| La ayuda fue necesaria.                          | The help was necessary.                       | feminine singular                  |
| ¿Son necesarios estos documentos?                | Are these documents necessary?                | masculine plural, question         |
| No es necesaria tanta prisa.                     | So much rushing isn't necessary.              | feminine singular, negation        |
| Compramos los materiales necesarios.             | We bought the necessary materials.            | masculine plural                   |
