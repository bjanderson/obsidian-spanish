# vivo / viva / vivos / vivas

## Meaning

*Vivo* means "alive" when used with *estar*. With *ser*, it takes on a
figurative sense — "lively," "bright," or "sharp" (*un color vivo*, "a
bright color"; *una persona viva*, "a sharp person"). It agrees in gender
and number: *vivo*, *viva*, *vivos*, *vivas*.

## Full Paradigm

| Gender / Number    | Form   |
| ------------------- | ------ |
| Masculine singular   | vivo   |
| Feminine singular    | viva   |
| Masculine plural     | vivos  |
| Feminine plural      | vivas  |

## Examples

| Spanish                                  | English                                | Notes                     |
| ------------------------------------------ | ---------------------------------------- | -------------------------- |
| El perro todavía está vivo.                | The dog is still alive.                  | masculine singular          |
| La planta está viva a pesar del frío.      | The plant is alive despite the cold.     | feminine singular, del      |
| Sus abuelos ya no están vivos.             | His grandparents are no longer alive.    | masculine plural, negation  |
| ¿Siguen vivas las tradiciones?             | Are the traditions still alive?          | feminine plural, question   |
| Es un color muy vivo.                      | It's a very bright color.                | masculine singular, figurative sense |
