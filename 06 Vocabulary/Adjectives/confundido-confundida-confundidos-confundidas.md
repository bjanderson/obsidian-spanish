# confundido / confundida / confundidos / confundidas

## Meaning

*Confundido* means "confused" — the past participle of *confundir* used with
*estar*. Agrees in gender and number: *confundido*, *confundida*,
*confundidos*, *confundidas*.

## Full Paradigm

| Gender / Number    | Form           |
| ------------------- | -------------- |
| Masculine singular   | confundido     |
| Feminine singular    | confundida     |
| Masculine plural     | confundidos    |
| Feminine plural      | confundidas    |
