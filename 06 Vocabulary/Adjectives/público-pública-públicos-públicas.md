# público / pública / públicos / públicas

## Meaning

*Público* means "public." It agrees in gender and number: *público*,
*pública*, *públicos*, *públicas*. As a noun (*el público*), it means
"the audience/public."

## Full Paradigm

| Gender / Number    | Form      |
| ------------------- | --------- |
| Masculine singular   | público   |
| Feminine singular    | pública   |
| Masculine plural     | públicos  |
| Feminine plural      | públicas  |

## Examples

| Spanish                                | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| Este es un parque público.                       | This is a public park.                        | masculine singular                 |
| ¿La reunión es pública?                          | Is the meeting public?                        | feminine singular, question         |
| No es información pública.                       | It isn't public information.                  | negation                          |
| Los servicios públicos mejoraron este año.       | Public services improved this year.           | masculine plural                   |
| El público aplaudió al final del concierto.      | The audience applauded at the end of the concert. | noun use, masculine singular  |
