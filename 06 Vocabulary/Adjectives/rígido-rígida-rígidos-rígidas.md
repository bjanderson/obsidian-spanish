# rígido / rígida / rígidos / rígidas

## Meaning

*Rígido* means "rigid, stiff" — physically inflexible, or figuratively
strict (*un horario rígido*, "a strict schedule"). It agrees in gender and
number: *rígido*, *rígida*, *rígidos*, *rígidas*.

## Full Paradigm

| Gender / Number    | Form      |
| ------------------- | --------- |
| Masculine singular   | rígido    |
| Feminine singular    | rígida    |
| Masculine plural     | rígidos   |
| Feminine plural      | rígidas   |

## Examples
