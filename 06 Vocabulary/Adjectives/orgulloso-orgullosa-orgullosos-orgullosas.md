# orgulloso / orgullosa / orgullosos / orgullosas

## Meaning

*Orgulloso* means "proud" — in the positive sense (pleased, satisfied) with *estar
orgulloso de* ("proud of"), or in a negative sense (arrogant) with *ser orgulloso*.
It agrees in gender and number: *orgulloso*, *orgullosa*, *orgullosos*, *orgullosas*.

## Full Paradigm

| Gender / Number    | Form          |
| ------------------ | ------------- |
| Masculine singular  | orgulloso     |
| Feminine singular   | orgullosa     |
| Masculine plural    | orgullosos    |
| Feminine plural     | orgullosas    |
