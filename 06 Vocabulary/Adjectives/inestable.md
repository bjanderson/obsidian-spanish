# inestable

## Meaning

*Inestable* means "unstable" — the negative counterpart of *estable*,
formed with the prefix *in-*. It has the same form for masculine and
feminine — it only changes for number: *inestable*, *inestables*.

## Full Paradigm

| Number     | Form         |
| ----------- | ------------ |
| Singular     | inestable    |
| Plural       | inestables   |

## Examples

| Spanish                                    | English                                | Notes                     |
| ---------------------------------------------- | ------------------------------------------ | -------------------------- |

| Su humor es inestable.                         | Her mood is unstable.                       | singular                    |
| Los precios están inestables esta semana.      | Prices are unstable this week.              | plural                       |
