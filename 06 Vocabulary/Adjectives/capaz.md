# capaz

## Meaning

*Capaz* means "capable" — usually followed by *de* plus an infinitive
(*capaz de resolverlo*, "capable of solving it"). It has the same form for
masculine and feminine — it only changes for number, with a spelling
change: *capaz*, *capaces*.

## Full Paradigm

| Number     | Form     |
| ----------- | -------- |
| Singular     | capaz    |
| Plural       | capaces  |

## Examples

| Spanish                              | English                                | Notes                       |
| --------------------------------------------- | ------------------------------------------------- | --------------------------------- |
| Es capaz de resolver el problema.                | She's capable of solving the problem.               | feminine singular             |
| Son capaces de aprender rápido.                  | They're capable of learning quickly.                | masculine plural               |
| ¿Eres capaz de terminarlo hoy?                   | Are you capable of finishing it today?              | question                     |
| No es capaz de mentir.                           | He isn't capable of lying.                          | negation                     |
| Contratamos empleados capaces.                   | We hired capable employees.                         | masculine plural               |
