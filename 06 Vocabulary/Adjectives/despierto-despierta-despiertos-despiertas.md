# despierto / despierta / despiertos / despiertas

## Meaning

*Despierto* means "awake." Used with *estar*. It's also used figuratively
to mean "sharp" or "quick-witted" (*un niño despierto*, "a bright child").
It agrees in gender and number: *despierto*, *despierta*, *despiertos*,
*despiertas*.

## Full Paradigm

| Gender / Number    | Form        |
| ------------------- | ----------- |
| Masculine singular   | despierto   |
| Feminine singular    | despierta   |
| Masculine plural     | despiertos  |
| Feminine plural      | despiertas  |
