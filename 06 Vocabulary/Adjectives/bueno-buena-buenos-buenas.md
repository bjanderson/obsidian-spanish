# bueno / buena / buenos / buenas

## Meaning

*Bueno* means "good." It agrees in gender and number: *bueno*, *buena*,
*buenos*, *buenas*. Before a masculine singular noun, it shortens to
*buen* (*un buen amigo*, "a good friend").

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | bueno   |
| Feminine singular    | buena   |
| Masculine plural     | buenos  |
| Feminine plural      | buenas  |

## Examples

| Spanish                                | English                            | Notes                       |
| --------------------------------------------- | -------------------------------------- | --------------------------------- |
| Es un buen amigo.                                | He's a good friend.                     | masculine singular, apocope (before noun) |
| ¿La comida está buena?                           | Is the food good?                       | feminine singular, question         |
| Estos resultados no son buenos.                  | These results aren't good.              | masculine plural, negation          |
| Tiene ideas muy buenas.                          | She has very good ideas.                | feminine plural                     |
| Fue una buena decisión.                          | It was a good decision.                 | feminine singular, after noun       |
