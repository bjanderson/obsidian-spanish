# tal / tales

## Meaning

*Tal* and *tales* mean "such" or "such a." They're invariable for gender —
only the number changes: *tal* singular, *tales* plural. The set phrase *tal
vez* ("maybe," "perhaps") uses *tal* as an adverb, not this adjective use.

## Full Paradigm

| Number   | Form  |
| -------- | ----- |
| Singular | tal   |
| Plural   | tales |

## Examples

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Nunca dije tal cosa.                        | I never said such a thing.               | singular                           |
| No puedo creer tales excusas.               | I can't believe such excuses.            | plural, negation                    |
| Tal vez llueva mañana.                      | Maybe it will rain tomorrow.             | set phrase *tal vez*, statement     |
| ¿Cómo se te ocurre tal idea?                | How did you come up with such an idea?   | singular, question                  |
| En tales circunstancias, es mejor esperar.  | In such circumstances, it's best to wait. | plural                            |
