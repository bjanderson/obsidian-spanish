# pesado / pesada / pesados / pesadas

## Meaning

*Pesado* means "heavy" by weight. It also means "annoying/tedious" in
casual speech (*un trabajo pesado*, "a tedious job"). It agrees in gender
and number: *pesado*, *pesada*, *pesados*, *pesadas*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | pesado  |
| Feminine singular    | pesada  |
| Masculine plural     | pesados |
| Feminine plural      | pesadas |

## Examples

| Spanish                              | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |

| La maleta está pesada.                           | The suitcase is heavy.                        | feminine singular                  |
| ¿Es pesado el trabajo hoy?                       | Is work tedious today?                        | masculine singular, "tedious," question |
