# sano / sana / sanos / sanas

## Meaning

*Sano* means "healthy." Used with *estar* for current health, or *ser*
for something inherently healthy (*una dieta sana*, "a healthy diet"). It
agrees in gender and number: *sano*, *sana*, *sanos*, *sanas*.

## Full Paradigm

| Gender / Number    | Form   |
| ------------------- | ------ |
| Masculine singular   | sano   |
| Feminine singular    | sana   |
| Masculine plural     | sanos  |
| Feminine plural      | sanas  |

## Examples

| Spanish                                | English                            | Notes                     |
| ------------------------------------------ | -------------------------------------- | -------------------------- |
| El bebé nació sano.                        | The baby was born healthy.             | masculine singular           |
| Se ve sana y fuerte.                       | She looks healthy and strong.          | feminine singular             |
| Quiere hijos sanos.                        | He wants healthy children.             | masculine plural               |
| Las plantas están sanas este año.          | The plants are healthy this year.      | feminine plural                 |
| ¿Comes de manera sana?                     | Do you eat in a healthy way?           | question                       |
