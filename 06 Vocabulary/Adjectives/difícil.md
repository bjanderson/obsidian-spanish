# difícil

## Meaning

*Difícil* means "difficult" or "hard." It has the same form for masculine
and feminine — it only changes for number: *difícil*, *difíciles*.

## Full Paradigm

| Number     | Form        |
| ----------- | ----------- |
| Singular     | difícil     |
| Plural       | difíciles   |

## Examples

| Spanish                              | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| El problema es difícil.                          | The problem is difficult.                     | masculine singular                 |
| Las decisiones fueron difíciles.                 | The decisions were difficult.                 | feminine plural                    |
| ¿Te parece difícil el idioma?                    | Does the language seem difficult to you?      | masculine singular, question       |
| No fue difícil encontrar la casa.                | It wasn't difficult to find the house.        | negation                          |
| Enfrentaron tiempos difíciles.                   | They faced difficult times.                   | masculine plural                   |
