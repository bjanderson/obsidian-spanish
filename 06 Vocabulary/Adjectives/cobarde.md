# cobarde

## Meaning

*Cobarde* means "cowardly." It has the same form for masculine and
feminine — it only changes for number: *cobarde*, *cobardes*.

## Full Paradigm

| Number     | Form       |
| ----------- | ---------- |
| Singular     | cobarde    |
| Plural       | cobardes   |

## Examples

| Spanish                                | English                                  | Notes                     |

| Su respuesta fue cobarde.                  | His response was cowardly.                     | singular                      |
| Los soldados no eran cobardes.             | The soldiers weren't cowardly.                 | plural, negation                |
