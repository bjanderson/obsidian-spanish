# importante

## Meaning

*Importante* means "important." It has the same form for masculine and
feminine — it only changes for number: *importante*, *importantes*.

## Full Paradigm

| Number     | Form          |
| ----------- | ------------- |
| Singular     | importante    |
| Plural       | importantes   |

## Examples

| Spanish                                    | English                                | Notes                       |
| -------------------------------------------------- | ---------------------------------------------- | --------------------------------- |
| Es una decisión importante.                          | It's an important decision.                      | feminine singular                  |
| ¿Es importante llegar temprano?                      | Is it important to arrive early?                 | question                          |
| No fue tan importante como pensamos.                 | It wasn't as important as we thought.            | negation                          |
| Los detalles importantes están en el contrato.       | The important details are in the contract.       | masculine plural                   |
| Tenemos varias reuniones importantes esta semana.    | We have several important meetings this week.    | feminine plural                    |
