# nacional

## Meaning

*Nacional* means "national." It has the same form for masculine and
feminine — it only changes for number: *nacional*, *nacionales*.

## Full Paradigm

| Number     | Form         |
| ----------- | ------------ |
| Singular     | nacional     |
| Plural       | nacionales   |

## Examples

| Spanish                                     | English                                | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| Es un símbolo nacional importante.               | It's an important national symbol.             | masculine singular                 |
| ¿Es este un feriado nacional?                    | Is this a national holiday?                    | question                          |
| No es un problema solo nacional.                 | It isn't only a national problem.              | negation                          |
| Los equipos nacionales compiten este mes.        | The national teams compete this month.         | masculine plural                   |
| Las noticias nacionales dominan la prensa hoy.   | National news dominates the press today.       | feminine plural                    |
