# firme

## Meaning

*Firme* means "firm" — physically solid and steady (*el suelo firme*, "firm
ground") or figuratively unwavering (*una decisión firme*, "a firm
decision"; *mantenerse firme*, "to stand firm"). It has the same form for
masculine and feminine — it only changes for number: *firme*, *firmes*.
Don't confuse it with [[fijo-fija-fijos-fijas|fijo]], a near-synonym that
means "fixed in place" rather than "solid/unwavering" — a *precio fijo* is a
set price, while a *decisión firme* is a resolute one.
