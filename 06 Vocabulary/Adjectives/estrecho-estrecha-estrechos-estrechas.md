# estrecho / estrecha / estrechos / estrechas

## Meaning

*Estrecho* means "narrow." It agrees in gender and number: *estrecho*,
*estrecha*, *estrechos*, *estrechas*.

## Full Paradigm

| Gender / Number    | Form      |
| ------------------- | --------- |
| Masculine singular   | estrecho  |
| Feminine singular    | estrecha  |
| Masculine plural     | estrechos |
| Feminine plural      | estrechas |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El pasillo es estrecho.                          | The hallway is narrow.                     | masculine singular                 |
| La calle es estrecha.                            | The street is narrow.                      | feminine singular                  |
| ¿Es estrecho el puente?                          | Is the bridge narrow?                      | masculine singular, question       |
| No es tan estrecha la habitación.                | The room isn't that narrow.                | feminine singular, negation        |
| Los caminos estrechos dificultan el tráfico.     | Narrow roads make traffic difficult.       | masculine plural                   |
