# diferente

## Meaning

*Diferente* means "different." It has the same form for masculine and
feminine — it only changes for number: *diferente*, *diferentes*.

## Full Paradigm

| Number     | Form          |
| ----------- | ------------- |
| Singular     | diferente     |
| Plural       | diferentes    |

## Examples

| Spanish                                | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| Este plato es diferente al de ayer.              | This dish is different from yesterday's.      | masculine singular, "al" contraction |
| ¿Notas algo diferente aquí?                      | Do you notice something different here?       | question                          |
| No es tan diferente como parece.                 | It isn't as different as it seems.            | negation                          |
| Tienen gustos muy diferentes.                    | They have very different tastes.              | masculine plural                   |
| Probamos varias recetas diferentes.              | We tried several different recipes.           | feminine plural                    |
