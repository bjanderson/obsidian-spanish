# gris

## Meaning

*Gris* means "gray." It has the same form for masculine and feminine — it
only changes for number: *gris*, *grises*.

## Full Paradigm

| Number     | Form    |
| ----------- | ------- |
| Singular     | gris    |
| Plural       | grises  |
