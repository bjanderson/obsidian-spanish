# negro / negra / negros / negras

## Meaning

*Negro* means "black." It agrees in gender and number: *negro*, *negra*,
*negros*, *negras*.

## Full Paradigm

| Gender / Number    | Form   |
| ------------------- | ------ |
| Masculine singular   | negro  |
| Feminine singular    | negra  |
| Masculine plural     | negros |
| Feminine plural      | negras |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El carro es negro.                               | The car is black.                          | masculine singular                 |
| Tiene una gata negra.                            | She has a black cat.                       | feminine singular                  |
| ¿Compraste los zapatos negros?                   | Did you buy the black shoes?               | masculine plural, question         |
| Las nubes negras anunciaban tormenta.            | The black clouds announced a storm.        | feminine plural                    |
| No me gusta el café negro.                       | I don't like black coffee.                 | masculine singular, negation       |
