# imposible

## Meaning

*Imposible* means "impossible." It has the same form for masculine and
feminine — it only changes for number: *imposible*, *imposibles*.

## Full Paradigm

| Number     | Form         |
| ----------- | ------------ |
| Singular     | imposible    |
| Plural       | imposibles   |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| Es imposible terminar hoy.                       | It's impossible to finish today.           | singular, impersonal               |
| Eran condiciones imposibles.                     | They were impossible conditions.           | plural                            |
| ¿Es imposible cambiar la fecha?                  | Is it impossible to change the date?       | question                          |
| No es imposible, solo difícil.                   | It isn't impossible, just difficult.       | negation                          |
| Enfrentaron retos imposibles.                    | They faced impossible challenges.          | plural                            |
