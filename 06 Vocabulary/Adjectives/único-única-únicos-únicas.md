# único / única / únicos / únicas

## Meaning

*Único* means "only" (before a noun) or "unique" (after a noun). It agrees
in gender and number: *único*, *única*, *únicos*, *únicas*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | único   |
| Feminine singular    | única   |
| Masculine plural     | únicos  |
| Feminine plural      | únicas  |

## Examples

| Spanish                                | English                                | Notes                       |
| --------------------------------------------- | ---------------------------------------------- | --------------------------------- |
| Es hijo único.                                   | He's an only child.                              | masculine singular, "only" sense    |
| ¿Es esta pieza única?                            | Is this piece unique?                            | feminine singular, question         |
| No fueron los únicos en llegar tarde.            | They weren't the only ones to arrive late.       | masculine plural, negation          |
| Estas son las únicas opciones que quedan.        | These are the only options left.                 | feminine plural                    |
| Tiene un estilo único.                           | She has a unique style.                          | masculine singular, "unique" sense   |
