# fresco / fresca / frescos / frescas

## Meaning

*Fresco* means "fresh" (food that hasn't spoiled) or "cool" (a mild,
pleasant temperature). It agrees in gender and number: *fresco*,
*fresca*, *frescos*, *frescas*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | fresco  |
| Feminine singular    | fresca  |
| Masculine plural     | frescos |
| Feminine plural      | frescas |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El pescado está fresco.                          | The fish is fresh.                         | masculine singular                 |
| La brisa era fresca.                             | The breeze was cool.                       | feminine singular                  |
| ¿Está fresco el pan?                             | Is the bread fresh?                        | masculine singular, question       |
| No encontramos verduras frescas.                 | We didn't find fresh vegetables.           | feminine plural, negation          |
| Prefiero los días frescos de otoño.              | I prefer cool autumn days.                 | masculine plural                   |
