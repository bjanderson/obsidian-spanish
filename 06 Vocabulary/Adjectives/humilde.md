# humilde

## Meaning

*Humilde* means "humble" — modest about one's own importance — or, describing
circumstances, "poor/modest" (*una familia humilde*, "a humble/poor family"). It has
the same form for masculine and feminine — it only changes for number: *humilde*,
*humildes*.

## Full Paradigm

| Number     | Form       |
| ----------- | ---------- |
| Singular     | humilde    |
| Plural       | humildes   |
