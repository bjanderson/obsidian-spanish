# moderno / moderna / modernos / modernas

## Meaning

*Moderno* means "modern" — up to date in style, design, or technology. It
agrees in gender and number: *moderno*, *moderna*, *modernos*, *modernas*.

## Full Paradigm

| Gender / Number    | Form      |
| ------------------- | --------- |
| Masculine singular   | moderno   |
| Feminine singular    | moderna   |
| Masculine plural     | modernos  |
| Feminine plural      | modernas  |

## Examples

| Spanish                                       | English                                     | Notes                       |
| ------------------------------------------------ | ---------------------------------------------- | ---------------------------------- |
| El edificio es moderno.                            | The building is modern.                        | masculine singular                 |
| La cocina es muy moderna.                          | The kitchen is very modern.                    | feminine singular                  |
| ¿Te gustan los muebles modernos?                   | Do you like the modern furniture?              | masculine plural, question         |
| No compraron las computadoras modernas todavía.    | They haven't bought the modern computers yet.  | feminine plural, negation          |
| Construyeron una ciudad moderna cerca del río.     | They built a modern city near the river.       | feminine singular, *del*           |
