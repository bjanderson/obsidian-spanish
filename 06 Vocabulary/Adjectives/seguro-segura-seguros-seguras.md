# seguro / segura / seguros / seguras

## Meaning

*Seguro* means "safe" (a place free of danger) or "sure/certain" (*estoy
seguro*, "I'm sure"). It agrees in gender and number: *seguro*, *segura*,
*seguros*, *seguras*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | seguro  |
| Feminine singular    | segura  |
| Masculine plural     | seguros |
| Feminine plural      | seguras |

## Examples

| Spanish                              | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| El barrio es seguro.                             | The neighborhood is safe.                     | masculine singular, "safe"         |
| ¿Estás seguro de eso?                            | Are you sure about that?                      | masculine singular, "sure," question |
| No es segura esa inversión.                      | That investment isn't safe.                   | feminine singular, negation        |
| Instalaron cerraduras seguras en la puerta.      | They installed secure locks on the door.      | feminine plural                    |
| Buscan rutas seguras para caminar de noche.      | They look for safe routes to walk at night.   | feminine plural                    |
