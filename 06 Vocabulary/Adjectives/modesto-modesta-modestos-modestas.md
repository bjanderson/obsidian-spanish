# modesto / modesta / modestos / modestas

## Meaning

*Modesto* means "modest" — not boastful about one's own achievements — or, describing
things, "simple/unpretentious" (*una casa modesta*, "a modest house"). It agrees in
gender and number: *modesto*, *modesta*, *modestos*, *modestas*.

## Full Paradigm

| Gender / Number    | Form        |
| ------------------ | ----------- |
| Masculine singular  | modesto     |
| Feminine singular   | modesta     |
| Masculine plural    | modestos    |
| Feminine plural     | modestas    |
