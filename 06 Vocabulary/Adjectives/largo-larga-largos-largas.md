# largo / larga / largos / largas

## Meaning

*Largo* means "long" (length or duration) — a false friend, since it does
not mean "large" in the size sense (that's *grande*). It agrees in gender
and number: *largo*, *larga*, *largos*, *largas*.

## Full Paradigm

| Gender / Number    | Form    |
| ------------------- | ------- |
| Masculine singular   | largo   |
| Feminine singular    | larga   |
| Masculine plural     | largos  |
| Feminine plural      | largas  |

## Examples

| Spanish                                | English                              | Notes                       |
| --------------------------------------------- | -------------------------------------------- | --------------------------------- |
| El viaje fue muy largo.                          | The trip was very long.                       | masculine singular                 |
| ¿Es larga la película?                           | Is the movie long?                            | feminine singular, question         |
| No fue un discurso largo.                        | It wasn't a long speech.                      | negation                          |
| Tiene el pelo largo.                             | She has long hair.                            | masculine singular                 |
| Las filas eran muy largas hoy.                   | The lines were very long today.               | feminine plural                    |
