# justo / justa / justos / justas

## Meaning

*Justo* means "fair" or "just." It agrees in gender and number: *justo*,
*justa*, *justos*, *justas*.

## Full Paradigm

| Gender / Number    | Form   |
| ------------------- | ------ |
| Masculine singular   | justo  |
| Feminine singular    | justa  |
| Masculine plural     | justos |
| Feminine plural      | justas |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El juez fue justo.                               | The judge was fair.                        | masculine singular                 |
| La decisión fue justa.                           | The decision was fair.                     | feminine singular                  |
| ¿Te parece justo el precio?                      | Does the price seem fair to you?           | masculine singular, question       |
| No fue un trato justo.                           | It wasn't a fair deal.                     | masculine singular, negation       |
| Buscan salarios justos para todos.               | They seek fair wages for everyone.         | masculine plural                   |
