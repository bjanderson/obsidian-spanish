# débil

## Meaning

*Débil* means "weak." It has the same form for masculine and feminine —
it only changes for number: *débil*, *débiles*.

## Full Paradigm

| Number     | Form      |
| ----------- | --------- |
| Singular     | débil     |
| Plural       | débiles   |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El paciente está débil.                          | The patient is weak.                       | singular                          |
| Sus piernas se sentían débiles.                  | Her legs felt weak.                        | plural                            |
| ¿Por qué te sientes tan débil?                   | Why do you feel so weak?                   | question                          |
| No es un argumento débil.                        | It isn't a weak argument.                  | negation                          |
| La señal del wifi está débil.                    | The wifi signal is weak.                   | singular, del contraction          |
