# honesto / honesta / honestos / honestas

## Meaning

*Honesto* means "honest." It agrees in gender and number: *honesto*,
*honesta*, *honestos*, *honestas*.

## Full Paradigm

| Gender / Number    | Form       |
| ------------------- | ---------- |
| Masculine singular   | honesto    |
| Feminine singular    | honesta    |
| Masculine plural     | honestos   |
| Feminine plural      | honestas   |
