# morado / morada / morados / moradas

## Meaning

*Morado* means "purple." It agrees in gender and number: *morado*,
*morada*, *morados*, *moradas*. It's also the common word for a "bruise"
color (*tenía la rodilla morada*, "her knee was bruised").

## Full Paradigm

| Gender / Number    | Form     |
| ------------------- | -------- |
| Masculine singular   | morado   |
| Feminine singular    | morada   |
| Masculine plural     | morados  |
| Feminine plural      | moradas  |
