# fácil

## Meaning

*Fácil* means "easy" or "simple." It has the same form for masculine and
feminine — it only changes for number: *fácil*, *fáciles*.

## Full Paradigm

| Number     | Form      |
| ----------- | --------- |
| Singular     | fácil     |
| Plural       | fáciles   |

## Examples

| Spanish                              | English                          | Notes                       |
| --------------------------------------------- | ----------------------------------------- | --------------------------------- |
| El examen fue fácil.                             | The exam was easy.                         | masculine singular                 |
| Las preguntas eran fáciles.                      | The questions were easy.                   | feminine plural                    |
| ¿Es fácil este juego?                            | Is this game easy?                         | masculine singular, question       |
| No fue tan fácil como pensaba.                   | It wasn't as easy as I thought.            | negation                          |
| Buscamos soluciones fáciles.                     | We're looking for easy solutions.          | feminine plural                    |
