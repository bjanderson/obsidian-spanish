# simple

## Meaning

*Simple* means "simple" or "uncomplicated." It has the same form for
masculine and feminine — it only changes for number: *simple*, *simples*.
Position can shift the sense: after the noun (its more common spot) it means
"uncomplicated"; before the noun it means "mere" or "just a," as in *una
simple pregunta* ("just a simple question").

## Full Paradigm

| Number   | Form    |
| -------- | ------- |
| Singular | simple  |
| Plural   | simples |

| Spanish                                        | English                                     | Notes                     |
