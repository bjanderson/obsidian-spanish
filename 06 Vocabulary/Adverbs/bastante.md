# bastante

## Meaning

*Bastante* works as both an adverb and an adjective/quantifier, and it never changes
for gender — only for number. As an **adverb**, it's completely invariable and means
"quite/rather" before an adjective, or "enough" after a verb: *Es bastante
interesante* ("It's quite interesting"), *No dormí bastante* ("I didn't sleep
enough"). As an **adjective/quantifier** before a noun, it means "enough," and only
the plural form changes: *bastante* (singular, both genders) / *bastantes* (plural,
both genders) — *bastante dinero* ("enough money"), *bastantes problemas* ("enough
problems").

## Core Uses

| Use                       | Pattern                | Example                        | English                        |
| ---------------------------- | ------------------------ | ---------------------------------- | ----------------------------------- |
| Adverb, before adjective         | bastante + adjective         | Es bastante fácil.                    | It's quite easy.                       |
| Adverb, after verb                    | verb + bastante                    | Ya comí bastante.                        | I already ate enough.                    |
| Adjective, singular                       | bastante + noun                          | Tengo bastante tiempo.                       | I have enough time.                         |
| Adjective, plural                              | bastantes + noun                              | Hay bastantes opciones.                          | There are quite a few options.                 |
