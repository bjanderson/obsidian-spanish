# no

## Meaning

*No* is invariant and does two jobs: standing alone as "no" (answering a question),
and placed right before a verb to negate it, like English "not" — but unlike
English, Spanish doesn't need a helper verb ("do/does") to negate: *No entiendo*
("I don't understand"), not *"I do not understand"* word-for-word.

## Core Uses

| Use                   | Pattern                    | Example                    | English                        |
| ------------------------ | ------------------------------- | -------------------------------- | ------------------------------------ |
| Standalone answer            | ¿...? — No.                       | ¿Vienes? — No.                    | Are you coming? — No.                  |
| Verb negation                  | no + [verb]                         | No quiero salir.                  | I don't want to go out.                |
| Tag question                     | [statement], ¿no?                     | Hace frío, ¿no?                   | It's cold, isn't it?                    |
| Double negative (grammatical)       | no + [verb] + nada/nadie/nunca          | No como nada.                     | I don't eat anything.                   |
