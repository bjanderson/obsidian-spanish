# poco

## Meaning

As an adverb, *poco* means "not much" or "little" — it modifies a verb or
adjective and never changes form: *Duerme poco* ("She doesn't sleep much"),
*Es poco probable* ("It's not very likely"). As an adjective, it agrees in
gender and number with the noun it describes — *poco*, *poca*, *pocos*,
*pocas* — and means "little" or "few": *poco dinero* ("little money"), *pocas
personas* ("few people").

*Un poco* (always this exact phrase, invariable) means "a little," a small but
real amount — the opposite sense from plain *poco*: *Habla un poco de
español* ("He speaks a little Spanish").

## Full Paradigm (adjective use)

| Gender / Number   | Form  |
| -------------------- | ------- |
| Masculine singular      | poco    |
| Feminine singular        | poca    |
| Masculine plural           | pocos   |
| Feminine plural              | pocas   |
