# lentamente

## Meaning

*Lentamente* means "slowly" — the *-mente* adverb from *lento/lenta* ("slow,"
adjective). It's near-synonymous with [[despacio]] but sits in a more formal or
descriptive register (narration, writing, careful speech), while *despacio* is the
go-to word in everyday commands and casual conversation. Opposite of [[rápidamente]].

## Examples

| Spanish                                      | English                                  | Notes            |
| ------------------------------------------------ | --------------------------------------------- | ------------------ |
| El sol se ponía lentamente detrás de las montañas. | The sun set slowly behind the mountains.   | description           |
| La economía se recupera lentamente.               | The economy is recovering slowly.            | description           |
| Leyó la carta lentamente, palabra por palabra.    | She read the letter slowly, word by word.    | description           |
| El río corre lentamente en esta parte.            | The river flows slowly in this part.         | description           |
| Todo cambió lentamente después de la mudanza.     | Everything changed slowly after the move.    | description           |

## Related Vocabulary

- [[despacio]] — near-synonym, more colloquial/spoken register.
- [[rápidamente]] — opposite, "quickly."
