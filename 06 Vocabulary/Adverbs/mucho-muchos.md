# mucho / muchos

## Meaning

*Mucho* has two jobs. As an invariable adverb, it means "a lot," modifying a
verb or adjective and never changing form: *Estudia mucho* ("She studies a
lot"), *Es mucho mejor* ("It's a lot better"). As an adjective, it agrees in
gender and number with the noun it describes — *mucho*, *mucha*, *muchos*,
*muchas* — and means "a lot of" or "many": *mucho dinero* ("a lot of money"),
*muchas personas* ("many people").

## Full Paradigm (adjective use)

| Gender / Number   | Form   |
| -------------------- | -------- |
| Masculine singular      | mucho    |
| Feminine singular        | mucha    |
| Masculine plural           | muchos   |
| Feminine plural              | muchas   |
