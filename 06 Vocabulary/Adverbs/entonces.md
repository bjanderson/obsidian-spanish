# entonces

## Meaning

*Entonces* means "then" — either "at that time" (temporal) or "in that case/so"
(logical consequence, close to *así que*).

## Core Uses

| Use                              | Pattern                    | Example                                    | English                              |
| ------------------------------------ | -------------------------------- | -------------------------------------------------- | ------------------------------------------- |
| At that time (temporal)               | entonces + [past-tense verb]      | Entonces vivíamos en Lima.                          | At that time, we lived in Lima.              |
| Logical consequence ("so")            | ..., entonces + [clause]          | No estudiaste, entonces no aprobaste.               | You didn't study, so you didn't pass.        |

## Examples

| Spanish                                     | English                                          | Notes                        |
| ----------------------------------------------- | ------------------------------------------------------ | -------------------------------- |
| Entonces no sabíamos nada del problema.          | Back then we didn't know anything about the problem.     | temporal, negation                |
| Si no te gusta, entonces no lo compres.          | If you don't like it, then don't buy it.                 | consequence                       |
| ¿Entonces qué hacemos ahora?                     | So what do we do now?                                     | question                          |
| No llegó a tiempo; entonces empezamos sin él.    | He didn't arrive on time, so we started without him.     | consequence                       |
| Entonces era estudiante, no profesor.            | Back then he was a student, not a teacher.                | temporal                          |
