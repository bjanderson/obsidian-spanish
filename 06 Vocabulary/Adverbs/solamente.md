# solamente

## Meaning

*Solamente* means "only" — it restricts a statement to a single thing, exactly like
*solo* used as an adverb. The two are interchangeable; *solamente* is a bit more
common in careful or written speech, while *solo* is the everyday, conversational
default.

## Examples

| Spanish                                       | English                              | Notes                     |
| ------------------------------------------------- | ----------------------------------------- | ------------------------------ |
| Solamente quiero un café, gracias.                | I only want a coffee, thanks.               | before a noun phrase              |
| Tenemos solamente dos días para terminar el proyecto. | We only have two days to finish the project. | restricting a quantity            |
| Puedes entrar solamente con una identificación válida. | You can only enter with a valid ID.          | restricting a condition            |
| Solamente él sabe la verdad.                       | Only he knows the truth.                      | restricting the subject              |
| No fue solamente un error, fue una decisión.       | It wasn't only a mistake, it was a decision. | negative contrast                    |
