# principalmente

## Meaning

*Principalmente* means "mainly" or "primarily" — it identifies the main reason,
cause, or element among several, rather than singling out a notable exception (that's
[[especialmente]]).

## Usage Notes

- Formed from the adjective *principal* + *-mente*. No standalone vocabulary file
  exists yet for *principal* in `06 Vocabulary/Adjectives/`.
- Common when answering "why" with a short reason: *¿Por qué...? Principalmente
  por/para...*.

## Examples

| Spanish                                            | English                                     | Notes           |
| ------------------------------------------------------ | ----------------------------------------------- | -------------------- |
| Trabajo principalmente desde casa.                        | I work mainly from home.                          | after the verb       |
| El curso está dirigido principalmente a principiantes.     | The course is aimed mainly at beginners.           | before *a*             |
| Vine principalmente para verte a ti.                        | I came mainly to see you.                          | before *para*          |
| ¿Por qué te mudaste? Principalmente por el trabajo.          | Why did you move? Mainly because of work.          | short answer          |
| El problema fue principalmente la falta de tiempo.           | The problem was mainly the lack of time.           | with *ser*             |

## Related Vocabulary

- [[especialmente]] — related, but marks a notable exception rather than the main cause
- [[finalmente]] — another discourse-organizing adverb, marks the last point instead of the main one
