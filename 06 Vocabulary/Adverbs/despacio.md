# despacio

## Meaning

*Despacio* means "slowly" — the everyday, spoken-register word for an unhurried pace,
especially common in commands and requests (*Habla más despacio, por favor*, "Speak more
slowly, please"). It's near-synonymous with [[lentamente]], but *despacio* is the more
colloquial, conversational choice, while *lentamente* leans more descriptive and written.
Contrasts with [[rápidamente]] ("quickly").

## Examples

| Spanish                                     | English                                | Notes                    |
| ---------------------------------------------- | ------------------------------------------- | --------------------------- |
| Maneja despacio, está lloviendo.               | Drive slowly, it's raining.                 | command                       |
| ¿Puedes repetirlo más despacio?                | Can you repeat that more slowly?            | request                       |
| El anciano caminaba despacio por el parque.    | The old man walked slowly through the park. | description                   |
| Vamos despacio, no hay prisa.                  | Let's go slowly, there's no rush.           | suggestion                    |
| Despacio y con cuidado, terminamos el trabajo. | Slowly and carefully, we finished the job.  | description                   |

## Related Vocabulary

- [[rápidamente]] — opposite, "quickly."
