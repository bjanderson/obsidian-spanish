# bien

## Meaning

*Bien* means "well" — describing how an action is done — or "fine/good" describing a
state (*estar bien*, "to be fine"). Invariable. Don't confuse it with the adjective
*bueno* ("good"), which agrees with a noun; *bien* modifies a verb, adjective, or
whole sentence instead.

## Examples

| Spanish                             | English                            | Notes                        |
| -------------------------------------- | --------------------------------------- | -------------------------------- |
| Ella canta muy bien.                    | She sings very well.                     | manner                            |
| ¿Cómo estás? — Estoy bien, gracias.     | "How are you?" "I'm fine, thanks."       | state                             |
| No dormí bien anoche.                   | I didn't sleep well last night.          | negation                          |
| Todo salió bien al final.               | Everything turned out well in the end.   | statement                         |
| ¿Hiciste bien la tarea?                 | Did you do the homework well?            | question                          |
