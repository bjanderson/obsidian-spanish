# aquí

## Meaning

*Aquí* means "here," referring to the speaker's location. The close synonym *acá* is
more common in some regions for movement toward the speaker (*ven acá*, "come here"),
while *aquí* is the neutral, standard form used throughout this vault.

## Examples

| Spanish                                | English                                | Notes                        |
| ------------------------------------------ | ------------------------------------------- | -------------------------------- |
| Vivo aquí desde hace cinco años.            | I've lived here for five years.              | statement                         |
| ¿Puedes venir aquí un momento?              | Can you come here for a moment?              | question                          |
| Aquí no se permite fumar.                   | Smoking isn't allowed here.                  | statement                         |
| Deja el paquete aquí, por favor.            | Leave the package here, please.              | command                           |
| No hay nadie aquí.                          | There's no one here.                         | negation                          |
