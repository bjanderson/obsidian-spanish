# nunca

## Meaning

*Nunca* means "never" — total negation in time. Placed before the verb, it needs no
extra negation: *Nunca voy al gimnasio* ("I never go to the gym"). Placed after the
verb, Spanish requires *no* before the verb as well: *No voy nunca al gimnasio* — a
standard double-negative construction, not an error. It combines with *casi* for
"almost never" (*casi nunca*) and pairs naturally with *tampoco* when adding a second
negative statement.

## Core Uses

| Use                          | Pattern             | Example                       | English                      |
| ----------------------------- | -------------------- | ------------------------------- | ------------------------------- |
| Simple negation, before verb  | nunca + verb          | Nunca como carne.                | I never eat meat.                |
| Simple negation, after verb   | no + verb ... nunca   | No como carne nunca.             | I never eat meat.                |
| Almost never                  | casi nunca            | Casi nunca llueve aquí.          | It almost never rains here.      |
| Never again / ever (emphatic) | nunca más             | No lo voy a hacer nunca más.     | I'm never going to do it again.  |
