# ya

## Meaning

*Ya* is invariant and shifts meaning with tense and context: "already" with a
completed action, "now"/"anymore" with a negative, and "right away" in a command or
urgent request.

## Core Uses

| Use                     | Pattern                | Example                    | English                        |
| --------------------------- | ---------------------------- | -------------------------------- | ------------------------------------ |
| Already (completed action)        | ya + [past-tense verb]          | Ya comí.                          | I already ate.                        |
| Now/anymore (with negation)          | ya no + [verb]                    | Ya no vive aquí.                  | He doesn't live here anymore.          |
| Right away (urgency)                    | ¡Ya!                                | ¡Hazlo ya!                        | Do it right now!                       |
| Now (in progress)                          | ya + [present-tense verb]             | Ya voy.                           | I'm coming (now).                      |

## Examples

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| ¿Ya terminaste la tarea?                    | Have you already finished the homework?  | already, question                 |
| Ya no trabajo en esa empresa.               | I don't work at that company anymore.    | now/anymore with negation          |
| ¡Ya voy, un momento!                        | I'm coming, one moment!                  | now (in progress)                  |
| Ya era tarde cuando llegamos.               | It was already late when we arrived.     | already, past context              |
| Termina eso ya, por favor.                  | Finish that right away, please.          | urgency                            |
