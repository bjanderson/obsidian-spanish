# así

## Meaning

*Así* means "like this/like that, this way" — describing manner or degree. As a
connector, *así que* means "so, therefore" (introducing a consequence), and
*así como* means "as well as, just as" (introducing a comparison).

## Core Uses

| Use                              | Pattern                | Example                              | English                                |
| ------------------------------------ | --------------------------- | ------------------------------------------- | --------------------------------------------- |
| Manner ("like this/that")             | así + [verb/description]     | Hazlo así.                                    | Do it like this.                               |
| Consequence ("so, therefore")         | así que + [clause]           | Llovía, así que no salimos.                   | It was raining, so we didn't go out.           |
| Comparison ("just as... also")        | así como + [noun/clause]     | Le gusta el café, así como el té.             | He likes coffee, just as he likes tea.         |

## Examples

| Spanish                                 | English                                    | Notes                        |
| ------------------------------------------- | ------------------------------------------------ | -------------------------------- |
| No sé por qué lo dijo así.                   | I don't know why he said it like that.            | manner                            |
| Así es como se hace.                         | This is how it's done.                            | manner                            |
| Estaba cansado, así que se acostó temprano.  | He was tired, so he went to bed early.            | consequence                       |
| ¿Siempre cocinas así?                        | Do you always cook like this?                     | question                          |
| No me hables así.                            | Don't talk to me like that.                       | negative command                  |
