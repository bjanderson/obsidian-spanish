# afortunadamente

## Meaning

*Afortunadamente* means "fortunately" or "luckily" — a sentence adverb expressing
relief that something turned out well. It's usually placed at the start of a
sentence, set off by a comma.

## Usage Notes

- Formed from the adjective *afortunado* + *-mente*. No standalone vocabulary file
  exists yet for *afortunado* in `06 Vocabulary/Adjectives/`.
- Synonym of [[felizmente]] when *felizmente* is used in its "fortunately" sense.

## Examples

| Spanish                                                | English                                         | Notes                |
| -------------------------------------------------------------- | ------------------------------------------------------ | -------------------------- |
| Afortunadamente, llegamos a tiempo al aeropuerto.                 | Fortunately, we arrived at the airport on time.           | sentence-initial            |
| El clima estuvo afortunadamente despejado todo el fin de semana.  | The weather was fortunately clear all weekend.            | mid-sentence                |
| Afortunadamente, nadie resultó herido en el choque.                | Fortunately, no one was hurt in the crash.                 | sentence-initial            |
| ¿Afortunadamente pudiste arreglar el auto?                          | Were you fortunately able to fix the car?                  | question                    |
| No fue fácil, pero afortunadamente todo salió bien.                 | It wasn't easy, but fortunately everything turned out fine. | after a contrast          |
