# hoy

## Meaning

*Hoy* is an invariable adverb meaning "today." It never changes form and doesn't
take an article. It shows up in fixed expressions like *hoy en día* ("nowadays,"
literally "today in day") and *hoy mismo* ("this very day," for emphasis).

## Examples

| Spanish                                | English                          | Notes                        |
| ------------------------------------------ | -------------------------------------- | --------------------------------- |
| Hoy tengo mucho trabajo.                    | Today I have a lot of work.            | statement                          |
| ¿Qué vamos a hacer hoy?                     | What are we going to do today?         | question                           |
| Hoy no llueve.                              | It's not raining today.                | negative                           |
| Hoy en día casi todos usan el celular.      | Nowadays almost everyone uses a cell phone. | fixed expression              |
| Voy a terminar el proyecto hoy mismo.       | I'm going to finish the project this very day. | emphatic                    |
