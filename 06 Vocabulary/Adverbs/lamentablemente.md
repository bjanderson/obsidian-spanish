# lamentablemente

## Meaning

*Lamentablemente* means "unfortunately" or "regrettably" — a sentence adverb that comments
on the whole statement that follows, usually placed at the start of the sentence and set
off by a comma. It comes from *lamentable* ("regrettable") + *-mente*.

## Examples

| Spanish                                        | English                                    | Notes                        |
| ----------------------------------------------- | ------------------------------------------- | ----------------------------- |
| Lamentablemente, no pudimos llegar a tiempo.     | Unfortunately, we couldn't arrive on time.  | clause-initial                |
| El vuelo, lamentablemente, fue cancelado.        | The flight was, unfortunately, canceled.    | mid-sentence                  |
| Lamentablemente no queda ninguna entrada disponible. | Unfortunately there are no tickets left. | no comma                      |
| ¿Vas a poder venir? — Lamentablemente, no.       | Will you be able to come? — Unfortunately, no. | short answer              |
| Lamentablemente, el paciente no mejoró.          | Unfortunately, the patient didn't improve.  | formal/serious register       |

## Related Vocabulary

- [[obviamente]], [[evidentemente]], [[ciertamente]] — other sentence-initial *-mente*
