# lujo

## Meaning

*Lujo* means "luxury" — something rich, extravagant, or not strictly necessary that
brings comfort or pleasure. It's a masculine noun, following the regular -o pattern.

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | el lujo    |
| Plural   | los lujos  |

## Examples

| Spanish                                              | English                                          | Notes                    |
| ----------------------------------------------------- | ------------------------------------------------- | -------------------------- |
| Este hotel es un verdadero lujo.                       | This hotel is a real luxury.                       | subject                     |
| No podemos permitirnos esos lujos.                     | We can't afford those luxuries.                    | plural, direct object       |
| Viajar en primera clase es un lujo que pocos pueden pagar. | Flying first class is a luxury few can afford.     | relative clause              |
| ¿Consideras el café importado un lujo o una necesidad?  | Do you consider imported coffee a luxury or a necessity? | question                  |
| Los lujos no traen la felicidad por sí solos.          | Luxuries don't bring happiness by themselves.      | plural, subject              |
