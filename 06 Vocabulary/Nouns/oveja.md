# oveja

## Meaning

*Oveja* means "sheep." It's feminine: *la oveja*.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la oveja    |
| Plural   | las ovejas  |

## Examples

| Spanish                                | English                              | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| La oveja se quedó cerca del corral.              | The sheep stayed near the pen.                | statement                             |
| ¿Cuántas ovejas tienen en el campo?              | How many sheep do they have in the field?     | question                              |
| No encontramos a la oveja perdida.               | We didn't find the lost sheep.                | negation, personal *a*                 |
| Las ovejas de esta región dan buena lana.        | The sheep in this region give good wool.      | plural                                 |
| El perro guio a las ovejas hacia el establo.     | The dog led the sheep toward the barn.        | statement, personal *a*                |
