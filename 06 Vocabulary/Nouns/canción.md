# canción

## Meaning

*Canción* means "song." It's a feminine noun.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | la canción    |
| Plural   | las canciones |

## Examples

| Spanish                                 | English                             | Notes         |
| ---------------------------------------------- | ------------------------------------------ | ----------------- |
| Esta canción me encanta.                         | I love this song.                           | statement          |
| ¿Quién escribió esa canción?                     | Who wrote that song?                        | question           |
| No conozco la canción que están tocando.         | I don't know the song they're playing.      | negation           |
| Cantamos varias canciones en la fiesta.          | We sang several songs at the party.         | plural             |
| Bailamos al ritmo de la canción.                 | We danced to the song's rhythm.             | statement          |
