# lluvia

## Meaning

*Lluvia* means "rain." It's a feminine noun, mostly used in the singular.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la lluvia    |
| Plural   | las lluvias  |

## Examples

| Spanish                                 | English                              | Notes         |
| ------------------------------------------------ | ------------------------------------------- | ----------------- |
| La lluvia empezó de repente.                        | The rain started suddenly.                   | statement          |
| ¿Va a haber lluvia mañana?                          | Is it going to rain tomorrow?                | question           |
| No salimos por la lluvia.                           | We didn't go out because of the rain.        | negation           |
| Las lluvias de esta temporada fueron muy fuertes.   | This season's rains were very heavy.         | plural             |
| Caminamos bajo la lluvia sin paraguas.              | We walked in the rain without an umbrella.   | statement          |
