# nación

## Meaning

*Nación* means "nation," a country and its people. It's a feminine noun.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la nación    |
| Plural   | las naciones |

## Examples

| Spanish                                 | English                              | Notes         |
| ------------------------------------------------ | ------------------------------------------- | ----------------- |
| Esta nación tiene una historia muy larga.           | This nation has a very long history.         | statement          |
| ¿Qué nación ganó más medallas?                      | Which nation won the most medals?            | question           |
| No representa a toda la nación.                     | He doesn't represent the whole nation.       | negation, personal a |
| Las Naciones Unidas se reunieron ayer.              | The United Nations met yesterday.            | plural, proper noun |
| Se declaró la independencia de la nación.           | The nation's independence was declared.      | statement, de      |
