# juego

## Meaning

*Juego* means "game" or "play," and also a matching "set" of things (like
a set of tools). It's a masculine noun.

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | el juego   |
| Plural   | los juegos |

## Examples

| Spanish                                  | English                             | Notes             |
| ----------------------------------------------- | ------------------------------------------ | --------------------- |
| Los niños inventaron un juego nuevo.              | The kids invented a new game.               | statement              |
| ¿Conoces este juego de mesa?                      | Do you know this board game?                | question               |
| No entiendo las reglas del juego.                 | I don't understand the game's rules.        | negation, del          |
| Compré un juego de sábanas nuevo.                 | I bought a new set of sheets.               | secondary sense        |
| Los juegos olímpicos empiezan en julio.           | The Olympic games start in July.            | plural                 |
