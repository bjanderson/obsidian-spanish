# realidad

## Meaning

*Realidad* means "reality," the actual state of things. It's a feminine
noun.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | la realidad   |
| Plural   | las realidades |

## Examples

| Spanish                                   | English                              | Notes         |
| ---------------------------------------------- | ------------------------------------------- | ----------------- |
| La realidad es más difícil de lo que pensaba.    | Reality is harder than I thought.            | statement          |
| ¿Aceptas la realidad de la situación?            | Do you accept the reality of the situation?  | question           |
| No quiero enfrentar esa realidad.                | I don't want to face that reality.           | negation           |
| Las realidades de cada país son distintas.       | Each country's realities are different.      | plural             |
| En realidad, nunca fuimos a esa fiesta.          | Actually, we never went to that party.       | idiomatic phrase   |
