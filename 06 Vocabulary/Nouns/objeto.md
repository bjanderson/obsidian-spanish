# objeto

## Meaning

*Objeto* means "object," a physical thing, or the purpose/goal of an
action. It's a masculine noun.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | el objeto   |
| Plural   | los objetos |

## Examples

| Spanish                                   | English                             | Notes         |
| ---------------------------------------------- | ------------------------------------------- | ----------------- |
| Encontré un objeto extraño en el jardín.         | I found a strange object in the garden.      | statement          |
| ¿Qué objeto es ese?                              | What object is that?                         | question           |
| No toques ese objeto sin permiso.                | Don't touch that object without permission.  | negation, command  |
| Los objetos de valor están en la caja fuerte.    | The valuable objects are in the safe.        | plural             |
| El objeto de la reunión es resolver el problema. | The meeting's purpose is to solve the problem. | secondary sense  |
