# museo

## Meaning

*Museo* means "museum" — a building where art, historical, or scientific
objects are displayed. It's masculine: *el museo*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el museo     |
| Plural   | los museos   |

## Examples

| Spanish                                              | English                                        | Notes                        |
| ---------------------------------------------------------- | ----------------------------------------------------- | -------------------------------- |
| Visitamos el museo de arte moderno.                        | We visited the modern art museum.                     | singular, direct object          |
| Llevé a los niños al museo el sábado.                      | I took the kids to the museum on Saturday.             | singular, personal *a*, *al* contraction |
| ¿Cuánto cuesta la entrada al museo?                        | How much does admission to the museum cost?            | singular, question, *al* contraction |
| No permiten tomar fotos dentro del museo.                  | They don't allow taking photos inside the museum.      | singular, negation, *del* contraction |
| Esta ciudad tiene varios museos interesantes.              | This city has several interesting museums.             | plural, direct object             |
