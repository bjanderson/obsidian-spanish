# otoño

## Meaning

*Otoño* means "autumn" or "fall." It's masculine: *el otoño*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el otoño     |
| Plural   | los otoños   |

## Examples

| Spanish                                  | English                              | Notes                    |
| ---------------------------------------------- | ------------------------------------------ | ------------------------------ |
| Las hojas caen en otoño.                        | Leaves fall in autumn.                     | statement                      |
| ¿Prefieres el otoño o la primavera?             | Do you prefer autumn or spring?            | question                       |
| No hizo tanto frío este otoño.                  | It wasn't that cold this autumn.           | negation                       |
| Los otoños en las montañas son hermosos.        | Autumns in the mountains are beautiful.    | plural                         |
| Empezamos clases al comienzo del otoño.         | We start classes at the start of autumn.   | statement                      |

## Related Vocabulary
