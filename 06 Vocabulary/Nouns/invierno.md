# invierno

## Meaning

*Invierno* means "winter." It's masculine: *el invierno*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el invierno    |
| Plural   | los inviernos  |

## Examples

| Spanish                                  | English                                 | Notes                    |
| ---------------------------------------------- | --------------------------------------------- | ------------------------------ |
| El invierno aquí es muy frío.                    | Winter here is very cold.                      | statement                      |
| ¿Nieva mucho en invierno?                        | Does it snow a lot in winter?                  | question                       |
| No salgo mucho durante el invierno.              | I don't go out much during winter.             | negation                       |
| Los inviernos pasados fueron más suaves.         | Past winters were milder.                      | plural                         |
| Nos quedamos en casa todo el invierno.           | We stayed home all winter.                     | statement                      |
