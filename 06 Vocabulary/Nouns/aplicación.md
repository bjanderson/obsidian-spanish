# aplicación

## Meaning

*Aplicación* means "application" or, casually, "app" — a program on a phone or
computer. It's a feminine noun. It also keeps the more formal English sense of
"application" as in a job or program application. The plural drops the accent
(*aplicaciones*) because the stress falls naturally on that syllable once another
syllable is added.

## Singular / Plural

| Number   | Form                |
| -------- | ------------------- |
| Singular | la aplicación        |
| Plural   | las aplicaciones      |
