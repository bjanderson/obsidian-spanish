# granja

## Meaning

*Granja* means "farm." It's feminine: *la granja*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la granja    |
| Plural   | las granjas  |

## Examples

| Spanish                                    | English                                 | Notes                    |
| -------------------------------------------------- | ---------------------------------------------- | ------------------------------ |
| Mi tío tiene una granja pequeña.                     | My uncle has a small farm.                      | statement                      |
| ¿Han visitado una granja alguna vez?                 | Have you all ever visited a farm?               | question                       |
| No hay vacas en esa granja.                          | There aren't any cows on that farm.             | negation                       |
| Las granjas de la región venden leche fresca.        | The farms in the region sell fresh milk.        | plural                          |
| Los niños dieron de comer a los animales de la granja. | The kids fed the farm animals.                | statement                       |
