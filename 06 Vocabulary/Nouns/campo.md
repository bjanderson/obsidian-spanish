# campo

## Meaning

*Campo* means "field" (a piece of land) or, more broadly, "the countryside"
as opposed to the city. It's masculine: *el campo*.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | el campo    |
| Plural   | los campos  |

## Examples

| Spanish                                   | English                                | Notes                          |
| -------------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| Mis abuelos viven en el campo.                        | My grandparents live in the countryside.       | statement, "countryside" sense         |
| ¿Prefieres la ciudad o el campo?                      | Do you prefer the city or the countryside?     | question                               |
| No sembramos nada en ese campo este año.              | We didn't plant anything in that field this year. | negation, "field" sense            |
| Los campos de esta zona producen mucho trigo.         | The fields in this area produce a lot of wheat. | plural, "field" sense                 |
| Pasamos el verano en el campo.                        | We spent the summer in the countryside.        | statement                              |
