# cerveza

## Meaning

*Cerveza* means "beer." It's feminine: *la cerveza*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la cerveza     |
| Plural   | las cervezas   |

## Examples

| Spanish                                 | English                              | Notes                          |
| ------------------------------------------------ | -------------------------------------------- | ------------------------------------ |
| La cerveza está bien fría.                         | The beer is nice and cold.                    | statement                             |
| ¿Tomamos una cerveza después del trabajo?          | Should we have a beer after work?             | question                              |
| No bebió cerveza en la fiesta.                     | He didn't drink beer at the party.            | negation                              |
| Las cervezas artesanales son populares ahora.      | Craft beers are popular now.                  | plural                                 |
| Pidieron dos cervezas para la mesa.                | They ordered two beers for the table.         | statement                              |
