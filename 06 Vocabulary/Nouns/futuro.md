# futuro

## Meaning

*Futuro* means "future," the time yet to come. It's a masculine noun,
almost always used in the singular.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el futuro    |
| Plural   | los futuros  |

## Examples

| Spanish                                    | English                              | Notes         |
| ----------------------------------------------- | ------------------------------------------- | ----------------- |
| Nadie sabe lo que trae el futuro.                | No one knows what the future holds.          | statement          |
| ¿Cómo ves el futuro de la empresa?               | How do you see the company's future?         | question, de       |
| No pienso mucho en el futuro.                    | I don't think much about the future.         | negation           |
| Los futuros posibles de esta industria varían.   | This industry's possible futures vary.       | plural, rare       |
| Estudia ingeniería para asegurar su futuro.      | She's studying engineering to secure her future. | statement      |
