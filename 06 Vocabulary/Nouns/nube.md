# nube

## Meaning

*Nube* means "cloud," both the weather phenomenon and, informally, digital
cloud storage. It's a feminine noun.

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | la nube    |
| Plural   | las nubes  |

## Examples

| Spanish                               | English                             | Notes             |
| ---------------------------------------------- | ------------------------------------------ | --------------------- |
| Esa nube tiene forma de perro.                   | That cloud is shaped like a dog.             | statement              |
| ¿Ves las nubes negras allá?                      | Do you see the dark clouds over there?       | question, plural       |
| No hay nubes en el cielo hoy.                    | There are no clouds in the sky today.        | negation               |
| Las nubes anuncian lluvia pronto.                | The clouds signal rain is coming soon.       | plural                 |
| Guardamos las fotos en la nube.                  | We saved the photos in the cloud.            | secondary sense        |
