# base

## Meaning

*Base* means "base" or "foundation," physical or conceptual. It's a
feminine noun.

## Singular / Plural

| Number   | Form      |
| -------- | --------- |
| Singular | la base   |
| Plural   | las bases |

## Examples

| Spanish                                  | English                              | Notes         |
| ----------------------------------------------- | ------------------------------------------- | ----------------- |
| La base del edificio se ve muy sólida.            | The building's base looks very solid.        | statement, del     |
| ¿Cuál es la base de tu argumento?                 | What's the basis of your argument?           | question, secondary sense |
| No tiene base científica esa idea.                | That idea has no scientific basis.           | negation           |
| Las bases del contrato son claras.                | The contract's terms are clear.              | plural, secondary sense |
| Construyeron la casa sobre una base firme.        | They built the house on a firm base.         | statement          |
