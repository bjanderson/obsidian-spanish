# semilla

## Meaning

*Semilla* means "seed." It's feminine: *la semilla*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la semilla   |
| Plural   | las semillas |

## Examples

| Spanish                                    | English                                | Notes                          |
| -------------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| Plantamos una semilla de aguacate.                   | We planted an avocado seed.                    | statement                             |
| ¿De dónde sacaste esa semilla?                       | Where did you get that seed?                   | question                              |
| No guardamos las semillas del tomate.                | We didn't save the tomato seeds.               | negation                              |
| Las semillas necesitan agua para germinar.           | Seeds need water to germinate.                 | plural                                 |
| El pájaro se comió todas las semillas.               | The bird ate all the seeds.                    | statement                              |
