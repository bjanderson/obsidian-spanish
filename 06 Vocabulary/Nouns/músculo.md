# músculo

## Meaning

*Músculo* means "muscle." It's masculine: *el músculo*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el músculo     |
| Plural   | los músculos   |

## Examples

| Spanish                                      | English                                | Notes                  |
| ------------------------------------------------ | -------------------------------------------- | ---------------------------- |
| Le duele el músculo de la pierna.            | His leg muscle hurts.                   | singular, subject, *de*        |
| Levantar pesas fortalece los músculos.       | Lifting weights strengthens the muscles. | plural, object                |
| ¿Sientes el músculo tenso?                   | Do you feel the muscle tense?           | question, singular             |
| No hagas ejercicio si tienes el músculo lastimado. | Don't exercise if your muscle is injured. | negative command         |
| Los músculos del corredor están muy definidos. | The runner's muscles are very defined. | plural, subject, *del*          |
