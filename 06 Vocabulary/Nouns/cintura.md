# cintura

## Meaning

*Cintura* means "waist." It's feminine: *la cintura*. Common in the idiom
*meter en cintura* ("to bring someone into line, discipline them").

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la cintura     |
| Plural   | las cinturas   |
