# tarea

## Meaning

*Tarea* means "task" in a work context, and "homework" in a school context —
which sense applies depends on the surrounding context.

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | la tarea        |
| Plural   | las tareas      |

## Examples

| Spanish                                          | English                                  | Notes         |
| ------------------------------------------------------ | ---------------------------------------------- | ----------------- |
| Tengo que terminar esta tarea hoy.                       | I have to finish this task today.               | statement           |
| ¿Ya hiciste la tarea de matemáticas?                     | Did you already do the math homework?           | question             |
| No entendió la tarea que le dieron.                      | He didn't understand the task he was given.     | negation             |
| Las tareas del proyecto se dividieron entre el equipo.    | The project's tasks were split among the team.  | plural, del          |
| El profesor asignó una tarea difícil.                    | The teacher assigned a difficult homework task. | statement             |
