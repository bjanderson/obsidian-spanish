# proceso

## Meaning

*Proceso* means "process" — a series of steps or a course of action leading to a
result (a legal process, a manufacturing process, a process of change). It's
masculine: *el proceso*. The plural is regular: *los procesos*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el proceso     |
| Plural   | los procesos   |

## Examples

| Spanish                                              | English                                        | Notes                          |
| ----------------------------------------------------- | ----------------------------------------------- | -------------------------------- |
| El proceso de solicitud tarda dos semanas.            | The application process takes two weeks.        | singular, subject                |
| Los procesos legales pueden ser lentos.                | Legal processes can be slow.                    | plural, subject                  |
| ¿Entiendes el proceso completo?                        | Do you understand the whole process?             | question, singular, object       |
| No terminamos el proceso a tiempo.                      | We didn't finish the process on time.            | negation, singular, object       |
| Durante el proceso, surgieron varios problemas.          | During the process, several problems came up.    | singular, after a preposition    |

## Related Vocabulary

- [[sistema]] — a *proceso* (process) usually runs within a *sistema* (system).
