# equilibrio

## Meaning

*Equilibrio* means "balance" — physical steadiness or, figuratively, a
stable state between competing forces. It's a masculine noun. Common
phrases: *perder el equilibrio* ("to lose one's balance"), *mantener el
equilibrio* ("to keep one's balance").

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | el equilibrio   |
| Plural   | los equilibrios |
