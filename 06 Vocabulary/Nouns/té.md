# té

## Meaning

*Té* means "tea." It's masculine: *el té*. Note the accent mark, which
distinguishes it from *te* (the pronoun "you").

## Singular / Plural

| Number   | Form      |
| -------- | --------- |
| Singular | el té     |
| Plural   | los tés   |

## Examples

| Spanish                                | English                              | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| El té está listo.                                | The tea is ready.                             | statement                             |
| ¿Prefieres té o café?                            | Do you prefer tea or coffee?                  | question                              |
| No tomo té con azúcar.                           | I don't drink tea with sugar.                 | negation                              |
| Los tés de hierbas ayudan a dormir.              | Herbal teas help you sleep.                   | plural                                 |
| Preparó té caliente para el frío.                | She made hot tea for the cold weather.        | statement                              |
