# pulmón

## Meaning

*Pulmón* means "lung." It's masculine: *el pulmón*. Note the written accent
on the singular (*pulmón*) disappears in the plural (*pulmones*) because the
stress naturally falls on the same syllable once another syllable is added.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el pulmón      |
| Plural   | los pulmones   |

## Examples

| Spanish                                       | English                                | Notes                    |
| ------------------------------------------------ | ------------------------------------------ | ----------------------------- |
| El humo le dañó los pulmones.                 | The smoke damaged his lungs.           | plural, indirect object + direct object |
| Respiró hondo y llenó los pulmones de aire.   | He breathed deeply and filled his lungs with air. | plural, object       |
| ¿Te duele el pulmón izquierdo?                | Does your left lung hurt?              | question, singular             |
| No fuma porque le afecta los pulmones.        | He doesn't smoke because it affects his lungs. | negation, plural         |
| Un pulmón sano es esencial para hacer ejercicio. | A healthy lung is essential for exercising. | singular, subject          |
