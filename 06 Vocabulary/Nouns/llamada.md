# llamada

## Meaning

*Llamada* means "call," specifically a phone call. It's feminine: *la
llamada*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la llamada     |
| Plural   | las llamadas   |

## Examples

| Spanish                                       | English                                    | Notes                     |
| ------------------------------------------------ | ------------------------------------------------ | ---------------------------- |
| Recibí una llamada de mi mamá.                | I got a call from my mom.                  | singular, statement       |
| ¿Puedes devolver la llamada más tarde?        | Can you return the call later?             | question                  |
| No contesté la llamada porque estaba ocupado. | I didn't answer the call because I was busy. | negation                |
| Las llamadas internacionales son caras.       | International calls are expensive.         | plural                     |
| Hice una llamada al banco.                    | I made a call to the bank.                 | *al* contraction, singular |
