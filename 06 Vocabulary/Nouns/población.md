# población

## Meaning

*Población* means "population," the people living in a place, or the town/
settlement itself. It's feminine.

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | la población    |
| Plural   | las poblaciones |

## Examples

| Spanish                                          | English                                  | Notes         |
| ------------------------------------------------------ | ---------------------------------------------- | ----------------- |
| La población de esta ciudad crece cada año.             | This city's population grows every year.        | statement          |
| ¿Cuál es la población del país?                          | What's the country's population?                | question, *del*    |
| No conocemos la población exacta del pueblo.             | We don't know the town's exact population.      | negation           |
| Las poblaciones rurales disminuyeron en la última década.| Rural populations declined in the last decade.  | plural             |
| Gran parte de la población vive en el campo.             | A large part of the population lives in the countryside. | usage note |
