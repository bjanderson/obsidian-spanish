# hierba

## Meaning

*Hierba* means "grass" or "herb." It's feminine: *la hierba*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la hierba    |
| Plural   | las hierbas  |

## Examples

| Spanish                                   | English                                | Notes                          |
| -------------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| La hierba del jardín está muy alta.                  | The garden's grass is very tall.               | statement, "grass" sense                |
| ¿Qué hierba usaste para la sopa?                     | What herb did you use for the soup?            | question, "herb" sense                  |
| No cortamos la hierba esta semana.                   | We didn't cut the grass this week.             | negation                              |
| Las hierbas aromáticas crecen en ese rincón.         | The aromatic herbs grow in that corner.        | plural                                 |
| Los niños se sentaron sobre la hierba.               | The kids sat on the grass.                     | statement                              |
