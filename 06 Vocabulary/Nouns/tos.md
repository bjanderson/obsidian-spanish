# tos

## Meaning

*Tos* means "cough." It's a feminine noun, usually used in the singular.

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | la tos     |
| Plural   | las toses  |

| Spanish                               | English                             | Notes         |

| No se le quita la tos con nada.                | The cough won't go away with anything.       | negation           |
