# pelota

## Meaning

*Pelota* means "ball," the round object used in sports and games. It's a feminine
noun, following the regular -a pattern.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la pelota      |
| Plural   | las pelotas    |

## Examples

| Spanish                                       | English                                | Notes                  |
| ----------------------------------------------------- | -------------------------------------------- | ---------------------------- |
| El perro persigue la pelota por el jardín.              | The dog chases the ball around the yard.       | direct object                 |
| Lanzó la pelota hacia la portería.                       | He threw the ball toward the goal.             | direct object                  |
| Compramos pelotas nuevas para el partido.                | We bought new balls for the match.             | plural, direct object           |
| ¿Me pasas la pelota?                                     | Can you pass me the ball?                      | question, indirect object *me*   |
| La pelota rebotó fuera de la cancha.                     | The ball bounced outside the court.            | subject                          |
