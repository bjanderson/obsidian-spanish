# cuerda

## Meaning

*Cuerda* means "rope," "cord," or "string" — including a musical
instrument's string (a guitar has *cuerdas*). It's a feminine noun. Common
phrase: *saltar la cuerda* ("to jump rope").

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la cuerda    |
| Plural   | las cuerdas  |
