# vegetal

## Meaning

*Vegetal* means "vegetable" in a broad, botanical sense (anything
plant-based), distinct from *verdura*, which refers specifically to
vegetables as food. It's masculine: *el vegetal*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el vegetal     |
| Plural   | los vegetales  |
