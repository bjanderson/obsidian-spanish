# celebración

## Meaning

*Celebración* means "celebration" — a somewhat broader and more formal word
than *fiesta* for marking an important event or occasion.

## Singular / Plural

| Number   | Form                 |
| -------- | -------------------- |
| Singular | la celebración       |
| Plural   | las celebraciones    |

## Examples

| Spanish                                          | English                                | Notes         |
| ------------------------------------------------------ | -------------------------------------------- | ----------------- |
| La celebración duró toda la noche.                        | The celebration lasted all night.              | statement            |
| ¿Organizaste la celebración tú sola?                      | Did you organize the celebration by yourself?  | question              |
| No hubo celebración este año.                             | There was no celebration this year.            | negation               |
| Las celebraciones religiosas son importantes en la comunidad. | Religious celebrations are important in the community. | plural       |
| Prepararon una gran celebración por el aniversario.        | They prepared a big celebration for the anniversary. | statement          |
