# fútbol

## Meaning

*Fútbol* means "soccer." It's a masculine noun, used almost always in the
singular as the name of the sport.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | el fútbol   |
| Plural   | los fútboles |

## Examples

| Spanish                                | English                              | Notes         |
| --------------------------------------------- | ------------------------------------------- | ----------------- |
| El fútbol es el deporte más popular aquí.       | Soccer is the most popular sport here.       | statement          |
| ¿Juegas fútbol los fines de semana?             | Do you play soccer on weekends?              | question           |
| No entiendo mucho de fútbol.                    | I don't know much about soccer.              | negation           |
