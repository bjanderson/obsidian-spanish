# producto

## Meaning

*Producto* means "product," something made or grown to be sold or used.
It's a masculine noun.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | el producto   |
| Plural   | los productos |

## Examples

| Spanish                                      | English                                | Notes         |
| --------------------------------------------------- | -------------------------------------------- | ----------------- |
| Este producto es nuevo en el mercado.                  | This product is new on the market.             | statement          |
| ¿Probaste el producto antes de comprarlo?              | Did you try the product before buying it?      | question           |
| No recomiendo ese producto a nadie.                    | I don't recommend that product to anyone.      | negation, indirect object |
| Los productos frescos están más caros este mes.        | Fresh products are more expensive this month.  | plural             |
| Fabrican el producto aquí mismo.                        | They manufacture the product right here.       | statement          |
