# sala

## Meaning

*Sala* means "living room." It's feminine: *la sala*. Some countries say *sala de estar*
for extra clarity, but *sala* alone is understood as the living room in a home context.
It can also mean "room" or "hall" more generally — e.g., *sala de espera* ("waiting room").

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | la sala    |
| Plural   | las salas  |
