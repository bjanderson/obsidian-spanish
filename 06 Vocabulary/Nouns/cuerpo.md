# cuerpo

## Meaning

*Cuerpo* means "body" — the whole physical body. It's masculine: *el cuerpo*.
It also names an organized group or "corps," as in *el cuerpo de bomberos* ("the
fire department").

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | el cuerpo     |
| Plural   | los cuerpos   |
