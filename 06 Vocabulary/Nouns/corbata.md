# corbata

## Meaning

*Corbata* means "necktie." It's feminine: *la corbata*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la corbata     |
| Plural   | las corbatas   |

## Examples

| Spanish                                             | English                                 | Notes    |
| ---------------------------------------------------------- | --------------------------------------------- | ---------- |
| La corbata combina con la camisa.                            | The tie matches the shirt.                    | statement  |
| ¿Sabes hacer el nudo de la corbata?                          | Do you know how to tie a tie?                 | question   |
| No me gusta usar corbata en verano.                          | I don't like wearing a tie in summer.         | negation   |
| Las corbatas de seda son más elegantes.                      | Silk ties are more elegant.                   | plural     |
| Se puso una corbata azul para la reunión.                    | He put on a blue tie for the meeting.         | statement  |
