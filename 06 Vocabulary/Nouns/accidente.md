# accidente

## Meaning

*Accidente* means "accident," an unplanned, harmful event. It's a
masculine noun.

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | el accidente    |
| Plural   | los accidentes  |

## Examples

| Spanish                                    | English                                | Notes         |
| --------------------------------------------- | --------------------------------------------- | ----------------- |
| Hubo un accidente en la carretera.               | There was an accident on the highway.          | statement          |
| ¿Cómo ocurrió el accidente?                      | How did the accident happen?                    | question           |
| No fue un accidente, fue a propósito.            | It wasn't an accident, it was on purpose.       | negation           |
| Los accidentes de tránsito aumentaron este año.  | Traffic accidents increased this year.          | plural             |
| Se lastimó la pierna en un accidente.            | He hurt his leg in an accident.                 | statement          |
