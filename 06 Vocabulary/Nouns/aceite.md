# aceite

## Meaning

*Aceite* means "oil," most often cooking oil. It's masculine: *el aceite*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el aceite    |
| Plural   | los aceites  |

## Examples

| Spanish                                | English                              | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| El aceite está muy caliente.                     | The oil is very hot.                          | statement                             |
| ¿Qué aceite usas para freír?                     | What oil do you use for frying?               | question                              |
| No quedó aceite para cocinar.                    | There wasn't any oil left for cooking.        | negation                              |
| Los aceites de oliva varían mucho en sabor.      | Olive oils vary a lot in flavor.              | plural                                 |
| Agregó un poco de aceite a la sartén.            | She added a little oil to the pan.            | statement                              |
