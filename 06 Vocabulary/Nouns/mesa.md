# mesa

## Meaning

*Mesa* means "table." It's a feminine noun, following the regular -a pattern.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la mesa     |
| Plural   | las mesas   |

## Examples

| Spanish                                        | English                                | Notes                  |
| ---------------------------------------------------- | -------------------------------------------- | -------------------------- |
| La comida está sobre la mesa.                          | The food is on the table.                     | subject                     |
| Pon los platos en la mesa, por favor.                  | Put the plates on the table, please.          | command                      |
| Compramos una mesa nueva para el comedor.              | We bought a new table for the dining room.    | direct object                 |
| ¿Cuántas sillas hay alrededor de la mesa?              | How many chairs are around the table?         | question                       |
| Las mesas del restaurante estaban todas ocupadas.      | The restaurant's tables were all taken.       | plural, subject                 |
