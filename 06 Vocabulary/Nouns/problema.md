# problema

## Meaning

*Problema* means "problem" — a difficulty, an issue, or a math/logic problem
to solve. Even though it ends in *-a*, it's masculine: *el problema*, not *la
problema*. It's one of a small group of Greek-origin *-ma* nouns that break
the usual "-*a* = feminine" pattern, alongside words like *el tema* ("the
topic"), *el sistema* ("the system"), *el programa* ("the program"), and *el
idioma* ("the language"). Any article or adjective modifying *problema*
agrees masculine: *el problema grave*, not *la problema grave*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el problema    |
| Plural   | los problemas  |

## Examples

| Spanish                                       | English                                    | Notes                       |
| ---------------------------------------------- | ------------------------------------------- | ---------------------------- |
| El problema es serio.                          | The problem is serious.                     | singular, subject            |
| Tenemos varios problemas que resolver.          | We have several problems to solve.          | plural, object                |
| ¿Cuál es el problema?                           | What's the problem?                         | singular, question            |
| No veo ningún problema con eso.                 | I don't see any problem with that.          | singular, negation             |
| Hablamos sobre los problemas del país.          | We talked about the country's problems.     | plural, after a preposition    |
