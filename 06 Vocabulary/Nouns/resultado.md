# resultado

## Meaning

*Resultado* means "result" or "outcome." It's a masculine noun.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el resultado   |
| Plural   | los resultados |

## Examples

| Spanish                                     | English                                | Notes         |
| -------------------------------------------------- | -------------------------------------------- | ----------------- |
| El resultado del examen fue excelente.                | The exam's result was excellent.               | statement, del     |
| ¿Ya viste el resultado del partido?                   | Did you already see the match's result?        | question, del      |
| No me gustó el resultado final.                       | I didn't like the final result.                | negation           |
| Los resultados llegaron más tarde de lo esperado.     | The results arrived later than expected.       | plural             |
| Obtuvimos buenos resultados con este método.          | We got good results with this method.          | statement          |
