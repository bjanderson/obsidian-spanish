# derrota

## Meaning

*Derrota* means "defeat" or "loss." It's a feminine noun.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la derrota   |
| Plural   | las derrotas |

## Examples

| Spanish                                | English                              | Notes         |
| --------------------------------------------- | ------------------------------------------- | ----------------- |
| La derrota los dejó muy tristes.                | The defeat left them very sad.               | statement          |
| ¿Cómo aceptaron la derrota?                     | How did they accept the defeat?              | question           |
| No queremos otra derrota como esa.              | We don't want another defeat like that one.  | negation           |
| El equipo sufrió tres derrotas seguidas.        | The team suffered three losses in a row.     | plural             |
| Aprendieron mucho de esa derrota.                | They learned a lot from that defeat.         | statement          |
