# radio

## Meaning

*Radio* has a genuinely important gender distinction: **el radio** refers to
the physical device (the radio set) in most of Latin America, while **la
radio** refers to the medium/broadcast or a radio station — what you listen
to, not what you hold. Mixing these up is a very common learner error, so
don't treat *radio* as having one fixed gender the way most nouns do. (In
Spain, *la radio* covers both senses — that's not the neutral Latin American
usage followed here.)

## Singular / Plural

| Sense                     | Form         |
| -------------------------- | ------------ |
| Device (the radio set)    | el radio     |
| Medium / broadcast / station | la radio  |

| Number   | Device      | Medium/Station |
| -------- | ----------- | -------------- |
| Singular | el radio    | la radio       |
| Plural   | los radios  | las radios     |

## Examples

| Spanish                                        | English                                   | Notes                     |
| --------------------------------------------------- | ------------------------------------------------ | ----------------------------- |
| Compré un radio nuevo para el carro.           | I bought a new radio for the car.         | device sense, singular    |
| Escucho la radio todas las mañanas.            | I listen to the radio every morning.      | medium sense, statement   |
| El radio de la cocina no prende.               | The kitchen radio won't turn on.          | device sense, negation    |
| ¿Conoces esa estación de radio?                | Do you know that radio station?           | question                  |
| No hay buena música en la radio hoy.           | There's no good music on the radio today. | medium sense, negation    |
