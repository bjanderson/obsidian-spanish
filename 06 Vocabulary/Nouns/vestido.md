# vestido

## Meaning

*Vestido* means "dress," the one-piece garment. It's masculine: *el
vestido*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el vestido     |
| Plural   | los vestidos   |

## Examples

| Spanish                                            | English                                | Notes    |
| -------------------------------------------------------- | ------------------------------------------- | ---------- |
| El vestido es de color verde.                              | The dress is green.                         | statement  |
| ¿Te probaste el vestido nuevo?                              | Did you try on the new dress?               | question   |
| No compré el vestido porque era muy caro.                  | I didn't buy the dress because it was too expensive. | negation |
| Los vestidos de esa tienda son muy elegantes.               | That store's dresses are very elegant.      | plural     |
| Llevaba un vestido largo a la boda.                         | She wore a long dress to the wedding.       | statement  |
