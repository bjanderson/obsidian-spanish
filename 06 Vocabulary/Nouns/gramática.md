# gramática

## Meaning

*Gramática* means "grammar" — the rules governing how a language works.
It's a feminine noun, normally used in the singular.

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | la gramática    |
| Plural   | las gramáticas  |

## Examples

| Spanish                                          | English                                    | Notes             |
| ------------------------------------------------- | ---------------------------------------------- | -------------------- |
| La gramática española tiene reglas claras para los verbos. | Spanish grammar has clear rules for verbs. | statement       |
