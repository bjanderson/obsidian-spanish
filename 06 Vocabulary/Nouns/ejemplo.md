# ejemplo

## Meaning

*Ejemplo* means "example" — an instance used to illustrate a point, or a model
of behavior to follow (*dar el ejemplo*, "to set the example"). It's
masculine: *el ejemplo*, following the regular "-*o* = masculine" pattern.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el ejemplo     |
| Plural   | los ejemplos   |

## Examples

| Spanish                                           | English                                    | Notes                       |
