# biblioteca

## Meaning

*Biblioteca* means "library" — a place holding a collection of books for
reading or borrowing. It's feminine: *la biblioteca*.

## Singular / Plural

| Number   | Form             |
| -------- | ---------------- |
| Singular | la biblioteca    |
| Plural   | las bibliotecas  |

## Examples

| Spanish                                                | English                                            | Notes                        |
| -------------------------------------------------------------- | -------------------------------------------------------- | -------------------------------- |
| Estudiamos en la biblioteca todas las tardes.                  | We study at the library every afternoon.                  | singular, after a preposition    |
| Devolví los libros a la biblioteca.                            | I returned the books to the library.                       | singular, indirect object         |
