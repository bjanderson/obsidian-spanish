# cena

## Meaning

*Cena* means "dinner," the evening meal. It's feminine: *la cena*.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la cena     |
| Plural   | las cenas   |

## Examples

| Spanish                                | English                              | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| La cena está casi lista.                         | Dinner is almost ready.                       | statement                             |
| ¿Qué vamos a cenar esta noche?                   | What are we having for dinner tonight?        | question                              |
| No hicimos cena anoche.                          | We didn't make dinner last night.             | negation                              |
| Las cenas familiares son importantes para ellos. | Family dinners are important to them.         | plural                                 |
| Invitamos a los vecinos a cenar con nosotros.    | We invited the neighbors to have dinner with us. | statement, personal *a*             |
