# cuestión

## Meaning

*Cuestión* means "question" in the sense of a matter, issue, or topic under
discussion (*una cuestión importante*, "an important matter") — not a
question you ask someone (that's *pregunta*). It's feminine: *la cuestión*.
The plural drops the written accent: *cuestiones* (the stress falls naturally
on the new syllable, so the accent mark is no longer needed).

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la cuestión    |
| Plural   | las cuestiones |

## Examples

| Spanish                                             | English                                  | Notes                          |
| ------------------------------------------------------ | -------------------------------------------- | ---------------------------------- |
| Es una cuestión muy delicada.                           | It's a very delicate matter.                  | singular, subject                   |
| No quiero hablar de esa cuestión ahora.                 | I don't want to talk about that matter now.   | negation, after a preposition        |
| ¿Podemos resolver esta cuestión hoy?                    | Can we resolve this matter today?             | question                             |
| Las cuestiones económicas dominan la reunión.           | Economic matters dominate the meeting.        | plural, subject                      |
| Depende de varias cuestiones legales.                   | It depends on several legal matters.          | plural, after a preposition, "de"    |
