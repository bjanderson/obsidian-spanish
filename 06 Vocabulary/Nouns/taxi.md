# taxi

## Meaning

*Taxi* means "taxi" or "cab." It's masculine: *el taxi*.

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | el taxi    |
| Plural   | los taxis  |

## Examples

| Spanish                                          | English                                | Notes    |
| ----------------------------------------------------- | ------------------------------------------ | ---------- |
| El taxi está esperando afuera.                        | The taxi is waiting outside.               | statement  |
| ¿Puedes llamar a un taxi?                             | Can you call a taxi?                       | question   |
| No hay taxis disponibles a esta hora.                 | There are no taxis available at this hour. | negation   |
| Los taxis de esta ciudad son amarillos.               | This city's taxis are yellow.              | plural     |
| Tomamos un taxi al aeropuerto.                        | We took a taxi to the airport.             | statement  |

## Related Vocabulary

- [[metro]] — usually faster than a taxi in heavy traffic.
