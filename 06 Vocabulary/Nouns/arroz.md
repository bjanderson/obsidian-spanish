# arroz

## Meaning

*Arroz* means "rice." It's masculine: *el arroz*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el arroz     |
| Plural   | los arroces  |

## Examples

| Spanish                                | English                             | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| El arroz ya está listo.                          | The rice is ready.                            | statement                             |
| ¿Cuánto arroz necesitamos para seis personas?    | How much rice do we need for six people?      | question                              |
| No quedó arroz para mañana.                      | There wasn't any rice left for tomorrow.      | negation                              |
| Los arroces de esta región usan mucho color.     | The rice dishes from this region use a lot of coloring. | plural, (z → c)               |
| Sirvió el pescado con arroz blanco.              | She served the fish with white rice.          | statement                              |
