# nieve

## Meaning

*Nieve* means "snow." It's feminine: *la nieve*. The plural (*las nieves*) is
rare, used mainly for the permanent snow on high mountain peaks.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la nieve    |
| Plural   | las nieves  |

## Examples

| Spanish                                          | English                                     | Notes                          |
| --------------------------------------------------- | ---------------------------------------------- | ---------------------------------- |
| La nieve cubrió las montañas.                        | Snow covered the mountains.                    | statement                          |
| ¿Ya cayó nieve este invierno?                        | Has snow fallen yet this winter?               | question                           |
| No hay nieve suficiente para esquiar.                | There isn't enough snow to ski.                | negation                           |
| Las nieves del volcán se ven desde el pueblo.        | The volcano's snows can be seen from the town. | plural, "eternal snow"             |
