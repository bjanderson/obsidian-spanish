# gripe

## Meaning

*Gripe* means "flu." It's a feminine noun, usually used in the singular
since it names a single illness.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la gripe    |
| Plural   | las gripes  |

## Examples

| Spanish                                 | English                             | Notes         |
| ---------------------------------------------- | ------------------------------------------ | ----------------- |
| Tengo gripe y no puedo ir a trabajar.             | I have the flu and can't go to work.        | statement          |
| ¿Te vacunaste contra la gripe este año?           | Did you get the flu vaccine this year?      | question           |
| No es gripe, es solo un resfriado leve.           | It's not the flu, it's just a mild cold.    | negation           |
| Hubo varias gripes distintas esa temporada.       | There were several different flu strains that season. | plural       |
| La gripe lo dejó en cama toda la semana.          | The flu left him in bed all week.           | statement          |
