# guerra

## Meaning

*Guerra* means "war," an armed conflict between nations or groups. It's a
feminine noun.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la guerra    |
| Plural   | las guerras  |

## Examples

| Spanish                                       | English                                    | Notes                     |
| ---------------------------------------------- | -------------------------------------------- | ---------------------------- |
| La guerra terminó hace cinco años.              | The war ended five years ago.                | statement                    |
| ¿Cuándo empezó la guerra?                       | When did the war start?                      | question                     |
| No quiero hablar de la guerra.                  | I don't want to talk about the war.          | negation, preposition        |
| Las guerras dejan muchas familias destruidas.   | Wars leave many families destroyed.          | plural                       |
| El país nunca se recuperó de la guerra.         | The country never recovered from the war.    | prepositional phrase         |
