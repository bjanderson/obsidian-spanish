# mono

## Meaning

*Mono* means "monkey." It's masculine: *el mono* (the feminine form *la
mona* refers specifically to a female monkey).

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | el mono    |
| Plural   | los monos  |

## Examples

| Spanish                                  | English                              | Notes                          |
| ------------------------------------------------ | -------------------------------------------- | ------------------------------------ |
| El mono saltó de rama en rama.                      | The monkey jumped from branch to branch.      | statement                             |
| ¿Viste al mono en la selva?                         | Did you see the monkey in the jungle?         | question, personal *a*                 |
| No logramos fotografiar al mono.                    | We couldn't manage to photograph the monkey.  | negation, personal *a*                 |
| Los monos de esta selva son muy ruidosos.           | The monkeys in this jungle are very noisy.    | plural                                 |
| El guía nos señaló un grupo de monos.               | The guide pointed out a group of monkeys.     | statement                              |
