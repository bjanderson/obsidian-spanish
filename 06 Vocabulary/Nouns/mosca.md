# mosca

## Meaning

*Mosca* means "fly," the insect. It's feminine: *la mosca*.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la mosca    |
| Plural   | las moscas  |

## Examples

| Spanish                                | English                              | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| Una mosca entró por la ventana.                  | A fly came in through the window.             | statement                             |
| ¿Por qué hay tantas moscas hoy?                  | Why are there so many flies today?            | question                              |
| No pudimos espantar la mosca de la comida.       | We couldn't shoo the fly away from the food.  | negation                              |
| Las moscas se juntan cerca de la basura.         | Flies gather near the trash.                  | plural                                 |
| Cerramos la puerta para que no entraran moscas.  | We closed the door so flies wouldn't come in. | subordinate clause                     |
