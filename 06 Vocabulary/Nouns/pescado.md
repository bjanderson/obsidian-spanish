# pescado

## Meaning

*Pescado* means "fish" as food, once caught — distinct from *pez*, the
living animal. It's masculine: *el pescado*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el pescado     |
| Plural   | los pescados   |
