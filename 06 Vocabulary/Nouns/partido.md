# partido

## Meaning

*Partido* means "match" or "game," a sports contest, and also "political
party." It's a masculine noun.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el partido   |
| Plural   | los partidos |

## Examples

| Spanish                                  | English                              | Notes             |
| ----------------------------------------------- | ------------------------------------------- | --------------------- |
| El partido empieza a las cinco.                   | The match starts at five.                    | statement              |
| ¿Viste el partido de anoche?                      | Did you watch last night's match?            | question               |
| No ganamos ni un partido esta temporada.          | We haven't won a single match this season.   | negation               |
| Hay varios partidos políticos en el país.         | There are several political parties in the country. | plural, secondary sense |
| Fuimos al partido con toda la familia.            | We went to the match with the whole family.  | statement, al          |
