# hielo

## Meaning

*Hielo* means "ice." It's masculine: *el hielo*. Common phrase: *romper el
hielo* ("to break the ice," socially).

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | el hielo   |
| Plural   | los hielos |

## Examples

| Spanish                                     | English                                    | Notes                       |
| ---------------------------------------------- | ----------------------------------------------- | -------------------------------- |
| El hielo se derritió rápido.                    | The ice melted fast.                            | statement                        |
| ¿Quieres hielo en tu bebida?                    | Do you want ice in your drink?                  | question                         |
