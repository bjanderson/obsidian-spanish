# temperatura

## Meaning

*Temperatura* means "temperature." It's feminine: *la temperatura*.

## Singular / Plural

| Number   | Form              |
| -------- | ----------------- |
| Singular | la temperatura    |
| Plural   | las temperaturas  |

## Examples

| Spanish                                          | English                                  | Notes                       |
| ----------------------------------------------------- | -------------------------------------------- | -------------------------------- |
| La temperatura bajó mucho anoche.                       | The temperature dropped a lot last night.     | statement                        |
| ¿Cuál es la temperatura ahora?                          | What's the temperature now?                   | question                         |
| No revisamos la temperatura del agua.                   | We didn't check the water's temperature.      | negation                         |
| Las temperaturas altas dañan las plantas.               | High temperatures damage the plants.          | plural                           |
| El médico le tomó la temperatura al niño.               | The doctor took the child's temperature.      | statement, personal *a*          |
