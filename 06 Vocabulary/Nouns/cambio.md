# cambio

## Meaning

*Cambio* means "change," both a shift or transformation and the coins/
money returned after a purchase. It's a masculine noun.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el cambio    |
| Plural   | los cambios  |

## Examples

| Spanish                                      | English                                | Notes             |
| --------------------------------------------------- | -------------------------------------------- | --------------------- |
| El cambio de clima fue muy repentino.                 | The weather change was very sudden.           | statement              |
| ¿Me das el cambio, por favor?                         | Can you give me the change, please?           | question, secondary sense |
| No tengo cambio para pagar el taxi.                   | I don't have change to pay the taxi.          | negation               |
| Hubo varios cambios en el equipo este año.            | There were several changes on the team this year. | plural            |
| El país necesita un cambio de gobierno.                | The country needs a change of government.     | *de*-phrase             |
