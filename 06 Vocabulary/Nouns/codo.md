# codo

## Meaning

*Codo* means "elbow." It's masculine: *el codo*. Common in idioms like *hablar
por los codos* ("to talk non-stop") and, colloquially, *empinar el codo* ("to
drink alcohol").

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el codo      |
| Plural   | los codos    |
