# segundo

## Meaning

As a noun, *segundo* means "second" — the unit of time (sixty *segundos* make up a
*minuto*). It's masculine: *el segundo*. Note that *segundo* is also very commonly
used as an ordinal adjective meaning "second" in a sequence (*el segundo día*, "the
second day") — context tells the two uses apart. This file covers the time-unit noun
sense.
