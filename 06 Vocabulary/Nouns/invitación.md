# invitación

## Meaning

*Invitación* means "invitation" — a request for someone to attend an event.

## Singular / Plural

| Number   | Form                |
| -------- | ------------------- |
| Singular | la invitación       |
| Plural   | las invitaciones    |

## Examples

| Spanish                                     | English                             | Notes            |
| -------------------------------------------------- | ------------------------------------------ | --------------------- |
| Recibí la invitación a la boda ayer.                 | I received the wedding invitation yesterday. | statement               |
| ¿Le mandaste la invitación a Pedro?                  | Did you send Pedro the invitation?           | question, personal a     |
| No aceptó la invitación.                             | He didn't accept the invitation.             | negation                  |
| Las invitaciones se enviaron la semana pasada.        | The invitations were sent out last week.     | plural                     |
| Mandó invitaciones a todos sus compañeros de trabajo. | She sent invitations to all her coworkers.   | personal a                 |
