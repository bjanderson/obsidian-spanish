# motocicleta

## Meaning

*Motocicleta* means "motorcycle." It's feminine: *la motocicleta*. Very
commonly shortened to *moto* in everyday speech.

## Singular / Plural

| Number   | Form                |
| -------- | ------------------- |
| Singular | la motocicleta      |
| Plural   | las motocicletas    |

## Examples

| Spanish                                                   | English                                 | Notes    |
| --------------------------------------------------------------- | ------------------------------------------- | ---------- |
| La motocicleta hace mucho ruido al arrancar.                    | The motorcycle makes a lot of noise starting up. | statement  |
| ¿Necesitas casco para andar en motocicleta?                     | Do you need a helmet to ride a motorcycle?  | question   |
| No manejo motocicleta porque me da miedo.                       | I don't ride a motorcycle because it scares me. | negation |
| Las motocicletas consumen menos gasolina que un auto.           | Motorcycles use less gas than a car.        | plural     |
| Fue al trabajo en motocicleta esta mañana.                      | He went to work by motorcycle this morning. | statement  |
