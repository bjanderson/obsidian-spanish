# actividad

## Meaning

*Actividad* means "activity." It's feminine: *la actividad* — like most Spanish
nouns ending in *-dad*, which are reliably feminine (a useful pattern: *ciudad*,
*verdad*, *realidad* all follow it too).

## Singular / Plural

| Number   | Form         |
| ---------- | -------------- |
| Singular     | la actividad   |
| Plural         | las actividades |

## Examples

| Spanish                                    | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Esta actividad es muy divertida.            | This activity is a lot of fun.           | singular, subject                  |
| ¿Qué actividades ofrece el gimnasio?        | What activities does the gym offer?      | plural, question                   |
| Organizamos una actividad para los niños.   | We organized an activity for the kids.   | singular, direct object             |
| Participó en varias actividades del club.   | She took part in several club activities. | plural, after a preposition        |
| No hay actividad en la oficina los domingos. | There's no activity in the office on Sundays. | singular, negation             |
