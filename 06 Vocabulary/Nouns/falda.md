# falda

## Meaning

*Falda* means "skirt." It's feminine: *la falda*.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la falda    |
| Plural   | las faldas  |

## Examples

| Spanish                                         | English                             | Notes    |
| ------------------------------------------------------ | ----------------------------------------- | ---------- |
| La falda le queda perfecta.                             | The skirt fits her perfectly.             | statement  |
| ¿Prefieres esta falda o el vestido?                     | Do you prefer this skirt or the dress?    | question   |
| No uso falda cuando hace frío.                          | I don't wear a skirt when it's cold.      | negation   |
| Las faldas largas están de moda esta temporada.         | Long skirts are in style this season.     | plural     |
| Se compró una falda para la fiesta.                     | She bought a skirt for the party.         | statement  |
