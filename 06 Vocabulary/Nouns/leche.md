# leche

## Meaning

*Leche* means "milk." It's feminine: *la leche*.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la leche    |
| Plural   | las leches  |

## Examples

| Spanish                                  | English                                | Notes                          |
| ------------------------------------------------ | ----------------------------------------------- | ------------------------------------ |
| La leche está fría todavía.                         | The milk is still cold.                          | statement                             |
| ¿Tomas leche con el desayuno?                       | Do you drink milk with breakfast?                | question                              |
| No queda leche en la nevera.                        | There's no milk left in the fridge.              | negation                              |
| Probamos varias leches vegetales.                   | We tried several plant-based milks.              | plural                                 |
| Hierve la leche antes de usarla en la receta.       | She boils the milk before using it in the recipe.| statement                              |
