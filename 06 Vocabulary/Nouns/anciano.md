# anciano

## Meaning

*Anciano* means "elderly person" — a respectful, neutral term for an older
person. The masculine form *el anciano* is the base entry here; the feminine
form is *la anciana* when referring specifically to a woman.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el anciano   |
| Plural   | los ancianos |
