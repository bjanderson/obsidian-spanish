# lápiz

## Meaning

*Lápiz* means "pencil." It's a masculine noun with an irregular plural: the final
*-z* changes to *-c-* before adding *-es* (*lápiz → lápices*), the standard pattern
for nouns ending in *-z*.

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | el lápiz        |
| Plural   | los lápices     |

## Examples

| Spanish                                            | English                                     | Notes                     |

| Escribí la carta con lápiz.                             | I wrote the letter in pencil.                   | instrumental *con*             |
| Necesito comprar lápices nuevos para la escuela.        | I need to buy new pencils for school.           | irregular plural               |
| ¿Tienes un lápiz que me prestes?                        | Do you have a pencil you can lend me?           | question                        |
