# contraseña

## Meaning

*Contraseña* means "password" — the secret code used to access an account or
device. It's a feminine noun.

## Singular / Plural

| Number   | Form                |
| -------- | ------------------- |
| Singular | la contraseña        |
| Plural   | las contraseñas       |

## Examples

| Spanish                                           | English                                     | Notes     |
| ---------------------------------------------------- | ---------------------------------------------- | --------- |
| Olvidé la contraseña de mi correo.                     | I forgot my email password.                    | statement |
| ¿Puedes cambiar la contraseña del wifi?                | Can you change the wifi's password?            | question, *del* |
| No compartas tu contraseña con nadie.                  | Don't share your password with anyone.         | negation  |
| Las contraseñas deben tener al menos ocho caracteres.  | Passwords must have at least eight characters. | plural    |
| Restablecí la contraseña de la cuenta.                 | I reset the account's password.                | statement |
