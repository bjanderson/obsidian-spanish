# página

## Meaning

*Página* means "page" — of a book, document, or (by extension) a website. It's a
feminine noun, following the regular -a pattern.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la página      |
| Plural   | las páginas    |

## Examples

| Spanish                                       | English                                | Notes                     |
| ---------------------------------------------------- | -------------------------------------------- | ------------------------------ |
| Abre el libro en la página diez.                        | Open the book to page ten.                    | command                          |
| Este cuaderno tiene cien páginas.                        | This notebook has a hundred pages.            | plural, direct object              |
| ¿En qué página te quedaste?                              | What page did you stop on?                    | question                          |
| Escribió su nombre en la primera página.                 | She wrote her name on the first page.         | ordinal, prepositional phrase       |
| Faltan varias páginas en este documento.                 | Several pages are missing from this document. | plural, subject                     |

## Related Vocabulary

- [[lápiz]] — a *lápiz* is what you use to write on a *página*.
- [[mapa]] — a *mapa* is often printed on a *página* of a book or atlas.
