# voz

## Meaning

*Voz* means "voice." It's a feminine noun with an irregular plural: the final *-z*
changes to *-c-* before adding *-es* (*voz → voces*), the same pattern seen in
*lápiz → lápices*.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la voz      |
| Plural   | las voces   |

## Examples

| Spanish                                         | English                                | Notes                    |
| -------------------------------------------------------- | -------------------------------------------- | ------------------------------ |
| Tiene una voz muy dulce.                                    | She has a very sweet voice.                    | direct object                    |
| Levantó la voz para que todos la escucharan.                | He raised his voice so everyone would hear him. | direct object, subjunctive clause |
| Las voces de los niños llenaban el patio.                    | The children's voices filled the courtyard.    | irregular plural, subject          |
| Reconocí su voz de inmediato.                                | I recognized her voice immediately.            | direct object                       |
| Habla en voz baja, por favor.                                | Speak quietly, please.                         | fixed phrase *en voz baja*, command  |
