# fruta

## Meaning

*Fruta* means "fruit" (the food). It's feminine: *la fruta*.

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | la fruta   |
| Plural   | las frutas |

## Examples

| Spanish                                  | English                              | Notes                          |
| ------------------------------------------------ | -------------------------------------------- | ------------------------------------ |
| Compramos fruta fresca en el mercado.               | We bought fresh fruit at the market.          | statement                             |
| ¿Qué fruta prefieres para el desayuno?              | What fruit do you prefer for breakfast?       | question                              |
| No comimos fruta ayer.                              | We didn't eat fruit yesterday.                | negation                              |
| Las frutas de esta región son muy dulces.           | The fruits from this region are very sweet.   | plural                                 |
| Preparó una ensalada de frutas para todos.          | She made a fruit salad for everyone.          | statement                              |
