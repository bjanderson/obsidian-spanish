# araña

## Meaning

*Araña* means "spider." It's feminine: *la araña*.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la araña    |
| Plural   | las arañas  |

## Examples

| Spanish                                 | English                             | Notes                          |
| ------------------------------------------------ | -------------------------------------------- | ------------------------------------ |
| La araña tejió una telaraña enorme.                 | The spider wove a huge web.                   | statement                             |
| ¿Le tienes miedo a las arañas?                      | Are you afraid of spiders?                    | question                              |
| No matamos la araña, la sacamos afuera.             | We didn't kill the spider, we took it outside.| negation                              |
| Las arañas de esta zona no son peligrosas.          | The spiders in this area aren't dangerous.    | plural                                 |
| Encontramos una araña grande en el sótano.          | We found a big spider in the basement.        | statement                              |
