# piscina

## Meaning

*Piscina* means "swimming pool." It's feminine: *la piscina*.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | la piscina    |
| Plural   | las piscinas  |

## Examples

| Spanish                                              | English                                        | Notes                        |
| ---------------------------------------------------------- | ----------------------------------------------------- | -------------------------------- |
| Los niños nadan en la piscina todos los días.              | The kids swim in the pool every day.                   | singular, after a preposition    |
| Nos bañamos en la piscina del hotel.                       | We swam in the hotel's pool.                            | singular, *del* contraction       |
| ¿Está climatizada la piscina?                              | Is the pool heated?                                     | singular, question               |
| No se permite correr cerca de la piscina.                  | Running near the pool isn't allowed.                     | singular, negation                |
| El hotel tiene tres piscinas para los huéspedes.           | The hotel has three pools for guests.                    | plural, direct object             |
