# abeja

## Meaning

*Abeja* means "bee." It's feminine: *la abeja*.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la abeja    |
| Plural   | las abejas  |

## Examples

| Spanish                                | English                              | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| Una abeja se posó en la flor.                    | A bee landed on the flower.                   | statement                             |
| ¿Te ha picado una abeja alguna vez?               | Has a bee ever stung you?                     | question                              |
| No molestamos a las abejas del jardín.           | We don't bother the garden's bees.            | negation, personal *a*                 |
| Las abejas producen miel para el invierno.       | Bees produce honey for winter.                | plural                                 |
| Observamos a las abejas trabajar en el panal.    | We watched the bees work in the hive.         | statement, personal *a*                |
