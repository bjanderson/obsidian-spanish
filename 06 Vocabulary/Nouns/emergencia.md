# emergencia

## Meaning

*Emergencia* means "emergency," an urgent situation requiring immediate
action. It's a feminine noun.

## Singular / Plural

| Number   | Form             |
| -------- | ---------------- |
| Singular | la emergencia    |
| Plural   | las emergencias  |

## Examples

| Spanish                                    | English                                | Notes         |
| --------------------------------------------- | --------------------------------------------- | ----------------- |
| Es una emergencia, necesito ayuda ya.            | It's an emergency, I need help now.             | statement          |
| ¿Cuál es la emergencia?                          | What's the emergency?                            | question           |
| No hay ninguna emergencia por ahora.             | There's no emergency for now.                    | negation           |
| El hospital atiende varias emergencias al día.   | The hospital handles several emergencies a day.  | plural             |
| Llamaron a la sala de emergencia de inmediato.   | They called the emergency room immediately.      | statement          |
