# calendario

## Meaning

*Calendario* means "calendar" — either the physical/digital object or the abstract
system for dividing time into days, months, and years. It's masculine:
*el calendario*.

## Singular / Plural

| Number   | Form              |
| -------- | ----------------- |
| Singular | el calendario     |
| Plural   | los calendarios   |

## Examples

| Spanish                                            | English                                     | Notes                          |
| ------------------------------------------------------ | --------------------------------------------------- | ---------------------------------- |
| Marqué la reunión en el calendario.                    | I marked the meeting on the calendar.                | statement, object                   |
| Revisamos el calendario del equipo cada lunes.          | We check the team's calendar every Monday.           | object, *del* contraction           |
| ¿Tienes el calendario de exámenes?                      | Do you have the exam calendar?                       | question                            |
| No encuentro el calendario de la oficina.                | I can't find the office calendar.                    | negation, object                    |
| Compramos un calendario nuevo para el año que viene.     | We bought a new calendar for next year.              | object, *para*-phrase               |

## Related Vocabulary

- [[fecha]] — the individual dates a *calendario* tracks.
- [[mes]] — the months a *calendario* is organized around.
- [[reloj]] — tracks time within a day, while a *calendario* tracks days across a year.
