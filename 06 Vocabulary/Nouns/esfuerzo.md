# esfuerzo

## Meaning

*Esfuerzo* means "effort" — the energy put into achieving something. It's a
masculine noun. Common phrase: *hacer un esfuerzo* ("to make an effort").

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el esfuerzo    |
| Plural   | los esfuerzos  |

## Examples

| Spanish                                          | English                              | Notes             |
| ------------------------------------------------- | --------------------------------------- | -------------------- |
| Hizo un gran esfuerzo para terminar el proyecto.   | She made a great effort to finish the project. | statement, idiom |
| ¿Vale la pena tanto esfuerzo?                      | Is so much effort worth it?              | question               |
| No basta con el esfuerzo si no hay estrategia.     | Effort isn't enough without a strategy.  | negation               |
| Sus esfuerzos finalmente dieron resultado.         | Her efforts finally paid off.            | plural                 |
