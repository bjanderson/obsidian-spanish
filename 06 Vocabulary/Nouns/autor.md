# autor

## Meaning

*Autor* means "author" — the person who wrote or created a book, article, or
other work. Unlike many profession nouns that stay the same for both genders
(*el/la estudiante*), *autor* changes form: a male author is *el autor* and a
female author is *la autora*, with the feminine *-a* ending added the same
way as *el profesor* / *la profesora*. Both forms are common and neither is
more "correct" — use the one that matches the person's gender.

## Singular / Plural

| Number   | Form                    |
| -------- | ----------------------- |
| Singular (masc.) | el autor         |
| Singular (fem.)  | la autora        |
| Plural (masc.)   | los autores      |
| Plural (fem.)    | las autoras      |

## Examples

| Spanish                                        | English                                | Notes                              |
| ------------------------------------------------ | ---------------------------------------- | ------------------------------------ |
| El autor de esta novela es boliviano.             | The author of this novel is Bolivian.     | singular masc., subject               |
| Admiro mucho a la autora de ese ensayo.           | I really admire the author of that essay. | singular fem., personal *a*, direct object |
| ¿Conoces al autor del libro?                      | Do you know the author of the book?       | question, "al" + personal *a*          |
| No he leído nada de esa autora todavía.           | I haven't read anything by that author yet. | negation                              |
| Los autores de la revista se reunieron ayer.      | The magazine's authors met yesterday.      | plural masc., subject                  |
