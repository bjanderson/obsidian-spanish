# ratón

## Meaning

*Ratón* means "mouse." It's masculine: *el ratón*. It's a false-friend trap
worth flagging: it covers both the small rodent animal and the computer
peripheral, just like "mouse" does in English — context tells you which
sense is meant, but don't assume only one meaning applies.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | el ratón      |
| Plural   | los ratones   |

## Examples

| Spanish                                             | English                                      | Notes                    |
| ------------------------------------------------------ | ---------------------------------------------------- | ---------------------------- |
| El ratón de la computadora dejó de funcionar.       | The computer mouse stopped working.          | tech sense, singular      |
| ¿Viste un ratón en la cocina?                       | Did you see a mouse in the kitchen?          | animal sense, question    |
| No me gusta usar el ratón, prefiero el teclado.     | I don't like using the mouse, I prefer the keyboard. | tech sense, negation |
| Los ratones inalámbricos son más cómodos.           | Wireless mice are more comfortable.          | tech sense, plural        |
| Compró una trampa para atrapar el ratón.            | She bought a trap to catch the mouse.        | animal sense, singular    |
