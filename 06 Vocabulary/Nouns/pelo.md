# pelo

## Meaning

*Pelo* means "hair." It's masculine: *el pelo*, and it's normally used as a
mass/collective noun (like English "hair") — the plural *pelos* refers to
individual hairs, often in an informal or slightly negative sense (e.g., stray
hairs found somewhere).

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | el pelo    |
| Plural   | los pelos  |

## Examples

| Spanish                                    | English                                | Notes                  |
| ---------------------------------------------- | ------------------------------------------- | --------------------------- |
| Tiene el pelo negro.                           | She has black hair.                         | statement                    |
| Me corté el pelo ayer.                         | I got my hair cut yesterday.                | object                       |
| ¿Te gusta mi corte de pelo?                    | Do you like my haircut?                     | question                     |
| No me gusta el pelo largo.                     | I don't like long hair.                     | negation                     |
| Encontré pelos de gato en el sofá.             | I found cat hairs on the sofa.              | plural = individual hairs    |
