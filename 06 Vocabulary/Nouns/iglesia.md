# iglesia

## Meaning

*Iglesia* means "church," both the building and the institution. It's a
feminine noun.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | la iglesia    |
| Plural   | las iglesias  |

## Examples

| Spanish                                    | English                             | Notes         |
| ----------------------------------------------- | ------------------------------------------ | ----------------- |
| La iglesia del pueblo es muy antigua.            | The town's church is very old.              | statement, *del*   |
| ¿A qué hora empieza la misa en la iglesia?       | What time does mass start at church?        | question           |
| No fuimos a la iglesia este domingo.             | We didn't go to church this Sunday.         | negation           |
| Hay dos iglesias cerca de mi casa.               | There are two churches near my house.       | plural             |
| Se casaron en una iglesia pequeña.               | They got married in a small church.         | prepositional phrase |
