# empleo

## Meaning

*Empleo* means "employment" or "a job" — often a bit more formal than
*trabajo*, and common in set phrases like *buscar empleo* ("to look for a
job") or *estar sin empleo* ("to be unemployed").

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el empleo    |
| Plural   | los empleos  |
