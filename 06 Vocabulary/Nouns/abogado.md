# abogado

## Meaning

*Abogado* means "lawyer." The feminine form is *abogada*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el abogado     |
| Plural   | los abogados   |

## Examples

| Spanish                                 | English                              | Notes             |
| ------------------------------------------------ | ------------------------------------------- | --------------------- |
| Mi abogado revisó todo el contrato.                 | My lawyer reviewed the whole contract.       | statement              |
| ¿Contrataste a un abogado para el caso?             | Did you hire a lawyer for the case?          | question, personal a   |
| No consulté a ningún abogado todavía.               | I haven't consulted any lawyer yet.          | negation, personal a   |
| La abogada defendió a su cliente con firmeza.       | The lawyer defended her client firmly.       | feminine, personal a   |
| Los abogados presentaron el caso ante el juez.      | The lawyers presented the case before the judge. | plural             |
