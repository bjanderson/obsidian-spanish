# memoria

## Meaning

*Memoria* means "memory," both the mental ability to remember and a
specific recollection. It's a feminine noun.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | la memoria    |
| Plural   | las memorias  |

## Examples

| Spanish                                   | English                              | Notes         |
| ---------------------------------------------- | ------------------------------------------- | ----------------- |
| Mi abuela todavía tiene muy buena memoria.       | My grandmother still has a very good memory. | statement          |
| ¿Guardas memoria de tu primer día de clases?     | Do you have a memory of your first day of class? | question       |
| No tengo memoria de ese viaje.                   | I have no memory of that trip.               | negation           |
| Escribió sus memorias antes de morir.            | He wrote his memoirs before dying.           | plural, secondary sense |
| Guardamos las fotos en la memoria del celular.   | We saved the photos in the phone's memory.   | secondary sense    |
