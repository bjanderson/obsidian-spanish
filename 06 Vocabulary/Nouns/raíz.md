# raíz

## Meaning

*Raíz* means "root." It's feminine: *la raíz*. It's also used figuratively
for the "root" of a problem or a word.

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | la raíz    |
| Plural   | las raíces |

## Examples

| Spanish                                     | English                                 | Notes                          |
| ---------------------------------------------- | ---------------------------------------------- | ------------------------------------ |
| La raíz del árbol rompió la acera.                | The tree's root broke the sidewalk.              | statement                             |
| ¿Cuál es la raíz de este problema?                | What's the root of this problem?                 | question, figurative sense              |
| No arrancamos la raíz por completo.               | We didn't pull out the root completely.           | negation                              |
| Las raíces de esa planta son profundas.           | That plant's roots are deep.                      | plural, (z → c)                        |
| Estudiamos la raíz de la palabra en clase.        | We studied the word's root in class.              | statement, figurative sense             |
