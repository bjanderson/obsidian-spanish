# modelo

## Meaning

*Modelo* means "model," either a design/pattern or a person who models. As
an object it's masculine (*el modelo*); as a person it's common gender —
*el modelo* / *la modelo*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el/la modelo |
| Plural   | los/las modelos |

## Examples

| Spanish                                    | English                               | Notes         |
| ----------------------------------------------- | -------------------------------------------- | ----------------- |
| Este modelo de carro es muy popular.               | This car model is very popular.                | statement          |
| ¿Qué modelo de teléfono tienes?                    | What phone model do you have?                  | question           |
| No es un buen modelo a seguir.                     | He's not a good role model to follow.          | negation           |
| La modelo desfiló con varios vestidos nuevos.      | The model walked the runway in several new dresses. | fem., person  |
| Compararon los distintos modelos disponibles.      | They compared the different models available. | plural             |
