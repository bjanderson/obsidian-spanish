# reloj

## Meaning

*Reloj* means "clock" or "watch" — context (or a phrase like *de pared* "wall" or
*de pulsera* "wrist") tells you which. It's masculine: *el reloj*. It's irregular in
the plural: since it ends in a consonant, it takes *-es*: *relojes*, not *relojs*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el reloj       |
| Plural   | los relojes    |

## Examples

| Spanish                                       | English                                    | Notes                          |
| -------------------------------------------------- | -------------------------------------------------- | ---------------------------------- |
| Miré el reloj antes de salir.                     | I looked at the clock before leaving.               | statement, object                   |
| Se le paró el reloj a mi abuelo.                   | My grandfather's watch stopped.                     | object, personal reference          |
| ¿Tienes hora? Se me paró el reloj.                 | Do you have the time? My watch stopped.             | question + statement                |
| No encuentro mi reloj esta mañana.                 | I can't find my watch this morning.                 | negation, object                    |
| Los relojes de esa tienda son muy caros.           | The clocks in that store are very expensive.        | plural, subject                     |
