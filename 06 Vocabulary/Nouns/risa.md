# risa

## Meaning

*Risa* means "laugh" or "laughter." It's a feminine noun, following the regular -a
pattern. The fixed phrase *dar risa* ("to make [someone] laugh") is very common.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la risa     |
| Plural   | las risas   |

## Examples

| Spanish                                          | English                                   | Notes                       |
| -------------------------------------------------------- | ---------------------------------------------- | -------------------------------- |
| Su risa se escuchaba desde la calle.                        | Her laugh could be heard from the street.        | subject                            |
| No pude contener la risa durante la película.               | I couldn't hold back my laughter during the movie. | direct object                    |
| Las risas llenaban la fiesta.                                | Laughter filled the party.                        | plural, subject                     |
| Me dio tanta risa que lloré.                                 | It made me laugh so hard I cried.                 | fixed phrase *dar risa*, indirect object *me* |
| Compartimos muchas risas ese día.                            | We shared a lot of laughs that day.               | plural, direct object                |
