# hígado

## Meaning

*Hígado* means "liver," the organ. It's masculine: *el hígado*.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | el hígado     |
| Plural   | los hígados   |

## Examples

| Spanish                                       | English                                  | Notes                  |
| ------------------------------------------------ | --------------------------------------------- | ---------------------------- |
| El alcohol daña el hígado con el tiempo.       | Alcohol damages the liver over time.          | singular, object              |
| Le diagnosticaron una enfermedad del hígado.   | They diagnosed him with a liver disease.      | singular, *del*                |
| ¿Sabes dónde está el hígado en el cuerpo?      | Do you know where the liver is in the body?   | question                       |
| No debes tomar tanto si te preocupa el hígado. | You shouldn't drink so much if you're worried about your liver. | negation |
| Los hígados de los animales se usan en algunas recetas. | Animal livers are used in some recipes. | plural, subject, *de*          |
