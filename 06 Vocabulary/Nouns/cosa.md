# cosa

## Meaning

*Cosa* means "thing" — a generic, unspecified object, idea, or matter. It's
feminine: *la cosa*, following the regular "-*a* = feminine" pattern. It shows
up constantly in set phrases like *otra cosa* ("something else"), *la misma
cosa* ("the same thing"), and *cualquier cosa* ("anything, whatever").

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | la cosa    |
| Plural   | las cosas  |

## Examples

| Spanish                                       | English                                  | Notes                      |
| ------------------------------------------------ | -------------------------------------------- | ------------------------------ |
| Esa cosa no funciona bien.                       | That thing doesn't work well.               | singular, subject               |
| Tengo muchas cosas que hacer hoy.                | I have a lot of things to do today.         | plural, object                   |
| ¿Qué es esa cosa en la mesa?                     | What is that thing on the table?            | singular, question                |
| No entiendo ni una cosa de lo que dices.         | I don't understand a single thing you say.  | singular, negation                 |
| Hablamos de cosas importantes.                   | We talked about important things.           | plural, after a preposition         |
