# habitación

## Meaning

*Habitación* means "room," most often a bedroom in a home or hotel. It's
feminine: *la habitación*.

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | la habitación   |
| Plural   | las habitaciones |

## Examples

| Spanish                                        | English                                | Notes                    |
| ----------------------------------------------------- | ---------------------------------------------- | -------------------------------- |
| Reservamos una habitación con vista al mar.    | We booked a room with an ocean view.    | singular, object                  |
| Limpié la habitación antes de que llegaran los invitados. | I cleaned the room before the guests arrived. | singular, object          |
| ¿Cuántas habitaciones tiene la casa?           | How many rooms does the house have?     | question, plural                  |
| No hay wifi en esa habitación del hotel.       | There's no wifi in that hotel room.     | negation, *del*                    |
| Las habitaciones del segundo piso tienen balcón. | The second-floor rooms have a balcony. | plural, subject, *del*             |
