# puerta

## Meaning

*Puerta* means "door." It's feminine: *la puerta*. It's also used for "gate" in
some contexts — e.g., *puerta de embarque* ("boarding gate") at an airport.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la puerta    |
| Plural   | las puertas  |

## Examples

| Spanish                                                | English                                        | Notes                     |
| ------------------------------------------------------------ | ------------------------------------------------------- | ------------------------------ |
| La puerta principal está cerrada con llave.                     | The front door is locked.                                  | singular, subject                |
| ¿Cuántas puertas tiene esa casa?                                | How many doors does that house have?                       | plural, question                  |
| Abrimos la puerta cuando escuchamos el timbre.                  | We open the door when we hear the doorbell.                | singular, habitual                |
| No dejes la puerta abierta, por favor.                          | Don't leave the door open, please.                          | singular, negative command        |
| El perro esperó frente a la puerta toda la tarde.               | The dog waited in front of the door all afternoon.          | singular, prepositional phrase    |
