# campeonato

## Meaning

*Campeonato* means "championship," a competition to determine the best
team or player. It's a masculine noun.

## Singular / Plural

| Number   | Form             |
| -------- | ---------------- |
| Singular | el campeonato    |
| Plural   | los campeonatos  |

## Examples

| Spanish                                    | English                                | Notes             |
| ------------------------------------------------- | -------------------------------------------- | --------------------- |
| El campeonato termina este fin de semana.            | The championship ends this weekend.            | statement              |
| ¿Ganaste el campeonato el año pasado?                | Did you win the championship last year?        | question               |
| No clasificamos para el campeonato nacional.         | We didn't qualify for the national championship. | negation             |
| Los campeonatos regionales empiezan en marzo.        | The regional championships start in March.     | plural                 |
| Su equipo llegó a la final del campeonato.           | Her team reached the championship final.       | statement, del         |
