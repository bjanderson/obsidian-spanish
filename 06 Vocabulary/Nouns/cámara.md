# cámara

## Meaning

*Cámara* means "camera." It's feminine: *la cámara*. It also has an
unrelated secondary sense as "chamber" in formal contexts (*cámara de
comercio* = "chamber of commerce") — worth knowing if you see it outside a
tech/photography context.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la cámara      |
| Plural   | las cámaras    |

## Examples

| Spanish                                          | English                                      | Notes                |
