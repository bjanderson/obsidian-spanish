# cultura

## Meaning

*Cultura* means "culture," the shared customs, art, and beliefs of a
group. It's a feminine noun.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la cultura   |
| Plural   | las culturas |

## Examples

| Spanish                                  | English                              | Notes         |
| ----------------------------------------------- | ------------------------------------------- | ----------------- |
| La cultura boliviana es muy rica.                 | Bolivian culture is very rich.               | statement          |
| ¿Conoces bien la cultura de este país?            | Do you know this country's culture well?     | question, de       |
| No respetan la cultura local.                     | They don't respect the local culture.        | negation           |
| Las culturas indígenas tienen tradiciones únicas. | Indigenous cultures have unique traditions.  | plural             |
| Aprendimos mucho sobre la cultura maya.           | We learned a lot about Mayan culture.        | statement          |
