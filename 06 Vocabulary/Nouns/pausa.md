# pausa

## Meaning

*Pausa* means "pause" — a brief stop or break in an action, conversation, or piece of
music. It's a feminine noun, following the regular -a pattern.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la pausa     |
| Plural   | las pausas   |

## Examples

| Spanish                                             | English                                    | Notes                    |
| ------------------------------------------------------- | ----------------------------------------------- | ----------------------------- |
| Hicimos una pausa para descansar.                          | We took a pause to rest.                          | direct object                   |
| La música tuvo una pausa larga antes del final.            | The music had a long pause before the end.        | *del* contraction                 |
| Necesito una pausa antes de seguir trabajando.             | I need a break before continuing to work.         | direct object                     |
| Tómate una pausa breve entre ejercicios.                   | Take a short break between exercises.             | command, reflexive *te*             |
| Hubo una pausa incómoda en la conversación.                | There was an awkward pause in the conversation.   | subject                            |
