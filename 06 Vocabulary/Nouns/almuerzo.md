# almuerzo

## Meaning

*Almuerzo* means "lunch." It's masculine: *el almuerzo*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el almuerzo    |
| Plural   | los almuerzos  |

## Examples

| Spanish                                | English                             | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| El almuerzo estará listo al mediodía.            | Lunch will be ready at noon.                  | statement                             |
| ¿Qué preparaste para el almuerzo?                | What did you make for lunch?                  | question                              |
| No tuvimos tiempo para almorzar hoy.             | We didn't have time for lunch today.          | negation                              |
| Los almuerzos escolares mejoraron este año.      | School lunches improved this year.            | plural                                 |
| Compartimos el almuerzo con unos amigos.         | We shared lunch with some friends.            | statement                              |
