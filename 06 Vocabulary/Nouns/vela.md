# vela

## Meaning

*Vela* means "candle." It's feminine: *la vela*. On a birthday cake, the number of
*velas* usually matches the age being celebrated.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la vela     |
| Plural   | las velas   |

## Examples

| Spanish                                     | English                            | Notes                |
| ---------------------------------------------- | ------------------------------------------ | -------------------------- |
| El pastel tiene una vela.                       | The cake has one candle.                    | statement, singular          |
| ¿Cuántas velas tiene el pastel?                 | How many candles does the cake have?        | question, plural             |
| No encendió la vela a tiempo.                   | She didn't light the candle in time.        | negation                     |
| Las velas se apagaron con el viento.            | The candles went out from the wind.         | plural, subject               |
| Valentina apaga las velas y todos sonríen.      | Valentina blows out the candles and everyone smiles. | plural, direct object |

## Related Vocabulary
