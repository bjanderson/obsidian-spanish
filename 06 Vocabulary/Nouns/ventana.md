# ventana

## Meaning

*Ventana* means "window." It's feminine: *la ventana*.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | la ventana    |
| Plural   | las ventanas  |

## Examples

| Spanish                                                | English                                          | Notes                     |
| ------------------------------------------------------------ | ---------------------------------------------------------- | ------------------------------ |
| La ventana da al jardín.                                        | The window looks out onto the garden.                         | singular, subject                |
| ¿Cuántas ventanas tiene el edificio?                             | How many windows does the building have?                      | plural, question                  |
| Abrimos las ventanas para que entre aire fresco.                 | We open the windows so fresh air comes in.                    | plural, subjunctive clause        |
| No hay cortinas en esa ventana.                                  | There are no curtains on that window.                          | singular, negation                |
| La luz entró por la ventana temprano en la mañana.               | The light came in through the window early in the morning.    | singular, "por" (through)         |
