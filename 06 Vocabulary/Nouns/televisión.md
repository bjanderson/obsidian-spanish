# televisión

## Meaning

*Televisión* means "television." It's feminine: *la televisión*. Strictly,
it refers to the medium/broadcast — watching TV, TV as an institution — while
the physical device is usually called *el televisor* (a related but
distinct word). In everyday speech, though, *televisión* is also used
loosely for the device itself.

## Singular / Plural

| Number   | Form                |
| -------- | ------------------- |
| Singular | la televisión       |
| Plural   | las televisiones    |

## Examples

| Spanish                                            | English                                     | Notes                |
| -------------------------------------------------------- | -------------------------------------------------------- | ------------------------ |
| Los niños ven mucha televisión.                    | The kids watch a lot of television.         | singular, statement  |
| ¿Qué hay en la televisión esta noche?              | What's on television tonight?               | question              |
| No prendas la televisión tan temprano.             | Don't turn on the television so early.      | negative command      |
| Las televisiones del aeropuerto mostraban las noticias. | The airport televisions were showing the news. | plural            |
| Se durmió viendo televisión.                       | He fell asleep watching television.         | statement              |
