# momento

## Meaning

*Momento* means "moment" — a point in time, whether brief (*un momento*, "a
moment") or more general (*en este momento*, "at this moment"). It's masculine:
*el momento*. Common set phrases include *por el momento* ("for the moment, for
now") and *de un momento a otro* ("any moment now").

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el momento   |
| Plural   | los momentos |

## Examples

| Spanish                                          | English                                | Notes                          |
| ------------------------------------------------- | --------------------------------------- | -------------------------------- |
| Este momento es único.                            | This moment is unique.                  | singular, subject                |
| ¿Puedes esperar un momento?                       | Can you wait a moment?                  | question, object                 |
| No recuerdo el momento exacto.                    | I don't remember the exact moment.      | negation, object                 |
| Hablamos de los mejores momentos del viaje.        | We talked about the trip's best moments. | plural, after a preposition, "del" |
| Llegamos al aeropuerto en el último momento.       | We got to the airport at the last moment. | singular, after a preposition, "al" |
