# pantalón

## Meaning

*Pantalón* means "pants" or "trousers." It's masculine: *el pantalón*. In
everyday speech, the plural *los pantalones* is very commonly used even when
talking about a single pair — much like English "pants" is already plural
for one item. Both *el pantalón* and *los pantalones* are correct for "the
pants" (one pair); use whichever sounds natural in context.

## Singular / Plural

| Number   | Form              |
| -------- | ----------------- |
| Singular | el pantalón       |
| Plural   | los pantalones (also used for one pair) |

## Examples

| Spanish                                                  | English                              | Notes    |
| ---------------------------------------------------------- | ------------------------------------------ | ---------- |
| El pantalón me queda un poco largo.                         | The pants are a bit long on me.            | statement, singular form |
| ¿Dónde compraste esos pantalones?                           | Where did you buy those pants?             | question, plural for one pair |
| No me gustan los pantalones ajustados.                      | I don't like tight pants.                  | negation   |
| Los pantalones de mezclilla nunca pasan de moda.            | Denim pants never go out of style.         | plural     |
| Se cambió de pantalón antes de salir.                       | He changed pants before going out.         | statement, singular form |
