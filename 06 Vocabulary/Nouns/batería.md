# batería

## Meaning

*Batería* means "battery" — the rechargeable kind in phones, laptops, and
cars. It's feminine: *la batería*. (Small disposable batteries, like AA
cells, are usually called *pilas* instead — a related but distinct word.)
*Batería* also has an unrelated secondary sense as a musical "drum kit."

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | la batería      |
| Plural   | las baterías    |

## Examples

| Spanish                                     | English                                | Notes                |
| ------------------------------------------- | ---------------------------------------- | ------------------------ |
| Se me acabó la batería del celular.         | My cell phone battery died.            | singular, statement  |
| ¿Tienes un cargador para la batería?        | Do you have a charger for the battery? | question              |
| No compres esa batería, es de mala calidad. | Don't buy that battery, it's poor quality. | negative command  |

| Toca la batería en una banda.               | He plays the drums in a band.          | secondary sense       |
