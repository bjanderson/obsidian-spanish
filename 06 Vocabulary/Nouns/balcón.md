# balcón

## Meaning

*Balcón* means "balcony." It's masculine: *el balcón*. Plural: *los balcones* — the
accent mark drops in the plural, since the stress falls naturally once *-es* is added.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | el balcón     |
| Plural   | los balcones  |

| Spanish                                                        | English                                                  | Notes                     |
