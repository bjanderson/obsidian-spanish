# estrella

## Meaning

*Estrella* means "star," both the astronomical object and, figuratively, a
famous person. It's a feminine noun.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la estrella    |
| Plural   | las estrellas  |

## Examples

| Spanish                                 | English                              | Notes             |
| ------------------------------------------------ | ------------------------------------------- | --------------------- |
| Vimos una estrella fugaz anoche.                    | We saw a shooting star last night.           | statement              |
| ¿Puedes ver la estrella más brillante desde aquí?   | Can you see the brightest star from here?    | question               |
| No hay estrellas visibles por la contaminación.     | There are no visible stars because of the pollution. | negation          |
| Las estrellas brillan más lejos de la ciudad.       | Stars shine brighter far from the city.      | plural                 |
| Se convirtió en una estrella de cine.               | She became a movie star.                     | figurative sense       |
