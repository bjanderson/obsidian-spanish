# computadora

## Meaning

*Computadora* means "computer." It's feminine: *la computadora*, and it's
the standard term used across most of Latin America.

## Singular / Plural

| Number   | Form                |
| -------- | ------------------- |
| Singular | la computadora      |
| Plural   | las computadoras    |

## Examples

| Spanish                                                | English                                          | Notes                |
| ------------------------------------------------------ | -------------------------------------------------- | ---------------------- |
| Prendí la computadora para trabajar.                   | I turned on the computer to work.                | singular, statement  |
| ¿Tienes una computadora portátil?                      | Do you have a laptop computer?                   | question              |
| No puedo abrir el archivo en esta computadora.         | I can't open the file on this computer.          | negation              |
| Las computadoras de la escuela son nuevas.             | The school's computers are new.                  | plural                |
| Guardó el documento en la computadora antes de apagarla. | She saved the document on the computer before turning it off. | singular |
