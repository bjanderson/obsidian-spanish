# idioma

## Meaning

*Idioma* means "language," a language spoken by a people or nation.
Despite ending in *-a*, it's masculine, like other Greek-origin *-ma*
nouns.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el idioma    |
| Plural   | los idiomas  |

## Examples

| Spanish                                  | English                              | Notes         |
| ----------------------------------------------- | ------------------------------------------- | ----------------- |
| El español es un idioma muy hablado.              | Spanish is a widely spoken language.          | statement          |
| ¿Cuántos idiomas hablas?                          | How many languages do you speak?              | question           |
| No domino ningún otro idioma todavía.             | I don't master any other language yet.        | negation           |
| Aprendieron tres idiomas en la escuela.           | They learned three languages at school.       | plural             |
| El idioma oficial del país es el español.         | The country's official language is Spanish.   | statement, del     |
