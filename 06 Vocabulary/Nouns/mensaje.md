# mensaje

## Meaning

*Mensaje* means "message" — a text message, voice message, or message in
general. It's masculine: *el mensaje*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el mensaje     |
| Plural   | los mensajes   |

## Examples

| Spanish                                             | English                                       | Notes                        |
| ------------------------------------------------------- | ----------------------------------------------------- | --------------------------------- |
| Te dejé un mensaje en el celular.                   | I left you a message on your cell phone.      | singular, statement          |
| ¿Leíste mi mensaje?                                 | Did you read my message?                      | question                     |
| No contestó el mensaje todavía.                     | He hasn't answered the message yet.           | negation                     |
| Los mensajes de voz son más rápidos que escribir.   | Voice messages are faster than writing.       | plural                        |
| Le envié un mensaje a mi hermana.                   | I sent a message to my sister.                | personal *a*, singular       |

## Related Vocabulary

- [[teléfono]] — the device a *mensaje* is usually sent from.
- [[correo]] — a near-synonym for a longer *mensaje*.
