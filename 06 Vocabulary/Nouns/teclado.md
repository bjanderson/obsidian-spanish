# teclado

## Meaning

*Teclado* means "keyboard" — most commonly a computer keyboard, but it also
refers to a musical keyboard as a secondary sense. It's masculine: *el
teclado*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el teclado     |
| Plural   | los teclados   |

## Examples

| Spanish                                        | English                                    | Notes                |
| --------------------------------------------------- | -------------------------------------------------- | ---------------------- |
| Se me dañó el teclado de la computadora.       | My computer keyboard broke.                | singular, statement  |
| ¿Prefieres un teclado mecánico?                | Do you prefer a mechanical keyboard?       | question              |
| No encuentro la tecla en este teclado.         | I can't find the key on this keyboard.     | negation              |
| Los teclados inalámbricos usan pilas.          | Wireless keyboards use batteries.          | plural                |
| Toca el teclado como profesional.              | He plays the keyboard like a professional. | secondary sense       |
