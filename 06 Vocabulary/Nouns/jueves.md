# jueves

## Meaning

*Jueves* is Thursday. Days of the week are lowercase in Spanish and
masculine: *el jueves*. Like the rest of Monday through Friday, it's
invariable in the plural — *los jueves* uses the same form as *el jueves*
(compare [[sábado]] and [[domingo]], which pluralize regularly).

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | el jueves  |
| Plural   | los jueves |

## Examples

| Spanish                                     | English                                        | Notes                            |
| -------------------------------------------- | ------------------------------------------------ | ----------------------------------- |
| El jueves viajo a Bolivia.                   | On Thursday I'm traveling to Bolivia.             | *el* + day, specific occurrence      |
| Los jueves vamos al gimnasio.                | On Thursdays we go to the gym.                    | *los* + day, habitual                |
| ¿Trabajas el jueves?                         | Do you work on Thursday?                          | question                              |
| El jueves no hubo clases por el feriado.     | There was no class on Thursday because of the holiday. | statement with explanation      |
| Llegamos el jueves por la mañana.            | We arrive on Thursday morning.                    | combined time expression              |
