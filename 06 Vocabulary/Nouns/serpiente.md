# serpiente

## Meaning

*Serpiente* means "snake." It's feminine: *la serpiente*.

## Singular / Plural

| Number   | Form              |
| -------- | ----------------- |
| Singular | la serpiente      |
| Plural   | las serpientes    |

## Examples

| Spanish                                     | English                                | Notes                          |
| -------------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| La serpiente se escondió entre las rocas.            | The snake hid among the rocks.                | statement                             |
| ¿Es venenosa esa serpiente?                          | Is that snake poisonous?                      | question                              |
| No tocamos la serpiente por precaución.              | We didn't touch the snake as a precaution.    | negation                              |
| Las serpientes de la selva son difíciles de ver.     | The jungle's snakes are hard to see.          | plural                                 |
| El guía nos advirtió sobre una serpiente cercana.    | The guide warned us about a nearby snake.     | statement                              |
