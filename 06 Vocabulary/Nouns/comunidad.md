# comunidad

## Meaning

*Comunidad* means "community" — a group of people who share a place,
interest, or identity. It's a feminine noun.

## Singular / Plural

| Number   | Form              |
| -------- | ----------------- |
| Singular | la comunidad      |
| Plural   | las comunidades   |

## Examples

| Spanish                                          | English                                    | Notes           |
| ------------------------------------------------- | ---------------------------------------------- | ------------------ |
| La comunidad se unió para ayudar a las víctimas.   | The community came together to help the victims. | statement, personal *a* |
| ¿Perteneces a alguna comunidad en línea?           | Do you belong to any online community?          | question             |
| No existe una comunidad tan unida como esta.       | There's no community as united as this one.     | negation             |
| Varias comunidades rurales carecen de agua potable. | Several rural communities lack clean water.    | plural                |
| Organizaron un evento para toda la comunidad.      | They organized an event for the whole community. | statement             |
