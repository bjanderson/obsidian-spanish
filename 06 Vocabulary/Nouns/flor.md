# flor

## Meaning

*Flor* means "flower." It's feminine: *la flor*.

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | la flor    |
| Plural   | las flores |

## Examples

| Spanish                                 | English                             | Notes                          |
| ------------------------------------------------ | -------------------------------------------- | ------------------------------------ |
| Esta flor huele muy bien.                          | This flower smells very good.                 | statement                             |
| ¿Qué flor le regalaste a tu mamá?                  | What flower did you give your mom?            | question, personal *a*                 |
| No cortamos las flores del jardín ajeno.           | We didn't cut the flowers from someone else's garden. | negation                       |
| Las flores de primavera son las más coloridas.     | Spring flowers are the most colorful.         | plural                                 |
| Compramos un ramo de flores para la fiesta.        | We bought a bouquet of flowers for the party. | statement                              |
