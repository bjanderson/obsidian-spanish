# ascensor

## Meaning

*Ascensor* means "elevator" (or "lift"). It's masculine: *el ascensor*. Note:
*elevador* is also common in some Latin American countries (e.g., Mexico); *ascensor*
is the more neutral, pan-regional term.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el ascensor    |
| Plural   | los ascensores |
