# pared

## Meaning

*Pared* means "wall" — an interior or exterior wall of a building. It's feminine:
*la pared*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la pared     |
| Plural   | las paredes  |

## Examples

| Spanish                                             | English                                       | Notes                     |
| ---------------------------------------------------------- | -------------------------------------------------------- | ------------------------------ |
| La pared del comedor es de color azul.                        | The dining room wall is blue.                                | singular, subject                |
| ¿Cuántas paredes tiene esta habitación?                        | How many walls does this room have?                          | plural, question                  |
| Colgamos un cuadro en la pared.                                | We hung a painting on the wall.                               | singular, object of preposition   |
| No hay ventanas en esa pared.                                  | There are no windows on that wall.                            | singular, negation                |
| El niño dibujó una línea en la pared con un lápiz.             | The boy drew a line on the wall with a pencil.                | singular, instrument ("con")       |
