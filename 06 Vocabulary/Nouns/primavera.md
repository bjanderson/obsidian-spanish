# primavera

## Meaning

*Primavera* means "spring," the season. It's feminine: *la primavera*.

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | la primavera    |
| Plural   | las primaveras  |

## Examples

| Spanish                                     | English                                | Notes                       |
| ---------------------------------------------- | ------------------------------------------- | -------------------------------- |
| La primavera llega en septiembre en Bolivia.    | Spring arrives in September in Bolivia.     | statement                        |
| ¿Te gusta más la primavera o el otoño?          | Do you like spring or autumn more?          | question                         |
| No hubo mucha lluvia esta primavera.            | There wasn't much rain this spring.         | negation                         |
| Las primaveras aquí son cortas.                 | Springs here are short.                     | plural                           |
| Las flores florecen en primavera.               | Flowers bloom in spring.                    | statement                        |
