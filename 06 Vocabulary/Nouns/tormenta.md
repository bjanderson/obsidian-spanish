# tormenta

## Meaning

*Tormenta* means "storm" — usually heavy rain, wind, or thunder together.
It's feminine: *la tormenta*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la tormenta    |
| Plural   | las tormentas  |

## Examples

| Spanish                                     | English                                | Notes                       |
| ---------------------------------------------- | ------------------------------------------- | -------------------------------- |
| Una tormenta fuerte llegó anoche.               | A strong storm arrived last night.          | statement                        |
| ¿Vieron la tormenta desde su casa?              | Did you all see the storm from your house?  | question                         |
| No salimos por la tormenta.                     | We didn't go out because of the storm.      | negation                         |
| Las tormentas de verano son comunes aquí.       | Summer storms are common here.              | plural                           |
| El cielo se oscureció antes de la tormenta.     | The sky darkened before the storm.          | statement                        |
