# verano

## Meaning

*Verano* means "summer." It's masculine: *el verano*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el verano    |
| Plural   | los veranos  |

## Examples

| Spanish                               | English                            | Notes                    |
| ------------------------------------------ | ---------------------------------------- | ------------------------------ |
| El verano aquí es muy caluroso.             | Summer here is very hot.                 | statement                      |
| ¿Qué planes tienes para el verano?          | What plans do you have for the summer?   | question                       |
| No fuimos a la playa este verano.           | We didn't go to the beach this summer.   | negation                       |
| Los veranos pasan muy rápido.               | Summers go by very fast.                 | plural                         |
| Trabajé todo el verano pasado.              | I worked all last summer.                | statement                      |

## Related Vocabulary
