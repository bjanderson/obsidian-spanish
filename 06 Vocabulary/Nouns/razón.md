# razón

## Meaning

*Razón* means "reason" — the cause or motive behind something. It's feminine: *la
razón*. The plural drops the written accent: *razones* (the stress falls
naturally on the new syllable, so the accent mark is no longer needed). *Razón*
also appears in the common set phrase *tener razón*, "to be right" (literally "to
have reason") — conjugate *tener*, not *ser* or *estar*, for this expression.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la razón     |
| Plural   | las razones  |

## Examples

| Spanish                                       | English                                    | Notes                          |
| ------------------------------------------------ | ---------------------------------------------- | --------------------------------- |
| No tengo ninguna razón para mentirte.               | I have no reason to lie to you.                  | negation, singular, object         |
| ¿Cuál es la razón de tu decisión?                     | What's the reason for your decision?               | question, singular                  |
| Dio varias razones para no ir.                          | She gave several reasons not to go.                  | plural, object                       |
| Lo hizo por esa razón.                                     | He did it for that reason.                             | singular, after a preposition          |
| Tienes razón, fue mi culpa.                                  | You're right, it was my fault.                           | set phrase "tener razón"               |
