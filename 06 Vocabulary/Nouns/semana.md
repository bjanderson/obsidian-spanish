# semana

## Meaning

*Semana* means "week." It's feminine: *la semana*. Regular *-a* → feminine noun, no
irregularities.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | la semana     |
| Plural   | las semanas   |

## Examples

| Spanish                                     | English                                  | Notes                          |
| ---------------------------------------------- | -------------------------------------------- | ---------------------------------- |
| La semana pasada viajé a Bolivia.             | Last week I traveled to Bolivia.             | singular, subject                    |
| Trabajo toda la semana sin descanso.          | I work all week without a break.             | object                                |
| ¿Cuántas semanas dura el curso?               | How many weeks does the course last?         | plural, question                      |
| No tengo planes para esta semana.             | I don't have plans for this week.            | negation, after a preposition          |
| Nos vemos dentro de dos semanas.              | See you in two weeks.                        | plural, after a preposition             |
