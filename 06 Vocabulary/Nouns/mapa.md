# mapa

## Meaning

*Mapa* means "map." Despite ending in *-a*, it's a **masculine** noun (*el mapa*, not
*la mapa*) — one of a small set of Greek-derived -a nouns (like *el problema*, *el
sistema*, *el programa*) that break the usual -a-is-feminine pattern. Don't apply the
"-a = feminine" rule here.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el mapa      |
| Plural   | los mapas    |

## Examples

| Spanish                                       | English                                | Notes                          |
| -------------------------------------------------- | ------------------------------------------ | ---------------------------------- |
| El mapa muestra todas las carreteras del país.      | The map shows all the roads in the country. | subject, masculine *el*             |
| Busca la ciudad en el mapa.                          | Look for the city on the map.               | command                             |
| Compramos un mapa turístico antes del viaje.         | We bought a tourist map before the trip.    | masculine *un*                      |
| Los mapas antiguos son fascinantes.                  | Old maps are fascinating.                   | plural                              |
| No entiendo este mapa; está muy confuso.             | I don't understand this map; it's very confusing. | masculine demonstrative *este* |
