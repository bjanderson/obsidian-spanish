# pájaro

## Meaning

*Pájaro* means "bird," specifically a small bird. It's masculine: *el
pájaro*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el pájaro    |
| Plural   | los pájaros  |

## Examples

| Spanish                                  | English                              | Notes                          |
| ------------------------------------------------ | -------------------------------------------- | ------------------------------------ |
| Un pájaro cantaba en el árbol.                      | A bird was singing in the tree.               | statement                             |
| ¿Escuchaste ese pájaro esta mañana?                 | Did you hear that bird this morning?          | question                              |
| No dejamos que el pájaro se escapara.               | We didn't let the bird escape.                | negation                              |
| Los pájaros migran antes del invierno.              | Birds migrate before winter.                  | plural                                 |
| Vimos varios pájaros posados en el cable.           | We saw several birds perched on the wire.     | statement                              |

## Related Vocabulary
