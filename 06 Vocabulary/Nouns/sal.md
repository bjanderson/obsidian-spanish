# sal

## Meaning

*Sal* means "salt." It's feminine: *la sal*.

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | la sal     |
| Plural   | las sales  |

## Examples

| Spanish                                | English                              | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| La sal está en la mesa.                          | The salt is on the table.                     | statement                             |
| ¿Me pasas la sal, por favor?                     | Can you pass me the salt, please?             | question                              |
| No le eches tanta sal a la sopa.                 | Don't put so much salt in the soup.           | negation                              |
