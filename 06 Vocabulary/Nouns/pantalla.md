# pantalla

## Meaning

*Pantalla* means "screen" — the display on a phone, computer, television,
or movie theater. It's feminine: *la pantalla*.

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | la pantalla     |
| Plural   | las pantallas   |

## Examples

| Spanish                                         | English                                     | Notes                |
| ---------------------------------------------------- | -------------------------------------------------- | ---------------------- |
| La pantalla del celular está rota.              | The cell phone screen is broken.            | singular, statement  |
| ¿Cuántas pulgadas tiene la pantalla?            | How many inches is the screen?              | question              |
| No veo bien la pantalla desde aquí.             | I can't see the screen well from here.      | negation              |
| Las pantallas grandes cansan menos la vista.    | Large screens tire the eyes less.           | plural                |
| Limpió la pantalla de la computadora.           | She cleaned the computer screen.            | singular               |
