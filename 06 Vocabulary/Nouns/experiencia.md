# experiencia

## Meaning

*Experiencia* means "experience," either a specific event lived through or
accumulated skill/knowledge. It's a feminine noun.

## Singular / Plural

| Number   | Form              |
| -------- | ----------------- |
| Singular | la experiencia    |
| Plural   | las experiencias  |

## Examples

| Spanish                                        | English                                    | Notes         |
| ---------------------------------------------------- | -------------------------------------------------- | ----------------- |
| Fue una experiencia inolvidable.                       | It was an unforgettable experience.                 | statement          |
| ¿Tienes experiencia en este trabajo?                   | Do you have experience in this job?                 | question           |
| No tengo experiencia con niños pequeños.               | I don't have experience with young children.        | negation           |
| Compartimos nuestras experiencias del viaje.           | We shared our experiences from the trip.            | plural             |
| Aprendió mucho a través de la experiencia.             | She learned a lot through experience.                | prepositional phrase |
