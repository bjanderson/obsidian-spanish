# montaña

## Meaning

*Montaña* means "mountain." It's feminine: *la montaña*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la montaña     |
| Plural   | las montañas   |

## Examples

| Spanish                                   | English                                | Notes                    |
| ------------------------------------------------ | --------------------------------------------- | ------------------------------ |
| Esa montaña tiene nieve todo el año.               | That mountain has snow all year.              | statement                      |
| ¿Subieron la montaña el fin de semana?             | Did you all climb the mountain over the weekend? | question                    |
| No vimos la montaña por la neblina.                | We didn't see the mountain because of the fog.  | negation                     |
| Las montañas de Bolivia son impresionantes.        | Bolivia's mountains are impressive.            | plural                         |
| Acampamos cerca de la montaña.                     | We camped near the mountain.                   | statement                      |
