# impresora

## Meaning

*Impresora* means "printer," the machine that prints documents. It's a feminine
noun.

## Singular / Plural

| Number   | Form              |
| -------- | ----------------- |
| Singular | la impresora       |
| Plural   | las impresoras     |

## Examples

| Spanish                                          | English                                | Notes     |
| -------------------------------------------------- | ---------------------------------------- | --------- |
| La impresora no tiene tinta.                        | The printer is out of ink.               | statement |
| ¿Dónde está la impresora de la oficina?             | Where's the office printer?              | question  |
| No funciona la impresora nueva.                     | The new printer doesn't work.            | negation  |
| Necesitamos comprar impresoras para el laboratorio. | We need to buy printers for the lab.     | plural    |
| El técnico revisó la impresora del segundo piso.    | The technician checked the second floor's printer. | *del* |
