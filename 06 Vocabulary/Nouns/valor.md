# valor

## Meaning

*Valor* means "value," either worth/price or, in a different sense,
courage. It's a masculine noun.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | el valor    |
| Plural   | los valores |

## Examples

| Spanish                                     | English                                | Notes             |
| --------------------------------------------- | --------------------------------------------- | --------------------- |
| El valor de la casa subió mucho.                | The house's value went up a lot.               | statement, de          |
| ¿Cuál es el valor de esta moneda antigua?       | What's this old coin's value?                  | question               |
| No tiene valor sentimental para mí.             | It has no sentimental value to me.             | negation               |
| Enseñan valores importantes en esa escuela.     | They teach important values at that school.    | plural, secondary sense |
| Actuó con mucho valor durante el incendio.      | He acted with great courage during the fire.   | secondary sense        |
