# proyecto

## Meaning

*Proyecto* means "project" — a planned piece of work, whether at a job,
school, or in one's personal life.

## Singular / Plural

| Number   | Form              |
| -------- | ----------------- |
| Singular | el proyecto       |
| Plural   | los proyectos     |

## Examples

| Spanish                                        | English                                | Notes             |
| ---------------------------------------------------- | -------------------------------------------- | ---------------------- |
| Terminamos el proyecto antes de la fecha límite.       | We finished the project before the deadline.  | statement                |
| ¿En qué proyecto estás trabajando?                     | What project are you working on?              | question                  |
| No avanzó mucho en el proyecto esta semana.            | He didn't make much progress on the project this week. | negation           |
| Los proyectos del equipo se presentan el viernes.       | The team's projects are presented on Friday.  | plural, del                |
| Le asignaron el proyecto nuevo a Marta.                | They assigned the new project to Marta.       | indirect object            |
