# cerdo

## Meaning

*Cerdo* means "pig." It's masculine: *el cerdo*. As food, it's also the
general word for "pork."

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | el cerdo    |
| Plural   | los cerdos  |

## Examples

| Spanish                               | English                             | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| El cerdo comió toda la mañana.                   | The pig ate all morning.                      | statement                             |
| ¿Cuántos cerdos hay en la granja?                | How many pigs are there on the farm?          | question                              |
| No vendimos ningún cerdo este año.               | We didn't sell a single pig this year.        | negation                              |
| Los cerdos se revuelcan en el barro.             | Pigs roll around in the mud.                  | plural                                 |
| Preparamos carne de cerdo para la cena.          | We prepared pork for dinner.                  | statement, "pork" sense                |
