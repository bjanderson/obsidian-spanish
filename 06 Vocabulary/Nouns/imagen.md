# imagen

## Meaning

*Imagen* means "image" or "picture." It's feminine, and its plural shifts
the written accent: *imágenes*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la imagen    |
| Plural   | las imágenes |

## Examples

| Spanish                                     | English                                | Notes         |
| ---------------------------------------------- | ------------------------------------------ | ----------------- |
| Esa imagen me da miedo.                          | That image scares me.                       | statement          |
| ¿De dónde sacaste esta imagen?                   | Where did you get this image from?          | question           |
| No pude descargar la imagen.                     | I couldn't download the image.              | negation           |
| El museo tiene imágenes de artistas famosos.     | The museum has images by famous artists.    | plural             |
| La calidad de la imagen es excelente.            | The image's quality is excellent.           | *de*-phrase        |
