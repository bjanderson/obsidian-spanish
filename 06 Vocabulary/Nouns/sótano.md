# sótano

## Meaning

*Sótano* means "basement" or "cellar." It's masculine: *el sótano*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el sótano    |
| Plural   | los sótanos  |

## Examples

| Spanish                                                | English                                          | Notes                     |
| ------------------------------------------------------------ | ---------------------------------------------------------- | ------------------------------ |
| El sótano guarda cajas viejas y muebles.                        | The basement holds old boxes and furniture.                    | singular, subject                |
| ¿Cuántos sótanos tiene ese edificio?                             | How many basements does that building have?                    | plural, question                  |
| Bajamos al sótano para buscar las decoraciones.                  | We went down to the basement to get the decorations.           | singular, "al" contraction        |
| No hay luz en el sótano; necesitamos una linterna.               | There's no light in the basement; we need a flashlight.        | singular, negation                |
| Los niños tienen miedo de entrar al sótano solos.                | The kids are afraid to go into the basement alone.             | singular, "al" contraction        |
