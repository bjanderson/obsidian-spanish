# sociedad

## Meaning

*Sociedad* means "society," a community of people living together. It can
also mean a business partnership. It's a feminine noun.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la sociedad    |
| Plural   | las sociedades |

## Examples

| Spanish                                          | English                                     | Notes            |
| ----------------------------------------------------- | ------------------------------------------------ | -------------------- |
| La sociedad cambia todo el tiempo.                     | Society changes all the time.                     | statement             |
| ¿Cómo ve la sociedad este problema?                    | How does society view this problem?               | question              |
| Esa costumbre ya no existe en la sociedad moderna.     | That custom no longer exists in modern society.    | negation              |
| Formaron una sociedad para vender ropa.                | They formed a partnership to sell clothes.         | secondary sense       |
| Las sociedades antiguas tenían reglas muy distintas.   | Ancient societies had very different rules.        | plural                |
