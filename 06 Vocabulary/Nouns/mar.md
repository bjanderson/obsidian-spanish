# mar

## Meaning

*Mar* means "sea." It's normally masculine (*el mar*), though it shows up
as feminine in a few fixed nautical or poetic expressions, like *alta mar*
("high seas").

## Singular / Plural

| Number   | Form      |
| -------- | --------- |
| Singular | el mar    |
| Plural   | los mares |

## Examples

| Spanish                                       | English                                  | Notes              |
| ----------------------------------------------- | ------------------------------------------- | ---------------------- |
| El mar está muy tranquilo hoy.                   | The sea is very calm today.                  | statement               |
| ¿Viste el mar desde el avión?                    | Did you see the sea from the plane?          | question                |
| No me gusta nadar en el mar de noche.            | I don't like swimming in the sea at night.   | negation                |
| Los mares del sur son más fríos.                 | The southern seas are colder.                | plural                  |
| El barco navegó por alta mar toda la noche.      | The ship sailed on the high seas all night.  | fixed expression, fem.  |
