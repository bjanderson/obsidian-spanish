# avión

## Meaning

*Avión* means "airplane." It's masculine: *el avión*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el avión     |
| Plural   | los aviones  |

## Examples

| Spanish                                             | English                                | Notes    |
| ------------------------------------------------------ | ----------------------------------------- | ---------- |
| El avión despega en una hora.                          | The plane takes off in an hour.           | statement  |
| ¿A qué hora aterriza el avión?                         | What time does the plane land?            | question   |
| No hay avión directo a esa ciudad.                     | There's no direct flight to that city.    | negation   |
| Los aviones grandes hacen mucho ruido.                 | Large planes make a lot of noise.         | plural     |
| Preferimos viajar en avión para ahorrar tiempo.        | We prefer to travel by plane to save time. | statement  |
