# martillo

## Meaning

*Martillo* means "hammer." It's a masculine noun, following the regular -o pattern.

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | el martillo     |
| Plural   | los martillos   |

## Examples

| Spanish                                    | English                              | Notes             |
| ------------------------------------------------ | ------------------------------------------ | -------------------- |
| Necesito un martillo para colgar el cuadro.        | I need a hammer to hang the picture.        | direct object          |
| Golpeó el clavo con el martillo.                    | He hit the nail with the hammer.            | instrumental *con*       |
| ¿Dónde dejaste los martillos?                       | Where did you leave the hammers?            | question, plural          |
| El carpintero usa varios martillos distintos.       | The carpenter uses several different hammers. | plural, direct object   |
| No encuentro mi martillo.                           | I can't find my hammer.                     | negation                  |
