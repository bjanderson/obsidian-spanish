# tipo

## Meaning

*Tipo* means "type" or "kind." It's a masculine noun, and colloquially it
can also mean "guy."

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | el tipo    |
| Plural   | los tipos  |

## Examples

| Spanish                                  | English                             | Notes         |
| ----------------------------------------------- | ------------------------------------------ | ----------------- |
| No me gusta ese tipo de música.                   | I don't like that type of music.            | negation           |
| ¿Qué tipo de comida prefieres?                    | What type of food do you prefer?            | question           |
| Este tipo de problema es común.                   | This type of problem is common.             | statement          |
| Hay varios tipos de cuenta bancaria.              | There are several types of bank account.    | plural             |
| Ese tipo que vive al lado es muy amable.          | That guy who lives next door is very kind.  | colloquial sense   |
