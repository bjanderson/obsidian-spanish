# bote

## Meaning

*Bote* means "boat" — typically a small boat (rowboat, motorboat), as
opposed to a large ship (*barco*). It's a masculine noun. In some Latin
American countries (notably Mexico), *bote* is also common slang for "can"
or "jar" — context makes clear which sense is meant.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | el bote     |
| Plural   | los botes   |
