# silla

## Meaning

*Silla* means "chair." It's a feminine noun, following the regular -a pattern.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la silla     |
| Plural   | las sillas   |

## Examples

| Spanish                                     | English                              | Notes                |
| --------------------------------------------------- | -------------------------------------------- | ------------------------ |
| Siéntate en esa silla.                                 | Sit in that chair.                            | command                    |
| Compramos seis sillas nuevas para el comedor.          | We bought six new chairs for the dining room. | plural, direct object       |
| La silla está rota.                                    | The chair is broken.                          | subject                     |
| ¿Me alcanzas una silla, por favor?                     | Can you hand me a chair, please?              | question, indirect object *me* |
| Pusieron las sillas alrededor de la mesa.              | They put the chairs around the table.         | plural, direct object          |
