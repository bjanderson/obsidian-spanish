# bosque

## Meaning

*Bosque* means "forest" or "woods." It's masculine: *el bosque*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el bosque    |
| Plural   | los bosques  |

## Examples

| Spanish                                  | English                              | Notes                    |
| ---------------------------------------------- | ------------------------------------------ | ------------------------------ |
| El bosque estaba muy tranquilo.                 | The forest was very quiet.                 | statement                      |
| ¿Caminaron por el bosque ayer?                  | Did you all walk through the forest yesterday? | question                    |
| No encontramos el sendero del bosque.           | We didn't find the forest trail.           | negation                       |
| Los bosques de esta zona son densos.            | The forests in this area are dense.        | plural                         |
| Nos perdimos dentro del bosque.                 | We got lost inside the forest.             | statement                      |
