# sistema

## Meaning

*Sistema* means "system." Despite ending in *-a* — the ending that normally signals a
feminine noun — *sistema* is **masculine**: *el sistema*, not *la sistema*. This is
because it comes from Greek by way of the *-ma* ending, and Greek-origin *-ma* nouns
keep their original masculine gender in Spanish. It's the same exception that applies
to [[tema]] and [[problema]] — worth memorizing as a small group rather than as
one-off exceptions.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | el sistema    |
| Plural   | los sistemas  |

## Examples

| Spanish                                              | English                                          | Notes              |
| ------------------------------------------------------ | --------------------------------------------------- | --------------------- |
| El sistema no funciona bien.                          | The system doesn't work well.                      | singular, subject     |
| Necesitamos actualizar el sistema.                    | We need to update the system.                       | object                |
| ¿Cómo funciona este sistema?                          | How does this system work?                          | question              |
| No confío en ese sistema.                             | I don't trust that system.                          | negation, after de/en |
| Los sistemas educativos varían mucho entre países.    | Educational systems vary a lot between countries.   | plural, subject        |
