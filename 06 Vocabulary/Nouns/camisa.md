# camisa

## Meaning

*Camisa* means "shirt." It's feminine: *la camisa*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la camisa    |
| Plural   | las camisas  |

## Examples

| Spanish                                          | English                              | Notes    |
| ------------------------------------------------------ | ----------------------------------------- | ---------- |
| La camisa está planchada y lista.                      | The shirt is ironed and ready.            | statement  |
| ¿Te gusta esta camisa azul?                            | Do you like this blue shirt?              | question   |
| No encuentro mi camisa favorita.                       | I can't find my favorite shirt.           | negation   |
| Las camisas de algodón son más cómodas.                | Cotton shirts are more comfortable.       | plural     |
| Se puso una camisa blanca para la entrevista.          | He put on a white shirt for the interview. | statement  |
