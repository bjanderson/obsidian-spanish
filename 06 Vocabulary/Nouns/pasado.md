# pasado

## Meaning

*Pasado* means "past," the time that already happened. It's a masculine
noun, almost always used in the singular.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el pasado    |
| Plural   | los pasados  |

## Examples

| Spanish                                    | English                              | Notes         |
| ----------------------------------------------- | ------------------------------------------- | ----------------- |
| No quiero hablar del pasado.                     | I don't want to talk about the past.         | negation, del      |
| ¿Conoces el pasado de esta ciudad?               | Do you know this city's past?                | question           |
| Su pasado fue muy difícil.                       | His past was very difficult.                 | statement          |
| Dejó atrás los errores del pasado.               | She left behind the past's mistakes.         | del                |
| Los pasados turbulentos de esas naciones son conocidos. | Those nations' turbulent pasts are well known. | plural, rare  |
