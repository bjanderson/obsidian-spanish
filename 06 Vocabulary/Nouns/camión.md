# camión

## Meaning

*Camión* means "truck," typically a vehicle for hauling cargo. It's
masculine: *el camión*. Note the regional twist: in Mexico, *camión*
commonly means "bus" instead — context (or the country) tells you which
sense is meant.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | el camión     |
| Plural   | los camiones  |

| Spanish                                              | English                                   | Notes    |
