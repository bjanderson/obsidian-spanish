# papa

## Meaning

*Papa* means "potato." It's feminine: *la papa*. This is the standard word for
"potato" across most of Latin America; Spain uses *patata* instead. Note the accent:
*papá* (with a written accent on the last syllable) means "dad" — a different word.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | la papa      |
| Plural   | las papas    |
