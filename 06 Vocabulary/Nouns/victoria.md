# victoria

## Meaning

*Victoria* means "victory" or "win." It's a feminine noun.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | la victoria   |
| Plural   | las victorias |

## Examples

| Spanish                                | English                              | Notes         |
| --------------------------------------------- | ------------------------------------------- | ----------------- |
| La victoria fue muy emocionante.                | The victory was very exciting.               | statement          |
| ¿Celebraron la victoria anoche?                 | Did they celebrate the victory last night?   | question           |
| No esperábamos esa victoria.                    | We weren't expecting that victory.           | negation           |
| Han tenido varias victorias seguidas.           | They've had several wins in a row.           | plural             |
| El equipo consiguió la victoria en el último minuto. | The team got the win in the last minute. | statement          |
