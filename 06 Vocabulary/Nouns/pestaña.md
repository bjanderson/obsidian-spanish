# pestaña

## Meaning

*Pestaña* means "eyelash." It's feminine: *la pestaña*. Common in the idiom
*quemarse las pestañas* ("to burn the midnight oil," study intensely).

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | la pestaña     |
| Plural   | las pestañas   |
