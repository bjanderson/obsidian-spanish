# ceja

## Meaning

*Ceja* means "eyebrow." It's feminine: *la ceja*. Common in the idiom
*levantar la ceja* ("to raise an eyebrow," showing skepticism or surprise).

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la ceja     |
| Plural   | las cejas   |
