# fin

## Meaning

*Fin* means "end" — the point where something finishes, whether that's a
story, a project, a period of time, or an event. It's masculine: *el fin*. It
also shows up in common fixed phrases like *al fin* ("finally"), *por fin*
("at last"), *a fin de* ("in order to"), and *fin de semana* ("weekend").

## Singular / Plural

| Number   | Form     |
| -------- | -------- |
| Singular | el fin   |
| Plural   | los fines |

## Examples

| Spanish                                    | English                             | Notes                            |
| ------------------------------------------- | ------------------------------------ | --------------------------------- |
| El fin de la película fue muy triste.        | The end of the movie was very sad.    | singular, subject                  |
| No vemos el fin del problema todavía.        | We don't see the end of the problem yet. | negation, "del"                |
| ¿Cuándo es el fin del curso?                 | When is the end of the course?        | question                           |
| Trabajamos duro a fin de terminar a tiempo.   | We work hard in order to finish on time. | fixed phrase "a fin de"          |
| Los fines de esas historias son inesperados.  | The endings of those stories are unexpected. | plural, subject             |
