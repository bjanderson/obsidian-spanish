# desayuno

## Meaning

*Desayuno* means "breakfast." It's masculine: *el desayuno*.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el desayuno    |
| Plural   | los desayunos  |

## Examples

| Spanish                                | English                              | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| El desayuno ya está servido.                     | Breakfast is already served.                  | statement                             |
| ¿A qué hora tomas desayuno?                      | What time do you have breakfast?              | question                              |
| No desayunamos nada esta mañana.                 | We didn't eat breakfast this morning.         | negation                              |
| Los desayunos del hotel son abundantes.          | The hotel's breakfasts are plentiful.         | plural                                 |
| Preparó un desayuno completo para todos.         | She made a full breakfast for everyone.       | statement                              |
