# clase

## Meaning

*Clase* means "class," either a school lesson, a category/type, or social
rank. It's a feminine noun.

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | la clase   |
| Plural   | las clases |

## Examples

| Spanish                                    | English                              | Notes         |
| ----------------------------------------------- | ------------------------------------------- | ----------------- |
| La clase de español empieza a las nueve.         | Spanish class starts at nine.                | statement          |
| ¿A qué clase perteneces tú?                      | What class do you belong to?                 | question, secondary sense |
| No fui a clase ayer por estar enfermo.           | I didn't go to class yesterday because I was sick. | negation      |
| Las clases terminan en diciembre.                | Classes end in December.                     | plural             |
| Ese carro es de primera clase.                   | That car is first class.                     | secondary sense    |
