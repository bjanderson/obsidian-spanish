# metro

## Meaning

*Metro* means "subway" or "metro system" — the underground/urban rail
network in a city. It's masculine: *el metro*. *Metro* is also the word for
the unit of length "meter" (*el metro mide cien centímetros*); context makes
the two senses easy to tell apart, and this file focuses on the
transportation sense.

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | el metro    |
| Plural   | los metros  |
