# tiempo

## Meaning

*Tiempo* is masculine (*el tiempo*). It covers both "time" in the general sense
(duration, the clock) and, separately, "weather" — context makes clear which one is
meant: *No tengo tiempo* ("I don't have time") vs. *Hace buen tiempo* ("The weather
is nice"). The plural *tiempos* usually means "eras" or "times" in a broader,
historical sense (*otros tiempos*, "other times").

## Singular / Plural

| Number   | Form         |
| ---------- | -------------- |
| Singular       | el tiempo      |
| Plural           | los tiempos    |

## Examples

| Spanish                                | English                          | Notes                        |
| ------------------------------------------ | -------------------------------------- | --------------------------------- |
| No tengo tiempo para eso ahora.             | I don't have time for that right now.  | subject/object, "time" sense       |
| ¿Qué tiempo hace hoy?                       | What's the weather like today?         | "weather" sense, question          |
| Vivimos en tiempos difíciles.               | We're living in difficult times.        | plural, broader sense               |
| Espero el resultado desde hace tiempo.      | I've been waiting for the result for a while. | after a preposition            |
| El tiempo de la reunión cambió.             | The meeting time changed.               | possessive *de*-phrase              |
