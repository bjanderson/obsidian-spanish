# noche

## Meaning

*Noche* means "night." It's feminine: *la noche*. It shows up in common
greetings and expressions like *buenas noches* ("good night/good evening") and
*esta noche* ("tonight").

## Singular / Plural

| Number   | Form        |
| -------- | ----------- |
| Singular | la noche    |
| Plural   | las noches  |

## Examples

| Spanish                                    | English                              | Notes                          |
| ----------------------------------------------- | ----------------------------------------- | ---------------------------------- |
| Esta noche voy a salir con amigos.              | I'm going out with friends tonight.       | singular, subject/time expression    |
| Trabajamos varias noches seguidas.              | We worked several nights in a row.        | plural, object                        |
| ¿Qué haces esta noche?                          | What are you doing tonight?               | question                              |
| No duermo bien por las noches.                  | I don't sleep well at night.              | negation, plural, after a preposition  |
| Volvimos a casa a las once de la noche.         | We got home at eleven at night.           | after a preposition, singular          |
