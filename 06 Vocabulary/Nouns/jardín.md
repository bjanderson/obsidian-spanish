# jardín

## Meaning

*Jardín* means "garden" or "yard" — usually the planted, green part of a property.
It's masculine: *el jardín*. Plural: *los jardines* — note the accent mark disappears
in the plural, since the stress falls naturally on that syllable once *-es* is added.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el jardín      |
| Plural   | los jardines   |
