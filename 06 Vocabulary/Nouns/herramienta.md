# herramienta

## Meaning

*Herramienta* means "tool" — an instrument used to perform a task, literal
or figurative (a "tool" for solving a problem). It's a feminine noun.

## Singular / Plural

| Number   | Form               |
| -------- | ------------------ |
| Singular | la herramienta     |
| Plural   | las herramientas   |

## Examples

| Spanish                                          | English                                | Notes             |
| ------------------------------------------------- | ----------------------------------------- | -------------------- |
| Necesito una herramienta para arreglar esto.       | I need a tool to fix this.                 | statement              |
| ¿Qué herramienta usaste para cortar el metal?      | What tool did you use to cut the metal?    | question                |
| No tengo la herramienta correcta para este trabajo. | I don't have the right tool for this job. | negation                |
| Guardó todas las herramientas en la caja.          | He kept all the tools in the box.          | plural                   |
| El internet es una herramienta poderosa para aprender. | The internet is a powerful tool for learning. | figurative sense    |
