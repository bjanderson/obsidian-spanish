# película

## Meaning

*Película* means "movie" or "film." It's a feminine noun.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | la película   |
| Plural   | las películas |

## Examples

| Spanish                                  | English                             | Notes         |
| ----------------------------------------------- | ------------------------------------------ | ----------------- |
| Vimos una película de terror anoche.              | We watched a horror movie last night.       | statement          |
| ¿Qué película quieres ver hoy?                    | What movie do you want to watch today?      | question           |
| No me gustó la película para nada.                | I didn't like the movie at all.             | negation           |
| Esas películas ganaron varios premios.            | Those movies won several awards.            | plural             |
| El director de la película es muy conocido.       | The movie's director is very well known.    | statement, de      |
