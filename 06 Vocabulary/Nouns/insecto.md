# insecto

## Meaning

*Insecto* means "insect." It's masculine: *el insecto*.

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | el insecto    |
| Plural   | los insectos  |

## Examples

| Spanish                                  | English                              | Notes                          |
| ------------------------------------------------ | -------------------------------------------- | ------------------------------------ |
| Ese insecto es enorme.                              | That insect is huge.                          | statement                             |
| ¿Qué insecto pica tanto en esta zona?               | Which insect bites so much in this area?      | question                              |
| No identificamos el insecto que encontramos.        | We didn't identify the insect we found.       | negation                              |
| Los insectos de la selva son muy variados.          | The jungle's insects are very varied.         | plural                                 |
| Usamos repelente para evitar los insectos.          | We used repellent to avoid the insects.       | statement                              |
