# hoja

## Meaning

*Hoja* means "leaf." It's feminine: *la hoja*. It also means a "sheet" of
paper (*una hoja de papel*).

## Singular / Plural

| Number   | Form       |
| -------- | ---------- |
| Singular | la hoja    |
| Plural   | las hojas  |

## Examples

| Spanish                                 | English                              | Notes                          |
| ------------------------------------------------ | -------------------------------------------- | ------------------------------------ |
| Una hoja cayó del árbol.                           | A leaf fell from the tree.                    | statement                             |
| ¿Me pasas una hoja de papel?                       | Can you pass me a sheet of paper?             | question, secondary sense               |
| No barrimos las hojas del patio todavía.           | We haven't swept the yard's leaves yet.       | negation                              |
| Las hojas cambian de color en otoño.               | Leaves change color in autumn.                | plural                                 |
| El viento arrastró las hojas por la calle.         | The wind swept the leaves down the street.    | statement                              |
