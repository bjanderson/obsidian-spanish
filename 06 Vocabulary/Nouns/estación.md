# estación

## Meaning

*Estación* has two common senses: a "season" of the year, or a "station"
(train, bus, radio). It's feminine: *la estación*.

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | la estación     |
| Plural   | las estaciones  |

## Examples

| Spanish                                          | English                                    | Notes                          |
| ----------------------------------------------------- | ----------------------------------------------- | ------------------------------------ |
| Mi estación favorita es el otoño.                       | My favorite season is autumn.                      | statement, "season" sense              |
| ¿Dónde queda la estación de tren?                       | Where's the train station?                        | question, "station" sense              |
| No encontramos la estación de autobuses.                | We didn't find the bus station.                    | negation                               |
| Las estaciones cambian el paisaje por completo.         | The seasons change the landscape completely.       | plural, "season" sense                 |
| Escuchamos esa estación de radio todos los días.        | We listen to that radio station every day.         | statement, "station" sense              |
