# postre

## Meaning

*Postre* means "dessert." It's masculine: *el postre*.

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el postre    |
| Plural   | los postres  |

## Examples

| Spanish                                | English                              | Notes                          |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| El postre estuvo delicioso.                      | The dessert was delicious.                    | statement                             |
| ¿Qué postre pediste?                             | What dessert did you order?                   | question                              |
| No comimos postre después de la cena.            | We didn't eat dessert after dinner.           | negation                              |
| Los postres de esa pastelería son famosos.       | That bakery's desserts are famous.            | plural                                 |
| Preparó un postre especial para el cumpleaños.   | She made a special dessert for the birthday.  | statement                              |
