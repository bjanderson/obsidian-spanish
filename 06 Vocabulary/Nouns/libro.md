# libro

## Meaning

*Libro* means "book." It's a masculine noun, following the regular -o pattern.

## Singular / Plural

| Number   | Form         |
| ---------- | -------------- |
| Singular      | el libro       |
| Plural           | los libros     |

## Examples

| Spanish                                | English                          | Notes                        |
| ------------------------------------------ | -------------------------------------- | --------------------------------- |
| El libro está sobre la mesa.                | The book is on the table.              | subject                            |
| ¿Ya leíste el libro que te presté?          | Did you already read the book I lent you? | direct object, question         |
| No encuentro mi libro de español.           | I can't find my Spanish book.          | direct object, negation            |
| Compré tres libros nuevos.                  | I bought three new books.              | plural                             |
| La portada del libro es muy bonita.         | The book's cover is very pretty.       | possessive *de*-phrase, *del*       |
