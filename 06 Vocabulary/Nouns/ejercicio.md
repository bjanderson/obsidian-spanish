# ejercicio

## Meaning

*Ejercicio* means "exercise," physical activity or a practice task (like a
homework exercise). It's a masculine noun.

## Singular / Plural

| Number   | Form           |
| -------- | -------------- |
| Singular | el ejercicio   |
| Plural   | los ejercicios |

## Examples

| Spanish                                    | English                                | Notes         |
| --------------------------------------------- | --------------------------------------------- | ----------------- |
| Hago ejercicio todas las mañanas.                | I exercise every morning.                       | statement          |
| ¿Terminaste el ejercicio de matemáticas?         | Did you finish the math exercise?               | question, secondary sense |
| No tengo tiempo para hacer ejercicio hoy.        | I don't have time to exercise today.            | negation           |
| El profesor puso cinco ejercicios de tarea.      | The teacher assigned five exercises for homework. | plural           |
| Caminar es un buen ejercicio para el corazón.    | Walking is good exercise for the heart.         | statement          |
