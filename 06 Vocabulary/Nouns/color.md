# color

## Meaning

*Color* means "color." It's a masculine noun — a common point of confusion
for English speakers, since many Spanish nouns ending in *-or* are
masculine. Common phrase: *de color* + [color name] ("colored ___," e.g.
*de color verde*, "green-colored").

## Singular / Plural

| Number   | Form         |
| -------- | ------------ |
| Singular | el color     |
| Plural   | los colores  |
