# diversión

## Meaning

*Diversión* means "fun" or "entertainment" — an activity that amuses or
delights. It's a feminine noun.

## Singular / Plural

| Number   | Form             |
| -------- | ---------------- |
| Singular | la diversión     |
| Plural   | las diversiones  |

## Examples

| Spanish                                          | English                                | Notes             |
| ------------------------------------------------- | ----------------------------------------- | -------------------- |
| El parque de diversiones abre a las diez.          | The amusement park opens at ten.           | idiomatic phrase       |
| ¿Qué haces para diversión los fines de semana?     | What do you do for fun on weekends?        | question                |
| No hubo mucha diversión en esa fiesta.             | There wasn't much fun at that party.       | negation                |
| Las diversiones del pueblo incluyen ferias y conciertos. | The town's entertainment includes fairs and concerts. | plural |
| Todo fue diversión hasta que empezó a llover.      | It was all fun until it started raining.   | statement                |
