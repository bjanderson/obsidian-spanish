# archivo

## Meaning

*Archivo* means "file" — most often a computer file, but also a physical file,
record, or archive (e.g. a filing cabinet at an office). It's a masculine noun.

## Singular / Plural

| Number   | Form            |
| -------- | --------------- |
| Singular | el archivo      |
| Plural   | los archivos    |

## Examples

| Spanish                                       | English                              | Notes    |
| ------------------------------------------------ | ---------------------------------------- | -------- |
| Guardé el archivo en la carpeta equivocada.        | I saved the file in the wrong folder.    | statement|
| ¿Enviaste el archivo por correo?                   | Did you send the file by email?          | question |
| No puedo abrir este archivo.                       | I can't open this file.                  | negation |
| Borré varios archivos viejos del escritorio.       | I deleted several old files from the desktop. | plural, *del* |
| El archivo del cliente está incompleto.            | The client's file is incomplete.         | *del*    |
