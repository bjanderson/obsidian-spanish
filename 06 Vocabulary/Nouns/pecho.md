# pecho

## Meaning

*Pecho* means "chest." It's masculine: *el pecho*. Common in idioms like
*sacar pecho* ("to puff out one's chest, be proud") and *dar el pecho* ("to
breastfeed").

## Singular / Plural

| Number   | Form          |
| -------- | ------------- |
| Singular | el pecho      |
| Plural   | los pechos    |
