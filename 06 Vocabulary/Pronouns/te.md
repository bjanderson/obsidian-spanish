# te

## Meaning

*Te* is the unstressed object pronoun for [[tú]] — it works as a direct
object, an indirect object, or a reflexive pronoun. It goes right before a
conjugated verb, or attaches to the end of an infinitive, gerund, or
affirmative command: *Voy a llamarte* ("I'm going to call you").

## Examples

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Te veo mañana.                              | I'll see you tomorrow.                   | direct object                      |
| Te mandé un mensaje ayer.                   | I sent you a message yesterday.          | indirect object                    |
| ¿Te duchaste esta mañana?                   | Did you shower this morning?             | reflexive, question                |
| No te preocupes por eso.                    | Don't worry about that.                  | reflexive, negative command         |
| Voy a llamarte esta noche.                  | I'm going to call you tonight.           | direct object, attached to infinitive |

## Related Vocabulary

- [[tú]] — the subject-pronoun form *te* stands in for.
- [[ti]] — the stressed form used after a preposition instead of *te*.
