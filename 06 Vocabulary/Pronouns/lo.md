# lo

## Meaning

*Lo* has two distinct jobs. First, as a direct object pronoun, it replaces a
masculine singular noun ("him"/"it") or stands for a whole idea already mentioned
("it," neuter): *Lo compré ayer* ("I bought it yesterday"), *No lo sabía* ("I didn't
know it," referring back to a fact). This vault follows the neutral rule: *lo* is
the direct object, never *le* — using *le* here would be leísmo, which this vault
avoids (see [[le-les|le / les]]).

Second, *lo* + an adjective turns that adjective into an abstract noun: *lo bueno*
("the good part"/"what's good"), *lo difícil* ("the difficult part").

## Core Uses

| Use                          | Pattern              | Example                     | English                        |
| -------------------------------- | ------------------------ | --------------------------------- | ------------------------------------ |
| Direct object (masc./neuter thing)     | [verb] + lo                | Lo vi en la tienda.                 | I saw him/it at the store.             |
| Direct object (referring to an idea)      | [verb] + lo                  | Ya lo sé.                            | I already know (it).                    |
| Abstract noun                                | lo + [adjective]                | Lo importante es llegar a tiempo.    | The important thing is to arrive on time. |

## Examples

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| ¿Viste a Pedro? — Sí, lo vi ayer.           | Did you see Pedro? — Yes, I saw him yesterday. | direct object, person         |
| Necesito el informe; ¿lo terminaste?        | I need the report; did you finish it?    | direct object, thing               |
| No lo puedo creer.                          | I can't believe it.                      | direct object, idea                 |
| Lo mejor de este trabajo es el equipo.      | The best thing about this job is the team. | abstract noun                    |
| Entiendo lo que dices.                      | I understand what you're saying.         | abstract, with *que*                |
