# se

## Meaning

*Se* is a third-person pronoun with several distinct jobs, all covered by the same
short word. It's invariant — the same form for singular and plural, masculine and
feminine.

## Core Uses

**1. Reflexive** — the subject does the action to itself: *usted/él/ella* and
*ustedes/ellos/ellas* forms.

| Spanish                     | English                    |
| ------------------------------ | ------------------------------ |
| Ella se lava las manos.          | She washes her hands.            |
| Ellos se levantan temprano.      | They get up early.                |

**2. Reciprocal** — "each other," always plural.

| Spanish                | English                |
| -------------------------- | -------------------------- |
| Se aman.                     | They love each other.        |
| Mis padres se conocieron en Cochabamba. | My parents met each other in Cochabamba. |

**3. Impersonal/passive** — no specific subject, like English "one" or a passive
sentence.

| Spanish                          | English                              |
| ------------------------------------ | ------------------------------------------ |
| Se habla español aquí.                 | Spanish is spoken here.                       |
| Se necesita paciencia para esto.       | One needs patience for this.                   |

**4. Replacing *le*/*les*** — before a direct object pronoun starting with *l-*
(*lo*, *la*, *los*, *las*), the indirect object pronouns *le*/*les* become *se*
instead. See B1.4.1.2 for the full rule.

| Without the rule (wrong)   | With the rule (correct)  | English                    |
| ------------------------------- | ----------------------------- | ------------------------------- |
| ~~Le lo dije.~~                     | Se lo dije.                     | I told it to him/her.             |

## Examples

| Spanish                                     | English                                | Notes                        |
| ------------------------------------------------ | --------------------------------------------- | --------------------------------- |
| Mi hermano se afeita todas las mañanas.            | My brother shaves every morning.              | reflexive                          |
| ¿A qué hora se acuestan los niños?                  | What time do the kids go to bed?              | reflexive, question                |
| Se escriben cartas cada semana.                     | They write to each other every week.          | reciprocal                         |
| No se puede fumar en el edificio.                    | Smoking isn't allowed in the building.        | impersonal                         |
| Le compré un regalo a mi hermana y se lo di ayer.    | I bought my sister a gift and gave it to her yesterday. | *le* → *se* before *lo* |
