# ti

## Meaning

*Ti* is the stressed pronoun used after most prepositions instead of [[tú]],
parallel to how [[mí]] replaces *yo*: *para ti* ("for you"), *sin ti*
("without you"). With *con*, the two fuse into *contigo* ("with you") instead
of *con ti* — the same way *con* + *mí* becomes [[conmigo]].

## Examples

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Este regalo es para ti.                     | This gift is for you.                    | statement                          |
| ¿Es este mensaje para ti?                   | Is this message for you?                 | question                           |
| Pienso mucho en ti.                         | I think about you a lot.                 | statement                          |
| No quiero ir sin ti.                        | I don't want to go without you.          | negation                           |
| Confío en ti completamente.                 | I trust you completely.                  | statement                          |

## Related Vocabulary

- [[te]] — the unstressed object-pronoun form.
- [[conmigo]] — the parallel fused form for "with me," built the same way *contigo* is.
- [[contigo]] — the fused form *ti* takes right after *con*.
