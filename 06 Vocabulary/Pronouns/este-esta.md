# este / esta

## Meaning

*Este* and *esta* are demonstratives — "this" — pointing to something close to
the speaker: *este* masculine, *esta* feminine. Both work as an adjective before
a noun (*este libro*, "this book"; *esta casa*, "this house") and, on their own,
as a pronoun standing in for the noun (*Prefiero este*, "I prefer this one").
There's also a neuter form, *esto*, used when there's no specific noun in mind
(*¿Qué es esto?*, "What is this?").

Don't confuse *esta* (demonstrative, no accent) with *está* (accented, a form of
the verb *estar*, "is"): *Esta está lista* ("This one is ready") uses both in the
same sentence with different meanings.

## Full Paradigm

| Gender / Number   | Form   |
| -------------------- | -------- |
| Masculine singular      | este     |
| Feminine singular        | esta     |
| Masculine plural           | estos    |
| Feminine plural              | estas    |
| Neuter (no specific noun)      | esto     |

## Examples

| Spanish                                | English                          | Notes                        |
| ------------------------------------------ | -------------------------------------- | --------------------------------- |
| Este restaurante es excelente.              | This restaurant is excellent.          | adjective, before a noun           |
| ¿Cuál prefieres, este o el otro?            | Which do you prefer, this one or the other? | pronoun, standing alone       |
| Este es mi hermano menor.                   | This is my younger brother.            | pronoun, introducing someone       |
| Esta camisa me queda bien.                  | This shirt fits me well.               | adjective, before a noun           |
| ¿Te gusta esta o la otra?                   | Do you like this one or the other?     | pronoun, standing alone            |
| Esta está lista para servir.                | This one is ready to serve.            | pronoun + *está* (verb), contrast   |
| Estos zapatos me quedan pequeños.           | These shoes are too small for me.      | masculine plural                   |
| Estas galletas están recién horneadas.      | These cookies are freshly baked.       | feminine plural                    |
| ¿Qué es esto?                                | What is this?                          | neuter, no specific noun            |
