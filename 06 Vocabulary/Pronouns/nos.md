# nos

## Meaning

*Nos* is the first-person plural object pronoun and, like [[me]], covers three
roles: direct object ("us"), indirect object ("to us"), and reflexive/reciprocal
("ourselves"/"each other").

## Core Uses

| Use                | Pattern              | Example                     | English                          |
| --------------------- | ------------------------- | ---------------------------------- | -------------------------------------- |
| Direct object              | [verb] + nos                  | Nos invitaron a la boda.             | They invited us to the wedding.          |
| Indirect object                | [verb] + nos                    | Nos explicó el plan.                 | He explained the plan to us.              |
| Reflexive                          | [verb] + nos                       | Nos levantamos temprano.             | We get up early.                          |
| Reciprocal                           | [verb] + nos                          | Nos conocemos desde niños.           | We've known each other since childhood.    |

## Examples

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Nos vieron en el centro.                    | They saw us downtown.                    | direct object                      |
| ¿Nos puedes ayudar con esto?                | Can you help us with this?               | indirect object, question          |
| Nos vamos de vacaciones mañana.             | We're leaving on vacation tomorrow.      | reflexive                          |
| Nos escribimos cada semana.                 | We write to each other every week.       | reciprocal                         |
| No nos dijeron la hora exacta.              | They didn't tell us the exact time.      | indirect object, negation          |
