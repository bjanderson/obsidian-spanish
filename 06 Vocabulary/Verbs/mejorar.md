# mejorar

## Meaning

*Mejorar* means "to improve" or "to get better" — it works both
transitively (improving something) and intransitively (getting better
yourself): *Mejoré mi español este año* ("I improved my Spanish this
year"), *Mi abuela ha mejorado mucho* ("My grandmother has gotten a lot
better"). It's a fully regular *-ar* verb — no stem change and no spelling
change.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | mejoro      |
| tú                       | mejoras     |
| usted / él / ella        | mejora      |
| nosotros / nosotras      | mejoramos   |
| ustedes / ellos / ellas  | mejoran     |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Mejoro un poco más cada día.               | I improve a little more every day.    | *yo*                             |
| ¿Mejoras tu técnica con estas clases?      | Are you improving your technique with these classes? | *tú*, question         |
| Ella mejora rápido después de la cirugía.  | She's recovering quickly after the surgery. | *ella*                     |
| Mejoramos el servicio cada trimestre.      | We improve the service every quarter. | *nosotros*                       |
| No mejoran las condiciones del contrato.   | They're not improving the terms of the contract. | *ellos*, negation         |
