# suponer

## Meaning

*Suponer* means "to suppose" or "to assume" — believing something is probably true
without full confirmation. It conjugates exactly like *poner* with the *su-* prefix
attached: irregular *yo* form (*supongo*), an irregular preterite stem (*supuse*),
irregular future/conditional stems (*supondr-*), and an irregular past participle
(*supuesto*, also the word for "assumption"/"of course," as in *por supuesto*).

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | supongo     |
| tú                       | supones     |
| usted / él / ella        | supone      |
| nosotros / nosotras      | suponemos   |
| ustedes / ellos / ellas  | suponen     |

**Examples:**

| Spanish                                   | English                             | Notes                  |
| ------------------------------------------ | ------------------------------------- | ------------------------ |
| Supongo que tienes razón.                   | I suppose you're right.               | *yo*, irregular *supongo* |
| ¿Supones que va a llover?                   | Do you suppose it's going to rain?    | *tú*, question             |
| Ella supone que llegaremos tarde.           | She assumes we'll arrive late.        | *ella*                      |
| Suponemos que el vuelo se retrasará.        | We assume the flight will be delayed. | *nosotros*                  |
| Ellos suponen que todo saldrá bien.         | They assume everything will turn out fine. | *ellos*                |

## Commands (Imperative)

*Suponer* is rarely used as a direct command — you don't usually order someone to
"suppose" something outright. It shows up mostly in soft, hedging phrases like
*supongamos que...* ("let's suppose that...").

| Form      | Affirmative | Negative        |
| --------- | ----------- | ---------------- |
| tú        | supón       | no supongas      |
| usted     | suponga     | no suponga       |
| nosotros  | supongamos  | no supongamos    |
| ustedes   | supongan    | no supongan      |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Supongamos que tienes razón.         | Let's suppose you're right.         | *nosotros*, affirmative, hedging     |
| No supongas nada sin preguntar.      | Don't assume anything without asking. | *tú*, negative                      |

## Gerund and Past Participle

| Form             | Spanish    | English    |
| ---------------- | ---------- | ---------- |
| Gerund (-ing)    | suponiendo | supposing  |
| Past Participle  | supuesto   | supposed   |

**Examples:**

| Spanish                                     | English                             | Notes                    |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------- |
| Suponiendo que llueva, llevaremos paraguas.      | Assuming it rains, we'll bring umbrellas. | gerund, conditional sense  |
| Por supuesto que voy a la fiesta.                | Of course I'm going to the party.       | *supuesto* as fixed phrase   |
