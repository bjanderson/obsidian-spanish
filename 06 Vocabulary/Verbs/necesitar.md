# necesitar

## Meaning

*Necesitar* means "to need" — a fully regular *-ar* verb with no stem changes or
spelling adjustments anywhere in its paradigm. It's followed directly by a noun or
an infinitive: *Necesito agua* ("I need water"), *Necesito salir* ("I need to go
out").

## Present Indicative

| Subject                 | Conjugation  |
| ------------------------ | -------------- |
| yo                       | necesito      |
| tú                       | necesitas     |
| usted / él / ella        | necesita      |
| nosotros / nosotras      | necesitamos   |
| ustedes / ellos / ellas  | necesitan     |

**Examples:**

| Spanish                                | English                              | Notes                    |
| ------------------------------------------ | -------------------------------------- | ---------------------------- |
| Necesito descansar un poco.                 | I need to rest a little.               | *yo*                          |
| ¿Necesitas ayuda con la maleta?             | Do you need help with the suitcase?    | *tú*, question                 |
| Ella necesita más tiempo para decidir.      | She needs more time to decide.         | *ella*                          |
| Necesitamos comprar leche.                  | We need to buy milk.                   | *nosotros*                       |
| No necesitan más excusas.                   | They don't need more excuses.          | *ellos*, negation                 |

## Commands (Imperative)

*Necesitar* is rarely used as a direct command — needing something isn't usually
something you order someone to do. The forms exist mainly for reference.

| Form     | Affirmative | Negative       |
| -------- | ----------- | --------------- |
| tú       | necesita    | no necesites   |
| usted    | necesite    | no necesite    |
| nosotros | necesitemos | no necesitemos |
| ustedes  | necesiten   | no necesiten   |

**Examples:**

| Spanish                              | English                          | Notes                          |
| ------------------------------------------ | --------------------------------------- | ------------------------------------ |
| No necesites tanto para ser feliz.          | Don't need so much to be happy.         | *tú*, negative, figurative             |

## Gerund and Past Participle

| Form             | Spanish      | English    |
| ---------------- | ------------ | ---------- |
| Gerund (-ing)    | necesitando  | needing    |
| Past Participle  | necesitado   | needed     |

**Examples:**

| Spanish                                          | English                                | Notes                    |
| ------------------------------------------------- | ------------------------------------------------ | ---------------------------- |
| Necesitando ayuda, llamó a su hermano.              | Needing help, he called his brother.              | gerund, adverbial use          |
| El proyecto sigue necesitado de más fondos.         | The project is still in need of more funding.     | past participle as adjective |
