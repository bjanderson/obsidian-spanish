# ocupar

## Meaning

*Ocupar* means "to occupy" — a space, a position, or someone's time. It's often used
reflexively, *ocuparse de*, meaning "to take care of/handle": *Me ocupo de eso*
("I'll take care of that"). It's a fully regular *-ar* verb.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | ocupo       |
| tú                       | ocupas      |
| usted / él / ella        | ocupa       |
| nosotros / nosotras      | ocupamos    |
| ustedes / ellos / ellas  | ocupan      |

**Examples:**

| Spanish                                | English                            | Notes           |
| ------------------------------------------ | ---------------------------------------- | ------------------ |
| Ocupo el mismo cargo desde hace un año.      | I've held the same position for a year.  | *yo*                 |
| ¿Ocupas mucho espacio en la oficina?          | Do you take up a lot of space in the office? | *tú*, question      |

| Ocupamos el segundo piso del edificio.          | We occupy the second floor of the building. | *nosotros*             |
| No ocupan toda la sala.                          | They don't occupy the whole room.        | *ellos*, negation             |
