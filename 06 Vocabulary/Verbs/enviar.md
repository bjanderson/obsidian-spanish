# enviar

## Meaning

*Enviar* means "to send" — dispatching something to a person or place: *Envío el
paquete hoy* (I'm sending the package today). It's close in meaning to *mandar*,
though *enviar* often sounds a touch more formal or precise (common in written and
business contexts), while *mandar* is the more casual, everyday choice and also
covers "to order/command," a sense *enviar* doesn't have. *Enviar* is a *-iar* verb
with a written-accent shift: the stress falls on the *í* in every present-tense form
except *nosotros* — *envío, envías, envía, enviamos, envían* — and the same pattern
carries into the present subjunctive and the *tú* command.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | envío       |
| tú                       | envías      |
| usted / él / ella        | envía       |
| nosotros / nosotras      | enviamos    |
| ustedes / ellos / ellas  | envían      |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Envío el informe todos los lunes.         | I send the report every Monday.       | *yo*, accented *í*            |
| ¿Envías tú las facturas o las envía él?   | Do you send the invoices, or does he? | *tú*, question, accented *í*  |
| Ella envía la carta certificada.          | She sends the letter by certified mail. | *ella*, accented *í*        |
| Enviamos los documentos por correo electrónico. | We send the documents by email.  | *nosotros*, no accent needed  |
| Mis colegas no envían nada sin revisarlo. | My colleagues don't send anything without reviewing it. | *ellos*, negation, accented *í* |

## Present Subjunctive

| ------------------------ | ------------- |

| tú                       | envíes      |
| usted / él / ella        | envíe       |
| nosotros / nosotras      | enviemos    |

**Examples:**

| Spanish                                       | English                                  | Notes                        |
| ------------------------------------------------- | --------------------------------------------- | -------------------------------- |
| Espero que envíe el paquete pronto.               | I hope she sends the package soon.            | *ella*, wish clause, accented *í* |

| Dudo que envíen el pedido esta semana.            | I doubt they'll send the order this week.     | *ellos*, doubt clause, accented *í* |

| Spanish                                          | English                                    | Notes                        |

## Commands (Imperative)

| --------- | ----------- | -------------- |
| tú        | envía       | no envíes     |
| usted     | envíe       | no envíe      |
| nosotros  | enviemos    | no enviemos   |
| ustedes   | envíen      | no envíen     |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Envíame el archivo por correo.       | Send me the file by email.          | *tú*, affirmative, accented *í*     |
| No envíes ese mensaje todavía.       | Don't send that message yet.        | *tú*, negative, accented *í*        |
| Enviemos la propuesta hoy mismo.     | Let's send the proposal today.      | *nosotros*, affirmative             |

## Gerund and Past Participle

| Form             | Spanish   | English  |
| ---------------- | --------- | -------- |
| Gerund (-ing)    | enviando  | sending  |
| Past Participle  | enviado   | sent     |

**Examples:**

| Spanish                                     | English                             | Notes                    |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------- |
| Enviando el mensaje temprano, evitó el retraso.  | Sending the message early, she avoided the delay. | gerund, adverbial use |
| Ya te he enviado toda la documentación.          | I've already sent you all the documentation. | past participle in present perfect |
