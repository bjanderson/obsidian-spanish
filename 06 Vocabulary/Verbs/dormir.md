# dormir

## Meaning

*Dormir* means "to sleep." It's an *o → ue* stem-changing verb in the present tense
(except *nosotros*), and it shifts *o → u* in the preterite third-person forms and
the gerund. Used reflexively, *dormirse* means "to fall asleep" — a different focus
(the moment of drifting off) from plain *dormir* (the state of sleeping).

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | duermo      |
| tú                       | duermes     |
| usted / él / ella        | duerme      |
| nosotros / nosotras      | dormimos    |
| ustedes / ellos / ellas  | duermen     |

**Examples:**

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | -------------------------------------- | --------------------------------- |
| Duermo ocho horas cada noche.               | I sleep eight hours every night.       | *yo*                                |
| ¿Duermes bien en este colchón?              | Do you sleep well on this mattress?    | *tú*, question                      |
| Mi bebé duerme toda la noche ya.            | My baby sleeps all night now.          | *él*                                |
| Dormimos poco durante los exámenes.         | We sleep little during exams.          | *nosotros*                          |
| Los gatos duermen casi todo el día.         | Cats sleep almost all day.             | *ellos*                             |

**Examples:**

| Spanish                          | English                        | Notes                              |

| Duerma tranquilo, todo está bien.       | Sleep peacefully, everything's fine.  | *usted*, affirmative                        |

**Examples:**

| Spanish                                       | English                                | Notes                    |
