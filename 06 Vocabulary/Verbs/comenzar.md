# comenzar

## Meaning

*Comenzar* means "to begin" or "to start," a close synonym of *empezar*. It's an
*e → ie* stem-changing verb (*comienzo*, not *comenzo*), and its preterite *yo* form
has a *z → c* spelling change (*comencé*, not *comenzé*) to keep the soft sound
before *e*.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | comienzo    |
| tú                       | comienzas   |
| usted / él / ella        | comienza    |
| nosotros / nosotras      | comenzamos  |
| ustedes / ellos / ellas  | comienzan   |

**Examples:**

| Spanish                                | English                              | Notes                    |
| ------------------------------------------ | -------------------------------------- | ---------------------------- |
| Comienzo el nuevo trabajo el lunes.         | I start the new job on Monday.        | *yo*                          |
| ¿A qué hora comienzas a estudiar?           | What time do you start studying?      | *tú*, question                 |
| La clase comienza a las nueve en punto.     | Class starts at nine sharp.           | *ella*                          |
| Comenzamos el proyecto la próxima semana.   | We're starting the project next week. | *nosotros*                       |
| Los exámenes comienzan mañana.              | The exams start tomorrow.             | *ellos*                           |

**Examples:**

| Spanish                       | English                     | Notes                          |
| ----------------------------------- | ---------------------------------- | ------------------------------------ |

| Comencemos de una vez.               | Let's get started already.         | *nosotros*, affirmative                |
