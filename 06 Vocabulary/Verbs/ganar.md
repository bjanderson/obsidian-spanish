# ganar

## Meaning

*Ganar* covers both "to win" (a game, a prize) and "to earn" (money, a living) —
one verb where English uses two. It's a fully regular *-ar* verb.

## Present Indicative

| Subject | Conjugation |
| --- | --- |
| yo | gano |
| tú | ganas |
| usted / él / ella | gana |
| nosotros / nosotras | ganamos |
| ustedes / ellos / ellas | ganan |

**Examples:**

| Spanish | English | Notes |
| --- | --- | --- |
| Gano un buen sueldo. | I earn a good salary. | *yo* |
| ¿Ganas más ahora que antes? | Do you earn more now than before? | *tú*, question |
| Ella gana el torneo casi siempre. | She wins the tournament almost every time. | *ella* |
| Ganamos el partido por dos goles. | We won the game by two goals. | *nosotros* |
| No ganan lo suficiente para vivir bien. | They don't earn enough to live well. | negation |
