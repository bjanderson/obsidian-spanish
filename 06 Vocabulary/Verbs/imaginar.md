# imaginar

## Meaning

*Imaginar* means "to imagine." It's often used reflexively, *imaginarse*, with the
same meaning and a slightly more emphatic feel: *¡Imagínate!* ("Just imagine!").
It's a fully regular *-ar* verb.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | imagino     |
| tú                       | imaginas    |
| usted / él / ella        | imagina     |
| nosotros / nosotras      | imaginamos  |
| ustedes / ellos / ellas  | imaginan    |

**Examples:**

| Spanish                                | English                            | Notes           |
| ------------------------------------------ | ---------------------------------------- | ------------------ |
| Imagino un futuro mejor.                     | I imagine a better future.               | *yo*                 |
| ¿Te imaginas viviendo en otro país?           | Can you imagine living in another country? | *tú*, question, reflexive |
| Ella se imagina la casa perfecta.               | She imagines the perfect house.          | *ella*, reflexive         |
| Imaginamos varias posibilidades.                 | We imagine several possibilities.        | *nosotros*                  |
| No se imaginan lo difícil que fue.                | They can't imagine how hard it was.      | *ellos*, negation, reflexive   |
