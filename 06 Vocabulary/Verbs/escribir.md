# escribir

## Meaning

*Escribir* means "to write." It's regular throughout every conjugated tense —
its only irregularity is the past participle, *escrito*, which doesn't follow
the usual *-ido* pattern.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | escribo     |
| tú                       | escribes    |
| usted / él / ella        | escribe     |
| nosotros / nosotras      | escribimos  |
| ustedes / ellos / ellas  | escriben    |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Escribo en mi diario todas las noches.     | I write in my journal every night.    | *yo*                            |
| ¿Escribes cartas a mano todavía?           | Do you still write letters by hand?   | *tú*, question                  |
| Ella escribe artículos para una revista.   | She writes articles for a magazine.   | *ella*                          |
| Escribimos juntos el guion.                | We write the script together.         | *nosotros*                      |
| No escriben mucho por correo.              | They don't write much by mail.        | *ellos*, negation                 |

| Spanish                                       | English                                  | Notes                        |

## Commands (Imperative)

| tú        | escribe     | no escribas   |
| usted     | escriba     | no escriba    |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Escribe tu nombre aquí.              | Write your name here.               | *tú*, affirmative                   |
| No escribas con tanta prisa.         | Don't write in such a hurry.        | *tú*, negative                      |
| Escriban sus respuestas abajo.       | Write your answers below.           | *ustedes*, affirmative               |

## Gerund and Past Participle

| Form             | Spanish      | English |
| ---------------- | ------------ | ------- |
| Gerund (-ing)    | escribiendo  | writing |
| Past Participle  | escrito      | written |

**Examples:**

| Spanish                                     | English                             | Notes                    |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------- |
| Escribiendo despacio, evitó los errores.         | Writing slowly, she avoided mistakes.    | gerund, adverbial use         |
| Este libro está escrito en español sencillo.     | This book is written in simple Spanish.  | past participle as adjective  |
