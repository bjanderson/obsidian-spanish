# decidir

## Meaning

*Decidir* means "to decide," usually followed by an infinitive or *que* + clause:
*Decidí quedarme* ("I decided to stay"). It's a fully regular *-ir* verb — no stem
changes, no spelling adjustments.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | decido      |
| tú                       | decides     |
| usted / él / ella        | decide      |
| nosotros / nosotras      | decidimos   |
| ustedes / ellos / ellas  | deciden     |

**Examples:**

| Spanish                                | English                            | Notes           |
| ------------------------------------------ | ---------------------------------------- | ------------------ |
| Yo decido qué hacemos hoy.                   | I decide what we do today.               | *yo*                 |
| ¿Tú decides o decido yo?                      | Do you decide or do I?                   | *tú*, question         |
| Ella decide rápido casi siempre.               | She decides quickly almost always.       | *ella*                    |
| Decidimos juntos las cosas importantes.         | We decide important things together.     | *nosotros*                  |
| No deciden nada sin consultarnos.                | They don't decide anything without consulting us. | *ellos*, negation    |
