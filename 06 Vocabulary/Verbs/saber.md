# saber

## Meaning

*Saber* means "to know" facts, information, or how to do something: *Sé la
respuesta* ("I know the answer"), *Sabe nadar* ("She knows how to swim"). It
contrasts with [[conocer]], which means "to know" in the sense of being
familiar with a person, place, or thing. Its *yo* form is irregular (*sé*),
and the preterite and both subjunctives use an irregular *sup-*/*sep-* stem.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | sé          |
| tú                       | sabes       |
| usted / él / ella        | sabe        |
| nosotros / nosotras      | sabemos     |
| ustedes / ellos / ellas  | saben       |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Sé hablar tres idiomas.                    | I know how to speak three languages.  | *yo*                            |
| ¿Sabes qué hora es?                        | Do you know what time it is?          | *tú*, question                  |
| Ella sabe cocinar muy bien.                | She knows how to cook very well.      | *ella*                          |
| No sabemos la respuesta todavía.           | We don't know the answer yet.         | *nosotros*, negation              |
| Ellos no saben nada del accidente.         | They don't know anything about the accident. | *ellos*, negation           |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | sabe        | no sepas      |
| usted     | sepa        | no sepa       |
| nosotros  | sepamos     | no sepamos    |
| ustedes   | sepan       | no sepan      |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Sabe que esto es importante.         | Know that this is important.        | *tú*, affirmative, rarely used      |
| No sepas más de lo necesario.        | Don't know more than necessary.     | *tú*, negative, uncommon             |
| Sepan que cuentan con mi apoyo.      | Know that you have my support.      | *ustedes*, affirmative, formal note   |
