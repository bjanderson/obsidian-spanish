# correr

## Meaning

*Correr* means "to run" — physically running, and by extension, things that move
quickly or flow: *correr riesgos* ("to take risks"), *el tiempo corre* ("time is
running out"). It's a fully regular *-er* verb with no stem changes or spelling
quirks anywhere in its conjugation.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | corro       |
| tú                       | corres      |
| usted / él / ella        | corre       |
| nosotros / nosotras      | corremos    |
| ustedes / ellos / ellas  | corren      |

**Examples:**

| Spanish                                | English                              | Notes                       |
| -------------------------------------------- | -------------------------------------------- | -------------------------------- |
| Corro todas las mañanas antes del trabajo.     | I run every morning before work.              | *yo*                              |
| ¿Corres en el parque o en la calle?             | Do you run in the park or on the street?      | *tú*, question                    |
| Ella corre muy rápido para su edad.             | She runs very fast for her age.               | *ella*                            |
| Corremos juntos los domingos.                    | We run together on Sundays.                   | *nosotros*                        |
| Los niños corren por el patio.                    | The kids run around the yard.                 | *ellos*                           |
