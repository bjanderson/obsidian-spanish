# permitir

## Meaning

*Permitir* means "to allow" or "to permit" — giving someone else the go-ahead to do
something. It's a fully regular *-ir* verb, no stem changes or spelling adjustments
anywhere in its paradigm.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | permito     |
| tú                       | permites    |
| usted / él / ella        | permite     |
| nosotros / nosotras      | permitimos  |
| ustedes / ellos / ellas  | permiten    |

**Examples:**

| Spanish                                     | English                                | Notes                     |
| ------------------------------------------- | --------------------------------------------- | ---------------------------- |
| El reglamento no permite mascotas aquí.       | The rules don't allow pets here.               | *él*, negation              |
| ¿Me permites pasar?                            | Will you let me by?                            | *tú*, question               |
| Mis padres no me permiten llegar tarde.        | My parents don't let me arrive late.           | *ellos*, negation            |
| Permitimos cambios hasta el viernes.           | We allow changes until Friday.                 | *nosotros*                   |
| El médico le permite hacer ejercicio suave.    | The doctor allows him to do light exercise.    | *él*, indirect object *le*    |
