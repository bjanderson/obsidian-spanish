# cantar

## Meaning

*Cantar* means "to sing." It's a fully regular *-ar* verb — every tense follows the
standard *-ar* pattern with no stem changes or spelling adjustments.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | canto       |
| tú                       | cantas      |
| usted / él / ella        | canta       |
| nosotros / nosotras      | cantamos    |
| ustedes / ellos / ellas  | cantan      |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Canto en la ducha todas las mañanas.       | I sing in the shower every morning.   | *yo*                            |
| ¿Cantas en algún coro?                     | Do you sing in a choir?               | *tú*, question                  |
| Mi abuela canta boleros viejos.            | My grandmother sings old boleros.     | *ella*                          |
| Cantamos juntos en la fiesta.              | We sang together at the party.        | *nosotros*                      |
| Los niños no cantan bien todavía.          | The kids don't sing well yet.         | *ellos*, negation                |
