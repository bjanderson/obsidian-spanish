# parecer

## Meaning

*Parecer* means "to seem" or "to appear": *Parece cansado* ("He seems
tired"). It works a lot like [[gustar]] — often used with an indirect object
pronoun: *Me parece buena idea* ("It seems like a good idea to me"). The
reflexive form *parecerse a* means "to resemble": *Se parece a su padre*
("He looks like his father"). Its only irregularity is a *c → zc* change in
the *yo* form of the present and throughout the subjunctive.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | parezco     |
| tú                       | pareces     |
| usted / él / ella        | parece      |
| nosotros / nosotras      | parecemos   |
| ustedes / ellos / ellas  | parecen     |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Parezco mayor con este corte de pelo.      | I look older with this haircut.       | *yo*, irregular *zc*             |
| ¿Te parece bien el plan?                   | Does the plan sound good to you?      | *tú*, question, *gustar*-like     |
| Ella se parece mucho a su madre.           | She looks a lot like her mother.      | *ella*, reflexive, "to resemble"   |
| Nos parecemos en muchas cosas.             | We're alike in a lot of ways.         | *nosotros*, reciprocal reflexive    |
| No parecen muy contentos.                  | They don't seem very happy.           | *ellos*, negation                  |

## Commands (Imperative)

*Parecer* is rarely used as a direct command — "seeming" isn't something you
order someone into. The forms exist mainly in set phrases like *no parezca
raro* ("don't act strange").

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | parece      | no parezcas   |
| usted     | parezca     | no parezca    |
| nosotros  | parezcamos  | no parezcamos |
| ustedes   | parezcan    | no parezcan   |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| No parezcas tan nervioso.            | Don't seem so nervous.              | *tú*, negative                      |
