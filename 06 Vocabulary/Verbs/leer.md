# leer

## Meaning

*Leer* means "to read": *Leo el periódico* (I read the newspaper). It's a regular
*-er* verb in terms of endings, but its stem ends in a vowel (*le-*), so the unstressed
*i* of certain endings turns into *y* between two vowels. This shows up in the
preterite third-person forms (*leyó, leyeron*), the gerund (*leyendo*), and the
imperfect subjunctive (*leyera*). Every other written *i* that follows a vowel in the
stem carries a written accent instead — *leí, leíste, leído* — to keep it as its own
syllable. Other verbs with this same *-er/-ir* + vowel-stem pattern include *creer*,
*caer*, and *oír*.

| ------------------------ | ------------ |
| yo                       | leo        |
| tú                       | lees       |
| usted / él / ella        | lee        |
| nosotros / nosotras      | leemos     |
| ustedes / ellos / ellas  | leen       |

**Examples:**

| Spanish                                  | English                              | Notes             |
| -------------------------------------------- | ----------------------------------------- | -------------------- |
| Leo una novela nueva cada mes.                | I read a new novel every month.           | *yo*                |
| ¿Lees el periódico por la mañana?             | Do you read the newspaper in the morning? | *tú*, question       |

| Leemos las instrucciones antes de empezar.    | We read the instructions before starting. | *nosotros*           |
| Los niños no leen bien de noche sin luz.      | The kids don't read well at night without light. | *ellos*, negation |
