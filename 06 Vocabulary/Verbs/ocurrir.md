# ocurrir

## Meaning

*Ocurrir* means "to occur" or "to happen" — a more formal synonym for
[[pasar]] in this sense: *Ocurrió un accidente* ("An accident occurred"). Like
[[existir]], it's used overwhelmingly in the third person, describing events
rather than people. The reflexive *ocurrírsele a alguien* means "for an idea
to occur to someone," using the same indirect-object-pronoun pattern as
[[gustar]]: *Se me ocurrió una idea* ("An idea occurred to me").

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Se me ocurre una idea mejor.               | A better idea occurs to me.           | impersonal, *gustar*-like pattern |
| ¿Se te ocurre algo para el regalo?         | Can you think of anything for the gift? | *tú* (as indirect object), question |

| Ocurrimos por casualidad en el mismo lugar. | We happened to be in the same place by chance. | *nosotros*                    |
| No ocurren cambios de la noche a la mañana. | Changes don't happen overnight.       | impersonal, negation             |

## Commands (Imperative)

*Ocurrir* is essentially never used as a direct command — events don't take
orders. The forms exist grammatically but have no real everyday use.
