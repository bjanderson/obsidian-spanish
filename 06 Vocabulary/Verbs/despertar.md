# despertar

## Meaning

*Despertar* means "to wake (someone) up." It's an *e → ie* stem-changing verb in the
present tense (except *nosotros*). It's most often used reflexively as *despertarse*
("to wake oneself up") when talking about your own waking up — this file covers the
base, non-reflexive paradigm, and the reflexive form simply adds *me/te/se/nos/se*
before the same conjugated verb: *Me despierto a las seis* ("I wake up at six").

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | despierto   |
| tú                       | despiertas  |
| usted / él / ella        | despierta   |
| nosotros / nosotras      | despertamos |
| ustedes / ellos / ellas  | despiertan  |

**Examples:**

| Spanish                                    | English                              | Notes                        |
| ------------------------------------------- | -------------------------------------- | --------------------------------- |
| Despierto a mis hijos a las siete.           | I wake my kids up at seven.             | *yo*                                |
| ¿Despiertas temprano los fines de semana?    | Do you wake up early on weekends?       | *tú*, question                      |
| El ruido despierta a todo el edificio.       | The noise wakes up the whole building.  | *él*                                 |
| Nos despertamos con el sonido de la lluvia.  | We woke up to the sound of the rain.    | *nosotros*                          |
| Ellos despiertan al bebé sin querer.         | They accidentally wake up the baby.     | *ellos*                             |
