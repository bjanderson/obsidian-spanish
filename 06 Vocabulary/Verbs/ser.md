# ser

## Meaning

*Ser* is one of Spanish's two verbs for "to be," used for identity, inherent
characteristics, origin, material, time, and possession. The core contrast is
with [[estar]]: *ser* covers what something fundamentally *is*, while *estar*
covers where it *is* or the condition it's currently *in*. *Es doctora* ("She's
a doctor," identity) vs. *Está cansada* ("She's tired," temporary state, with
*estar*). *Ser* is highly irregular in almost every tense.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | soy         |
| tú                       | eres        |
| usted / él / ella        | es          |
| nosotros / nosotras      | somos       |
| ustedes / ellos / ellas  | son         |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Soy de Bolivia.                            | I'm from Bolivia.                     | *yo*, origin                   |
| ¿Eres estudiante?                          | Are you a student?                    | *tú*, identity, question       |
| Marta es muy trabajadora.                  | Marta is very hardworking.             | *ella*, characteristic          |
| Somos buenos amigos.                       | We're good friends.                    | *nosotros*                     |
| Mis padres no son de aquí.                 | My parents aren't from here.           | *ellos*, negation               |

**Examples:**

| Spanish                                     | English                                | Notes                        |
| --------------------------------------------- | ---------------------------------------- | ------------------------------ |

**Examples:**

| Spanish                                       | English                                  | Notes                        |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | sé          | no seas       |
| usted     | sea         | no sea        |
| nosotros  | seamos      | no seamos     |
| ustedes   | sean        | no sean       |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Sé tú mismo.                         | Be yourself.                        | *tú*, affirmative                   |
| No seas tan duro contigo mismo.      | Don't be so hard on yourself.       | *tú*, negative                      |
| Sean pacientes, por favor.           | Please be patient.                  | *ustedes*, affirmative               |

**Examples:**
