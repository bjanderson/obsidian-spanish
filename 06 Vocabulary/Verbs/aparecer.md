# aparecer

## Meaning

*Aparecer* means "to appear" or "to show up" — something or someone becomes visible
or turns up unexpectedly. It's a *-zc-* verb: the *yo* form inserts a *z* before the
*c* (*aparezco*), and that same *zc* pattern carries into the present subjunctive.
Otherwise it's regular.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | aparezco    |
| tú                       | apareces    |
| usted / él / ella        | aparece     |
| nosotros / nosotras      | aparecemos  |
| ustedes / ellos / ellas  | aparecen    |

**Examples:**

| Spanish                                    | English                              | Notes                    |
| ------------------------------------------ | ---------------------------------------- | ---------------------------- |
| Siempre aparezco tarde a las reuniones.     | I always show up late to meetings.       | *yo*                          |
| ¿Por qué apareces tan cansado hoy?          | Why do you look so tired today?          | *tú*, question                 |
| El error aparece solo en ciertos casos.     | The error appears only in certain cases. | *él*                            |
| No aparecemos en la lista final.            | We don't appear on the final list.       | *nosotros*, negation             |
| Los resultados aparecen en pantalla.        | The results appear on screen.            | *ellos*                          |

## Commands (Imperative)

*Aparecer* is uncommon as a direct command — you don't usually order someone to
"appear." The forms exist mainly in scolding or urgent contexts.

| Form     | Affirmative | Negative       |
| -------- | ----------- | --------------- |
| tú       | aparece     | no aparezcas   |
| usted    | aparezca    | no aparezca    |
| nosotros | aparezcamos | no aparezcamos |
| ustedes  | aparezcan   | no aparezcan   |

**Examples:**

| Spanish                              | English                            | Notes                          |
| ----------------------------------------- | ---------------------------------------- | ------------------------------------ |
| ¡Aparece de una vez!                       | Show up already!                        | *tú*, affirmative, urgent             |
| No aparezcas sin avisar la próxima vez.    | Don't show up without warning next time. | *tú*, negative                        |

## Gerund and Past Participle

| Form             | Spanish     | English    |
| ---------------- | ----------- | ---------- |
| Gerund (-ing)    | apareciendo | appearing  |
| Past Participle  | aparecido   | appeared   |

**Examples:**

| Spanish                                           | English                                  | Notes                    |
| -------------------------------------------------- | ------------------------------------------------ | ---------------------------- |
| Apareciendo de la nada, sorprendió a todos.         | Appearing out of nowhere, he surprised everyone.  | gerund, adverbial use          |
| El sospechoso sigue desaparecido, no ha aparecido.  | The suspect is still missing; he hasn't turned up. | past participle, compound tense |
