# desayunar

## Meaning

*Desayunar* means "to have breakfast" or "to eat breakfast." It's a regular
*-ar* verb, so every tense follows the standard *-ar* pattern with no stem
change or spelling shift.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ----------- |
| yo                      | desayuno    |
| tú                      | desayunas   |
| usted / él / ella       | desayuna    |
| nosotros / nosotras     | desayunamos |
| ustedes / ellos / ellas | desayunan   |

**Examples:**

| Spanish                                  | English                                | Notes     |
| ----------------------------------------- | --------------------------------------- | --------- |
| Desayuno café con pan cada mañana.        | I have coffee and bread for breakfast every morning. | statement |
| ¿A qué hora desayunas?                    | What time do you have breakfast?        | question  |
| Ella desayuna huevos y jugo.              | She has eggs and juice for breakfast.   | statement |
| Desayunamos juntos los domingos.          | We have breakfast together on Sundays.  | statement |
| Ellos no desayunan antes de correr.       | They don't have breakfast before running. | negation  |
