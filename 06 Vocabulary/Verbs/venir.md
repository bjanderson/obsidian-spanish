# venir

## Meaning

*Venir* means "to come" — movement toward the speaker, the opposite of
[[ir]]. It follows the same irregularity pattern as [[tener]]: a *g* inserted
in the *yo* form, an *e → ie* stem change in most present-tense forms, an
irregular preterite stem (*vin-*), and an irregular future/conditional stem
(*vendr-*).

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | vengo       |
| tú                       | vienes      |
| usted / él / ella        | viene       |
| nosotros / nosotras      | venimos     |
| ustedes / ellos / ellas  | vienen      |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Vengo de trabajar.                         | I'm coming from work.                 | *yo*                            |
| ¿Vienes a la fiesta esta noche?            | Are you coming to the party tonight?  | *tú*, question                  |
| Ella viene todos los sábados.              | She comes every Saturday.             | *ella*                          |
| Venimos juntos desde la estación.          | We're coming together from the station. | *nosotros*                     |
| No vienen a la reunión.                    | They aren't coming to the meeting.    | *ellos*, negation                 |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | ven         | no vengas     |
| usted     | venga       | no venga      |
| nosotros  | vengamos    | no vengamos   |
| ustedes   | vengan      | no vengan     |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Ven aquí un momento.                 | Come here for a moment.             | *tú*, affirmative, irregular form   |
| No vengas tan tarde otra vez.        | Don't come so late again.           | *tú*, negative                      |
| Vengan cuando quieran.               | Come whenever you like.             | *ustedes*, affirmative               |

| Gerund (-ing)    | viniendo  | coming  |

**Examples:**

| Spanish                                     | English                             | Notes                    |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------- |
| Viniendo del trabajo, se detuvo a comprar pan.   | Coming from work, he stopped to buy bread. | gerund, adverbial use     |
| Ha venido mucha gente al evento.                 | A lot of people have come to the event.  | past participle, compound tense |
