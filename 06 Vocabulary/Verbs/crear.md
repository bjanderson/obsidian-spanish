# crear

## Meaning

*Crear* means "to create" or "to bring into being" — a new thing, a system, a
problem, an opportunity. It's a fully regular *-ar* verb. Don't confuse it with the
unrelated verb *creer* ("to believe") — they share some conjugated forms by
coincidence (*crea* vs *cree*), but they're different verbs with different meanings.

## Present Indicative

| Subject | Conjugation |
| --- | --- |
| yo | creo |
| tú | creas |
| usted / él / ella | crea |
| nosotros / nosotras | creamos |
| ustedes / ellos / ellas | crean |

**Examples:**

| Spanish | English | Notes |
| --- | --- | --- |
| Creo contenido para redes sociales. | I create content for social media. | *yo* |
| ¿Creas tus propios diseños? | Do you create your own designs? | *tú*, question |
| Ella crea joyería artesanal. | She makes handmade jewelry. | *ella* |
| Creamos un ambiente de confianza. | We create an atmosphere of trust. | *nosotros* |
| No crean problemas donde no los hay. | Don't create problems where there aren't any. | *ustedes*, negation |
