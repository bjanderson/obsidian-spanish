# seguir

## Meaning

*Seguir* means "to follow" (*Sigo tus consejos*, "I follow your advice") or
"to continue" (*Sigue lloviendo*, "It's still raining"). *Seguir* + gerund is
the everyday way to say "to keep on doing something": *Sigo estudiando* ("I
keep studying"/"I'm still studying"). It has an *e → i* stem change in the
present and preterite, plus a spelling change (*gu → g*) before *-o* and *-a*
endings to preserve the hard *g* sound.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | sigo        |
| tú                       | sigues      |
| usted / él / ella        | sigue       |
| nosotros / nosotras      | seguimos    |
| ustedes / ellos / ellas  | siguen      |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Sigo tus pasos con cuidado.                | I follow your steps carefully.        | *yo*, spelling change *g*        |
| ¿Sigues viviendo en el mismo barrio?       | Do you still live in the same neighborhood? | *tú*, question, *seguir* + gerund |
| Ella sigue el mismo camino cada día.       | She follows the same path every day.  | *ella*                          |
| Seguimos las instrucciones al pie de la letra. | We follow the instructions exactly. | *nosotros*                      |
| No siguen las reglas del juego.            | They don't follow the rules of the game. | *ellos*, negation                |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | sigue       | no sigas      |
| usted     | siga        | no siga       |
| nosotros  | sigamos     | no sigamos    |
| ustedes   | sigan       | no sigan      |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Sigue derecho hasta el semáforo.     | Keep going straight to the light.   | *tú*, affirmative                   |
| No sigas ese camino, está cerrado.   | Don't take that path, it's closed.  | *tú*, negative                      |
| Sigan las señales del aeropuerto.    | Follow the airport signs.           | *ustedes*, affirmative               |

| ---------------- | ---------- | ------- |

**Examples:**

| Spanish                                     | English                             | Notes                    |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------- |
