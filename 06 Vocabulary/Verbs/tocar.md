# tocar

## Meaning

*Tocar* covers two everyday senses: physical touch ("to touch") and playing a
musical instrument ("to play"): *tocar la guitarra* ("to play the guitar"). It's a
regular *-ar* verb with one spelling change: the *c* becomes *qu* before *e*, so the
preterite *yo* form is *toqué*, not *tocé*. The same *c → qu* shift shows up in the
present subjunctive.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | toco        |
| tú                       | tocas       |
| usted / él / ella        | toca        |
| nosotros / nosotras      | tocamos     |
| ustedes / ellos / ellas  | tocan       |

**Examples:**

| Spanish                                   | English                             | Notes                  |
| ------------------------------------------ | ------------------------------------- | ------------------------ |
| Toco el piano desde niño.                   | I've played piano since I was a kid.  | *yo*                      |
| ¿Tocas algún instrumento?                   | Do you play any instrument?           | *tú*, question              |
| Ella toca la puerta con cuidado.            | She touches the door carefully.       | *ella*                       |
| Tocamos la guitarra los fines de semana.    | We play guitar on weekends.           | *nosotros*                     |
| Ellos tocan en una banda local.             | They play in a local band.            | *ellos*                        |

## Preterite

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | toqué       |
| tú                       | tocaste     |
| usted / él / ella        | tocó        |
| nosotros / nosotras      | tocamos     |
| ustedes / ellos / ellas  | tocaron     |

**Examples:**

| Spanish                                   | English                             | Notes                  |
| ------------------------------------------ | ------------------------------------- | ------------------------ |
| Toqué el violín en el concierto.            | I played the violin at the concert.   | *yo*, c→qu spelling         |
| ¿Tocaste la campana?                        | Did you ring the bell?                | *tú*, question                |
| No tocó nada en la mesa.                    | He didn't touch anything on the table. | *él*, negation                |
| Tocamos varias canciones anoche.            | We played several songs last night.   | *nosotros*                      |
| Los músicos tocaron por dos horas.          | The musicians played for two hours.   | *ellos*                          |

## Present Subjunctive

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | toque       |
| tú                       | toques      |
| usted / él / ella        | toque       |
| nosotros / nosotras      | toquemos    |
| ustedes / ellos / ellas  | toquen      |

**Examples:**

| Spanish                                   | English                             | Notes                  |
| ------------------------------------------ | ------------------------------------- | ------------------------ |
| Espero que toques algo bonito.              | I hope you play something nice.       | *tú*, wish clause             |
| Ojalá toque bien en el concierto.           | I hope she plays well at the concert. | *ella*, *ojalá*                 |
| No creo que yo toque hoy.                   | I don't think I'll play today.        | *yo*, doubt clause              |
| Es mejor que no toquemos ese tema.          | It's better that we don't touch on that topic. | *nosotros*                 |
| Dudo que toquen esa canción.                | I doubt they'll play that song.       | *ellos*, doubt clause             |

## Imperfect Subjunctive

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | tocara      |
| tú                       | tocaras     |
| usted / él / ella        | tocara      |
| nosotros / nosotras      | tocáramos   |
| ustedes / ellos / ellas  | tocaran     |

**Examples:**

| Spanish                                   | English                             | Notes                  |
| ------------------------------------------ | ------------------------------------- | ------------------------ |
| Si tocara mejor, entraría a la banda.       | If I played better, I'd join the band. | *yo*, *si* clause            |

| Era raro que tocaran tan temprano.          | It was strange that they played so early. | *ellos*                     |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | toca        | no toques     |
| usted     | toque       | no toque      |
| nosotros  | toquemos    | no toquemos   |
| ustedes   | toquen      | no toquen     |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Toca esa canción otra vez.           | Play that song again.               | *tú*, affirmative                    |
| No toques mis cosas sin permiso.     | Don't touch my things without permission. | *tú*, negative                  |

## Gerund and Past Participle

| Form             | Spanish   | English   |
| ---------------- | --------- | --------- |
| Gerund (-ing)    | tocando   | touching/playing |
| Past Participle  | tocado    | touched/played    |

**Examples:**

| Spanish                                     | English                             | Notes                    |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------- |
| Tocando con pasión, emocionó al público.         | Playing with passion, he moved the audience. | gerund, adverbial use     |
| El tema ya está tocado por otra banda.           | The song has already been played by another band. | past participle as adjective |
