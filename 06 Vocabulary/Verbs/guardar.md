# guardar

## Meaning

*Guardar* means "to keep" or "to save" something for later — putting it somewhere
safe, whether that's a physical object in a drawer or a file on a computer. It's a
fully regular *-ar* verb with no stem changes or spelling adjustments in any tense.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | guardo      |
| tú                       | guardas     |
| usted / él / ella        | guarda      |
| nosotros / nosotras      | guardamos   |
| ustedes / ellos / ellas  | guardan     |

**Examples:**

| Spanish                                       | English                                | Notes                       |
| ---------------------------------------------- | --------------------------------------------- | ----------------------------- |
| Guardo mis documentos en esta carpeta.          | I keep my documents in this folder.            | *yo*                          |
| ¿Guardas el recibo de la compra?                | Do you keep the purchase receipt?              | *tú*, question                |
| Ella guarda un secreto desde hace años.         | She's kept a secret for years.                 | *ella*                        |
| Guardamos la comida en el refrigerador.         | We keep the food in the fridge.                | *nosotros*                    |
| Mis padres no guardan nada en ese cajón.        | My parents don't keep anything in that drawer. | *ellos*, negation              |
