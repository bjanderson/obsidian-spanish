# tener

## Meaning

*Tener* is the everyday verb for "to have" — possession, age (*Tengo treinta
años*, "I'm thirty"), and physical sensations (*Tengo hambre*, "I'm hungry,"
literally "I have hunger"). Don't confuse it with [[haber]], the auxiliary
"to have" used only to build compound tenses. *Tener que* + infinitive means
"to have to": *Tengo que trabajar* ("I have to work"). It's irregular
throughout, with a *g* inserted in the *yo* form and an *e → ie* stem change
in most present-tense forms.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | tengo       |
| tú                       | tienes      |
| usted / él / ella        | tiene       |
| nosotros / nosotras      | tenemos     |
| ustedes / ellos / ellas  | tienen      |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Tengo dos hermanos.                        | I have two brothers.                  | *yo*, possession                |
| ¿Tienes tiempo para hablar?                | Do you have time to talk?             | *tú*, question                  |
| Ella tiene mucha experiencia.              | She has a lot of experience.          | *ella*                          |
| Tenemos que salir temprano.                | We have to leave early.               | *nosotros*, *tener que*          |
| No tienen suficiente dinero.               | They don't have enough money.         | *ellos*, negation                 |
