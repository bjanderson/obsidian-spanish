# usar

## Meaning

*Usar* means "to use." With clothing or accessories, it can also mean "to wear":
*Usa lentes* ("She wears glasses"). It's a fully regular *-ar* verb — no stem
changes, no spelling adjustments.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | uso         |
| tú                       | usas        |
| usted / él / ella        | usa         |
| nosotros / nosotras      | usamos      |
| ustedes / ellos / ellas  | usan        |

**Examples:**

| Spanish                                | English                            | Notes           |
| ------------------------------------------ | ---------------------------------------- | ------------------ |
| Uso el celular para trabajar.               | I use my phone for work.                 | *yo*                |
| ¿Usas transporte público?                    | Do you use public transportation?        | *tú*, question       |
| Ella usa uniforme en el trabajo.             | She wears a uniform at work.             | *ella*, "to wear"     |
| Usamos esta sala para las reuniones.         | We use this room for meetings.           | *nosotros*             |
| No usan ese programa ya.                     | They don't use that program anymore.     | *ellos*, negation        |
