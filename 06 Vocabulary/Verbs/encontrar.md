# encontrar

## Meaning

*Encontrar* means "to find": *Encontré las llaves* ("I found the keys"). The
reflexive *encontrarse* means "to be located" (*El banco se encuentra cerca*,
"The bank is located nearby") or "to feel" (health): *Me encuentro mejor*
("I feel better"). It's an *o → ue* stem-changing verb in the present tense —
the stem vowel changes in every present-tense form except *nosotros*.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | encuentro   |
| tú                       | encuentras  |
| usted / él / ella        | encuentra   |
| nosotros / nosotras      | encontramos |
| ustedes / ellos / ellas  | encuentran  |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Encuentro esto muy interesante.            | I find this very interesting.         | *yo*                            |
| ¿Encuentras difícil este idioma?           | Do you find this language difficult?  | *tú*, question                  |
| Ella se encuentra bien hoy.                | She's feeling well today.             | *ella*, reflexive, "to feel"      |
| Encontramos la solución juntos.            | We find the solution together.        | *nosotros*                      |
| No encuentran las llaves.                  | They can't find the keys.             | *ellos*, negation                 |

## Related Vocabulary

- [[buscar]] — the action that usually leads to *encontrar*, "to look for."
- [[seguir]] — an unrelated but similarly-spelled verb; don't confuse "to find" with "to follow/continue."
- [[descubrir]] — near-synonym — *encontrar* is finding, *descubrir* is discovering (often something new or hidden).
