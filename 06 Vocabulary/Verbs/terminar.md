# terminar

## Meaning

*Terminar* means "to finish" or "to end" something: *Termino mi tarea* (I finish my
homework). It also works intransitively for something that simply ends on its own:
*La película termina a las nueve* (The movie ends at nine). *Terminar de* + infinitive
means "to finish doing something": *Terminé de leer el libro* (I finished reading the
book). It's a fully regular *-ar* verb — no stem changes, no spelling changes, no
irregular forms anywhere in the paradigm.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------ |
| yo                       | termino    |
| tú                       | terminas   |
| usted / él / ella        | termina    |
| nosotros / nosotras      | terminamos |
| ustedes / ellos / ellas  | terminan   |

**Examples:**

| Spanish                                | English                          | Notes                    |
| ---------------------------------------- | ----------------------------------- | --------------------------- |
| Termino mi tarea a las ocho.             | I finish my homework at eight.      | *yo*                       |
| ¿Terminas el reporte hoy?                | Are you finishing the report today? | *tú*, question             |
| Sofía no termina de comer todavía.       | Sofía isn't finished eating yet.    | *ella*, negation, *terminar de* + inf. |
| Terminamos el proyecto antes de la fecha límite. | We finish the project before the deadline. | *nosotros* |
| ¿Ya terminan ustedes el examen?          | Are you all finishing the exam already? | *ustedes*, question   |
