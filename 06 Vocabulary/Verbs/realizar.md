# realizar

## Meaning

*Realizar* means "to carry out" or "to accomplish" — completing a plan, project, or
goal: *realizar un sueño* ("to make a dream come true"). It's a false friend: it
does **not** mean "to realize" in the sense of becoming aware of something — that's
*darse cuenta*. *Realizar* is a regular *-ar* verb except for one spelling change:
the *z* becomes *c* before *e*, so the preterite *yo* form is *realicé*, not
*realizé*. The same *z → c* shift shows up in the present subjunctive.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | realizo     |
| tú                       | realizas    |
| usted / él / ella        | realiza     |
| nosotros / nosotras      | realizamos  |
| ustedes / ellos / ellas  | realizan    |

**Examples:**

| Spanish                                   | English                             | Notes                  |
| ------------------------------------------ | ------------------------------------- | ------------------------ |
| Realizo mi trabajo con cuidado.             | I carry out my work carefully.        | *yo*                      |
| ¿Realizas ejercicio todos los días?         | Do you exercise every day?            | *tú*, question             |
| Ella realiza estudios de mercado.           | She carries out market research.      | *ella*                      |
| Realizamos el proyecto en tres meses.       | We carried out the project in three months. | *nosotros*            |
| Los técnicos realizan pruebas cada semana.  | The technicians run tests every week. | *ellos*                     |

## Preterite

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | realicé     |
| tú                       | realizaste  |
| usted / él / ella        | realizó     |
| nosotros / nosotras      | realizamos  |
| ustedes / ellos / ellas  | realizaron  |

**Examples:**

| Spanish                                   | English                             | Notes                  |
| ------------------------------------------ | ------------------------------------- | ------------------------ |
| Realicé mi sueño de viajar por Bolivia.     | I made my dream of traveling through Bolivia come true. | *yo*, z→c spelling |
| ¿Realizaste el examen ayer?                 | Did you take the exam yesterday?      | *tú*, question             |
| No realizó el viaje por falta de dinero.    | She didn't make the trip due to lack of money. | *ella*, negation      |
| Realizamos una encuesta el mes pasado.      | We conducted a survey last month.     | *nosotros*                  |
| Los organizadores realizaron el evento sin problemas. | The organizers carried out the event without problems. | *ellos*     |

## Commands (Imperative)

| Form      | Affirmative | Negative       |
| --------- | ----------- | --------------- |
| tú        | realiza     | no realices     |
| usted     | realice     | no realice      |
| nosotros  | realicemos  | no realicemos   |
| ustedes   | realicen    | no realicen     |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Realiza tus sueños con esfuerzo.     | Make your dreams come true through effort. | *tú*, affirmative           |
| No realices cambios sin avisar.      | Don't make changes without notice.  | *tú*, negative                       |
| Realicemos el plan juntos.           | Let's carry out the plan together.  | *nosotros*, affirmative              |

**Examples:**

| Spanish                                     | English                             | Notes                    |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------- |
| Realizando el trabajo con calma, evitó errores.  | Carrying out the work calmly, he avoided mistakes. | gerund, adverbial use   |
