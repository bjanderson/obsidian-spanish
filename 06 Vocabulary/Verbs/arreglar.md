# arreglar

## Meaning

*Arreglar* means "to fix" or "to repair" (*Arreglé el carro*, "I fixed the
car"), and more broadly "to arrange" or "to tidy up" (*Arreglar el cuarto*,
"to tidy up the room"). The reflexive *arreglarse* means "to get ready" or
"to sort itself out": *Todo se arreglará* ("Everything will work out"). It's
a fully regular *-ar* verb — no stem change and no spelling change.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | arreglo     |
| tú                       | arreglas    |
| usted / él / ella        | arregla     |
| nosotros / nosotras      | arreglamos  |
| ustedes / ellos / ellas  | arreglan    |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Arreglo mi cuarto los sábados.             | I tidy up my room on Saturdays.       | *yo*                            |
| ¿Arreglas los problemas técnicos aquí?     | Do you fix the technical problems here? | *tú*, question                |
| Ella arregla relojes antiguos.             | She repairs antique clocks.           | *ella*                          |
| Arreglamos la casa antes de la visita.     | We tidy up the house before the visit. | *nosotros*                     |
| No arreglan el ascensor desde hace días.   | They haven't fixed the elevator in days. | *ellos*, negation             |
