# servir

## Meaning

*Servir* means "to serve" — bringing food or drink, or being of use for a purpose:
*Esto sirve para limpiar vidrios* ("This is good for cleaning glass"). It's an
*e → i* stem-changing verb in the present tense (*sirvo*, not *servo*), and the same
*e → i* shift shows up in the preterite 3rd persons and the gerund.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | sirvo       |
| tú                       | sirves      |
| usted / él / ella        | sirve       |
| nosotros / nosotras      | servimos    |
| ustedes / ellos / ellas  | sirven      |

**Examples:**

| Spanish                                | English                              | Notes                    |
| ------------------------------------------ | -------------------------------------- | ---------------------------- |
| Sirvo la cena a las siete.                  | I serve dinner at seven.               | *yo*                          |
| ¿Para qué sirve este botón?                 | What is this button for?               | *él*, question                 |
| Ella sirve mesas los fines de semana.       | She waits tables on weekends.          | *ella*                          |
| Servimos café y té en la reunión.           | We serve coffee and tea at the meeting. | *nosotros*                       |
| Esos zapatos ya no sirven para correr.      | Those shoes aren't good for running anymore. | *ellos*                     |

| Sirvamos primero a los invitados.     | Let's serve the guests first.      | *nosotros*, affirmative                |
