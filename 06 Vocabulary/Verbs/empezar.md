# empezar

## Meaning

*Empezar* means "to begin" or "to start." *Empezar a* + infinitive is the
everyday way to say "to start doing something": *Empiezo a trabajar a las
ocho* ("I start working at eight"). It's an *e → ie* stem-changing verb in the
present, and has a spelling change (*z → c*) before *-é* and *-e* endings —
the preterite *yo* form and the whole subjunctive.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | empiezo     |
| tú                       | empiezas    |
| usted / él / ella        | empieza     |
| nosotros / nosotras      | empezamos   |
| ustedes / ellos / ellas  | empiezan    |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Empiezo a trabajar a las ocho.             | I start working at eight.             | *yo*, *empezar a*                 |
| ¿Cuándo empiezas las clases?               | When do your classes start?           | *tú*, question                   |
| Ella empieza el proyecto mañana.           | She's starting the project tomorrow.  | *ella*                          |
| Empezamos la reunión a tiempo.             | We start the meeting on time.         | *nosotros*                      |
| No empiezan hasta las nueve.               | They don't start until nine.          | *ellos*, negation                 |

**Examples:**

| Spanish                                       | English                                  | Notes                        |
| ------------------------------------------------- | --------------------------------------------- | -------------------------------- |
| Espero que empiece a tiempo.                      | I hope it starts on time.                     | impersonal, wish clause, spelling change |
| Ojalá empieces pronto tu nuevo trabajo.           | I hope you start your new job soon.           | *tú*, *ojalá*                    |
