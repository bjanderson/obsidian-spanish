# poner

## Meaning

*Poner* means "to put" or "to place": *Pon el libro en la mesa* ("Put the
book on the table"). The reflexive form *ponerse* means "to put on"
(clothing) or "to become" (a sudden change of state): *Se puso nervioso* ("He
got nervous"). *Poner* is irregular in the *yo* form of the present, the
preterite (irregular *pus-* stem), the future/conditional stem (*pondr-*), and
the past participle (*puesto*).

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | pongo       |
| tú                       | pones       |
| usted / él / ella        | pone        |
| nosotros / nosotras      | ponemos     |
| ustedes / ellos / ellas  | ponen       |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Pongo la mesa antes de cenar.              | I set the table before dinner.        | *yo*                            |
| ¿Dónde pones las llaves?                   | Where do you put the keys?            | *tú*, question                  |
| Ella se pone nerviosa antes de hablar.     | She gets nervous before speaking.     | *ella*, reflexive                |
| Ponemos música mientras cocinamos.         | We put on music while we cook.        | *nosotros*                      |
| No ponen atención en clase.                | They don't pay attention in class.    | *ellos*, negation, idiom          |

| Form      | Affirmative | Negative      |

| tú        | pon         | no pongas     |
| usted     | ponga       | no ponga      |

| ustedes   | pongan      | no pongan     |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Pon la mesa, por favor.              | Set the table, please.              | *tú*, affirmative, irregular form   |

| Pongan atención, por favor.          | Please pay attention.               | *ustedes*, affirmative               |
