# pasar

## Meaning

*Pasar* is a regular *-ar* verb with several everyday meanings: "to happen"
(*¿Qué pasa?*, "What's happening?"), "to pass/go by" (*Pasó por mi casa*, "He
went by my house"), and "to spend time" (*Pasamos el fin de semana juntos*,
"We spent the weekend together"). *Pasarlo bien/mal* means "to have a good/bad
time."

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | paso        |
| tú                       | pasas       |
| usted / él / ella        | pasa        |
| nosotros / nosotras      | pasamos     |
| ustedes / ellos / ellas  | pasan       |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Paso mucho tiempo estudiando.              | I spend a lot of time studying.       | *yo*                            |
| ¿Qué te pasa?                              | What's wrong with you?                | *tú*, question, idiom            |
| Ella pasa por mi casa todos los días.      | She passes by my house every day.     | *ella*                          |
| Pasamos las vacaciones en la playa.        | We spent the vacation at the beach.   | *nosotros*                      |
| No pasa nada, tranquilo.                   | Nothing's wrong, relax.                | impersonal, negation             |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | pasa        | no pases      |
| usted     | pase        | no pase       |
| nosotros  | pasemos     | no pasemos    |
| ustedes   | pasen       | no pasen      |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Pasa, la puerta está abierta.        | Come in, the door is open.          | *tú*, affirmative, idiom            |
| No pases por esa calle de noche.     | Don't go down that street at night. | *tú*, negative                      |
| Pasen, por favor.                    | Come in, please.                    | *ustedes*, affirmative               |
