# existir

## Meaning

*Existir* means "to exist." It's a regular *-ir* verb throughout, and because
of its meaning, it's used overwhelmingly in the third person, describing
things rather than people: *Existen varias soluciones* ("There are several
solutions," literally "Several solutions exist"). The full paradigm below is
complete for reference, but real usage leans heavily on the third-person
forms.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | existo      |
| tú                       | existes     |
| usted / él / ella        | existe      |
| nosotros / nosotras      | existimos   |
| ustedes / ellos / ellas  | existen     |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Existo gracias a mis padres.               | I exist thanks to my parents.         | *yo*, philosophical use            |
| Aunque lo dudes, existes para alguien.     | Even if you doubt it, you exist for someone. | *tú*                        |
| Ese problema no existe realmente.          | That problem doesn't really exist.    | impersonal, negation               |
| Existimos en un mundo complicado.          | We exist in a complicated world.      | *nosotros*                      |
| Existen varias formas de resolverlo.       | There are several ways to solve it.   | impersonal, "there are"           |

## Commands (Imperative)

*Existir* is essentially never used as a direct command — existence isn't
something you order someone into. The forms exist grammatically but have no
real everyday use.
