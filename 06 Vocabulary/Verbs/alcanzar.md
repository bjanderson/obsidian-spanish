# alcanzar

## Meaning

*Alcanzar* means "to reach" both physically (*Alcanzo el estante de arriba*, I can
reach the top shelf) and figuratively (*Alcanzó sus metas*, She achieved her goals).
It also means "to catch up to" someone (*Te alcanzo en la esquina*, I'll catch up
with you at the corner) and, in the phrase *alcanzar para*, "to be enough for"
(*El dinero no alcanza para todo*, The money isn't enough for everything). *Alcanzar*
is a regular *-ar* verb apart from one spelling change: because Spanish spelling
never writes *z* before *e* or *i*, the *z* becomes *c* whenever the ending starts
with *e* — in the *yo* preterite (*alcancé*), throughout the present subjunctive
(*alcance, alcances...*), and in the *usted/ustedes* and negative *tú* commands. This
is a spelling rule, not a true irregularity — the same pattern shows up in *empezar*,
*comenzar*, and *lanzar*. Don't confuse this *z → c* spelling-change pattern with the
unrelated *-zco* verbs like *nacer* or *ofrecer*, which insert a *-zc-* in the *yo*
form instead.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------ |
| yo                       | alcanzo    |
| tú                       | alcanzas   |
| usted / él / ella        | alcanza    |
| nosotros / nosotras      | alcanzamos |
| ustedes / ellos / ellas  | alcanzan   |

**Examples:**

| Spanish                                       | English                                  | Notes             |
| -------------------------------------------------- | ------------------------------------------------ | -------------------- |
| Alcanzo el estante de arriba con la escalera.       | I can reach the top shelf with the stepladder.    | *yo*                |
| ¿Alcanzas a ver el letrero desde aquí?              | Can you make out the sign from here?              | *tú*, question       |
| El sueldo no alcanza para pagar todo.               | The salary isn't enough to pay for everything.    | *ella/it*, negation, *alcanzar para* |
| Alcanzamos la cima antes del mediodía.              | We reach the summit before noon.                  | *nosotros*           |
| Mis ahorros no alcanzan para el viaje.              | My savings aren't enough for the trip.             | *ellos*, negation    |
