# cerrar

## Meaning

*Cerrar* means "to close" or "to shut." It's an *e → ie* stem-changing verb: the
stem vowel changes in every present-tense form except *nosotros*.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | cierro      |
| tú                       | cierras     |
| usted / él / ella        | cierra      |
| nosotros / nosotras      | cerramos    |
| ustedes / ellos / ellas  | cierran     |

**Examples:**

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | -------------------------------------- | --------------------------------- |
| Cierro la puerta con llave todas las noches. | I lock the door every night.          | *yo*                                |
| ¿Cierras las ventanas cuando llueve?        | Do you close the windows when it rains? | *tú*, question                    |
| La tienda cierra a las nueve.               | The store closes at nine.              | *ella*                              |
| Cerramos el negocio los domingos.           | We close the business on Sundays.      | *nosotros*                          |
| Cierran los ojos para concentrarse.         | They close their eyes to concentrate.  | *ellos*                             |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | cierra      | no cierres    |
| usted     | cierre      | no cierre     |
| nosotros  | cerremos    | no cerremos   |
| ustedes   | cierren     | no cierren    |

**Examples:**

| Spanish                        | English                      | Notes                    |
| ------------------------------------ | ------------------------------------ | ---------------------------- |
| Cierra la puerta, hace frío.          | Close the door, it's cold.           | *tú*, affirmative              |
| No cierres la tienda todavía.         | Don't close the store yet.           | *tú*, negative                  |
| Cierre la ventana, por favor.         | Close the window, please.            | *usted*, affirmative            |
| Cerremos el trato hoy mismo.          | Let's close the deal today.          | *nosotros*, affirmative         |

**Examples:**

| Spanish                                    | English                              | Notes                    |

| Salió cerrando la puerta con fuerza.               | She left, slamming the door.                  | gerund, manner                |
| La tienda está cerrada los lunes.                  | The store is closed on Mondays.               | past participle as adjective  |
