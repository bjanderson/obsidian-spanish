# perder

## Meaning

*Perder* means "to lose" — an object (*Perdí las llaves*, "I lost my keys"),
a game (*Perdimos el partido*, "We lost the game"), or time (*Pierdes tiempo*,
"You're wasting time"). The reflexive *perderse* means "to get lost": *Me
perdí en el centro* ("I got lost downtown"). It's an *e → ie* stem-changing
verb in the present — the stem vowel changes in every present-tense form
except *nosotros*.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | pierdo      |
| tú                       | pierdes     |
| usted / él / ella        | pierde      |
| nosotros / nosotras      | perdemos    |
| ustedes / ellos / ellas  | pierden     |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Pierdo las llaves todo el tiempo.          | I lose my keys all the time.          | *yo*                            |
| ¿Pierdes la paciencia fácilmente?          | Do you lose your patience easily?     | *tú*, question                  |
| Ella nunca pierde la calma.                | She never loses her cool.             | *ella*, negation                 |
| Perdemos tiempo si esperamos aquí.         | We're wasting time if we wait here.   | *nosotros*                      |
| No pierden la esperanza.                   | They don't lose hope.                 | *ellos*, negation                 |
