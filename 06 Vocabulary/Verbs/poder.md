# poder

## Meaning

*Poder* + infinitive expresses "can" or "to be able to" — physical ability,
permission, or simple possibility, depending on context: *¿Puedo pasar?* can mean
"Can I come in?" (ability) or "May I come in?" (permission). It's an *o → ue*
stem-changing verb: the stem vowel changes in every present-tense form except
*nosotros*. Don't confuse it with *saber* (to know how to do something as a learned
skill) — see [[querer]] for a related modal-verb contrast.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | puedo       |
| tú                       | puedes      |
| usted / él / ella        | puede       |
| nosotros / nosotras      | podemos     |
| ustedes / ellos / ellas  | pueden      |

**Examples:**

| Spanish                                  | English                              | Notes                        |
| ----------------------------------------- | -------------------------------------- | -------------------------------- |
| Puedo terminar el informe hoy.            | I can finish the report today.         | *yo*, ability                  |
| ¿Puedes venir a la reunión?               | Can you come to the meeting?           | *tú*, question                  |
| Ella no puede salir esta noche.           | She can't go out tonight.              | *ella*, negation                |
| Podemos resolver esto juntos.             | We can solve this together.            | *nosotros*                     |
| Mis vecinos pueden estacionar aquí.       | My neighbors can park here.            | *ellos*, permission             |

## Commands (Imperative)

*Poder* is grammatically capable of forming commands, but almost nobody uses it that
way — you don't order someone to "be able" to do something. The table below is
included for completeness; in real speech, this verb is used far more in the
indicative and subjunctive tenses above.

| Form      | Affirmative | Negative     |
| --------- | ----------- | ------------- |
| tú        | puede       | no puedas    |
| usted     | pueda       | no pueda     |
| nosotros  | podamos     | no podamos   |
| ustedes   | puedan      | no puedan    |

No natural example sentence is included here — native speakers avoid commanding
*poder* directly, for the reason given above. The forms in the table are correct if
you need them, but don't force an example sentence out of them.

## Gerund and Past Participle

| Form             | Spanish  | English  |
| ---------------- | -------- | -------- |
| Gerund (-ing)    | pudiendo | being able |
| Past Participle  | podido   | been able |

**Examples:**

| Spanish                                        | English                                  | Notes                    |
| --------------------------------------------------- | ---------------------------------------------- | ---------------------------- |
| Pudiendo trabajar desde casa, ahorra tiempo cada día. | Being able to work from home, he/she saves time every day. | gerund, adverbial use |
| Habiendo podido resolverlo, se sintió aliviada.     | Having been able to solve it, she felt relieved. | compound gerund, past participle |
