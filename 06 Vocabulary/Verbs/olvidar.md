# olvidar

## Meaning

*Olvidar* means "to forget." It's often used reflexively, *olvidarse de*, with the
same meaning: *Olvidé las llaves* and *Me olvidé de las llaves* both mean "I forgot
the keys." It's a fully regular *-ar* verb.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | olvido      |
| tú                       | olvidas     |
| usted / él / ella        | olvida      |
| nosotros / nosotras      | olvidamos   |
| ustedes / ellos / ellas  | olvidan     |

**Examples:**

| Spanish                                | English                            | Notes           |
| ------------------------------------------ | ---------------------------------------- | ------------------ |
| Siempre olvido dónde dejo las llaves.        | I always forget where I leave my keys.   | *yo*                 |
| ¿Olvidas las cosas seguido?                   | Do you forget things often?              | *tú*, question         |
| Ella nunca olvida un cumpleaños.               | She never forgets a birthday.            | *ella*, negation           |
| Olvidamos el paraguas en casa.                  | We forgot the umbrella at home.          | *nosotros*                   |
| No olvidan la cita importante.                   | They don't forget the important appointment. | *ellos*, negation         |
