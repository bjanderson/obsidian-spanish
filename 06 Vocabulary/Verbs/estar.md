# estar

## Meaning

*Estar* is one of Spanish's two verbs for "to be," used for location and
temporary or changeable states. The core contrast is with [[ser]]: *estar*
covers where something *is* or the condition it's currently *in*, while *ser*
covers what something fundamentally *is*. *Está en la cocina* ("She's in the
kitchen," location) vs. *Está cansada* ("She's tired," a temporary state) —
compare to *Es doctora* ("She's a doctor," identity, with *ser*).

*Estar* is irregular in the present indicative, the preterite, and the present
subjunctive; the other tenses follow the regular *-ar* pattern.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | estoy       |
| tú                       | estás       |
| usted / él / ella        | está        |
| nosotros / nosotras      | estamos     |
| ustedes / ellos / ellas  | están       |

**Examples:**

| Spanish                              | English                          | Notes                        |
| ----------------------------------------- | -------------------------------------- | --------------------------------- |
| Estoy en casa toda la tarde.                | I'm at home all afternoon.             | *yo*, location                     |
| ¿Estás bien? Te ves preocupado.             | Are you okay? You look worried.        | *tú*, condition, question           |
| Mi hermana está en Cochabamba esta semana.  | My sister is in Cochabamba this week.  | *ella*, location                    |
| Estamos muy cansados después del viaje.     | We're very tired after the trip.       | *nosotros*, condition               |
| Ellos están felices con los resultados.     | They're happy with the results.        | *ellos*, condition                  |

## Preterite

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | estuve      |
| tú                       | estuviste   |
| usted / él / ella        | estuvo      |
| nosotros / nosotras      | estuvimos   |
| ustedes / ellos / ellas  | estuvieron  |

**Examples:**

| Spanish                                    | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Estuve enfermo toda la semana pasada.       | I was sick all last week.                | *yo*                                |
| ¿Estuviste en la reunión de ayer?           | Were you at yesterday's meeting?         | *tú*, question                     |
| La tienda estuvo cerrada por el feriado.    | The store was closed for the holiday.    | *ella* (referring to *la tienda*)   |
| Estuvimos esperando casi una hora.          | We were waiting for almost an hour.      | *nosotros*                          |
| Estuvieron de vacaciones en la playa.       | They were on vacation at the beach.      | *ellos*                             |

## Imperfect

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | estaba      |
| tú                       | estabas     |
| usted / él / ella        | estaba      |
| nosotros / nosotras      | estábamos   |
| ustedes / ellos / ellas  | estaban     |

**Examples:**

| Spanish                                    | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| De niño, estaba siempre afuera jugando.     | As a kid, I was always outside playing.  | *yo*                                |
| ¿Dónde estabas cuando te llamé?             | Where were you when I called you?        | *tú*, question                     |

| Estábamos nerviosos antes del examen.       | We were nervous before the exam.         | *nosotros*                          |
| Las calles estaban vacías esa noche.        | The streets were empty that night.       | *ellas*                             |

## Present Subjunctive

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | esté        |
| tú                       | estés       |
| usted / él / ella        | esté        |
| nosotros / nosotras      | estemos     |
| ustedes / ellos / ellas  | estén       |

**Examples:**

| Spanish                                    | English                                | Notes                        |
| ------------------------------------------ | --------------------------------------------- | --------------------------------- |
| Espero que estés bien.                      | I hope you're doing well.                      | *tú*, wish clause                  |
| Ojalá esté lista la comida pronto.          | I hope the food's ready soon.                  | *ella*, *ojalá*                     |
| No creo que esté en casa a esta hora.       | I don't think he's home at this hour.          | doubt clause                       |
| Es importante que estemos todos de acuerdo. | It's important that we all agree.              | *nosotros*                         |
| Dudo que estén listos tan temprano.         | I doubt they'll be ready that early.           | *ellos*, doubt clause              |

**Examples:**

## Commands (Imperative)

| Form      | Affirmative | Negative     |
| --------- | ----------- | -------------- |
| tú        | está        | no estés      |
| usted     | esté        | no esté       |
| nosotros  | estemos     | no estemos    |
| ustedes   | estén       | no estén      |

**Examples:**

| Spanish                          | English                       | Notes                          |
| ------------------------------------ | ------------------------------------ | ------------------------------------ |
| Está atento durante la explicación.    | Pay attention during the explanation. | *tú*, affirmative                     |
| No estés tan nervioso, todo va a salir bien. | Don't be so nervous, everything will be fine. | *tú*, negative                 |
| Esté tranquilo, lo vamos a resolver.    | Stay calm, we're going to solve it.   | *usted*, affirmative                  |
| Estemos listos antes de que lleguen.    | Let's be ready before they arrive.    | *nosotros*, affirmative                |
| No estén afuera después de que oscurezca. | Don't be outside after it gets dark. | *ustedes*, negative                    |

## Gerund and Past Participle

| Form             | Spanish | English |
| ---------------- | ------- | ------- |
| Gerund (-ing)    | estando | being   |
| Past Participle  | estado  | been    |

**Examples:**

| Spanish                                         | English                              | Notes                    |
| ---------------------------------------------------- | ------------------------------------------ | ---------------------------- |
| Estando tan lejos, es difícil ayudar.                 | Being so far away, it's hard to help.       | gerund, adverbial use |
| Nunca había estado tan nervioso.                       | I had never been so nervous.                | past participle, compound tense |
