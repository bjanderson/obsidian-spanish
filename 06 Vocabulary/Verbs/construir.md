# construir

## Meaning

*Construir* means "to build" or "to construct" — physically, or figuratively (*construir
una relación*, "to build a relationship"). Verbs ending in *-uir* insert a *y* right
before the ending in most present-tense forms (except *nosotros*), and in the
preterite third-person forms and gerund.

## Present Indicative

| Subject                 | Conjugation  |
| ------------------------ | -------------- |
| yo                       | construyo    |
| tú                       | construyes   |
| usted / él / ella        | construye    |
| nosotros / nosotras      | construimos  |
| ustedes / ellos / ellas  | construyen   |

**Examples:**

| Spanish                                    | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Construyo modelos a escala en mi tiempo libre. | I build scale models in my free time.  | *yo*                                |
| ¿Construyes tú mismo tus muebles?           | Do you build your own furniture?         | *tú*, question                      |
| La empresa construye edificios en toda la ciudad. | The company builds buildings all over the city. | *ella*                       |
| Construimos una casa juntos hace años.      | We built a house together years ago.     | *nosotros*                          |
| Construyen puentes por toda la región.      | They build bridges throughout the region. | *ellos*                            |

## Commands (Imperative)

| Form      | Affirmative  | Negative         |
| --------- | ------------ | ----------------- |
| tú        | construye    | no construyas     |
| usted     | construya    | no construya      |
| nosotros  | construyamos | no construyamos   |
| ustedes   | construyan   | no construyan     |

**Examples:**

| Spanish                              | English                          | Notes                    |
| ------------------------------------------ | ---------------------------------------- | ---------------------------- |
| Construye algo que dure, no algo rápido.    | Build something lasting, not something quick. | *tú*, affirmative         |
| No construyas sin un plan claro.            | Don't build without a clear plan.        | *tú*, negative                 |
| Construya con materiales de calidad.        | Build with quality materials.            | *usted*, affirmative           |
| Construyamos algo juntos.                   | Let's build something together.          | *nosotros*, affirmative        |
