# querer

## Meaning

*Querer* means "to want" when followed by a noun or an infinitive: *Quiero un café*
(I want a coffee), *Quiero salir* (I want to go out). With a person as the direct
object, it means "to love": *Te quiero* (I love you) — a common, everyday way to say
"I love you," less intense than *te amo*. It's an *e → ie* stem-changing verb: the
stem vowel changes in every present-tense form except *nosotros*.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | quiero      |
| tú                       | quieres     |
| usted / él / ella        | quiere      |
| nosotros / nosotras      | queremos    |
| ustedes / ellos / ellas  | quieren     |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Quiero un vaso de agua.                   | I want a glass of water.              | *yo*, noun object              |
| ¿Quieres ir al cine conmigo?              | Do you want to go to the movies with me? | *tú*, question             |
| Marta quiere a sus padres.                | Marta loves her parents.              | *ella*, personal *a*           |
| Queremos aprender español.                | We want to learn Spanish.             | *nosotros*, infinitive object  |
| Mis hermanos no quieren comer verduras.   | My siblings don't want to eat vegetables. | *ellos*, negation           |

## Commands (Imperative)

*Querer* is rarely used as a direct command — you don't usually order someone to
"want" something. The forms exist and appear mainly in set, affectionate expressions
like *quiéreme* (love me).

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | quiere      | no quieras    |
| usted     | quiera      | no quiera     |
| nosotros  | queramos    | no queramos   |
| ustedes   | quieran     | no quieran    |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Quiéreme como soy.                   | Love me as I am.                    | *tú*, affirmative, affectionate set phrase |
| No quieras controlarlo todo.         | Don't try to control everything.    | *tú*, negative                      |
| No quiera hacerlo todo usted solo.   | Don't try to do it all by yourself. | *usted*, negative                   |

## Gerund and Past Participle

| Form             | Spanish   | English  |
| ---------------- | --------- | -------- |
| Gerund (-ing)    | queriendo | wanting  |
| Past Participle  | querido   | wanted   |

**Examples:**

| Spanish                                     | English                             | Notes                    |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------- |
| Queriendo evitar el conflicto, se quedó callado. | Wanting to avoid the conflict, he stayed quiet. | gerund, adverbial use |
| *Querido* también funciona como adjetivo: *mi querido amigo*. | *Querido* also works as an adjective: "my dear friend." | past participle as adjective |
