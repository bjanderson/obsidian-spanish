# morir

## Meaning

*Morir* means "to die": *Mi abuelo murió el año pasado* (My grandfather died last
year). It's also common in figurative, everyday expressions: *Me muero de hambre* (I'm
starving, literally "dying of hunger"), *Me muero de risa* (I'm dying laughing). It's
an *o → ue* stem-changing verb in the present, following the same pattern as *dormir*
— the stem vowel changes in every present-tense form except *nosotros*. In the
preterite and forms built on the preterite stem (imperfect subjunctive, gerund), the
*o* weakens to *u* instead, but only in the third-person forms: *murió, murieron,
muriendo*. The *nosotros* form of the present subjunctive also takes this *u* change:
*muramos*. Its past participle is irregular: *muerto* (not *morido*), which is also
the everyday adjective for "dead."

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------ |
| yo                       | muero      |
| tú                       | mueres     |
| usted / él / ella        | muere      |
| nosotros / nosotras      | morimos    |
| ustedes / ellos / ellas  | mueren     |

**Examples:**

| Spanish                                   | English                              | Notes                    |
| ------------------------------------------------ | -------------------------------------------- | ----------------------------- |
| Me muero de hambre después del gimnasio.          | I'm starving after the gym.                   | *yo*, idiomatic               |
| ¿Te mueres de curiosidad por saber el final?      | Are you dying of curiosity to know the ending? | *tú*, question               |
| La planta se muere sin suficiente sol.            | The plant is dying without enough sun.        | *ella*, reflexive, inanimate  |
| No nos morimos de aburrimiento en este pueblo.    | We don't die of boredom in this town.         | *nosotros*, negation, idiomatic |
| Muchos animales mueren por la deforestación.      | Many animals die because of deforestation.    | *ellos*                       |

## Commands (Imperative)

*Morir* is almost never used as a literal command, since you can't order someone to
die. The forms are mostly used in figurative or reflexive expressions.

| Form      | Affirmative | Negative     |
| --------- | ----------- | ------------- |
| tú        | muere      | no mueras    |
| usted     | muera      | no muera     |
| nosotros  | muramos    | no muramos   |
| ustedes   | mueran     | no mueran    |

**Examples:**

| Spanish                                | English                             | Notes                        |
| -------------------------------------------- | ------------------------------------------ | ----------------------------------- |
| ¡No te mueras de vergüenza, todos se equivocan! | Don't die of embarrassment, everyone makes mistakes! | *tú*, negative, figurative use |
| No se muera de preocupación, todo saldrá bien. | Don't worry yourself to death, it'll all work out. | *usted*, negative               |
| No muramos de aburrimiento, salgamos a caminar. | Let's not die of boredom, let's go for a walk. | *nosotros*, negative              |
| No mueran de calor, tomen agua.               | Don't die of heat, drink water.            | *ustedes*, negative                 |
