# explicar

## Meaning

*Explicar* means "to explain" — making something clear or understandable to
someone. It's a regular *-ar* verb with one spelling change: the *c* becomes *qu*
before *e*, so the preterite *yo* form is *expliqué*, not *explicé*. The same
*c → qu* shift shows up in the present subjunctive.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | explico     |
| tú                       | explicas    |
| usted / él / ella        | explica     |
| nosotros / nosotras      | explicamos  |
| ustedes / ellos / ellas  | explican    |

**Examples:**

| Spanish                                   | English                             | Notes                  |
| ------------------------------------------ | ------------------------------------- | ------------------------ |
| Explico la lección paso a paso.             | I explain the lesson step by step.    | *yo*                      |
| ¿Explicas bien las reglas del juego?        | Do you explain the rules of the game well? | *tú*, question         |
| Ella explica el problema con claridad.      | She explains the problem clearly.     | *ella*                      |
| Explicamos el proyecto a los inversionistas. | We explain the project to the investors. | *nosotros*                |
| Los profesores explican el tema en clase.   | The teachers explain the topic in class. | *ellos*                    |

## Preterite

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | expliqué    |
| tú                       | explicaste  |
| usted / él / ella        | explicó     |
| nosotros / nosotras      | explicamos  |
| ustedes / ellos / ellas  | explicaron  |

**Examples:**

| Spanish                                   | English                             | Notes                  |
| ------------------------------------------ | ------------------------------------- | ------------------------ |
| Expliqué el error a mi jefe.                | I explained the mistake to my boss.   | *yo*, c→qu spelling         |
| ¿Explicaste tu decisión a tus padres?       | Did you explain your decision to your parents? | *tú*, question         |
| No explicó por qué llegó tarde.             | He didn't explain why he arrived late. | *él*, negation               |
| Explicamos la situación con calma.          | We explained the situation calmly.    | *nosotros*                    |
| Los abogados explicaron el contrato.        | The lawyers explained the contract.   | *ellos*                        |

## Present Subjunctive

| Subject                 | Conjugation |
| ------------------------ | ------------- |

| tú                       | expliques   |
| usted / él / ella        | explique    |
| nosotros / nosotras      | expliquemos |

**Examples:**

| Spanish                                   | English                             | Notes                  |
| ------------------------------------------ | ------------------------------------- | ------------------------ |
| Espero que expliques tu decisión.           | I hope you explain your decision.     | *tú*, wish clause            |

## Commands (Imperative)

| Form      | Affirmative | Negative        |
| --------- | ----------- | ----------------- |
| tú        | explica     | no expliques      |
| usted     | explique    | no explique       |
| nosotros  | expliquemos | no expliquemos    |
| ustedes   | expliquen   | no expliquen      |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Explica el problema con calma.       | Explain the problem calmly.         | *tú*, affirmative                    |
| No expliques más de lo necesario.    | Don't explain more than necessary.  | *tú*, negative                       |

| Gerund (-ing)    | explicando  | explaining |

**Examples:**

| Spanish                                     | English                             | Notes                    |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------- |
| Explicando con paciencia, logró convencerlos.    | Explaining patiently, he managed to convince them. | gerund, adverbial use   |
| El proceso ya está explicado en el manual.       | The process is already explained in the manual. | past participle as adjective |
