# decir

## Meaning

*Decir* means "to say" or "to tell" — *Dijo que sí* ("He said yes"), *Dime la
verdad* ("Tell me the truth"). It's heavily irregular: an *e → i* stem change
in the present, a completely irregular preterite stem (*dij-*), an irregular
future/conditional stem (*dir-*), and an irregular past participle (*dicho*).

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | digo        |
| tú                       | dices       |
| usted / él / ella        | dice        |
| nosotros / nosotras      | decimos     |
| ustedes / ellos / ellas  | dicen       |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Digo la verdad siempre.                    | I always tell the truth.              | *yo*                            |
| ¿Qué dices tú de este plan?                | What do you say about this plan?      | *tú*, question                  |
| Ella dice que va a llegar tarde.           | She says she'll arrive late.          | *ella*                          |
| Decimos lo mismo siempre.                  | We always say the same thing.         | *nosotros*                      |
| No dicen toda la verdad.                   | They don't tell the whole truth.      | *ellos*, negation                 |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | di          | no digas      |
| usted     | diga        | no diga       |
| nosotros  | digamos     | no digamos    |
| ustedes   | digan       | no digan      |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Dime qué pasó.                       | Tell me what happened.              | *tú*, affirmative, irregular form   |
| No digas nada todavía.               | Don't say anything yet.             | *tú*, negative                      |
| Digan la verdad, por favor.          | Please tell the truth.              | *ustedes*, affirmative               |

## Gerund and Past Participle

| Form             | Spanish  | English |
| ---------------- | -------- | ------- |
| Gerund (-ing)    | diciendo | saying/telling |
| Past Participle  | dicho    | said/told |

**Examples:**

| Spanish                                     | English                             | Notes                    |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------- |
| Diciendo eso, se fue de la sala.                 | Saying that, he left the room.           | gerund, adverbial use         |
| Lo hecho, hecho está; lo dicho, dicho está.      | What's done is done; what's said is said. | past participle, set phrase   |

## Related Vocabulary

- [[expresar]] — near-synonym — *decir* is saying, *expresar* is expressing (feelings, ideas).
- [[palabra]] — related — you *decir* (say) *palabras* (words).
