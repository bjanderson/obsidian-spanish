# mostrar

## Meaning

*Mostrar* means "to show." It's an *o → ue* stem-changing verb: the stem vowel
changes in every present-tense form except *nosotros*.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | muestro     |
| tú                       | muestras    |
| usted / él / ella        | muestra     |
| nosotros / nosotras      | mostramos   |
| ustedes / ellos / ellas  | muestran    |

**Examples:**

| Spanish                                | English                            | Notes           |
| ------------------------------------------ | ---------------------------------------- | ------------------ |
| Te muestro el resultado ahora.               | I'll show you the result now.            | *yo*                 |
| ¿Muestras interés en el proyecto?             | Do you show interest in the project?     | *tú*, question         |
| Ella muestra mucha paciencia.                  | She shows a lot of patience.             | *ella*                    |
| Mostramos el plan a los inversionistas.         | We show the plan to the investors.       | *nosotros*                  |
| No muestran ningún cambio todavía.               | They don't show any change yet.          | *ellos*, negation              |

## Commands (Imperative)

| ustedes   | muestren    | no muestren      |

**Examples:**

| Spanish                       | English                       | Notes                     |
| ---------------------------------- | ------------------------------------ | ------------------------------ |
| Muéstrame el mapa, por favor.        | Show me the map, please.             | *tú*, affirmative                 |

| Mostremos los avances al equipo.       | Let's show the progress to the team. | *nosotros*, affirmative             |

## Gerund and Past Participle

| Form             | Spanish   | English  |
| ---------------- | --------- | -------- |
| Gerund (-ing)    | mostrando | showing  |
| Past Participle  | mostrado  | shown    |

**Examples:**

| Spanish                                | English                          | Notes                     |
| ------------------------------------------ | ---------------------------------------- | ------------------------------ |
| Mostrando gran calma, resolvió el problema.  | Showing great calm, he solved the problem. | gerund, adverbial use          |
| El plan ya ha sido mostrado al comité.        | The plan has already been shown to the committee. | past participle, passive voice |
