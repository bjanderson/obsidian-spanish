# sentir

## Meaning

*Sentir* means "to feel" (an emotion or physical sensation) or "to be sorry":
*Lo siento* ("I'm sorry"). The reflexive *sentirse* is the everyday way to
describe how you feel: *Me siento bien* ("I feel good"). It's a stem-changing
*-ir* verb with two patterns: *e → ie* in the present (except *nosotros*), and
*e → i* in the preterite third-person forms, the gerund, and the imperfect
subjunctive.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | siento      |
| tú                       | sientes     |
| usted / él / ella        | siente      |
| nosotros / nosotras      | sentimos    |
| ustedes / ellos / ellas  | sienten     |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Me siento cansado hoy.                     | I feel tired today.                   | *yo*, reflexive                  |
| ¿Cómo te sientes?                          | How are you feeling?                  | *tú*, question, reflexive          |
| Ella siente mucho no poder venir.          | She's very sorry she can't come.      | *ella*                          |
| Sentimos un gran alivio.                   | We feel a great relief.               | *nosotros*                      |
| No sienten nada de frío.                   | They don't feel cold at all.          | *ellos*, negation                 |

## Preterite

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | sentí       |
| tú                       | sentiste    |
| usted / él / ella        | sintió      |
| nosotros / nosotras      | sentimos    |
| ustedes / ellos / ellas  | sintieron   |

**Examples:**

| Spanish                                     | English                                | Notes                        |
| --------------------------------------------- | ---------------------------------------- | ------------------------------ |
| Sentí un dolor fuerte en la espalda.           | I felt a sharp pain in my back.          | *yo*                             |
| ¿Sentiste el temblor anoche?                   | Did you feel the earthquake last night?  | *tú*, question                  |
| Ella se sintió mejor después de dormir.        | She felt better after sleeping.          | *ella*, reflexive, stem change *e → i* |
| Sentimos mucha alegría con la noticia.         | We felt a lot of joy at the news.        | *nosotros*                      |
| No sintieron nada raro.                        | They didn't feel anything strange.       | *ellos*, negation, stem change   |

## Present Subjunctive

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | sienta      |
| tú                       | sientas     |
| usted / él / ella        | sienta      |
| nosotros / nosotras      | sintamos    |
| ustedes / ellos / ellas  | sientan     |

**Examples:**

| Spanish                                       | English                                  | Notes                        |
| ------------------------------------------------- | --------------------------------------------- | -------------------------------- |
| Espero que se sienta mejor pronto.                | I hope he feels better soon.                  | *usted/él/ella*, wish clause, reflexive |
| Ojalá te sientas cómodo aquí.                     | I hope you feel comfortable here.             | *tú*, *ojalá*, reflexive          |
| No creo que ella sienta lo mismo.                 | I don't think she feels the same way.         | *ella*, doubt clause              |
| Es importante que nos sintamos seguros.           | It's important that we feel safe.             | *nosotros*, reflexive, stem change *e → i* |
| Dudo que sientan pena por eso.                    | I doubt they feel bad about that.             | *ellos*, doubt clause             |

## Imperfect Subjunctive

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | sintiera    |

| usted / él / ella        | sintiera    |
| nosotros / nosotras      | sintiéramos |

**Examples:**

| Spanish                                          | English                                    | Notes                        |

| Si sintiera dolor, iría al médico.                     | If I felt pain, I'd go to the doctor.           | *yo*, *si* clause                |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | siente      | no sientas    |
| usted     | sienta      | no sienta     |
| nosotros  | sintamos    | no sintamos   |
| ustedes   | sientan     | no sientan    |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Siéntete libre de preguntar.         | Feel free to ask.                   | *tú*, affirmative, reflexive        |
| No te sientas culpable.              | Don't feel guilty.                  | *tú*, negative, reflexive            |
| Siéntanse cómodos en casa.           | Make yourselves comfortable at home. | *ustedes*, affirmative, reflexive    |

## Gerund and Past Participle

| Form             | Spanish    | English |
| ---------------- | ---------- | ------- |
| Gerund (-ing)    | sintiendo  | feeling |
| Past Participle  | sentido    | felt    |

**Examples:**

| Spanish                                     | English                             | Notes                    |
| ----------------------------------------------- | ---------------------------------------- | ---------------------------- |
| Sintiendo lástima, le ofreció ayuda.             | Feeling sorry for him, she offered help. | gerund, adverbial use, stem change *e → i* |
| Se ha sentido diferente desde entonces.          | He's felt different ever since.          | past participle, reflexive, compound tense |
