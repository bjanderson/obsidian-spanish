# producir

## Meaning

*Producir* means "to produce" — manufacturing, generating, or causing
something: *La fábrica produce autos* ("The factory produces cars"), *Esto
produce mucho estrés* ("This causes a lot of stress"). It has a *c → zc*
change in the *yo* form of the present (and throughout the subjunctive), plus
a fully irregular preterite stem, *produj-*, which drops the *i* in the
*ustedes/ellos/ellas* ending (*produjeron*, not *produjieron*) — the same
pattern as [[decir]] and *traer*.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | produzco    |
| tú                       | produces    |
| usted / él / ella        | produce     |
| nosotros / nosotras      | producimos  |
| ustedes / ellos / ellas  | producen    |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Produzco informes cada semana.             | I produce reports every week.         | *yo*, irregular *zc*              |
| ¿Produces suficiente para vender?          | Do you produce enough to sell?        | *tú*, question                  |
| Esta granja produce leche fresca.          | This farm produces fresh milk.        | impersonal subject                |
| Producimos más de lo esperado.             | We produce more than expected.        | *nosotros*                      |
| No producen suficiente para el mercado.    | They don't produce enough for the market. | *ellos*, negation             |
