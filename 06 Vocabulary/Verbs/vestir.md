# vestir

## Meaning

*Vestir* means "to dress (someone)." It's an *e → i* stem-changing verb in the
present tense (except *nosotros*), and the same *e → i* shift shows up in the
preterite third-person forms and the gerund. It's most often used reflexively as
*vestirse* ("to get dressed") when talking about dressing yourself — this file
covers the base, non-reflexive paradigm, and the reflexive form simply adds
*me/te/se/nos/se* before the same conjugated verb: *Me visto rápido* ("I get
dressed quickly").

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | visto       |
| tú                       | vistes      |
| usted / él / ella        | viste       |
| nosotros / nosotras      | vestimos    |
| ustedes / ellos / ellas  | visten      |

**Examples:**

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | -------------------------------------- | --------------------------------- |
| Visto a mi hijo antes de ir a la escuela.   | I dress my son before going to school.  | *yo*                                |
| ¿Te vistes rápido en las mañanas?           | Do you get dressed quickly in the morning? | *tú*, question, reflexive       |
| Ella viste muy bien para las entrevistas.   | She dresses very well for interviews.   | *ella*                              |
| Nos vestimos igual sin querer.              | We ended up dressed the same by accident. | *nosotros*, reflexive             |
| Los actores se visten antes de la obra.     | The actors get dressed before the play. | *ellos*, reflexive                  |

**Examples:**

| Spanish                              | English                          | Notes                              |
| -------------------------------------------- | -------------------------------------- | ------------------------------------------ |
| Viste al bebé, hace frío afuera.               | Dress the baby, it's cold outside.      | *tú*, affirmative                          |
| No vistas al niño con eso, está sucio.         | Don't dress the kid in that, it's dirty. | *tú*, negative                            |
| Vista con cuidado, la ceremonia es formal.      | Dress carefully, the ceremony is formal. | *usted*, affirmative                       |
