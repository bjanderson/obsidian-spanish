# aprender

## Meaning

*Aprender* means "to learn": *Aprendo español* (I'm learning Spanish). Followed by
*a* + infinitive, it means "to learn how to do something": *Aprendí a nadar* (I
learned to swim). It's a completely regular *-er* verb with no stem changes or
spelling shifts in any tense.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | aprendo     |
| tú                       | aprendes    |
| usted / él / ella        | aprende     |
| nosotros / nosotras      | aprendemos  |
| ustedes / ellos / ellas  | aprenden    |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Aprendo español todos los días.           | I learn Spanish every day.            | *yo*                          |
| ¿Aprendes rápido los idiomas nuevos?      | Do you learn new languages quickly?   | *tú*, question                |
| Ella aprende a tocar guitarra sola.       | She's learning to play guitar on her own. | *ella*, *a* + infinitive   |
| Aprendemos algo nuevo cada semana.        | We learn something new every week.    | *nosotros*                    |
| Mis alumnos no aprenden sin práctica.     | My students don't learn without practice. | *ellos*, negation          |
