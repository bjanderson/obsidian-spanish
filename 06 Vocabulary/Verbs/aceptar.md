# aceptar

## Meaning

*Aceptar* means "to accept" — agreeing to a proposal, an offer, or a condition.
It's a fully regular *-ar* verb with no stem changes or spelling adjustments in any
tense.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | acepto      |
| tú                       | aceptas     |
| usted / él / ella        | acepta      |
| nosotros / nosotras      | aceptamos   |
| ustedes / ellos / ellas  | aceptan     |

**Examples:**

| Spanish                                   | English                             | Notes                  |
| ------------------------------------------ | ------------------------------------- | ------------------------ |
| Acepto tu disculpa.                         | I accept your apology.                | *yo*                      |
| ¿Aceptas el trabajo?                        | Do you accept the job?                | *tú*, question            |

| Aceptamos todas las tarjetas de crédito.    | We accept all credit cards.           | *nosotros*                |
| Mis padres aceptan mi decisión.             | My parents accept my decision.        | *ellos*                   |
