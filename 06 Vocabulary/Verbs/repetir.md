# repetir

## Meaning

*Repetir* means "to repeat." It's an *e → i* stem-changing verb: the stem vowel
changes in every present-tense form except *nosotros*, and the same shift shows up
in the preterite third-person forms and the gerund.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | repito      |
| tú                       | repites     |
| usted / él / ella        | repite      |
| nosotros / nosotras      | repetimos   |
| ustedes / ellos / ellas  | repiten     |

**Examples:**

| Spanish                                | English                            | Notes           |
| ------------------------------------------ | ---------------------------------------- | ------------------ |
| Repito la palabra hasta memorizarla.         | I repeat the word until I memorize it.   | *yo*                 |
| ¿Repites lo mismo en cada clase?              | Do you repeat the same thing in every class? | *tú*, question      |
| Ella repite el ejercicio tres veces.           | She repeats the exercise three times.    | *ella*                  |
| Repetimos las instrucciones al grupo.           | We repeat the instructions to the group.  | *nosotros*                |
| No repiten el error otra vez.                    | They don't repeat the mistake again.     | *ellos*, negation             |
