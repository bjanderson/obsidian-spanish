# andar

## Meaning

*Andar* means "to walk" or, more loosely, "to go around" doing something (*anda
buscando trabajo*, "he's going around looking for work"). Its present tense is
fully regular, but its preterite is irregular — it does not take the expected
*-é/-aste/-ó* endings. Instead it borrows the irregular preterite pattern shared
by *estar* and *tener*: *anduve*, not *andé*.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | ando        |
| tú                       | andas       |
| usted / él / ella        | anda        |
| nosotros / nosotras      | andamos     |
| ustedes / ellos / ellas  | andan       |

**Examples:**

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | -------------------------------------- | --------------------------------- |
| Ando un poco cansado hoy.                   | I'm a bit tired today.                 | *yo*, idiomatic "to be" sense      |
| ¿Andas ocupado esta semana?                 | Are you busy this week?                | *tú*, question                     |
| Ella anda por el centro casi todos los días. | She walks around downtown almost every day. | *ella*                       |
| Andamos sin rumbo por la ciudad.            | We walked aimlessly through the city.  | *nosotros*                         |
| Andan buscando un nuevo apartamento.        | They're going around looking for a new apartment. | *ellos*                    |

## Preterite

| Subject                 | Conjugation  |
| ------------------------ | -------------- |
| yo                       | anduve       |
| tú                       | anduviste    |
| usted / él / ella        | anduvo       |
| nosotros / nosotras      | anduvimos    |
| ustedes / ellos / ellas  | anduvieron   |

**Examples:**

| Spanish                                    | English                              | Notes                        |
| ------------------------------------------ | ---------------------------------------- | --------------------------------- |
| Anduve por el parque toda la tarde.         | I walked around the park all afternoon.  | *yo*, irregular stem               |
| ¿Anduviste solo por esa zona?               | Did you walk around that area alone?     | *tú*, question                     |
| Anduvo perdido por horas.                   | He wandered around lost for hours.       | *él*                                |
| Anduvimos juntos hasta la estación.         | We walked together to the station.       | *nosotros*                          |
| Anduvieron de tienda en tienda.             | They went from store to store.           | *ellos*                             |

**Examples:**

| Spanish                                       | English                                  | Notes                        |

## Commands (Imperative)

| Form      | Affirmative | Negative     |
| --------- | ----------- | ------------ |
| tú        | anda        | no andes     |
| usted     | ande        | no ande      |
| nosotros  | andemos     | no andemos   |
| ustedes   | anden       | no anden     |

**Examples:**

| Spanish                        | English                      | Notes                    |
| ------------------------------------ | ------------------------------------ | ---------------------------- |
| Anda con cuidado por esa calle.       | Walk carefully down that street.     | *tú*, affirmative              |
| No andes solo tan tarde.              | Don't walk around alone so late.     | *tú*, negative                  |
| Ande despacio, por favor.             | Walk slowly, please.                 | *usted*, affirmative            |
| Andemos juntos hasta la parada.       | Let's walk together to the stop.     | *nosotros*, affirmative         |
