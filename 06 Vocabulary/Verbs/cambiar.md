# cambiar

## Meaning

*Cambiar* means "to change," both transitively (*Cambié mi contraseña*, I changed my
password) and intransitively (*El clima cambió de repente*, The weather changed
suddenly). It also covers "to exchange": *Cambié dólares por pesos* (I exchanged
dollars for pesos). The reflexive *cambiarse* means "to change clothes" or "to move
to a new home" (*Me cambié de casa*), but this file covers the plain, non-reflexive
paradigm. *Cambiar* is a fully regular *-ar* verb — no stem changes, no spelling
changes, no irregular forms anywhere in the paradigm.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------ |
| yo                       | cambio     |
| tú                       | cambias    |
| usted / él / ella        | cambia     |
| nosotros / nosotras      | cambiamos  |
| ustedes / ellos / ellas  | cambian    |

**Examples:**

| Spanish                                     | English                               | Notes             |
| ------------------------------------------------- | -------------------------------------------- | -------------------- |
| Cambio de opinión seguido.                          | I change my mind often.                       | *yo*                |
| ¿Cambias de trabajo este año?                       | Are you changing jobs this year?              | *tú*, question       |
| El clima cambia rápido en la montaña.               | The weather changes fast in the mountains.    | *él*, inanimate      |
| Cambiamos de plan a último momento.                 | We change plans at the last minute.           | *nosotros*           |
| Mis vecinos no cambian sus hábitos fácilmente.      | My neighbors don't change their habits easily. | *ellos*, negation  |
