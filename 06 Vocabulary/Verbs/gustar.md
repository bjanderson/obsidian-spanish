# gustar

## Meaning

*Gustar* works backwards from English "to like." The grammatical subject is the
thing being liked, and the person who likes it is marked with an indirect object
pronoun (*me*, *te*, *le*, *nos*, *les*). *Me gusta el café* literally means
"Coffee is pleasing to me," even though it translates as "I like coffee." Because
the verb agrees with the thing liked (not the person), it's overwhelmingly used in
the third person: *gusta* for a singular thing liked, *gustan* for plural things.
The full paradigm below is complete for reference, but real usage leans heavily on
those two forms.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | gusto       |
| tú                       | gustas      |
| usted / él / ella        | gusta       |
| nosotros / nosotras      | gustamos    |
| ustedes / ellos / ellas  | gustan      |

**Examples:**

| Spanish                                | English                              | Notes                       |
| -------------------------------------------- | -------------------------------------------- | -------------------------------- |
| Me gusta el café por las mañanas.              | I like coffee in the morning.                 | *gusta* + singular thing liked    |
| ¿Te gustan las películas de terror?              | Do you like horror movies?                    | *gustan* + plural, question        |
| A ella le gusta mucho bailar.                     | She really likes to dance.                    | *gusta* + infinitive               |
| Nos gustan los fines de semana tranquilos.        | We like quiet weekends.                       | *gustan* + plural                  |
| A ellos no les gusta madrugar.                     | They don't like getting up early.             | negation                           |

## Commands (Imperative)

*Gustar* is almost never used as a direct command — you don't order someone to
"like" something, the same way you can't in English.

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | gusta       | no gustes     |
| usted     | guste       | no guste      |
| nosotros  | gustemos    | no gustemos   |
| ustedes   | gusten      | no gusten     |

**Examples:**

| Spanish                       | English                       | Notes                          |
| ------------------------------------ | ------------------------------------ | ----------------------------------- |
| Que te guste o no, tienes que ir.      | Whether you like it or not, you have to go. | fixed expression, not a true command |

## Gerund and Past Participle

| Form             | Spanish  | English  |
| ---------------- | -------- | -------- |
| Gerund (-ing)    | gustando | liking / being pleasing |
| Past Participle  | gustado  | liked    |

**Examples:**

| Spanish                                    | English                                | Notes                    |
| -------------------------------------------------- | --------------------------------------------- | ---------------------------- |
| El plan me está gustando cada vez más.               | I'm liking the plan more and more.             | gerund, progressive tense    |
| Ese estilo de música nunca me ha gustado.             | I've never liked that style of music.          | past participle, perfect tense |
