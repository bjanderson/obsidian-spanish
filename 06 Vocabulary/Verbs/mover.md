# mover

## Meaning

*Mover* means "to move" something physically. It's an *o → ue* stem-changing verb:
the stem vowel changes in every present-tense form except *nosotros*. Don't confuse
it with *mudarse* ("to move house/relocate") — *mover* is for moving an object or
part of the body, not for changing residence.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | muevo       |
| tú                       | mueves      |
| usted / él / ella        | mueve       |
| nosotros / nosotras      | movemos     |
| ustedes / ellos / ellas  | mueven      |

**Examples:**

| Spanish                                | English                              | Notes                        |
| ------------------------------------------ | -------------------------------------- | --------------------------------- |
| Muevo la silla para limpiar debajo.         | I move the chair to clean underneath.  | *yo*                                |
| ¿Mueves los muebles tú solo?                | Do you move the furniture by yourself? | *tú*, question                      |
| Ella mueve la cabeza cuando no está de acuerdo. | She shakes her head when she disagrees. | *ella*                        |
| Movemos la mesa cada vez que limpiamos.     | We move the table every time we clean. | *nosotros*                          |
| No mueven ni un dedo para ayudar.           | They don't lift a finger to help.      | *ellos*, negation, idiomatic         |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | mueve       | no muevas     |
| usted     | mueva       | no mueva      |
| nosotros  | movamos     | no movamos    |
| ustedes   | muevan      | no muevan     |

**Examples:**

| Spanish                          | English                          | Notes                    |
| -------------------------------------- | ---------------------------------------- | ---------------------------- |
| Mueve la silla un poco a la izquierda.  | Move the chair a little to the left.     | *tú*, affirmative              |
| No muevas nada hasta que yo llegue.     | Don't move anything until I get there.   | *tú*, negative                  |
| Mueva el auto, por favor.               | Move the car, please.                    | *usted*, affirmative            |
| Movamos esto antes de que lleguen.      | Let's move this before they arrive.      | *nosotros*, affirmative         |
