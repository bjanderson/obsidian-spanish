# vivir

## Meaning

*Vivir* means "to live" — both residence (*Vivo en La Paz*, "I live in La
Paz") and being alive (*Vivió noventa años*, "He lived ninety years"). It's a
fully regular *-ir* verb throughout every tense.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | vivo        |
| tú                       | vives       |
| usted / él / ella        | vive        |
| nosotros / nosotras      | vivimos     |
| ustedes / ellos / ellas  | viven       |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Vivo cerca del centro.                     | I live near downtown.                 | *yo*                            |
| ¿Vives solo o con tu familia?              | Do you live alone or with your family? | *tú*, question                  |
| Ella vive en un apartamento pequeño.       | She lives in a small apartment.       | *ella*                          |
| Vivimos aquí desde hace cinco años.        | We've lived here for five years.      | *nosotros*                      |
| No viven muy lejos de aquí.                | They don't live very far from here.   | *ellos*, negation                 |

## Commands (Imperative)

| --------- | ----------- | -------------- |
| tú        | vive        | no vivas      |
| usted     | viva        | no viva       |
| nosotros  | vivamos     | no vivamos    |
| ustedes   | vivan       | no vivan      |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Vive el presente, no te preocupes tanto por el futuro. | Live in the present, don't worry so much about the future. | *tú*, affirmative |
| No vivas con tanto estrés.           | Don't live with so much stress.     | *tú*, negative                      |
| Vivan felices juntos.                | Live happily together.              | *ustedes*, affirmative               |
