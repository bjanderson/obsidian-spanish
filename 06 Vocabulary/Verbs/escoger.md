# escoger

## Meaning

*Escoger* means "to choose," "to pick," or "to select" among options:
*Escogí el vestido azul* ("I chose the blue dress"). When the object is a
specific person, it takes the personal *a*: *Escogieron a María para el
puesto* ("They chose María for the position"). *Escoger* has a spelling
change, not a stem change: the *g* becomes *j* whenever it's followed by *a*
or *o*, to keep the soft sound consistent — so the *yo* form is *escojo* (not
*escogo*), and the entire present subjunctive uses *escoja, escojas...* since
those endings all start with *-a*. Everywhere else (before *e* or *i*), the
spelling stays *escog-*.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | escojo      |
| tú                       | escoges     |
| usted / él / ella        | escoge      |
| nosotros / nosotras      | escogemos   |
| ustedes / ellos / ellas  | escogen     |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Escojo la ruta más rápida.                 | I choose the fastest route.           | *yo*, *g → j*                   |
| ¿Escoges el restaurante esta noche?        | Are you picking the restaurant tonight? | *tú*, question                |
| Ella siempre escoge el asiento de ventana. | She always picks the window seat.     | *ella*                          |
| Escogemos entre los dos candidatos.        | We're choosing between the two candidates. | *nosotros*                 |
| No escogen bien a sus proveedores.         | They don't choose their suppliers well. | *ellos*, negation, personal *a* |

**Examples:**

| Spanish                                       | English                                  | Notes                        |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | escoge      | no escojas    |
| usted     | escoja      | no escoja     |
| nosotros  | escojamos   | no escojamos  |
| ustedes   | escojan     | no escojan    |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Escoge el que más te guste.          | Choose the one you like best.       | *tú*, affirmative, no *g → j*       |
| No escojas el más barato solamente.  | Don't choose the cheapest one alone. | *tú*, negative, *g → j*             |
| Escoja con calma, no hay prisa.      | Choose calmly, there's no rush.     | *usted*, affirmative                |
| Escojamos juntos el regalo.          | Let's choose the gift together.     | *nosotros*, affirmative, *g → j*    |
