# utilizar

## Meaning

*Utilizar* means "to use" or "to make use of" — a slightly more formal register
than [[usar]], its everyday synonym. It's a regular *-ar* verb with one spelling
quirk: the *z* changes to *c* right before an *e*, which only shows up in the
*yo* preterite and throughout the present subjunctive.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | utilizo     |
| tú                       | utilizas    |
| usted / él / ella        | utiliza     |
| nosotros / nosotras      | utilizamos  |
| ustedes / ellos / ellas  | utilizan    |

**Examples:**

| Spanish                                    | English                              | Notes                       |
| ---------------------------------------------- | -------------------------------------------- | -------------------------------- |
| Utilizo esta aplicación para el trabajo.        | I use this app for work.                      | *yo*                              |
| ¿Utilizas transporte público a diario?          | Do you use public transportation daily?       | *tú*, question                    |
| Ella utiliza métodos modernos de enseñanza.     | She uses modern teaching methods.             | *ella*                            |
| Utilizamos energía solar en la casa.            | We use solar energy in the house.             | *nosotros*                        |
| No utilizan bien los recursos disponibles.      | They don't use the available resources well.  | *ellos*, negation                 |

## Commands (Imperative)

| Form      | Affirmative | Negative       |
| --------- | ----------- | --------------- |
| tú        | utiliza     | no utilices    |
| usted     | utilice     | no utilice     |
| nosotros  | utilicemos  | no utilicemos  |
| ustedes   | utilicen    | no utilicen    |

**Examples:**

| Spanish                                    | English                              | Notes                          |
| ------------------------------------------------ | -------------------------------------------------- | ----------------------------------- |
| Utiliza el casco cuando andes en bicicleta.        | Use a helmet when you ride your bike.                | *tú*, affirmative                   |
| No utilices ese enchufe, está dañado.              | Don't use that outlet, it's damaged.                 | *tú*, negative                      |
| Utilice la puerta de emergencia, por favor.        | Please use the emergency door.                       | *usted*, affirmative                |
| Utilicemos el tiempo con más cuidado.              | Let's use our time more carefully.                   | *nosotros*, affirmative             |
| No utilicen ese dato sin confirmarlo.              | Don't use that data without confirming it.           | *ustedes*, negative                 |
