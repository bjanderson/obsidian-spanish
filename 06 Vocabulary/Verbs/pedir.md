# pedir

## Meaning

*Pedir* means "to ask for" or "to request" a thing: *Pido un café* ("I ask
for/order a coffee"). Don't confuse it with [[preguntar]], "to ask" a
question — *pedir* is for things, favors, or requests, *preguntar* is for
information. It's an *e → i* stem-changing verb throughout the present,
preterite third-person forms, gerund, and imperfect subjunctive — the stem
vowel changes everywhere except *nosotros* in most tenses.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | pido        |
| tú                       | pides       |
| usted / él / ella        | pide        |
| nosotros / nosotras      | pedimos     |
| ustedes / ellos / ellas  | piden       |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Pido un favor de vez en cuando.            | I ask for a favor once in a while.    | *yo*                            |
| ¿Pides ayuda cuando la necesitas?          | Do you ask for help when you need it? | *tú*, question                  |
| Ella pide disculpas por el error.          | She apologizes for the mistake.       | *ella*, idiom                    |
| Pedimos la cuenta al final de la cena.     | We ask for the check at the end of dinner. | *nosotros*                    |
| No piden mucho a cambio.                   | They don't ask for much in return.    | *ellos*, negation                 |
