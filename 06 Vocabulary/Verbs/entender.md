# entender

## Meaning

*Entender* means "to understand" — a close synonym of [[comprender]], often
used interchangeably: *No entiendo* / *No comprendo* ("I don't understand").
It's an *e → ie* stem-changing verb in the present — the stem vowel changes in
every present-tense form except *nosotros*.

## Present Indicative

| Subject                 | Conjugation |
| ------------------------ | ------------- |
| yo                       | entiendo    |
| tú                       | entiendes   |
| usted / él / ella        | entiende    |
| nosotros / nosotras      | entendemos  |
| ustedes / ellos / ellas  | entienden   |

**Examples:**

| Spanish                                  | English                              | Notes                         |
| ----------------------------------------- | ------------------------------------- | ------------------------------ |
| Entiendo el problema perfectamente.        | I understand the problem perfectly.   | *yo*                            |
| ¿Entiendes lo que digo?                    | Do you understand what I'm saying?    | *tú*, question                  |
| Ella entiende tres idiomas.                | She understands three languages.      | *ella*                          |
| Entendemos tu preocupación.                | We understand your concern.           | *nosotros*                      |
| No entienden la instrucción.               | They don't understand the instruction. | *ellos*, negation                |

## Commands (Imperative)

| Form      | Affirmative | Negative      |
| --------- | ----------- | -------------- |
| tú        | entiende    | no entiendas  |
| usted     | entienda    | no entienda   |
| nosotros  | entendamos  | no entendamos |
| ustedes   | entiendan   | no entiendan  |

**Examples:**

| Spanish                          | English                        | Notes                          |
| ------------------------------------ | ----------------------------------- | ----------------------------------- |
| Entiende mi posición, por favor.     | Please understand my position.      | *tú*, affirmative                   |
| No entiendas esto como una crítica.  | Don't take this as criticism.       | *tú*, negative, idiom                |
| Entiendan que esto lleva tiempo.     | Understand that this takes time.    | *ustedes*, affirmative               |
