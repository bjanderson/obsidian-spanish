# si

## Meaning

*Si* (no accent) introduces a conditional clause — "if." It also shows up
in indirect questions meaning "whether" (*No sé si viene*, "I don't know
if/whether she's coming"). Don't confuse it with [[sí|sí]] (with an
accent), the separate word for "yes" — the accent mark is the only thing
that tells them apart in writing; they sound identical.

## Core Uses

| Use                              | Pattern                                    | Example                                  | English                                 |
| ---------------------------------- | ------------------------------------------------ | ----------------------------------------------- | ---------------------------------------------- |
| Real/likely condition                  | Si + present indicative, + present/future/imperative | Si llueve, no salimos.                            | If it rains, we won't go out.                    |
| Hypothetical (contrary to present)      | Si + imperfect subjunctive, + conditional            | Si tuviera dinero, viajaría más.                  | If I had money, I'd travel more.                 |
| Indirect question ("whether")            | [verb] + si + [clause]                                 | No sé si va a llover.                             | I don't know if it's going to rain.               |

## Examples

| Spanish                                    | English                                   | Notes                            |
| --------------------------------------------- | ------------------------------------------------ | ----------------------------------- |
| Si tienes tiempo, llámame.                     | If you have time, call me.                          | real condition, imperative            |
| Si estudias, apruebas el examen.               | If you study, you'll pass the exam.                 | real condition, present               |
| Si fuera rico, compraría esa casa.             | If I were rich, I'd buy that house.                 | hypothetical, contrary to present     |
| No sé si él sabe la verdad.                    | I don't know if he knows the truth.                 | indirect question ("whether")         |
| Pregúntale si quiere venir con nosotros.       | Ask her if she wants to come with us.               | indirect question ("whether")         |
