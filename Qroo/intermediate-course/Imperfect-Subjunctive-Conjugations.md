# **Qroo Spanish Crew Conjugating Verbs in the Imperfect Subjunctive**

#### **Introduction**

This guide focuses exclusively on how to conjugate into the imperfect subjunctive, not when. The easiest way to learn when is to learn constructions that "trigger" the subjunctive. You can learn triggers by watching my videos on the subject.

The imperfect subjunctive has two interchangeable forms: one using **-ra** endings and the other using **-se** endings. The **-ra** form is more commonly used in spoken Spanish, so we will focus on it here.

# **Formation of the Imperfect Subjunctive**

To conjugate a verb in the imperfect subjunctive:

- 1. Start with the **ellos/ellas/ustedes** form of the verb in the preterit tense.
- 2. Remove the **-ron** ending to find the stem.
- 3. Add the appropriate imperfect subjunctive ending.

# **Imperfect Subjunctive Endings (-ra Form)**

| Subject Pronoun                | Ending |
|--------------------------------|--------|
| yo                             | -ra    |
| tú                             | -ras   |
| él/ella/usted                  | -ra    |
| nosotros/nosotras              | -ramos |
| vosotros/vosotras (Spain only) | -rais  |
| ellos/ellas/ustedes            | -ran   |

*Note:* In the **nosotros** form, add a written accent on the vowel before **ramos**.

# **Irregular Verbs**

Irregular verbs in the imperfect subjunctive maintain the irregular stem from the **ellos/ellas/ustedes** form of the preterit tense.

#### **Summary**

The imperfect subjunctive provides two conjugation forms, with the **-ra** form being more common. It is formed using the **ellos/ellas/ustedes** stem from the preterit tense and adding the appropriate endings. Remembering irregular stems from the preterit will help with irregular verbs like **hacer**, **tener**, and **ser/ir**.
