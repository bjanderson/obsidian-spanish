# I. Pure Reflexive Verbs (True Reflexives)

#### Explanation

Pure reflexive verbs describe actions the subject performs **on themselves**. These verbs often exist in both a non‑pronominal and pronominal form.

- **lavar** = to wash (something)
- **lavarse** = to wash oneself

The reflexive pronoun matches the subject: - me, te, se, nos, se

| Subject                 | Reflexive Pronoun |
|-------------------------|-------------------|
| yo                      | me                |
| tú                      | te                |
| él / ella / usted       | se                |
| nosotros/as             | nos               |
| vosotros/as             | os (Spain only)   |
| ellos / ellas / ustedes | se                |

When referring to body parts or clothing, Spanish usually uses the **definite article**, not a possessive adjective.

**Example:** - *I wash my hands.* → **Me lavo las manos.**

#### Reflexive Conjugation Chart (Example: *lavarse*)

| Subject                 | Conjugation            |
|-------------------------|------------------------|
| yo                      | me lavo                |
| tú                      | te lavas               |
| él / ella / usted       | se lava                |
| nosotros/as             | nos lavamos            |
| vosotros/as             | os laváis (Spain only) |
| ellos / ellas / ustedes | se lavan               |

# II. Reciprocal Pronominal Verbs

## Explanation

Reciprocal verbs show that **two or more people perform an action on each other**. These verbs are used **only in the plural**.

Common reciprocal verbs: - abrazarse (to hug each other) - ayudarse (to help each other)

**Example:** - *We hug each other.* → **Nos abrazamos.**

# III. Inherently Pronominal Verbs (Pure Pronominals)

### Explanation

Some verbs **only exist in the pronominal form**. They do not have a non‑pronominal version and must be learned as complete units.

Common examples: - **quejarse de** = to complain about - **arrepentirse de** = to regret

**Example:** - *Carlos complains about everything.* → **Carlos se queja de todo.**

# IV. Pronominal Verbs for Passive Voice ("Se" Passive)

#### Explanation

The pronominal **se** is often used to express the passive voice when the agent is unknown or unimportant.

**Example:** - *Tickets are sold here.* → **Se venden boletos aquí.**

The verb agrees with the noun being described.

# V. Pseudo‑Reflexive Verbs (Emotions & States)

#### Explanation

These verbs look reflexive but express **emotional or psychological states**, not physical actions.

Common examples: - **enojarse** = to get angry - **alegrarse** = to become happy

**Example:** - *I get angry easily.* → **Me enojo fácilmente.**

# VI. Change in Meaning: Pronominal vs Non‑Pronominal

#### Explanation

Some verbs change meaning when used in the pronominal form.

Examples: - **dormir** = to sleep → **dormirse** = to fall asleep - **ir** = to go → **irse** = to leave

**Example:** - *I fall asleep on the couch.* → **Me duermo en el sofá.**
