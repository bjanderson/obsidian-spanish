# Pronominal Verbs with Patterns

Read the explanation carefully before each exercise. Each section focuses on a category of pronominal verbs and shows how they are used with the **patterns you already know** (tener que, querer, ir a, poder). An example is always provided before you begin.

# I. Pure Reflexive Verbs (True Reflexives)

## Explanation

Pure reflexive verbs describe actions the subject performs **on themselves**. These verbs usually exist in both a non‑pronominal and a pronominal form.

- **lavar** = to wash (something)
- **lavarse** = to wash oneself

Reflexive pronouns must agree with the subject: **me, te, se, nos, se**

When using reflexive verbs with **body parts**, Spanish normally uses the **definite article** (el, la, los, las), not a possessive adjective.

### **Example:**

I wash my hands. → **Me lavo las manos.**

## Reflexive Conjugation Chart (Example: *lavarse*)

| Subject                 | Conjugation            |
|-------------------------|------------------------|
| yo                      | me lavo                |
| tú                      | te lavas               |
| él / ella / usted       | se lava                |
| nosotros/as             | nos lavamos            |
| vosotros/as             | os laváis (Spain only) |
| ellos / ellas / ustedes | se lavan               |

# II. Pronominal Verbs with Patterns (Tener que / Querer / Ir a / Poder)

### Explanation

In this lesson, pronominal verbs are practiced using **patterns** instead of full conjugation. The verb stays in the infinitive, but the **reflexive pronoun changes** to match the subject.

Common patterns: - **tener que + infinitive** (to have to) - **querer + infinitive** (to want) - **ir a + infinitive** (to be going to) - **poder + infinitive** (can / may)

### **Example:**

I have to go to bed. → **Tengo que acostarme.**

# III. Asking Permission with Pronominal Verbs (Poder)

### Explanation

The pattern **poder + infinitive** is commonly used to ask for permission. With pronominal verbs, the reflexive pronoun must still match the subject.

### **Example:**

Can I wash my hands? → **¿Puedo lavarme las manos?**

# IV. Inherently Pronominal Verbs

## Explanation

Some verbs exist **only** in the pronominal form and must be learned that way. A common example is **quejarse de** (to complain about), which always includes the preposition **de**.

### **Example:**

I want to complain about the traffic. → **Quiero quejarme del tráfico.**

# V. Body Parts with Pronominal Verbs

## Explanation

When a pronominal verb is used with a body part, Spanish uses the **definite article**, not a possessive adjective.

### **Example:**

I'm going to brush my teeth. → **Voy a cepillarme los dientes.**
