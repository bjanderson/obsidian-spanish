In this video, I cover the **imperative mood in Spanish**, which is used to give commands. You might also hear it referred to as the **command form**. Spanish has its own set of conjugations that make it crystal clear when someone is giving a command—something we don't really have in English, where it all depends on voice and tone. In Spanish, the verb form says it all.

# **1. What Is the Imperative?**

The imperative lets us give direct instructions or orders.

Examples:

- *Siéntate.* = Sit down.
- *No te sientes.* = Don't sit down.

It only exists in the **present tense**, but it has different forms depending on who you're talking to and whether the command is **affirmative** or **negative**.

# **2. The Form You'll Use Most: Tú Commands**

This is what you'll use the most—when talking to friends, family, or people you're close to.

# **A. Regular Verbs – Affirmative (Tú)**

Take the present tense form for **tú** and drop the final **-s**.

- *Hablas* → *Habla*
- *Comes* → *Come*
- *Escribes* → *Escribe*

# **B. Regular Verbs – Negative (Tú)**

- Use the **present subjunctive** pattern:
- *No hables, no comas, no escribas*

# **C. Pronouns with Tú Commands**

- **Affirmative:** Attach the pronouns to the end: *Póntela.*
- **Negative:** Place the pronouns before the verb: *No te la pongas.*

#### **3. Common Irregular Tú Commands**

Here are the irregulars I cover in the video. These show up constantly, so I recommend memorizing them.

#### **Verb Tú Affirmative Tú Negative**

| hacer | haz | no hagas  |
|-------|-----|-----------|
| decir | di  | no digas  |
| ir    | ve  | no vayas  |
| poner | pon | no pongas |
| salir | sal | no salgas |
| ser   | sé  | no seas   |
| tener | ten | no tengas |
| venir | ven | no vengas |

Examples I used:

- *Hazlo ya.* = Do it now.
- *No lo hagas.* = Don't do it.

#### **4. Formal Usted Commands**

I also cover how to give polite or formal commands using **usted**. These follow the **present subjunctive** forms and are the same for both affirmative and negative commands.

- *Hable / No hable*
- *Coma / No coma*
- *Siéntese / No se siente*
- *Póngasela / No se la ponga*

# **5. Ustedes Commands (Group You)**

Whether you're in Latin America or using formal Spanish in Spain, the **ustedes** commands follow the same pattern as **usted**, just with an **-n** at the end.

- *Hablen / No hablen*
- *Pónganla / No la pongan*
- *Vayanse / No se vayan*

This is used when talking to a group.

#### **6. Vosotros Commands (Used in Spain Only)**

I include this for those learning European Spanish.

# **A. Affirmative:**

Drop the -r from the infinitive and add **-d**:

– *Hablad, comed, vivid*

#### **B. Negative:**

Use the present subjunctive with **vosotros** endings:

– *No habléis, no comáis, no salgáis*

With reflexives, the **-d** is dropped before adding **-os**:

– *Sentaos / No os sentéis*

### **7. Nosotros Commands ("Let's…")**

These are for suggesting actions you'll do together.

Use the present subjunctive for both affirmative and negative:

- *Hablemos / No hablemos*
- *Comamos / No comamos*

You can also use **Vamos a + infinitive** as a more casual alternative:

– *Vamos a comer.* = Let's eat.

With reflexives, Spanish drops the final **-s** before adding **-nos**:

– *Sentémonos / No nos sentemos*

# **8. Object Pronoun Order**

When you add object pronouns to commands, the order matters:

#### **Reflexive → Indirect → Direct**

Examples:

- *Póntela.* = Put it on.
- *No te la pongas.* = Don't put it on.
- *Díselo.* = Tell it to him/her.
- *No se lo digas.* = Don't tell it to him/her.

### **9. Final Tips**

I recommend starting with the **tú commands**—you'll use them the most.

Learn the **common irregulars** early, and don't stress too much about *vosotros* unless you're focusing on Spain.
