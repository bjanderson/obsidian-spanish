# **Qroo Paul's Spanish Master Course Lesson 10 Summary Skool.com/qroo**

Demonstrative adjectives are words like *this, that, these, those* used to point out specific things. In Spanish, they must match the gender (masculine/feminine) and number (singular/plural) of the noun.

The basic word order is similar to English:

**demonstrative + noun**

Example: *esta casa* = this house

# **"This" and "These"**

|       | Masculine | Feminine |
|-------|-----------|----------|
| this  | este      | esta     |
| these | estos     | estas    |

# Examples:

*este libro* — this book

*estos zapatos* — these shoes

*esta casa* — this house

*estas llaves* — these keys

# **"That" and "Those" (Closer Distance)**

|       | Masculine | Feminine |
|-------|-----------|----------|
| that  | ese       | esa      |
| those | esos      | esas     |

## Examples:

*ese carro* — that car

*esos perros* — those dogs

*esa silla* — that chair

*esas camisas* — those shirts

## **"That" and "Those" (Farther Distance / Over There)**

|                    | Masculine | Feminine |
|--------------------|-----------|----------|
| that (over there)  | aquel     | aquella  |
| those (over there) | aquellos  | aquellas |

Examples:

*aquel edificio* — that building (over there)

*aquella montaña* — that mountain (over there)

*aquellos niños* — those kids (over there)

*aquellas flores* — those flowers (over there)

Note: In daily speech, many native speakers simply use *ese/esa* even for distant things. *Aquel/aquella* is mainly used when you want to emphasize distance.

# **Neuter Forms for Concepts or Unknown Objects**

Use these when referring to something vague, general, or not identified yet.

Examples:

*¿Qué es esto?* — What is this?

*Quiero hablar de eso.* — I want to talk about that.

*¿Cómo se dice esto?* — How do you say this?

Important:

There is a neuter form *aquello*, but it's rarely used and not necessary to focus on for now.

# **Using Demonstratives Without Nouns ("This one," "That one")**

You can drop the noun if it's clear from context.

### Examples:

*¿Quieres este libro?* — Do you want this book?

*No, no quiero ese.* — No, I don't want that one.

*Prefiero esta.* — I prefer this one.

# **Talking About Time**

Demonstratives can also refer to time periods:

*En ese entonces* = at that time

*En aquel entonces* = back then (more distant)

### Examples:

*En ese entonces, Juan trabajaba con su padre.* — At that time, Juan was working with his father.

*En aquel entonces, las cosas eran muy diferentes.* — Back then, things were very different.

# **Quick Reference Chart**

|                         | Masculine        | Feminine Neuter                            |
|-------------------------|------------------|--------------------------------------------|
| This / These            | este / estos     | esta / estas esto                          |
| That / Those (near-ish) | ese / esos       | esa / esas eso                             |
| That / Those (far away) | aquel / aquellos | aquella / aquellas (aquello - rarely used) |

# **Practice Tip**

Throughout your day, pick random objects or situations and practice:

*Esta taza de café* — This cup of coffee

*Esa mesa* — That table

*Aquel edificio* — That building (over there)

*¿Qué es esto?* — What is this?

*No quiero esa.* — I don't want that one.

The more you use them naturally, the faster they'll stick.
