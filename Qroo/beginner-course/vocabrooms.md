## **Qroo Paul's Spanish Master Course Vocabulary (Rooms and Furniture) Skool.com/qroo**

## **Parts of a Room**

- La ventana window
- La puerta door
- El piso floor (*el suelo* is more common in Spain)
- El techo ceiling
- La pared wall
- La esquina corner (external, outside)
- El rincón corner (internal, inside)
- La chimenea fireplace (or chimney)
- La escalera staircase
- El interruptor light switch

## **Furniture**

- La mesa table
- La silla chair
- El sofá sofa, couch
- El sillón armchair
- La cama bed
- El buró nightstand (*la mesita de noche* in some regions)
- El escritorio desk
- La cómoda dresser
- El ropero wardrobe (*el armario* in other countries)
- El librero bookshelf
- La alacena pantry or cupboard

- El gabinete cabinet
- El tapete rug (*alfombra* is also common elsewhere)
- El espejo mirror

## **Other Related Vocabulary**

- La lámpara lamp
- El cuadro picture or painting
- Las cortinas curtains
- Las persianas blinds
- El ventilador fan
- El aire acondicionado air conditioner
- La calefacción heating
- El televisor television set
- La televisión television programming
