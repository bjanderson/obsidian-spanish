| How do you form the present perfect in Spanish? |
| ------------------------------------------------------------- |
| *haber* (present tense) + past participle<br><br><!--ANKI_NOTE_ID:1786537946847--> |

| Why is "*He un carro nuevo*" wrong? |
| ---------------------------------------------- |
| *Haber* doesn't express possession — that's *tener*'s job. Correct: *Tengo un carro nuevo*.<br><br><!--ANKI_NOTE_ID:1786537946850--> |

| Why is "*He ya comido*" wrong? |
| ------------------------------------------- |
| Nothing can separate *haber* from the past participle. Correct: *Ya he comido*.<br><br><!--ANKI_NOTE_ID:1786537946852--> |

| Why is "*Ella ha comida*" wrong? |
| ------------------------------------------- |
| The past participle never changes for gender or number in the present perfect. Correct: *Ella ha comido*.<br><br><!--ANKI_NOTE_ID:1786537946855--> |

| Where do object pronouns go relative to *haber* in the present perfect? |
| ------------------------------------------------------------------------------------ |
| Before *haber*, not between *haber* and the participle. (e.g. *Lo he visto*, not *He lo visto*.)<br><br><!--ANKI_NOTE_ID:1786537946857--> |
