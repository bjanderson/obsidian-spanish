| How do you form the regular past participle of an -ar verb? |
| ---------------------------------------------------------------------------- |
| Drop -ar, add -ado (e.g. *hablar* → *hablado*)<br><br><!--ANKI_NOTE_ID:1786538232449--> |

| How do you form the regular past participle of an -er or -ir verb? |
| ------------------------------------------------------------------------------------- |
| Drop the ending, add -ido (e.g. *comer* → *comido*, *vivir* → *vivido*)<br><br><!--ANKI_NOTE_ID:1786538232460--> |

| --------------------------------------------------------------- |
| dicho<br><br><!--ANKI_NOTE_ID:1786538232464--> |

| What is the irregular past participle of *escribir*? |
| ---------------------------------------------------------------------- |

| What is the irregular past participle of *ver*? |

| What is the irregular past participle of *volver*? |
| ---------------------------------------------------------------- |
| vuelto<br><br><!--ANKI_NOTE_ID:1786538232487--> |

| What is the past participle of *devolver*, and why? |
| -------------------------------------------------------------------- |
| *devuelto* — it inherits the irregularity from its root verb *volver*.<br><br><!--ANKI_NOTE_ID:1786538232490--> |

| Why does *leer* need a written accent in its past participle (*leído*)? |
| ------------------------------------------------------------------------------------- |
| Some -er/-ir verbs need an accent on the *í* to avoid an awkward vowel combination — without it, *leido* looks wrong.<br><br><!--ANKI_NOTE_ID:1786538232493--> |

| Why is "*Ellas han escritas*" wrong? |
| ----------------------------------------------- |
| The past participle never changes for gender or number inside the present perfect. Correct: *Ellas han escrito*.<br><br><!--ANKI_NOTE_ID:1786538232496--> |

| Fill in the blank: No he ______ (leer) ese libro todavía. |
| -------------------------------------------------------------------------- |
| leído<br><br><!--ANKI_NOTE_ID:1786538232498--> |

| Translate: I've done everything possible. |
| -------------------------------------------------------- |
| He hecho todo lo posible.<br><br><!--ANKI_NOTE_ID:1786538232501--> |
