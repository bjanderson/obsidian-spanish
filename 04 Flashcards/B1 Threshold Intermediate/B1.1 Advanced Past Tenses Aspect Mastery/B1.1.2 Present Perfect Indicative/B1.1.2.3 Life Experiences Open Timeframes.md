| Which tense do you use for an open timeframe (life so far, this year if still ongoing)? |
| ------------------------------------------------------------------------------------------------------ |
| the present perfect<br><br><!--ANKI_NOTE_ID:1786538516723--> |

| Which tense do you use for a closed, specific past moment? |
| --------------------------------------------------------------------------- |
| the preterite<br><br><!--ANKI_NOTE_ID:1786538516735--> |

| How do you say "I've never tried ceviche"? |
| ------------------------------------------------------- |
| Nunca he probado el ceviche.<br><br><!--ANKI_NOTE_ID:1786538516738--> |

| What's the standard way to ask "Have you ever...?" in Spanish? |
| ------------------------------------------------------------------------------ |
| ¿Alguna vez has...?<br><br><!--ANKI_NOTE_ID:1786538516741--> |

| Translate: Have you ever been to Argentina? |
| ---------------------------------------------------------- |
| ¿Alguna vez has estado en Argentina?<br><br><!--ANKI_NOTE_ID:1786538516744--> |

| Why is "*Ayer he ido al médico*" wrong in neutral Latin American Spanish? |
| ------------------------------------------------------------------------------------------- |
| *Ayer* is a closed, specific moment — it needs the preterite. Correct: *Ayer fui al médico*.<br><br><!--ANKI_NOTE_ID:1786538516748--> |

| Why does "*Este año he leído diez libros*" use the present perfect instead of the preterite? |
| ------------------------------------------------------------------------------------------------------------ |
| *Este año* is still an open, ongoing timeframe — the year isn't over yet.<br><br><!--ANKI_NOTE_ID:1786538516750--> |

| How would the same sentence change if you were talking about *last* year instead? |
| ------------------------------------------------------------------------------------------------- |
| It becomes closed, so you'd use the preterite: *El año pasado leí diez libros.*<br><br><!--ANKI_NOTE_ID:1786538516753--> |

| Translate: I've already watched that series twice. |
| -------------------------------------------------------------------- |
| Ya he visto esa serie dos veces.<br><br><!--ANKI_NOTE_ID:1786538516756--> |

| Translate: We still haven't decided where to go. |
| ------------------------------------------------------------- |
| Todavía no hemos decidido a dónde ir.<br><br><!--ANKI_NOTE_ID:1786538516759--> |

| Fill in the blank: La semana pasada ______ (nosotros, trabajar) todos los días. |
| --------------------------------------------------------------------------------------------- |
| trabajamos<br><br><!--ANKI_NOTE_ID:1786538516764--> |

| Fill in the blank: Esta semana ______ (yo, trabajar) mucho. |
| ---------------------------------------------------------------------------- |
| he trabajado<br><br><!--ANKI_NOTE_ID:1786538516767--> |

| In Spain (and parts of Peru and Bolivia), does the present perfect also cover recently-finished closed moments? |
| ------------------------------------------------------------------------------------------------------------------------------ |
| Yes — that's a regional variation to recognize, but the neutral Latin American pattern (open timeframe only) is what to use.<br><br><!--ANKI_NOTE_ID:1786538516771--> |
