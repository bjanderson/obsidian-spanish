| Why is "Fui a la tienda desde dos años" wrong? |
| ------------------------------------------------- |
| *Desde* points to a starting moment, not a duration — the sentence needs *hace* + preterite for "X time ago": *Fui a la tienda hace dos años.*<br><br><!--ANKI_NOTE_ID:1786729841455--> |

| Why is "Viví aquí desde 2020" wrong for "I've been living here since 2020"? |
| -------------------------------------------------------------------------------- |
| *Desde* for an ongoing state needs a present-tense verb, not the preterite: *Vivo aquí desde 2020.*<br><br><!--ANKI_NOTE_ID:1786729841457--> |

| Does *hace* conjugate for person (yo, tú, ellos, etc.) in these time expressions? |
| -------------------------------------------------------------------------------------- |
| No — *hace* stays the same regardless of the subject: *hace, hace, hace*, always.<br><br><!--ANKI_NOTE_ID:1786729841473--> |
