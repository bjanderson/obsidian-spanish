| ------------------------------------------------------------ |

| ------------------------------------------------------------------- |

| Fill in the blank: (yo) ___ dos años ___ (estudiar) español. |
| ------------------------------------------------------------------ |
| Llevo / estudiando<br><br><!--ANKI_NOTE_ID:1786729847782--> |

| Fill in the blank: Mi tía ___ diez años ___ (vivir) en Bolivia. |
| ----------------------------------------------------------------- |
| lleva / viviendo<br><br><!--ANKI_NOTE_ID:1786729847787--> |

| What conjugates in "llevar + time + gerund" — llevar or the gerund? |
| --------------------------------------------------------------------- |
| Only *llevar* conjugates (llevo, llevas, lleva...) — the gerund never changes form.<br><br><!--ANKI_NOTE_ID:1786729847792--> |

| Why is "Llevo tres años vivir aquí" wrong? |
| ----------------------------------------------- |
| The verb after the time expression must be a gerund, not an infinitive: *Llevo tres años viviendo aquí.*<br><br><!--ANKI_NOTE_ID:1786729847797--> |

| Translate: I haven't slept well in two days. (use llevar + sin + infinitive) |
| ----------------------------------------------------------------------------------- |
| Llevo dos días sin dormir bien.<br><br><!--ANKI_NOTE_ID:1786729847802--> |

| Why is "Llevo dos días no dormir bien" wrong? |
| ---------------------------------------------------- |
| The negative pattern uses *sin* + infinitive, not *no* + gerund: *Llevo dos días sin dormir bien.*<br><br><!--ANKI_NOTE_ID:1786729847805--> |

| Translate: She's been working at the same hospital for ten years. |
| --------------------------------------------------------------------- |
| Ella lleva diez años trabajando en el mismo hospital.<br><br><!--ANKI_NOTE_ID:1786729847809--> |

| What informal regional variant can replace *llevar* in this construction? |
| ------------------------------------------------------------------------------ |
| *Tener* — e.g. *Tengo cinco años trabajando aquí* means the same as *Llevo cinco años trabajando aquí.*<br><br><!--ANKI_NOTE_ID:1786729847813--> |

| Fill in the blank: Nosotros ___ una hora ___ (esperar) el tren. |
| ---------------------------------------------------------------------- |
| llevamos / esperando<br><br><!--ANKI_NOTE_ID:1786729847817--> |

| Translate: How long have you (usted) been living in Bolivia? |
| -------------------------------------------------------------------- |
| ¿Cuánto tiempo lleva usted viviendo en Bolivia?<br><br><!--ANKI_NOTE_ID:1786729847820--> |

| Where does the time expression go in "llevar + gerund"? |
| --------------------------------------------------------------- |
| Between *llevar* and the gerund: *llevar* + time + gerund, e.g. *Llevo cinco años trabajando aquí.*<br><br><!--ANKI_NOTE_ID:1786729847824--> |

| Translate: They haven't spoken to each other in years. |
| -------------------------------------------------------------- |
| Llevan años sin hablarse.<br><br><!--ANKI_NOTE_ID:1786729847826--> |

| Translate: I'm still waiting for the answer. |
| --------------------------------------------------- |
| Todavía llevo esperando la respuesta.<br><br><!--ANKI_NOTE_ID:1786729847829--> |

| Fill in the blank: Ellos ___ tres meses ___ (buscar) apartamento. |
| -------------------------------------------------------------------- |
| llevan / buscando<br><br><!--ANKI_NOTE_ID:1786729847831--> |
