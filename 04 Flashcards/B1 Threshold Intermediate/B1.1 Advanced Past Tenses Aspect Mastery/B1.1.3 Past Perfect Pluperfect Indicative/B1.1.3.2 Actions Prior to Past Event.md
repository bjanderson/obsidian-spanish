#anki/Spanish/B1-Threshold-Intermediate/B1-1-Advanced-Past-Tenses-Aspect-Mastery/B1-1-3-Past-Perfect-Pluperfect-Indicative/B1-1-3-2-Actions-Prior-to-Past-Event

| In a two-event past sequence, which event takes the past perfect — the earlier or the later one? |
| ------------------------------------------------------------------------------------------------------------------ |
| The earlier event.<br><br><!--ANKI_NOTE_ID:1786539063624--> |

| What connector word commonly introduces the later reference point in a past-perfect sentence? |
| ------------------------------------------------------------------------------------------------------------- |
| *cuando* (when)<br><br><!--ANKI_NOTE_ID:1786539063634--> |

| What word pairs naturally with the past perfect to mean "already"? |
| ------------------------------------------------------------------------------------- |
| *ya*<br><br><!--ANKI_NOTE_ID:1786539063647--> |

| What phrase pairs naturally with the past perfect to mean "not yet"? |
| --------------------------------------------------------------------------------------- |
| *todavía no*<br><br><!--ANKI_NOTE_ID:1786539063652--> |

| Translate: When I arrived at the party, everyone had already started dancing. |
| ----------------------------------------------------------------------------------------------- |
| Cuando llegué a la fiesta, todos ya habían empezado a bailar.<br><br><!--ANKI_NOTE_ID:1786539063656--> |

| Translate: She had already left when I called her. |
| -------------------------------------------------------------------- |
| Ella ya había salido cuando la llamé.<br><br><!--ANKI_NOTE_ID:1786539063659--> |

| Translate: I hadn't studied at all before the exam. |
| --------------------------------------------------------------------- |
| No había estudiado nada antes del examen.<br><br><!--ANKI_NOTE_ID:1786539063663--> |

| Can the past perfect clause come before or after the reference-point clause? |
| ----------------------------------------------------------------------------------------------- |
| Either — word order is flexible as long as it's clear which event happened first.<br><br><!--ANKI_NOTE_ID:1786539063666--> |

| In "*Cuando llegó, ya habían empezado a comer*," which action happened first? |
| ----------------------------------------------------------------------------------------------- |
| *habían empezado a comer* (they had started eating) — the past perfect marks the earlier event.<br><br><!--ANKI_NOTE_ID:1786539063669--> |

| Why is it wrong to use the past perfect for the most recent event in a two-event sequence? |
| ------------------------------------------------------------------------------------------------------------ |
| The past perfect is reserved for whichever event happened first — the more recent event takes preterite or imperfect instead.<br><br><!--ANKI_NOTE_ID:1786539063672--> |

| Fill in the blank: Todavía no ______ (yo, terminar) la tarea cuando se fue la luz. |
| --------------------------------------------------------------------------------------------------- |
| había terminado<br><br><!--ANKI_NOTE_ID:1786539063676--> |

| Translate: By the time the doctor arrived, the patient had already improved. |
| ---------------------------------------------------------------------------------------------- |
| Cuando el médico llegó, el paciente ya había mejorado.<br><br><!--ANKI_NOTE_ID:1786539063679--> |
