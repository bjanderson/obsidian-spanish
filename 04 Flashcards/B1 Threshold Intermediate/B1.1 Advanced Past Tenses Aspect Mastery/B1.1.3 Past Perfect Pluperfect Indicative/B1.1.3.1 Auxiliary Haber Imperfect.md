| What is the "nosotros" form of *haber* in the imperfect tense? |
| --------------------------------------------------------------------------- |
| habíamos<br><br><!--ANKI_NOTE_ID:1786538808140--> |

| What is the "ellos/ellas/ustedes" form of *haber* in the imperfect tense? |
| -------------------------------------------------------------------------------------- |
| habían<br><br><!--ANKI_NOTE_ID:1786538808144--> |

| How do you form the past perfect (pluperfect) in Spanish? |
| -------------------------------------------------------------------------- |
| *haber* (imperfect tense) + past participle<br><br><!--ANKI_NOTE_ID:1786538808147--> |

| What does the past perfect express? |
| ---------------------------------------------- |
| An action that had already happened before another point in the past.<br><br><!--ANKI_NOTE_ID:1786538808151--> |

| Translate: María had read the book before class. |
| ------------------------------------------------------------- |
| María había leído el libro antes de la clase.<br><br><!--ANKI_NOTE_ID:1786538808155--> |

| Translate: They had already left when I called. |
| ------------------------------------------------------------- |
| Ellos ya habían salido cuando llamé.<br><br><!--ANKI_NOTE_ID:1786538808159--> |

| Why can "*había*" be ambiguous, and how do you tell which meaning is intended? |
| ------------------------------------------------------------------------------------------------ |
| *Había* can be the impersonal "there was/were" or the auxiliary "had" — check whether a past participle follows to know which one it is.<br><br><!--ANKI_NOTE_ID:1786538808164--> |

| Why is "*Había ya terminado*" wrong? |
| ----------------------------------------------- |
| *Haber* and the past participle must stay glued together. Correct: *Ya había terminado*.<br><br><!--ANKI_NOTE_ID:1786538808168--> |

| Why is "*Había lo visto*" wrong? |
| ------------------------------------------- |
| Object pronouns go before *haber*, not after. Correct: *Lo había visto*.<br><br><!--ANKI_NOTE_ID:1786538808172--> |

| Does the past perfect tense in Spanish use the preterite or imperfect form of *haber*? |
| --------------------------------------------------------------------------------------------------- |
| The imperfect (*había, habías...*) — never the preterite (*hubo*).<br><br><!--ANKI_NOTE_ID:1786538808176--> |

| Fill in the blank: ¿______ (tú) estudiado español antes de este curso? |
| ------------------------------------------------------------------------------------ |
| Habías<br><br><!--ANKI_NOTE_ID:1786538808179--> |
