#anki/Spanish/B1-Threshold-Intermediate/B1-1-Advanced-Past-Tenses-Aspect-Mastery/B1-1-1-Advanced-Contrast-Preterite-vs-Imperfect/B1-1-1-2-Multilayered-Narrative-Framing

| In a Spanish story, which tense typically sets the background scene? |
| ----------------------------------------------------------------------------------- |
| the imperfect<br><br><!--ANKI_NOTE_ID:1786537693074--> |

| In a Spanish story, which tense typically moves the plot forward with specific events? |
| --------------------------------------------------------------------------------------------------- |
| the preterite<br><br><!--ANKI_NOTE_ID:1786537693087--> |

| What does the preterite continuous (*estuve* + gerund) emphasize? |
| ------------------------------------------------------------------------------- |
| An action that lasted a defined stretch of time and is now over.<br><br><!--ANKI_NOTE_ID:1786537693097--> |

| What does the imperfect continuous (*estaba* + gerund) emphasize? |
| ------------------------------------------------------------------------------- |
| An action in progress when something else happened.<br><br><!--ANKI_NOTE_ID:1786537693102--> |

| Translate: I was reading a book when the phone rang. |
| --------------------------------------------------------------------- |
| Estaba leyendo un libro cuando sonó el teléfono.<br><br><!--ANKI_NOTE_ID:1786537693106--> |

| Translate: I was working on that project all afternoon. |
| ------------------------------------------------------------------------ |
| Estuve trabajando toda la tarde en ese proyecto.<br><br><!--ANKI_NOTE_ID:1786537693110--> |

| What does *debí* (preterite of *deber*) express about a past action? |
| ------------------------------------------------------------------------------------- |
| Regret — something that should have happened but didn't. (e.g. *Debí decirle la verdad*.)<br><br><!--ANKI_NOTE_ID:1786537693114--> |

| What's a common, slightly more formal way to say the same thing as "*Debí decirle la verdad*"? |
| ---------------------------------------------------------------------------------------------------------------- |
| *Debí haberle dicho la verdad* (adding *haber* + past participle).<br><br><!--ANKI_NOTE_ID:1786537693118--> |

| What does *debía* (imperfect of *deber*) typically express? |
| ---------------------------------------------------------------------------- |
| Advice given at the time, without necessarily implying regret. (e.g. *Le dije que debía vender su casa*.)<br><br><!--ANKI_NOTE_ID:1786537693122--> |

| Why is "*Estuve leyendo cuando sonó el teléfono*" awkward? |
| ------------------------------------------------------------------------- |
| An interrupted background action calls for imperfect continuous, not preterite continuous. Correct: *Estaba leyendo cuando sonó el teléfono*.<br><br><!--ANKI_NOTE_ID:1786537693126--> |

| Why does a story told entirely in the preterite sound off? |
| -------------------------------------------------------------------------- |
| It reads like a list of disconnected events with no background — real narration needs imperfect for scene-setting alongside preterite for events.<br><br><!--ANKI_NOTE_ID:1786537693130--> |

| Fill in the blank: Hacía frío y el cielo ______ (parecer) que iba a nevar. |
| ------------------------------------------------------------------------------------------- |
| parecía<br><br><!--ANKI_NOTE_ID:1786537693134--> |

| Translate: We should have left earlier. |
| -------------------------------------------------- |
| Debimos haber salido más temprano.<br><br><!--ANKI_NOTE_ID:1786537693137--> |
