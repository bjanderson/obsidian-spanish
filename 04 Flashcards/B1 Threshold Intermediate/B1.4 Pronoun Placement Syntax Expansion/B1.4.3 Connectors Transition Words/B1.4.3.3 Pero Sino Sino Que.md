#anki/Spanish/B1-Threshold-Intermediate/B1-4-Pronoun-Placement-Syntax-Expansion/B1-4-3-Connectors-Transition-Words/B1-4-3-3-Pero-Sino-Sino-Que

| Can "sino" follow a positive statement? |
| ------------------------------------------------------------- |
|  No — "sino" only ever follows a negative statement<br><br><!--ANKI_NOTE_ID:1786561930064--> |

| What's the difference between "sino" and "sino que"? |
| ------------------------------------------------------------------------- |
|  "Sino" is used when nothing after it has a new conjugated verb; "sino que" is used when what follows has its own new conjugated verb<br><br><!--ANKI_NOTE_ID:1786561930068--> |

| Fill in the blank: No quiero pizza, _____ pasta. |
| ------------------------------------------------------------------ |
|  sino<br><br><!--ANKI_NOTE_ID:1786561930073--> |

| Fill in the blank: No compramos una casa, _____ alquilamos un condominio. |
| ------------------------------------------------------------------------------------------------------ |
|  sino que<br><br><!--ANKI_NOTE_ID:1786561930077--> |

| Fill in the blank: Este restaurante es bueno, _____ es muy caro. |
| ------------------------------------------------------------------------------------ |
|  pero<br><br><!--ANKI_NOTE_ID:1786561930080--> |

| Fix the mistake: "No quiero pizza, pero pasta." |
| ---------------------------------------------------------------- |
|  No quiero pizza, sino pasta. (replacing a negated thing needs "sino")<br><br><!--ANKI_NOTE_ID:1786561930084--> |

| Fix the mistake: "No compramos una casa, sino alquilamos un condominio." |
| ------------------------------------------------------------------------------------------------------ |
|  No compramos una casa, sino que alquilamos un condominio. (missing "que" before a new conjugated verb)<br><br><!--ANKI_NOTE_ID:1786561930087--> |

| Fix the mistake: "No quiero pizza, sino que pasta." |
| ---------------------------------------------------------------------- |
|  No quiero pizza, sino pasta. ("que" isn't needed — no new conjugated verb follows)<br><br><!--ANKI_NOTE_ID:1786561930090--> |

| Fix the mistake: "Me gusta el café, sino el té." |
| ------------------------------------------------------------------- |
|  Me gusta el café, pero el té también. (sino can't follow a positive statement — needs pero)<br><br><!--ANKI_NOTE_ID:1786561930093--> |

| Translate: Their dog isn't black, but golden. |
| -------------------------------------------------------------- |
|  Su perro no es negro, sino dorado.<br><br><!--ANKI_NOTE_ID:1786561930096--> |

| Translate: The dog didn't attack the ducks, but instead swam with them. |
| ------------------------------------------------------------------------------------------------ |
|  El perro no atacó a los patos, sino que nadó con ellos.<br><br><!--ANKI_NOTE_ID:1786561930099--> |

| Does "pero" ever require the first clause to be negative? |
| ---------------------------------------------------------------------------- |
|  No — "pero" works after both positive and negative statements<br><br><!--ANKI_NOTE_ID:1786561930101--> |

| Translate: The movie is interesting, but too long. |
| ------------------------------------------------------------------------ |
|  La película es interesante, pero demasiado larga.<br><br><!--ANKI_NOTE_ID:1786561930104--> |
