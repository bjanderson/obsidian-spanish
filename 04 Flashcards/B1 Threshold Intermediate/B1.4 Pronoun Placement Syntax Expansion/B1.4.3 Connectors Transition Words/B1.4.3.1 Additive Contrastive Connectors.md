#anki/Spanish/B1-Threshold-Intermediate/B1-4-Pronoun-Placement-Syntax-Expansion/B1-4-3-Connectors-Transition-Words/B1-4-3-1-Additive-Contrastive-Connectors

| What does "además" mean, and what kind of connector is it? |
| ---------------------------------------------------------------------------------- |
|  "Moreover/also/in addition" — an additive connector<br><br><!--ANKI_NOTE_ID:1786561416630--> |

| What does "sin embargo" mean, and what kind of connector is it? |
| --------------------------------------------------------------------------------------- |
|  "However/nevertheless" — a contrastive connector<br><br><!--ANKI_NOTE_ID:1786561416647--> |

| What does "no obstante" mean, and how does it compare to "sin embargo"? |
| ------------------------------------------------------------------------------------------------ |
|  "Nonetheless" — nearly interchangeable with "sin embargo," but more formal<br><br><!--ANKI_NOTE_ID:1786561416651--> |

| What's different about how "aunque" connects ideas, compared to the other three connectors in this lesson? |
| ------------------------------------------------------------------------------------------------------------------------------- |
|  "Aunque" joins two ideas inside one sentence; the others connect two separate sentences<br><br><!--ANKI_NOTE_ID:1786561416655--> |

| Translate: I study a lot. I also practice every day. |
| ------------------------------------------------------------------------- |
|  Estudio mucho. Además, practico todos los días.<br><br><!--ANKI_NOTE_ID:1786561416658--> |

| Translate: It's cold. However, we went out for a walk. |
| ---------------------------------------------------------------------------- |
|  Hace frío. Sin embargo, salimos a caminar.<br><br><!--ANKI_NOTE_ID:1786561416662--> |

| Translate: Although I was tired, I finished the project. |
| ------------------------------------------------------------------------------- |
|  Aunque estaba cansado, terminé el proyecto.<br><br><!--ANKI_NOTE_ID:1786561416665--> |

| Fix the mistake: "Estaba cansado. Aunque terminé el proyecto." |
| ------------------------------------------------------------------------------------- |
|  Estaba cansado, aunque terminé el proyecto. (aunque joins one sentence, not two separate ones)<br><br><!--ANKI_NOTE_ID:1786561416669--> |

| Fix the mistake: "Hace frío. Además, salimos a caminar." (contrast meaning) |
| ------------------------------------------------------------------------------------------------- |
|  Hace frío. Sin embargo, salimos a caminar. (además adds, it doesn't contrast)<br><br><!--ANKI_NOTE_ID:1786561416672--> |

| Fix the mistake: "Sin embargo salimos." |
| ------------------------------------------------------------- |
|  Sin embargo, salimos. (needs a comma after sin embargo)<br><br><!--ANKI_NOTE_ID:1786561416675--> |

| Is "no obstante" common in casual, everyday conversation? |
| ---------------------------------------------------------------------------- |
|  Not really — it sounds formal/bookish; "sin embargo" or "pero" fit casual speech better<br><br><!--ANKI_NOTE_ID:1786561416678--> |

| Translate: The plan was risky. Nonetheless, it worked. |
| --------------------------------------------------------------------------- |
|  El plan era arriesgado. No obstante, funcionó.<br><br><!--ANKI_NOTE_ID:1786561416680--> |

| Do "sin embargo" and "no obstante" typically need a comma when they start a sentence? |
| ------------------------------------------------------------------------------------------------------------ |
|  Yes<br><br><!--ANKI_NOTE_ID:1786561416683--> |
