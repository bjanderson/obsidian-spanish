| Does "ya que" introduce a cause or a consequence? |
| ------------------------------------------------------------------- |
|  A cause<br><br><!--ANKI_NOTE_ID:1786561633076--> |

| Does "por eso" introduce a cause or a consequence? |
| -------------------------------------------------------------------- |
|  A consequence<br><br><!--ANKI_NOTE_ID:1786561633088--> |

| What does "por lo tanto" mean, and how does it compare to "por eso"? |
| ------------------------------------------------------------------------------------------------- |
|  "Therefore/consequently" — same idea as "por eso" but more formal<br><br><!--ANKI_NOTE_ID:1786561633092--> |

| Translate: Since you have time, help me with this. |
| ------------------------------------------------------------------------ |
|  Ya que tienes tiempo, ayúdame con esto.<br><br><!--ANKI_NOTE_ID:1786561633096--> |

| Translate: I didn't study. That's why I failed the exam. |
| ------------------------------------------------------------------------------ |
|  No estudié. Por eso, reprobé el examen.<br><br><!--ANKI_NOTE_ID:1786561633099--> |

| Translate: Prices went up. Therefore, we sold less. |
| ------------------------------------------------------------------------ |
|  Los precios subieron. Por lo tanto, vendimos menos.<br><br><!--ANKI_NOTE_ID:1786561633104--> |

| Is "por lo tanto" natural in casual conversation with friends? |
| ------------------------------------------------------------------------------------- |
|  Not really — it sounds formal/stiff; "por eso" fits casual speech better<br><br><!--ANKI_NOTE_ID:1786561633107--> |

| Fix the mistake: cause and consequence reversed — "No estudié. Ya que reprobé el examen." |
| ------------------------------------------------------------------------------------------------------------ |
|  No estudié. Por eso, reprobé el examen. (por eso introduces the consequence, not ya que)<br><br><!--ANKI_NOTE_ID:1786561633110--> |

| What's the subtle difference between "ya que" and "porque"? |
| ---------------------------------------------------------------------------------- |
|  "Ya que" usually leads the sentence with a reason the listener likely already knows; "porque" more often answers a direct "why" and can go anywhere in the sentence<br><br><!--ANKI_NOTE_ID:1786561633114--> |

| Fix the mistake: "Por eso nos quedamos." (missing punctuation) |
| ------------------------------------------------------------------------------------- |
|  Por eso, nos quedamos. (needs a comma after por eso)<br><br><!--ANKI_NOTE_ID:1786561633117--> |

| Translate: Since it's raining, we're staying home. |
| ------------------------------------------------------------------------ |
|  Ya que llueve, nos quedamos en casa.<br><br><!--ANKI_NOTE_ID:1786561633120--> |

| Translate: The system failed. Therefore, we lost the data. |
| -------------------------------------------------------------------------------- |
|  El sistema falló. Por lo tanto, perdimos los datos.<br><br><!--ANKI_NOTE_ID:1786561633124--> |
