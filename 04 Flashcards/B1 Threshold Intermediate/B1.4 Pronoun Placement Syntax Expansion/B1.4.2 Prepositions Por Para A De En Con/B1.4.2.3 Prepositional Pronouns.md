#anki/Spanish/B1-Threshold-Intermediate/B1-4-Pronoun-Placement-Syntax-Expansion/B1-4-2-Prepositions-Por-Para-A-De-En-Con/B1-4-2-3-Prepositional-Pronouns

| What pronoun follows most prepositions instead of "yo"? |
| ---------------------------------------------------------------------------- |
|  mí<br><br><!--ANKI_NOTE_ID:1786561138979--> |

| What pronoun follows most prepositions instead of "tú"? |
| ---------------------------------------------------------------------------- |
|  ti<br><br><!--ANKI_NOTE_ID:1786561138983--> |

| Fix the mistake: "Es para yo." |
| ----------------------------------------------------- |
|  Es para mí. (prepositions take mí, not yo)<br><br><!--ANKI_NOTE_ID:1786561138987--> |

| What word replaces "con mí" entirely? |
| ------------------------------------------------------------- |
|  conmigo<br><br><!--ANKI_NOTE_ID:1786561138991--> |

| What word replaces "con ti" entirely? |
| ------------------------------------------------------------- |
|  contigo<br><br><!--ANKI_NOTE_ID:1786561138995--> |

| Fix the mistake: "¿Quieres venir con mí?" |
| ------------------------------------------------------------- |
|  ¿Quieres venir conmigo? ("con mí" doesn't exist in Spanish)<br><br><!--ANKI_NOTE_ID:1786561138998--> |

| Why does "mí" carry a written accent? |
| ------------------------------------------------------------- |
|  To distinguish it from "mi," the possessive meaning "my"<br><br><!--ANKI_NOTE_ID:1786561139001--> |

| Translate: They talked about him all night. |
| ------------------------------------------------------------------- |
|  Hablaron de él toda la noche.<br><br><!--ANKI_NOTE_ID:1786561139005--> |

| Which preposition is the exception that takes subject pronouns (tú, yo) instead of ti/mí? |
| ------------------------------------------------------------------------------------------------------------ |
|  entre<br><br><!--ANKI_NOTE_ID:1786561139008--> |

| Translate: This secret stays between you and me. |
| -------------------------------------------------------------------- |
|  Este secreto queda entre tú y yo.<br><br><!--ANKI_NOTE_ID:1786561139011--> |

| Fix the mistake: "entre ti y mí" |
| ---------------------------------------------------- |
|  entre tú y yo (entre takes subject pronouns, not mí/ti)<br><br><!--ANKI_NOTE_ID:1786561139014--> |

| Do él, ella, usted, nosotros, and ustedes change form after a preposition? |
| ------------------------------------------------------------------------------------------------ |
|  No — only mí and ti are different from the subject pronouns<br><br><!--ANKI_NOTE_ID:1786561139017--> |

| Translate: I can't live without you. |
| -------------------------------------------------------------- |
|  No puedo vivir sin ti.<br><br><!--ANKI_NOTE_ID:1786561139020--> |
