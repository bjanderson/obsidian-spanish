#anki/Spanish/B1-Threshold-Intermediate/B1-4-Pronoun-Placement-Syntax-Expansion/B1-4-2-Prepositions-Por-Para-A-De-En-Con/B1-4-2-2-Personal-A-Rule

| When is the personal "a" required before a direct object? |
| ---------------------------------------------------------------------------- |
|  When the direct object is a specific person or a pet<br><br><!--ANKI_NOTE_ID:1786560897127--> |

| Fix the mistake: "Veo María." |
| ------------------------------------------------- |
|  Veo a María. (missing the personal a before a specific person)<br><br><!--ANKI_NOTE_ID:1786560897133--> |

| Fix the mistake: "Veo a la playa." |
| ---------------------------------------------------------- |
|  Veo la playa. (no personal a for inanimate objects — playa is a thing)<br><br><!--ANKI_NOTE_ID:1786560897135--> |

| Do other animals besides pets take the personal "a"? |
| ------------------------------------------------------------------------- |
|  No — only pets are treated like people; other animals don't take it<br><br><!--ANKI_NOTE_ID:1786560897137--> |

| Translate: I adopted a cat last month. |
| -------------------------------------------------------------------- |
|  Adopté a un gato el mes pasado.<br><br><!--ANKI_NOTE_ID:1786560897139--> |

| What's the difference between "Buscamos un profesor" and "Buscamos a un profesor que conocemos"? |
| ------------------------------------------------------------------------------------------------------------------------- |
|  The first is non-specific (any professor); the second is specific (a professor we already know), so it takes the personal a<br><br><!--ANKI_NOTE_ID:1786560897141--> |

| Does "tener" normally take the personal a? |
| ------------------------------------------------------------ |
|  No — even with people/pets, tener usually skips it: Tengo un perro<br><br><!--ANKI_NOTE_ID:1786560897143--> |

| Translate: I have two children. |
| ----------------------------------------------------- |
|  Tengo dos hijos.<br><br><!--ANKI_NOTE_ID:1786560897144--> |

| Do "alguien" and "nadie" usually take the personal a? |
| -------------------------------------------------------------------------- |
|  Yes — even though they don't name a specific person<br><br><!--ANKI_NOTE_ID:1786560897146--> |

| Translate: I don't know anyone here. |
| -------------------------------------------------------------- |
|  No conozco a nadie aquí.<br><br><!--ANKI_NOTE_ID:1786560897148--> |

| In "Voy a invitar a mi hermano a la fiesta," which "a" is the personal a? |
| ------------------------------------------------------------------------------------------------------------ |
|  The second one, "a mi hermano" — brother is the direct object<br><br><!--ANKI_NOTE_ID:1786560897150--> |

| Fix the mistake: "Tengo a un perro." (ordinary ownership) |
| ---------------------------------------------------------------------------- |
|  Tengo un perro. (no personal a with tener in its ordinary sense)<br><br><!--ANKI_NOTE_ID:1786560897151--> |

| Translate: I see the men. |
| ------------------------------------------------- |
|  Veo a los hombres.<br><br><!--ANKI_NOTE_ID:1786560897153--> |
