#anki/Spanish/B1-Threshold-Intermediate/B1-4-Pronoun-Placement-Syntax-Expansion/B1-4-2-Prepositions-Por-Para-A-De-En-Con/B1-4-2-1-Por-vs-Para-Core-Contrast

| What's the core contrast between "por" and "para"? |
| ------------------------------------------------------------------------------ |
|  "Por" looks backward to a cause/reason; "para" looks forward to a purpose/goal<br><br><!--ANKI_NOTE_ID:1786560604549--> |

| Fill in the blank: No pudimos salir _____ la nieve. |
| ------------------------------------------------------------------------ |
|  por<br><br><!--ANKI_NOTE_ID:1786560604551--> |

| Fill in the blank: Ahorro dinero _____ comprar una casa. |
| ------------------------------------------------------------------------------ |
|  para<br><br><!--ANKI_NOTE_ID:1786560604554--> |

| Which preposition marks duration ("for three hours")? |
| ---------------------------------------------------------------------------- |
|  por<br><br><!--ANKI_NOTE_ID:1786560604556--> |

| Which preposition marks a deadline ("by Friday")? |
| -------------------------------------------------------------------- |
|  para<br><br><!--ANKI_NOTE_ID:1786560604558--> |

| Translate: I paid a lot for the house. (exchange/price) |
| --------------------------------------------------------------------------- |
|  Pagué mucho por la casa.<br><br><!--ANKI_NOTE_ID:1786560604560--> |

| Translate: This gift is for you. (recipient) |
| ---------------------------------------------------------------- |
|  Este regalo es para ti.<br><br><!--ANKI_NOTE_ID:1786560604562--> |

| Which preposition marks movement through a place? |
| -------------------------------------------------------------------- |
|  por<br><br><!--ANKI_NOTE_ID:1786560604564--> |

| Which preposition marks a destination? |
| ---------------------------------------------------------- |
|  para<br><br><!--ANKI_NOTE_ID:1786560604566--> |

| Translate: I work for her. (she's my boss) |
| -------------------------------------------------------------- |
|  Trabajo para ella.<br><br><!--ANKI_NOTE_ID:1786560604568--> |

| Translate: I work because of her. (on her behalf) |
| --------------------------------------------------------------------- |
|  Trabajo por ella.<br><br><!--ANKI_NOTE_ID:1786560604571--> |

| Fix the mistake: "Lloró para lo que pasó ayer." |
| -------------------------------------------------------------------- |
|  Lloró por lo que pasó ayer. (cause needs "por")<br><br><!--ANKI_NOTE_ID:1786560604573--> |

| Fix the mistake: "Necesito esto por el viernes." (deadline meaning) |
| ------------------------------------------------------------------------------------------- |
|  Necesito esto para el viernes. (deadline needs "para")<br><br><!--ANKI_NOTE_ID:1786560604575--> |
