#anki/Spanish/B1-Threshold-Intermediate/B1-4-Pronoun-Placement-Syntax-Expansion/B1-4-4-Basic-Relative-Pronouns/B1-4-4-2-Quien-Quienes-for-People-after-Prepositions

| What do "quien" and "quienes" refer to — people, things, or both? |
| ------------------------------------------------------------------------------------- |
|  Only people, never things<br><br><!--ANKI_NOTE_ID:1786573396645--> |

| Do "quien" and "quienes" agree in gender or in number with the person they refer to? |
| -------------------------------------------------------------------------------------------------------- |
|  Number only (singular/plural) — not gender<br><br><!--ANKI_NOTE_ID:1786573396659--> |

| What is the main situation that calls for "quien" or "quienes" instead of "que"? |
| ---------------------------------------------------------------------------------------------------- |
|  Right after a preposition (con, para, de, a...) when referring to a person<br><br><!--ANKI_NOTE_ID:1786573396667--> |

| Translate: The woman with whom I work is an engineer. |
| ------------------------------------------------------------------------- |
|  La mujer con quien trabajo es ingeniera.<br><br><!--ANKI_NOTE_ID:1786573396671--> |

| Translate: The neighbors with whom we always have dinner are very kind. |
| ----------------------------------------------------------------------------------------- |
|  Los vecinos con quienes siempre cenamos son muy amables.<br><br><!--ANKI_NOTE_ID:1786573396674--> |

| Fix the mistake: "La mujer quien trabajo con es ingeniera." |
| -------------------------------------------------------------------------------- |
|  La mujer con quien trabajo es ingeniera. (the preposition must come before quien, never stranded at the end)<br><br><!--ANKI_NOTE_ID:1786573396678--> |

| Why is a preposition never left at the end of a Spanish clause the way it can be in English? |
| ------------------------------------------------------------------------------------------------------------------ |
|  Spanish requires the preposition to come directly before the relative pronoun<br><br><!--ANKI_NOTE_ID:1786573396682--> |

| Fix the mistake: "El chico quien conocí ayer es mi primo." |
| ------------------------------------------------------------------------------- |
|  El chico que conocí ayer es mi primo. (que, not quien, is used in a restrictive clause with no preposition)<br><br><!--ANKI_NOTE_ID:1786573396686--> |

| Translate: My brother, who lives in Bogotá, is coming to visit. |
| ------------------------------------------------------------------------------------ |
|  Mi hermano, quien vive en Bogotá, viene de visita.<br><br><!--ANKI_NOTE_ID:1786573396691--> |

| In a non-restrictive clause (extra info about a person, set off by commas), can you use "quien" even without a preposition? |
| ---------------------------------------------------------------------------------------------------------------------------------------------- |
|  Yes — quien works there too, and sounds a bit more polished than que<br><br><!--ANKI_NOTE_ID:1786573396695--> |

| Translate: The person whom I saw yesterday works here. |
| -------------------------------------------------------------------------- |
|  La persona a quien vi ayer trabaja aquí.<br><br><!--ANKI_NOTE_ID:1786573396699--> |

| Fix the mistake: "La persona quien vi ayer trabaja aquí." |
| ------------------------------------------------------------------------------- |
|  La persona a quien vi ayer trabaja aquí. (the personal a is required before quien when the person is a direct object)<br><br><!--ANKI_NOTE_ID:1786573396702--> |

| Translate: The teacher for whom I wrote the essay reviewed it carefully. |
| ------------------------------------------------------------------------------------------ |
|  El profesor para quien escribí el ensayo lo revisó con cuidado.<br><br><!--ANKI_NOTE_ID:1786573396705--> |

| Fix the mistake: "Los amigos con quien salgo viven cerca." |
| -------------------------------------------------------------------------------- |
|  Los amigos con quienes salgo viven cerca. (a plural group needs quienes, not quien)<br><br><!--ANKI_NOTE_ID:1786573396708--> |

| Translate: The students whom we talked about already graduated. |
| ------------------------------------------------------------------------------------ |
|  Las estudiantes de quienes hablamos ya se graduaron.<br><br><!--ANKI_NOTE_ID:1786573396711--> |

| Fix the mistake: "La casa en quien vivo es antigua." |
| -------------------------------------------------------------------------- |
|  La casa en que vivo es antigua. (quien is for people only — use que for a house)<br><br><!--ANKI_NOTE_ID:1786573396714--> |

| Translate: The friends I go out with on Saturdays are from college. |
| -------------------------------------------------------------------------------------- |
|  Los amigos con quienes salgo los sábados son de la universidad.<br><br><!--ANKI_NOTE_ID:1786573396716--> |
