#anki/Spanish/B1-Threshold-Intermediate/B1-4-Pronoun-Placement-Syntax-Expansion/B1-4-4-Basic-Relative-Pronouns/B1-4-4-3-Donde-Como-Cuando-as-Relative-Adverbs

| What kind of detail does "donde" as a relative adverb refer back to? |
| -------------------------------------------------------------------------------------- |
|  A place<br><br><!--ANKI_NOTE_ID:1786573814367--> |

| What kind of detail does "cuando" as a relative adverb refer back to? |
| --------------------------------------------------------------------------------------- |
|  A time<br><br><!--ANKI_NOTE_ID:1786573814382--> |

| What kind of detail does "como" as a relative adverb refer back to? |
| ------------------------------------------------------------------------------------- |
|  A manner or way of doing something<br><br><!--ANKI_NOTE_ID:1786573814385--> |

| Translate: The house where I grew up no longer exists. |
| -------------------------------------------------------------------------- |
|  La casa donde crecí ya no existe.<br><br><!--ANKI_NOTE_ID:1786573814387--> |

| Translate: I remember the day when we met. |
| ----------------------------------------------------------- |
|  Recuerdo el día cuando nos conocimos.<br><br><!--ANKI_NOTE_ID:1786573814390--> |

| Translate: I like how you cook. |
| ---------------------------------------------------- |
|  Me gusta como cocinas.<br><br><!--ANKI_NOTE_ID:1786573814392--> |

| Fix the mistake: "La forma cómo lo hizo fue rara." |
| -------------------------------------------------------------------- |
|  La forma como lo hizo fue rara. (no accent mark — cómo with an accent is the question word, not the relative adverb)<br><br><!--ANKI_NOTE_ID:1786573814395--> |

| Why is "cómo" written without an accent mark when it's a relative adverb? |
| -------------------------------------------------------------------------------------------- |
|  The accent mark is only for the question/exclamation word; the relative adverb como is unaccented<br><br><!--ANKI_NOTE_ID:1786573814397--> |

| Fix the mistake: "El motivo donde se fue no está claro." |
| ------------------------------------------------------------------------------- |
|  El motivo por el que se fue no está claro. (a reason isn't a place, so donde is wrong here — use que)<br><br><!--ANKI_NOTE_ID:1786573814399--> |

| Fix the mistake: "El lugar cuando fuimos de vacaciones era hermoso." |
| ------------------------------------------------------------------------------------------------ |
|  El lugar donde fuimos de vacaciones era hermoso. (donde is for places, not cuando)<br><br><!--ANKI_NOTE_ID:1786573814401--> |

| Fix the mistake: "El año donde nací fue muy importante." |
| ------------------------------------------------------------------------------- |
|  El año cuando nací fue muy importante. (cuando is for times, not donde)<br><br><!--ANKI_NOTE_ID:1786573814403--> |

| Translate: The restaurant where we had dinner last night closed. |
| -------------------------------------------------------------------------------------- |
|  El restaurante donde cenamos anoche cerró.<br><br><!--ANKI_NOTE_ID:1786573814406--> |

| Translate: I don't understand how you solved the problem so fast. |
| --------------------------------------------------------------------------------------- |
|  No entiendo como resolviste el problema tan rápido.<br><br><!--ANKI_NOTE_ID:1786573814408--> |

| What formal alternative to "donde" uses a preposition plus "que"? |
| ------------------------------------------------------------------------------------- |
|  en que / en la que / en el que<br><br><!--ANKI_NOTE_ID:1786573814410--> |

| Translate: That was the period when prices rose a lot. |
| -------------------------------------------------------------------------- |
|  Esa fue la época cuando los precios subieron mucho.<br><br><!--ANKI_NOTE_ID:1786573814412--> |

| Is "donde vivo" or "en donde vivo" the more natural, streamlined way to say "where I live"? |
| ------------------------------------------------------------------------------------------------------------- |
|  "Donde vivo" — the "en" is redundant since donde already means "where"<br><br><!--ANKI_NOTE_ID:1786573814414--> |

| Translate: My town, where everyone knows each other, is very small. |
| ------------------------------------------------------------------------------------------ |
|  Mi pueblo, donde todos se conocen, es muy pequeño.<br><br><!--ANKI_NOTE_ID:1786573814416--> |
