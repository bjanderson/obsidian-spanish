#anki/Spanish/B1-Threshold-Intermediate/B1-4-Pronoun-Placement-Syntax-Expansion/B1-4-4-Basic-Relative-Pronouns/B1-4-4-1-Que-as-All-Purpose-Relative-Pronoun

| What is the default, all-purpose relative pronoun in Spanish? |
| ---------------------------------------------------------------------------------- |
|  que<br><br><!--ANKI_NOTE_ID:1786562138676--> |

| Does "que" work for both people and things? |
| ------------------------------------------------------------- |
|  Yes<br><br><!--ANKI_NOTE_ID:1786562138681--> |

| Can you drop "que" the way English sometimes drops "that"? |
| --------------------------------------------------------------------------------- |
|  No — Spanish always requires the relative pronoun<br><br><!--ANKI_NOTE_ID:1786562138685--> |

| Fix the mistake: "El libro leí fue interesante." |
| ------------------------------------------------------------------ |
|  El libro que leí fue interesante. (que can never be dropped)<br><br><!--ANKI_NOTE_ID:1786562138689--> |

| Translate: The woman who works here is my neighbor. |
| ------------------------------------------------------------------------ |
|  La mujer que trabaja aquí es mi vecina.<br><br><!--ANKI_NOTE_ID:1786562138693--> |

| What kind of clause does "que" typically appear in — restrictive or non-restrictive? |
| ------------------------------------------------------------------------------------------------------------- |
|  Restrictive — clauses essential to identifying which person or thing is meant, with no commas<br><br><!--ANKI_NOTE_ID:1786562138697--> |

| Fix the mistake: "La mujer quien trabaja aquí es mi vecina." |
| --------------------------------------------------------------------------------- |
|  La mujer que trabaja aquí es mi vecina. (que, not quien, is used in restrictive clauses)<br><br><!--ANKI_NOTE_ID:1786562138701--> |

| Translate: The car that we bought is very comfortable. |
| --------------------------------------------------------------------------- |
|  El carro que compramos es muy cómodo.<br><br><!--ANKI_NOTE_ID:1786562138705--> |

| Why does adding commas around "que leí" change "El libro que leí fue interesante"? |
| ------------------------------------------------------------------------------------------------------------- |
|  Without commas, que identifies which book (restrictive); with commas, it becomes extra information about a book already identified another way<br><br><!--ANKI_NOTE_ID:1786562138708--> |

| Translate: The students who study more pass. |
| -------------------------------------------------------------- |
|  Los estudiantes que estudian más aprueban.<br><br><!--ANKI_NOTE_ID:1786562138712--> |

| When you're not sure which relative pronoun to use, what's the safest default? |
| ------------------------------------------------------------------------------------------------ |
|  que<br><br><!--ANKI_NOTE_ID:1786562138715--> |

| Translate: The teacher who teaches math is very patient. |
| ---------------------------------------------------------------------------- |
|  El profesor que enseña matemáticas es muy paciente.<br><br><!--ANKI_NOTE_ID:1786562138718--> |
