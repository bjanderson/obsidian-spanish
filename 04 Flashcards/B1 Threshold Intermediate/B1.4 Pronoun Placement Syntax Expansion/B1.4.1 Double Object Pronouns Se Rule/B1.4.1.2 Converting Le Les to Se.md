#anki/Spanish/B1-Threshold-Intermediate/B1-4-Pronoun-Placement-Syntax-Expansion/B1-4-1-Double-Object-Pronouns-Se-Rule/B1-4-1-2-Converting-Le-Les-to-Se

| What happens when "le" or "les" would come right before "lo/la/los/las"? |
| ------------------------------------------------------------------------------------------------ |
|  It changes to "se"<br><br><!--ANKI_NOTE_ID:1786560116798--> |

| Combine correctly: le + lo → ___ di a Juan. |
| ------------------------------------------------------------------- |
|  Se lo di a Juan.<br><br><!--ANKI_NOTE_ID:1786560116810--> |

| Fix the mistake: "Le lo di a Juan." |
| ---------------------------------------------------------- |
|  Se lo di a Juan. (le never comes directly before lo)<br><br><!--ANKI_NOTE_ID:1786560116813--> |

| Is this "se" the same as reflexive "se" (as in "se levanta")? |
| ------------------------------------------------------------------------------------------ |
|  No — this "se" is a sound-avoidance substitute for le/les, unrelated to reflexive verbs<br><br><!--ANKI_NOTE_ID:1786560116815--> |

| Why is "Se lo di" ambiguous on its own? |
| ------------------------------------------------------------- |
|  "Se" could mean to him, to her, to you (usted), or to them<br><br><!--ANKI_NOTE_ID:1786560116817--> |

| How do you clarify an ambiguous "se"? |
| ------------------------------------------------------------- |
|  Add a phrase with "a": Se lo di a ella (I gave it to her)<br><br><!--ANKI_NOTE_ID:1786560116818--> |

| Combine correctly: les + los → ___ expliqué con calma. |
| ------------------------------------------------------------------------------ |
|  Se los expliqué con calma.<br><br><!--ANKI_NOTE_ID:1786560116820--> |

| Does the direct object pronoun (lo/la/los/las) ever change in this rule? |
| ------------------------------------------------------------------------------------------ |
|  No — only le/les changes to se; the direct object pronoun stays the same<br><br><!--ANKI_NOTE_ID:1786560116822--> |

| Translate: I sent it to him/her yesterday. |
| -------------------------------------------------------------- |
|  Se lo mandé ayer.<br><br><!--ANKI_NOTE_ID:1786560116823--> |

| Fix the mistake: "Les la prestamos." |
| --------------------------------------------------- |
|  Se la prestamos. (les must become se before la)<br><br><!--ANKI_NOTE_ID:1786560116825--> |

| Translate: Did you tell it to your sister? |
| -------------------------------------------------------------- |
|  ¿Se lo dijiste a tu hermana?<br><br><!--ANKI_NOTE_ID:1786560116827--> |

| Combine correctly: les + lo → ___ entregaron a los clientes. |
| ------------------------------------------------------------------------------------ |
|  Se lo entregaron a los clientes.<br><br><!--ANKI_NOTE_ID:1786560116829--> |

| Translate: We lent them to him without a problem. |
| ------------------------------------------------------------------------ |
|  Se los prestamos sin problema.<br><br><!--ANKI_NOTE_ID:1786560116831--> |
