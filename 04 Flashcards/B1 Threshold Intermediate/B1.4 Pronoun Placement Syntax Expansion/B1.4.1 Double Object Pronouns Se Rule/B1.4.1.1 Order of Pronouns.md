#anki/Spanish/B1-Threshold-Intermediate/B1-4-Pronoun-Placement-Syntax-Expansion/B1-4-1-Double-Object-Pronouns-Se-Rule/B1-4-1-1-Order-of-Pronouns

| When a sentence has both an indirect and a direct object pronoun, what order do they go in? |
| ------------------------------------------------------------------------------------------------------------------- |
|  Indirect before direct (think "I.D.")<br><br><!--ANKI_NOTE_ID:1786559878099--> |

| Combine correctly: me + lo → ___ dio ayer. |
| ------------------------------------------------------------------ |
|  Me lo dio ayer.<br><br><!--ANKI_NOTE_ID:1786559878101--> |

| Combine correctly: te + la → ___ mandé por correo. |
| -------------------------------------------------------------------------- |
|  Te la mandé por correo.<br><br><!--ANKI_NOTE_ID:1786559878103--> |

| Fix the mistake: "Lo me dio ayer." |
| -------------------------------------------------------- |
|  Me lo dio ayer. (indirect must come before direct)<br><br><!--ANKI_NOTE_ID:1786559878106--> |

| Translate: They showed them to us. |
| -------------------------------------------------------- |
|  Nos los mostraron.<br><br><!--ANKI_NOTE_ID:1786559878108--> |

| Translate: Will you lend it to me? |
| -------------------------------------------------------- |
|  ¿Me lo prestas?<br><br><!--ANKI_NOTE_ID:1786559878110--> |

| Can the two pronouns be separated from each other in a sentence? |
| ------------------------------------------------------------------------------------- |
|  No — they always travel together as a pair<br><br><!--ANKI_NOTE_ID:1786559878112--> |

| What question does the indirect object pronoun answer? |
| --------------------------------------------------------------------------- |
|  To/for whom?<br><br><!--ANKI_NOTE_ID:1786559878114--> |

| What question does the direct object pronoun answer? |
| ------------------------------------------------------------------------- |
|  What?<br><br><!--ANKI_NOTE_ID:1786559878116--> |

| Translate: I'll explain it to you. |
| -------------------------------------------------------- |
|  Te lo explico.<br><br><!--ANKI_NOTE_ID:1786559878118--> |

| Fix the mistake: "La te mandé por correo." |
| ---------------------------------------------------------------- |
|  Te la mandé por correo. (indirect before direct)<br><br><!--ANKI_NOTE_ID:1786559878121--> |

| Combine correctly: nos + las → ¿___ traes cuando vengas? |
| -------------------------------------------------------------------------------- |
|  ¿Nos las traes cuando vengas?<br><br><!--ANKI_NOTE_ID:1786559878123--> |

| Translate: They brought it to us. |
| ------------------------------------------------------- |
|  Nos lo trajeron.<br><br><!--ANKI_NOTE_ID:1786559878125--> |
