#anki/Spanish/B1-Threshold-Intermediate/B1-4-Pronoun-Placement-Syntax-Expansion/B1-4-1-Double-Object-Pronouns-Se-Rule/B1-4-1-3-Double-Pronoun-Placement-Rules

| Where does the pronoun pair go with a conjugated verb? |
| ------------------------------------------------------------------------- |
|  Before the verb, as separate words<br><br><!--ANKI_NOTE_ID:1786560362348--> |

| Where can the pronoun pair go with an infinitive? |
| ------------------------------------------------------------------- |
|  Attached to the end, forming one word (e.g. dárselo)<br><br><!--ANKI_NOTE_ID:1786560362351--> |

| Where does the pronoun pair go with an affirmative command? |
| -------------------------------------------------------------------------------- |
|  Attached to the end (e.g. Dáselo)<br><br><!--ANKI_NOTE_ID:1786560362353--> |

| Where does the pronoun pair go with a negative command? |
| ---------------------------------------------------------------------------- |
|  Before the verb, as separate words (e.g. No se lo des)<br><br><!--ANKI_NOTE_ID:1786560362356--> |

| Translate: I'm going to give it to him. (attached to the infinitive) |
| ------------------------------------------------------------------------------------------------- |
|  Voy a dárselo.<br><br><!--ANKI_NOTE_ID:1786560362358--> |

| Translate: I'm going to give it to him. (before the conjugated verb) |
| ------------------------------------------------------------------------------------------------- |
|  Se lo voy a dar.<br><br><!--ANKI_NOTE_ID:1786560362360--> |

| Are both "Voy a dárselo" and "Se lo voy a dar" correct? |
| --------------------------------------------------------------------------- |
|  Yes — Spanish allows both placements when there's an infinitive/gerund with a conjugated helper verb<br><br><!--ANKI_NOTE_ID:1786560362362--> |

| Fix the mistake: "No dáselo todavía." |
| ------------------------------------------------------- |
|  No se lo des todavía. (negative commands never attach the pronoun pair)<br><br><!--ANKI_NOTE_ID:1786560362363--> |

| Fix the mistake: "Estoy explicandoselo ahora." |
| -------------------------------------------------------------------- |
|  Estoy explicándoselo ahora. (missing the written accent)<br><br><!--ANKI_NOTE_ID:1786560362365--> |

| Translate: I'm explaining it to him right now. (gerund) |
| --------------------------------------------------------------------------- |
|  Estoy explicándoselo ahora mismo.<br><br><!--ANKI_NOTE_ID:1786560362367--> |

| Fix the mistake: "Se voy a darlo mañana." |
| ------------------------------------------------------------- |
|  Voy a dárselo mañana. (the pronoun pair can't be split apart)<br><br><!--ANKI_NOTE_ID:1786560362369--> |

| Translate: Give it to her when you see her. (affirmative command) |
| ------------------------------------------------------------------------------------------------ |
|  Dáselo cuando la veas.<br><br><!--ANKI_NOTE_ID:1786560362371--> |

| Does attaching two pronouns to a gerund require a written accent? |
| ------------------------------------------------------------------------------------ |
|  Yes — to keep the stress on the syllable it had before attachment<br><br><!--ANKI_NOTE_ID:1786560362372--> |
