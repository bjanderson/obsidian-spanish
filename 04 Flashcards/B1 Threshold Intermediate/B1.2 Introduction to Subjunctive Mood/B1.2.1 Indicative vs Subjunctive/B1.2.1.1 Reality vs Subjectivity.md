#anki/Spanish/B1-Threshold-Intermediate/B1-2-Introduction-to-Subjunctive-Mood/B1-2-1-Indicative-vs-Subjunctive/B1-2-1-1-Reality-vs-Subjectivity

| What is the indicative mood used for? |
| ------------------------------------------------ |
| Facts, certainty, objective reality. (e.g. *Ella escribe*.)<br><br><!--ANKI_NOTE_ID:1786539969873--> |

| What is the subjunctive mood used for? |
| ------------------------------------------------- |
| Subjectivity, doubt, desire, emotion, uncertainty. (e.g. *Espero que ella escriba*.)<br><br><!--ANKI_NOTE_ID:1786539969884--> |

| What is the third Spanish mood besides indicative and subjunctive? |
| ------------------------------------------------------------------------------- |
| The imperative (used for direct commands, e.g. *¡Escribe!*)<br><br><!--ANKI_NOTE_ID:1786539969891--> |

| Where does the subjunctive typically appear in a sentence? |
| --------------------------------------------------------------------------- |
| In a subordinate clause attached to a main clause with *que* — rarely standing alone.<br><br><!--ANKI_NOTE_ID:1786539969893--> |

| Why is relying only on the abstract "doubt/uncertainty" definition unreliable for deciding when to use the subjunctive? |
| ------------------------------------------------------------------------------------------------------------------------------------- |
| Some triggers (like *antes de que*) require the subjunctive even without real doubt — e.g. *Tienes que lavar el carro antes de que llegue tu papá* doesn't imply doubt that dad is coming.<br><br><!--ANKI_NOTE_ID:1786539969895--> |

| What is a more reliable way to know when to use the subjunctive than the abstract definition? |
| --------------------------------------------------------------------------------------------------------------- |
| Learning specific subjunctive triggers — fixed phrases and patterns that always call for it.<br><br><!--ANKI_NOTE_ID:1786539969897--> |

| When does *antes de que* trigger the subjunctive? |
| ------------------------------------------------------------- |
| When there's a subject change between the two clauses.<br><br><!--ANKI_NOTE_ID:1786539969899--> |

| What structure do you use instead of *antes de que* + subjunctive when there's no subject change? |
| -------------------------------------------------------------------------------------------------------------------- |
| *antes de* + infinitive (e.g. *Suelo leer antes de acostarme*.)<br><br><!--ANKI_NOTE_ID:1786539969901--> |

| Translate: I hope she writes soon. |
| ----------------------------------------------- |
| Espero que ella escriba pronto.<br><br><!--ANKI_NOTE_ID:1786539969904--> |

| Translate: I don't think he works here. |
| -------------------------------------------------- |
| No creo que él trabaje aquí.<br><br><!--ANKI_NOTE_ID:1786539969906--> |

| Translate: Before the movie starts, I have to buy popcorn. (subject changes) |
| ---------------------------------------------------------------------------------------------- |
| Antes de que empiece la película, tengo que comprar palomitas.<br><br><!--ANKI_NOTE_ID:1786539969909--> |

| Translate: I usually brush my teeth before going to the beach. (same subject) |
| ----------------------------------------------------------------------------------------------- |
| Suelo cepillarme los dientes antes de ir a la playa.<br><br><!--ANKI_NOTE_ID:1786539969912--> |
