#anki/Spanish/B1-Threshold-Intermediate/B1-2-Introduction-to-Subjunctive-Mood/B1-2-1-Indicative-vs-Subjunctive/B1-2-1-2-Main-Clause-Que-Subordinate-Structure

| What are the three parts of a typical subjunctive sentence? |
| -------------------------------------------------------------------------- |
| Main clause + *que* + subordinate clause (with the subjunctive verb)<br><br><!--ANKI_NOTE_ID:1786540290898--> |

| What is the single most important rule for whether a sentence needs *que* + subjunctive? |
| ---------------------------------------------------------------------------------------------------------- |
| The subject of the main clause and the subject of the subordinate clause must be different people.<br><br><!--ANKI_NOTE_ID:1786540290919--> |

| What structure do you use when the main and subordinate clause share the same subject? |
| -------------------------------------------------------------------------------------------------------- |
| No *que*, no subjunctive — just the infinitive (e.g. *Quiero ir a la playa*).<br><br><!--ANKI_NOTE_ID:1786540290924--> |

| Translate: I want you to go to the beach. |
| ---------------------------------------------------- |
| Quiero que vayas a la playa.<br><br><!--ANKI_NOTE_ID:1786540290929--> |

| Translate: I want to go to the beach. (same subject) |
| ------------------------------------------------------------------- |
| Quiero ir a la playa.<br><br><!--ANKI_NOTE_ID:1786540290933--> |

| Why is "*Quiero vayas a la tienda*" wrong? |
| ------------------------------------------------------- |
| It's missing *que* — the connector is required between the main clause and the subordinate clause.<br><br><!--ANKI_NOTE_ID:1786540290937--> |

| Why is "*Quiero que vas a la playa*" wrong? |
| -------------------------------------------------------- |
| Once there's a subject change after *que*, the subordinate verb must be subjunctive, not indicative. Correct: *vayas*.<br><br><!--ANKI_NOTE_ID:1786540290940--> |

| Why is "*Quiero que vaya a la playa*" wrong if you mean "I want to go" (same subject)? |
| -------------------------------------------------------------------------------------------------------- |
| With no subject change, you don't use *que* + subjunctive at all — it should be *Quiero ir a la playa*.<br><br><!--ANKI_NOTE_ID:1786540290943--> |

| Does the main clause of a subjunctive sentence always have to express desire? |
| ------------------------------------------------------------------------------------------------ |
| No — it can also be a time trigger (*cuando*), an emotion, a doubt, or an impersonal expression; the mechanics stay the same either way.<br><br><!--ANKI_NOTE_ID:1786540290946--> |

| Translate: Let me know when you get home. |
| ---------------------------------------------------- |
| Avísame cuando llegues a casa.<br><br><!--ANKI_NOTE_ID:1786540290949--> |

| Can you swap in a different subject for the subordinate clause without changing the formula? |
| --------------------------------------------------------------------------------------------------------------- |
| Yes — e.g. *Quiero que Juan vaya a la tienda* (I want Juan to go to the store).<br><br><!--ANKI_NOTE_ID:1786540290953--> |

| Fill in the blank: Avísame cuando ______ (tú, tener) la información. |
| ---------------------------------------------------------------------------------- |
| tengas<br><br><!--ANKI_NOTE_ID:1786540290956--> |
