#anki/Spanish/B1-Threshold-Intermediate/B1-2-Introduction-to-Subjunctive-Mood/B1-2-2-Present-Subjunctive-Formation/B1-2-2-1-Present-Subjunctive-Stems

| What is the shortcut for finding a verb's present subjunctive stem? |
| ------------------------------------------------------------------------------------- |
| Take the *yo* form of the present indicative and drop the final -o.<br><br><!--ANKI_NOTE_ID:1786540754374--> |

| What is the subjunctive stem of *hablar*? |
| ---------------------------------------------------- |
| habl- (from *yo hablo*)<br><br><!--ANKI_NOTE_ID:1786540754385--> |

| What is the subjunctive stem of *tener*? |
| --------------------------------------------------- |
| teng- (from *yo tengo*)<br><br><!--ANKI_NOTE_ID:1786540754387--> |

| What is the subjunctive stem of *hacer*? |
| --------------------------------------------------- |
| hag- (from *yo hago*)<br><br><!--ANKI_NOTE_ID:1786540754389--> |

| What is the subjunctive stem of *salir*? |
| --------------------------------------------------- |
| salg- (from *yo salgo*)<br><br><!--ANKI_NOTE_ID:1786540754391--> |

| What is the subjunctive stem of *pensar*? |
| ---------------------------------------------------- |
| piens- (from *yo pienso*)<br><br><!--ANKI_NOTE_ID:1786540754393--> |

| Why do *-go* verbs like *tener* and *hacer* keep their irregularity in the subjunctive? |
| ------------------------------------------------------------------------------------------------------ |
| Because the subjunctive stem comes from the irregular *yo* form (*tengo*, *hago*), not the infinitive.<br><br><!--ANKI_NOTE_ID:1786540754395--> |

| Do stem-changing verbs like *pensar* and *poder* follow the *yo*-form shortcut? |
| ------------------------------------------------------------------------------------------------ |
| Yes — their *yo* form already shows the stem change (*pienso*, *puedo*), so the shortcut still works.<br><br><!--ANKI_NOTE_ID:1786540754397--> |

| Which six verbs do NOT follow the *yo*-form shortcut for their subjunctive stem? |
| -------------------------------------------------------------------------------------------------- |
| *Ser, ir, saber, estar, haber, dar* (the "DISHES" verbs) — covered separately as exceptions.<br><br><!--ANKI_NOTE_ID:1786540754399--> |

| Why is "hac-" wrong as the subjunctive stem of *hacer*? |
| --------------------------------------------------------------------- |
| It was built from the infinitive instead of the *yo* form. The correct stem is *hag-*, from *yo hago*.<br><br><!--ANKI_NOTE_ID:1786540754401--> |

| Why is "sal-" wrong as the subjunctive stem of *salir*? |
| --------------------------------------------------------------------- |
| It ignores the *-go* irregularity — the correct stem is *salg-*, from *yo salgo*.<br><br><!--ANKI_NOTE_ID:1786540754403--> |

| Fill in the blank: The subjunctive stem of *conocer* is ______, from *yo conozco*. |
| --------------------------------------------------------------------------------------------------- |
| conozc-<br><br><!--ANKI_NOTE_ID:1786540754405--> |
