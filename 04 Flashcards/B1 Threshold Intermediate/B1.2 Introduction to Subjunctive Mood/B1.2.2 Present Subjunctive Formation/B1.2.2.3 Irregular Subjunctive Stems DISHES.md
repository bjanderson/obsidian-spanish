#anki/Spanish/B1-Threshold-Intermediate/B1-2-Introduction-to-Subjunctive-Mood/B1-2-2-Present-Subjunctive-Formation/B1-2-2-3-Irregular-Subjunctive-Stems-DISHES

| What does the mnemonic DISHES stand for? |
| ----------------------------------------------------- |
|  Dar, Ir, Ser, Haber, Estar, Saber — the six fully irregular present-subjunctive verbs.<br><br><!--ANKI_NOTE_ID:1786552497577--> |

| What is the "yo" present subjunctive form of *dar*? |
| ------------------------------------------------------------------- |
|  dé (with a written accent)<br><br><!--ANKI_NOTE_ID:1786552497602--> |

| What is the "yo" present subjunctive form of *ir*? |
| ------------------------------------------------------------------ |
|  vaya<br><br><!--ANKI_NOTE_ID:1786552497613--> |

| What is the "yo" present subjunctive form of *ser*? |
| ------------------------------------------------------------------- |
|  sea<br><br><!--ANKI_NOTE_ID:1786552497617--> |

| What is the "yo" present subjunctive form of *haber*? |
| ---------------------------------------------------------------------- |
|  haya<br><br><!--ANKI_NOTE_ID:1786552497621--> |

| What is the "yo" present subjunctive form of *estar*? |
| ---------------------------------------------------------------------- |
|  esté (with a written accent)<br><br><!--ANKI_NOTE_ID:1786552497625--> |

| What is the "yo" present subjunctive form of *saber*? |
| ---------------------------------------------------------------------- |
|  sepa<br><br><!--ANKI_NOTE_ID:1786552497629--> |

| Why can't you derive *ir*'s subjunctive stem from its *yo* form the normal way? |
| ------------------------------------------------------------------------------------------------- |
|  *Ir*'s *yo* form is *voy*, but the subjunctive stem is *vay-*, not *voy-* — it doesn't follow the usual shortcut.<br><br><!--ANKI_NOTE_ID:1786552497633--> |

| Why does *dé* need a written accent? |
| ----------------------------------------------- |
|  To distinguish it from *de*, the preposition meaning "of/from."<br><br><!--ANKI_NOTE_ID:1786552497636--> |

| Translate: I hope you give me an answer soon. |
| ---------------------------------------------------------- |
|  Espero que me des una respuesta pronto.<br><br><!--ANKI_NOTE_ID:1786552497640--> |

| Translate: I want you to go to the meeting. |
| -------------------------------------------------------- |
|  Quiero que vayas a la reunión.<br><br><!--ANKI_NOTE_ID:1786552497643--> |

| Translate: I hope there aren't any problems. |
| ------------------------------------------------------------ |
|  Espero que no haya problemas.<br><br><!--ANKI_NOTE_ID:1786552497646--> |

| Is *haber*'s subjunctive form (*haya*) ever used to mean "to have" in the sense of possession? |
| ------------------------------------------------------------------------------------------------------------- |
|  No — *haber* is only the impersonal "there be" (*haya*) or the auxiliary for perfect tenses, never possession (that's *tener*).<br><br><!--ANKI_NOTE_ID:1786552497650--> |
