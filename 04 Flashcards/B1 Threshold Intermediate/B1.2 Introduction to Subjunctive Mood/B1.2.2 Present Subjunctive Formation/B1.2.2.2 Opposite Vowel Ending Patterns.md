#anki/Spanish/B1-Threshold-Intermediate/B1-2-Introduction-to-Subjunctive-Mood/B1-2-2-Present-Subjunctive-Formation/B1-2-2-2-Opposite-Vowel-Ending-Patterns

| What vowel do -AR verbs switch to in the present subjunctive? |
| -------------------------------------------------------------------------------- |
| -e- (e.g. *hablar* → *hable*)<br><br><!--ANKI_NOTE_ID:1786541055400--> |

| What vowel do -ER and -IR verbs switch to in the present subjunctive? |
| -------------------------------------------------------------------------------------------- |
| -a- (e.g. *comer* → *coma*, *vivir* → *viva*)<br><br><!--ANKI_NOTE_ID:1786541055410--> |

| Do -ER and -IR verbs have different subjunctive endings from each other? |
| ---------------------------------------------------------------------------------------- |
| No — they share the exact same endings (-a, -as, -a, -amos, -an).<br><br><!--ANKI_NOTE_ID:1786541055413--> |

| What is the *nosotros* present subjunctive form of *comer*? |
| ---------------------------------------------------------------------------- |
| comamos<br><br><!--ANKI_NOTE_ID:1786541055415--> |

| What is the *nosotros* present subjunctive form of *hablar*? |
| ----------------------------------------------------------------------------- |
| hablemos<br><br><!--ANKI_NOTE_ID:1786541055417--> |

| Do -AR and -ER stem-changing verbs (like *pensar*, *poder*) change their stem in the *nosotros* subjunctive form? |
| ----------------------------------------------------------------------------------------------------------------------------------- |
| No — *nosotros* stays unchanged: *pensemos*, *podamos*.<br><br><!--ANKI_NOTE_ID:1786541055419--> |

| Do -IR stem-changing verbs (like *pedir*) change their stem in the *nosotros* subjunctive form? |
| --------------------------------------------------------------------------------------------------------------- |
| Yes — this is an exception. *Pedir* → *pidamos* (not *pedamos*).<br><br><!--ANKI_NOTE_ID:1786541055421--> |

| Why is "*pedamos*" wrong for the *nosotros* subjunctive of *pedir*? |
| ------------------------------------------------------------------------------------- |
| -IR stem-changing verbs keep their stem change in *nosotros*, unlike -AR/-ER stem-changers. Correct: *pidamos*.<br><br><!--ANKI_NOTE_ID:1786541055423--> |

| What spelling change happens to *buscar* in the present subjunctive, and why? |
| ------------------------------------------------------------------------------------------------ |
| *busque* — the *c* becomes *qu* to keep the hard /k/ sound before the *-e* ending.<br><br><!--ANKI_NOTE_ID:1786541055425--> |

| What spelling change happens to *pagar* in the present subjunctive, and why? |
| ----------------------------------------------------------------------------------------------- |
| *pague* — the *g* becomes *gu* to keep the hard /g/ sound before the *-e* ending.<br><br><!--ANKI_NOTE_ID:1786541055427--> |

| What spelling change happens to *empezar* in the present subjunctive, and why? |
| ------------------------------------------------------------------------------------------------- |
| *empiece* — the *z* becomes *c* before the *-e* ending (standard Spanish spelling rule).<br><br><!--ANKI_NOTE_ID:1786541055429--> |

| Fill in the blank: Espero que tú ______ (hablar) con ella. |
| ------------------------------------------------------------------------- |
| hables<br><br><!--ANKI_NOTE_ID:1786541055431--> |
