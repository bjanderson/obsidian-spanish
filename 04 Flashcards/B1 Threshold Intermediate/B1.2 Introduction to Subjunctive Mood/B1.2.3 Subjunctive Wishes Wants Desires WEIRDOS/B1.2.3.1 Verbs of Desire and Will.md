#anki/Spanish/B1-Threshold-Intermediate/B1-2-Introduction-to-Subjunctive-Mood/B1-2-3-Subjunctive-Wishes-Wants-Desires-WEIRDOS/B1-2-3-1-Verbs-of-Desire-and-Will

| What is the subjunctive-trigger sentence pattern? |
| ------------------------------------------------------------- |
|  [Trigger verb in indicative] + que + [verb in subjunctive]<br><br><!--ANKI_NOTE_ID:1786552965251--> |

| What are the three subjunctive triggers covered in this lesson? |
| ------------------------------------------------------------------------------ |
|  Querer que (to want that), esperar que (to hope that), desear que (to wish that)<br><br><!--ANKI_NOTE_ID:1786552965255--> |

| When do you use the subjunctive after querer/esperar/desear? |
| --------------------------------------------------------------------------- |
|  Only when the subject of the second verb is different from the first<br><br><!--ANKI_NOTE_ID:1786552965259--> |

| Translate: I want to study more. (one subject) |
| -------------------------------------------------------------- |
|  Quiero estudiar más.<br><br><!--ANKI_NOTE_ID:1786552965262--> |

| Translate: I want you to study more. (two subjects) |
| ---------------------------------------------------------------------- |
|  Quiero que estudies más.<br><br><!--ANKI_NOTE_ID:1786552965265--> |

| Fill in the blank: Espero que tú _____ (llegar) a tiempo. |
| -------------------------------------------------------------------------- |
|  llegues<br><br><!--ANKI_NOTE_ID:1786552965267--> |

| Fill in the blank: Deseo que ustedes _____ (tener) un buen viaje. |
| ---------------------------------------------------------------------------------- |
|  tengan<br><br><!--ANKI_NOTE_ID:1786552965270--> |

| Why is "Quiero que estudie" wrong if you mean "I want to study"? |
| ----------------------------------------------------------------------------------------- |
|  With only one subject, no *que* or subjunctive is needed — it should be "Quiero estudiar."<br><br><!--ANKI_NOTE_ID:1786552965273--> |

| Why is "Espero que llegas a tiempo" incorrect? |
| ---------------------------------------------------------------- |
|  *Esperar que* triggers the subjunctive in the second clause — it should be "llegues," not "llegas."<br><br><!--ANKI_NOTE_ID:1786552965275--> |

| Translate: I hope they arrive on time. |
| ---------------------------------------------------- |
|  Espero que lleguen a tiempo.<br><br><!--ANKI_NOTE_ID:1786552965277--> |

| Translate: We wish you a happy birthday. |
| -------------------------------------------------------- |
|  Deseamos que tengas un feliz cumpleaños.<br><br><!--ANKI_NOTE_ID:1786552965286--> |

| Is "desear que" more formal or more casual than "esperar que"? |
| ------------------------------------------------------------------------------- |
|  More formal — common in polite wishes and greeting-card language<br><br><!--ANKI_NOTE_ID:1786552965289--> |

| What does "esperar que" mean, and how is it different from "esperar el autobús"? |
| ------------------------------------------------------------------------------------------------- |
|  "Esperar que" means "to hope that"; "esperar el autobús" means "to wait for the bus" — different senses of *esperar*<br><br><!--ANKI_NOTE_ID:1786552965292--> |

| Translate: Do you want me to help you? |
| ---------------------------------------------------- |
|  ¿Quieres que te ayude?<br><br><!--ANKI_NOTE_ID:1786552965294--> |

| Fill in the blank: Quiero _____ (descansar) hoy. (same subject) |
| ------------------------------------------------------------------------------- |
|  descansar<br><br><!--ANKI_NOTE_ID:1786552965297--> |

| Translate: She hopes you feel better soon. |
| ------------------------------------------------------------ |
|  Ella espera que te mejores pronto.<br><br><!--ANKI_NOTE_ID:1786552965299--> |

| What is missing from this sentence: "Quiero estudies más"? |
| --------------------------------------------------------------------------- |
|  The word *que* — it must link the two clauses: "Quiero que estudies más."<br><br><!--ANKI_NOTE_ID:1786552965302--> |

| Translate: I wish you a lot of success. |
| ----------------------------------------------------- |
|  Te deseo que tengas mucho éxito.<br><br><!--ANKI_NOTE_ID:1786552965304--> |
