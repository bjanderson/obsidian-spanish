#anki/Spanish/B1-Threshold-Intermediate/B1-2-Introduction-to-Subjunctive-Mood/B1-2-3-Subjunctive-Wishes-Wants-Desires-WEIRDOS/B1-2-3-2-Requests-and-Recommendations

| What are the three request/recommendation subjunctive triggers covered in this lesson? |
| ------------------------------------------------------------------------------------------------------- |
|  Pedir que (to ask/request that), recomendar que (to recommend that), sugerir que (to suggest that)<br><br><!--ANKI_NOTE_ID:1786553293178--> |

| Translate: I'm asking you to help me. |
| --------------------------------------------------- |
|  Te pido que me ayudes.<br><br><!--ANKI_NOTE_ID:1786553293190--> |

| Translate: I recommend that you try the soup. |
| -------------------------------------------------------------- |
|  Te recomiendo que pruebes la sopa.<br><br><!--ANKI_NOTE_ID:1786553293197--> |

| Translate: I suggest you rest today. |
| -------------------------------------------------- |
|  Te sugiero que descanses hoy.<br><br><!--ANKI_NOTE_ID:1786553293202--> |

| What kind of pronoun do pedir/recomendar/sugerir usually take, pointing at the person being asked or advised? |
| ------------------------------------------------------------------------------------------------------------------------------- |
|  An indirect object pronoun (me, te, le, nos, les)<br><br><!--ANKI_NOTE_ID:1786553293207--> |

| Why doesn't "preguntar" trigger the subjunctive the way "pedir" does? |
| ------------------------------------------------------------------------------------------- |
|  *Preguntar* just asks for information; only *pedir* expresses wanting someone to do something<br><br><!--ANKI_NOTE_ID:1786553293213--> |

| Fix the mistake: "Le pregunto que venga a la fiesta." |
| ---------------------------------------------------------------------- |
|  Le pido que venga a la fiesta. (*pedir*, not *preguntar*, triggers this pattern)<br><br><!--ANKI_NOTE_ID:1786553293220--> |

| Fix the mistake: "Te pido que llegas a tiempo." |
| ----------------------------------------------------------------- |
|  Te pido que llegues a tiempo. (subjunctive, not indicative)<br><br><!--ANKI_NOTE_ID:1786553293227--> |

| Fill in the blank: Le recomiendo que _____ (probar) el ceviche. |
| ---------------------------------------------------------------------------------- |
|  pruebe<br><br><!--ANKI_NOTE_ID:1786553293233--> |

| Fill in the blank: Les sugiero que _____ (salir) más temprano. |
| --------------------------------------------------------------------------------- |
|  salgan<br><br><!--ANKI_NOTE_ID:1786553293240--> |

| Fill in the blank: Nos piden que _____ (traer) algo de comer. |
| -------------------------------------------------------------------------------- |
|  traigamos<br><br><!--ANKI_NOTE_ID:1786553293247--> |

| What's the difference in tone between "recomendar que" and "sugerir que"? |
| ------------------------------------------------------------------------------------------- |
|  *Recomendar* leans toward a stronger "this is a good idea"; *sugerir* is a lighter suggestion — they overlap heavily in practice<br><br><!--ANKI_NOTE_ID:1786553293253--> |

| Translate: My doctor recommends that I sleep more. |
| -------------------------------------------------------------------- |
|  Mi doctor me recomienda que duerma más.<br><br><!--ANKI_NOTE_ID:1786553293258--> |

| Translate: They're asking us to bring something to eat. |
| -------------------------------------------------------------------------- |
|  Nos piden que traigamos algo de comer.<br><br><!--ANKI_NOTE_ID:1786553293261--> |

| Why is "Sugiero que vengas mañana" incomplete-sounding to a native speaker? |
| --------------------------------------------------------------------------------------------- |
|  It's missing the indirect object pronoun — Spanish speakers usually say "Te sugiero que vengas mañana."<br><br><!--ANKI_NOTE_ID:1786553293265--> |

| Translate: He recommends that I study more. |
| ----------------------------------------------------------- |
|  Él me recomienda que estudie más.<br><br><!--ANKI_NOTE_ID:1786553293267--> |
