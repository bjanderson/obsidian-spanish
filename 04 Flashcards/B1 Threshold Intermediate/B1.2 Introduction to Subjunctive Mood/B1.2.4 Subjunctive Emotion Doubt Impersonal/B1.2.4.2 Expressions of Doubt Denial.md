#anki/Spanish/B1-Threshold-Intermediate/B1-2-Introduction-to-Subjunctive-Mood/B1-2-4-Subjunctive-Emotion-Doubt-Impersonal/B1-2-4-2-Expressions-of-Doubt-Denial

| Does plain "creo que" (no negation) take the indicative or the subjunctive? |
| ------------------------------------------------------------------------------------------- |
|  The indicative — it expresses certainty<br><br><!--ANKI_NOTE_ID:1786553780003--> |

| Does "no creo que" take the indicative or the subjunctive? |
| ------------------------------------------------------------------------------- |
|  The subjunctive — negating "creer" turns certainty into doubt<br><br><!--ANKI_NOTE_ID:1786553780007--> |

| Translate: I think it's true. |
| ----------------------------------------------- |
|  Creo que es verdad.<br><br><!--ANKI_NOTE_ID:1786553780010--> |

| Translate: I don't think it's true. |
| ----------------------------------------------------------- |
|  No creo que sea verdad.<br><br><!--ANKI_NOTE_ID:1786553780013--> |

| Does "dudar que" ever need "no" in front of it to trigger the subjunctive? |
| ------------------------------------------------------------------------------------------- |
|  No — "dudar" is already a doubt-expression on its own<br><br><!--ANKI_NOTE_ID:1786553780016--> |

| Translate: I doubt he'll arrive on time. |
| ------------------------------------------------------------ |
|  Dudo que llegue a tiempo.<br><br><!--ANKI_NOTE_ID:1786553780019--> |

| What is the rule of thumb for choosing indicative vs. subjunctive with belief verbs? |
| ------------------------------------------------------------------------------------------------------- |
|  Certainty → indicative; doubt or denial → subjunctive<br><br><!--ANKI_NOTE_ID:1786553780023--> |

| Fix the mistake: "Creo que esté en casa." |
| ------------------------------------------------------------- |
|  Creo que está en casa. (positive belief takes the indicative)<br><br><!--ANKI_NOTE_ID:1786553780027--> |

| Fix the mistake: "No creo que está en casa." |
| ------------------------------------------------------------------ |
|  No creo que esté en casa. (negated belief takes the subjunctive)<br><br><!--ANKI_NOTE_ID:1786553780031--> |

| How does "parecer que" behave compared to "no parecer que"? |
| -------------------------------------------------------------------------------- |
|  "Parece que" + indicative; "no parece que" + subjunctive — same certainty/doubt flip as creer<br><br><!--ANKI_NOTE_ID:1786553780034--> |

| Translate: It doesn't seem like she's tired. |
| ------------------------------------------------------------------ |
|  No parece que esté cansada.<br><br><!--ANKI_NOTE_ID:1786553780037--> |

| Translate: I deny that I said that. |
| ----------------------------------------------------------- |
|  Niego que haya dicho eso.<br><br><!--ANKI_NOTE_ID:1786553780040--> |

| Why does "negar" trigger the subjunctive? |
| ------------------------------------------------------------- |
|  Denying something is a form of doubting its truth<br><br><!--ANKI_NOTE_ID:1786553780043--> |

| Fill in the blank: Dudo que ella _____ (querer) ir a la tienda. |
| ---------------------------------------------------------------------------------- |
|  quiera<br><br><!--ANKI_NOTE_ID:1786553780046--> |

| Is it true that every negated verb triggers the subjunctive? |
| ------------------------------------------------------------------------------- |
|  No — this rule is specific to verbs of belief/certainty (creer, parecer) being negated<br><br><!--ANKI_NOTE_ID:1786553780049--> |
