| What kind of subjunctive trigger is "me alegra que"? |
| ------------------------------------------------------------------------ |
|  An emotional-reaction trigger — it makes me happy that...<br><br><!--ANKI_NOTE_ID:1786553564284--> |

| Translate: I'm glad you're here. |
| -------------------------------------------------- |
|  Me alegra que estés aquí.<br><br><!--ANKI_NOTE_ID:1786553564288--> |

| Translate: I'm afraid we'll arrive late. |
| ------------------------------------------------------------ |
|  Tengo miedo de que lleguemos tarde.<br><br><!--ANKI_NOTE_ID:1786553564291--> |

| Why do emotion triggers use the subjunctive even when the fact is 100% certain? |
| -------------------------------------------------------------------------------------------------- |
|  The trigger is the emotional reaction, not the certainty of the fact<br><br><!--ANKI_NOTE_ID:1786553564294--> |

| Fix the mistake: "Me alegra que hoy es viernes." |
| ------------------------------------------------------------------ |
|  Me alegra que hoy sea viernes. (subjunctive, not indicative, even though it's certainly Friday)<br><br><!--ANKI_NOTE_ID:1786553564297--> |

| Fix the mistake: "Tengo miedo que llueva." |
| ---------------------------------------------------------- |
|  Tengo miedo de que llueva. (needs "de")<br><br><!--ANKI_NOTE_ID:1786553564300--> |

| Translate: It surprises me that you haven't called. |
| ------------------------------------------------------------------------ |
|  Me sorprende que no hayas llamado.<br><br><!--ANKI_NOTE_ID:1786553564302--> |

| Fill in the blank: Le molesta que _____ (fumar) dentro de la casa. (ellos) |
| ------------------------------------------------------------------------------------------- |
|  fumen<br><br><!--ANKI_NOTE_ID:1786553564305--> |

| Fill in the blank: Siento mucho que _____ (perder) tu trabajo. (tú) |
| ---------------------------------------------------------------------------------- |
|  hayas perdido<br><br><!--ANKI_NOTE_ID:1786553564307--> |

| Translate: It makes us sad that you're leaving so soon. |
| -------------------------------------------------------------------------- |
|  Nos pone tristes que te vayas tan pronto.<br><br><!--ANKI_NOTE_ID:1786553564310--> |

| What does "tener miedo de que" mean, and what word must not be dropped? |
| ------------------------------------------------------------------------------------------ |
|  "To be afraid that" — the "de" must not be dropped<br><br><!--ANKI_NOTE_ID:1786553564312--> |

| Translate: We're glad everyone's here. |
| ---------------------------------------------------- |
|  Nos alegra que estén todos aquí.<br><br><!--ANKI_NOTE_ID:1786553564316--> |

| What pronoun type do expressions like "me alegra," "te sorprende," and "le molesta" use, and why? |
| ------------------------------------------------------------------------------------------------------------------- |
|  An indirect object pronoun (me, te, le, nos, les) — it names whose emotion it is<br><br><!--ANKI_NOTE_ID:1786553564320--> |

| Translate: I'm very sorry you're feeling bad. |
| ------------------------------------------------------------- |
|  Siento mucho que te sientas mal.<br><br><!--ANKI_NOTE_ID:1786553564324--> |

| Fill in the blank: Nos entristece que se _____ (mudar) tan lejos. |
| ---------------------------------------------------------------------------------- |
|  mude<br><br><!--ANKI_NOTE_ID:1786553564328--> |
