#anki/Spanish/B1-Threshold-Intermediate/B1-2-Introduction-to-Subjunctive-Mood/B1-2-4-Subjunctive-Emotion-Doubt-Impersonal/B1-2-4-3-Impersonal-Phrases

| What is the impersonal-expression sentence pattern? |
| -------------------------------------------------------------------- |
|  Es + adjective + que + [verb in subjunctive]<br><br><!--ANKI_NOTE_ID:1786554000674--> |

| Translate: It's important that you arrive on time. |
| ------------------------------------------------------------------------- |
|  Es importante que llegues a tiempo.<br><br><!--ANKI_NOTE_ID:1786554000677--> |

| Translate: It's necessary that we finish today. |
| ---------------------------------------------------------------------- |
|  Es necesario que terminemos hoy.<br><br><!--ANKI_NOTE_ID:1786554000680--> |

| Does an impersonal expression need a subject change to trigger the subjunctive, the way "querer que" does? |
| ------------------------------------------------------------------------------------------------------------------------------- |
|  No — impersonal expressions have no personal subject of their own, so the subjunctive applies in the second clause regardless<br><br><!--ANKI_NOTE_ID:1786554000683--> |

| Does "es verdad que" (it's true that) take the indicative or the subjunctive? |
| ---------------------------------------------------------------------------------------------- |
|  The indicative — it states a fact, not a judgment<br><br><!--ANKI_NOTE_ID:1786554000685--> |

| Fix the mistake: "Es importante que llegas a tiempo." |
| ---------------------------------------------------------------------- |
|  Es importante que llegues a tiempo. (subjunctive, not indicative)<br><br><!--ANKI_NOTE_ID:1786554000688--> |

| Fix the mistake: "Es verdad que haga frío." |
| ----------------------------------------------------------- |
|  Es verdad que hace frío. (indicative, since it states a fact)<br><br><!--ANKI_NOTE_ID:1786554000690--> |

| Translate: It's good that you're trying. |
| ------------------------------------------------------------ |
|  Es bueno que lo intentes.<br><br><!--ANKI_NOTE_ID:1786554000693--> |

| Translate: It's strange that he hasn't answered yet. |
| -------------------------------------------------------------------------- |
|  Es raro que no haya contestado todavía.<br><br><!--ANKI_NOTE_ID:1786554000696--> |

| What structure does Spanish use for a general statement with no specific subject, like "It's important to study"? |
| ------------------------------------------------------------------------------------------------------------------------------------- |
|  The infinitive, with no "que": Es importante estudiar<br><br><!--ANKI_NOTE_ID:1786554000698--> |

| Fix the mistake: "Es importante que estudiar." |
| ---------------------------------------------------------------- |
|  Either "Es importante estudiar" (infinitive, no que) or "Es importante que estudies" (que + subjunctive)<br><br><!--ANKI_NOTE_ID:1786554000700--> |

| Fill in the blank: Es necesario que todos _____ (participar). |
| -------------------------------------------------------------------------------- |
|  participen<br><br><!--ANKI_NOTE_ID:1786554000703--> |

| Fill in the blank: Es mejor que _____ (esperar). (nosotros) |
| ------------------------------------------------------------------------------ |
|  esperemos<br><br><!--ANKI_NOTE_ID:1786554000705--> |

| Translate: It's a shame that you can't come. |
| ---------------------------------------------------------------- |
|  Es una lástima que no puedas venir.<br><br><!--ANKI_NOTE_ID:1786554000707--> |

| Give two more impersonal expressions besides "es importante que" and "es necesario que" that follow the same pattern. |
| ------------------------------------------------------------------------------------------------------------------------------------------- |
|  Any two of: es bueno que, es malo que, es raro que, es mejor que, es una lástima que<br><br><!--ANKI_NOTE_ID:1786554000711--> |
