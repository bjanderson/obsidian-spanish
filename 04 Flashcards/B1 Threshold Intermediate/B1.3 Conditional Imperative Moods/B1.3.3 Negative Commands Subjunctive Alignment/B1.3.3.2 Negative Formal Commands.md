#anki/Spanish/B1-Threshold-Intermediate/B1-3-Conditional-Imperative-Moods/B1-3-3-Negative-Commands-Subjunctive-Alignment/B1-3-3-2-Negative-Formal-Commands

| Is the negative usted/ustedes command form different from the affirmative form? |
| ------------------------------------------------------------------------------------------------- |
|  No — it's the identical present-subjunctive form, just with "no" added in front<br><br><!--ANKI_NOTE_ID:1786557710154--> |

| Give the negative usted command for "hablar." |
| -------------------------------------------------------------------- |
|  no hable<br><br><!--ANKI_NOTE_ID:1786557710157--> |

| Give the negative ustedes command for "comer." |
| --------------------------------------------------------------------- |
|  no coman<br><br><!--ANKI_NOTE_ID:1786557710160--> |

| Give the negative usted command for "ir." |
| ------------------------------------------------------------- |
|  no vaya<br><br><!--ANKI_NOTE_ID:1786557710163--> |

| Give the negative ustedes command for "ser." |
| ---------------------------------------------------------------- |
|  no sean<br><br><!--ANKI_NOTE_ID:1786557710167--> |

| Give the negative usted command for "dar." |
| -------------------------------------------------------------- |
|  no dé<br><br><!--ANKI_NOTE_ID:1786557710169--> |

| How is learning negative formal commands easier than negative tú commands? |
| ------------------------------------------------------------------------------------------------- |
|  There's only one form to learn per verb — it covers both affirmative and negative<br><br><!--ANKI_NOTE_ID:1786557710172--> |

| Fix the mistake: "No tráigalo." |
| --------------------------------------------------- |
|  No lo traiga. (pronoun goes before the verb in a negative command)<br><br><!--ANKI_NOTE_ID:1786557710175--> |

| Translate: Don't worry. (ustedes) |
| ------------------------------------------------------- |
|  No se preocupen.<br><br><!--ANKI_NOTE_ID:1786557710177--> |

| Translate: Don't speak so fast, please. (usted) |
| -------------------------------------------------------------------- |
|  No hable tan rápido, por favor.<br><br><!--ANKI_NOTE_ID:1786557710180--> |

| Do the DISHES irregular subjunctive stems carry over into negative formal commands? |
| -------------------------------------------------------------------------------------------------------- |
|  Yes — since formal commands ARE the subjunctive, all the same irregularities apply<br><br><!--ANKI_NOTE_ID:1786557710182--> |

| Give the negative usted command for "estar." |
| ---------------------------------------------------------------- |
|  no esté<br><br><!--ANKI_NOTE_ID:1786557710185--> |

| Translate: Don't be so negative. (ustedes) |
| -------------------------------------------------------------- |
|  No sean tan negativos.<br><br><!--ANKI_NOTE_ID:1786557710187--> |

| What's the difference between "No hables" and "No hable"? |
| -------------------------------------------------------------------------------- |
|  "No hables" is the informal tú negative command; "No hable" is the formal usted negative command<br><br><!--ANKI_NOTE_ID:1786557710189--> |
