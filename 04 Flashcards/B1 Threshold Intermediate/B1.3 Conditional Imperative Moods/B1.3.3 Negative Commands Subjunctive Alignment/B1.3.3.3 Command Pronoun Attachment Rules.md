#anki/Spanish/B1-Threshold-Intermediate/B1-3-Conditional-Imperative-Moods/B1-3-3-Negative-Commands-Subjunctive-Alignment/B1-3-3-3-Command-Pronoun-Attachment-Rules

| Where does an object pronoun go in an affirmative command? |
| ------------------------------------------------------------------------------- |
|  Attached to the end of the verb, as one word<br><br><!--ANKI_NOTE_ID:1786557961002--> |

| Where does an object pronoun go in a negative command? |
| --------------------------------------------------------------------------- |
|  Before the verb, as its own word<br><br><!--ANKI_NOTE_ID:1786557961007--> |

| Combine: come + lo (affirmative tú) |
| --------------------------------------------------- |
|  Cómelo<br><br><!--ANKI_NOTE_ID:1786557961012--> |

| Combine: no comas + lo (negative tú) |
| ---------------------------------------------------- |
|  No lo comas<br><br><!--ANKI_NOTE_ID:1786557961015--> |

| Combine: traiga + lo (affirmative usted) |
| -------------------------------------------------------------- |
|  Tráigalo<br><br><!--ANKI_NOTE_ID:1786557961020--> |

| When do you need a written accent after attaching a pronoun to a command? |
| ------------------------------------------------------------------------------------------------ |
|  When the command has more than one syllable, to keep the stress on its original syllable<br><br><!--ANKI_NOTE_ID:1786557961023--> |

| Combine: pon + lo (affirmative tú) — does this need an accent? |
| ----------------------------------------------------------------------------------- |
|  Ponlo — no accent needed, it's only one syllable<br><br><!--ANKI_NOTE_ID:1786557961027--> |

| Combine: escribe + lo (affirmative tú) |
| -------------------------------------------------------- |
|  Escríbelo<br><br><!--ANKI_NOTE_ID:1786557961031--> |

| Fix the mistake: "No cómelo todavía." |
| ------------------------------------------------------- |
|  No lo comas todavía. (pronoun must precede, not attach, in a negative command)<br><br><!--ANKI_NOTE_ID:1786557961034--> |

| What happens to "le" when it's followed by "lo," "la," "los," or "las"? |
| ------------------------------------------------------------------------------------------ |
|  It changes to "se"<br><br><!--ANKI_NOTE_ID:1786557961038--> |

| Combine: di + le + lo (affirmative tú, two pronouns) |
| -------------------------------------------------------------------------- |
|  Díselo<br><br><!--ANKI_NOTE_ID:1786557961043--> |

| Fix the mistake: "Escribelo en la pizarra." |
| ------------------------------------------------------------- |
|  Escríbelo en la pizarra. (missing the accent)<br><br><!--ANKI_NOTE_ID:1786557961047--> |

| Does this attach-vs-precede rule apply the same way to tú, usted, and ustedes commands? |
| ------------------------------------------------------------------------------------------------------------- |
|  Yes — the same rule applies across every command type<br><br><!--ANKI_NOTE_ID:1786557961051--> |

| Translate: Bring it tomorrow, please. (affirmative usted) |
| -------------------------------------------------------------------------------- |
|  Tráigalo mañana, por favor.<br><br><!--ANKI_NOTE_ID:1786557961056--> |
