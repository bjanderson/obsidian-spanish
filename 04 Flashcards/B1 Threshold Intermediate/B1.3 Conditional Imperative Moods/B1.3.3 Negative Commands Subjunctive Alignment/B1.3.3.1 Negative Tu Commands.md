#anki/Spanish/B1-Threshold-Intermediate/B1-3-Conditional-Imperative-Moods/B1-3-3-Negative-Commands-Subjunctive-Alignment/B1-3-3-1-Negative-Tu-Commands

| What grammar pattern do negative tú commands use? |
| ------------------------------------------------------------------ |
|  "No" + the present subjunctive tú form<br><br><!--ANKI_NOTE_ID:1786557480129--> |

| Give the negative tú command for "hablar." |
| -------------------------------------------------------------- |
|  no hables<br><br><!--ANKI_NOTE_ID:1786557480133--> |

| Give the negative tú command for "comer." |
| ------------------------------------------------------------- |
|  no comas<br><br><!--ANKI_NOTE_ID:1786557480138--> |

| Do the affirmative tú irregulars (ven, di, sal, haz, ten, ve, pon, sé) carry over into negative commands? |
| ------------------------------------------------------------------------------------------------------------------------------- |
|  No — the negative form follows the regular subjunctive pattern instead<br><br><!--ANKI_NOTE_ID:1786557480142--> |

| Give the negative tú command for "venir." |
| ------------------------------------------------------------- |
|  no vengas<br><br><!--ANKI_NOTE_ID:1786557480145--> |

| Give the negative tú command for "decir." |
| ------------------------------------------------------------- |
|  no digas<br><br><!--ANKI_NOTE_ID:1786557480149--> |

| Fix the mistake: "No ven tarde." |
| ---------------------------------------------------- |
|  No vengas tarde. (irregular affirmative stem, not the subjunctive form)<br><br><!--ANKI_NOTE_ID:1786557480152--> |

| Give the negative tú command for "ir." |
| ---------------------------------------------------------- |
|  no vayas<br><br><!--ANKI_NOTE_ID:1786557480156--> |

| Where do object pronouns go in a negative command? |
| ------------------------------------------------------------------ |
|  Before the verb — the opposite of affirmative commands, where they attach to the end<br><br><!--ANKI_NOTE_ID:1786557480159--> |

| Fix the mistake: "No cómelo." |
| ------------------------------------------------------ |
|  No lo comas. (pronoun goes before the verb in a negative command)<br><br><!--ANKI_NOTE_ID:1786557480162--> |

| Translate: Don't speak so loudly. |
| ------------------------------------------------------- |
|  No hables tan alto.<br><br><!--ANKI_NOTE_ID:1786557480165--> |

| Translate: Don't go alone. |
| ------------------------------------------------ |
|  No vayas solo.<br><br><!--ANKI_NOTE_ID:1786557480168--> |

| Fix the mistake: "No hablas tan alto." |
| ---------------------------------------------------------------- |
|  No hables tan alto. (present indicative used instead of subjunctive)<br><br><!--ANKI_NOTE_ID:1786557480171--> |

| Give the negative tú command for "poner." |
| ------------------------------------------------------------- |
|  no pongas<br><br><!--ANKI_NOTE_ID:1786557480175--> |
