#anki/Spanish/B1-Threshold-Intermediate/B1-3-Conditional-Imperative-Moods/B1-3-1-Simple-Conditional-Tense/B1-3-1-2-Irregular-Conditional-Stems

| Which 8 verbs have irregular stems in the conditional? |
| ------------------------------------------------------------------------- |
|  decir, hacer, poder, poner, querer, saber, salir, tener<br><br><!--ANKI_NOTE_ID:1786556463658--> |

| What tense's irregular stems does the conditional reuse? |
| --------------------------------------------------------------------------- |
|  The future tense — same irregular stems, different endings<br><br><!--ANKI_NOTE_ID:1786556463662--> |

| What is the conditional stem for "decir"? |
| ----------------------------------------------------------- |
|  dir-<br><br><!--ANKI_NOTE_ID:1786556463665--> |

| What is the conditional stem for "tener"? |
| ----------------------------------------------------------- |
|  tendr-<br><br><!--ANKI_NOTE_ID:1786556463669--> |

| What is the conditional stem for "hacer"? |
| ----------------------------------------------------------- |
|  har-<br><br><!--ANKI_NOTE_ID:1786556463672--> |

| What is the conditional stem for "poner"? |
| ----------------------------------------------------------- |
|  pondr-<br><br><!--ANKI_NOTE_ID:1786556463675--> |

| Do irregular-stem verbs use different conditional endings than regular verbs? |
| ---------------------------------------------------------------------------------------------- |
|  No — the endings (-ía, -ías, -ía, -íamos, -ían) are identical; only the stem changes<br><br><!--ANKI_NOTE_ID:1786556463680--> |

| Conjugate "poder" in the conditional for "ella." |
| -------------------------------------------------------------------- |
|  podría<br><br><!--ANKI_NOTE_ID:1786556463684--> |

| Conjugate "saber" in the conditional for "yo." |
| ------------------------------------------------------------------ |
|  sabría<br><br><!--ANKI_NOTE_ID:1786556463688--> |

| Fix the mistake: "Yo tenería que trabajar mañana." |
| -------------------------------------------------------------------- |
|  Yo tendría que trabajar mañana. (the stem is tendr-, not tener + ía)<br><br><!--ANKI_NOTE_ID:1786556463692--> |

| Translate: What would you do? |
| ----------------------------------------------- |
|  ¿Qué harías?<br><br><!--ANKI_NOTE_ID:1786556463695--> |

| Translate: I would have to study more. |
| ---------------------------------------------------------- |
|  Tendría que estudiar más.<br><br><!--ANKI_NOTE_ID:1786556463699--> |

| Translate: She could help you tomorrow. |
| ----------------------------------------------------------- |
|  Ella podría ayudarte mañana.<br><br><!--ANKI_NOTE_ID:1786556463702--> |

| What's the difference between "podría" (conditional) and "puede" (present)? |
| ------------------------------------------------------------------------------------------- |
|  "Podría" softens it into a polite possibility ("could/would be able to"); "puede" is a plain present-tense fact ("can/is able to")<br><br><!--ANKI_NOTE_ID:1786556463706--> |

| Fill in the blank: Nosotros _____ (poner) la mesa si llegaran a tiempo. |
| ------------------------------------------------------------------------------------------------------------------ |
|  pondríamos<br><br><!--ANKI_NOTE_ID:1786556463710--> |
