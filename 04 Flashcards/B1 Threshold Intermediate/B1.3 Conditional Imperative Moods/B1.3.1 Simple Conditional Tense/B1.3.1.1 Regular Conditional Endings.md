#anki/Spanish/B1-Threshold-Intermediate/B1-3-Conditional-Imperative-Moods/B1-3-1-Simple-Conditional-Tense/B1-3-1-1-Regular-Conditional-Endings

| What are the five regular conditional endings? |
| ---------------------------------------------------------------- |
|  -ía, -ías, -ía, -íamos, -ían<br><br><!--ANKI_NOTE_ID:1786556208526--> |

| How do you form the regular conditional tense? |
| ----------------------------------------------------------------- |
|  Take the full infinitive and add the conditional ending — no stem changes<br><br><!--ANKI_NOTE_ID:1786556208531--> |

| Are the conditional endings different for -ar, -er, and -ir verbs? |
| ------------------------------------------------------------------------------------- |
|  No — all three verb types use the exact same set of endings<br><br><!--ANKI_NOTE_ID:1786556208535--> |

| Conjugate "hablar" in the conditional for "yo." |
| ------------------------------------------------------------------- |
|  hablaría<br><br><!--ANKI_NOTE_ID:1786556208539--> |

| Conjugate "comer" in the conditional for "tú." |
| ------------------------------------------------------------------ |
|  comerías<br><br><!--ANKI_NOTE_ID:1786556208543--> |

| Conjugate "vivir" in the conditional for "nosotros." |
| ---------------------------------------------------------------------------- |
|  viviríamos<br><br><!--ANKI_NOTE_ID:1786556208546--> |

| Translate: I would talk to her if I could. |
| ------------------------------------------------------------ |
|  Yo hablaría con ella si pudiera.<br><br><!--ANKI_NOTE_ID:1786556208550--> |

| Translate: They would buy the house. |
| -------------------------------------------------- |
|  Ellos comprarían la casa.<br><br><!--ANKI_NOTE_ID:1786556208554--> |

| What's the difference between "hablaría" (conditional) and "hablaba" (imperfect)? |
| -------------------------------------------------------------------------------------------------- |
|  "Hablaría" means "would speak"; "hablaba" means "used to speak / was speaking" — different meanings<br><br><!--ANKI_NOTE_ID:1786556208558--> |

| Why do "yo" and "él/ella/usted" share the same conditional form? |
| ------------------------------------------------------------------------------------------- |
|  Both use the -ía ending, just like in the imperfect tense — context tells you which is meant<br><br><!--ANKI_NOTE_ID:1786556208561--> |

| Fix the mistake: "hablaria" (missing accent). |
| ------------------------------------------------------------------------- |
|  hablaría — the í always carries a written accent<br><br><!--ANKI_NOTE_ID:1786556208565--> |

| Fill in the blank: Ella _____ (vivir) en la playa si tuviera dinero. |
| ------------------------------------------------------------------------------------------------ |
|  viviría<br><br><!--ANKI_NOTE_ID:1786556208568--> |

| Fill in the blank: Nosotros _____ (viajar) más si tuviéramos tiempo. |
| ------------------------------------------------------------------------------------------------ |
|  viajaríamos<br><br><!--ANKI_NOTE_ID:1786556208571--> |
