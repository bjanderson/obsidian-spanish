#anki/Spanish/B1-Threshold-Intermediate/B1-3-Conditional-Imperative-Moods/B1-3-1-Simple-Conditional-Tense/B1-3-1-3-Conditional-Uses-Advice-Politeness

| What are the three main everyday uses of the conditional tense covered in this lesson? |
| ------------------------------------------------------------------------------------------------------------- |
|  Politeness, giving advice, and talking about hypothetical situations<br><br><!--ANKI_NOTE_ID:1786556610177--> |

| Translate: Could you tell me the time, please? (formal) |
| ---------------------------------------------------------------------------- |
|  ¿Podría decirme la hora, por favor?<br><br><!--ANKI_NOTE_ID:1786556610182--> |

| Translate: Could you help me with this? (informal) |
| ----------------------------------------------------------------------- |
|  ¿Podrías ayudarme con esto?<br><br><!--ANKI_NOTE_ID:1786556610186--> |

| What Spanish pattern means "if I were you"? |
| ----------------------------------------------------------------- |
|  Yo que tú (or Yo en tu lugar) + conditional<br><br><!--ANKI_NOTE_ID:1786556610190--> |

| Translate: If I were you, I'd talk to her. |
| -------------------------------------------------------------- |
|  Yo que tú, hablaría con ella.<br><br><!--ANKI_NOTE_ID:1786556610193--> |

| Is "me gustaría una hamburguesa" a natural way to order food? |
| ---------------------------------------------------------------------------------------------- |
|  No — it sounds overly formal; "quiero" or "quisiera" are more natural for ordering<br><br><!--ANKI_NOTE_ID:1786556610197--> |

| What's the difference between "¿podría...?" and "¿podrías...?" |
| ------------------------------------------------------------------------------------------- |
|  "Podría" is formal (usted); "podrías" is informal (tú)<br><br><!--ANKI_NOTE_ID:1786556610200--> |

| Translate: Would you like to come to the party? (informal) |
| -------------------------------------------------------------------------------- |
|  ¿Te gustaría venir a la fiesta?<br><br><!--ANKI_NOTE_ID:1786556610203--> |

| Fill in the blank: Me _____ (gustar) aprender a tocar guitarra. |
| ------------------------------------------------------------------------------------------ |
|  gustaría<br><br><!--ANKI_NOTE_ID:1786556610206--> |

| What is the basic pattern for a hypothetical "if X, then Y" sentence in the conditional? |
| ------------------------------------------------------------------------------------------------------------- |
|  Si + [past-tense "if" clause], + conditional<br><br><!--ANKI_NOTE_ID:1786556610209--> |

| Translate: If I had more time, I would travel more. |
| ------------------------------------------------------------------------ |
|  Si tuviera más tiempo, viajaría más.<br><br><!--ANKI_NOTE_ID:1786556610213--> |

| Translate: He said he would arrive late. |
| ------------------------------------------------------------ |
|  Dijo que llegaría tarde.<br><br><!--ANKI_NOTE_ID:1786556610217--> |

| Fix the mistake: "Yo hablaría con ella" used to mean "If I were you, I'd talk to her." |
| ------------------------------------------------------------------------------------------------------- |
|  Yo que tú, hablaría con ella. (missing the "yo que tú" advice marker)<br><br><!--ANKI_NOTE_ID:1786556610221--> |

| Why shouldn't you say "¿podrías...?" to a stranger you should address formally? |
| ------------------------------------------------------------------------------------------------ |
|  "Podrías" is the informal (tú) form — too casual for someone you'd address as usted<br><br><!--ANKI_NOTE_ID:1786556610225--> |
