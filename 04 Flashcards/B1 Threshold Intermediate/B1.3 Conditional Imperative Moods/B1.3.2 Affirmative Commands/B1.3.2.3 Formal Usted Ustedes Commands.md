#anki/Spanish/B1-Threshold-Intermediate/B1-3-Conditional-Imperative-Moods/B1-3-2-Affirmative-Commands/B1-3-2-3-Formal-Usted-Ustedes-Commands

| What grammar pattern do formal usted/ustedes commands use? |
| ------------------------------------------------------------------------------- |
|  The present subjunctive form for usted or ustedes<br><br><!--ANKI_NOTE_ID:1786557276903--> |

| Give the usted command for "hablar." |
| ---------------------------------------------------------- |
|  hable<br><br><!--ANKI_NOTE_ID:1786557276907--> |

| Give the ustedes command for "comer." |
| ----------------------------------------------------------- |
|  coman<br><br><!--ANKI_NOTE_ID:1786557276911--> |

| How do you make a formal command negative? |
| ------------------------------------------------------------ |
|  Just add "no" in front — the verb form doesn't change<br><br><!--ANKI_NOTE_ID:1786557276915--> |

| Translate: Speak more slowly, please. (usted) |
| ------------------------------------------------------------------ |
|  Hable más despacio, por favor.<br><br><!--ANKI_NOTE_ID:1786557276918--> |

| Translate: Don't worry. (usted) |
| --------------------------------------------------- |
|  No se preocupe.<br><br><!--ANKI_NOTE_ID:1786557276920--> |

| Give the usted command for "ir." |
| ------------------------------------------------------ |
|  vaya<br><br><!--ANKI_NOTE_ID:1786557276923--> |

| Give the ustedes command for "ser." |
| --------------------------------------------------------- |
|  sean<br><br><!--ANKI_NOTE_ID:1786557276926--> |

| Fix the mistake: "Habla más despacio, señor." |
| -------------------------------------------------------------------- |
|  Hable más despacio, señor. (usted form needed with "señor")<br><br><!--ANKI_NOTE_ID:1786557276928--> |

| Is "ustedes" only used for formal groups in Latin American Spanish? |
| ------------------------------------------------------------------------------------------ |
|  No — in Latin America, "ustedes" is the only plural "you," formal or informal<br><br><!--ANKI_NOTE_ID:1786557276931--> |

| Give the ustedes command for "tener." |
| ----------------------------------------------------------- |
|  tengan<br><br><!--ANKI_NOTE_ID:1786557276933--> |

| Translate: Come early. (ustedes) |
| ---------------------------------------------------- |
|  Vengan temprano.<br><br><!--ANKI_NOTE_ID:1786557276936--> |

| Why do irregular verbs like "ir" and "ser" keep their irregular stems in formal commands? |
| ------------------------------------------------------------------------------------------------------------ |
|  Because formal commands ARE the present subjunctive — they inherit every subjunctive irregularity<br><br><!--ANKI_NOTE_ID:1786557276938--> |

| Translate: Write your name here. (usted) |
| ---------------------------------------------------------------- |
|  Escriba su nombre aquí.<br><br><!--ANKI_NOTE_ID:1786557276940--> |
