#anki/Spanish/B1-Threshold-Intermediate/B1-3-Conditional-Imperative-Moods/B1-3-2-Affirmative-Commands/B1-3-2-1-Informal-Affirmative-Tu-Commands

| What form is the regular affirmative tú command built from? |
| ---------------------------------------------------------------------------- |
|  The él/ella (3rd person singular) form of the present indicative<br><br><!--ANKI_NOTE_ID:1786556871402--> |

| Give the affirmative tú command for "hablar." |
| ------------------------------------------------------------------- |
|  habla<br><br><!--ANKI_NOTE_ID:1786556871406--> |

| Give the affirmative tú command for "comer." |
| ------------------------------------------------------------------ |
|  come<br><br><!--ANKI_NOTE_ID:1786556871410--> |

| Give the affirmative tú command for "escribir." |
| --------------------------------------------------------------------- |
|  escribe<br><br><!--ANKI_NOTE_ID:1786556871414--> |

| Does the imperative mood have a "yo" form? |
| ------------------------------------------------------------ |
|  No — you can't command yourself<br><br><!--ANKI_NOTE_ID:1786556871418--> |

| Fix the mistake: "Hablas más despacio" used as a command. |
| -------------------------------------------------------------------------------- |
|  Habla más despacio. (drop the -s; that's the present tense, not the command)<br><br><!--ANKI_NOTE_ID:1786556871422--> |

| Translate: Call your mom. (command) |
| --------------------------------------------------- |
|  Llama a tu mamá.<br><br><!--ANKI_NOTE_ID:1786556871425--> |

| Fix the mistake: "Llama tu mamá." |
| ------------------------------------------------------- |
|  Llama a tu mamá. (missing the personal "a")<br><br><!--ANKI_NOTE_ID:1786556871429--> |

| Translate: Eat your vegetables. (command) |
| ------------------------------------------------------------- |
|  Come tus verduras.<br><br><!--ANKI_NOTE_ID:1786556871432--> |

| Give the affirmative tú command for "cerrar." |
| ------------------------------------------------------------------- |
|  cierra<br><br><!--ANKI_NOTE_ID:1786556871435--> |

| Give the affirmative tú command for "seguir." |
| ------------------------------------------------------------------- |
|  sigue<br><br><!--ANKI_NOTE_ID:1786556871438--> |

| Can you use this affirmative command form for a negative command like "don't speak"? |
| ------------------------------------------------------------------------------------------------------- |
|  No — negative commands use a completely different form, covered separately<br><br><!--ANKI_NOTE_ID:1786556871442--> |

| Translate: Write your name here. (command) |
| -------------------------------------------------------------- |
|  Escribe tu nombre aquí.<br><br><!--ANKI_NOTE_ID:1786556871444--> |
