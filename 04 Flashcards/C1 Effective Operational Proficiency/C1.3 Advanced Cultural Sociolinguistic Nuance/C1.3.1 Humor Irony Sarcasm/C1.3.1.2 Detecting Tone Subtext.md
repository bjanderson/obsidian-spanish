#anki/Spanish/C1-Effective-Operational-Proficiency/C1-3-Advanced-Cultural-Sociolinguistic-Nuance/C1-3-1-Humor-Irony-Sarcasm/C1-3-1-2-Detecting-Tone-Subtext

| What is the main auditory cue that signals sarcasm in spoken Spanish, when the words themselves sound sincere? |
| ---------------------------------------------------------------------------------------------------- |
| A flat, monotone delivery — or the opposite, an obviously exaggerated, over-the-top enthusiasm — on a phrase that would normally carry warm or excited intonation. <br><br><!--ANKI_NOTE_ID:1786642510254--> |

| Translate, keeping the sarcastic tone in mind: "Oh, great..." (said flatly after hearing bad news). |
| ----------------------------------------------------------------------------------------- |
| Qué bueno... <br><br><!--ANKI_NOTE_ID:1786642510267--> |

| What does *obvio* mean when used sincerely, and what can it mean when said with a flat, mocking tone? |
| ------------------------------------------------------------------------------------------- |
| Sincerely: "obviously" (plain agreement). Sarcastically: implies the question or statement was dumb or unnecessary to ask/say. <br><br><!--ANKI_NOTE_ID:1786642510272--> |

| Fill in the blank with a sarcasm marker: —¿Tú crees que Marco va a llegar a tiempo? —_______, seguro. (implying doubt he'll show up on time) |
| -------------------------------------------------------------------------------------------------------------------------- |
| Ya <br><br><!--ANKI_NOTE_ID:1786642510276--> |

| Why is *claro que sí* considered a "sarcasm marker" rather than always meaning sincere agreement? |
| -------------------------------------------------------------------------------------------- |
| Its literal meaning is "of course" / enthusiastic agreement, but said with flat or ironic delivery it can signal doubt or resentment instead — tone, not the words, decides the meaning. <br><br><!--ANKI_NOTE_ID:1786642510281--> |

| What is "hedged criticism" (*crítica atenuada*), and give one example phrase. |
| ------------------------------------------------------------------------ |
| Softened, indirect disapproval phrased as mild or neutral wording instead of stating criticism directly — e.g. *no está mal* ("it's not bad") used to mean "I didn't really like it." <br><br><!--ANKI_NOTE_ID:1786642510285--> |

| Translate, capturing the softened/hedged meaning: "It could be better." (said about something the speaker actually disliked) |
| ------------------------------------------------------------------------------------------------------------- |
| Podría ser mejor. <br><br><!--ANKI_NOTE_ID:1786642510288--> |

| A friend says "no es exactamente lo que teníamos en mente" about your proposal. What is the real message behind this hedge? |
| ------------------------------------------------------------------------------------------------------------- |
| The proposal missed the mark / isn't good enough — the phrase softens a negative judgment instead of stating it bluntly. <br><br><!--ANKI_NOTE_ID:1786642510292--> |

| What does the interjection *ay sí* signal when used sarcastically? |
| -------------------------------------------------------------- |
| Sarcastic disbelief or dismissal — similar to English "oh sure" said with an eye-roll. <br><br><!--ANKI_NOTE_ID:1786642510295--> |

| Explain why *cómo no* can be either sincere or sarcastic — what decides which meaning applies? |
| -------------------------------------------------------------------------------------- |
| The words alone mean "of course" (genuine willingness); tone and context decide whether it's sincere agreement or mocking agreement. <br><br><!--ANKI_NOTE_ID:1786642510298--> |

| Translate, capturing the sarcastic reading: "You don't say." (implying the news wasn't surprising at all) |
| ---------------------------------------------------------------------------------------------- |
| No me digas. <br><br><!--ANKI_NOTE_ID:1786642510301--> |

| Why can *no me digas* NOT be translated the same way every time it appears? |
| ------------------------------------------------------------------------ |
| It can express genuine surprise in one context and dry, sarcastic "obviously" in another — the correct reading depends entirely on whether the news was actually unexpected. <br><br><!--ANKI_NOTE_ID:1786642510304--> |

| Fix the redundant subject pronoun: "¿Tú crees que él va a llegar a tiempo?" |
| -------------------------------------------------------------------- |
| ¿Crees que él va a llegar a tiempo? (drop *tú* — the *-es* verb ending already makes the subject clear; *él* stays because third person needs it to avoid ambiguity) <br><br><!--ANKI_NOTE_ID:1786642510307--> |

| What does the regional note in this lesson say about sarcastic intonation across Spanish-speaking countries? |
| -------------------------------------------------------------------------------------------------- |
| How strongly intonation carries sarcasm — and how common sarcasm is in everyday speech — varies by country; there's no single universal "sarcastic voice" across the Spanish-speaking world. <br><br><!--ANKI_NOTE_ID:1786642510309--> |

| —Perdí el vuelo y me cancelaron el hotel. —Qué bueno... Is this sincere or sarcastic, and why? |
| --------------------------------------------------------------------------------------- |
| Sarcastic — the situation described is bad news, so *qué bueno* ("how great") flatly delivered means the opposite of what it literally says. <br><br><!--ANKI_NOTE_ID:1786642510311--> |

| —¿Te gustó la película? —No está mal. What is the speaker really communicating? |
| ---------------------------------------------------------------------------- |
| Mild disapproval, softened. If they had genuinely liked it, they would likely have said so directly (e.g. *me encantó*); *no está mal* is a hedge, not real praise. <br><br><!--ANKI_NOTE_ID:1786642510314--> |

| What common mistake happens when a learner overuses sarcasm markers like *obvio* or *ya* in the wrong context? |
| ------------------------------------------------------------------------------------------------------- |
| Using them with a sarcastic edge in formal or unfamiliar-relationship settings can come across as rude — these markers work best with people the speaker already has an easy, informal rapport with. <br><br><!--ANKI_NOTE_ID:1786642510316--> |

| Translate, using a sarcastic interjection: "Sure, right." (expressing disbelief that something will actually happen) |
| ------------------------------------------------------------------------------------------------------- |
| Ya, seguro. <br><br><!--ANKI_NOTE_ID:1786642510318--> |
