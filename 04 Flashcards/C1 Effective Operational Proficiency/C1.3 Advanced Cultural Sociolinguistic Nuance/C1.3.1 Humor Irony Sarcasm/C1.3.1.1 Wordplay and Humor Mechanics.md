#anki/Spanish/C1-Effective-Operational-Proficiency/C1-3-Advanced-Cultural-Sociolinguistic-Nuance/C1-3-1-Humor-Irony-Sarcasm/C1-3-1-1-Wordplay-and-Humor-Mechanics

| What is the Spanish term for a wordplay collision between two different words or phrasings that happen to sound alike? |
| ------------------------------------------------------------------------------------------------------------------- |
| Doble sentido ("double meaning"). <br><br><!--ANKI_NOTE_ID:1786641819472--> |

| What is polisemia (polysemy) in the context of Spanish wordplay, and how is it different from doble sentido? |
| ------------------------------------------------------------------------------------------------------------ |
| One single word that already carries two or more established meanings (e.g., *esposas* = wives / handcuffs) — different from *doble sentido* because it's one word with layered senses, not two separate words that happen to sound alike. <br><br><!--ANKI_NOTE_ID:1786641819475--> |

| Fill in the blank: —¿Qué le dijo un pez a otro pez? —______. |
| -------------------------------------------------------------- |
| Nada <br><br><!--ANKI_NOTE_ID:1786641819493--> |

| Why is "—¿Qué le dijo un pez a otro pez? —Nada." funny? Explain the double meaning. |
| ------------------------------------------------------------------------------------ |
| *Nada* means both "nothing" and is the third-person singular of *nadar* ("he/she swims") — exactly what a fish does. <br><br><!--ANKI_NOTE_ID:1786641819497--> |

| What two meanings does *esposas* carry in Spanish? |
| --------------------------------------------------- |
| Wives and handcuffs. <br><br><!--ANKI_NOTE_ID:1786641819502--> |

| Translate and explain the joke: "—¿Por qué los presos no deberían casarse? —Porque ya tienen suficientes esposas." |
| -------------------------------------------------------------------------------------------------------------------- |
| "Why shouldn't prisoners get married? — Because they already have enough handcuffs/wives." Polysemy: *esposas* = wives / handcuffs — both meanings have to stay active for the joke to land. <br><br><!--ANKI_NOTE_ID:1786641819506--> |

| In "Al final no había vino en la mesa... hasta que vino Andrés con una botella," what two grammatical roles does *vino* play? |
| --------------------------------------------------------------------------------------------------------------------------------- |
| First the noun "wine," then the preterite verb form "he came" (from *venir*) — a homograph doing double duty. <br><br><!--ANKI_NOTE_ID:1786641819510--> |

| What does *fresco* mean in "—Mesero, ¿este pescado está fresco? —Tan fresco que si lo toca, seguro le contesta"? |
| ---------------------------------------------------------------------------------------------------------------- |
| Both "fresh" (referring to the fish) and "sassy/impudent" (a person who talks back) — the waiter answers both senses at once. <br><br><!--ANKI_NOTE_ID:1786641819514--> |

| Distinguish these three words by stress and meaning: *término*, *termino*, *terminó*. |
| ---------------------------------------------------------------------------------------- |
| *Término* = noun "term" (stress on the first syllable); *termino* = "I finish" (yo termino, present, stress on the second syllable); *terminó* = "it/he/she finished" (preterite, stress on the last syllable). <br><br><!--ANKI_NOTE_ID:1786641819519--> |

| What is a *chiste*'s *planteamiento*? |
| -------------------------------------- |
| The setup — the part of the joke that primes the listener toward one reading. <br><br><!--ANKI_NOTE_ID:1786641819523--> |

| What is a *chiste*'s *remate*? |
| ------------------------------- |
| The punchline — the part that resolves the setup a different way, usually by triggering a pun or double meaning. <br><br><!--ANKI_NOTE_ID:1786641819526--> |

| What is *albur*, and to which region of the Spanish-speaking world is it specific? |
| -------------------------------------------------------------------------------------- |
| A competitive, largely improvised verbal-dueling tradition built on rapid double entendres (often sexual innuendo). It is specific to Mexican Spanish and a particular social register — not a general Latin American practice. <br><br><!--ANKI_NOTE_ID:1786641819530--> |

| True or false: this lesson teaches you how to perform *albur* in conversation. |
| --------------------------------------------------------------------------------- |
| False — *albur* is presented as a cultural phenomenon to recognize, not a technique to attempt; it takes native-level fluency and depends heavily on context and register. <br><br><!--ANKI_NOTE_ID:1786641819533--> |

| Why does translating a Spanish pun word for word into English usually kill the joke? |
| ---------------------------------------------------------------------------------------- |
| Because the humor depends on a coincidence in Spanish sound or spelling that usually doesn't exist in English — you have to explain the double meaning instead of translating literally. <br><br><!--ANKI_NOTE_ID:1786641819535--> |

| Fill in the blanks (pay attention to the accent marks): "Ese es el ______ médico, pero yo ya ______, porque el dolor nunca ______." |
| ---------------------------------------------------------------------------------------------------------------------------------------- |
| término / termino / terminó <br><br><!--ANKI_NOTE_ID:1786641819538--> |

| How would you say "Did you catch the double meaning, or should I explain it?" in Spanish? |
| --------------------------------------------------------------------------------------------- |
| ¿Captaste el doble sentido o te lo explico? <br><br><!--ANKI_NOTE_ID:1786641819541--> |

| What Spanish phrase means "wordplay" in general — broader than *doble sentido*, which implies exactly two meanings? |
| ------------------------------------------------------------------------------------------------------------------- |
| Juego de palabras <br><br><!--ANKI_NOTE_ID:1786641819543--> |

| What does the collocation *sacar una sonrisa/risa* mean, and how is it used to talk about jokes? |
| ------------------------------------------------------------------------------------------------- |
| Literally "to pull out a smile/laugh" — used to describe a joke's effect, e.g., "siempre me saca una sonrisa" ("it always gets a smile out of me"). <br><br><!--ANKI_NOTE_ID:1786641819546--> |

| What is the common mistake in assuming *esposas* only means "wives," or *vino* only means "wine"? |
| ------------------------------------------------------------------------------------------------------ |
| Missing that the word is being used in its other established sense in context — the joke or sentence depends on the listener catching both meanings, not just the more familiar one. <br><br><!--ANKI_NOTE_ID:1786641819549--> |
