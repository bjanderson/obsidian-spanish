#anki/Spanish/C1-Effective-Operational-Proficiency/C1-3-Advanced-Cultural-Sociolinguistic-Nuance/C1-3-3-Auditory-Comprehension-Rapid-Accents/C1-3-3-1-Fast-Speech-Elision-Assimilation

| What is the difference between elision and assimilation, as fast-speech phenomena? |
| ---------------------------------------------------------------------------- |
| Elision drops a sound entirely (e.g. *cansado* → *cansao*). Assimilation changes a sound to match a neighboring sound instead of dropping it (e.g. *un beso* → *um beso*). <br><br><!--ANKI_NOTE_ID:1786721670890--> |

| What is "linking" (*sinalefa*), and give one example. |
| --------------------------------------------------- |
| Merging the end of one word into the start of the next, especially vowel-to-vowel, so they glide together as one syllable — e.g. *mi amigo* sounding almost like *miamigo*. <br><br><!--ANKI_NOTE_ID:1786721670894--> |

| What full word does the fast-speech form *cansao* represent, and what sound was dropped? |
| ------------------------------------------------------------------------------------ |
| *Cansado* — the *d* between two vowels weakens and disappears in fast speech. <br><br><!--ANKI_NOTE_ID:1786721670899--> |

| Translate to fast-speech (informal) spelling: "Es para mí." |
| ------------------------------------------------------- |
| Es pa' mí. <br><br><!--ANKI_NOTE_ID:1786721670904--> |

| Translate to fast-speech (informal) spelling: "No hay nada." |
| ---------------------------------------------------------- |
| No hay na'. <br><br><!--ANKI_NOTE_ID:1786721670909--> |

| Why does *un beso* often sound like *um beso* in fast speech, but *un abrazo* does not change the same way? |
| ------------------------------------------------------------------------------------------------------ |
| The *n* in *un* nasal-assimilates to *m* before *b*, *p*, or *v* — *beso* starts with *b*, so it triggers the shift. *Abrazo* starts with a vowel, which doesn't trigger nasal assimilation. <br><br><!--ANKI_NOTE_ID:1786721670913--> |

| What does *voy a comer* often sound like in fast, casual speech? |
| ---------------------------------------------------------- |
| Vua comer — *voy a* compresses heavily before an infinitive. <br><br><!--ANKI_NOTE_ID:1786721670916--> |

| Which regional accent group is most associated with weakening or dropping final *-s* (e.g. *los amigos* → *lo(h) amigo(h)*)? |
| -------------------------------------------------------------------------------------------------------------------- |
| Caribbean and coastal accents. This pattern is much rarer in highland/Andean Spanish, where final consonants tend to stay crisp. <br><br><!--ANKI_NOTE_ID:1786721670920--> |

| Fill in the blank with the standard (careful) form: —¿'Tá listo el café? —Sí, ya 'tá. This is a reduced form of which two words? |
| -------------------------------------------------------------------------------------------------------------------------- |
| Está (in both cases) <br><br><!--ANKI_NOTE_ID:1786721670923--> |

| Why shouldn't a learner treat every fast-speech reduction pattern as universal across all Spanish-speaking countries? |
| ----------------------------------------------------------------------------------------------------------------- |
| Some reductions, like final *-s* weakening, are strongly regional (common in Caribbean/coastal speech, rare in Andean speech) — assuming one region's pattern applies everywhere will trip up a listener elsewhere. <br><br><!--ANKI_NOTE_ID:1786721670926--> |

| What skill do native listeners rely on to understand fast speech, even when individual sounds are reduced or dropped? |
| ------------------------------------------------------------------------------------------------------------------ |
| Sentence stress, rhythm, and context — these carry more information than any single sound, filling in what a "weak" sound didn't fully convey. <br><br><!--ANKI_NOTE_ID:1786721670929--> |

| Why is it risky for a learner to start using reductions like *pa'* and *ta'* in their own speech before they're ready? |
| --------------------------------------------------------------------------------------------------------------- |
| Recognizing a reduction by ear is a listening skill; producing it too early, especially in formal settings, can sound unnatural or overly casual for the context. <br><br><!--ANKI_NOTE_ID:1786721670932--> |

| Translate to fast-speech (informal) spelling: "Mi amigo dice que va a llegar tarde." |
| ------------------------------------------------------------------------------- |
| Miamigo dice que va a llegar tarde. <br><br><!--ANKI_NOTE_ID:1786721670935--> |

| What does *de ella* often sound like in fast speech, and what phenomenon does this show? |
| -------------------------------------------------------------------------------------- |
| Della — vowel linking (*sinalefa*), where the *e* at the end of *de* merges with the *e* at the start of *ella*. <br><br><!--ANKI_NOTE_ID:1786721670939--> |

| A learner hears "Toy muy cansao, no he dormío na'." What is the careful, full-word version of this sentence? |
| ----------------------------------------------------------------------------------------------------- |
| Estoy muy cansado, no he dormido nada. <br><br><!--ANKI_NOTE_ID:1786721670944--> |
