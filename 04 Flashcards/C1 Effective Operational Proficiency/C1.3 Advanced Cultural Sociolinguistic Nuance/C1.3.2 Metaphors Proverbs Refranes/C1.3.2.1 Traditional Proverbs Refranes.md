#anki/Spanish/C1-Effective-Operational-Proficiency/C1-3-Advanced-Cultural-Sociolinguistic-Nuance/C1-3-2-Metaphors-Proverbs-Refranes/C1-3-2-1-Traditional-Proverbs-Refranes

| What is a *refrán*, and why can't a learner rely on its literal words to understand it? |
| ----------------------------------------------------------------------------------- |
| A short, fixed traditional saying that carries a piece of folk wisdom. Its literal words almost never match its intended meaning — you have to recognize the fixed phrase and jump straight to its figurative sense. <br><br><!--ANKI_NOTE_ID:1786721598261--> |

| Why can't you conjugate, rephrase, or swap synonyms into a refrán the way you would an ordinary sentence? |
| ------------------------------------------------------------------------------------------------- |
| A refrán's wording is fixed, almost like a quotation everyone already knows — changing the words breaks the recognizable shape and makes it sound like a mistake instead of a shared cultural reference. <br><br><!--ANKI_NOTE_ID:1786721598285--> |

| Translate: "A bird in the hand is worth two in the bush." (as the Spanish refrán) |
| ------------------------------------------------------------------------ |
| Más vale pajarito en mano que cien volando. <br><br><!--ANKI_NOTE_ID:1786721598289--> |

| What is the accepted regional variant of *más vale pajarito en mano que cien volando*, and what changes? |
| --------------------------------------------------------------------------------------------------- |
| Más vale pájaro en mano que cien volando — drops the diminutive *-ito*. Both forms are widely understood and used interchangeably. <br><br><!--ANKI_NOTE_ID:1786721598294--> |

| When would a native speaker say *más vale pajarito en mano que cien volando*? |
| -------------------------------------------------------------------------- |
| When someone is about to give up a modest sure thing while chasing a bigger, riskier prize — advising them to take the safe option instead. <br><br><!--ANKI_NOTE_ID:1786721598298--> |

| Translate, using the correct refrán: "You snooze, you lose." (in the sense of missing an opportunity by acting too slowly) |
| -------------------------------------------------------------------------------------------------------------- |
| Camarón que se duerme, se lo lleva la corriente. <br><br><!--ANKI_NOTE_ID:1786721598301--> |

| Literally, what does *camarón que se duerme, se lo lleva la corriente* say, and what does it mean figuratively? |
| ------------------------------------------------------------------------------------------------------- |
| Literally: "the shrimp that falls asleep gets carried away by the current." Figuratively: you snooze, you lose — said about someone who missed a chance by being too slow or passive. <br><br><!--ANKI_NOTE_ID:1786721598305--> |

| Fill in the blank with the correct refrán: —No llamé todavía por el apartamento. —¡Llama ya! _______________________. |
| -------------------------------------------------------------------------------------------------------------- |
| Camarón que se duerme, se lo lleva la corriente. <br><br><!--ANKI_NOTE_ID:1786721598308--> |

| Translate: "Don't look a gift horse in the mouth." |
| --------------------------------------------- |
| A caballo regalado no se le mira el diente. <br><br><!--ANKI_NOTE_ID:1786721598313--> |

| Why is *a caballo regalado no se le mira el diente* usually said as mild correction rather than neutral advice? |
| ------------------------------------------------------------------------------------------------------- |
| It's typically directed at someone who is criticizing or nitpicking something they received for free — it gently tells them not to. <br><br><!--ANKI_NOTE_ID:1786721598317--> |

| Translate: "Better late than never." |
| --------------------------------- |
| Más vale tarde que nunca. <br><br><!--ANKI_NOTE_ID:1786721598321--> |

| What situation calls for *el que mucho abarca poco aprieta*? |
| ---------------------------------------------------------- |
| Someone taking on too many projects or commitments at once and doing none of them well — close to "jack of all trades, master of none." <br><br><!--ANKI_NOTE_ID:1786721598325--> |

| Translate: "Every cloud has a silver lining." |
| ------------------------------------------ |
| No hay mal que por bien no venga. <br><br><!--ANKI_NOTE_ID:1786721598328--> |

| —Perdí el vuelo, pero así conocí a mi pareja actual. —¿Qué refrán responde mejor a esto? |
| ---------------------------------------------------------------------------------- |
| No hay mal que por bien no venga. (Points out the hidden upside in the bad situation.) <br><br><!--ANKI_NOTE_ID:1786721598332--> |

| Translate, capturing the encouraging tone: "Chin up — we'll do it inside." (about a rained-out outdoor plan) |
| ---------------------------------------------------------------------------------------------------- |
| Al mal tiempo, buena cara: lo hacemos adentro. <br><br><!--ANKI_NOTE_ID:1786721598335--> |

| What is the difference in use between *no hay mal que por bien no venga* and *al mal tiempo, buena cara*? |
| ------------------------------------------------------------------------------------------------- |
| *No hay mal que por bien no venga* is usually said after a good outcome is already visible; *al mal tiempo, buena cara* is said as active encouragement while still in the middle of a hard situation. <br><br><!--ANKI_NOTE_ID:1786721598339--> |

| Translate: "Easier said than done." |
| ---------------------------------- |
| Del dicho al hecho hay mucho trecho. <br><br><!--ANKI_NOTE_ID:1786721598342--> |

| What does *en boca cerrada no entran moscas* advise, and in what kind of moment would someone say it? |
| ----------------------------------------------------------------------------------------------- |
| "Silence is golden" / better to keep your mouth shut — said as advice or gentle approval when someone is about to say (or wisely didn't say) something better left unsaid. <br><br><!--ANKI_NOTE_ID:1786721598345--> |

| What does *cría fama y échate a dormir* mean, and does it only apply to bad reputations? |
| ------------------------------------------------------------------------------------ |
| "Build a reputation and it sticks" — once a reputation is established, it's hard to shake off, whether that reputation is good or bad. <br><br><!--ANKI_NOTE_ID:1786721598348--> |

| Fix the mistake: a learner says *más vale un pájaro en la mano que ciento volando*, adding extra articles to the standard refrán. Why is this wrong even though the meaning is clear? |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Refranes are fixed phrases — adding extra articles breaks the recognizable shape. The correct standard form is *más vale pajarito en mano que cien volando* (or the *pájaro* variant), without inserted articles. <br><br><!--ANKI_NOTE_ID:1786721598350--> |
