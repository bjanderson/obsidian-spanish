| How do you say "clearly/plainly" as a stance-marking phrase, used to frame an opinion as self-evident? |
| -------------------------------------------------------------------------------------------------------- |
| a todas luces<br><br><!--ANKI_NOTE_ID:1786639161720--> |

| Translate: It's worth asking whether the plan will actually work. |
| --------------------------------------------------------------------- |
| Cabe cuestionar si el plan realmente funcionará.<br><br><!--ANKI_NOTE_ID:1786639161723--> |

| What does "no es casualidad que" signal, and what mood does the following verb take? |
| ------------------------------------------------------------------------------------------ |
| It signals the writer believes an event has a hidden or deliberate cause ("it's no coincidence that..."); the following verb is subjunctive.<br><br><!--ANKI_NOTE_ID:1786639161726--> |

| Translate: It's striking that nobody mentioned the real cost. |
| ------------------------------------------------------------------- |
| Resulta llamativo que nadie mencionara el costo real.<br><br><!--ANKI_NOTE_ID:1786639161728--> |

| Fill in the blank with the correct mood: No deja de sorprender que nadie ______ (responder) a la prensa. |
| ---------------------------------------------------------------------------------------------------------- |
| responda (subjunctive — triggered by the stance-marking expression "no deja de sorprender que")<br><br><!--ANKI_NOTE_ID:1786639161730--> |

| What does "con el pretexto de" mean, and what does it imply about the stated reason? |
| -------------------------------------------------------------------------------------- |
| "Under the pretext of" — it implies the stated reason is false or self-serving.<br><br><!--ANKI_NOTE_ID:1786639161732--> |

| What is "la ironía" in the context of editorial writing? |
| ------------------------------------------------------------ |
| Saying the opposite of what's meant, or describing something in terms that clash with the facts, to make a critical point.<br><br><!--ANKI_NOTE_ID:1786639161734--> |

| Why might a writer put a word like "impecable" in quotation marks when describing a failed policy? |
| ---------------------------------------------------------------------------------------------------- |
| To signal irony — the quotation marks show the writer means the opposite of the word, sarcastically praising something they consider a failure.<br><br><!--ANKI_NOTE_ID:1786639161737--> |

| What is "la litotes" (understatement) doing when a writer calls a disastrous decision "no fue la decisión más acertada"? |
| ---------------------------------------------------------------------------------------------------------------------------- |
| Deliberately downplaying the severity, which by contrast makes the real weight of the failure more obvious to the reader.<br><br><!--ANKI_NOTE_ID:1786639161739--> |

| Translate: They lost several seats after the final vote count, calling it a "necessary" reform. |
| ------------------------------------------------------------------------------------------------- |
| Perdieron varios escaños tras el escrutinio final, llamándolo una reforma "necesaria".<br><br>(Note: <em>adjetivo cargado</em> in quotes signals the writer doesn't endorse the label.)<br><br><!--ANKI_NOTE_ID:1786639161741--> |

| What is a "pregunta retórica" (rhetorical question) used for in political or sports commentary? |
| ------------------------------------------------------------------------------------------------- |
| To lead the reader toward a conclusion without stating it directly — the writer isn't expecting a real answer.<br><br><!--ANKI_NOTE_ID:1786639161743--> |

| Why is "¿Hasta cuándo seguiremos tolerando esta impunidad?" not a genuine question? |
| ------------------------------------------------------------------------------------ |
| It's a rhetorical question — the writer is making an argument (that the impunity has gone on too long), not asking for information.<br><br><!--ANKI_NOTE_ID:1786639161745--> |

| What two phrases mark neutral reporting by attributing a claim to a source instead of stating it as fact? |
| ---------------------------------------------------------------------------------------------------------- |
| según fuentes (according to sources) and se informó que (it was reported that)<br><br><!--ANKI_NOTE_ID:1786639161747--> |

| Translate: According to the official statement, the meeting ran longer than expected. |
| ------------------------------------------------------------------------------------------ |
| Según el comunicado oficial, la reunión se prolongó más de lo previsto.<br><br><!--ANKI_NOTE_ID:1786639161750--> |

| Why is "El Congreso aprueba, sin debate, una reforma fiscal que golpeará a los más pobres" editorializing rather than neutral reporting? |
| -------------------------------------------------------------------------------------------------------------------------------------------- |
| It states a judgment ("golpeará a los más pobres") as fact instead of attributing it to a source, unlike a neutral headline that would just name the event.<br><br><!--ANKI_NOTE_ID:1786639161752--> |

| Common mistake: why is it wrong to read "resulta llamativo que ningún funcionario haya respondido" as neutral description? |
| -------------------------------------------------------------------------------------------------------------------------------- |
| "Resulta llamativo que" is a stance-marking phrase — the writer is editorializing (implying suspicion), not just describing a fact.<br><br><!--ANKI_NOTE_ID:1786639161754--> |

| Common mistake: why shouldn't you look for an answer to a rhetorical question in the rest of the article? |
| -------------------------------------------------------------------------------------------------------------- |
| Because the writer isn't asking for information — the question itself is the argument, so treating it as literal misses the point.<br><br><!--ANKI_NOTE_ID:1786639161756--> |

| Translate, keeping the personal a: The judge questioned the minister before handing down the ruling. |
| ----------------------------------------------------------------------------------------------------- |
| La jueza cuestionó al ministro antes de dictar el fallo.<br><br>(Personal <em>a</em> on <em>al ministro</em> — a specific person as direct object.)<br><br><!--ANKI_NOTE_ID:1786639161758--> |
