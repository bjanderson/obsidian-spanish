| Why is "Estimado doctora Núñez" wrong? |
| --------------------------------------- |
| "Estimado" is masculine but "doctora" and the recipient are feminine — it should agree: "Estimada doctora Núñez".<br><br><!--ANKI_NOTE_ID:1786636358997--> |

| What does "sin otro particular" signal in a formal letter? |
| ------------------------------------------------------------ |
| That the writer has nothing further to add and is closing the letter — typically placed right before the sign-off.<br><br><!--ANKI_NOTE_ID:1786636359023--> |

| Translate: "Thank you in advance for your attention." |

| Why is "Estimado señor Ruiz," (with a comma) wrong in formal Spanish? |
| ------------------------------------------------------------------- |
| Formal Spanish letters/emails use a colon after the recipient's name — "Estimado señor Ruiz:" — not a comma like English does.<br><br><!--ANKI_NOTE_ID:1786636359035--> |

| Fill in the blank: "Deseo contactar _________ director del departamento." (personal a + al) |
| ------------------------------------------------------------------------------------------- |
| al<br><br><!--ANKI_NOTE_ID:1786636359039-->                                                                                             |

| Why is "Deseo contactar el director" wrong? |
| --------------------------------------------- |
| It's missing the personal "a" before a specific person as a direct object, and needs to contract with "el": "Deseo contactar al director".<br><br><!--ANKI_NOTE_ID:1786636359043--> |

| Translate: "I would appreciate it if you could confirm receipt of this email." |
| -------------------------------------------------------------------------------- |
| Le agradecería que me confirmara la recepción de este correo.<br><br><!--ANKI_NOTE_ID:1786636359048-->                    |

| What is wrong with opening a letter "Distinguido señor" and closing it "Un saludo"? |
| --------------------------------------------------------------------------------- |
| The opening and closing don't match in formality — "Distinguido" is very high-formal but "Un saludo" is casual. The whole letter should hold one consistent register.<br><br><!--ANKI_NOTE_ID:1786636359052--> |

| Why does "estimado/a" get called a formula rather than ordinary grammar? |
| --------------------------------------------------------------------------- |
| It's a fixed phrase learners memorize as a whole chunk to open formal letters/emails, not something built freshly from grammar rules each time.<br><br><!--ANKI_NOTE_ID:1786636359070--> |
