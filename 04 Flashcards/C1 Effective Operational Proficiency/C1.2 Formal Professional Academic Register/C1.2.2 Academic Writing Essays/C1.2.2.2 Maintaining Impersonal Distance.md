| Translate: "It is believed that the climate is changing faster than expected." |
| -------------------------------------------------------------------------------- |
| Se cree que el clima está cambiando más rápido de lo previsto.<br><br><!--ANKI_NOTE_ID:1786637967773--> |

| Fill in the blank (impersonal se): "_________ (estimar) que el proyecto costará dos millones de dólares." |
| -------------------------------------------------------------------------------------------------------- |
| Se estima<br><br><!--ANKI_NOTE_ID:1786637967784--> |

| Why does impersonal se always take the third-person singular, even before a plural-sounding idea like "se necesita más información"? |
| ------------------------------------------------------------------------------------------------------------------------------------ |
| Impersonal se has no noun for the verb to agree with — there's no direct object driving agreement, so the verb always stays singular, regardless of what follows.<br><br><!--ANKI_NOTE_ID:1786637967787--> |

| Translate: "The results were published last week." (passive se) |
| ------------------------------------------------------------------ |
| Los resultados se publicaron la semana pasada.<br><br><!--ANKI_NOTE_ID:1786637967790--> |

| Fill in the blank (passive se): "La nueva ley _________ (aprobar) la semana pasada." |
| ---------------------------------------------------------------------------------- |
| se aprobó<br><br><!--ANKI_NOTE_ID:1786637967792--> |

| Why is "se publicaron los resultados" plural but "se vive bien aquí" singular? |
| --------------------------------------------------------------------------------- |
| "Resultados" is the grammatical subject of a passive se construction, so the verb agrees with it (plural). "Se vive bien aquí" is impersonal se with no subject noun, so it stays singular regardless.<br><br><!--ANKI_NOTE_ID:1786637967795--> |

| Translate: "The law was approved by Congress in March." (name the agent) |
| ---------------------------------------------------------------------------- |
| La ley fue aprobada por el Congreso en marzo.<br><br><!--ANKI_NOTE_ID:1786637967797--> |

| Fill in the blank: "Los resultados _________ (confirmar, ser-passive) por un segundo estudio." |
| ------------------------------------------------------------------------------------------------ |
| fueron confirmados<br><br><!--ANKI_NOTE_ID:1786637967800--> |

| Why is "la ley fue aprobada" correct but "la ley fue aprobado" wrong? |
| -------------------------------------------------------------------------- |
| In the ser-passive, the past participle functions like an adjective and must agree in gender and number with the subject — "ley" is feminine singular, so it's "aprobada," not "aprobado."<br><br><!--ANKI_NOTE_ID:1786637967802--> |

| When should you prefer ser + past participle over passive se? |
| -------------------------------------------------------------------- |
| When the agent performing the action needs to be named explicitly (with "por"), which is common in formal written/report register — passive se doesn't name an agent.<br><br><!--ANKI_NOTE_ID:1786637967805--> |

| Rewrite to remove the first-person opener: "Yo creo que los datos son insuficientes." |
| ------------------------------------------------------------------------------------------ |
| Se puede argumentar que los datos son insuficientes. (or: Cabe señalar que los datos son insuficientes.)<br><br><!--ANKI_NOTE_ID:1786637967807--> |

| Translate: "It's worth noting that fifteen percent of participants dropped out." |
| ------------------------------------------------------------------------------------ |
| Cabe señalar que el quince por ciento de los participantes abandonó el estudio.<br><br><!--ANKI_NOTE_ID:1786637967809--> |

| What impersonal phrase can replace "en mi opinión" in an objective report? |
| --------------------------------------------------------------------------------- |
| "Desde una perspectiva objetiva," "según los datos disponibles," or "de acuerdo con el estudio."<br><br><!--ANKI_NOTE_ID:1786637967812--> |

| Why is "un aumento enorme" weaker in objective writing than "un aumento del quince por ciento"? |
| ------------------------------------------------------------------------------------------------ |
| "Enorme" is a subjective, emotionally loaded adjective with no measurable basis; a specific number grounds the claim in evidence instead of the writer's impression.<br><br><!--ANKI_NOTE_ID:1786637967814--> |

| Fix the register error: "El informe concluye que la política tuvo un efecto decepcionante." |
| ------------------------------------------------------------------------------------------------ |
| El informe concluye que la política tuvo un efecto limitado. ("Decepcionante" is subjective/emotional; "limitado" is neutral and evidence-based.)<br><br><!--ANKI_NOTE_ID:1786637967816--> |

| Why is "los boletos son vendidos en la entrada" less natural than "los boletos se venden en la entrada"? |
| ------------------------------------------------------------------------------------------------------------- |
| Spanish uses the se passive far more often than the ser-passive in everyday and general statements; the ser-passive here reads as an over-literal translation from English passive voice.<br><br><!--ANKI_NOTE_ID:1786637967818--> |

| Translate: "It was decided that the meeting would be postponed." (use se, not ser + past participle) |
| ------------------------------------------------------------------------------------------------------- |
| Se decidió que la reunión se pospondría.<br><br><!--ANKI_NOTE_ID:1786637967820--> |
