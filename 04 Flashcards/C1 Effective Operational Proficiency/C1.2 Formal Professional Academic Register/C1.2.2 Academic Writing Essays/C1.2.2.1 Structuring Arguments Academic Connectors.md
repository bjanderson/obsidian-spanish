| Why is "a tenor de mí" not idiomatic for stating a personal opinion? |
| ------------------------------------------------------------------------- |
| "A tenor de" introduces a formal basis like data, a study, or a legal text — not a personal viewpoint; use "en mi opinión" or "a mi parecer" instead.<br><br><!--ANKI_NOTE_ID:1786637441479--> |

| Why does "de ahí que" take the subjunctive ("sea", not "es")? |
| ------------------------------------------------------------------ |
| "De ahí que" is a fixed connector that always triggers the subjunctive in the clause that follows, regardless of how certain the fact is.<br><br><!--ANKI_NOTE_ID:1786637441483--> |

| Why is "no obstante" a better fit than "sin embargo" for a formal academic essay, even though both mean "however"? |
| -------------------------------------------------------------------------------------------------------------------- |
| Both are correct, but "no obstante" reads as more formal/literary; "sin embargo" is the safe everyday-formal default and works in almost any written register.<br><br><!--ANKI_NOTE_ID:1786637441497--> |

| Fill in the blank: "_________, ningún sistema educativo puede tener éxito sin la participación de las familias." (In the final analysis) |
| --------------------------------------------------------------------------------------------------------------------------------------- |
| En última instancia<br><br><!--ANKI_NOTE_ID:1786637441501--> |

| What's the difference in strength between "en definitiva" and "en última instancia" when concluding an argument? |
| --------------------------------------------------------------------------------------------------------------------- |
| Both mean roughly "ultimately," but "en última instancia" is slightly stronger and is typically reserved for the writer's final or strongest claim.<br><br><!--ANKI_NOTE_ID:1786637441503--> |

| Why is it a mistake to use "en suma" in the middle of a paragraph that still has more points to come? |
| ------------------------------------------------------------------------------------------------------------- |
| "En suma" signals to the reader that the argument is wrapping up, so using it mid-argument confuses the essay's structure even if the sentence itself is grammatical.<br><br><!--ANKI_NOTE_ID:1786637441505--> |

| Why is "entonces" generally a poor choice in a formal academic essay, compared to "por lo tanto"? |
| ------------------------------------------------------------------------------------------------- |
| "Entonces" is a spoken-register connector that sounds underdeveloped in formal writing; "por lo tanto" (or "por consiguiente") is the appropriate written-register equivalent for "therefore."<br><br><!--ANKI_NOTE_ID:1786637441506--> |
