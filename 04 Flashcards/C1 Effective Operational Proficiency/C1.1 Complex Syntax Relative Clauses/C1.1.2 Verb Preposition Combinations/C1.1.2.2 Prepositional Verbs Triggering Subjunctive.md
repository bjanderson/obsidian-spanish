| What determines whether *antes de/para/sin* takes the infinitive or *que* + subjunctive? |
| ------------------------------------------------------------------------------------------- |
| Whether the subject stays the same across both actions (infinitive) or changes (que + subjunctive).<br><br><!--ANKI_NOTE_ID:1786621262145--> |

| Fill in the blank: Antes de ______ (salir), apagué las luces. (same subject) |
| ---------------------------------------------------------------------------------- |
| salir<br><br><!--ANKI_NOTE_ID:1786621262148--> |

| Fill in the blank: Antes de que ______ (salir) tú, dime el plan. (different subject) |
| -------------------------------------------------------------------------------------------- |
| salgas<br><br><!--ANKI_NOTE_ID:1786621262151--> |

| Translate: I bought flowers to decorate the house. (same subject) |
| ------------------------------------------------------------------------ |
| Compré flores para decorar la casa.<br><br><!--ANKI_NOTE_ID:1786621262153--> |

| Translate: I bought flowers for you to decorate the house. (different subjects) |
| ---------------------------------------------------------------------------------- |
| Compré flores para que decoraras la casa.<br><br><!--ANKI_NOTE_ID:1786621262155--> |

| Why does "para que" trigger the subjunctive? |
| ---------------------------------------------------- |
| Because the subject changes between the two clauses — the subjunctive marks that the second action is outside the speaker's own direct experience.<br><br><!--ANKI_NOTE_ID:1786621262157--> |

| Fill in the blank: Ella se fue sin ______ (despedirse). (same subject) |
| ------------------------------------------------------------------------------- |
| despedirse<br><br><!--ANKI_NOTE_ID:1786621262159--> |

| Fill in the blank: Ella se fue sin que nadie se ______ (dar) cuenta. (different subject) |
| -------------------------------------------------------------------------------------------- |
| diera<br><br><!--ANKI_NOTE_ID:1786621262161--> |

| What tense of the subjunctive follows a past-tense main clause? |
| ------------------------------------------------------------------ |
| The imperfect subjunctive — e.g. *Apagué la luz para que los niños durmieran.*<br><br><!--ANKI_NOTE_ID:1786621262163--> |

| Translate: I turned off the light so the children could sleep. |
| ----------------------------------------------------------------- |
| Apagué la luz para que los niños durmieran.<br><br><!--ANKI_NOTE_ID:1786621262165--> |

| Why is "Compré flores para decores la casa" wrong? |
| ---------------------------------------------------------- |
| The subject changed (I bought, you decorate), so it needs *para que* + subjunctive: *para que decores la casa.*<br><br><!--ANKI_NOTE_ID:1786621262167--> |

| What does *al + infinitive* mean, and why doesn't it have a subjunctive counterpart? |
| ------------------------------------------------------------------------------------------ |
| "Upon doing something" — it always keeps the same subject, so there's no different-subject case that would trigger subjunctive.<br><br><!--ANKI_NOTE_ID:1786621262169--> |

| Translate: Upon arriving home, I went to bed. |
| ------------------------------------------------------ |
| Al llegar a casa, me acosté.<br><br><!--ANKI_NOTE_ID:1786621262171--> |

| Fill in the blank: Trabajó todo el fin de semana con tal de ______ (terminar) el proyecto. (same subject) |
| ----------------------------------------------------------------------------------------------------------------- |
| terminar<br><br><!--ANKI_NOTE_ID:1786621262173--> |

| Why is "Antes de que yo salga, compro pan" considered wrong/overly formal here? |
| --------------------------------------------------------------------------------------- |
| The subject doesn't change (both actions are "yo"), so it should just be *antes de salir* + infinitive, not *antes de que* + subjunctive.<br><br><!--ANKI_NOTE_ID:1786621262175--> |

| Fill in the blank: Guardé un pedazo de pastel para que lo ______ (probar) tú. |
| -------------------------------------------------------------------------------------- |
| probaras<br><br><!--ANKI_NOTE_ID:1786621262178--> |
