| What preposition follows *depender*? |
| ------------------------------------------ |
| de — e.g. *depende de ti*, never *depende en*.<br><br><!--ANKI_NOTE_ID:1786621032589--> |

| Why is "depender en" incorrect? |
| -------------------------------------- |
| Spanish always pairs *depender* with *de*, unlike English "depend on" — the preposition doesn't transfer literally between the two languages.<br><br><!--ANKI_NOTE_ID:1786621032593--> |

| Translate: We can always count on our neighbors. |
| ---------------------------------------------------- |
| Siempre podemos contar con nuestros vecinos.<br><br><!--ANKI_NOTE_ID:1786621032597--> |

| Fill in the blank: Mi hermana se enamoró ______ un compañero de trabajo. |
| ---------------------------------------------------------------------------- |
| de<br><br><!--ANKI_NOTE_ID:1786621032602--> |

| What form of the verb must follow the preposition in these fixed verb + preposition pairs — infinitive or gerund? |
| --------------------------------------------------------------------------------------------------------------------- |
| The infinitive — e.g. *sueño con viajar*, never *sueño con viajando*.<br><br><!--ANKI_NOTE_ID:1786621032607--> |

| Fill in the blank: Los vecinos se quejan ______ ruido todas las noches. (use the contraction) |
| ---------------------------------------------------------------------------------------------------- |
| del<br><br><!--ANKI_NOTE_ID:1786621032611--> |

| Why does "se quejan de el ruido" need to change? |
| -------------------------------------------------------- |
| *De* + *el* must contract to *del*: *se quejan del ruido*.<br><br><!--ANKI_NOTE_ID:1786621032615--> |

| Translate: I got tired of waiting and decided to leave. |
| ---------------------------------------------------------- |
| Me cansé de esperar y decidí irme.<br><br><!--ANKI_NOTE_ID:1786621032619--> |

| What is the difference between *pensar en* and *pensar de*? |
| -------------------------------------------------------------- |
| *Pensar en* = to think about something/someone. *Pensar de* = to give an opinion about something (usually in a question like *¿qué piensas de...?*).<br><br><!--ANKI_NOTE_ID:1786621032623--> |
