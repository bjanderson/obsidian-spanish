| What does an absolute participle clause do, in plain terms? |
| ------------------------------------------------------------------ |
| It compactly says "once X happened" by placing a past participle before a noun, with no conjugated verb needed.<br><br><!--ANKI_NOTE_ID:1786621577695--> |

| Fill in the blank: ______ (Terminar) la reunión, nos fuimos a casa. |
| ---------------------------------------------------------------------------- |
| Terminada<br><br><!--ANKI_NOTE_ID:1786621577706--> |

| Why is it "Terminada la reunión" and not "Terminado la reunión"? |
| ------------------------------------------------------------------------ |
| The participle must agree in gender and number with the noun that follows it — *la reunión* is feminine, so it's *terminada*.<br><br><!--ANKI_NOTE_ID:1786621577720--> |

| Translate: Once the contract was signed, we started working. |
| --------------------------------------------------------------------- |
| Firmado el contrato, empezamos a trabajar.<br><br><!--ANKI_NOTE_ID:1786621577723--> |

| Fill in the blank: ______ (Resolver) los problemas técnicos, la reunión pudo continuar. |
| ---------------------------------------------------------------------------------------------- |
| Resueltos<br><br><!--ANKI_NOTE_ID:1786621577726--> |

| Does the participle in an absolute participle clause ever stay unchanged like it does in a compound tense (e.g. "he terminado")? |
| ---------------------------------------------------------------------------------------------------------------------------------------- |
| No — in a compound tense the participle never changes, but in an absolute clause it agrees with the following noun because it's acting like an adjective.<br><br><!--ANKI_NOTE_ID:1786621577728--> |

| Translate: Once the doors were closed, the guard turned off the lights. |
| ---------------------------------------------------------------------------- |
| Cerradas las puertas, el guardia apagó las luces.<br><br><!--ANKI_NOTE_ID:1786621577731--> |

| What normal, everyday alternative could replace "Terminada la reunión, nos fuimos"? |
| -------------------------------------------------------------------------------------------- |
| Cuando terminó la reunión, nos fuimos. (a full clause with a conjugated verb)<br><br><!--ANKI_NOTE_ID:1786621577733--> |

| Fill in the blank: ______ (Publicar) los resultados, los estudiantes revisaron sus notas. |
| ------------------------------------------------------------------------------------------------- |
| Publicados<br><br><!--ANKI_NOTE_ID:1786621577736--> |

| Why is "La reunión terminada, nos fuimos" not the standard word order? |
| --------------------------------------------------------------------------- |
| The participle goes first, before the noun — the standard order is *Terminada la reunión...*, not noun then participle.<br><br><!--ANKI_NOTE_ID:1786621577738--> |

| Translate: Once the technical problems were resolved, the meeting could continue. |
| ---------------------------------------------------------------------------------------- |
| Resueltos los problemas técnicos, la reunión pudo continuar.<br><br><!--ANKI_NOTE_ID:1786621577740--> |

| What is the irregular past participle of *decir*, used in the common phrase "that said"? |
| -------------------------------------------------------------------------------------------------- |
| dicho — e.g. *Dicho esto, procedamos con la votación.*<br><br><!--ANKI_NOTE_ID:1786621577743--> |

| Is this construction more common in casual speech or in formal writing/narration? |
| -------------------------------------------------------------------------------------------- |
| Formal writing and narration — casual speech usually prefers *cuando* + a conjugated verb.<br><br><!--ANKI_NOTE_ID:1786621577745--> |

| Fill in the blank: ______ (Cerrar) la tienda, el dueño se fue a casa. |
| -------------------------------------------------------------------------- |
| Cerrada<br><br><!--ANKI_NOTE_ID:1786621577747--> |

| Translate: Once the homework was done, the kids went out to play. |
| -------------------------------------------------------------------------- |
| Hecha la tarea, los niños salieron a jugar.<br><br><!--ANKI_NOTE_ID:1786621577753--> |

| Fill in the blank: ______ (Aprobar) el presupuesto, el equipo pudo empezar a comprar equipo. |
| ------------------------------------------------------------------------------------------------- |
| Aprobado<br><br><!--ANKI_NOTE_ID:1786621577755--> |
