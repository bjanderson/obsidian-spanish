| What does a simple gerund clause typically express about the main action? |
| -------------------------------------------------------------------------------- |
| The manner, cause, or a simultaneous circumstance — "by/while doing X."<br><br><!--ANKI_NOTE_ID:1786634374523--> |

| Fill in the blank: ______ (Trabajar) duro, logró su meta. |
| ------------------------------------------------------------------ |
| Trabajando<br><br><!--ANKI_NOTE_ID:1786634374540--> |

| What does the compound gerund *habiendo + participle* express, compared to a simple gerund? |
| ------------------------------------------------------------------------------------------------- |
| An action completed *before* the main clause's action — "having done X" — instead of a simultaneous action.<br><br><!--ANKI_NOTE_ID:1786634374544--> |

| Fill in the blank: ______ (Terminar) el informe, se fue a casa. (compound gerund) |
| ------------------------------------------------------------------------------------------ |
| Habiendo terminado<br><br><!--ANKI_NOTE_ID:1786634374548--> |

| Translate: Having considered all the factors, we decided to accept the offer. |
| -------------------------------------------------------------------------------------- |
| Habiendo considerado todos los factores, decidimos aceptar la oferta.<br><br><!--ANKI_NOTE_ID:1786634374552--> |

| Why is "habiendo terminada" wrong? |
| ----------------------------------------- |
| The participle inside *habiendo + participle* never changes form — it's part of a verb form, not acting as an adjective, so it's always *habiendo terminado*.<br><br><!--ANKI_NOTE_ID:1786634374555--> |

| Translate: Knowing it would rain, we brought umbrellas. |
| ------------------------------------------------------------------ |
| Sabiendo que llovería, llevamos paraguas.<br><br><!--ANKI_NOTE_ID:1786634374560--> |

| Fill in the blank: ______ (Leer) el contrato completo, firmé sin dudar. (compound gerund) |
| ------------------------------------------------------------------------------------------------- |
| Habiendo leído<br><br><!--ANKI_NOTE_ID:1786634374564--> |

| What condition must be true for a gerund clause to work — about the subjects of the two clauses? |
| ---------------------------------------------------------------------------------------------------------- |
| The gerund clause's implied subject must match the main clause's subject; if they differ, use a full clause with *como*, *ya que*, or *después de que* instead.<br><br><!--ANKI_NOTE_ID:1786634374568--> |

| Translate: Having resolved the conflict, the team could focus on the work. |
| ------------------------------------------------------------------------------------ |
| Habiendo resuelto el conflicto, el equipo pudo enfocarse en el trabajo.<br><br><!--ANKI_NOTE_ID:1786634374572--> |

| Is the adverbial gerund clause more common in formal writing or casual conversation? |
| ----------------------------------------------------------------------------------------------- |
| Formal writing and narration — essays, reports, news. Casual speech usually prefers *cuando*, *porque*, or *como* + a conjugated verb.<br><br><!--ANKI_NOTE_ID:1786634374575--> |

| Fill in the blank: ______ (Vivir) tan lejos, casi nunca los vemos. |
| -------------------------------------------------------------------------- |
| Viviendo<br><br><!--ANKI_NOTE_ID:1786634374578--> |

| What is the key difference between *hablando* and *habiendo hablado*? |
| ------------------------------------------------------------------------------ |
| *Hablando* is a simple gerund (simultaneous action); *habiendo hablado* is a compound gerund (a prior completed action).<br><br><!--ANKI_NOTE_ID:1786634374581--> |

| Translate: By working together, they finished the project ahead of schedule. |
| --------------------------------------------------------------------------------------- |
| Trabajando juntos, terminaron el proyecto antes de tiempo.<br><br><!--ANKI_NOTE_ID:1786634374584--> |

| Fill in the blank: ______ (Resolver) el conflicto, el equipo pudo enfocarse en el trabajo. (compound gerund) |
| ------------------------------------------------------------------------------------------------------------------- |
| Habiendo resuelto<br><br><!--ANKI_NOTE_ID:1786634374589--> |
