#anki/Spanish/C1-Effective-Operational-Proficiency/C1-1-Complex-Syntax-Relative-Clauses/C1-1-1-Advanced-Relative-Pronouns/C1-1-1-1-Restrictive-vs-Non-Restrictive-Relative-Clauses

| What is the difference between a restrictive and a non-restrictive relative clause? |
| ------------------------------------------------------------------------------------ |
| A restrictive clause narrows down which noun you mean (essential, no commas). A non-restrictive clause adds extra info about a noun already identified (removable, set off by commas).<br><br><!--ANKI_NOTE_ID:1786620499195--> |

| Which relative pronoun is the default choice in a restrictive clause with no preposition? |
| -------------------------------------------------------------------------------------------- |
| *Que* — e.g. *el libro que leí*.<br><br><!--ANKI_NOTE_ID:1786620499198--> |

| Translate: The report, which we reviewed yesterday, has several errors. |
| -------------------------------------------------------------------------- |
| El informe, el cual revisamos ayer, tiene varios errores.<br><br><!--ANKI_NOTE_ID:1786620499200--> |

| Fill in the blank: La empresa contrató a la asistente del director, ______ habla tres idiomas. (referring to the assistant, feminine) |
| ------------------------------------------------------------------------------------------------------------------------------------------ |
| la cual<br><br><!--ANKI_NOTE_ID:1786620499202--> |

| Why is *la cual* used instead of *el cual* in "La empresa contrató a la asistente del director, la cual habla tres idiomas"? |
| --------------------------------------------------------------------------------------------------------------------------------- |
| It agrees with and clarifies the clause refers to *la asistente* (feminine), not *el director* (masculine).<br><br><!--ANKI_NOTE_ID:1786620499205--> |

| Translate: These are the documents without which we cannot continue. |
| -------------------------------------------------------------------------- |
| Estos son los documentos sin los cuales no podemos continuar.<br><br><!--ANKI_NOTE_ID:1786620499207--> |

| Fill in the blank: Vi el edificio en ______ trabaja mi hermana. |
| --------------------------------------------------------------------- |
| el cual<br><br><!--ANKI_NOTE_ID:1786620499209--> |

| Which form of "cual" agrees with "la reunión" (a feminine singular noun)? |
| -------------------------------------------------------------------------- |
| la cual<br><br><!--ANKI_NOTE_ID:1786620499211--> |

| Why is this sentence wrong: "El libro el cual leí está en la mesa."? |
| --------------------------------------------------------------------------- |
| *El cual* cannot open a restrictive clause right after its antecedent with no preposition and no comma — that slot belongs to *que*: *El libro que leí...*<br><br><!--ANKI_NOTE_ID:1786620499213--> |

| Fix the error: "La reunión, el cual duró dos horas, fue productiva." |
| ----------------------------------------------------------------------- |
| La reunión, la cual duró dos horas, fue productiva. (must agree in gender with *la reunión*)<br><br><!--ANKI_NOTE_ID:1786620499215--> |

| Translate: The students who arrived late could not get in. |
| ------------------------------------------------------------- |
| Los estudiantes que llegaron tarde no pudieron entrar.<br><br><!--ANKI_NOTE_ID:1786620499217--> |

| True or false: A non-restrictive clause can be removed from the sentence without losing essential meaning. |
| ------------------------------------------------------------------------------------------------------------- |
| True — it only adds extra detail about a noun already identified.<br><br><!--ANKI_NOTE_ID:1786620499220--> |

| Fill in the blank: La reunión, durante ______ se tomaron varias decisiones importantes, duró dos horas. |
| ------------------------------------------------------------------------------------------------------------ |
| la cual<br><br><!--ANKI_NOTE_ID:1786620499224--> |

| What punctuation signals a non-restrictive clause in writing? |
| --------------------------------------------------------------- |
| Commas set off the clause on both sides (or one side, at the end of the sentence).<br><br><!--ANKI_NOTE_ID:1786620499226--> |

| Translate: The meeting, during which several important decisions were made, lasted two hours. |
| ---------------------------------------------------------------------------------------------- |
| La reunión, durante la cual se tomaron varias decisiones importantes, duró dos horas.<br><br><!--ANKI_NOTE_ID:1786620499228--> |

| Why does "la razón por que" sound incomplete/unclear in formal Spanish? |
| ------------------------------------------------------------------------- |
| After a compound or formal preposition like *por*, *el cual* forms read more naturally than *que*: *la razón por la cual*.<br><br><!--ANKI_NOTE_ID:1786620499229--> |

| Fill in the blank: Estos son los documentos sin ______ no podemos firmar el contrato. |
| ------------------------------------------------------------------------------------------ |
| los cuales<br><br><!--ANKI_NOTE_ID:1786620499231--> |

| Translate: The project that we presented was approved without changes. |
| ------------------------------------------------------------------------- |
| El proyecto que presentamos fue aprobado sin cambios.<br><br><!--ANKI_NOTE_ID:1786620499233--> |
