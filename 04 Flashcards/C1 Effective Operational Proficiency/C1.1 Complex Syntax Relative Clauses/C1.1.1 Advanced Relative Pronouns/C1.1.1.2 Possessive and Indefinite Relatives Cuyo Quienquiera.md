#anki/Spanish/C1-Effective-Operational-Proficiency/C1-1-Complex-Syntax-Relative-Clauses/C1-1-1-Advanced-Relative-Pronouns/C1-1-1-2-Possessive-and-Indefinite-Relatives-Cuyo-Quienquiera

| What does *cuyo* agree with — the possessor or the thing possessed? |
| ------------------------------------------------------------------- |
| The thing possessed. *Cuyo/cuya/cuyos/cuyas* matches the noun that follows it, never the owner.<br><br><!--ANKI_NOTE_ID:1786620754370--> |

| Translate: The writer whose book won the prize gave an interview. |
| ---------------------------------------------------------------------- |
| El escritor cuyo libro ganó el premio dio una entrevista.<br><br><!--ANKI_NOTE_ID:1786620754381--> |

| Fill in the blank: La mujer ______ casa visitamos es mi tía. |
| ------------------------------------------------------------------ |
| cuya<br><br><!--ANKI_NOTE_ID:1786620754392--> |

| Why is "la mujer cuyo casa" wrong? |
| -------------------------------------- |
| *Cuyo* must agree with *casa* (feminine), so it should be *cuya casa*, not *cuyo casa*.<br><br><!--ANKI_NOTE_ID:1786620754396--> |

| Fill in the blank: Los vecinos ______ quejas llegaron a la alcaldía fueron escuchados. |
| --------------------------------------------------------------------------------------- |
| cuyas<br><br><!--ANKI_NOTE_ID:1786620754399--> |

| Can *cuyo* be used to ask "Whose book is this?" |
| ---------------------------------------------------- |
| No — *cuyo* only connects clauses. Questions use *¿de quién es este libro?*<br><br><!--ANKI_NOTE_ID:1786620754403--> |

| Is an article used between *cuyo* and the noun it modifies (e.g. "cuyo el libro")? |
| ---------------------------------------------------------------------------------------- |
| No — *cuyo* goes directly before the noun with no article: *cuyo libro*, not *cuyo el libro*.<br><br><!--ANKI_NOTE_ID:1786620754407--> |

| Translate: Whoever wins the contest will receive a prize. |
| ---------------------------------------------------------------- |
| Quienquiera que gane el concurso recibirá un premio.<br><br><!--ANKI_NOTE_ID:1786620754411--> |

| What verb mood typically follows *quienquiera que* and *cualquiera que*? |
| -------------------------------------------------------------------------- |
| The subjunctive — e.g. *quienquiera que gane*, *cualquiera que sea*.<br><br><!--ANKI_NOTE_ID:1786620754415--> |

| Fill in the blank: Puedes llamar a ______ persona del equipo. (any) |
| --------------------------------------------------------------------- |
| cualquier<br><br><!--ANKI_NOTE_ID:1786620754418--> |

| Why does *cualquiera* shorten to *cualquier* in "cualquier persona"? |
| -------------------------------------------------------------------------- |
| *Cualquiera* drops the final *-a* to *cualquier* when placed directly before a singular noun.<br><br><!--ANKI_NOTE_ID:1786620754422--> |

| Translate: The company whose employees quit had to close. |
| ---------------------------------------------------------------- |
| La empresa cuyos empleados renunciaron tuvo que cerrar.<br><br><!--ANKI_NOTE_ID:1786620754425--> |

| What is the plural form of *quienquiera* used for more than one unknown person? |
| -------------------------------------------------------------------------------- |
| quienesquiera — e.g. *quienesquiera que sean*.<br><br><!--ANKI_NOTE_ID:1786620754429--> |

| Fill in the blank: ______ que sea tu decisión, te apoyamos. (Whatever) |
| ------------------------------------------------------------------------- |
| Cualquiera<br><br><!--ANKI_NOTE_ID:1786620754432--> |

| Translate: I met the artist whose painting is in the museum. |
| --------------------------------------------------------------------- |
| Conocí a la artista cuya pintura está en el museo.<br><br><!--ANKI_NOTE_ID:1786620754435--> |

| Is *cuyo* common in everyday casual speech or mostly in formal/literary Spanish? |
| -------------------------------------------------------------------------------- |
| Mostly formal/literary. In casual speech, people often restructure with *de quien* instead.<br><br><!--ANKI_NOTE_ID:1786620754438--> |

| Fill in the blank: Puedes tomar ______ autobús que pase por aquí. (any) |
| ---------------------------------------------------------------------------- |
| cualquier<br><br><!--ANKI_NOTE_ID:1786620754441--> |
