| What is "my" before a singular noun? |
| ------------------------------------------------ |
|  mi<br><br><!--ANKI_NOTE_ID:1786449796545--> |

| What is "my" before a plural noun? |
| ---------------------------------------------- |
|  mis<br><br><!--ANKI_NOTE_ID:1786449796559--> |

| What is "your" (tú) before a singular noun? |
| ---------------------------------------------------------- |
|  tu<br><br><!--ANKI_NOTE_ID:1786449796562--> |

| What are the four possible meanings of *su*? |
| ------------------------------------------------------- |
|  his, her, your (formal, usted), or their<br><br><!--ANKI_NOTE_ID:1786449796565--> |

| Does *mi/tu/su* change for the gender of the noun, or only for number? |
| ---------------------------------------------------------------------------------- |
|  Only for number — they don't change for gender.<br><br><!--ANKI_NOTE_ID:1786449796567--> |

| Which possessive changes for both gender and number? |
| ------------------------------------------------------------------ |
|  *nuestro/nuestra/nuestros/nuestras*.<br><br><!--ANKI_NOTE_ID:1786449796570--> |

| Translate: My brother lives in Lima. |
| ------------------------------------------------- |
|  Mi hermano vive en Lima.<br><br><!--ANKI_NOTE_ID:1786449796573--> |

| Translate: Where are your (tú) keys? |
| ------------------------------------------------- |
|  ¿Dónde están tus llaves?<br><br><!--ANKI_NOTE_ID:1786449796575--> |

| Translate: Our car is at the shop. |
| ------------------------------------------- |
|  Nuestro carro está en el taller.<br><br><!--ANKI_NOTE_ID:1786449796577--> |

| Translate: Our family is big. |
| ---------------------------------------- |
|  Nuestra familia es grande.<br><br><!--ANKI_NOTE_ID:1786449796580--> |

| How do you clarify who "su casa" belongs to? |
| --------------------------------------------------------- |
|  Add *de él, de ella, de usted,* or *de ellos*: *la casa de ella*.<br><br><!--ANKI_NOTE_ID:1786449796582--> |

| Why is "Me duele mi codo" unnatural for "My elbow hurts"? |
| ------------------------------------------------------------------------- |
|  Spanish skips the possessive with body parts when the owner is obvious — use the article instead: *Me duele el codo*.<br><br><!--ANKI_NOTE_ID:1786449796584--> |

| Fix the agreement error: "nuestro casa" |
| ---------------------------------------------------- |
|  nuestra casa — *nuestro* must agree in gender with *casa* (feminine).<br><br><!--ANKI_NOTE_ID:1786449796586--> |

| Translate: Her house is very big. |
| -------------------------------------------- |
|  Su casa es muy grande.<br><br><!--ANKI_NOTE_ID:1786449796589--> |

| Translate: Put on your shoes. |
| ---------------------------------------- |
|  Ponte los zapatos.<br><br><!--ANKI_NOTE_ID:1786449796591--> |

| Why does "Ponte los zapatos" use "los" instead of "tus"? |
| ------------------------------------------------------------------- |
|  With clothing and the owner obvious from context, Spanish uses the definite article instead of a possessive.<br><br><!--ANKI_NOTE_ID:1786449796593--> |
