| How many distance levels does Spanish have for demonstratives, compared to English's two? |
| -------------------------------------------------------------------------------------------------- |
|  Three: close (*este*), nearby/near listener (*ese*), and far away (*aquel*).<br><br><!--ANKI_NOTE_ID:1786450004625--> |

| What is "this" for a masculine singular noun? |
| ----------------------------------------------------------- |
|  este<br><br><!--ANKI_NOTE_ID:1786450004637--> |

| What is "these" for a feminine plural noun? |
| --------------------------------------------------------- |
|  estas<br><br><!--ANKI_NOTE_ID:1786450004641--> |

| What is "that" (nearby) for a masculine singular noun? |
| ------------------------------------------------------------------------ |
|  ese<br><br><!--ANKI_NOTE_ID:1786450004645--> |

| What is "that" (far away) for a feminine singular noun? |
| ------------------------------------------------------------------------- |
|  aquella<br><br><!--ANKI_NOTE_ID:1786450004649--> |

| Translate: This book is very interesting. |
| ------------------------------------------------------- |
|  Este libro es muy interesante.<br><br><!--ANKI_NOTE_ID:1786450004653--> |

| Translate: Do you like these photos? |
| ---------------------------------------------------- |
|  ¿Te gustan estas fotos?<br><br><!--ANKI_NOTE_ID:1786450004656--> |

| Translate: That mountain over there looks huge. |
| ------------------------------------------------------------- |
|  Aquella montaña se ve enorme.<br><br><!--ANKI_NOTE_ID:1786450004659--> |

| In casual speech, which demonstrative often replaces *aquel* for "not right here" things? |
| --------------------------------------------------------------------------------------------------- |
|  *ese* — *aquel* is mostly reserved for emphasizing real distance.<br><br><!--ANKI_NOTE_ID:1786450004663--> |

| What does the neuter form *esto* refer to? |
| -------------------------------------------------------- |
|  An idea or an unidentified thing, not a specific noun: *¿Qué es esto?*<br><br><!--ANKI_NOTE_ID:1786450004666--> |

| Translate: I don't want that one, I prefer this one. |
| --------------------------------------------------------------- |
|  No quiero ese, prefiero este.<br><br><!--ANKI_NOTE_ID:1786450004669--> |

| Fix the agreement error: "este casa" |
| ------------------------------------------------ |
|  esta casa — *casa* is feminine, so it needs *esta*, not *este*.<br><br><!--ANKI_NOTE_ID:1786450004673--> |

| Why is *aquel* wrong for something sitting right next to you? |
| ------------------------------------------------------------------------- |
|  *aquel* is for things far from both speaker and listener — use *este* for something close by.<br><br><!--ANKI_NOTE_ID:1786450004677--> |

| Translate: What is this? |
| ---------------------------------- |
|  ¿Qué es esto?<br><br><!--ANKI_NOTE_ID:1786450004681--> |

| Do demonstratives go before or after the noun? |
| -------------------------------------------------------------- |
|  Before — *este libro*, not *libro este*.<br><br><!--ANKI_NOTE_ID:1786450004684--> |

| Translate: That car belongs to my neighbor. |
| --------------------------------------------------------- |
|  Ese carro es de mi vecino.<br><br><!--ANKI_NOTE_ID:1786450004688--> |
