#anki/Spanish/A1-Breakthrough-Absolute-Beginner/A1-3-Essential-Verbs-Present-Indicative/A1-3-5-Possessive-Demonstrative-Adjectives/A1-3-5-3-Long-Form-Possessive-Pronouns

| What is the main difference between a short-form possessive (_mi, tu, su_) and a long-form possessive pronoun (_mío, tuyo, suyo_)? |
| ------------------------------------------------------------------------------------------------------------------------------- |
| The short form always comes before a noun (_mi casa_). The long form either stands alone (usually after *ser*: _es mía_) or comes after the noun (_una casa mía_), and can replace the noun entirely with an article (_la mía_). <br><br><!--ANKI_NOTE_ID:1786725096639--> |

| Unlike the short-form possessives, what do ALL long-form possessives agree with? |
| -------------------------------------------------------------------------- |
| Both gender AND number with the noun they refer to (e.g. mío/mía/míos/mías) — not just number like most short forms. <br><br><!--ANKI_NOTE_ID:1786725096644--> |

| Translate: "Whose jacket is this? It's mine." (feminine noun) |
| ----------------------------------------------------------- |
| ¿De quién es esta chaqueta? Es mía. <br><br><!--ANKI_NOTE_ID:1786725096648--> |

| Translate: "My phone isn't working; can you lend me yours?" |
| ------------------------------------------------------- |
| Mi teléfono no funciona; ¿me prestas el tuyo? <br><br><!--ANKI_NOTE_ID:1786725096652--> |

| Fill in the blank with the correct long-form possessive: Estos libros son ______ (mine, plural), esos son tuyos. |
| -------------------------------------------------------------------------------------------------------- |
| míos <br><br><!--ANKI_NOTE_ID:1786725096656--> |

| Translate: "A friend of mine works at that company." |
| ---------------------------------------------------- |
| Un amigo mío trabaja en esa empresa. <br><br><!--ANKI_NOTE_ID:1786725096659--> |

| Why is _suyo/suya/suyos/suyas_ ambiguous, and how do speakers clarify it? |
| ------------------------------------------------------------------- |
| It can mean "his," "hers," "yours (formal)," or "theirs" — speakers add *de él, de ella, de usted,* or *de ellos* when the owner isn't clear from context. <br><br><!--ANKI_NOTE_ID:1786725096662--> |

| Translate, clarifying the ambiguity: "It's not his, it's hers." |
| ------------------------------------------------------------- |
| No es de él, es de ella. <br><br><!--ANKI_NOTE_ID:1786725096665--> |

| Fix the mistake: "Esta mochila es mío." Why is it wrong, and what's the correct form? |
| ------------------------------------------------------------------------------- |
| Wrong because *mochila* is feminine, but *mío* is masculine. Correct: "Esta mochila es mía." <br><br><!--ANKI_NOTE_ID:1786725096668--> |

| Fix the mistake: "Mío carro es rojo." Why is this wrong? |
| -------------------------------------------------------- |
| The long form can't go before the noun like the short form does — that position needs the short form (*Mi carro es rojo*) or the long form after the noun/with an article (*El carro mío es rojo* / *El mío es rojo*). <br><br><!--ANKI_NOTE_ID:1786725096671--> |

| Translate: "These books are mine, those are yours." (plural, informal "you") |
| ---------------------------------------------------------------------- |
| Estos libros son míos, esos son tuyos. <br><br><!--ANKI_NOTE_ID:1786725096674--> |

| What does *nuestra casa* become when using the long form to say "our house" is compared with "yours"? Translate: "Our house is small; theirs is huge." |
| -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Nuestra casa es pequeña; la suya es enorme. <br><br><!--ANKI_NOTE_ID:1786725096676--> |

| When the long-form possessive comes right after a noun (like *un amigo mío*), what extra meaning does that word order often imply? |
| -------------------------------------------------------------------------------------------------------------------------------- |
| It often implies "one among several" — *un amigo mío* suggests you have more than one friend, similar to English "a friend of mine." <br><br><!--ANKI_NOTE_ID:1786725096679--> |
