| Which form of a stem-changing verb never changes its stem? |
| ---------------------------------------------------------------- |
|  *nosotros* — the stress falls elsewhere, so the vowel stays plain.<br><br><!--ANKI_NOTE_ID:1786449096100--> |

| What does *querer* change into for *yo, tú, él/ella/usted,* and *ellos/ustedes*? |
| ---------------------------------------------------------------------------------------- |
|  The *e* in the stem becomes *ie*: *quiero, quieres, quiere, quieren*.<br><br><!--ANKI_NOTE_ID:1786449096102--> |

| Conjugate *pensar* for *nosotros*. |
| -------------------------------------------- |
|  pensamos — no stem change<br><br><!--ANKI_NOTE_ID:1786449096103--> |

| Translate: I want a coffee. |
| ------------------------------------ |
|  Quiero un café.<br><br><!--ANKI_NOTE_ID:1786449096105--> |

| Translate: Can you (tú) help me? |
| ----------------------------------------- |
|  ¿Puedes ayudarme?<br><br><!--ANKI_NOTE_ID:1786449096106--> |

| Translate: She asks for the check. |
| -------------------------------------------- |
|  Ella pide la cuenta.<br><br><!--ANKI_NOTE_ID:1786449096108--> |

| Why is "quieremos" wrong for "we want"? |
| -------------------------------------------------- |
|  *nosotros* never takes the stem change — the correct form is *queremos*.<br><br><!--ANKI_NOTE_ID:1786449096110--> |

| Name the three stem-change patterns covered in this lesson. |
| --------------------------------------------------------------------- |
|  *e → ie, o → ue,* and *e → i*.<br><br><!--ANKI_NOTE_ID:1786449096111--> |

| Give one other *o → ue* verb besides *poder*. |
| -------------------------------------------------------- |
|  *volver*, *dormir*, or *encontrar* (any one).<br><br><!--ANKI_NOTE_ID:1786449096113--> |

| Give one other *e → i* verb besides *pedir*. |
| -------------------------------------------------------- |
|  *servir*, *repetir*, or *seguir* (any one).<br><br><!--ANKI_NOTE_ID:1786449096114--> |

| Conjugate *dormir* for *yo*. |
| -------------------------------------- |
|  duermo<br><br><!--ANKI_NOTE_ID:1786449096116--> |

| Translate: My friends are coming back tomorrow. |
| ------------------------------------------------------------ |
|  Mis amigos vuelven mañana.<br><br><!--ANKI_NOTE_ID:1786449096118--> |

| Translate: Do you (tú) understand the question? |
| ------------------------------------------------------------ |
|  ¿Entiendes la pregunta?<br><br><!--ANKI_NOTE_ID:1786449096119--> |

| Is the stem-change pattern predictable from a verb's spelling alone? |
| ----------------------------------------------------------------------------- |
|  No — it has to be learned with the verb itself.<br><br><!--ANKI_NOTE_ID:1786449096121--> |
