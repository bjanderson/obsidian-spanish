| What's the difference between *sé* and *se*? |
| -------------------------------------------------------- |
|  *sé* means "I know" (from *saber*); *se* is the reflexive pronoun — spelled almost the same but very different meanings.<br><br><!--ANKI_NOTE_ID:1786449326653--> |

| Why is "tú hagos" wrong? |
| --------------------------------- |
|  The irregular *-go* ending only applies to *yo* — *tú* stays regular: *haces*.<br><br><!--ANKI_NOTE_ID:1786449326655--> |
