| What two things happen to *tener* that make it irregular? |
| ------------------------------------------------------------------- |
|  The *yo* form takes *-go* (*tengo*), and the *tú/él/ellos* forms take an *e → ie* stem change.<br><br><!--ANKI_NOTE_ID:1786449564623--> |

| Translate: I have to work tomorrow. |
| -------------------------------------------- |
|  Tengo que trabajar mañana.<br><br><!--ANKI_NOTE_ID:1786449564626--> |

| Translate: We're going to study tonight. |
| --------------------------------------------------- |
|  Vamos a estudiar esta noche.<br><br><!--ANKI_NOTE_ID:1786449564629--> |

| What does *tener que* + infinitive mean? |
| --------------------------------------------------- |
|  "To have to..." — expressing obligation.<br><br><!--ANKI_NOTE_ID:1786449564633--> |

| What does *ir a* + infinitive mean? |
| ------------------------------------------ |
|  "Going to..." — expressing near-future plans.<br><br><!--ANKI_NOTE_ID:1786449564637--> |

| Why is "tengo trabajar" incomplete? |
| -------------------------------------------- |
|  It's missing *que* — obligation requires *tener que* + infinitive: *tengo que trabajar*.<br><br><!--ANKI_NOTE_ID:1786449564641--> |

| Fix the contraction error: "voy a el parque" |
| ------------------------------------------------------- |
|  voy al parque — *a + el* contracts to *al*.<br><br><!--ANKI_NOTE_ID:1786449564644--> |

| Translate: I have two brothers. |
| -------------------------------------- |
|  Tengo dos hermanos.<br><br><!--ANKI_NOTE_ID:1786449564647--> |

| Translate: Do you (tú) have time today? |
| ------------------------------------------------- |
|  ¿Tienes tiempo hoy?<br><br><!--ANKI_NOTE_ID:1786449564651--> |

| Translate: My parents are going to Colombia in June. |
| --------------------------------------------------------------- |
|  Mis padres van a Colombia en junio.<br><br><!--ANKI_NOTE_ID:1786449564655--> |

| Why is "tú tenes" wrong for "you have"? |
| ---------------------------------------------------- |
|  *tener* has an *e → ie* stem change for *tú* — the correct form is *tienes*.<br><br><!--ANKI_NOTE_ID:1786449564658--> |

| Is *ir* regular or completely irregular in the present indicative? |
| ----------------------------------------------------------------------------- |
|  Completely irregular — all five forms must be memorized as a set.<br><br><!--ANKI_NOTE_ID:1786449564662--> |
