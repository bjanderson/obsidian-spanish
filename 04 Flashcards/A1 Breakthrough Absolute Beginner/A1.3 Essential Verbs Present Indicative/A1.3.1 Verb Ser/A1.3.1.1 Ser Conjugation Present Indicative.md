| Why is "tu eres de Chile" written incorrectly? |
| ---------------------------------------------------------- |
| The subject pronoun *tú* needs an accent mark — *tu* without the accent is the possessive "your."<br><br><!--ANKI_NOTE_ID:1786447772461--> |

| Is *ser* regular or irregular in the present indicative? |
| ------------------------------------------------------------ |
| Irregular — its forms don't follow a predictable stem pattern.<br><br><!--ANKI_NOTE_ID:1786447772463--> |

| Which verb form goes with *usted*, the same as *él* or a different one? |
| ---------------------------------------------------------------------------- |
| The same form as *él/ella*: *es*.<br><br><!--ANKI_NOTE_ID:1786447772465--> |
