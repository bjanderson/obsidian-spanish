| Why does "Es un profesor" sound off without an adjective? |
| ------------------------------------------------------------- |
|  The article *un/una* is normally dropped before an unmodified profession: *Es profesor.*<br><br><!--ANKI_NOTE_ID:1786447919660--> |

| Why is "Soy cansado" incorrect for "I'm tired"? |
| ---------------------------------------------------- |
|  Tiredness is a temporary state, so it takes *estar*: *Estoy cansado.*<br><br><!--ANKI_NOTE_ID:1786447919678--> |

| Which verb do "alive" and "dead" always take, even though they seem permanent? |
| ------------------------------------------------------------------------------ |
|  *estar* — *Está viva. Está muerto.*<br><br><!--ANKI_NOTE_ID:1786447919679--> |

| List four categories of meaning covered by *ser*. |
| ------------------------------------------------------ |
|  Identity, origin, profession, and nationality (or inherent traits).<br><br><!--ANKI_NOTE_ID:1786447919681--> |
