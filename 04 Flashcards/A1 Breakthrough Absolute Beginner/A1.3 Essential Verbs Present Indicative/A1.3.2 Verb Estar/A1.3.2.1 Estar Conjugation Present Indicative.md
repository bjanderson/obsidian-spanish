| Which forms of *estar* carry a written accent mark? |
| ------------------------------------------------------- |
|  *estás, está,* and *están* — every form except *yo* and *nosotros*.<br><br><!--ANKI_NOTE_ID:1786448216526--> |

| Is *estar* regular or irregular in the present indicative? |
| ---------------------------------------------------------------- |
|  Irregular — its forms don't follow a predictable pattern.<br><br><!--ANKI_NOTE_ID:1786448216529--> |

| What's the difference between *esta* and *está*? |
| -------------------------------------------------------- |
|  *esta* means "this" (demonstrative); *está* means "is" (verb) — the accent is the only difference.<br><br><!--ANKI_NOTE_ID:1786448216533--> |
