| When do you use *hay* instead of *estar*? |
| ------------------------------------------------ |
|  To say something exists, before you know where it is: *¿Hay café?*<br><br><!--ANKI_NOTE_ID:1786448360239--> |

| When do you switch from *hay* to *estar*? |
| ------------------------------------------------ |
|  Once the thing is already known/specific and you want to say where it is: *Está en la cocina.*<br><br><!--ANKI_NOTE_ID:1786448360242--> |

| Why is "es rica" wrong for describing how this soup tastes right now? |
| ----------------------------------------------------------------------- |
|  A dish's taste in the moment is a temporary state, so it takes *estar*: *está rica*.<br><br><!--ANKI_NOTE_ID:1786448360260--> |

| Which two things does *estar* express, beyond conjugation? |
| ------------------------------------------------------------------ |
|  Location, and temporary physical/emotional states (including how food tastes right now).<br><br><!--ANKI_NOTE_ID:1786448360267--> |
