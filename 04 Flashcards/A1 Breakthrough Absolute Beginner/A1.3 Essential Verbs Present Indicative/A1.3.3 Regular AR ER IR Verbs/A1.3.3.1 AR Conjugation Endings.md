| What's the first step in conjugating any regular *-AR* verb? |
| ---------------------------------------------------------------------- |
|  Drop the *-ar* from the infinitive to get the stem.<br><br><!--ANKI_NOTE_ID:1786448566245--> |

| Why is "hablaro" wrong for "I speak"? |
| ------------------------------------------ |
|  The *-ar* wasn't dropped before adding *-o*; the correct form is *hablo*.<br><br><!--ANKI_NOTE_ID:1786448566249--> |

| What's the difference between the *tú* ending *-as* and the *él/ella* ending *-a*? |
| -------------------------------------------------------------------------------------------- |
|  The *-s* — *hablas* is *tú*, *habla* is *él/ella/usted*.<br><br><!--ANKI_NOTE_ID:1786448566253--> |
