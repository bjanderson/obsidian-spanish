| What's the key difference between *-AR* and *-ER* endings, besides *yo*? |
| ------------------------------------------------------------------------------ |
|  *-AR* endings mostly use *a* (*-as, -a, -amos, -an*); *-ER* endings mostly use *e* (*-es, -e, -emos, -en*).<br><br><!--ANKI_NOTE_ID:1786448689811--> |

| Why is "comas" wrong for the *yo* form of *comer*? |
| ----------------------------------------------------------- |
|  *comas* would be a different form entirely — the correct *yo* form is *como*.<br><br><!--ANKI_NOTE_ID:1786448689813--> |

| Which subject pronoun's ending is identical for both *-AR* and *-ER* verbs? |
| ------------------------------------------------------------------------------------ |
|  *yo* — both take *-o* (*hablo, como*).<br><br><!--ANKI_NOTE_ID:1786448689815--> |
