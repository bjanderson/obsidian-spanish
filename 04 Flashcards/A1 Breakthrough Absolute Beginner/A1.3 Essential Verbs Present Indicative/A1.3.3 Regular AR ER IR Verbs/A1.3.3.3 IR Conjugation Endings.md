| What's the only ending that differs between *-ER* and *-IR* verbs? |
| ---------------------------------------------------------------------------- |
|  The *nosotros* form: *-emos* for *-ER* verbs, *-imos* for *-IR* verbs.<br><br><!--ANKI_NOTE_ID:1786448877325--> |

| Why is "vivemos" wrong for "we live"? |
| ---------------------------------------------- |
|  *-IR* verbs use *-imos* for *nosotros*, not *-emos* — the correct form is *vivimos*.<br><br><!--ANKI_NOTE_ID:1786448877327--> |
