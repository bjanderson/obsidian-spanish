| Are numbers 16-29 written as one fused word or three separate words? |
| -------------------------------------------------------------------------------------- |
| One fused word (e.g. dieciséis, veintidós).<br><br><!--ANKI_NOTE_ID:1786461118003--> |

| Are numbers 30-99 written as one fused word or three separate words? |
| -------------------------------------------------------------------------------------- |
| Three separate words joined by "y" (e.g. treinta y cinco).<br><br><!--ANKI_NOTE_ID:1786461118005--> |

| How do you write 100 in Spanish? |
| ------------------------------------------------- |
| Cien<br><br><!--ANKI_NOTE_ID:1786461118006--> |

| How do you write 101 in Spanish? |
| ------------------------------------------------- |
| Ciento uno<br><br><!--ANKI_NOTE_ID:1786461118008--> |

| When do you use "cien" vs. "ciento"? |
| ------------------------------------------------------- |
| "Cien" for exactly 100 or directly before a noun; "ciento" once the number continues past 100.<br><br><!--ANKI_NOTE_ID:1786461118010--> |

| Fix the error: "Cuesta ciento dólares." |
| ------------------------------------------------------ |
| Cuesta cien dólares — use *cien*, not *ciento*, for exactly 100.<br><br><!--ANKI_NOTE_ID:1786461118011--> |

| How does "uno" change before a masculine noun, even inside a compound number? |
| --------------------------------------------------------------------------------------------- |
| It shortens to *un* — e.g. *treinta y un libros*, not *treinta y uno libros*.<br><br><!--ANKI_NOTE_ID:1786461118013--> |

| How does "uno" change before a feminine noun, even inside a compound number? |
| -------------------------------------------------------------------------------------------- |
| It becomes *una* — e.g. *treinta y una personas*.<br><br><!--ANKI_NOTE_ID:1786461118015--> |

| Fix the error: "Tengo diez y seis años." |
| ------------------------------------------------------- |
| Tengo dieciséis años — 16-29 use the fused single-word form, not three separate words.<br><br><!--ANKI_NOTE_ID:1786461118017--> |

| Translate: There are forty-five students in the class. |
| ------------------------------------------------------------------------ |
| Hay cuarenta y cinco estudiantes en la clase.<br><br><!--ANKI_NOTE_ID:1786461118019--> |

| Translate: I bought thirty-one tickets. (boletos, masculine) |
| ------------------------------------------------------------------------------ |
| Compré treinta y un boletos.<br><br><!--ANKI_NOTE_ID:1786461118022--> |

| Translate: I live on floor one hundred five. |
| ------------------------------------------------------------- |
| Vivo en el piso ciento cinco.<br><br><!--ANKI_NOTE_ID:1786461118024--> |
