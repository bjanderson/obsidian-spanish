| What day does the week start on in Spanish calendars, Monday or Sunday? |
| ------------------------------------------------------------------------------------------ |
| Monday (lunes) — domingo (Sunday) is the last day.<br><br><!--ANKI_NOTE_ID:1786461199317--> |

| What is the date formula in Spanish? |
| ------------------------------------------------------- |
| el + day number + de + month + de + year<br><br><!--ANKI_NOTE_ID:1786461199343--> |

| Does the day or the month come first in a Spanish date? |
| ------------------------------------------------------------------------- |
| The day comes first — opposite of the common US month/day order.<br><br><!--ANKI_NOTE_ID:1786461199352--> |

| What word is used for "the 1st" of the month, instead of a cardinal number? |
| --------------------------------------------------------------------------------------------- |
| El primero<br><br><!--ANKI_NOTE_ID:1786461199355--> |

| How do you say "on Mondays" as a repeated habit? |
| --------------------------------------------------------------- |
| Los lunes<br><br><!--ANKI_NOTE_ID:1786461199357--> |

| How do you say "on Monday" for one specific Monday? |
| ---------------------------------------------------------------------- |
| El lunes<br><br><!--ANKI_NOTE_ID:1786461199359--> |

| What question asks "What day is it today?" |
| ------------------------------------------------------------ |
| ¿Qué día es hoy?<br><br><!--ANKI_NOTE_ID:1786461199361--> |

| What question asks "What's the date?" |
| -------------------------------------------------------- |
| ¿Cuál es la fecha (de hoy)?<br><br><!--ANKI_NOTE_ID:1786461199363--> |

| Fix the capitalization error: "Hoy es Lunes." |
| ---------------------------------------------------------------- |
| Hoy es lunes — days stay lowercase.<br><br><!--ANKI_NOTE_ID:1786461199365--> |

| Fix the word order error: "Mi cumpleaños es julio 12." |
| ------------------------------------------------------------------------- |
| Mi cumpleaños es el 12 de julio — day before month, using the *el...de* formula.<br><br><!--ANKI_NOTE_ID:1786461199367--> |

| Translate: My birthday is July 12th. |
| ------------------------------------------------------- |
| Mi cumpleaños es el 12 de julio.<br><br><!--ANKI_NOTE_ID:1786461199368--> |

| Translate: The meeting is on October 1st. |
| ---------------------------------------------------------- |
| La reunión es el primero de octubre.<br><br><!--ANKI_NOTE_ID:1786461199370--> |

| Are ordinal numbers ("second," "third") used for most dates, or cardinal numbers? |
| ----------------------------------------------------------------------------------------------- |
| Cardinal numbers (dos, tres, catorce...) — except *el primero* for the 1st.<br><br><!--ANKI_NOTE_ID:1786461199372--> |
