| How do you say "It's one o'clock" in Spanish? |
| -------------------------------------------------------------- |
| Es la una.<br><br><!--ANKI_NOTE_ID:1786461207567--> |

| How do you say "It's five o'clock" in Spanish? |
| --------------------------------------------------------------- |
| Son las cinco.<br><br><!--ANKI_NOTE_ID:1786461207569--> |

| Why does "Es la una" use the singular "es" while other hours use "son"? |
| ------------------------------------------------------------------------------------------ |
| One o'clock is treated as singular ("the one hour"); every other hour count is plural, so it takes *son*.<br><br><!--ANKI_NOTE_ID:1786461207571--> |

| Fix the error: "Son la una." |
| --------------------------------------------------- |
| Es la una — one o'clock takes the singular *es*, not *son*.<br><br><!--ANKI_NOTE_ID:1786461207574--> |

| What word means "quarter past" in a time expression? |
| -------------------------------------------------------------------- |
| Cuarto (y cuarto)<br><br><!--ANKI_NOTE_ID:1786461207579--> |

| What word means "half past" in a time expression? |
| ----------------------------------------------------------------- |
| Media (y media)<br><br><!--ANKI_NOTE_ID:1786461207582--> |

| How do you say "It's 7:40" using the standard Spanish counting-down pattern? |
| ------------------------------------------------------------------------------------------- |
| Son las ocho menos veinte.<br><br><!--ANKI_NOTE_ID:1786461207584--> |

| Past the half hour, does Spanish usually keep counting minutes up, or count down to the next hour? |
| ------------------------------------------------------------------------------------------------------------------ |
| Count down to the next hour, using *menos*.<br><br><!--ANKI_NOTE_ID:1786461207587--> |

| What question asks "What time is it?" |
| -------------------------------------------------------- |
| ¿Qué hora es?<br><br><!--ANKI_NOTE_ID:1786461207589--> |

| How do you say "at seven o'clock" (for when something happens)? |
| ------------------------------------------------------------------------------- |
| A las siete<br><br><!--ANKI_NOTE_ID:1786461207591--> |

| What phrase means "on the dot" / "sharp" when telling time? |
| ------------------------------------------------------------------------------- |
| En punto<br><br><!--ANKI_NOTE_ID:1786461207594--> |

| How do you specify "p.m." when saying a time, e.g. "9 p.m."? |
| -------------------------------------------------------------------------------- |
| Add *de la noche* — Son las nueve de la noche.<br><br><!--ANKI_NOTE_ID:1786461207596--> |

| Translate: It's 1:30 p.m. |
| ---------------------------------------- |
| Es la una y media de la tarde.<br><br><!--ANKI_NOTE_ID:1786461207599--> |

| Translate: What time is it? It's 11:15. |
| ------------------------------------------------------------ |
| ¿Qué hora es? Son las once y cuarto.<br><br><!--ANKI_NOTE_ID:1786461207600--> |

| Translate: The class starts at 8 a.m. |
| -------------------------------------------------------- |
| La clase empieza a las ocho de la mañana.<br><br><!--ANKI_NOTE_ID:1786461207602--> |
