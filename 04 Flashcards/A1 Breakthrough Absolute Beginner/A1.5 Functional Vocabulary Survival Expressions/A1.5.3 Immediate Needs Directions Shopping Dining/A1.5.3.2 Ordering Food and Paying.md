| How do you ask for the check in a restaurant? |
| -------------------------------------------------------------- |
| La cuenta, por favor.<br><br><!--ANKI_NOTE_ID:1786461254343--> |

| What phrase means "for me," used when ordering as part of a group? |
| ------------------------------------------------------------------------------------ |
| Para mí<br><br><!--ANKI_NOTE_ID:1786461254345--> |

| What is a slightly softer, more polite alternative to "quiero" when ordering? |
| ------------------------------------------------------------------------------------------- |
| Me gustaría (or quisiera)<br><br><!--ANKI_NOTE_ID:1786461254347--> |

| How do you ask a server "What do you recommend?" |
| --------------------------------------------------------------- |
| ¿Qué me recomienda?<br><br><!--ANKI_NOTE_ID:1786461254349--> |

| Does "¿Qué me recomienda?" use the tú form or the usted form? |
| ------------------------------------------------------------------------------- |
| The usted form — service interactions default to formal register.<br><br><!--ANKI_NOTE_ID:1786461254350--> |

| What is a more formal way to ask for the check, using "traer"? |
| ------------------------------------------------------------------------------- |
| ¿Me trae la cuenta?<br><br><!--ANKI_NOTE_ID:1786461254352--> |

| How do you ask whether the tip is included? |
| ------------------------------------------------------------ |
| ¿Está incluida la propina?<br><br><!--ANKI_NOTE_ID:1786461254354--> |

| Why is it useful to ask "¿Está incluida la propina?" when traveling? |
| -------------------------------------------------------------------------------------- |
| Tipping customs vary by country, so it avoids an awkward surprise.<br><br><!--ANKI_NOTE_ID:1786461254356--> |

| Fix the register mismatch: asking a waiter for the check with "¿Me traes la cuenta?" |
| ------------------------------------------------------------------------------------------------------ |
| ¿Me trae la cuenta? — service context defaults to the formal *usted* form (*trae*, not *traes*).<br><br><!--ANKI_NOTE_ID:1786461254357--> |

| Translate: What would you like to drink? (formal, server asking) |
| ------------------------------------------------------------------------------- |
| ¿Qué le gustaría tomar?<br><br><!--ANKI_NOTE_ID:1786461254359--> |

| Translate: For me, the soup, please. |
| ------------------------------------------------------- |
| Para mí, la sopa, por favor.<br><br><!--ANKI_NOTE_ID:1786461254361--> |

| Translate: Could you bring me more water, please? |
| ---------------------------------------------------------------------- |
| ¿Me trae más agua, por favor?<br><br><!--ANKI_NOTE_ID:1786461254363--> |

| Translate: The check, please. Is the tip included? |
| ----------------------------------------------------------------------- |
| La cuenta, por favor. ¿Está incluida la propina?<br><br><!--ANKI_NOTE_ID:1786461254365--> |

| Translate: I would like the table near the window. |
| ----------------------------------------------------------------------- |
| Quisiera la mesa cerca de la ventana.<br><br><!--ANKI_NOTE_ID:1786461254366--> |
