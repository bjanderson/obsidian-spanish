| Which verb is more common for everyday requests like ordering food, even where English says "need": necesito or quiero? |
| -------------------------------------------------------------------------------------------------------------------------------------- |
| Quiero — *necesito* implies real urgency, which sounds odd for a casual order.<br><br><!--ANKI_NOTE_ID:1786461248038--> |

| Fix the tone mismatch: ordering a coffee with "Necesito un café." |
| ------------------------------------------------------------------------------------- |
| Quiero un café — *necesito* sounds urgent; *quiero* is the natural way to order.<br><br><!--ANKI_NOTE_ID:1786461248040--> |

| What's the difference between "¿Hay un baño cerca?" and "¿Dónde está el baño?" |
| ----------------------------------------------------------------------------------------------- |
| *¿Hay...?* asks whether something exists nearby; *¿Dónde está...?* asks the location of a thing already known to exist.<br><br><!--ANKI_NOTE_ID:1786461248042--> |

| Do "necesito" and "quiero" need an extra connecting word before a noun or infinitive? |
| ------------------------------------------------------------------------------------------------------ |
| No — both attach directly, with no extra preposition.<br><br><!--ANKI_NOTE_ID:1786461248044--> |
