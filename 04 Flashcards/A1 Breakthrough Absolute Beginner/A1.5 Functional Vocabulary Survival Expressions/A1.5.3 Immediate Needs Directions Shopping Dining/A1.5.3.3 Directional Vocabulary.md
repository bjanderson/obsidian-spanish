| How do you say "to the right" in Spanish? |
| ---------------------------------------------------------- |
| A la derecha<br><br><!--ANKI_NOTE_ID:1786461262918--> |

| How do you say "to the left" in Spanish? |
| --------------------------------------------------------- |
| A la izquierda<br><br><!--ANKI_NOTE_ID:1786461262920--> |

| How do you say "straight ahead" in Spanish? |
| ------------------------------------------------------------ |
| Derecho (or todo derecho)<br><br><!--ANKI_NOTE_ID:1786461262922--> |

| What's the difference between "derecho" and "derecha"? |
| ------------------------------------------------------------------------ |
| *Derecho* means "straight"; *derecha* means "right" — they look alike but mean different things.<br><br><!--ANKI_NOTE_ID:1786461262924--> |

| Fix the confusion: "Gire derecho en la esquina" meant as "turn right." |
| ------------------------------------------------------------------------------------------ |
| Gire a la derecha en la esquina — *derecho* means "straight," not "right."<br><br><!--ANKI_NOTE_ID:1786461262926--> |

| What verb, plus a direction, is used for giving a "turn" command formally? |
| ------------------------------------------------------------------------------------------- |
| Gire or Doble (usted command form)<br><br><!--ANKI_NOTE_ID:1786461262928--> |

| How do you ask "How do I get to...?" |
| ------------------------------------------------------- |
| ¿Cómo llego a...?<br><br><!--ANKI_NOTE_ID:1786461262930--> |

| How do you ask "Where is... located?" |
| -------------------------------------------------------- |
| ¿Dónde queda...?<br><br><!--ANKI_NOTE_ID:1786461262932--> |

| How do you say "next to" in Spanish? |
| ------------------------------------------------------- |
| Al lado de<br><br><!--ANKI_NOTE_ID:1786461262934--> |

| Fix the missing contraction: "El banco está al lado de el parque." |
| ------------------------------------------------------------------------------------ |
| El banco está al lado del parque — *de + el* contracts to *del*.<br><br><!--ANKI_NOTE_ID:1786461262936--> |

| How do you say "across from / in front of" in Spanish? |
| ------------------------------------------------------------------------ |
| Enfrente de<br><br><!--ANKI_NOTE_ID:1786461262938--> |

| How do you say "It's two blocks from here"? |
| ------------------------------------------------------------ |
| Está a dos cuadras de aquí.<br><br><!--ANKI_NOTE_ID:1786461262940--> |

| Why do direction-giving commands like "gire" default to the formal usted form? |
| -------------------------------------------------------------------------------------------------- |
| You're typically asking or being told directions by a stranger, which defaults to formal register.<br><br><!--ANKI_NOTE_ID:1786461262942--> |

| Translate: Excuse me, how do I get to the station? |
| ----------------------------------------------------------------------- |
| Disculpe, ¿cómo llego a la estación?<br><br><!--ANKI_NOTE_ID:1786461262944--> |

| Translate: Go straight ahead and then turn left. |
| ------------------------------------------------------------------- |
| Siga todo derecho y luego gire a la izquierda.<br><br><!--ANKI_NOTE_ID:1786461262952--> |
