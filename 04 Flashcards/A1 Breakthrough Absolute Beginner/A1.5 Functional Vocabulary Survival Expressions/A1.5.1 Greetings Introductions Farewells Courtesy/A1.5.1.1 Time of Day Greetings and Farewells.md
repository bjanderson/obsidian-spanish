| How do you say "good morning" in Spanish? |
| -------------------------------------------------------- |
| Buenos días<br><br><!--ANKI_NOTE_ID:1786461097853--> |

| How do you say "good afternoon" in Spanish? |
| ---------------------------------------------------------- |
| Buenas tardes<br><br><!--ANKI_NOTE_ID:1786461097856--> |

| How do you say "good evening/good night" in Spanish? |
| ---------------------------------------------------------------------- |
| Buenas noches<br><br><!--ANKI_NOTE_ID:1786461097858--> |

| Why is it "buenos días" but "buenas tardes"? |
| --------------------------------------------------------------- |
| The greeting agrees in gender with the noun that follows — *días* is masculine, *tardes* and *noches* are feminine.<br><br><!--ANKI_NOTE_ID:1786461097860--> |

| Can "buenas noches" be used as a greeting, a farewell, or both? |
| ------------------------------------------------------------------------------- |
| Both — it greets someone arriving at night and also says goodbye when parting for the night.<br><br><!--ANKI_NOTE_ID:1786461097862--> |

| What is a casual farewell meaning "see you later"? |
| ----------------------------------------------------------------- |
| Hasta luego<br><br><!--ANKI_NOTE_ID:1786461097864--> |

| What is a casual farewell meaning "see you tomorrow"? |
| -------------------------------------------------------------------- |
| Hasta mañana<br><br><!--ANKI_NOTE_ID:1786461097866--> |

| What is a casual way to say "see you" / "we'll see each other"? |
| ------------------------------------------------------------------------------- |
| Nos vemos<br><br><!--ANKI_NOTE_ID:1786461097868--> |

| Is "adiós" the best choice for a casual, everyday farewell among friends? |
| -------------------------------------------------------------------------------------------- |
| Not usually — *hasta luego* or *nos vemos* sound more natural when you expect to see the person again soon; *adiós* can feel more final.<br><br><!--ANKI_NOTE_ID:1786461097870--> |

| Fix the agreement error: "Bueno días, profesor." |
| ------------------------------------------------------------------- |
| Buenos días, profesor — the greeting must agree with the masculine plural *días*.<br><br><!--ANKI_NOTE_ID:1786461097872--> |

| Translate: Good afternoon, do you have a moment? |
| ------------------------------------------------------------------- |
| Buenas tardes, ¿tiene un momento?<br><br><!--ANKI_NOTE_ID:1786461097874--> |

| Translate: Good night, sleep well. |
| --------------------------------------------- |
| Buenas noches, que descanses.<br><br><!--ANKI_NOTE_ID:1786461097876--> |

| Translate: See you Monday, have a good weekend. |
| ------------------------------------------------------------------ |
| Nos vemos el lunes, que tengas buen fin de semana.<br><br><!--ANKI_NOTE_ID:1786461097878--> |

| Can "hola" be combined with a time-of-day greeting, like "¡Hola, buenos días!"? |
| -------------------------------------------------------------------------------------------------- |
| Yes — combining them is common and friendly, not redundant.<br><br><!--ANKI_NOTE_ID:1786461097880--> |

| Is there a strict clock cutoff between "buenas tardes" and "buenas noches"? |
| ------------------------------------------------------------------------------------------- |
| No — there's no hard cutoff; it's judged by what feels natural in the moment.<br><br><!--ANKI_NOTE_ID:1786461097882--> |
