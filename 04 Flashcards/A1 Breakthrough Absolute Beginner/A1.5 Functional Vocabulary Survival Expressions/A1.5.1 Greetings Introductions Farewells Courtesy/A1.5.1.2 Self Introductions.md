| What is the most common way to say "My name is..." in Spanish? |
| -------------------------------------------------------------------------------- |

| What is another way to give your name, more direct than "me llamo"? |
| ------------------------------------------------------------------------------------- |
| Soy...<br><br><!--ANKI_NOTE_ID:1786461103645--> |

| How do you ask "What's your name?" informally? |
| ----------------------------------------------------------------- |
| ¿Cómo te llamas?<br><br><!--ANKI_NOTE_ID:1786461103648--> |

| How do you ask "What's your name?" formally? |
| --------------------------------------------------------- |
| ¿Cómo se llama usted?<br><br><!--ANKI_NOTE_ID:1786461103650--> |

| What is the standard response after being introduced to someone? |
| ------------------------------------------------------------------------------- |
| Mucho gusto<br><br><!--ANKI_NOTE_ID:1786461103652--> |

| What does "encantado/encantada" agree with — the speaker's gender or the listener's? |
| -------------------------------------------------------------------------------------------------- |
| The speaker's own gender.<br><br><!--ANKI_NOTE_ID:1786461103654--> |

| A woman introducing herself says "encantad_?" — fill in the ending. |
| ------------------------------------------------------------------------------------- |
| Encantada<br><br><!--ANKI_NOTE_ID:1786461103655--> |

| How do you say "I'm from..." in Spanish? |
| --------------------------------------------------------- |
| Soy de...<br><br><!--ANKI_NOTE_ID:1786461103657--> |

| How do you say "I work at/as..." in Spanish? |
| --------------------------------------------------------- |
| Trabajo en/como...<br><br><!--ANKI_NOTE_ID:1786461103659--> |

| Fix the error: "Yo llamo Diego." |
| ------------------------------------------------- |
| Me llamo Diego — the reflexive *me* is required; dropping it changes the meaning.<br><br><!--ANKI_NOTE_ID:1786461103661--> |

| A man introducing himself uses which ending: "encantado" or "encantada"? |
| -------------------------------------------------------------------------------------------- |
| Encantado<br><br><!--ANKI_NOTE_ID:1786461103663--> |

| Translate: My name is Luis. Nice to meet you. |
| ---------------------------------------------------------------- |
| Me llamo Luis. Mucho gusto.<br><br><!--ANKI_NOTE_ID:1786461103665--> |

| Translate: I'm from Bolivia and I study medicine. |
| ------------------------------------------------------------------ |
| Soy de Bolivia y estudio medicina.<br><br><!--ANKI_NOTE_ID:1786461103666--> |

| Fix the register mismatch: "¿Cómo te llamas, señor?" said to a stranger who deserves formal address. |
| ---------------------------------------------------------------------------------------------------------------------- |
| ¿Cómo se llama usted, señor? — the formal *usted* form matches addressing a stranger respectfully.<br><br><!--ANKI_NOTE_ID:1786461103668--> |

| Translate: I'm Elena, delighted to meet you. (female speaker) |
| ------------------------------------------------------------------------------ |
| Soy Elena, encantada de conocerte.<br><br><!--ANKI_NOTE_ID:1786461103670--> |
