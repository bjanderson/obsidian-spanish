| What register should you default to with a stranger you're meeting for the first time? |
| ---------------------------------------------------------------------------------------------------- |
| Usted<br><br><!--ANKI_NOTE_ID:1786461110342--> |

| What register should you default to with a peer your own age in a casual context? |
| ------------------------------------------------------------------------------------------------- |
| Tú<br><br><!--ANKI_NOTE_ID:1786461110345--> |

| Name two contexts where usted is the default, besides talking to strangers. |
| ------------------------------------------------------------------------------------------- |
| Older people, and authority figures (boss, official, doctor) or professional/service contexts.<br><br><!--ANKI_NOTE_ID:1786461110346--> |

| What Spanish verb means "to address someone as tú"? |
| -------------------------------------------------------------------- |
| Tutear<br><br><!--ANKI_NOTE_ID:1786461110348--> |

| What is a polite way to propose switching from usted to tú with someone? |
| -------------------------------------------------------------------------------------------- |
| ¿Nos podemos tutear?<br><br><!--ANKI_NOTE_ID:1786461110350--> |

| Does the relationship typically shift from tú to usted, or from usted to tú, as people grow closer? |
| ----------------------------------------------------------------------------------------------------------------- |
| From usted to tú — it's a one-directional move toward more informality.<br><br><!--ANKI_NOTE_ID:1786461110352--> |

| If you're genuinely unsure which register to use, which is the safer default? |
| ------------------------------------------------------------------------------------------------- |
| Usted — it risks sounding a little distant, but it's never disrespectful.<br><br><!--ANKI_NOTE_ID:1786461110354--> |

| What might an unwanted, too-early use of tú come across as? |
| ------------------------------------------------------------------------------- |
| Presumptuous.<br><br><!--ANKI_NOTE_ID:1786461110355--> |

| Translate, formal register: Excuse me, do you know where the bank is? |
| ------------------------------------------------------------------------------------------- |
| Disculpe, ¿sabe usted dónde queda el banco?<br><br><!--ANKI_NOTE_ID:1786461110357--> |

| Translate, informal register: Hey, do you have a minute? |
| -------------------------------------------------------------------------- |
| Oye, ¿tienes un minuto?<br><br><!--ANKI_NOTE_ID:1786461110359--> |

| Fix the register mismatch: greeting a new boss on day one with "¿Tú tienes un momento?" |
| --------------------------------------------------------------------------------------------------------- |
| ¿Usted tiene un momento? — a new boss calls for the formal *usted*, not the informal *tú*.<br><br><!--ANKI_NOTE_ID:1786461110360--> |

| Does register usage stay exactly the same across all of Latin America? |
| ------------------------------------------------------------------------------------------ |
| No — some regions lean more informal and others more formal; watch and match local usage.<br><br><!--ANKI_NOTE_ID:1786461110362--> |

| Translate: We know each other well now, can we use tú? |
| ------------------------------------------------------------------------- |
| Ya nos conocemos bien, ¿nos podemos tutear?<br><br><!--ANKI_NOTE_ID:1786461110364--> |

| Why might it be safer to wait for the other person to propose switching to tú, rather than initiating it yourself? |
| ------------------------------------------------------------------------------------------------------------------------------------ |
| Switching too soon can feel presumptuous; waiting for a signal or asking directly avoids that awkwardness.<br><br><!--ANKI_NOTE_ID:1786461110366--> |
