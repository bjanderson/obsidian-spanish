| Does *ustedes* stress the second-to-last or last syllable? Why? |
| ---------- |
| Second-to-last — *us-TE-des* — because it ends in *s*.<br><br><!--ANKI_NOTE_ID:1786404110883--> |

| Does *feliz* stress the second-to-last or last syllable? Why? |
| ---------- |
| Last — *fe-LIZ* — because it ends in *z*, not *n*/*s*.<br><br><!--ANKI_NOTE_ID:1786404110885--> |

| Why does *doctor* stress the last syllable? |
| ---------- |
| Because it ends in *r*, a consonant other than *n* or *s*.<br><br><!--ANKI_NOTE_ID:1786404110887--> |

| Why does *examen* stress the second-to-last syllable? |
| ---------- |
| Because it ends in *n*.<br><br><!--ANKI_NOTE_ID:1786404110889--> |

| True or false: a word ending in *l* stresses its last syllable by default. |
| ---------- |
| True — *l* is not *n* or *s*, so the last-syllable rule applies.<br><br><!--ANKI_NOTE_ID:1786404110892--> |

| How do you count syllables in a Spanish word for stress purposes? |
| ---------- |
| Count the vowel sounds, not the letters.<br><br><!--ANKI_NOTE_ID:1786404110894--> |

| Translate and mark the stress: I need a paper. (papel) |

| Translate and mark the stress: You all work a lot. (trabajar) |
| ---------- |

| Translate and mark the stress: The city is very big. (ciudad) |
| ---------- |
| La ciu**dad** es muy grande.<br><br><!--ANKI_NOTE_ID:1786404110902--> |

| Why doesn't *casa* need a written accent mark? |
| ---------- |
| Because it already follows the default rule — it ends in a vowel, so stress naturally falls on the second-to-last syllable.<br><br><!--ANKI_NOTE_ID:1786404110904--> |

| Does the final *y* in *hoy* count as a vowel sound or a consonant for stress purposes? |
| ---------- |
| A vowel sound — it's part of the final syllable's vowel sound, not a consonant.<br><br><!--ANKI_NOTE_ID:1786404110910--> |
