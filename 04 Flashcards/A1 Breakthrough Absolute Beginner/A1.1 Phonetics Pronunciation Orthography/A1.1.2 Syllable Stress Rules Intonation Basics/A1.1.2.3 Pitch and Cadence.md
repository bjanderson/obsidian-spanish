| What pitch pattern does a Spanish statement usually end with? |
| ---------- |
| A falling pitch on the final stressed syllable.<br><br><!--ANKI_NOTE_ID:1786404385337--> |

| What pitch pattern does a Spanish yes/no question usually end with? |
| ---------- |
| A rising pitch at the end.<br><br><!--ANKI_NOTE_ID:1786404385348--> |

| What pitch pattern does a Spanish information question usually have? |
| ---------- |
| The pitch rises early on the question word, then falls again by the end.<br><br><!--ANKI_NOTE_ID:1786404385351--> |

| Statement or yes/no question: ¿Tienes hambre? |
| ---------- |
| Yes/no question — rising pitch at the end.<br><br><!--ANKI_NOTE_ID:1786404385353--> |

| Statement or yes/no question: Tienes hambre. |
| ---------- |
| Statement — falling pitch at the end.<br><br><!--ANKI_NOTE_ID:1786404385354--> |

| What often signals the difference between "Vamos al cine." and "¿Vamos al cine?" in speech? |
| ---------- |
| Pitch alone — the words are identical, but the question rises at the end while the statement falls.<br><br><!--ANKI_NOTE_ID:1786404385356--> |

| Where does the pitch rise in an information question like *¿Dónde vives?*? |
| ---------- |
| Early, on the question word (*dónde*), then it falls again by the end.<br><br><!--ANKI_NOTE_ID:1786404385358--> |

| List five common Spanish information question words. |
| ---------- |
| *qué*, *dónde*, *cuándo*, *cómo*, *por qué* (also *quién*, *cuál*)<br><br><!--ANKI_NOTE_ID:1786404385360--> |

| True or false: information questions rise all the way to the end, like yes/no questions. |
| ---------- |
| False — they rise early on the question word, then fall back down by the end.<br><br><!--ANKI_NOTE_ID:1786404385362--> |

| Why do Spanish speakers rely so heavily on intonation for yes/no questions? |
| ---------- |
| Because word order often doesn't change between a statement and a yes/no question — pitch is the main signal.<br><br><!--ANKI_NOTE_ID:1786404385364--> |

| Translate and identify the intonation pattern: Are you coming to the party? |
| ---------- |
| ¿Vienes a la fiesta? — yes/no question, rising pitch at the end.<br><br><!--ANKI_NOTE_ID:1786404385366--> |

| Translate and identify the intonation pattern: Where does he work? |
| ---------- |
| ¿Dónde trabaja? — information question, rise on *dónde*, then fall.<br><br><!--ANKI_NOTE_ID:1786404385368--> |

| Translate and identify the intonation pattern: We are going home. |
| ---------- |
| Vamos a casa. — statement, falling pitch at the end.<br><br><!--ANKI_NOTE_ID:1786404385370--> |

| What mistake happens if a speaker uses flat, unchanging pitch on a yes/no question? |
| ---------- |
| It can sound like a statement instead of a question to a native listener.<br><br><!--ANKI_NOTE_ID:1786404385373--> |

| What mistake happens if a speaker lets pitch keep rising through an entire information question? |
| ---------- |
| It wrongly copies the yes/no pattern instead of falling back down after the question word.<br><br><!--ANKI_NOTE_ID:1786404385375--> |

| Statement or information question: ¿Cómo se llama tu perro? |
| ---------- |
| Information question — rise on *cómo*, fall by the end.<br><br><!--ANKI_NOTE_ID:1786404385377--> |

| Statement or information question: ¿Por qué estás tan cansado? |
| ---------- |
| Information question — rise on *por qué*, fall by the end.<br><br><!--ANKI_NOTE_ID:1786404385380--> |

| In writing, what marks a question in Spanish that pitch marks in speech? |
| ---------- |
| The inverted question mark ¿ at the start and ? at the end.<br><br><!--ANKI_NOTE_ID:1786404385382--> |
