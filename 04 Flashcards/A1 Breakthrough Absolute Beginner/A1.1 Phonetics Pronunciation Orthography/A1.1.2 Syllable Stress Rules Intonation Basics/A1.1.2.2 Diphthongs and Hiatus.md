| Which Spanish vowels are "strong"? |
| ---------- |
| *a*, *e*, *o*<br><br><!--ANKI_NOTE_ID:1786404251689--> |

| Which Spanish vowels are "weak"? |
| ---------- |
| *i*, *u*<br><br><!--ANKI_NOTE_ID:1786404251701--> |

| What vowel combination forms a diphthong? |
| ---------- |
| A strong vowel with a weak vowel (either order), or two weak vowels together.<br><br><!--ANKI_NOTE_ID:1786404251704--> |

| What vowel combination forms a hiatus? |
| ---------- |
| Two strong vowels next to each other.<br><br><!--ANKI_NOTE_ID:1786404251707--> |

| Diptongo or hiato: bien |
| ---------- |
| Diptongo — *ie* is weak + strong.<br><br><!--ANKI_NOTE_ID:1786404251710--> |

| Diptongo or hiato: caos |
| ---------- |
| Hiato — *ao* is strong + strong.<br><br><!--ANKI_NOTE_ID:1786404251714--> |

| Diptongo or hiato: cuidado |
| ---------- |
| Diptongo — *ui* is weak + weak.<br><br><!--ANKI_NOTE_ID:1786404251717--> |

| Diptongo or hiato: feo |
| ---------- |
| Hiato — *eo* is strong + strong.<br><br><!--ANKI_NOTE_ID:1786404251720--> |

| Diptongo or hiato: nuevo |
| ---------- |
| Diptongo — *ue* is strong + weak.<br><br><!--ANKI_NOTE_ID:1786404251723--> |

| Diptongo or hiato: día |
| ---------- |
| Hiato — the accent on *í* breaks what would be a diphthong.<br><br><!--ANKI_NOTE_ID:1786404251726--> |

| Why is *país* two syllables (pa-ís) instead of one? |
| ---------- |
| The written accent on *í* forces a hiatus, splitting it from the strong vowel *a*.<br><br><!--ANKI_NOTE_ID:1786404251729--> |

| Diptongo or hiato: maíz |
| ---------- |
| Hiato — the accent on *í* breaks the diphthong.<br><br><!--ANKI_NOTE_ID:1786404251732--> |

| How many syllables does *ciudad* have? |
| ---------- |
| Two — *ciu-dad*, since *iu* is a weak+weak diphthong.<br><br><!--ANKI_NOTE_ID:1786404251735--> |

| How many syllables does *caos* have? |
| ---------- |
| Two — *ca-os*, since *ao* is a strong+strong hiatus.<br><br><!--ANKI_NOTE_ID:1786404251737--> |

| True or false: two weak vowels together always form a hiatus. |
| ---------- |
| False — two weak vowels together form a diphthong, not a hiatus.<br><br><!--ANKI_NOTE_ID:1786404251740--> |

| What does an accent mark on a weak vowel next to a strong vowel do to the syllable split? |
| ---------- |
| It forces a hiatus, breaking the pair into two separate syllables instead of a diphthong.<br><br><!--ANKI_NOTE_ID:1786404251742--> |

| Diptongo or hiato: reina |
| ---------- |
| Diptongo — *ei* is strong + weak.<br><br><!--ANKI_NOTE_ID:1786404251745--> |

| Diptongo or hiato: leo (I read) |
| ---------- |
| Hiato — *eo* is strong + strong.<br><br><!--ANKI_NOTE_ID:1786404251747--> |

| Translate and identify diptongo/hiato: What day is it? (día) |
| ---------- |
| ¿Qué día es? — *día* is a hiato.<br><br><!--ANKI_NOTE_ID:1786404251750--> |

| Translate and identify diptongo/hiato: I have a new car. (nuevo) |
| ---------- |
| Tengo un carro nuevo. — *nuevo* is a diptongo.<br><br><!--ANKI_NOTE_ID:1786404251752--> |

| Why doesn't a consonant between two vowels create a diphthong or hiatus? |
| ---------- |
| Diphthongs and hiatuses only apply to vowels that are directly adjacent — a consonant between them keeps the vowels in separate syllables for an unrelated reason.<br><br><!--ANKI_NOTE_ID:1786404251755--> |
