| How does *c* sound before *a, o,* or *u*? Give an example. |
| -------------------------------------------------------------- |
| A hard "k" sound, as in *casa*.<br><br><!--ANKI_NOTE_ID:1786401390087--> |

| How does *c* sound before *e* or *i* in neutral Latin American Spanish? Give an example. |
| ---------------------------------------------------------------------------------------------- |
| A soft "s" sound, as in *cielo* ("syelo," not "kyelo").<br><br><!--ANKI_NOTE_ID:1786401390098--> |

| How is *z* pronounced in this course's neutral Latin American Spanish? |
| ------------------------------------------------------------------------- |
| Like an English "s" — *zapato* sounds like "sapato."<br><br><!--ANKI_NOTE_ID:1786401390106--> |

| True or false: *g* is pronounced the same way in *gato* and *gente*. |
| --------------------------------------------------------------------------- |
| False — hard "g" before *a/o/u* (*gato*), but a throaty *j* sound before *e/i* (*gente*).<br><br><!--ANKI_NOTE_ID:1786401390109--> |

| How is the letter *j* pronounced in Spanish, and does the following vowel change it? |
| -------------------------------------------------------------------------------------------- |
| Always a harsh, throaty sound made in the back of the throat — the same regardless of the vowel after it.<br><br><!--ANKI_NOTE_ID:1786401390111--> |

| When is the letter *h* pronounced in Spanish? |
| ------------------------------------------------- |
| Never — *h* is always silent.<br><br><!--ANKI_NOTE_ID:1786401390115--> |

| Translate: hello |
| ----------------- |
| hola<br><br><!--ANKI_NOTE_ID:1786401390119--> |

| What is the difference in pronunciation between a single *r* between vowels and a double *rr*? |
| -------------------------------------------------------------------------------------------------------- |
| Single *r* is one quick tap of the tongue; *rr* is a trill — several rapid taps in a row.<br><br><!--ANKI_NOTE_ID:1786401390122--> |

| Translate: dog (trilled rr) |
| ---------------------------- |
| perro<br><br><!--ANKI_NOTE_ID:1786401390125--> |

| Translate: but |
| --------------- |
| pero<br><br><!--ANKI_NOTE_ID:1786401390128--> |

| Why do *pero* and *perro* mean different things even though they're spelled almost the same? |
| ------------------------------------------------------------------------------------------------------ |
| The single tap *r* in *pero* versus the trilled *rr* in *perro* is the only difference, and it changes the meaning.<br><br><!--ANKI_NOTE_ID:1786401390131--> |

| How is *ñ* pronounced, and is it a separate letter from *n*? |
| -------------------------------------------------------------------- |
| Like the "ny" in "canyon" — yes, *ñ* is its own distinct letter, not a decorated *n*.<br><br><!--ANKI_NOTE_ID:1786401390134--> |

| Translate: year |
| ---------------- |
| año<br><br><!--ANKI_NOTE_ID:1786401390137--> |

| A learner pronounces the *h* in *hora* (hour). What's wrong? |
| -------------------------------------------------------------------- |
| The *h* should be silent — *hora* starts on the vowel sound, no "h" pronounced.<br><br><!--ANKI_NOTE_ID:1786401390140--> |

| A learner says *gente* with a hard "g," like in "get." What's wrong? |
| ------------------------------------------------------------------------ |
| Before *e* or *i*, *g* becomes the throaty *j* sound, not a hard "g."<br><br><!--ANKI_NOTE_ID:1786401390143--> |

| A learner pronounces *zapato* with a "th" sound at the start. What's wrong for this course? |
| ------------------------------------------------------------------------------------------------- |
| That's the Spain pronunciation of *z* — this course uses the neutral Latin American "s" sound instead.<br><br><!--ANKI_NOTE_ID:1786401390146--> |

| Translate: I have a dog but I don't have a cat. |
| --------------------------------------------------- |
| Tengo un perro pero no tengo gato.<br><br><!--ANKI_NOTE_ID:1786401390149--> |

| Translate: How old are you? |
| ------------------------------- |
| ¿Cuántos años tienes?<br><br><!--ANKI_NOTE_ID:1786401390152--> |

| A learner pronounces *niño* with a plain "n" instead of *ñ*. What happens to the word? |
| ------------------------------------------------------------------------------------------------ |
| It turns into a different word — *ñ* and *n* are distinct sounds, not interchangeable.<br><br><!--ANKI_NOTE_ID:1786401390155--> |

| Fill in the missing letter: "_ugo" (juice), and explain how it's pronounced. |
| ------------------------------------------------------------------------------------ |
| jugo — the *j* is a harsh, throaty sound, never like an English "j."<br><br><!--ANKI_NOTE_ID:1786401390158--> |
