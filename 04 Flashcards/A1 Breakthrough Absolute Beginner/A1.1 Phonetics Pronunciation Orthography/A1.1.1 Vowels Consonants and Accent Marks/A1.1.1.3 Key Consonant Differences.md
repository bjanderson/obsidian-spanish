| In neutral Latin American Spanish, what sound do *c* (before *e/i*) and *z* always make? |
| -------------------------------------------------------------------------------------------- |
| The "s" sound — this merger is called *seseo*.<br><br><!--ANKI_NOTE_ID:1786384241848--> |

| What is *seseo*? |
| -------------------------- |
| The Latin American merger where *c* (before *e/i*) and *z* both sound like "s," instead of the Spain "th" sound.<br><br><!--ANKI_NOTE_ID:1786384241874--> |

| What sound does *c* make before *a, o,* or *u*? |
| ------------------------------------------------------ |
| A hard "k" sound.<br><br><!--ANKI_NOTE_ID:1786384241878--> |

| Does "cuesta" have a hard or soft *c* sound? |
| ------------------------------------------------- |
| Hard — the *c* is followed by *u*, so it sounds like "k."<br><br><!--ANKI_NOTE_ID:1786384241881--> |

| Does "cielo" have a hard or soft *c* sound? |
| ------------------------------------------------ |
| Soft — the *c* is followed by *i*, so it sounds like "s."<br><br><!--ANKI_NOTE_ID:1786384241885--> |

| What sound does *g* make before *a, o,* or *u*? |
| ------------------------------------------------------ |
| A hard "g" sound, like the English "g" in "go."<br><br><!--ANKI_NOTE_ID:1786384241888--> |

| What sound does *g* make before *e* or *i*? |
| -------------------------------------------------- |
| The same harsh, breathy *jota* sound as *j*.<br><br><!--ANKI_NOTE_ID:1786384241891--> |

| Fill in the blank: in "gente," the *g* sounds like ___. |
| ----------------------------------------------------------------- |
| *j* (the *jota* sound)<br><br><!--ANKI_NOTE_ID:1786384241894--> |

| Fill in the blank: in "gato," the *g* sounds like ___. |
| ---------------------------------------------------------------- |
| a hard "g" (like English "go")<br><br><!--ANKI_NOTE_ID:1786384241898--> |

| What sound does *j* always make, regardless of the following vowel? |
| ---------------------------------------------------------------------------- |
| The harsh, breathy *jota* sound.<br><br><!--ANKI_NOTE_ID:1786384241901--> |

| True or false: the letter *h* makes a sound in Spanish. |
| ----------------------------------------------------------------- |
| False — *h* is always silent.<br><br><!--ANKI_NOTE_ID:1786384241903--> |

| What's the difference between a single *r* between vowels and *rr*? |
| ---------------------------------------------------------------------------- |
| A single *r* between vowels is a soft tap; *rr* is a rolled trill.<br><br><!--ANKI_NOTE_ID:1786384241906--> |

| Why do "pero" and "perro" mean different things? |
| --------------------------------------------------------- |
| *Pero* uses the soft tap *r* (meaning "but"); *perro* uses the rolled trill *rr* (meaning "dog").<br><br><!--ANKI_NOTE_ID:1786384241909--> |

| Fill in the blank: at the start of a word, a single *r* is pronounced like ___. |
| -------------------------------------------------------------------------------------- |
| a rolled trill (like *rr*)<br><br><!--ANKI_NOTE_ID:1786384241911--> |

| What sound does *ñ* make? |
| --------------------------------- |
| A nasal "ny" sound, like the "ny" in "canyon."<br><br><!--ANKI_NOTE_ID:1786384241914--> |

| Why is "año" not the same word as "ano"? |
| --------------------------------------------------- |
| *Ñ* is a distinct nasal sound from *n*, not an accented *n* — the two spellings are different words with different meanings.<br><br><!--ANKI_NOTE_ID:1786384241917--> |

| Translate: "The sky is clear." |
| ------------------------------------- |
| El cielo está despejado.<br><br><!--ANKI_NOTE_ID:1786384241920--> |

| Translate: "My brother plays soccer." |
| -------------------------------------------- |
| Mi hermano juega al fútbol.<br><br><!--ANKI_NOTE_ID:1786384241923--> |

| Translate: "I bought a new car." |
| ----------------------------------------- |
| Compré un carro nuevo.<br><br><!--ANKI_NOTE_ID:1786384241926--> |

| A learner pronounces "gente" with a hard "g" sound, like "GEN-teh." What's wrong? |
| ---------------------------------------------------------------------------------------- |
| *G* before *e* should sound like *jota*, not a hard "g" — it should sound like "HEN-teh."<br><br><!--ANKI_NOTE_ID:1786384241929--> |
