| Where does stress fall by default in a word ending in a vowel, *n*, or *s*? |
| --------------------------------------------------------------------------------- |
| On the second-to-last syllable — no written accent needed.<br><br><!--ANKI_NOTE_ID:1786401793237--> |

| Where does stress fall by default in a word ending in a consonant other than *n* or *s*? |
| -------------------------------------------------------------------------------------------- |
| On the last syllable — no written accent needed.<br><br><!--ANKI_NOTE_ID:1786401793248--> |

| What does a written accent mark (tilde) do when a word breaks the default stress rules? |
| ------------------------------------------------------------------------------------------- |
| It shows exactly where the real stress falls, overriding the default rule.<br><br><!--ANKI_NOTE_ID:1786401793250--> |

| *árbol* ends in a consonant other than *n/s*, so the default rule expects final-syllable stress. Why does it carry a written accent? |
| -------------------------------------------------------------------------------------------------------------------------------------------- |
| Because the real stress falls on the first syllable, breaking the default rule — the accent marks the exception.<br><br><!--ANKI_NOTE_ID:1786401793252--> |

| What is the difference in meaning between *el* and *él*? |
| ----------------------------------------------------------- |
| *el* (no accent) is the article "the"; *él* (with accent) is the pronoun "he/him."<br><br><!--ANKI_NOTE_ID:1786401793254--> |

| Translate: He has a tree. |
| ----------------------------- |
| Él tiene un árbol.<br><br><!--ANKI_NOTE_ID:1786401793256--> |

| Translate: The tree is big. |
| -------------------------------- |
| El árbol es grande.<br><br><!--ANKI_NOTE_ID:1786401793258--> |

| What is the difference in meaning between *tu* and *tú*? |
| ----------------------------------------------------------- |
| *tu* (no accent) means "your"; *tú* (with accent) means "you."<br><br><!--ANKI_NOTE_ID:1786401793260--> |

| Translate: Do you have my number? |
| --------------------------------------- |
| ¿Tú tienes mi número?<br><br><!--ANKI_NOTE_ID:1786401793263--> |

| What is the difference in meaning between *mi* and *mí*? |
| ----------------------------------------------------------- |
| *mi* (no accent) means "my"; *mí* (with accent) means "me" (after a preposition).<br><br><!--ANKI_NOTE_ID:1786401793265--> |

| Translate: That gift is for me. |
| ------------------------------------- |
| Ese regalo es para mí.<br><br><!--ANKI_NOTE_ID:1786401793267--> |

| A learner writes "el tiene un perro" without an accent on *el*. What's wrong? |
| ------------------------------------------------------------------------------------ |
| It should be *él* — the pronoun "he" needs the accent; without it, *el* reads as the article "the."<br><br><!--ANKI_NOTE_ID:1786401793269--> |

| Do accent marks in Spanish ever go on a consonant? |
| -------------------------------------------------------- |
| No — accent marks only ever go on one of the five vowels (á, é, í, ó, ú).<br><br><!--ANKI_NOTE_ID:1786401793271--> |

| Why does *habló* (he spoke) need a written accent, but *hablo* (I speak) does not? |
| ------------------------------------------------------------------------------------------ |
| *hablo* follows the default rule (ends in a vowel, stress on the second-to-last syllable); *habló* breaks it by stressing the last syllable, so it needs the accent.<br><br><!--ANKI_NOTE_ID:1786401793273--> |

| Question words like *qué*, *dónde*, and *cómo* carry a written accent whenever they do what? |
| ------------------------------------------------------------------------------------------------------ |
| Whenever they're used to ask a question — directly or indirectly.<br><br><!--ANKI_NOTE_ID:1786401793276--> |

| Translate: What time is it? |
| -------------------------------- |
| ¿Qué hora es?<br><br><!--ANKI_NOTE_ID:1786401793278--> |

| A learner asks "¿Como te llamas?" without an accent on *como*. What's wrong? |
| --------------------------------------------------------------------------------- |
| Question words need the accent — it should be *¿Cómo te llamas?*<br><br><!--ANKI_NOTE_ID:1786401793281--> |

| True or false: most Spanish words need a written accent mark. |
| ------------------------------------------------------------------ |
| False — most words follow the default stress rules and need no accent at all.<br><br><!--ANKI_NOTE_ID:1786401793283--> |

| Translate: I need a quick coffee. |
| --------------------------------------- |
| Necesito un café rápido.<br><br><!--ANKI_NOTE_ID:1786401793285--> |

| Why do both *café* and *rápido* need written accents in that sentence? |
| ------------------------------------------------------------------------------ |
| Both break the default stress rules — *café* stresses its last syllable despite ending in a vowel, and *rápido* stresses its first syllable despite ending in a vowel.<br><br><!--ANKI_NOTE_ID:1786401793287--> |
