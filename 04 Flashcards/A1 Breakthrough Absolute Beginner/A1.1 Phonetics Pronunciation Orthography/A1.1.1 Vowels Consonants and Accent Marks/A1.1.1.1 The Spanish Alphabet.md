| How many letters does the Spanish alphabet have? |
| -------------------------------------------------- |
| 27<br><br><!--ANKI_NOTE_ID:1786383202824--> |

| What is the extra letter in the Spanish alphabet that English doesn't have? |
| ----------------------------------------------------------------------------- |
| Ñ (*eñe*)<br><br><!--ANKI_NOTE_ID:1786383202834--> |

| What is the Spanish name for the letter H? |
| -------------------------------------------- |
| *hache*<br><br><!--ANKI_NOTE_ID:1786383202844--> |

| How is the letter H pronounced in Spanish words like "hola"? |
| ---------------------------------------------------------------- |
| It is always silent.<br><br><!--ANKI_NOTE_ID:1786383202846--> |

| What is the Spanish name for the letter J? |
| -------------------------------------------- |
| *jota*<br><br><!--ANKI_NOTE_ID:1786383202848--> |

| What does *jota* sound like? |
| ------------------------------- |
| A harsh, breathy sound close to the English "h" in "hot."<br><br><!--ANKI_NOTE_ID:1786383202850--> |

| What is the Spanish name for the letter Ñ? |
| -------------------------------------------- |
| *eñe*<br><br><!--ANKI_NOTE_ID:1786383202852--> |

| Why is Ñ a separate letter from N, not just an accented N? |
| -------------------------------------------------------------- |
| It changes a word's meaning, not just its pronunciation — e.g. *ano* (anus) vs. *año* (year).<br><br><!--ANKI_NOTE_ID:1786383202855--> |

| Fill in the blank: *año* means "year." Remove the tilde and you get ___, meaning "anus." |
| ------------------------------------------------------------------------------------------ |
| *ano*<br><br><!--ANKI_NOTE_ID:1786383202857--> |

| Are LL and RR counted as separate letters in the modern Spanish alphabet? |
| ------------------------------------------------------------------------------ |
| No — since the 2010 spelling reform, they're two-letter combinations, alphabetized under L and R.<br><br><!--ANKI_NOTE_ID:1786383202860--> |

| What is the Spanish verb for "to spell out loud, letter by letter"? |
| ------------------------------------------------------------------------ |
| *deletrear*<br><br><!--ANKI_NOTE_ID:1786383202862--> |

| Translate: "How do you spell your name?" |
| ------------------------------------------- |
| ¿Cómo se escribe tu nombre?<br><br><!--ANKI_NOTE_ID:1786383202864--> |

| Translate: "It's written with 'eñe,' not 'ene.'" |
| ----------------------------------------------------- |
| Se escribe con "eñe", no con "ene".<br><br><!--ANKI_NOTE_ID:1786383202867--> |

| Translate: "My last name is spelled A-N-D-E-R-S-O-N." |
| ----------------------------------------------------------- |
| Mi apellido se deletrea A-N-D-E-R-S-O-N.<br><br><!--ANKI_NOTE_ID:1786383202869--> |

| Translate: "The H is silent in Spanish." |
| --------------------------------------------- |
| La hache es muda en español.<br><br><!--ANKI_NOTE_ID:1786383202871--> |

| Why might a Spanish speaker say "jota, no ge" when spelling "jamón"? |
| -------------------------------------------------------------------------- |
| J and G can both sound like the harsh "h" before *e*/*i*, so speakers clarify which letter it is.<br><br><!--ANKI_NOTE_ID:1786383202873--> |

| In which kind of Spanish words do K and W usually appear? |
| ----------------------------------------------------------- |
| Loanwords, e.g. *kilómetro*, *whisky*.<br><br><!--ANKI_NOTE_ID:1786383202876--> |

| What mistake do English speakers often make with the H in "hola" or "hotel"? |
| ------------------------------------------------------------------------------ |
| Pronouncing it, when it must stay silent.<br><br><!--ANKI_NOTE_ID:1786383202878--> |

| What are the two common Spanish words for "the alphabet"? |
| --------------------------------------------------------------- |
| *el abecedario* and *el alfabeto*<br><br><!--ANKI_NOTE_ID:1786383202880--> |

| Fill in the blank: "La ___ es muda en español." (the letter H) |
| -------------------------------------------------------------------- |
| hache<br><br><!--ANKI_NOTE_ID:1786383202882--> |

| Why does *deletrear* matter as a skill for a Spanish learner? |
| ------------------------------------------------------------------- |
| You need it constantly — for phone numbers, emails, forms, and names.<br><br><!--ANKI_NOTE_ID:1786383202885--> |
