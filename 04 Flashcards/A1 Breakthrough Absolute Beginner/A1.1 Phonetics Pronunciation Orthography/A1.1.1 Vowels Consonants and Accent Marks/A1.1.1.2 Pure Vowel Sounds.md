| How many vowel sounds does Spanish have, and how many sounds can each one make? |
| --------------------------------------------------------------------------------- |
| Five vowels (*a, e, i, o, u*), each with exactly one sound, always.<br><br><!--ANKI_NOTE_ID:1786400571236--> |

| What English vowel habit must you avoid when speaking Spanish? |
| ------------------------------------------------------------------ |
| Gliding one vowel into a second sound (a diphthong) — Spanish vowels stay pure, with no glide.<br><br><!--ANKI_NOTE_ID:1786400571248--> |

| Which English word sound does the Spanish *a* match? |
| ---------------------------------------------------------- |
| The "a" in "father."<br><br><!--ANKI_NOTE_ID:1786400571250--> |

| Which English word sound does the Spanish *i* match? |
| ---------------------------------------------------------- |
| The "ee" in "see," but short and crisp, not drawn out.<br><br><!--ANKI_NOTE_ID:1786400571251--> |

| Which English word sound does the Spanish *u* match? |
| ---------------------------------------------------------- |
| The "oo" in "food," fully rounded.<br><br><!--ANKI_NOTE_ID:1786400571253--> |

| Say the Spanish word *no* the correct way. What is the biggest mistake English speakers make with it? |
| ---------------------------------------------------------------------------------------------------------- |
| One short, pure "oh" — the mistake is gliding it into "oh-oo," the way English "no" sounds.<br><br><!--ANKI_NOTE_ID:1786400571254--> |

| True or false: Spanish reduces unstressed vowels to a mushy "uh" sound, the way English does in "about." |
| --------------------------------------------------------------------------------------------------------------- |
| False — Spanish vowels stay full and clear whether stressed or unstressed.<br><br><!--ANKI_NOTE_ID:1786400571256--> |

| A learner pronounces *mesa* with the *e* sounding like the English letter name "ey." What is wrong, and what should it sound like instead? |
| ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Spanish *e* is not "ey" — it should sound closer to the "e" in "bed," short and crisp.<br><br><!--ANKI_NOTE_ID:1786400571270--> |

| A learner stretches *sí* into a long "seeee" for emphasis. Why is this a mistake in Spanish? |
| --------------------------------------------------------------------------------------------------- |
| Spanish vowels stay short even under emphasis — Spanish does not lengthen vowels the way English does.<br><br><!--ANKI_NOTE_ID:1786400571272--> |

| Fill in the vowel: "c_sa" (house) |
| ----------------------------------- |

| Fill in the vowel: "libr_" (book) |
| ------------------------------------ |
| libro<br><br><!--ANKI_NOTE_ID:1786400571275--> |

| Why does *perro* (dog) keep the same *e* and *o* sounds in both syllables, unlike English words with unstressed vowels? |
| -------------------------------------------------------------------------------------------------------------------------- |
| Spanish vowels never weaken or change sound based on stress — every *e* is the same *e*, every *o* is the same *o*.<br><br><!--ANKI_NOTE_ID:1786400571277--> |
