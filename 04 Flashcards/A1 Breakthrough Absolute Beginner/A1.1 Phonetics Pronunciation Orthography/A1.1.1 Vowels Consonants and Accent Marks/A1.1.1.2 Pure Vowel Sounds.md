| How many vowel sounds does Spanish have? |
| ------------------------------------------- |
| Five — one per vowel letter: *a, e, i, o, u*.<br><br><!--ANKI_NOTE_ID:1786383667948--> |

| True or false: a Spanish vowel's sound can change depending on the word it's in. |
| -------------------------------------------------------------------------------------- |
| False — each vowel has exactly one pronunciation, always.<br><br><!--ANKI_NOTE_ID:1786383667960--> |

| What English sound does the Spanish *a* match? |
| --------------------------------------------------- |
| The "a" in "father."<br><br><!--ANKI_NOTE_ID:1786383667963--> |

| What English sound does the Spanish *i* match? |
| --------------------------------------------------- |
| The "ee" in "machine."<br><br><!--ANKI_NOTE_ID:1786383667967--> |

| What English sound does the Spanish *u* match? |
| --------------------------------------------------- |
| The "oo" in "flu."<br><br><!--ANKI_NOTE_ID:1786383667970--> |

| Why is the Spanish *e* called a "pure" vowel sound? |
| ---------------------------------------------------------- |
| It stays one steady sound and doesn't glide into a "y" sound the way English "ay" does.<br><br><!--ANKI_NOTE_ID:1786383667973--> |

| Why is the Spanish *o* called a "pure" vowel sound? |
| ---------------------------------------------------------- |
| It stays one steady sound and doesn't glide into a "w" sound the way English "oh" does.<br><br><!--ANKI_NOTE_ID:1786383667977--> |

| What happens to unstressed vowels in Spanish? |
| ---------------------------------------------------- |
| Nothing — they stay full and clear. Spanish has no schwa sound.<br><br><!--ANKI_NOTE_ID:1786383667980--> |

| Fill in the blank: pronounce "bebé" without letting the final ___ glide into a "y" sound. |
| ------------------------------------------------------------------------------------------------- |
| e<br><br><!--ANKI_NOTE_ID:1786383667983--> |

| Fill in the blank: pronounce "oso" without letting either ___ glide into a "w" sound. |
| --------------------------------------------------------------------------------------------- |
| o<br><br><!--ANKI_NOTE_ID:1786383667986--> |

| Why is "beh-BEY" a mispronunciation of "bebé"? |
| ------------------------------------------------------ |
| The final *e* is glided into a "y" sound instead of staying a pure *e*.<br><br><!--ANKI_NOTE_ID:1786383667989--> |

| Translate: "The bear eats a lot." |
| ------------------------------------------ |
| El oso come mucho.<br><br><!--ANKI_NOTE_ID:1786383667999--> |

| Translate: "You are my friend." |
| ---------------------------------------- |
| Tú eres mi amigo.<br><br><!--ANKI_NOTE_ID:1786383668002--> |

| What English word illustrates the schwa sound that Spanish vowels never make? |
| ------------------------------------------------------------------------------------ |
| "about" (the reduced "a" sound)<br><br><!--ANKI_NOTE_ID:1786383668005--> |

| Why is it wrong to pronounce "computadora" with a reduced first vowel, the way English says "computer"? |
| ------------------------------------------------------------------------------------------------------------- |
| Spanish vowels never reduce to a schwa, even when unstressed — every vowel stays full.<br><br><!--ANKI_NOTE_ID:1786383668008--> |

| What are the five Spanish vowel letters? |
| ------------------------------------------- |
| a, e, i, o, u<br><br><!--ANKI_NOTE_ID:1786383668011--> |

| Fill in the blank: "casa" has a pure ___ sound, like "ah" in "father." |
| -------------------------------------------------------------------------------- |
| a<br><br><!--ANKI_NOTE_ID:1786383668014--> |

| A learner pronounces "sí" like the English word "eye." What's wrong? |
| ------------------------------------------------------------------------------ |
| Spanish *í* is a pure "ee" sound (like "machine"), not a diphthong like English "eye."<br><br><!--ANKI_NOTE_ID:1786383668017--> |
