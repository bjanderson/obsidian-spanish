| Why is the "h" silent in "hola"?  |
| --------------------------------- |
| In Spanish, "h" is always silent.<br><br><!--ANKI_NOTE_ID:1786322578297-->|

| How does "j" sound in a word like "jugo"? |
| ----------------------------------------- |
| Like the English "h".<br><br><!--ANKI_NOTE_ID:1786322578300-->|

| How does "ll" sound in a word like "llamar"? |
| -------------------------------------------- |
| Like the English "y".<br><br><!--ANKI_NOTE_ID:1786322578302-->|

| What sound does "ñ" add to a word like "niño"? |
| ---------------------------------------------- |
| An "ny" sound.<br><br><!--ANKI_NOTE_ID:1786322578304-->|

| How is "rr" pronounced in a word like "perro"? |
| ---------------------------------------------- |
| As a strong rolled "r".<br><br><!--ANKI_NOTE_ID:1786322578307-->|
