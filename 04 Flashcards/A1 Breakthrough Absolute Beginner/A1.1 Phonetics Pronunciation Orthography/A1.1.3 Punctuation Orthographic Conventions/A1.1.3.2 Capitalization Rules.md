| Are days of the week capitalized in Spanish? |
| ------------------------------------------------- |
| No, they stay lowercase: *lunes, martes, miércoles*...<br><br><!--ANKI_NOTE_ID:1786406255038--> |

| Are months capitalized in Spanish? |
| ----------------------------------------- |
| No, they stay lowercase: *enero, febrero, marzo*...<br><br><!--ANKI_NOTE_ID:1786406255069--> |

| Fix the capitalization: Hoy es Lunes. |
| -------------------------------------------- |
| Hoy es lunes.<br><br><!--ANKI_NOTE_ID:1786406255073--> |

| Fix the capitalization: Mi cumpleaños es en Julio. |
| ----------------------------------------------------------- |

| Translate: I speak Spanish and English. |
| ---------------------------------------------- |
| Hablo español e inglés.<br><br><!--ANKI_NOTE_ID:1786406255079--> |

| Why does "y" become "e" in "español e inglés"? |
| ------------------------------------------------------- |
| *Y* changes to *e* before a word that starts with the *i* sound, to avoid two *i* sounds running together.<br><br><!--ANKI_NOTE_ID:1786406255083--> |

| Fix the capitalization: Ella habla Francés. |
| ---------------------------------------------------- |

| Somos argentinos.<br><br><!--ANKI_NOTE_ID:1786406255089--> |

| ------------------------------------------------ |
| Somos chilenos.<br><br><!--ANKI_NOTE_ID:1786406255093--> |

| Are seasons capitalized in Spanish? |
| ------------------------------------------ |
| No, they stay lowercase: *primavera, verano, otoño, invierno*.<br><br><!--ANKI_NOTE_ID:1786406255097--> |

| Translate: My favorite season is autumn. |
| ------------------------------------------------ |
| Mi estación favorita es el otoño.<br><br><!--ANKI_NOTE_ID:1786406255100--> |

| Fix the capitalization: Prefiero el Verano al Invierno. |
| ---------------------------------------------------------------- |
| Prefiero el verano al invierno.<br><br><!--ANKI_NOTE_ID:1786406255103--> |

| Is *doctor* capitalized when spelled out with someone's name, as in "el doctor Ramírez"? |
| ------------------------------------------------------------------------------------------------ |
| No — it stays lowercase. Only the abbreviation *Dr.* is capitalized.<br><br><!--ANKI_NOTE_ID:1786406255106--> |

| Fix the capitalization: Vino a verme el Doctor Salas. |
| -------------------------------------------------------------- |
| Vino a verme el doctor Salas.<br><br><!--ANKI_NOTE_ID:1786406255110--> |

| Translate: Dr. Vega called this morning. |
| ------------------------------------------------ |
| La Dra. Vega llamó esta mañana.<br><br><!--ANKI_NOTE_ID:1786406255112--> |

| What Spanish rule explains why "Doctor Salas" is wrong but "Dr. Salas" is correct? |
| ------------------------------------------------------------------------------------------ |
| Titles stay lowercase when spelled out with a name, but their abbreviations are capitalized.<br><br><!--ANKI_NOTE_ID:1786406255115--> |

| Fix the capitalization: El Doctor Ramírez trabaja los Lunes y Miércoles. |
| ----------------------------------------------------------------------------------- |
| El doctor Ramírez trabaja los lunes y miércoles.<br><br><!--ANKI_NOTE_ID:1786406255118--> |

| What kinds of words does Spanish still capitalize, just like English? |
| ------------------------------------------------------------------------------ |
| The first word of a sentence, people's names, and place names (cities, countries, etc.).<br><br><!--ANKI_NOTE_ID:1786406255120--> |

| Translate: She is Chilean, but she lives in Peru. |
| ------------------------------------------------------- |
| Ella es chilena, pero vive en Perú.<br><br><!--ANKI_NOTE_ID:1786406255123--> |

| Why does *chilena* stay lowercase but *Perú* is capitalized in the same sentence? |
| -------------------------------------------------------------------------------------------- |
| *chilena* is a nationality (stays lowercase); *Perú* is a specific place name (a proper noun, so it's capitalized).<br><br><!--ANKI_NOTE_ID:1786406255125--> |
