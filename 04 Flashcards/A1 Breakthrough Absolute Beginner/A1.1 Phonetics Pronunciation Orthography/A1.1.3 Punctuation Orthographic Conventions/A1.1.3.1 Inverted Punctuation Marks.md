| What mark opens a Spanish question, and what closes it? |
| --------------------------------------------------------- |
| It opens with *¿* and closes with *?*.<br><br><!--ANKI_NOTE_ID:1786406068887--> |

| What mark opens a Spanish exclamation, and what closes it? |
| ------------------------------------------------------------ |
| It opens with *¡* and closes with *!*.<br><br><!--ANKI_NOTE_ID:1786406068898--> |

| Add the missing marks: ___Cómo te llamas___ |
| ---------------------------------------------- |
| ¿Cómo te llamas?<br><br><!--ANKI_NOTE_ID:1786406068901--> |

| Add the missing marks: ___Feliz cumpleaños___ |
| -------------------------------------------------- |
| ¡Feliz cumpleaños!<br><br><!--ANKI_NOTE_ID:1786406068904--> |

| Translate: Where do you live? |
| -------------------------------- |
| ¿Dónde vives?<br><br><!--ANKI_NOTE_ID:1786406068906--> |

| Translate: What a beautiful day! |
| ----------------------------------- |
| ¡Qué día tan bonito!<br><br><!--ANKI_NOTE_ID:1786406068909--> |

| In "Oye, ¿tienes hambre?", why does *Oye* sit outside the question marks? |
| ----------------------------------------------------------------------------- |
| Because *Oye* isn't part of the question itself — only the actual question gets bracketed.<br><br><!--ANKI_NOTE_ID:1786406068911--> |

| Fix the punctuation: Oye tienes un minuto |
| ---------------------------------------------- |
| Oye, ¿tienes un minuto?<br><br><!--ANKI_NOTE_ID:1786406068914--> |

| Fix the punctuation: Bueno nos vemos mañana |
| -------------------------------------------------- |
| Bueno, ¡nos vemos mañana!<br><br><!--ANKI_NOTE_ID:1786406068916--> |

| What is a sentence called that uses both question and exclamation marks together, like ¡¿Ganamos?!? |
| ---------------------------------------------------------------------------------------------------------- |
| An exclamatory question — asking something with strong surprise or emotion.<br><br><!--ANKI_NOTE_ID:1786406068918--> |

| Punctuate this exclamatory question: Ganamos |
| --------------------------------------------------- |
| ¡¿Ganamos?! (or ¿¡Ganamos!?)<br><br><!--ANKI_NOTE_ID:1786406068920--> |

| Why is "Cómo te llamas?" (no opening mark) incorrect in Spanish? |
| ----------------------------------------------------------------------- |
| Spanish questions require an opening *¿* as well as the closing *?* — it should be "¿Cómo te llamas?"<br><br><!--ANKI_NOTE_ID:1786406068922--> |

| Translate: Are you coming with us? |
| ----------------------------------------- |
| ¿Vienes con nosotros?<br><br><!--ANKI_NOTE_ID:1786406068924--> |

| Translate: Watch out! |
| --------------------------- |
| ¡Cuidado!<br><br><!--ANKI_NOTE_ID:1786406068926--> |

| Punctuate: No sabía nada de esto qué locura |
| -------------------------------------------------- |
| No sabía nada de esto, ¡qué locura!<br><br><!--ANKI_NOTE_ID:1786406068928--> |

| Punctuate: Ya salí de trabajar dónde nos vemos |
| ------------------------------------------------------ |
| Ya salí de trabajar, ¿dónde nos vemos?<br><br><!--ANKI_NOTE_ID:1786406068930--> |

| True or false: every Spanish exclamation needs both an opening *¡* and a closing *!*. |
| --------------------------------------------------------------------------------------------- |
| True.<br><br><!--ANKI_NOTE_ID:1786406068932--> |

| Translate: How much does it cost? |
| ---------------------------------------- |
| ¿Cuánto cuesta?<br><br><!--ANKI_NOTE_ID:1786406068935--> |

| Punctuate this reaction to surprising news: En serio |
| ------------------------------------------------------------- |
| ¡¿En serio?!<br><br><!--ANKI_NOTE_ID:1786406068937--> |

| Translate: Excuse me, do you know where the bathroom is? |
| ------------------------------------------------------------------ |
| Perdón, ¿sabes dónde queda el baño?<br><br><!--ANKI_NOTE_ID:1786406068939--> |

| What happens to the opening mark's position when only part of a sentence is a question? |
| --------------------------------------------------------------------------------------------- |
| It moves to right where the question itself begins, not to the start of the whole sentence.<br><br><!--ANKI_NOTE_ID:1786406068941--> |
