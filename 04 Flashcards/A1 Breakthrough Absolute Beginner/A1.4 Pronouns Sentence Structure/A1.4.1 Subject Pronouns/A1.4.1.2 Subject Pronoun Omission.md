| What term describes a language whose verb endings are rich enough to let you drop the subject pronoun? |
| --------------------------------------------------------------------------------------------------------------------- |
| Pro-drop<br><br><!--ANKI_NOTE_ID:1786453708471--> |

| Why can Spanish drop "yo" from "Como pan" and still mean "I eat bread"? |
| ------------------------------------------------------------------------------------------ |
| The verb ending *-o* already identifies the subject as "I" — the pronoun is extra information the listener doesn't need.<br><br><!--ANKI_NOTE_ID:1786453708475--> |

| Is stating a subject pronoun before every verb the normal way to speak Spanish, or does it sound off? |
| ----------------------------------------------------------------------------------------------------------------------- |
| It sounds off — dropping the pronoun is the normal, unmarked way to speak; stating it constantly reads as unnatural.<br><br><!--ANKI_NOTE_ID:1786453708479--> |

| Name one of the two main reasons to keep a subject pronoun in Spanish. |
| ----------------------------------------------------------------------------------------- |
| To clear up ambiguity, or to add contrast/emphasis.<br><br><!--ANKI_NOTE_ID:1786453708483--> |

| Why might you keep the pronoun with a verb conjugated for "habla"? |
| ------------------------------------------------------------------------------------- |
| *Habla* is shared by *él, ella,* and *usted* — if context doesn't make the subject clear, state the pronoun to avoid ambiguity.<br><br><!--ANKI_NOTE_ID:1786453708486--> |

| Translate, omitting the subject pronoun: I live in Bolivia. |
| ------------------------------------------------------------------------------- |
| Vivo en Bolivia.<br><br><!--ANKI_NOTE_ID:1786453708490--> |

| Translate, omitting the subject pronoun: We work on Saturdays. |
| ---------------------------------------------------------------------------------- |
| Trabajamos los sábados.<br><br><!--ANKI_NOTE_ID:1786453708493--> |

| Translate, omitting the subject pronoun: Do you speak Spanish? |
| ---------------------------------------------------------------------------------- |
| ¿Hablas español?<br><br><!--ANKI_NOTE_ID:1786453708497--> |

| Translate, keeping both pronouns for contrast: She cooks and he cleans. |
| ------------------------------------------------------------------------------------------ |
| Ella cocina y él limpia.<br><br><!--ANKI_NOTE_ID:1786453708501--> |

| Translate, keeping the pronoun for emphasis: I do want dessert, thanks. |
| ------------------------------------------------------------------------------------------ |
| Yo sí quiero postre, gracias.<br><br><!--ANKI_NOTE_ID:1786453708504--> |

| Translate, keeping the pronoun for clarity: You (formal) are from here, right? |
| ----------------------------------------------------------------------------------------------- |
| Usted es de aquí, ¿verdad?<br><br><!--ANKI_NOTE_ID:1786453708508--> |

| Fix the unnatural sentence: "Yo vivo en Lima. Yo trabajo en un banco. Yo tengo dos hijos." |
| --------------------------------------------------------------------------------------------------------- |
| Vivo en Lima. Trabajo en un banco. Tengo dos hijos. — repeating *yo* in every sentence sounds unnatural once the subject is established.<br><br><!--ANKI_NOTE_ID:1786453708511--> |

| Why does "—¿Quieres postre? —No, no quiero." repeat "no" twice? |
| ---------------------------------------------------------------------------------- |
| A negative answer to a question naturally doubles *no* — once standalone, once before the verb; it's not a mistake.<br><br><!--ANKI_NOTE_ID:1786453708514--> |

| Is dropping the subject pronoun also the default in questions, or only in statements? |
| ------------------------------------------------------------------------------------------------------- |
| Also in questions — a plain, unemphatic question like *¿Hablas español?* drops the pronoun the same way a statement does.<br><br><!--ANKI_NOTE_ID:1786453708517--> |

| Translate, choosing whether to state the pronoun: My brother doesn't drive yet. |
| ------------------------------------------------------------------------------------------------ |
| Mi hermano no maneja todavía. — the subject is already named as "mi hermano," so no separate pronoun is needed.<br><br><!--ANKI_NOTE_ID:1786453708520--> |

| Simplify this over-pronouned sentence: "Tú no hablas español, pero tú entiendes un poco." |
| -------------------------------------------------------------------------------------------------------- |
| No hablas español, pero entiendes un poco. — with no contrast between two different subjects, the repeated *tú* isn't needed.<br><br><!--ANKI_NOTE_ID:1786453708523--> |
