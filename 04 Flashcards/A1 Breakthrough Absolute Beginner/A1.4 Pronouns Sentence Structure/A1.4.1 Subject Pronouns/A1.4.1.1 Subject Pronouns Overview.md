| What is the subject pronoun for "I"? |
| ------------------------------------------------- |
| yo<br><br><!--ANKI_NOTE_ID:1786453702107--> |

| What is the informal subject pronoun for "you" (singular)? |
| -------------------------------------------------------------------------- |
| tú<br><br><!--ANKI_NOTE_ID:1786453702111--> |

| What is the formal subject pronoun for "you" (singular)? |
| ------------------------------------------------------------------------ |
| usted<br><br><!--ANKI_NOTE_ID:1786453702114--> |

| What is the only plural "you" pronoun used in Latin American Spanish? |
| ----------------------------------------------------------------------------------- |
| ustedes<br><br><!--ANKI_NOTE_ID:1786453702118--> |

| What pronoun does Spain use for informal plural "you" that Latin American Spanish does not use? |
| ------------------------------------------------------------------------------------------------------------- |
| vosotros/vosotras<br><br><!--ANKI_NOTE_ID:1786453702122--> |

| When does "nosotros" become "nosotras"? |
| -------------------------------------------------- |
| When the group being referred to is all female.<br><br><!--ANKI_NOTE_ID:1786453702125--> |

| What verb form do "usted" and "ustedes" take — the same as which other pronouns? |
| -------------------------------------------------------------------------------------------------- |
| The same forms as *él/ella* (for usted) and *ellos/ellas* (for ustedes).<br><br><!--ANKI_NOTE_ID:1786453702128--> |

| Translate, stating the pronoun for emphasis: I work at a hospital. |
| ----------------------------------------------------------------------------------- |
| Yo trabajo en un hospital.<br><br><!--ANKI_NOTE_ID:1786453702131--> |

| Translate, stating the pronoun for emphasis: Do you (informal) live near here? |
| --------------------------------------------------------------------------------------------- |
| ¿Tú vives cerca de aquí?<br><br><!--ANKI_NOTE_ID:1786453702134--> |

| Translate: You (formal) are very kind. |
| ------------------------------------------------- |
| Usted es muy amable.<br><br><!--ANKI_NOTE_ID:1786453702137--> |

| Translate, stating the pronoun for emphasis: We are sisters. |
| ------------------------------------------------------------------------------ |
| Nosotras somos hermanas.<br><br><!--ANKI_NOTE_ID:1786453702140--> |

| Translate, stating the pronoun for emphasis: They (masculine/mixed group) arrive tomorrow. |
| -------------------------------------------------------------------------------------------------------- |
| Ellos llegan mañana.<br><br><!--ANKI_NOTE_ID:1786453702143--> |

| Why would you use *tú* instead of *usted* with a new friend your own age? |
| -------------------------------------------------------------------------------------------- |
| *Tú* is the informal register, used with friends, family, and peers — *usted* is reserved for formal or respectful address.<br><br><!--ANKI_NOTE_ID:1786453702147--> |

| Fix the register error: greeting your new boss with "¿Tú tienes tiempo?" |
| ------------------------------------------------------------------------------------------ |
| ¿Usted tiene tiempo? — a new boss calls for the formal *usted*, not the informal *tú*.<br><br><!--ANKI_NOTE_ID:1786453702151--> |

| Why is there no separate Spanish subject pronoun for "it"? |
| ------------------------------------------------------------------------- |
| Spanish either drops the subject entirely or uses *él/ella* if standing in for a specific masculine or feminine noun — there's no neutral "it."<br><br><!--ANKI_NOTE_ID:1786453702155--> |

| Fix the dialect error: a Mexican learner writes "vosotros vivís aquí" to mean "you all live here." |
| ---------------------------------------------------------------------------------------------------------------- |
| Ustedes viven aquí — Latin American Spanish uses *ustedes* for plural "you" in every register; *vosotros* is a Spain-only form.<br><br><!--ANKI_NOTE_ID:1786453702159--> |

| Translate, stating the pronoun for emphasis: Do you all (plural) want coffee? |
| -------------------------------------------------------------------------------------------- |
| ¿Ustedes quieren café?<br><br><!--ANKI_NOTE_ID:1786453702162--> |

| Translate, stating the pronoun for emphasis: We (all-male group) live near here. |
| ------------------------------------------------------------------------------------------------- |
| Nosotros vivimos cerca de aquí.<br><br><!--ANKI_NOTE_ID:1786453702166--> |
