| Is stacking "no" with a negative word like "nada" a mistake in Spanish, the way it is in English? |
| ------------------------------------------------------------------------------------------------------------------- |
| No — it's required. *No tengo nada* ("I don't have anything") is the normal, correct way to say it.<br><br><!--ANKI_NOTE_ID:1786453742197--> |

| What is the basic pattern for combining "no" with a negative word? |
| -------------------------------------------------------------------------------------- |
| No + verb + negative word — e.g. *No conozco a nadie aquí.*<br><br><!--ANKI_NOTE_ID:1786453742201--> |

| What is the rule for when you can drop "no" entirely from a negative sentence? |
| ----------------------------------------------------------------------------------------------- |
| When the negative word itself comes before the verb — one negative marker up front is enough.<br><br><!--ANKI_NOTE_ID:1786453742204--> |

| Rewrite without "no": "No vino nadie." |
| ------------------------------------------------------- |
| Nadie vino.<br><br><!--ANKI_NOTE_ID:1786453742207--> |

| Translate, negative word after the verb: I've never traveled to Europe. |
| ------------------------------------------------------------------------------------------ |
| No he viajado nunca a Europa.<br><br><!--ANKI_NOTE_ID:1786453742210--> |

| Translate, negative word before the verb, no "no": I've never traveled to Europe. |
| -------------------------------------------------------------------------------------------------- |
| Nunca he viajado a Europa.<br><br><!--ANKI_NOTE_ID:1786453742213--> |

| What does "tampoco" mean, and where does it typically appear? |
| ------------------------------------------------------------------------------- |
| "Neither/either" — used to agree with a negative statement, e.g. *A mí tampoco me gusta.*<br><br><!--ANKI_NOTE_ID:1786453742216--> |

| Translate: There's nobody in the office. |
| ------------------------------------------------------------- |
| No hay nadie en la oficina.<br><br><!--ANKI_NOTE_ID:1786453742219--> |

| Fix the agreement error: "No tengo ningún idea." |
| ------------------------------------------------------------- |
| No tengo ninguna idea — *ningún* must agree in gender with *idea* (feminine): *ninguna*.<br><br><!--ANKI_NOTE_ID:1786453742221--> |

| Before what kind of noun does "ningún" drop its final -o, the same way "un" does? |
| -------------------------------------------------------------------------------------------------- |
| A masculine singular noun — e.g. *ningún problema*.<br><br><!--ANKI_NOTE_ID:1786453742224--> |

| Translate: I don't have any problem with that. |
| --------------------------------------------------------------- |
| No tengo ningún problema con eso.<br><br><!--ANKI_NOTE_ID:1786453742226--> |

| Translate: I never tell anybody anything. |
| ------------------------------------------------------------ |
| Nunca le digo nada a nadie.<br><br><!--ANKI_NOTE_ID:1786453742229--> |

| Fix the redundancy error: "No nadie vino a la fiesta." |
| ------------------------------------------------------------------------- |
| Nadie vino a la fiesta — drop *no* since *nadie* already leads the sentence.<br><br><!--ANKI_NOTE_ID:1786453742231--> |

| Translate: Nobody knows the answer. |
| ------------------------------------------------------------ |
| Nadie sabe la respuesta.<br><br><!--ANKI_NOTE_ID:1786453742233--> |

| How many negative words can appear in a single Spanish sentence? |
| ------------------------------------------------------------------------------- |
| More than one — e.g. *Nunca le digo nada a nadie* stacks three.<br><br><!--ANKI_NOTE_ID:1786453742236--> |

| Translate, agreeing with a negative statement: I don't like cold coffee either. |
| ------------------------------------------------------------------------------------------------ |
| A mí tampoco me gusta el café frío.<br><br><!--ANKI_NOTE_ID:1786453742238--> |
