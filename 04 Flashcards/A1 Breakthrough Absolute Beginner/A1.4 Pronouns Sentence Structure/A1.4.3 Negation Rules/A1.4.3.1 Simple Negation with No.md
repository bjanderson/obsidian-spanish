#anki/Spanish/A1-Breakthrough-Absolute-Beginner/A1-4-Pronouns-Sentence-Structure/A1-4-3-Negation-Rules/A1-4-3-1-Simple-Negation-with-No

| Where does "no" go to make a Spanish sentence negative? |
| ------------------------------------------------------------------------- |
| Directly before the conjugated verb.<br><br><!--ANKI_NOTE_ID:1786453736222--> |

| Fix the word order error: "Hablo no inglés." |
| ------------------------------------------------------------- |
| No hablo inglés — *no* must come before the verb, never after it.<br><br><!--ANKI_NOTE_ID:1786453736226--> |

| Does Spanish have an equivalent of the English contraction "don't"? |
| ------------------------------------------------------------------------------------ |
| No — *no* always stays a separate word placed in front of the verb.<br><br><!--ANKI_NOTE_ID:1786453736229--> |

| Translate: I don't understand the question. |
| -------------------------------------------------------------- |
| No entiendo la pregunta.<br><br><!--ANKI_NOTE_ID:1786453736233--> |

| Translate: We can't go out today. |
| ------------------------------------------------ |
| No podemos salir hoy.<br><br><!--ANKI_NOTE_ID:1786453736236--> |

| Translate, with a stated subject: My brother doesn't drive yet. |
| --------------------------------------------------------------------------------- |
| Mi hermano no maneja todavía.<br><br><!--ANKI_NOTE_ID:1786453736240--> |

| Where does "no" go relative to a stated subject, like in "Ella no vive aquí"? |
| -------------------------------------------------------------------------------------------- |
| After the subject, immediately before the verb.<br><br><!--ANKI_NOTE_ID:1786453736243--> |

| Translate: You all don't work on Sundays. |
| ------------------------------------------------------------ |
| Ustedes no trabajan los domingos.<br><br><!--ANKI_NOTE_ID:1786453736246--> |

| Why does a natural negative answer to a question often use "no" twice, as in "—¿Vienes? —No, no puedo"? |
| ------------------------------------------------------------------------------------------------------------------------- |
| It's normal, not redundant — the first *no* is the standalone answer, the second is the negation marker before the verb.<br><br><!--ANKI_NOTE_ID:1786453736250--> |

| Is it correct to shorten "No, no quiero" to just "No, quiero" to avoid repeating "no"? |
| ------------------------------------------------------------------------------------------------------- |
| No — both *no*s are needed; cutting the second one changes the meaning to an affirmative.<br><br><!--ANKI_NOTE_ID:1786453736253--> |

| Translate as a negative question: Aren't you hungry? |
| ------------------------------------------------------------------- |
| ¿No tienes hambre?<br><br><!--ANKI_NOTE_ID:1786453736256--> |

| What does this lesson's basic no + verb pattern set up for the next lesson on negative words like nada/nadie/nunca? |
| ----------------------------------------------------------------------------------------------------------------------------------- |
| The negative words combine with this same *no* + verb pattern, adding the negative word after the verb — see [[A1.4.3.2 Double Negatives]].<br><br><!--ANKI_NOTE_ID:1786453736260--> |

| Translate: We haven't talked much lately. |
| ------------------------------------------------------------ |
| No hablamos mucho últimamente.<br><br><!--ANKI_NOTE_ID:1786453736263--> |

| Fix the error: "No, quiero" as an answer meaning "No, I don't want to." |
| ------------------------------------------------------------------------------------------ |
| No, no quiero — a negative answer needs *no* before the verb as well as the standalone *no*.<br><br><!--ANKI_NOTE_ID:1786453736266--> |
