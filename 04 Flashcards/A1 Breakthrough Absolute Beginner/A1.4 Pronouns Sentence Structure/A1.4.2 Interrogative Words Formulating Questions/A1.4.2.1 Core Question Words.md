| What mark does every Spanish question word carry, even when its unaccented twin means something else? |
| -------------------------------------------------------------------------------------------------------------------- |
| A written accent mark.<br><br><!--ANKI_NOTE_ID:1786453715245--> |

| Explain the difference between "como" and "cómo." |
| ------------------------------------------------------------------ |
| *Como* (no accent) means "like/as"; *cómo* (with accent) means "how" — the accent marks it as a question word.<br><br><!--ANKI_NOTE_ID:1786453715249--> |

| Fix the error: "¿Que quieres comer?" |
| ------------------------------------------------- |
| ¿Qué quieres comer? — question words always carry a written accent.<br><br><!--ANKI_NOTE_ID:1786453715254--> |

| Explain the difference between "por qué" and "porque." |
| ------------------------------------------------------------------------ |
| *Por qué* (two words, accented) means "why"; *porque* (one word) means "because."<br><br><!--ANKI_NOTE_ID:1786453715258--> |

| How does "cuánto" change when the following noun is plural and feminine? |
| -------------------------------------------------------------------------------------------- |
| It becomes *cuántas* — *cuánto* agrees in gender and number with the noun that follows it.<br><br><!--ANKI_NOTE_ID:1786453715262--> |

| Fix the agreement error: "¿Cuánto hermanas tienes?" |
| ------------------------------------------------------------------ |
| ¿Cuántas hermanas tienes? — *cuánto* must agree with the feminine plural noun *hermanas*.<br><br><!--ANKI_NOTE_ID:1786453715266--> |

| Translate: How much does this ticket cost? |
| ----------------------------------------------------------- |

| Translate: Why aren't you coming to the party? |
| --------------------------------------------------------------- |
| ¿Por qué no vienes a la fiesta?<br><br><!--ANKI_NOTE_ID:1786453715280--> |

| Do Spanish question words still carry their accent inside an indirect question with no question marks, like "No sé dónde está"? |
| ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Yes — *dónde* keeps its accent even without question marks, since the accent marks the word itself as interrogative.<br><br><!--ANKI_NOTE_ID:1786453715282--> |
