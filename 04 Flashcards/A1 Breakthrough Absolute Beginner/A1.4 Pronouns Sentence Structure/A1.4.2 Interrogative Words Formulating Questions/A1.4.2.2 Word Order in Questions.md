| What is the required word order once a question word starts a Spanish question, if the subject is stated? |
| ---------------------------------------------------------------------------------------------------------------------------- |
| Question word + verb + subject.<br><br><!--ANKI_NOTE_ID:1786453722596--> |

| Does Spanish use a helper verb like English "do" to form questions? |
| ------------------------------------------------------------------------------------- |
| No — Spanish has no equivalent; the verb itself moves instead of inserting a helper word.<br><br><!--ANKI_NOTE_ID:1786453722600--> |

| Fix the word order error: "¿Dónde tu hermano vive?" |
| ------------------------------------------------------------------ |
| ¿Dónde vive tu hermano? — the subject must come after the verb once a question word starts the sentence.<br><br><!--ANKI_NOTE_ID:1786453722603--> |

| Translate: Where does your dad work? |
| ------------------------------------------------- |
| ¿Dónde trabaja tu papá?<br><br><!--ANKI_NOTE_ID:1786453722606--> |

| Translate: What time does the movie start? |
| ----------------------------------------------------------- |
| ¿A qué hora empieza la película?<br><br><!--ANKI_NOTE_ID:1786453722608--> |

| For a plain yes/no question with no question word, is inverting the subject and verb required? |
| ------------------------------------------------------------------------------------------------------------------- |
| No — both inverted and non-inverted order are natural; *¿Tú hablas español?* and *¿Hablas tú español?* are both correct.<br><br><!--ANKI_NOTE_ID:1786453722611--> |

| Translate, dropping the subject: Are you coming to the meeting tomorrow? |
| ------------------------------------------------------------------------------------------- |
| ¿Vienes a la reunión mañana?<br><br><!--ANKI_NOTE_ID:1786453722613--> |

| What two punctuation marks does every written Spanish question need? |
| -------------------------------------------------------------------------------------- |
| An inverted question mark (¿) at the start and a regular one (?) at the end.<br><br><!--ANKI_NOTE_ID:1786453722616--> |

| Fix the punctuation error: "Habla usted inglés?" |
| --------------------------------------------------------------- |
| ¿Habla usted inglés? — Spanish needs the opening ¿ as well as the closing ?.<br><br><!--ANKI_NOTE_ID:1786453722618--> |

| Translate, with the subject after the verb: Do you all have time today? |
| ------------------------------------------------------------------------------------------ |
| ¿Tienen ustedes tiempo hoy?<br><br><!--ANKI_NOTE_ID:1786453722620--> |

| Translate: When does your flight arrive? |
| --------------------------------------------------------- |
| ¿Cuándo llega tu vuelo?<br><br><!--ANKI_NOTE_ID:1786453722623--> |

| Why does "¿A qué hora cierra la tienda?" put "la tienda" after the verb "cierra"? |
| -------------------------------------------------------------------------------------------------- |
| Once a question phrase starts the sentence, even a full noun-phrase subject comes after the verb, not before it.<br><br><!--ANKI_NOTE_ID:1786453722625--> |

| Turn this statement into a question asking "where": "Tu hermano vive en La Paz." |
| ------------------------------------------------------------------------------------------------- |
| ¿Dónde vive tu hermano?<br><br><!--ANKI_NOTE_ID:1786453722628--> |

| Turn this statement into a yes/no question: "Usted habla inglés." |
| ----------------------------------------------------------------------------------- |
| ¿Habla usted inglés?<br><br><!--ANKI_NOTE_ID:1786453722631--> |

| Is subject-verb inversion optional or required when a question word is present? |
| ------------------------------------------------------------------------------------------------- |
| Required — unlike plain yes/no questions, a question word forces the subject after the verb.<br><br><!--ANKI_NOTE_ID:1786453722634--> |
