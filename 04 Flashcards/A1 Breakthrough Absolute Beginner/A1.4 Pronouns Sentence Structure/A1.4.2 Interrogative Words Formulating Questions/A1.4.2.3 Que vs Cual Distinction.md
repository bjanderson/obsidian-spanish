#anki/Spanish/A1-Breakthrough-Absolute-Beginner/A1-4-Pronouns-Sentence-Structure/A1-4-2-Interrogative-Words-Formulating-Questions/A1-4-2-3-Que-vs-Cual-Distinction

| Which word do you use to ask for a definition or explanation: qué or cuál? |
| -------------------------------------------------------------------------------------------- |
| Qué — e.g. *¿Qué es un contrato?* ("What is a contract?").<br><br><!--ANKI_NOTE_ID:1786453730272--> |

| Which word do you use to ask someone to pick one option from a set: qué or cuál? |
| ----------------------------------------------------------------------------------------------------- |
| Cuál — e.g. *¿Cuál prefieres?* ("Which one do you prefer?").<br><br><!--ANKI_NOTE_ID:1786453730275--> |

| Which word normally goes directly before a noun in neutral Spanish: qué or cuál? |
| ----------------------------------------------------------------------------------------------------- |
| Qué — e.g. *¿Qué libro lees?* ("What book are you reading?").<br><br><!--ANKI_NOTE_ID:1786453730278--> |

| Translate, asking for a definition: What is inflation? |
| ------------------------------------------------------------------------ |
| ¿Qué es la inflación?<br><br><!--ANKI_NOTE_ID:1786453730281--> |

| Translate, asking for a specific answer: What is your name? |
| ----------------------------------------------------------------------------- |
| ¿Cuál es tu nombre?<br><br><!--ANKI_NOTE_ID:1786453730284--> |

| Why does "¿Cuál es tu nombre?" use cuál instead of qué? |
| -------------------------------------------------------------------------- |
| Asking for a name is asking for a specific answer from a set of possibilities, not a definition — that's the *cuál* pattern before *ser*.<br><br><!--ANKI_NOTE_ID:1786453730287--> |

| Fix the error: "¿Qué es tu número de teléfono?" |
| ------------------------------------------------------------------ |
| ¿Cuál es tu número de teléfono? — a phone number is a specific-answer question, so it needs *cuál*, not *qué*.<br><br><!--ANKI_NOTE_ID:1786453730289--> |

| What preposition pairs naturally with cuál/cuáles to narrow a set explicitly? |
| -------------------------------------------------------------------------------------------------- |
| De — e.g. *¿Cuál de los dos quieres?* ("Which of the two do you want?").<br><br><!--ANKI_NOTE_ID:1786453730292--> |

| Translate, choosing from an explicit set: Which of these cars do you prefer? |
| ------------------------------------------------------------------------------------------------- |
| ¿Cuál de estos carros prefieres?<br><br><!--ANKI_NOTE_ID:1786453730296--> |

| Fix the error: "¿Cuál libro lees?" |
| --------------------------------------------------- |
| ¿Qué libro lees? — directly before a noun, *qué* is the neutral choice, not *cuál*.<br><br><!--ANKI_NOTE_ID:1786453730299--> |

| What is the plural form of cuál, and when do you use it? |
| ------------------------------------------------------------------------- |
| Cuáles — used when the expected answer involves more than one item, e.g. *¿Cuáles son tus platillos favoritos?*<br><br><!--ANKI_NOTE_ID:1786453730302--> |

| Translate: What is a noun? |
| ------------------------------------------ |
| ¿Qué es un sustantivo?<br><br><!--ANKI_NOTE_ID:1786453730306--> |

| Translate: What are your plans for the weekend? |
| -------------------------------------------------------------------- |
| ¿Cuáles son tus planes para el fin de semana?<br><br><!--ANKI_NOTE_ID:1786453730309--> |

| When asking "¿Qué es el amor?" vs. "¿Cuál es tu color favorito?", what's the underlying distinction being tested? |
| ----------------------------------------------------------------------------------------------------------------------------------- |
| *Qué* + *ser* asks for a definition ("what is love"); *cuál* + *ser* asks for a specific answer from a set ("which color, of all colors, is yours").<br><br><!--ANKI_NOTE_ID:1786453730313--> |
