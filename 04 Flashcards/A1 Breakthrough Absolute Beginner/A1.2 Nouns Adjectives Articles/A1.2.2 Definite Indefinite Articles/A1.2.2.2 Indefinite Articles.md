| Which indefinite article goes with a singular masculine noun? |
| ------------------------------------------------------------------ |
| *un*, like *un libro*.<br><br><!--ANKI_NOTE_ID:1786407688366--> |

| Which indefinite article goes with a singular feminine noun? |
| ------------------------------------------------------------------ |
| *una*, like *una mesa*.<br><br><!--ANKI_NOTE_ID:1786407688370--> |

| Which indefinite article goes with a plural masculine noun? |
| ----------------------------------------------------------------- |
| *unos*, like *unos libros* ("some books").<br><br><!--ANKI_NOTE_ID:1786407688373--> |

| Which indefinite article goes with a plural feminine noun? |
| ---------------------------------------------------------------- |
| *unas*, like *unas mesas* ("some tables").<br><br><!--ANKI_NOTE_ID:1786407688376--> |

| Translate: I have a dog. |
| --------------------------------- |
| Tengo un perro.<br><br><!--ANKI_NOTE_ID:1786407688380--> |

| Translate: I bought a new shirt. |
| ------------------------------------------ |
| Compré una camisa nueva.<br><br><!--ANKI_NOTE_ID:1786407688384--> |

| Translate: There are some books on the table. |
| -------------------------------------------------------- |
| Hay unos libros en la mesa.<br><br><!--ANKI_NOTE_ID:1786407688387--> |

| What can *unos/unas* mean besides "some"? |
| --------------------------------------------------- |
| "About" or "approximately," as in *unos veinte minutos* (about twenty minutes).<br><br><!--ANKI_NOTE_ID:1786407688390--> |

| Translate: They're arriving in about ten minutes. |
| ------------------------------------------------------------ |
| Llegan en unos diez minutos.<br><br><!--ANKI_NOTE_ID:1786407688393--> |

| Fill in the blank: Necesito ___ ideas. (some ideas) |
| ---------------------------------------------------------------- |
| unas<br><br><!--ANKI_NOTE_ID:1786407688396--> |

| Fill in the blank: Vive en ___ apartamento pequeño. |
| ---------------------------------------------------------------- |
| un<br><br><!--ANKI_NOTE_ID:1786407688399--> |

| What is the main new piece indefinite articles add beyond the singular *un/una* you already know from definite articles? |
| ---------------------------------------------------------------------------------------------------------------------------------- |
| The plural forms *unos/unas*, meaning "some" (or "about" with numbers) — English doesn't have one direct equivalent word.<br><br><!--ANKI_NOTE_ID:1786407688402--> |
