| Translate: I'm a teacher. |
| ---------------------------------- |
| Soy profesor(a).<br><br><!--ANKI_NOTE_ID:1786407688414--> |

| Why doesn't "Soy profesor" need *un*? |
| ------------------------------------------------ |
| Spanish drops the indefinite article for an unmodified profession, nationality, or religion right after *ser*.<br><br><!--ANKI_NOTE_ID:1786407688417--> |

| Translate: I'm an excellent teacher. |
| ------------------------------------------------- |
| Soy un(a) profesor(a) excelente.<br><br><!--ANKI_NOTE_ID:1786407688419--> |

| Why does *un* return in "Soy un profesor excelente" but not in "Soy profesor"? |
| ---------------------------------------------------------------------------------------- |
| The article comes back as soon as an adjective describes the noun — now you're picking one out of a group, not just naming a category.<br><br><!--ANKI_NOTE_ID:1786407688422--> |

| Fix the sentence: Soy un enfermera. |
| ---------------------------------------------- |
| Soy enfermera.<br><br><!--ANKI_NOTE_ID:1786407688425--> |

| Fix the sentence: Es doctora muy dedicada. |
| ------------------------------------------------------- |
| Es una doctora muy dedicada.<br><br><!--ANKI_NOTE_ID:1786407688428--> |

| Translate: She's Colombian. |
| ------------------------------------- |
| Es colombiana.<br><br><!--ANKI_NOTE_ID:1786407688430--> |

| Translate: We left without an umbrella. |
| ---------------------------------------------------- |
| Salimos sin paraguas.<br><br><!--ANKI_NOTE_ID:1786407688432--> |

| Does "sin paraguas" need *un* before *paraguas*? |
| ------------------------------------------------------------ |
| No — Spanish commonly drops the article after *sin* when the noun is unspecified.<br><br><!--ANKI_NOTE_ID:1786407688435--> |

| Fill in the blank: ¿Tienes ___ carro? (casual, "Do you have a car?") |
| ------------------------------------------------------------------------------ |
| (no article) — ¿Tienes carro?<br><br><!--ANKI_NOTE_ID:1786407688437--> |

| Translate: He's an excellent engineer. |
| ----------------------------------------------- |
| Es un ingeniero excelente.<br><br><!--ANKI_NOTE_ID:1786407688439--> |

| True or false: Spanish always uses *un/una* before a profession, just like English uses "a." |
| ------------------------------------------------------------------------------------------------------ |
| False — Spanish drops it for an unmodified profession right after *ser*.<br><br><!--ANKI_NOTE_ID:1786407688442--> |
