| Which definite article goes with a singular masculine noun? |
| --------------------------------------------------------------- |
| *el*, like *el libro*.<br><br><!--ANKI_NOTE_ID:1786407688313--> |

| Which definite article goes with a singular feminine noun? |
| -------------------------------------------------------------- |
| *la*, like *la mesa*.<br><br><!--ANKI_NOTE_ID:1786407688316--> |

| Which definite article goes with a plural masculine noun? |
| ------------------------------------------------------------- |
| *los*, like *los libros*.<br><br><!--ANKI_NOTE_ID:1786407688319--> |

| Which definite article goes with a plural feminine noun? |
| ------------------------------------------------------------ |
| *las*, like *las mesas*.<br><br><!--ANKI_NOTE_ID:1786407688321--> |

| Translate: I like classical music. |
| ----------------------------------------- |
| Me gusta la música clásica.<br><br><!--ANKI_NOTE_ID:1786407688324--> |

| Why does *la música* need an article here, when English drops "the"? |
| ------------------------------------------------------------------------------ |
| Spanish uses the definite article for general categories, even where English doesn't.<br><br><!--ANKI_NOTE_ID:1786407688327--> |

| Fill in the blank: Nos vemos ___ lunes. (on Monday) |
| ------------------------------------------------------------ |
| el<br><br><!--ANKI_NOTE_ID:1786407688329--> |

| Fill in the blank: Hoy es ___ lunes. (Today is Monday.) |
| ------------------------------------------------------------------ |
| (no article) — Hoy es lunes.<br><br><!--ANKI_NOTE_ID:1786407688331--> |

| Why does "Hoy es lunes" have no article, but "Nos vemos el lunes" does? |
| -------------------------------------------------------------------------------- |
| Days of the week take the article for a specific/recurring event, but not right after *ser*.<br><br><!--ANKI_NOTE_ID:1786407688333--> |

| --------------------------------------------------------- |
| El libro está en la mesa.<br><br><!--ANKI_NOTE_ID:1786407688340--> |
