| Does *naranja* (orange) change for gender or number? |
| -------------------------------------------------------------- |
| No — it's fully invariable: *una camisa naranja, unas camisas naranja*.<br><br><!--ANKI_NOTE_ID:1786407688566--> |

| Fix the mistake: unas camisas naranjas |
| --------------------------------------------------- |
| unas camisas naranja<br><br><!--ANKI_NOTE_ID:1786407688569--> |

| What Spanish word is the common, safe choice for "brown" in neutral Latin American speech? |
| -------------------------------------------------------------------------------------------------- |
| *café*<br><br><!--ANKI_NOTE_ID:1786407688573--> |

| Does *café* change for gender or number when describing a noun? |
| ------------------------------------------------------------------------- |
| No — it stays the same: *los zapatos café*.<br><br><!--ANKI_NOTE_ID:1786407688576--> |

| What construction always avoids color-agreement problems, no matter the color? |
| ---------------------------------------------------------------------------------------- |
| *color* + [color noun], like *zapatos color café*.<br><br><!--ANKI_NOTE_ID:1786407688579--> |

| Translate: an orange shirt |
| ------------------------------------- |
| una camisa naranja<br><br><!--ANKI_NOTE_ID:1786407688582--> |

| Fill in the blank: las paredes verde ___ (light) |
| ----------------------------------------------------------- |
| claro<br><br><!--ANKI_NOTE_ID:1786407688584--> |

| Fill in the blank: el carro azul ___ (dark) |
| ------------------------------------------------------ |
| oscuro<br><br><!--ANKI_NOTE_ID:1786407688587--> |

| Do *claro* and *oscuro* change to match the noun? |
| ------------------------------------------------------------ |
| No — they stay fixed after the color they modify.<br><br><!--ANKI_NOTE_ID:1786407688590--> |

| Translate: the light green walls |
| ------------------------------------------- |
| las paredes verde claro<br><br><!--ANKI_NOTE_ID:1786407688593--> |

| Is *marrón* a regular agreeing adjective or an invariable one? |
| ------------------------------------------------------------------------ |
| Regular — it agrees normally: *marrón, marrones*.<br><br><!--ANKI_NOTE_ID:1786407688596--> |

| Which two colors from A1.2.3.1 only change for number, not gender, but are NOT part of this lesson's fully-invariable group? |
| -------------------------------------------------------------------------------------------------------------------------------------- |
| *verde* and *azul* — they still add *-s* in the plural, unlike *naranja* or *café*.<br><br><!--ANKI_NOTE_ID:1786407688599--> |
