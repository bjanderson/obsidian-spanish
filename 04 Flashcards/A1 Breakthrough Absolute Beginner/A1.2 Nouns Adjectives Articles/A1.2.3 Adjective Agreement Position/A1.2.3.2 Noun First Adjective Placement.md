| In Spanish, does the adjective usually come before or after the noun? |
| ------------------------------------------------------------------------- |
| After the noun — *el carro rojo*, not *el rojo carro*.<br><br><!--ANKI_NOTE_ID:1786407688514--> |

| Fix the word order: el rojo carro |
| -------------------------------------------- |
| el carro rojo<br><br><!--ANKI_NOTE_ID:1786407688519--> |

| Translate: a big table |
| --------------------------------- |
| una mesa grande<br><br><!--ANKI_NOTE_ID:1786407688522--> |

| Translate: an interesting book |
| ----------------------------------------- |
| un libro interesante<br><br><!--ANKI_NOTE_ID:1786407688525--> |

| Fix the word order: una interesante película |
| -------------------------------------------------------- |
| una película interesante<br><br><!--ANKI_NOTE_ID:1786407688527--> |

| Translate: a Mexican woman |
| ------------------------------------- |
| una mujer mexicana<br><br><!--ANKI_NOTE_ID:1786407688529--> |

| How do you join two adjectives that both describe the same noun? |
| -------------------------------------------------------------------------- |
| With *y*, placed after the noun: *una casa grande y bonita*.<br><br><!--ANKI_NOTE_ID:1786407688531--> |

| Translate: a big, pretty house |
| ----------------------------------------- |
| una casa grande y bonita<br><br><!--ANKI_NOTE_ID:1786407688534--> |

| Fix the word order: unos negros zapatos |
| ---------------------------------------------------- |
| unos zapatos negros<br><br><!--ANKI_NOTE_ID:1786407688536--> |

| Does the adjective still need to agree in gender/number after being placed correctly? |
| ------------------------------------------------------------------------------------------------ |
| Yes — placement and agreement are two separate rules that both apply at the same time.<br><br><!--ANKI_NOTE_ID:1786407688538--> |

| Translate: some black shoes |
| -------------------------------------- |
| unos zapatos negros<br><br><!--ANKI_NOTE_ID:1786407688540--> |
