#anki/Spanish/A1-Breakthrough-Absolute-Beginner/A1-2-Nouns-Adjectives-Articles/A1-2-1-Noun-Gender-and-Pluralization/A1-2-1-3-Pluralization-Rules

| What plural ending do vowel-ending nouns take? |
| ------------------------------------------------------ |
| Just *-s*, like *casa* → *casas*.<br><br><!--ANKI_NOTE_ID:1786407688265--> |

| What plural ending do consonant-ending nouns take? |
| ------------------------------------------------------------ |
| *-es*, like *ciudad* → *ciudades*.<br><br><!--ANKI_NOTE_ID:1786407688268--> |

| Pluralize: el papel |
| -------------------------- |
| los papeles<br><br><!--ANKI_NOTE_ID:1786407688271--> |

| Pluralize: el lápiz |
| -------------------------- |
| los lápices<br><br><!--ANKI_NOTE_ID:1786407688273--> |

| What happens to a noun ending in *-z* before adding *-es*? |
| -------------------------------------------------------------------- |
| The *z* changes to *c*: *lápiz* → *lápices*.<br><br><!--ANKI_NOTE_ID:1786407688276--> |

| Pluralize: la ciudad |
| --------------------------- |
| las ciudades<br><br><!--ANKI_NOTE_ID:1786407688279--> |

| Pluralize: el joven |
| -------------------------- |
| los jóvenes<br><br><!--ANKI_NOTE_ID:1786407688281--> |

| Why does *joven* need a written accent in its plural form *jóvenes*? |
| ---------------------------------------------------------------------------- |
| To keep the stress on the same syllable it had in the singular.<br><br><!--ANKI_NOTE_ID:1786407688283--> |

| Pluralize: la nación |
| --------------------------- |
| las naciones<br><br><!--ANKI_NOTE_ID:1786407688285--> |

| Why does *nación* lose its accent in the plural form *naciones*? |
| ---------------------------------------------------------------------- |
| Because the stress naturally falls on that syllable once *-es* is added, so the accent mark isn't needed anymore.<br><br><!--ANKI_NOTE_ID:1786407688288--> |

| Fix the plural: los ciudads |
| -------------------------------------- |
| las ciudades<br><br><!--ANKI_NOTE_ID:1786407688290--> |

| Pluralize: el coche |
| -------------------------- |
| los coches<br><br><!--ANKI_NOTE_ID:1786407688292--> |

| Pluralize: el reloj |
| -------------------------- |
| los relojes<br><br><!--ANKI_NOTE_ID:1786407688294--> |

| Fix the plural: los lapizes |
| -------------------------------------- |
| los lápices<br><br><!--ANKI_NOTE_ID:1786407688297--> |

| Does the article change along with the noun in the plural? |
| -------------------------------------------------------------------- |
| Yes — *el/la* becomes *los/las* to match.<br><br><!--ANKI_NOTE_ID:1786407688299--> |
