#anki/Spanish/A2-Waystage-Elementary/A2-4-Practical-Vocabulary-Situational-Usage/A2-4-2-Work-Professions-Weather/A2-4-2-2-Expressing-Weather

| Which verb is used for general weather traits like heat, cold, sun, and wind (*hacer*, *estar*, or *haber*)? |
| ------------------------------------------------------------------------------------------------------------------------- |
| *hacer* (e.g. *Hace calor*, *Hace frío*, *Hace sol*, *Hace viento*)<br><br><!--ANKI_NOTE_ID:1786533789548--> |

| Which verb is used for weather actively happening, like rain or snow (*hacer*, *estar*, or *haber*)? |
| --------------------------------------------------------------------------------------------------------------- |
| *estar* + gerund (e.g. *Está lloviendo*, *Está nevando*)<br><br><!--ANKI_NOTE_ID:1786533789559--> |

| Which verb is used for fog, storms, and clouds "existing" (*hacer*, *estar*, or *haber*)? |
| ------------------------------------------------------------------------------------------------- |
| *haber*, always as *hay* (e.g. *Hay niebla*, *Hay tormenta*)<br><br><!--ANKI_NOTE_ID:1786533789569--> |

| Translate: It's very hot today. |
| ------------------------------------------ |
| Hace mucho calor hoy.<br><br><!--ANKI_NOTE_ID:1786533789576--> |

| Translate: It's raining right now. |
| --------------------------------------------- |
| Está lloviendo ahora mismo.<br><br><!--ANKI_NOTE_ID:1786533789580--> |

| Translate: There's a lot of fog on the highway. |
| ------------------------------------------------------------ |
| Hay mucha niebla en la carretera.<br><br><!--ANKI_NOTE_ID:1786533789585--> |

| Translate: What's the weather like? |
| ------------------------------------------ |
| ¿Qué tiempo hace?<br><br><!--ANKI_NOTE_ID:1786533789590--> |

| Why is "*Está calor*" wrong? |
| ------------------------------------- |
| General atmospheric conditions like heat use *hacer*, not *estar*. Correct: *Hace calor*.<br><br><!--ANKI_NOTE_ID:1786533789593--> |

| Why is "*Está mucho nublado*" wrong? |
| ----------------------------------------------- |
| *Estar* + adjective weather expressions use *muy* for emphasis, not *mucho*. Correct: *Está muy nublado*.<br><br><!--ANKI_NOTE_ID:1786533789597--> |

| Why is "*Han nubes*" wrong? |
| ------------------------------------ |
| *Haber* in weather expressions always stays as the impersonal *hay*, regardless of what follows. Correct: *Hay nubes*.<br><br><!--ANKI_NOTE_ID:1786533789600--> |

| Fill in the blank: ______ mucho viento esta tarde. |
| ---------------------------------------------------------------- |
| Hace<br><br><!--ANKI_NOTE_ID:1786533789604--> |

| Fill in the blank: ______ nevando en las montañas. |
| ---------------------------------------------------------------- |
| Está<br><br><!--ANKI_NOTE_ID:1786533789608--> |

| Fill in the blank: ______ tormenta esta noche. |
| ------------------------------------------------------------ |
| Hay<br><br><!--ANKI_NOTE_ID:1786533789611--> |

| Does Spanish use *ser* for weather conditions? |
| ---------------------------------------------------------- |
| No — Spanish never uses *ser* for weather. Weather expressions use *hacer*, *estar*, or *haber* depending on the type.<br><br><!--ANKI_NOTE_ID:1786533789615--> |
