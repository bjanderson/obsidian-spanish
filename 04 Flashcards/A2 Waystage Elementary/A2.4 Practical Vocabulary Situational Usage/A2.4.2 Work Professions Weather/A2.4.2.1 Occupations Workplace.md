| Do you use an article ("un/una") with *ser* + occupation in Spanish? |
| ---------------------------------------------------------------------------------- |
| No, normally not — *Soy maestra*, not *Soy una maestra* (unless a descriptive adjective is added).<br><br><!--ANKI_NOTE_ID:1786533556547--> |

| Why is "*Contratamos el nuevo programador*" wrong? |
| ------------------------------------------------------------- |
| It's missing the personal *a* before a specific-person direct object. Correct: *Contratamos al nuevo programador*.<br><br><!--ANKI_NOTE_ID:1786533556556--> |

| What's the difference between *trabajo* and *empleo*? |
| -------------------------------------------------------------------- |
| *Trabajo* is broader (job or work as an activity); *empleo* specifically means formal employment.<br><br><!--ANKI_NOTE_ID:1786533556559--> |

| Which two common occupation words don't change form for gender, only the article does? |
| --------------------------------------------------------------------------------------------------- |
