| How do you say "ticket" in Spanish? |
| ------------------------------------------ |
| el boleto<br><br><!--ANKI_NOTE_ID:1786534198266--> |

| Why should you avoid using *billete* to mean "ticket" in Latin American Spanish? |
| ------------------------------------------------------------------------------------------- |
| *Billete* is the Spain-specific term for a ticket. In Latin America, *billete* usually means a currency bill/banknote — use *boleto* for "ticket" instead.<br><br><!--ANKI_NOTE_ID:1786534198270--> |

| How do you say "ticket window" in Spanish? |
| ------------------------------------------------------ |
| la taquilla (or la ventanilla)<br><br><!--ANKI_NOTE_ID:1786534198274--> |

| How do you say "round trip" in Spanish? |
| -------------------------------------------------- |
| ida y vuelta<br><br><!--ANKI_NOTE_ID:1786534198278--> |

| How do you say "one way" (ticket) in Spanish? |
| ---------------------------------------------------------- |
| solo de ida<br><br><!--ANKI_NOTE_ID:1786534198282--> |

| How do you say "platform" (train/bus) in Spanish? |
| ---------------------------------------------------------------- |
| el andén<br><br><!--ANKI_NOTE_ID:1786534198286--> |

| What verb means "to board" (a bus, plane, etc.)? |
| --------------------------------------------------------------- |
| abordar<br><br><!--ANKI_NOTE_ID:1786534198293--> |

| Which verb for "to take" (transportation) is the safer default across all countries, *tomar* or *coger*? |
| ----------------------------------------------------------------------------------------------------------------------- |
| *tomar* — *coger* has a vulgar meaning in some countries (Mexico, Argentina).<br><br><!--ANKI_NOTE_ID:1786534198298--> |

| What does *el camión* usually mean, and what does it mean specifically in Mexico? |
| ------------------------------------------------------------------------------------------------- |
| Usually "truck" — in Mexico, it commonly means "bus."<br><br><!--ANKI_NOTE_ID:1786534198302--> |

| Translate: What time does the next bus leave? |

| Translate: I want a round-trip ticket to Cancún. |
| ------------------------------------------------------------- |
| Quiero un boleto de ida y vuelta a Cancún.<br><br><!--ANKI_NOTE_ID:1786534198310--> |

| Translate: Where's the ticket window? |
| -------------------------------------------------- |

| Fill in the blank: El tren sale ______ andén número tres. |

| Why is "*un boleto Cancún*" incomplete? |
| ------------------------------------------------- |
| It's missing a preposition before the destination — it needs *a* or *para*: *un boleto a Cancún*.<br><br><!--ANKI_NOTE_ID:1786534198320--> |
