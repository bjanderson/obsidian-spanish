| Why is "*el desayuno está incluida*" wrong? |
| ---------------------------------------------------- |
| *Desayuno* is masculine, so the adjective must agree: *incluido*, not *incluida*.<br><br><!--ANKI_NOTE_ID:1786534426171--> |

| What's the difference between *dejar la habitación* and *dejar de* + infinitive? |
| ------------------------------------------------------------------------------------------------ |
| *Dejar la habitación* means "to check out / leave the room." *Dejar de* + infinitive means "to stop doing something" — different structures, different meanings.<br><br><!--ANKI_NOTE_ID:1786534426176--> |
