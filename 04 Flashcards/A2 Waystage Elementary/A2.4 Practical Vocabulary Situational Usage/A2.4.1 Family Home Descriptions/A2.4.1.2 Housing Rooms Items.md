| Which verb do you use to say where something is located, *ser* or *estar*? |
| ------------------------------------------------------------------------------------ |
| *estar* (e.g. *La mesa está en la cocina*)<br><br><!--ANKI_NOTE_ID:1786533036295--> |

| Why is "*La mesa es en la cocina*" wrong? |
| -------------------------------------------------- |
| Location always uses *estar*, not *ser*. Correct form: *La mesa está en la cocina*.<br><br><!--ANKI_NOTE_ID:1786533036298--> |

| Is *departamento* more common in Mexico or in Spain? |
| ---------------------------------------------------------------- |
| Mexico (and the Southern Cone) — Spain typically uses *piso* for "apartment."<br><br><!--ANKI_NOTE_ID:1786533036314--> |

| Why should you avoid using *piso* to mean "apartment" in neutral Latin American Spanish? |
| ------------------------------------------------------------------------------------------------------ |
| *Piso* meaning "apartment" is a Spain-specific usage. In Latin American Spanish, *piso* usually means "floor," and "apartment" is *apartamento* or *departamento*.<br><br><!--ANKI_NOTE_ID:1786533036316--> |
