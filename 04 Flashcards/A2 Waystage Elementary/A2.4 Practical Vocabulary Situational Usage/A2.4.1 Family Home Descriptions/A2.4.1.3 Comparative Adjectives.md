| What is the formula for "as ___ as" in Spanish? |
| --------------------------------------------------------- |

| Why is "*tan alto que*" wrong when comparing two equal heights? |
| ------------------------------------------------------------------------- |
| Equal comparisons need *como*, not *que* — *que* is only for unequal comparisons (*más/menos*). Correct: *tan alto como*.<br><br><!--ANKI_NOTE_ID:1786533311070--> |

| Why is "*Mis hermanas son más alto que yo*" wrong? |
| --------------------------------------------------------------- |
| The adjective must agree with *hermanas* (feminine plural). Correct: *más altas*.<br><br><!--ANKI_NOTE_ID:1786533311074--> |

| When should you use *mayor/menor* instead of *más grande/más pequeño*? |
| ------------------------------------------------------------------------------------ |
| *Mayor/menor* are used for comparing age (older/younger). *Más grande/más pequeño* are used for physical size.<br><br><!--ANKI_NOTE_ID:1786533311077--> |

| Fill in the blank: Este libro es menos interesante ______ el otro. |
| ------------------------------------------------------------------------------ |
| que<br><br><!--ANKI_NOTE_ID:1786533311080--> |

| Fill in the blank: Ana es tan alta ______ su hermano. |
| ------------------------------------------------------------------ |
| como<br><br><!--ANKI_NOTE_ID:1786533311083--> |

| Does the adjective in a comparison agree in gender and number with the noun it describes? |
| ------------------------------------------------------------------------------------------------------- |
| Yes — comparative adjectives still follow normal gender/number agreement rules.<br><br><!--ANKI_NOTE_ID:1786533311086--> |
