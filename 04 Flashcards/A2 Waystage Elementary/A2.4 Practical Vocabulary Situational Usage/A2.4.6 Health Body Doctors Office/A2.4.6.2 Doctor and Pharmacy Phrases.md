| What is the Spanish phrase for "to make an appointment"? |
| ---------------------------------------------------------------- |
| Sacar una cita (or pedir una cita) |

<!--ANKI_NOTE_ID:1786742993873-->

| Translate: I need to make an appointment with the doctor. |
| ------------------------------------------------------------------ |
| Necesito sacar una cita con el médico. |

<!--ANKI_NOTE_ID:1786742993883-->

| What does "desde hace" mean, and how is it used? |
| --------------------------------------------------------- |
| "For" (a duration up to now) — e.g. "Tengo tos desde hace tres días" (I've had a cough for three days). |

<!--ANKI_NOTE_ID:1786742993886-->

| Translate: Doctor, I've had a sore throat for three days. |
| ------------------------------------------------------------------ |
| Doctor, tengo dolor de garganta desde hace tres días. |

<!--ANKI_NOTE_ID:1786742993888-->

| What is the Spanish verb for "to prescribe," and its noun form "prescription"? |
| ---------------------------------------------------------------------------------------- |
| Recetar (verb); la receta (noun). |

<!--ANKI_NOTE_ID:1786742993891-->

| Translate: The doctor prescribed an antibiotic for me. |
| ---------------------------------------------------------- |
| El médico me recetó un antibiótico. |

<!--ANKI_NOTE_ID:1786742993893-->

| Fill in the blank: ______ esta medicina cada ocho horas. (formal command: "Take") |
| ------------------------------------------------------------------------------------------ |
| Tome |

<!--ANKI_NOTE_ID:1786742993895-->

| Why is "Tome" the correct command form here, not "Toma"? |
| ------------------------------------------------------------------ |
| A doctor addresses a patient formally with "usted," so the command uses the "usted" form, not the "tú" form. |

<!--ANKI_NOTE_ID:1786742993897-->

| What is the Spanish phrase for "You have to rest"? |
| ------------------------------------------------------------ |
| Tiene que descansar. |

<!--ANKI_NOTE_ID:1786742993899-->

| Translate: Do you have something for a headache? |
| --------------------------------------------------------- |
| ¿Tiene algo para el dolor de cabeza? |

<!--ANKI_NOTE_ID:1786742993900-->

| Translate: Is a prescription needed for this syrup? |
| ------------------------------------------------------------- |
| ¿Se necesita receta para este jarabe? |

<!--ANKI_NOTE_ID:1786742993902-->

| What is the Spanish word for "pill"? |
| ------------------------------------------- |
| La pastilla |

<!--ANKI_NOTE_ID:1786742993908-->

| What is the Spanish word for "syrup" (medicine)? |
| --------------------------------------------------------- |
| El jarabe |

<!--ANKI_NOTE_ID:1786742993910-->

| What is the Spanish word for "pharmacist"? |
| --------------------------------------------------- |
| El farmacéutico / la farmacéutica |

<!--ANKI_NOTE_ID:1786742993912-->

| Fill in the blank: Vengo a recoger una receta ______ nombre de Ana López. (correct preposition) |

| a |

<!--ANKI_NOTE_ID:1786742993914-->

| What is a common formal question a doctor asks to open a consultation? |
| ------------------------------------------------------------------------------- |
| ¿Qué le pasa? (What's wrong?) |
