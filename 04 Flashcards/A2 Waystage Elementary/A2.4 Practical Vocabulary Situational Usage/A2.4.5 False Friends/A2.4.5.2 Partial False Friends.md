| What does "actualmente" mean in Spanish? |
| ------------------------------------------- |
| Currently / nowadays (not "actually"). |

<!--ANKI_NOTE_ID:1786739873973-->

| What is the Spanish word or phrase for "actually"? |
| ------------------------------------------------------ |
| De hecho (or en realidad) |

<!--ANKI_NOTE_ID:1786739873984-->

| Translate: I currently live in Guadalajara. |
| ------------------------------------------------ |
| Actualmente vivo en Guadalajara. |

<!--ANKI_NOTE_ID:1786739873986-->

| Why is it wrong to translate "I realized I was late" using "realicé"? |
| --------------------------------------------------------------------------- |
| "Realizar" means to carry out/accomplish; "to realize" (become aware) is "darse cuenta de." |

<!--ANKI_NOTE_ID:1786739873988-->

| Translate: He finally fulfilled his dream of traveling through South America. |
| ------------------------------------------------------------------------------------- |
| Por fin realizó su sueño de viajar por Sudamérica. |

<!--ANKI_NOTE_ID:1786739873991-->

| Fill in the blank: Me ______ de que había olvidado las llaves. (realized) |
| -------------------------------------------------------------------------------- |
| di cuenta |

<!--ANKI_NOTE_ID:1786739873993-->

| What does "atender" mean in Spanish? |
| ----------------------------------------- |
| To attend to / assist (a customer, patient) — not "to attend" an event. |

<!--ANKI_NOTE_ID:1786739873995-->

| What is the Spanish phrase for "to attend" an event? |
| ------------------------------------------------------- |
| Asistir a |

<!--ANKI_NOTE_ID:1786739873997-->

| Translate: I'm going to attend my cousin's wedding on Saturday. |
| ------------------------------------------------------------------- |
| Voy a asistir a la boda de mi primo el sábado. |

<!--ANKI_NOTE_ID:1786739873999-->

| Why is "asistir" not the same as the English word "assist"? |
| ------------------------------------------------------------------ |
| "Asistir" means "to attend"; the Spanish word for "assist/help" is "ayudar." |

<!--ANKI_NOTE_ID:1786739874000-->

| Translate: Can you help me with this problem? |
| ---------------------------------------------------- |
| ¿Puedes ayudarme con este problema? |

<!--ANKI_NOTE_ID:1786739874002-->

| What does "introducir" mean in Spanish? |
| -------------------------------------------- |
| To insert / bring in (a topic or object) — not "to introduce" a person. |

<!--ANKI_NOTE_ID:1786739874004-->

| Translate: I introduced my friend to my parents. |
| ------------------------------------------------------ |
| Les presenté a mi amiga a mis padres. |

<!--ANKI_NOTE_ID:1786739874006-->

| In "Les presenté a mi amiga a mis padres," why are there two different "a"s? |
| --------------------------------------------------------------------------------------------------- |
| The first "a" (a mi amiga) is the personal a marking a specific-person direct object; the second "a" (a mis padres) is the preposition introducing the indirect object, matched by the clitic "les." |

<!--ANKI_NOTE_ID:1786739874008-->

| What does "discutir" usually imply in everyday Spanish? |
| --------------------------------------------------------------- |
| Arguing/conflict, not a neutral "discussion." |

<!--ANKI_NOTE_ID:1786739874010-->

| What is a more neutral way to say "let's discuss this" without implying an argument? |
| ---------------------------------------------------------------------------------------------- |
| Hablemos sobre esto / Vamos a conversar sobre esto |

<!--ANKI_NOTE_ID:1786739874012-->

| What is the Spanish word for "to record" (audio/video), since "recordar" does not mean that? |
| ------------------------------------------------------------------------------------------------------ |
| Grabar |
