| What ending do you add to the infinitive for the "yo" form in the simple future? |
| ---------------------------------------------------------------------------------- |
| -é (e.g. *hablaré*)<br><br><!--ANKI_NOTE_ID:1786530388675-->                       |

| What ending do you add to the infinitive for the "tú" form in the simple future? |
| ------------------------------------------------------------------------------------ |
| -ás (e.g. *hablarás*)<br><br><!--ANKI_NOTE_ID:1786530388686-->                        |

| What ending do you add to the infinitive for "nosotros" in the simple future? |
| ----------------------------------------------------------------------------------- |
| -emos, no written accent (e.g. *hablaremos*)<br><br><!--ANKI_NOTE_ID:1786530388694--> |

| Which future-tense form is the only one without a written accent mark? |
| -------------------------------------------------------------------------- |
| The *nosotros/nosotras* form (e.g. *hablaremos*, not *hablarémos*)<br><br><!--ANKI_NOTE_ID:1786530388696--> |

| Translate: I will speak with my boss tomorrow. |
| -------------------------------------------------- |
| Hablaré con mi jefe mañana.<br><br><!--ANKI_NOTE_ID:1786530388698--> |

| Translate: Will you eat at home tonight? (tú) |
| ------------------------------------------------- |
| ¿Comerás en casa esta noche?<br><br><!--ANKI_NOTE_ID:1786530388700--> |

| Translate: She will live in Bogotá next year. |
| ------------------------------------------------- |
| Ella vivirá en Bogotá el próximo año.<br><br><!--ANKI_NOTE_ID:1786530388702--> |

| Translate: We will study on Saturday. |
| ------------------------------------------ |
| Estudiaremos el sábado.<br><br><!--ANKI_NOTE_ID:1786530388704--> |

| Translate: My cousins will travel to Peru in July. |
| -------------------------------------------------------- |
| Mis primos viajarán a Perú en julio.<br><br><!--ANKI_NOTE_ID:1786530388705--> |

| Fill in the blank: Yo (hablar) ______ con el doctor mañana. |
| ------------------------------------------------------------------ |
| hablaré<br><br><!--ANKI_NOTE_ID:1786530388707--> |

| Fill in the blank: Nosotros (vivir) ______ en otra ciudad. |
| ------------------------------------------------------------------ |
| viviremos<br><br><!--ANKI_NOTE_ID:1786530388709--> |

| Fill in the blank: Ellos (trabajar) ______ este fin de semana. |
| ------------------------------------------------------------------------- |
| trabajarán<br><br><!--ANKI_NOTE_ID:1786530388710--> |

| Why is "*habl* + *aré*" wrong for the future tense of *hablar*? |
| ----------------------------------------------------------------------- |
| The future tense keeps the whole infinitive — you add the ending to *hablar*, not a shortened stem. Correct form: *hablaré*.<br><br><!--ANKI_NOTE_ID:1786530388712--> |

| Why is "*hablarémos*" wrong? |
| ----------------------------------- |
| The *nosotros* form never takes a written accent in the future tense. Correct form: *hablaremos*.<br><br><!--ANKI_NOTE_ID:1786530388714--> |

| Why is "*hablaras*" wrong for "you will speak"? |
| -------------------------------------------------------- |
| It's missing the accent mark, which makes it look like a different tense (imperfect subjunctive) instead of future. Correct form: *hablarás*.<br><br><!--ANKI_NOTE_ID:1786530388715--> |

| Which two tenses can also express future meaning besides the simple future? |
| ----------------------------------------------------------------------------------- |
| *Ir a* + infinitive (*voy a estudiar*) and the present tense with a time expression (*trabajo mañana*).<br><br><!--ANKI_NOTE_ID:1786530388717--> |

| Why should you avoid the simple future tense when making a polite request, like English "Will you...?" |
| --------------------------------------------------------------------------------------------------------------- |
| Spanish uses the present tense for polite requests instead (*¿Me traes otra servilleta, por favor?*) — the future tense sounds odd there.<br><br><!--ANKI_NOTE_ID:1786530388719--> |
