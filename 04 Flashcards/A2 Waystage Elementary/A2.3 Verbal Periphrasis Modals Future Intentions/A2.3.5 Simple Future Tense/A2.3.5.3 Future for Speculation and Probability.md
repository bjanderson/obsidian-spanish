#anki/Spanish/A2-Waystage-Elementary/A2-3-Verbal-Periphrasis-Modals-Future-Intentions/A2-3-5-Simple-Future-Tense/A2-3-5-3-Future-for-Speculation-and-Probability

| What is the "future of probability" used for? |
| ------------------------------------------------------ |
| Speculating or guessing about the present — not talking about a real future event.<br><br><!--ANKI_NOTE_ID:1786531010523--> |

| Translate (as a guess, not a real future plan): Who could that be? |
| ---------------------------------------------------------------------------- |
| ¿Quién será?<br><br><!--ANKI_NOTE_ID:1786531010543--> |

| Translate: She's probably at the office. |
| ------------------------------------------------ |
| Estará en la oficina.<br><br><!--ANKI_NOTE_ID:1786531010563--> |

| Translate: They're probably around thirty years old. |
| --------------------------------------------------------------- |
| Tendrán unos treinta años.<br><br><!--ANKI_NOTE_ID:1786531010565--> |

| Translate: He's not answering — he's probably busy. |
| ------------------------------------------------------------- |
| No contesta — estará ocupado.<br><br><!--ANKI_NOTE_ID:1786531010567--> |

| Which two verbs are most commonly used with the future of probability? |
| ---------------------------------------------------------------------------------- |
| *ser* and *estar*<br><br><!--ANKI_NOTE_ID:1786531010569--> |

| Why might "*Serán las tres*" mean two different things? |
| -------------------------------------------------------------------- |
| It could be a real future statement ("It will be three o'clock") or a present-tense guess ("It's probably three o'clock") — context decides which.<br><br><!--ANKI_NOTE_ID:1786531010570--> |

| What situation commonly triggers the future of probability in conversation? |
| --------------------------------------------------------------------------------------- |
| Something unexpected happening — a knock at the door, an unknown caller, an unanswered question.<br><br><!--ANKI_NOTE_ID:1786531010572--> |

| Give an alternative way to express the same idea as "*Estará ocupada*" without the future tense. |
| ---------------------------------------------------------------------------------------------------------- |
| *Debe de estar ocupada* (using *deber de* + infinitive), or *Probablemente está ocupada*.<br><br><!--ANKI_NOTE_ID:1786531010574--> |

| Fill in the blank to guess someone's age: Mi vecino ______ unos cuarenta años. (tener) |
| ------------------------------------------------------------------------------------------------- |
| tendrá<br><br><!--ANKI_NOTE_ID:1786531010576--> |

| Fill in the blank to guess why someone didn't answer: No contesta — ______ dormido. (estar) |
| -------------------------------------------------------------------------------------------------------- |
| estará<br><br><!--ANKI_NOTE_ID:1786531010578--> |

| Is the future of probability common in formal writing, or mostly in casual speech? |
| ------------------------------------------------------------------------------------------------ |
| Mostly casual, conversational speech — formal writing tends to prefer *probablemente* or *creo que*.<br><br><!--ANKI_NOTE_ID:1786531010580--> |

| Why is it a mistake to assume every future-tense sentence describes a later event? |
| ------------------------------------------------------------------------------------------------ |
| The future tense can also express a present-tense guess (the future of probability) — you need context to tell the two uses apart.<br><br><!--ANKI_NOTE_ID:1786531010582--> |
