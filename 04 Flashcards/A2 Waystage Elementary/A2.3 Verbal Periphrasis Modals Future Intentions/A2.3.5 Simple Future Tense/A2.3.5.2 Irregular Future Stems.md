| Why is "*tenerá*" wrong for the future tense of *tener*? |
| ------------------------------------------------------------------ |
| *Tener* doesn't use the full infinitive in the future — it takes the irregular stem *tendr-*. Correct form: *tendrá*.<br><br><!--ANKI_NOTE_ID:1786530701716--> |

| Why is "*decirá*" wrong for the future tense of *decir*? |
| ------------------------------------------------------------------ |
| *Decir* shortens all the way down to the stem *dir-* in the future, not the full infinitive. Correct form: *dirá*.<br><br><!--ANKI_NOTE_ID:1786530701717--> |

| Do irregular future verbs use different endings than regular future verbs? |
| ------------------------------------------------------------------------------------ |
| No — the endings (-é, -ás, -á, -emos, -án) are the same for every verb. Only the stem changes for irregular verbs.<br><br><!--ANKI_NOTE_ID:1786530701719--> |

| Which letter is inserted into the stem for *tener*, *poner*, *salir*, and *venir* in the future tense? |
| ------------------------------------------------------------------------------------------------------------------- |
| A *d* is inserted: *tendr-, pondr-, saldr-, vendr-*.<br><br><!--ANKI_NOTE_ID:1786530701721--> |
