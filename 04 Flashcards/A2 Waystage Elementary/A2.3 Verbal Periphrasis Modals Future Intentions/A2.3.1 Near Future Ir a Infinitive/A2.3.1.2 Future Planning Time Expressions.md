| In "Mañana voy a viajar" and "Voy a viajar mañana," which word order is correct? |
| -------------------------------------------------------------------------------- |
| Both — the time expression can go at the start or the end of the sentence.<br><br><!--ANKI_NOTE_ID:1786496599000--> |

| Why is "en poco" wrong for "soon"? |
| ------------------------------------- |
| The correct phrase is *dentro de poco*, not *en poco*.<br><br><!--ANKI_NOTE_ID:1786496599004--> |

| What's the difference between *pasado mañana* and *el mes pasado*? |
| -------------------------------------------------------------------- |
| *Pasado mañana* means "the day after tomorrow"; *el mes pasado* means "last month" — *pasado* changes meaning with word order.<br><br><!--ANKI_NOTE_ID:1786496599007--> |
