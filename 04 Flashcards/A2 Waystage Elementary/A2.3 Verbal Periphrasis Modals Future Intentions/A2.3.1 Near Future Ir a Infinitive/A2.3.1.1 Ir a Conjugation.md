| Why is "Voy a como" incorrect? |
| --------------------------------- |
| The verb after *a* must stay in the infinitive (*comer*), not be conjugated.<br><br><!--ANKI_NOTE_ID:1786496372850--> |

| Why is "Voy comer" incorrect? |
| -------------------------------- |
| It is missing the required *a* between *ir* and the infinitive.<br><br><!--ANKI_NOTE_ID:1786496372856--> |

| In "Voy a descansar," why is there no subject pronoun before "voy"? |
| ------------------------------------------------------------------- |
| The *ir* conjugation already shows the subject is *yo*, so the pronoun is dropped in normal speech.<br><br><!--ANKI_NOTE_ID:1786496372861--> |

| Translate: What are you all going to do tomorrow? |
| ---------------------------------------------------- |
| ¿Qué van a hacer ustedes mañana?<br><br><!--ANKI_NOTE_ID:1786496372866--> |

| Does the infinitive after *ir a* change to match the subject? |
| ------------------------------------------------------------- |
| No — the infinitive never changes, no matter the subject.<br><br><!--ANKI_NOTE_ID:1786496372870--> |
