#anki/Spanish/A2-Waystage-Elementary/A2-3-Verbal-Periphrasis-Modals-Future-Intentions/A2-3-4-Verbs-Like-Gustar-Emotional-Expression/A2-3-4-2-Other-Indirect-Verbs-Encantar-Doler

| What does *encantar* mean, and how is it stronger than *gustar*? |
| ------------------------------------------------------------------------ |
| "To love / to be delighted by" — it expresses a stronger feeling than *gustar* ("to like").<br><br><!--ANKI_NOTE_ID:1786498002559--> |

| What does *doler* mean? |
| -------------------------------- |
| to hurt, to be painful<br><br><!--ANKI_NOTE_ID:1786498002561--> |

| What does *importar* mean? |
| ------------------------------------- |
| to matter, to care about<br><br><!--ANKI_NOTE_ID:1786498002564--> |

| What does *faltar* mean? |
| ----------------------------------- |
| to lack, to be missing/needed<br><br><!--ANKI_NOTE_ID:1786498002566--> |

| What formula do *encantar*, *doler*, *importar*, and *faltar* all follow? |
| ---------------------------------------------------------------------------------- |
| Same as *gustar*: [indirect pronoun] + verb form + [thing(s)]<br><br><!--ANKI_NOTE_ID:1786498002569--> |

| Fill in the blank: Me ______ el chocolate. (encantar) |
| ------------------------------------------------------------------ |
| encanta<br><br><!--ANKI_NOTE_ID:1786498002571--> |

| Fill in the blank: ¿Te ______ los pies? (doler) |
| ------------------------------------------------------------ |
| duelen<br><br><!--ANKI_NOTE_ID:1786498002574--> |

| Fill in the blank: No me ______ el precio. (importar) |
| ------------------------------------------------------------------- |
| importa<br><br><!--ANKI_NOTE_ID:1786498002576--> |

| Fill in the blank: Nos ______ dos sillas. (faltar) |
| ------------------------------------------------------------ |
| faltan<br><br><!--ANKI_NOTE_ID:1786498002579--> |

| Translate: I love this song. |
| ------------------------------------- |
| Me encanta esta canción.<br><br><!--ANKI_NOTE_ID:1786498002582--> |

| Translate: My throat hurts. |
| -------------------------------------- |
| Me duele la garganta.<br><br><!--ANKI_NOTE_ID:1786498002584--> |

| Translate: Your opinion matters a lot to me. |
| --------------------------------------------------------- |
| Me importa mucho tu opinión.<br><br><!--ANKI_NOTE_ID:1786498002586--> |

| Translate: We're short on time. |
| ------------------------------------------ |
| Nos falta tiempo.<br><br><!--ANKI_NOTE_ID:1786498002589--> |

| Why is "Me duele las piernas" incorrect? |
| ------------------------------------------------- |
| *Piernas* is plural, so the verb must also be plural: *Me duelen las piernas*.<br><br><!--ANKI_NOTE_ID:1786498002591--> |

| What's the difference between *faltar* and *perder*? |
| ------------------------------------------------------------------ |
| *Faltar* means something is missing/lacking; *perder* means to lose something you once had.<br><br><!--ANKI_NOTE_ID:1786498002593--> |

| Translate: Do your eyes hurt? |
| --------------------------------------- |
| ¿Te duelen los ojos?<br><br><!--ANKI_NOTE_ID:1786498002596--> |

| Translate: My parents love traveling. |
| ---------------------------------------------- |
| A mis papás les encantan los viajes.<br><br><!--ANKI_NOTE_ID:1786498002598--> |

| Can *importar* be used in the affirmative, not just negative? |
| ------------------------------------------------------------------------ |
| Yes — e.g. *Me importa mucho tu opinión* ("Your opinion matters a lot to me").<br><br><!--ANKI_NOTE_ID:1786498002600--> |

| Translate: We're missing two chairs. |
| ------------------------------------------------- |
| Nos faltan dos sillas.<br><br><!--ANKI_NOTE_ID:1786498002603--> |
