#anki/Spanish/A2-Waystage-Elementary/A2-3-Verbal-Periphrasis-Modals-Future-Intentions/A2-3-4-Verbs-Like-Gustar-Emotional-Expression/A2-3-4-1-Gustar-Mechanics

| In "Me gusta el café," what is the actual grammatical subject? |
| ------------------------------------------------------------------------ |
| *el café* — the thing being liked, not the person<br><br><!--ANKI_NOTE_ID:1786497825812--> |

| What indirect object pronoun means "to me"? |
| ---------------------------------------------------- |
| me<br><br><!--ANKI_NOTE_ID:1786497825816--> |

| What indirect object pronoun means "to him/her/you (formal)"? |
| ------------------------------------------------------------------------ |
| le<br><br><!--ANKI_NOTE_ID:1786497825820--> |

| What indirect object pronoun means "to us"? |
| ---------------------------------------------------- |
| nos<br><br><!--ANKI_NOTE_ID:1786497825823--> |

| What indirect object pronoun means "to them/you all"? |
| ---------------------------------------------------------------- |
| les<br><br><!--ANKI_NOTE_ID:1786497825826--> |

| When do you use *gusta* instead of *gustan*? |
| --------------------------------------------------------- |
| When the thing liked is singular, or is an infinitive (activity).<br><br><!--ANKI_NOTE_ID:1786497825829--> |

| When do you use *gustan* instead of *gusta*? |
| --------------------------------------------------------- |
| When the thing liked is plural.<br><br><!--ANKI_NOTE_ID:1786497825832--> |

| Fill in the blank: Me ______ el chocolate. |
| ------------------------------------------------------ |
| gusta<br><br><!--ANKI_NOTE_ID:1786497825835--> |

| Fill in the blank: Nos ______ los libros de misterio. |
| ------------------------------------------------------------------ |
| gustan<br><br><!--ANKI_NOTE_ID:1786497825838--> |

| Why does "Me gusta correr, nadar y esquiar" use *gusta*, not *gustan*, despite listing three activities? |
| ------------------------------------------------------------------------------------------------------------------- |
| Infinitives are always treated as singular with *gustar*, no matter how many are listed.<br><br><!--ANKI_NOTE_ID:1786497825841--> |

| Translate: I like chocolate. |
| ------------------------------------- |
| Me gusta el chocolate.<br><br><!--ANKI_NOTE_ID:1786497825845--> |

| Translate: Do you like animals? |
| ------------------------------------------ |
| ¿Te gustan los animales?<br><br><!--ANKI_NOTE_ID:1786497825848--> |

| Translate: Juan likes soccer. |
| ---------------------------------------- |
| A Juan le gusta el fútbol.<br><br><!--ANKI_NOTE_ID:1786497825852--> |

| Why does "A Juan le gusta el pan" include both *a Juan* and *le*? |
| ------------------------------------------------------------------------ |
| *Le* alone is ambiguous (him/her/you formal), so *a Juan* clarifies exactly who is meant.<br><br><!--ANKI_NOTE_ID:1786497825855--> |

| Why is "Me gusta pan" incorrect? |
| ----------------------------------------- |
| *Gustar* with a noun requires the definite article: it must be *el pan*.<br><br><!--ANKI_NOTE_ID:1786497825858--> |

| Translate: We like to travel in the summer. |
| -------------------------------------------------------- |
| Nos gusta viajar en verano.<br><br><!--ANKI_NOTE_ID:1786497825861--> |

| Translate: My parents like action movies. |
| -------------------------------------------------------- |
| A mis papás les gustan las películas de acción.<br><br><!--ANKI_NOTE_ID:1786497825863--> |

| Short answer: ¿Te gusta el pan? |
| ---------------------------------------- |
| Sí, me gusta.<br><br><!--ANKI_NOTE_ID:1786497825866--> |

| Why is "gustar" sometimes called a "backward" verb for English speakers? |
| -------------------------------------------------------------------------------- |
| The thing liked is the subject, and the person doing the liking is expressed with an indirect object pronoun — the reverse of English word order.<br><br><!--ANKI_NOTE_ID:1786497825868--> |
