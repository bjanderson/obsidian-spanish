#anki/Spanish/A2-Waystage-Elementary/A2-3-Verbal-Periphrasis-Modals-Future-Intentions/A2-3-3-Obligation-Ability-Modals/A2-3-3-2-Impersonal-Obligation-Hay-Que

| What is the formula for expressing a general necessity in Spanish? |
| ---------------------------------------------------------------------- |
| hay que + infinitive<br><br><!--ANKI_NOTE_ID:1786497418608--> |

| Does *hay que* ever change form to match a subject? |
| ------------------------------------------------------------ |
| No — it's impersonal and always stays *hay que*.<br><br><!--ANKI_NOTE_ID:1786497418611--> |

| What verb does *hay* come from? |
| -------------------------------------- |
| haber<br><br><!--ANKI_NOTE_ID:1786497418614--> |

| Translate: One has to study to learn. |
| ------------------------------------------------ |
| Hay que estudiar para aprender.<br><br><!--ANKI_NOTE_ID:1786497418618--> |

| Translate: You need to arrive early to the meeting. |
| ---------------------------------------------------------------- |
| Hay que llegar temprano a la reunión.<br><br><!--ANKI_NOTE_ID:1786497418621--> |

| Translate: There's no need to worry so much. |
| --------------------------------------------------------- |
| No hay que preocuparse tanto.<br><br><!--ANKI_NOTE_ID:1786497418626--> |

| Translate: One has to think before speaking. |
| --------------------------------------------------------- |
| Hay que pensar antes de hablar.<br><br><!--ANKI_NOTE_ID:1786497418630--> |

| What's the difference between *Tengo que estudiar* and *Hay que estudiar*? |
| -------------------------------------------------------------------------------- |
| *Tengo que estudiar* is a personal obligation (specifically me); *Hay que estudiar* is a general statement not aimed at anyone in particular.<br><br><!--ANKI_NOTE_ID:1786497418633--> |

| Why is "hayo que" incorrect? |
| ----------------------------------- |
| *Hay que* never conjugates — it has no subject to agree with.<br><br><!--ANKI_NOTE_ID:1786497418638--> |

| Fill in the blank: ______ respetar las reglas del lugar. |
| ------------------------------------------------------------------ |
| Hay que<br><br><!--ANKI_NOTE_ID:1786497418641--> |

| Fill in the blank: Para cocinar bien, ______ practicar mucho. |
| -------------------------------------------------------------------- |
| hay que<br><br><!--ANKI_NOTE_ID:1786497418645--> |

| How do you tell apart the two uses of "hay" in Spanish? |
| ------------------------------------------------------------------ |
| *Hay* + noun means "there is/are"; *hay que* + infinitive means "one has to."<br><br><!--ANKI_NOTE_ID:1786497418649--> |

| Translate: One has to respect the rules of the place. |
| -------------------------------------------------------------------- |
| Hay que respetar las reglas del lugar.<br><br><!--ANKI_NOTE_ID:1786497418653--> |

| When would you use *hay que* instead of *tener que*? |
| ------------------------------------------------------------------ |
| When the obligation is general, not tied to one specific person.<br><br><!--ANKI_NOTE_ID:1786497418656--> |

| Translate: To get in, you have to show an ID. |
| ---------------------------------------------------------- |
| Para entrar, hay que mostrar una identificación.<br><br><!--ANKI_NOTE_ID:1786497418660--> |

| Translate: This needs to be fixed as soon as possible. |
| --------------------------------------------------------------------- |
| Hay que arreglar esto lo antes posible.<br><br><!--ANKI_NOTE_ID:1786497418664--> |

| Translate: There's no need to yell. |
| -------------------------------------------- |
| No hay que gritar.<br><br><!--ANKI_NOTE_ID:1786497418667--> |

| Is "hay que" formal or informal register? |
| -------------------------------------------------- |
| Neutral — it works in both casual and formal speech, since it doesn't target a specific person.<br><br><!--ANKI_NOTE_ID:1786497418670--> |

| Translate: You have to be patient with these things. |
| -------------------------------------------------------------------- |
| Hay que tener paciencia con estas cosas.<br><br><!--ANKI_NOTE_ID:1786497418674--> |
