| What are the three parts of the "have to" formula in Spanish? |
| ------------------------------------------------------------------- |
| conjugated *tener* + *que* + infinitive<br><br><!--ANKI_NOTE_ID:1786497158585--> |

| What are the two parts of the "should" formula in Spanish? |
| ------------------------------------------------------------------ |
| conjugated *deber* + infinitive<br><br><!--ANKI_NOTE_ID:1786497158588--> |

| Conjugate *tener* for *yo* in the present tense. |
| ------------------------------------------------------ |

| Conjugate *tener* for *nosotros* in the present tense. |
| -------------------------------------------------------------- |
| tenemos<br><br><!--ANKI_NOTE_ID:1786497158594--> |

| Conjugate *deber* for *tú* in the present tense. |
| ------------------------------------------------------ |
| debes<br><br><!--ANKI_NOTE_ID:1786497158597--> |

| Why is "Tengo trabajar" incorrect? |
| ----------------------------------------- |
| It's missing *que* — the formula requires *tener* + *que* + infinitive.<br><br><!--ANKI_NOTE_ID:1786497158618--> |

| Why is "Debo que estudiar" incorrect? |
| -------------------------------------------- |
| *Deber* takes the infinitive directly, with no *que* in between.<br><br><!--ANKI_NOTE_ID:1786497158621--> |

| What's the difference in strength between *tener que* and *deber*? |
| ---------------------------------------------------------------------------- |
| *Tener que* expresses a real obligation ("have to"); *deber* is softer, closer to a recommendation ("should").<br><br><!--ANKI_NOTE_ID:1786497158625--> |

| Translate: Marta has to call the doctor. |
| ----------------------------------------------- |
| Marta tiene que llamar al médico.<br><br><!--ANKI_NOTE_ID:1786497158628--> |

| Why does "llamar al médico" use *al* instead of *a el*? |
| ---------------------------------------------------------------- |
| *A* + *el* always contracts to *al*.<br><br><!--ANKI_NOTE_ID:1786497158632--> |

| Translate: The students should turn in the homework. |
| ---------------------------------------------------------------- |
| Los estudiantes deben entregar la tarea.<br><br><!--ANKI_NOTE_ID:1786497158636--> |

| Conjugate *tener* for *ustedes/ellos/ellas* in the present tense. |
| ------------------------------------------------------------------------ |
| tienen<br><br><!--ANKI_NOTE_ID:1786497158639--> |

| Why does "Tengo que trabajar el lunes" use "el" before "lunes"? |
| ------------------------------------------------------------------------ |
| Spanish uses the definite article with a specific day when stating what happens on it.<br><br><!--ANKI_NOTE_ID:1786497158643--> |

| ------------------------------------------------------------- |
| Quiero, pero no puedo. Tengo que trabajar.<br><br><!--ANKI_NOTE_ID:1786497158646--> |
