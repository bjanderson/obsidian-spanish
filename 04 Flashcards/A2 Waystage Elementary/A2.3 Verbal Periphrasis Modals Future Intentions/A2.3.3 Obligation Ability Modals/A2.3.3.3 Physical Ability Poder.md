| What are the two parts of the "can / to be able to" formula in Spanish? |
| -------------------------------------------------------------------------------- |
| conjugated *poder* + infinitive<br><br><!--ANKI_NOTE_ID:1786497615758--> |

| Conjugate *poder* for *yo* in the present tense. |
| ------------------------------------------------------ |
| puedo<br><br><!--ANKI_NOTE_ID:1786497615761--> |

| Conjugate *poder* for *tú* in the present tense. |
| ------------------------------------------------------ |
| puedes<br><br><!--ANKI_NOTE_ID:1786497615763--> |

| Conjugate *poder* for *nosotros* in the present tense. |
| -------------------------------------------------------------- |
| podemos<br><br><!--ANKI_NOTE_ID:1786497615766--> |

| Conjugate *poder* for *ustedes/ellos/ellas* in the present tense. |
| ------------------------------------------------------------------------ |
| pueden<br><br><!--ANKI_NOTE_ID:1786497615769--> |

| What stem change does *poder* have, and which form is exempt? |
| ----------------------------------------------------------------------- |
| *o → ue*; *nosotros* keeps the regular stem (*podemos*).<br><br><!--ANKI_NOTE_ID:1786497615772--> |

| Fill in the blank: Yo no ______ salir hoy. (poder) |
| ------------------------------------------------------------ |
| puedo<br><br><!--ANKI_NOTE_ID:1786497615775--> |

| Fill in the blank: ¿Tú ______ ayudarme con esto? (poder) |
| -------------------------------------------------------------------- |
| puedes<br><br><!--ANKI_NOTE_ID:1786497615778--> |

| Translate: Can you work on Saturday? |
| ------------------------------------------- |
| ¿Puedes trabajar el sábado?<br><br><!--ANKI_NOTE_ID:1786497615782--> |

| Translate: I can't go out today, I have a lot of work. |
| --------------------------------------------------------------------- |
| No puedo salir hoy, tengo mucho trabajo.<br><br><!--ANKI_NOTE_ID:1786497615785--> |

| Translate: Can we talk for a moment? |
| ------------------------------------------- |
| ¿Podemos hablar un momento?<br><br><!--ANKI_NOTE_ID:1786497615788--> |

| Translate: Marta can't come to the party. |
| -------------------------------------------------- |
| Marta no puede venir a la fiesta.<br><br><!--ANKI_NOTE_ID:1786497615791--> |

| Translate: Can you help me look for the keys? |
| ---------------------------------------------------------- |
| ¿Me puedes ayudar a buscar las llaves?<br><br><!--ANKI_NOTE_ID:1786497615794--> |

| Why is "podemos" the odd one out among the *poder* conjugations? |
| ------------------------------------------------------------------------- |
| It's the only form that doesn't apply the *o→ue* stem change.<br><br><!--ANKI_NOTE_ID:1786497615797--> |

| What's the difference between *poder* and *saber* when talking about ability? |
| -------------------------------------------------------------------------------------- |
| *Poder* is about being able to do something right now (physically/circumstantially); *saber* is about knowing how to do something as a learned skill.<br><br><!--ANKI_NOTE_ID:1786497615800--> |

| Translate: I want to work on Saturdays, but I can't. |
| ------------------------------------------------------------------- |
| Quiero trabajar los sábados, pero no puedo.<br><br><!--ANKI_NOTE_ID:1786497615805--> |

| Does "¿Puedo confirmar la reserva?" always mean asking about ability? |
| -------------------------------------------------------------------------------- |
| No — it can also mean asking for permission ("May I confirm the reservation?"), depending on context.<br><br><!--ANKI_NOTE_ID:1786497615809--> |

| Translate: We can't go to the party this weekend. |
| ---------------------------------------------------------- |
| No podemos ir a la fiesta este fin de semana.<br><br><!--ANKI_NOTE_ID:1786497615812--> |

| Why is "yo poder estudiar" incorrect? |
| -------------------------------------------- |
| *Poder* must be conjugated to match the subject — the infinitive form can't stand alone as the main verb.<br><br><!--ANKI_NOTE_ID:1786497615815--> |
