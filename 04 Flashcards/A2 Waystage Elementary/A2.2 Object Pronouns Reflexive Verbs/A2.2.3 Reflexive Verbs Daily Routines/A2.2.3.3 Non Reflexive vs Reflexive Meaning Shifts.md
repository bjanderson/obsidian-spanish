| What's the difference between *dormir* and *dormirse*? |
| ------------------------------------------------------------------------ |
|  *Dormir* is the state of sleeping; *dormirse* is the moment of falling asleep.<br><br><!--ANKI_NOTE_ID:1786469024243--> |

| What's the difference between *ir* and *irse*? |
| ------------------------------------------------------------ |
|  *Ir* points toward a destination; *irse* emphasizes leaving/departing, with no destination needed.<br><br><!--ANKI_NOTE_ID:1786469024253--> |

| What are the two common meanings of *ponerse*? |
| ------------------------------------------------------------ |
|  "To put on" (clothing) and "to become" (a temporary state or emotion).<br><br><!--ANKI_NOTE_ID:1786469024255--> |

| Translate: I fell asleep during the movie. |
| ------------------------------------------------------------ |
|  Me dormí durante la película.<br><br><!--ANKI_NOTE_ID:1786469024257--> |

| Translate: I'm leaving, it's already late. |
| ------------------------------------------------------------ |
|  Me voy, ya es tarde.<br><br><!--ANKI_NOTE_ID:1786469024259--> |

| Translate: I put on a coat because it was cold. |
| ---------------------------------------------------------------- |
|  Me puse un abrigo porque hacía frío.<br><br><!--ANKI_NOTE_ID:1786469024261--> |

| Translate: He got very nervous before the exam. |
| ---------------------------------------------------------------- |
|  Se puso muy nervioso antes del examen.<br><br><!--ANKI_NOTE_ID:1786469024263--> |

| What does *comerse* add to the meaning of *comer*? |
| --------------------------------------------------------------------- |
|  The sense of finishing/eating something up completely.<br><br><!--ANKI_NOTE_ID:1786469024264--> |

| Translate: I ate the whole cake by myself. |
| ------------------------------------------------------------ |
|  Me comí todo el pastel yo solo.<br><br><!--ANKI_NOTE_ID:1786469024266--> |

| What's the difference between *encontrar* and *encontrarse con*? |
| -------------------------------------------------------------------------------- |
|  *Encontrar* means to find an object; *encontrarse con* means to run into or meet up with a person.<br><br><!--ANKI_NOTE_ID:1786469024268--> |

| Translate: I ran into an old friend today. |
| ------------------------------------------------------------ |
|  Me encontré con un viejo amigo hoy.<br><br><!--ANKI_NOTE_ID:1786469024270--> |

| Is the non-reflexive form of these verbs wrong or outdated? |
| ----------------------------------------------------------------------------- |
|  No — both the reflexive and non-reflexive forms are correct; they just mean different things.<br><br><!--ANKI_NOTE_ID:1786469024272--> |

| Why is "Dormí durante la película" a poor way to say "I fell asleep during the movie"? |
| -------------------------------------------------------------------------------------------------------- |
|  *Dormí* (non-reflexive) suggests you slept the whole time; *me dormí* (reflexive) marks the moment you fell asleep.<br><br><!--ANKI_NOTE_ID:1786469024274--> |
