| What ending signals that a verb is reflexive in its infinitive/dictionary form? |
| ------------------------------------------------------------------------------------------------- |
|  *-se* (e.g. *lavarse*, *levantarse*).<br><br><!--ANKI_NOTE_ID:1786468595643--> |

| What is the reflexive pronoun for *yo*? |
| ------------------------------------------------------ |
|  me<br><br><!--ANKI_NOTE_ID:1786468595653--> |

| What is the reflexive pronoun for *tú*? |
| ------------------------------------------------------ |
|  te<br><br><!--ANKI_NOTE_ID:1786468595658--> |

| What is the reflexive pronoun for *él/ella/usted*? |
| ------------------------------------------------------------------- |
|  se<br><br><!--ANKI_NOTE_ID:1786468595660--> |

| What is the reflexive pronoun for *nosotros*? |
| ------------------------------------------------------------ |
|  nos<br><br><!--ANKI_NOTE_ID:1786468595662--> |

| What is the reflexive pronoun for *ellos/ustedes*? |
| ------------------------------------------------------------------- |
|  se<br><br><!--ANKI_NOTE_ID:1786468595664--> |

| Does *se* change between *él/ella/usted* and *ellos/ustedes*? |
| ------------------------------------------------------------------------------- |
|  No — *se* is the same for both singular and plural third person.<br><br><!--ANKI_NOTE_ID:1786468595665--> |

| Translate: I wash my hands before eating. |
| ------------------------------------------------------ |
|  Me lavo las manos antes de comer.<br><br><!--ANKI_NOTE_ID:1786468595667--> |

| Translate: Do you wake up early on Mondays? |
| ---------------------------------------------------------- |
|  ¿Te despiertas temprano los lunes?<br><br><!--ANKI_NOTE_ID:1786468595669--> |

| Translate: We sit down in the front row. |
| --------------------------------------------------------- |
|  Nos sentamos en la primera fila.<br><br><!--ANKI_NOTE_ID:1786468595671--> |

| Why is "Lavo las manos" incomplete for "I wash my hands" (in the reflexive sense)? |
| -------------------------------------------------------------------------------------------------- |
|  It's missing the reflexive pronoun *me* — the correct form is *Me lavo las manos*.<br><br><!--ANKI_NOTE_ID:1786468595673--> |

| With a conjugated verb + infinitive, where can the reflexive pronoun go? |
| -------------------------------------------------------------------------------------- |
|  Before the conjugated verb, or attached to the infinitive — e.g. *Me voy a lavar* / *Voy a lavarme*.<br><br><!--ANKI_NOTE_ID:1786468595675--> |

| Translate: My kids go to bed at nine. |
| ------------------------------------------------------ |
|  Mis hijos se acuestan a las nueve.<br><br><!--ANKI_NOTE_ID:1786468595676--> |
