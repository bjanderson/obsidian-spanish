| Why does Spanish say "me lavo las manos" instead of "me lavo mis manos"? |
| -------------------------------------------------------------------------------------------- |
|  With reflexive verbs acting on a body part, Spanish uses the definite article, not a possessive — the reflexive pronoun already shows whose hands are meant.<br><br><!--ANKI_NOTE_ID:1786468785991--> |

| Translate: I wake up at six every day. |
| ----------------------------------------------------- |

| ------------------------------------------------------------------ |
|  Nos cepillamos los dientes tres veces al día.<br><br><!--ANKI_NOTE_ID:1786468785995--> |

| Is *despertarse* a regular or stem-changing verb? |
| ------------------------------------------------------------------ |
|  Stem-changing (e → ie): *me despierto, te despiertas, se despierta...*<br><br><!--ANKI_NOTE_ID:1786468785997--> |
