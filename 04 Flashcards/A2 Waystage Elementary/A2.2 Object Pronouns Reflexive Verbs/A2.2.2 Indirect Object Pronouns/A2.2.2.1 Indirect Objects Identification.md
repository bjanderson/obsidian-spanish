| What question does an indirect object answer? |
| ------------------------------------------------------------- |
|  "To whom?" or "for whom?"<br><br><!--ANKI_NOTE_ID:1786468031418--> |

| What is the indirect object pronoun for "to/for him/her/usted"? |
| -------------------------------------------------------------------------------- |
|  le<br><br><!--ANKI_NOTE_ID:1786468031428--> |

| What is the indirect object pronoun for "to/for them/ustedes"? |
| ------------------------------------------------------------------------------- |
|  les<br><br><!--ANKI_NOTE_ID:1786468031439--> |

| Do *le* and *les* change for gender? |
| ------------------------------------------------ |
|  No — they only change for number, never gender.<br><br><!--ANKI_NOTE_ID:1786468031444--> |

| In "Le di el libro a Juan," what is the direct object and what is the indirect object? |
| ---------------------------------------------------------------------------------------------------------- |
|  *El libro* is the direct object (what was given); *Juan*/*le* is the indirect object (who received it).<br><br><!--ANKI_NOTE_ID:1786468031446--> |

| Translate: I gave the book to Juan. |
| ---------------------------------------------------- |
|  Le di el libro a Juan.<br><br><!--ANKI_NOTE_ID:1786468031448--> |

| Translate: Can you explain this to me? |
| ----------------------------------------------------- |
|  ¿Me puedes explicar esto?<br><br><!--ANKI_NOTE_ID:1786468031450--> |

| Translate: I wrote them a message. |
| --------------------------------------------------- |
|  Les escribí un mensaje.<br><br><!--ANKI_NOTE_ID:1786468031452--> |

| Why is it wrong to use *lo* instead of *le* in "Le di el libro a Juan"? |
| -------------------------------------------------------------------------------------------- |
|  *Juan* is the indirect object (recipient), and *le* is the indirect object pronoun; *lo* would be for a direct object.<br><br><!--ANKI_NOTE_ID:1786468031454--> |

| What kind of verbs typically take an indirect object? |
| ------------------------------------------------------------------------ |
|  Verbs of giving, telling, and communicating (*dar, decir, escribir, contar*) — anything with a sender and a receiver.<br><br><!--ANKI_NOTE_ID:1786468031456--> |

| Translate: I bought my mom a gift. |
| --------------------------------------------------- |
|  Le compré un regalo a mi mamá.<br><br><!--ANKI_NOTE_ID:1786468031458--> |

| Where does an indirect object pronoun go with a single conjugated verb? |
| -------------------------------------------------------------------------------------- |
|  Before the verb — same placement rule as direct object pronouns.<br><br><!--ANKI_NOTE_ID:1786468031460--> |

| Translate: Did he/she tell you the truth? |
| ------------------------------------------------------ |
|  ¿Te dijo la verdad?<br><br><!--ANKI_NOTE_ID:1786468031462--> |
