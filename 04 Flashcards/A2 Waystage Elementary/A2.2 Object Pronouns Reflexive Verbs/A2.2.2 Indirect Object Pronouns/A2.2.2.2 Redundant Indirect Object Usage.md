#anki/Spanish/A2-Waystage-Elementary/A2-2-Object-Pronouns-Reflexive-Verbs/A2-2-2-Indirect-Object-Pronouns/A2-2-2-2-Redundant-Indirect-Object-Usage

| What is the "redundant" pattern with verbs like *dar* and *decir*? |
| ------------------------------------------------------------------------------------ |
|  Keeping the indirect object pronoun (*le*/*les*) even when the recipient is already named with *a + person*.<br><br><!--ANKI_NOTE_ID:1786468263443--> |

| Why is "Di el libro a Juan" incomplete-sounding in Spanish? |
| ----------------------------------------------------------------------------- |
|  It's missing the required *le*; the natural form is *Le di el libro a Juan*.<br><br><!--ANKI_NOTE_ID:1786468263453--> |

| Can you drop the "*a* + person" phrase and keep just the pronoun? |
| ------------------------------------------------------------------------------------- |
|  Yes — *Le di el libro* is complete on its own.<br><br><!--ANKI_NOTE_ID:1786468263456--> |

| Can you drop the pronoun and keep just "*a* + person"? |
| ---------------------------------------------------------------------- |
|  No — that's not standard; the pronoun is required.<br><br><!--ANKI_NOTE_ID:1786468263458--> |

| Name three verbs that typically take this mandatory redundant pronoun. |
| -------------------------------------------------------------------------------------- |
|  Any three of: *dar, decir, contar, comprar, escribir, enviar/mandar, pedir, prestar, devolver*.<br><br><!--ANKI_NOTE_ID:1786468263460--> |

| Translate: I gave the keys to my brother. |
| ------------------------------------------------------ |
|  Le di las llaves a mi hermano.<br><br><!--ANKI_NOTE_ID:1786468263462--> |

| Translate: I told María the truth. |
| --------------------------------------------------- |
|  Le dije la verdad a María.<br><br><!--ANKI_NOTE_ID:1786468263464--> |

| Translate: I bought my wife a car. |
| --------------------------------------------------- |
|  Le compré un carro a mi esposa.<br><br><!--ANKI_NOTE_ID:1786468263465--> |

| Translate: Did you return the book to your professor? |
| ------------------------------------------------------------------------ |
|  ¿Le devolviste el libro a tu profesor?<br><br><!--ANKI_NOTE_ID:1786468263467--> |

| Does *le* change to agree with the gender of the named recipient (e.g., *a Juan* vs. *a María*)? |
| ------------------------------------------------------------------------------------------------------------------ |
|  No — *le* stays the same regardless of the recipient's gender.<br><br><!--ANKI_NOTE_ID:1786468263469--> |

| Translate: I lent my cousin money. |
| --------------------------------------------------- |
|  Le presté dinero a mi primo.<br><br><!--ANKI_NOTE_ID:1786468263470--> |

| Does this redundant-pronoun rule apply to every Spanish verb, or a specific group? |
| -------------------------------------------------------------------------------------------------- |
|  A specific group of give/tell/communicate verbs — not a universal rule for all sentences.<br><br><!--ANKI_NOTE_ID:1786468263472--> |

| Translate: I sent my grandparents a letter. |
| ---------------------------------------------------------- |
|  Les mandé una carta a mis abuelos.<br><br><!--ANKI_NOTE_ID:1786468263474--> |
