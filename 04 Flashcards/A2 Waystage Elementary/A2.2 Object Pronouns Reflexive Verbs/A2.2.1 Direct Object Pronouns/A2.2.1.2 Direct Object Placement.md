#anki/Spanish/A2-Waystage-Elementary/A2-2-Object-Pronouns-Reflexive-Verbs/A2-2-1-Direct-Object-Pronouns/A2-2-1-2-Direct-Object-Placement

| With a single conjugated verb, where does the direct object pronoun go? |
| ----------------------------------------------------------------------------------------- |
|  Before the verb.<br><br><!--ANKI_NOTE_ID:1786467793368--> |

| Why is "Veo la" wrong for "I see it"? |
| ------------------------------------------------------- |
|  With a single conjugated verb, the pronoun must go before it — the correct form is *La veo*.<br><br><!--ANKI_NOTE_ID:1786467793379--> |

| With a conjugated verb + infinitive, how many correct pronoun placements are there? |
| --------------------------------------------------------------------------------------------------- |
|  Two — before the conjugated verb, or attached to the infinitive.<br><br><!--ANKI_NOTE_ID:1786467793381--> |

| Give both correct placements for "I want to see it." |
| ------------------------------------------------------------------ |
|  La quiero ver. / Quiero verla.<br><br><!--ANKI_NOTE_ID:1786467793383--> |

| Where does the pronoun go when attached to a gerund (*-ndo* form)? |
| -------------------------------------------------------------------------------- |
|  Attached to the end of the gerund, with a written accent added.<br><br><!--ANKI_NOTE_ID:1786467793385--> |

| Why does *leyendo* become *leyéndolo* and not *leyendolo*? |
| -------------------------------------------------------------------------- |
|  Attaching a pronoun to a gerund requires a written accent to keep the original stress.<br><br><!--ANKI_NOTE_ID:1786467793387--> |

| Does attaching a pronoun to an infinitive require an accent? |
| ------------------------------------------------------------------------------ |
|  No — infinitives like *verla* or *comprarlos* don't need one.<br><br><!--ANKI_NOTE_ID:1786467793389--> |

| Translate: I'm reading it right now. (two ways) |
| ---------------------------------------------------------------- |
|  Lo estoy leyendo ahora mismo. / Estoy leyéndolo ahora mismo.<br><br><!--ANKI_NOTE_ID:1786467793391--> |

| Translate: I've known her for years. |
| ---------------------------------------------------- |
|  La conozco desde hace años.<br><br><!--ANKI_NOTE_ID:1786467793393--> |

| Is there a "correct" choice between the two placements with an infinitive, or are both equally valid? |
| ------------------------------------------------------------------------------------------------------------------------ |
|  Both are equally valid — it's a stylistic choice, not a rule with one right answer.<br><br><!--ANKI_NOTE_ID:1786467793395--> |

| Translate: Do you want to buy it? (two ways) |
| ------------------------------------------------------------- |
|  ¿Lo quieres comprar? / ¿Quieres comprarlo?<br><br><!--ANKI_NOTE_ID:1786467793397--> |

| Translate: We're waiting for her outside. (two ways) |
| ----------------------------------------------------------------------- |
|  La estamos esperando afuera. / Estamos esperándola afuera.<br><br><!--ANKI_NOTE_ID:1786467793398--> |

| Why is "quierola ver" wrong for "I want to see it"? |
| --------------------------------------------------------------------- |
|  A pronoun can't attach to a conjugated verb — only to an infinitive or gerund; the correct forms are *La quiero ver* or *Quiero verla*.<br><br><!--ANKI_NOTE_ID:1786467793400--> |

| Translate: I need them for tomorrow. |
| ---------------------------------------------------- |
|  Los necesito para mañana.<br><br><!--ANKI_NOTE_ID:1786467793402--> |

| Translate: I can help them tomorrow. (two ways) |
| -------------------------------------------------------------- |
|  Los puedo ayudar mañana. / Puedo ayudarlos mañana.<br><br><!--ANKI_NOTE_ID:1786467793404--> |
