| What question does a direct object answer? |
| ------------------------------------------------------------ |
|  "What?" or "whom?" after the verb.<br><br><!--ANKI_NOTE_ID:1786467615968--> |

| What direct object pronoun replaces a masculine singular noun? |
| -------------------------------------------------------------------------------- |
|  lo<br><br><!--ANKI_NOTE_ID:1786467615970--> |

| What direct object pronoun replaces a feminine singular noun? |
| ------------------------------------------------------------------------------- |
|  la<br><br><!--ANKI_NOTE_ID:1786467615973--> |

| What direct object pronoun replaces a masculine plural noun (or a mixed group)? |
| ------------------------------------------------------------------------------------------------- |
|  los<br><br><!--ANKI_NOTE_ID:1786467615975--> |

| What direct object pronoun replaces a feminine plural noun? |
| ----------------------------------------------------------------------------- |
|  las<br><br><!--ANKI_NOTE_ID:1786467615976--> |

| Do direct object pronouns need to agree in gender and number with the noun they replace? |
| ------------------------------------------------------------------------------------------------------ |
|  Yes — always.<br><br><!--ANKI_NOTE_ID:1786467615978--> |

| Translate the exchange: "Do you know Juan?" — "I don't know him." |
| ----------------------------------------------------------------------------------- |
|  ¿Conoces a Juan? — No lo conozco.<br><br><!--ANKI_NOTE_ID:1786467615980--> |

| Translate the exchange: "Do you have the keys?" — "Yes, I have them." |
| ----------------------------------------------------------------------------------------- |
|  ¿Tienes las llaves? — Sí, las tengo.<br><br><!--ANKI_NOTE_ID:1786467615981--> |

| Why does "Conozco a Juan" have a personal *a*, but "Lo conozco" doesn't? |
| -------------------------------------------------------------------------------------------- |
|  The personal *a* marks a specific-person direct object noun; the pronoun that replaces it doesn't carry the *a*.<br><br><!--ANKI_NOTE_ID:1786467615983--> |

| Why is "A lo veo" wrong? |
| ---------------------------------------- |
|  The personal *a* never attaches to a direct object pronoun — only to the full noun.<br><br><!--ANKI_NOTE_ID:1786467615985--> |

| What is the "neuter" use of *lo*? |
| ----------------------------------------------------- |
|  Referring to an idea or fact rather than a specific noun, e.g. *No lo sé* ("I don't know [that]").<br><br><!--ANKI_NOTE_ID:1786467615986--> |

| Translate: Do you want to watch the movie? — Yes, I want to watch it. |
| ----------------------------------------------------------------------------------------- |
|  ¿Quieres ver la película? — Sí, quiero verla.<br><br><!--ANKI_NOTE_ID:1786467615988--> |

| Do *me*, *te*, and *nos* change for gender? |
| ------------------------------------------------------------ |
|  No — they stay the same regardless of gender.<br><br><!--ANKI_NOTE_ID:1786467615990--> |

| Translate: I didn't understand it. |
| --------------------------------------------------- |
|  No lo entendí.<br><br><!--ANKI_NOTE_ID:1786467615991--> |
