| Why is "hizo" spelled with a *z* instead of a *c*? |
| ------------------------------------------------------------------ |
|  The *c* changes to *z* before *o* to keep the "s" sound consistent.<br><br><!--ANKI_NOTE_ID:1786464677608--> |

| Do the irregular-stem preterite forms (*tuve*, *pude*, *vine*...) carry written accents? |
| ------------------------------------------------------------------------------------------------------ |
|  No — none of them carry a written accent.<br><br><!--ANKI_NOTE_ID:1786464677610--> |

| Why is "tené" wrong for "I had"? |
| ---------------------------------------------- |
|  The irregular *yo* ending is *-e* with no accent, attached to the stem *tuv-*; the correct form is *tuve*.<br><br><!--ANKI_NOTE_ID:1786464677622--> |
