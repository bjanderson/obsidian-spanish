| Which subject forms get the spelling change: only *yo*, or all subjects? |
| -------------------------------------------------------------------------------------- |
|  Only *yo* — every other subject (*tú, él/ella/usted, nosotros, ellos/ustedes*) stays completely regular.<br><br><!--ANKI_NOTE_ID:1786464947332--> |

| Why does *buscar* become *busqué* instead of *buscé*? |
| ---------------------------------------------------------------------- |
|  "C" before "é" would sound like "s"; changing to *qu* keeps the hard "k" sound of the infinitive.<br><br><!--ANKI_NOTE_ID:1786464947335--> |

| Why does *pagar* become *pagué* instead of *pagé*? |
| ----------------------------------------------------------------- |
|  "G" before "é" would soften; adding a silent *u* (*gué*) keeps the hard "g" sound.<br><br><!--ANKI_NOTE_ID:1786464947338--> |

| Why does *empezar* become *empecé* instead of *empezé*? |
| ------------------------------------------------------------------------- |
|  Spanish spelling avoids *z* before *e*; it changes to *c* instead.<br><br><!--ANKI_NOTE_ID:1786464947340--> |

| Does this spelling change alter how the word is pronounced? |
| ----------------------------------------------------------------------------- |
|  No — it preserves the original pronunciation; only the spelling changes.<br><br><!--ANKI_NOTE_ID:1786464947343--> |

| Why is "jugaste" not spelled "juguaste" for "you played"? |
| ----------------------------------------------------------------------------- |
|  The spelling change only happens in the *yo* form; *tú* and other subjects stay regular.<br><br><!--ANKI_NOTE_ID:1786464947354--> |
