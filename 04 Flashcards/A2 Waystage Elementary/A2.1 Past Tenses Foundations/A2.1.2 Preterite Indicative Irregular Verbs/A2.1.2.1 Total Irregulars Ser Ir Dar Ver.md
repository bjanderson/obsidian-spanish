| What do *ser* and *ir* have in common in the preterite? |
| ----------------------------------------------------------------------- |
|  They share the exact same forms — *fui, fuiste, fue, fuimos, fueron*.<br><br><!--ANKI_NOTE_ID:1786464373163--> |

| How do you tell *ser* and *ir* apart in the preterite? |
| ---------------------------------------------------------------------- |
|  Context — *ir* is usually followed by *a* + a destination; *ser* describes identity or a state.<br><br><!--ANKI_NOTE_ID:1786464373165--> |

| Is "fui" in "Fui a la playa" from *ser* or *ir*? |
| ---------------------------------------------------------------- |
|  *ir* — it's followed by *a* + a destination.<br><br><!--ANKI_NOTE_ID:1786464373167--> |

| Is "fui" in "Fui doctor por veinte años" from *ser* or *ir*? |
| -------------------------------------------------------------------------------- |
|  *ser* — it describes an identity/role, not movement.<br><br><!--ANKI_NOTE_ID:1786464373169--> |

| Why is "dí" wrong for "I gave"? |
| -------------------------------------------- |
|  *Dar* takes no written accent in the preterite; the correct form is *di*.<br><br><!--ANKI_NOTE_ID:1786464373171--> |

| Why is "vió" wrong for "he/she saw"? |
| ------------------------------------------------- |
|  *Ver* takes no written accent in the preterite; the correct form is *vio*.<br><br><!--ANKI_NOTE_ID:1786464373173--> |
