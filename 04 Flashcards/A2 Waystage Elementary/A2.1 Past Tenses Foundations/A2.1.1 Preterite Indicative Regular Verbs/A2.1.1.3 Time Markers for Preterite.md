| Why does *pasada* end in *-a* in "la semana pasada" but *pasado* ends in *-o* in "el mes pasado"? |
| --------------------------------------------------------------------------------------------------------------- |
|  *Pasado*/*pasada* is an adjective that agrees in gender with the noun — *semana* is feminine, *mes* is masculine.<br><br><!--ANKI_NOTE_ID:1786464097581--> |

| Which tense do these time markers usually trigger: *ayer*, *anoche*, *hace + time*? |
| ------------------------------------------------------------------------------------------------- |
|  The preterite — they name a closed, finished stretch of time.<br><br><!--ANKI_NOTE_ID:1786464097583--> |

| What's the difference between *anoche* and *esta noche*? |
| ------------------------------------------------------------------------ |
|  *Anoche* is "last night" (past, finished); *esta noche* is "tonight" (not yet finished).<br><br><!--ANKI_NOTE_ID:1786464097585--> |

| Why is "la semana pasado" wrong? |
| --------------------------------------------- |
|  *Pasado* must agree with the feminine noun *semana*; the correct form is *pasada*.<br><br><!--ANKI_NOTE_ID:1786464097587--> |
