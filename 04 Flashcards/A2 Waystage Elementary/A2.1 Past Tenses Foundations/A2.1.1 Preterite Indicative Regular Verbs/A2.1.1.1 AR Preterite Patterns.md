| Which accent mark is missing: "hable" (meant as "I spoke")? |
| ----------------------------------------------------------------------- |
|  The *é* needs an accent — *hablé*, not *hable* (which is a subjunctive form).<br><br><!--ANKI_NOTE_ID:1786463375461--> |

| Why is "hablamos" ambiguous on its own? |
| ---------------------------------------------------- |
|  It's identical in the present ("we speak") and the preterite ("we spoke") — only context or a time word shows which one is meant.<br><br><!--ANKI_NOTE_ID:1786463375463--> |

| Why is "Hablas ayer" wrong for "You spoke yesterday"? |
| ------------------------------------------------------------------ |
|  *Hablas* is present tense; the preterite *tú* form is *hablaste*.<br><br><!--ANKI_NOTE_ID:1786463375465--> |

| What's the first step in conjugating any regular *-AR* verb in the preterite? |
| -------------------------------------------------------------------------------------- |
|  Drop the *-ar* from the infinitive to get the stem, then add the preterite ending.<br><br><!--ANKI_NOTE_ID:1786463375468--> |
