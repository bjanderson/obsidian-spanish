| Do *-ER* and *-IR* verbs use the same preterite endings, or different ones? |
| ------------------------------------------------------------------------------------ |
|  The same set of endings — *-í, -iste, -ió, -imos, -ieron* — works for both.<br><br><!--ANKI_NOTE_ID:1786463745033--> |

| Why is "comaste" wrong for "you ate"? |
| -------------------------------------------------- |
|  *-aste* is the *-AR* ending; regular *-ER*/*-IR* verbs use *-iste*, so the correct form is *comiste*.<br><br><!--ANKI_NOTE_ID:1786463745035--> |

| What's the first step in conjugating any regular *-ER* or *-IR* verb in the preterite? |
| ---------------------------------------------------------------------------------------------------- |
|  Drop the *-er* or *-ir* from the infinitive to get the stem, then add the preterite ending.<br><br><!--ANKI_NOTE_ID:1786463745037--> |
