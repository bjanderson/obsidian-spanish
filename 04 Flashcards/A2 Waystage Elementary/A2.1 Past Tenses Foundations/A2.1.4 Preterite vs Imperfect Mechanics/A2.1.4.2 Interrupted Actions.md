#anki/Spanish/A2-Waystage-Elementary/A2-1-Past-Tenses-Foundations/A2-1-4-Preterite-vs-Imperfect-Mechanics/A2-1-4-2-Interrupted-Actions

| What is the formula for an interrupted action in the past? |
| ------------------------------------------------------------------------------ |
|  imperfect + *cuando* + preterite<br><br><!--ANKI_NOTE_ID:1786466370819--> |

| In "Estaba durmiendo cuando sonó el teléfono," which verb is the ongoing action and which is the interruption? |
| --------------------------------------------------------------------------------------------------------------------------------- |
|  *Estaba durmiendo* (imperfect) is ongoing; *sonó* (preterite) is the interruption.<br><br><!--ANKI_NOTE_ID:1786466370821--> |

| Does flipping the clause order change which verb gets which tense? |
| ---------------------------------------------------------------------------------- |
|  No — *cuando* + preterite always marks the interrupting event, no matter which clause comes first.<br><br><!--ANKI_NOTE_ID:1786466370841--> |

| Translate: I was sleeping when the phone rang. |
| ------------------------------------------------------------- |
|  Estaba durmiendo cuando sonó el teléfono.<br><br><!--ANKI_NOTE_ID:1786466370843--> |

| Translate: When I arrived at the party, everyone was dancing. |
| ------------------------------------------------------------------------------- |
|  Cuando llegué a la fiesta, todos bailaban.<br><br><!--ANKI_NOTE_ID:1786466370845--> |

| What tense do both verbs usually take with *mientras* when two actions happen in parallel? |
| --------------------------------------------------------------------------------------------------------- |
|  Both imperfect — e.g. *Mientras cocinaba, escuchaba música.*<br><br><!--ANKI_NOTE_ID:1786466370847--> |

| When does the second verb after *mientras* switch to the preterite? |
| ----------------------------------------------------------------------------------- |
|  When it's a one-time interrupting event rather than an ongoing parallel action.<br><br><!--ANKI_NOTE_ID:1786466370850--> |

| Translate: While I was cooking, the phone rang. |
| ------------------------------------------------------------- |
|  Mientras cocinaba, sonó el teléfono.<br><br><!--ANKI_NOTE_ID:1786466370852--> |

| Why is "Estaba durmiendo cuando sonaba el teléfono" wrong for "I was sleeping when the phone rang"? |
| ------------------------------------------------------------------------------------------------------------------------ |
|  *Sonaba* (imperfect) wrongly makes the ringing sound ongoing/repeated; a single ring is *sonó* (preterite).<br><br><!--ANKI_NOTE_ID:1786466370854--> |

| Why is "Estuve durmiendo cuando sonó el teléfono" wrong? |
| ------------------------------------------------------------------------- |
|  Putting the sleeping in the preterite loses the "already in progress" meaning; it should stay imperfect (*estaba durmiendo*).<br><br><!--ANKI_NOTE_ID:1786466370856--> |

| Translate: We were walking through the park when it started to rain. |
| -------------------------------------------------------------------------------------- |
|  Caminábamos por el parque cuando empezó a llover.<br><br><!--ANKI_NOTE_ID:1786466370858--> |

| Translate: Juan was in the Army when he met Maria. |
| ------------------------------------------------------------------- |
|  Juan estaba en el ejército cuando conoció a María.<br><br><!--ANKI_NOTE_ID:1786466370860--> |

| Is *cuando* almost always followed by which tense when introducing the interrupting event? |
| --------------------------------------------------------------------------------------------------------- |
|  The preterite.<br><br><!--ANKI_NOTE_ID:1786466370862--> |

| What does "Mientras esperábamos, hablábamos de trabajo" describe — an interruption or parallel actions? |
| -------------------------------------------------------------------------------------------------------------------------- |
|  Parallel actions — both verbs are imperfect, describing two things happening at the same time.<br><br><!--ANKI_NOTE_ID:1786466370863--> |
