#anki/Spanish/A2-Waystage-Elementary/A2-1-Past-Tenses-Foundations/A2-1-4-Preterite-vs-Imperfect-Mechanics/A2-1-4-1-Completed-Actions-vs-Background-States

| What kind of past action does the preterite describe? |
| ------------------------------------------------------------------------ |
|  The main event — a specific action that happened and finished.<br><br><!--ANKI_NOTE_ID:1786466109668--> |

| What kind of past action does the imperfect describe? |
| ------------------------------------------------------------------------ |
|  The background — an ongoing state, scene, or habitual action with no clear endpoint.<br><br><!--ANKI_NOTE_ID:1786466109679--> |

| In "Fui a la tienda y compré pan," why are both verbs preterite? |
| -------------------------------------------------------------------------------------- |
|  They're two sequential, completed events — the main actions of the story.<br><br><!--ANKI_NOTE_ID:1786466109690--> |

| In "Hacía frío cuando salimos," why is *hacía* imperfect? |
| ------------------------------------------------------------------------- |
|  It's the background condition (the cold) that was already true when the main event (going out) happened.<br><br><!--ANKI_NOTE_ID:1786466109692--> |

| Translate: I went to the store and bought bread. |
| ----------------------------------------------------------------- |
|  Fui a la tienda y compré pan.<br><br><!--ANKI_NOTE_ID:1786466109694--> |

| Translate: My father used to smoke every day. |
| ------------------------------------------------------------ |
|  Mi papá fumaba todos los días.<br><br><!--ANKI_NOTE_ID:1786466109697--> |

| Translate: She arrived late because traffic was very heavy. |
| ----------------------------------------------------------------------------- |
|  Ella llegó tarde porque el tráfico estaba muy pesado.<br><br><!--ANKI_NOTE_ID:1786466109699--> |

| Why does "El cielo estaba gris" use the imperfect rather than the preterite? |
| -------------------------------------------------------------------------------------------- |
|  It's pure scene-setting/description, not a completed event.<br><br><!--ANKI_NOTE_ID:1786466109701--> |

| Is a long but specific, finished period of time (like "vivimos allí diez años") preterite or imperfect? |
| -------------------------------------------------------------------------------------------------------------------------- |
|  Preterite — it names one finished stretch, not an open-ended background state.<br><br><!--ANKI_NOTE_ID:1786466109703--> |

| Translate: We lived in that house for five years. |
| ------------------------------------------------------------------ |
|  Vivimos en esa casa por cinco años.<br><br><!--ANKI_NOTE_ID:1786466109705--> |

| Why is "Iba a la tienda" different from "Fui a la tienda"? |
| -------------------------------------------------------------------------- |
|  *Iba* has no clear endpoint (ongoing/habitual); *fui* is one specific, completed trip.<br><br><!--ANKI_NOTE_ID:1786466109708--> |

| What's the difference between "El restaurante estaba lleno" (imperfect) and a preterite version of that same idea? |
| -------------------------------------------------------------------------------------------------------------------------------------- |
|  The imperfect frames it as background/description; a preterite version would wrongly suggest the fullness itself was a completed event, not a state.<br><br><!--ANKI_NOTE_ID:1786466109710--> |

| Translate: It was cold and the sky looked like it was going to snow. |
| -------------------------------------------------------------------------------------- |
|  Hacía frío y el cielo parecía que iba a nevar.<br><br><!--ANKI_NOTE_ID:1786466109712--> |

| In a story, does the imperfect or the preterite move the plot forward? |
| -------------------------------------------------------------------------------------- |
|  The preterite — it marks the events that actually happen and push the story ahead.<br><br><!--ANKI_NOTE_ID:1786466109714--> |
