| What does *soler* mean in the present tense? |
| ------------------------------------------------------------- |
|  "To usually do" something.<br><br><!--ANKI_NOTE_ID:1786465914894--> |

| What does *soler* mean in the imperfect tense? |
| --------------------------------------------------------------- |
|  "To used to do" something.<br><br><!--ANKI_NOTE_ID:1786465914897--> |

| What form does the verb after *soler* always take? |
| -------------------------------------------------------------------- |
|  The infinitive — never a conjugated second verb.<br><br><!--ANKI_NOTE_ID:1786465914899--> |

| Conjugate *soler* for *yo* in the present. |
| ------------------------------------------------------- |
|  suelo<br><br><!--ANKI_NOTE_ID:1786465914901--> |

| Conjugate *soler* for *tú* in the present. |
| ------------------------------------------------------- |
|  sueles<br><br><!--ANKI_NOTE_ID:1786465914903--> |

| Conjugate *soler* for *nosotros* in the present. |
| ----------------------------------------------------------------- |
|  solemos<br><br><!--ANKI_NOTE_ID:1786465914905--> |

| Conjugate *soler* for *yo* in the imperfect. |
| --------------------------------------------------------- |
|  solía<br><br><!--ANKI_NOTE_ID:1786465914907--> |

| Conjugate *soler* for *ellos* in the imperfect. |
| ------------------------------------------------------------ |
|  solían<br><br><!--ANKI_NOTE_ID:1786465914909--> |

| What kind of stem change does *soler* have in the present tense? |
| ------------------------------------------------------------------------------ |
|  *o → ue* (suelo, sueles, suele, solemos, suelen)<br><br><!--ANKI_NOTE_ID:1786465914911--> |

| Does *soler* stem-change in the imperfect? |
| ------------------------------------------------------- |
|  No — the imperfect forms (*solía, solías...*) don't stem-change; stem changes only apply to the present.<br><br><!--ANKI_NOTE_ID:1786465914913--> |

| Why is "suelo como" wrong for "I usually eat"? |
| ----------------------------------------------------------------- |
|  The verb after *soler* must stay in the infinitive; the correct form is *suelo comer*.<br><br><!--ANKI_NOTE_ID:1786465914915--> |

| Why might you need a subject pronoun with *solía* but not with *suelo*? |
| -------------------------------------------------------------------------------------- |
|  *Solía* is identical for *yo, él, ella,* and *usted*, so context alone may not clarify who; *suelo* is unambiguously *yo*.<br><br><!--ANKI_NOTE_ID:1786465914917--> |

| Translate: I usually have breakfast before seven. |
| ------------------------------------------------------------------ |
|  Suelo desayunar antes de las siete.<br><br><!--ANKI_NOTE_ID:1786465914919--> |

| Translate: My brother usually gets up early. |
| ------------------------------------------------------------- |
|  Mi hermano suele levantarse temprano.<br><br><!--ANKI_NOTE_ID:1786465914921--> |

| Translate: I used to read every night. |
| ----------------------------------------------------------- |
|  Solía leer todas las noches.<br><br><!--ANKI_NOTE_ID:1786465914923--> |

| Translate: My parents used to travel a lot. |
| ---------------------------------------------------------- |
|  Mis padres solían viajar mucho.<br><br><!--ANKI_NOTE_ID:1786465914925--> |
