| What four situations typically call for the imperfect? |
| -------------------------------------------------------------------- |
|  Habits/routines, descriptions, age, and telling time in the past.<br><br><!--ANKI_NOTE_ID:1786465685542--> |

| Which verb (in the imperfect) does Spanish always use to state someone's age in the past? |
| ------------------------------------------------------------------------------------------------------- |
|  *tener*<br><br><!--ANKI_NOTE_ID:1786465685553--> |

| Which verb (in the imperfect) does Spanish always use to tell time in the past? |
| ------------------------------------------------------------------------------------------------- |
|  *ser*<br><br><!--ANKI_NOTE_ID:1786465685556--> |

| Translate: I was fifteen when I learned to drive. |
| ------------------------------------------------------------------ |
|  Tenía quince años cuando aprendí a manejar.<br><br><!--ANKI_NOTE_ID:1786465685559--> |

| Translate: It was ten at night when we arrived. |
| ---------------------------------------------------------------- |
|  Eran las diez de la noche cuando llegamos.<br><br><!--ANKI_NOTE_ID:1786465685562--> |

| Why is "era la una" correct but "era las dos" wrong? |
| --------------------------------------------------------------------- |
|  *Era* is only for one o'clock; every other hour uses the plural *eran* (*eran las dos, eran las tres...*).<br><br><!--ANKI_NOTE_ID:1786465685566--> |

| Why is "Tuve diez años" wrong for "I was ten years old"? |
| ------------------------------------------------------------------------- |
|  Age in the past always uses the imperfect (*tenía*), never the preterite.<br><br><!--ANKI_NOTE_ID:1786465685569--> |

| Translate: My grandmother was very affectionate. |
| ------------------------------------------------------------------ |
|  Mi abuela era muy cariñosa.<br><br><!--ANKI_NOTE_ID:1786465685572--> |

| Does a habitual past action need an explicit frequency word like *siempre* to use the imperfect? |
| ------------------------------------------------------------------------------------------------------------------ |
|  No — the imperfect applies to repeated/habitual actions whether or not a frequency word is stated.<br><br><!--ANKI_NOTE_ID:1786465685575--> |

| Translate: We used to live near the sea back then. |
| ------------------------------------------------------------------- |
|  Vivíamos cerca del mar en ese entonces.<br><br><!--ANKI_NOTE_ID:1786465685578--> |

| What kind of past-tense sentence uses the imperfect the whole way through, even across several clauses? |
| -------------------------------------------------------------------------------------------------------------------------- |
|  A description — it stays in the imperfect throughout, not just at the start.<br><br><!--ANKI_NOTE_ID:1786465685581--> |

| Translate: It was very hot that summer. |
| ---------------------------------------------------------- |
|  Hacía mucho calor ese verano.<br><br><!--ANKI_NOTE_ID:1786465685584--> |

| Why does age/time use the imperfect even though it can refer to one specific moment? |
| -------------------------------------------------------------------------------------------------------- |
|  Age and time-telling are fixed imperfect constructions in Spanish — not a stylistic choice based on how specific the moment feels.<br><br><!--ANKI_NOTE_ID:1786465685587--> |

| Translate: What time was it when you got home? |
| ---------------------------------------------------------------- |
|  ¿Qué hora era cuando llegaste a casa?<br><br><!--ANKI_NOTE_ID:1786465685589--> |

| Translate: My first boss was very demanding. |
| ------------------------------------------------------------- |
|  Mi primer jefe era muy exigente.<br><br><!--ANKI_NOTE_ID:1786465685592--> |

| What's wrong with saying "Fue muy nervioso antes del examen" for "He was very nervous before the exam"? |
| -------------------------------------------------------------------------------------------------------------------------- |
|  Describing an emotional state uses the imperfect (*estaba*), not the preterite (*fue*/*estuvo*).<br><br><!--ANKI_NOTE_ID:1786465685594--> |
