| What is the *yo* imperfect ending for regular *-AR* verbs? |
| ------------------------------------------------------------------------ |
|  -aba<br><br><!--ANKI_NOTE_ID:1786465215144--> |

| What is the *yo* imperfect ending for regular *-ER*/*-IR* verbs? |
| ---------------------------------------------------------------------------------- |
|  -ía<br><br><!--ANKI_NOTE_ID:1786465215158--> |

| What is the *nosotros* imperfect ending for regular *-AR* verbs? |
| ---------------------------------------------------------------------------------- |
|  -ábamos<br><br><!--ANKI_NOTE_ID:1786465215164--> |

| What is the *nosotros* imperfect ending for regular *-ER*/*-IR* verbs? |
| ------------------------------------------------------------------------------------------ |
|  -íamos<br><br><!--ANKI_NOTE_ID:1786465215167--> |

| Conjugate *hablar* for *yo* in the imperfect. |
| ------------------------------------------------------------ |
|  hablaba<br><br><!--ANKI_NOTE_ID:1786465215171--> |

| Conjugate *comer* for *tú* in the imperfect. |
| ----------------------------------------------------------- |
|  comías<br><br><!--ANKI_NOTE_ID:1786465215174--> |

| Conjugate *vivir* for *nosotros* in the imperfect. |
| ------------------------------------------------------------------- |
|  vivíamos<br><br><!--ANKI_NOTE_ID:1786465215178--> |

| Conjugate *jugar* for *ellos* in the imperfect. |
| ------------------------------------------------------------ |
|  jugaban<br><br><!--ANKI_NOTE_ID:1786465215182--> |

| Which two subjects share the exact same form in the regular imperfect? |
| -------------------------------------------------------------------------------------- |
|  *yo* and *él/ella/usted* — both use *-aba* or *-ía* with no distinction.<br><br><!--ANKI_NOTE_ID:1786465215185--> |

| Does the *-ER*/*-IR* imperfect *nosotros* form carry a written accent? |
| -------------------------------------------------------------------------------------- |
|  Yes — every *-ía* form carries an accent on the *í*, including *nosotros* (*-íamos*).<br><br><!--ANKI_NOTE_ID:1786465215189--> |

| Why is "comiamos" wrong for "we used to eat"? |
| ------------------------------------------------------------ |
|  It's missing the accent — the correct form is *comíamos*.<br><br><!--ANKI_NOTE_ID:1786465215193--> |

| What does the imperfect describe that the preterite doesn't? |
| ------------------------------------------------------------------------------ |
|  Ongoing, repeated, or habitual past actions without a clear beginning or end — "used to" / "was -ing."<br><br><!--ANKI_NOTE_ID:1786465215197--> |

| Translate: I used to talk a lot with my grandparents. |
| ------------------------------------------------------------------ |
|  Hablaba mucho con mis abuelos.<br><br><!--ANKI_NOTE_ID:1786465215200--> |

| Translate: We used to play in that park. |
| --------------------------------------------------------- |
|  Jugábamos en ese parque.<br><br><!--ANKI_NOTE_ID:1786465215204--> |

| Translate: She always used to eat early. |
| --------------------------------------------------------- |
|  Ella siempre comía temprano.<br><br><!--ANKI_NOTE_ID:1786465215208--> |

| Are there any stem changes in the regular imperfect? |
| --------------------------------------------------------------------- |
|  No — the stem never changes in the regular imperfect, no matter the subject.<br><br><!--ANKI_NOTE_ID:1786465215211--> |
