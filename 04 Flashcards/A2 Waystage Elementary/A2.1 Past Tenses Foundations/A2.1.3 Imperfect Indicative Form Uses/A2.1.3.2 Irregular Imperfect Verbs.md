| What are the only three irregular verbs in the entire imperfect tense? |
| -------------------------------------------------------------------------------------- |
|  *ser*, *ir*, and *ver*<br><br><!--ANKI_NOTE_ID:1786465447918--> |

| Conjugate *ser* for *yo* in the imperfect. |
| ------------------------------------------------------- |
|  era<br><br><!--ANKI_NOTE_ID:1786465447929--> |

| Conjugate *ir* for *tú* in the imperfect. |
| ------------------------------------------------------ |
|  ibas<br><br><!--ANKI_NOTE_ID:1786465447931--> |

| Conjugate *ver* for *ella* in the imperfect. |
| ------------------------------------------------------------- |
|  veía<br><br><!--ANKI_NOTE_ID:1786465447933--> |

| Conjugate *ser* for *nosotros* in the imperfect. |
| ----------------------------------------------------------------- |
|  éramos<br><br><!--ANKI_NOTE_ID:1786465447936--> |

| Conjugate *ir* for *ellos* in the imperfect. |
| ------------------------------------------------------------- |
|  iban<br><br><!--ANKI_NOTE_ID:1786465447938--> |

| Conjugate *ver* for *nosotros* in the imperfect. |
| ------------------------------------------------------------------- |
|  veíamos<br><br><!--ANKI_NOTE_ID:1786465447940--> |

| What stem does *ser* build its imperfect on? |
| ------------------------------------------------------------- |
|  *er-* (era, eras, era, éramos, eran)<br><br><!--ANKI_NOTE_ID:1786465447942--> |

| What stem does *ir* build its imperfect on? |
| ------------------------------------------------------------ |
|  *ib-* (iba, ibas, iba, íbamos, iban)<br><br><!--ANKI_NOTE_ID:1786465447944--> |

| Why is *ver*'s imperfect *veía* and not *vía*? |
| ----------------------------------------------------------------- |
|  *Ver* keeps the *e* from the infinitive; a fully regular *-er* verb would drop it.<br><br><!--ANKI_NOTE_ID:1786465447947--> |

| Are *tener*, *hacer*, and *estar* irregular in the imperfect? |
| ------------------------------------------------------------------------------- |
|  No — only *ser*, *ir*, and *ver* are irregular in the imperfect; every other verb is regular.<br><br><!--ANKI_NOTE_ID:1786465447950--> |

| Translate: As a young person, I was very shy. |
| ------------------------------------------------------------ |
|  Era muy tímido/tímida de joven.<br><br><!--ANKI_NOTE_ID:1786465447953--> |

| Translate: Did you use to go to the beach every summer? |
| ------------------------------------------------------------------------- |
|  ¿Ibas a la playa cada verano?<br><br><!--ANKI_NOTE_ID:1786465447955--> |

| Translate: She used to watch that show every night. |
| --------------------------------------------------------------------- |
|  Ella veía esa serie todas las noches.<br><br><!--ANKI_NOTE_ID:1786465447958--> |

| Translate: We were neighbors many years ago. |
| ----------------------------------------------------------- |
|  Éramos vecinos hace muchos años.<br><br><!--ANKI_NOTE_ID:1786465447960--> |

| Why is "vía" wrong for "I used to see"? |
| ------------------------------------------------------ |
|  It's missing the irregular *e*; the correct form is *veía*.<br><br><!--ANKI_NOTE_ID:1786465447963--> |
