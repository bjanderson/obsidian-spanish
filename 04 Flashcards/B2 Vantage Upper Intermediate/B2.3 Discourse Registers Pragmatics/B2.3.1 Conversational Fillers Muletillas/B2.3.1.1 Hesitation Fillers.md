#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-3-Discourse-Registers-Pragmatics/B2-3-1-Conversational-Fillers-Muletillas/B2-3-1-1-Hesitation-Fillers

| What does "este" work like when used as a filler mid-sentence? |
| ------------------------------------------------------------------------------- |
|  English "um" — a pure hesitation sound while you think of the next word<br><br><!--ANKI_NOTE_ID:1786580102567--> |

| What does "bueno" do at the start of a response? |
| ------------------------------------------------------------------ |
|  It softens a transition or introduces a response, like "well" in English<br><br><!--ANKI_NOTE_ID:1786580102578--> |

| What does "o sea" do in a sentence? |
| ------------------------------------------------------- |
|  Rephrases or clarifies what you just said, like "I mean" or "that is to say"<br><br><!--ANKI_NOTE_ID:1786580102581--> |

| How does "es decir" compare to "o sea" in register? |
| --------------------------------------------------------------------- |
|  Es decir is a slightly more formal cousin of o sea, also meaning "that is to say"<br><br><!--ANKI_NOTE_ID:1786580102584--> |

| Translate, using a filler: I want... um... to order a coffee. |
| ---------------------------------------------------------------------------------- |
|  Quiero... este... pedir un café.<br><br><!--ANKI_NOTE_ID:1786580102587--> |

| Translate: As far as I know, he lives in Guadalajara. |
| -------------------------------------------------------------------------- |
|  Que yo sepa, vive en Guadalajara.<br><br><!--ANKI_NOTE_ID:1786580102591--> |

| Why is the subjunctive used in "que yo sepa" even though there's no obvious subjunctive trigger? |
| ---------------------------------------------------------------------------------------------------------------- |
|  It's a fixed expression — memorize the whole chunk rather than analyzing it grammatically<br><br><!--ANKI_NOTE_ID:1786580102593--> |

| Translate: As far as I remember, we never talked about that. |
| ------------------------------------------------------------------------------- |
|  Que yo recuerde, nunca hablamos de eso.<br><br><!--ANKI_NOTE_ID:1786580102596--> |

| Is it more natural to avoid all hesitation fillers to sound "correct" in Spanish? |
| -------------------------------------------------------------------------------------------------- |
|  No — speech with zero hesitation markers can sound stiff and over-rehearsed<br><br><!--ANKI_NOTE_ID:1786580102599--> |

| Translate: We arrived late, I mean, like always. |
| ---------------------------------------------------------------- |
|  Llegamos tarde, o sea, como siempre.<br><br><!--ANKI_NOTE_ID:1786580102603--> |

| Fix the mistake: repeating "este... este... este..." in every single sentence of a conversation. |
| ---------------------------------------------------------------------------------------------------------------- |
|  Mix fillers like este, bueno, and o sea — repeating just one becomes a verbal tic<br><br><!--ANKI_NOTE_ID:1786580102607--> |

| Translate: I study at night, that is, after work. |
| --------------------------------------------------------------------- |
|  Estudio por las noches, es decir, después del trabajo.<br><br><!--ANKI_NOTE_ID:1786580102611--> |
