#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-3-Discourse-Registers-Pragmatics/B2-3-1-Conversational-Fillers-Muletillas/B2-3-1-2-Conversation-Steering-Tag-Questions

| Which tag question is the most universal — works after any statement, in any register? |
| -------------------------------------------------------------------------------------------------------- |
|  ¿Verdad?<br><br><!--ANKI_NOTE_ID:1786580332268--> |

| Which tag question is the most casual, everyday version, roughly equivalent to ¿verdad?? |
| -------------------------------------------------------------------------------------------------------- |
|  ¿No?<br><br><!--ANKI_NOTE_ID:1786580332282--> |

| Does a Spanish tag question need to match the verb tense of the statement it follows? |
| ------------------------------------------------------------------------------------------------------- |
|  No — the tag stays exactly the same no matter what tense came before it<br><br><!--ANKI_NOTE_ID:1786580332287--> |

| Translate: You live nearby, right? |
| ---------------------------------------------------- |
|  Vives cerca de aquí, ¿verdad?<br><br><!--ANKI_NOTE_ID:1786580332291--> |

| In English, "isn't it?" flips to "is it?" after a negative statement. Does Spanish do the same with ¿verdad?/¿no?? |
| ---------------------------------------------------------------------------------------------------------------------------------- |
|  No — ¿verdad? and ¿no? work identically after both positive and negative statements<br><br><!--ANKI_NOTE_ID:1786580332296--> |

| Translate: You're not coming today, right? |
| ------------------------------------------------------------ |
|  No vienes hoy, ¿verdad?<br><br><!--ANKI_NOTE_ID:1786580332300--> |

| Which region is ¿cierto? especially common in, as an alternative to ¿verdad?? |
| ------------------------------------------------------------------------------------------------- |
|  Parts of South America<br><br><!--ANKI_NOTE_ID:1786580332304--> |

| What does ¿ya? check for, that's different from ¿verdad?/¿no?/¿cierto??? |
| -------------------------------------------------------------------------------------------- |
|  Whether something has happened yet, or confirms readiness/understanding<br><br><!--ANKI_NOTE_ID:1786580332308--> |

| Translate: I'll wait for you outside, okay? |
| ----------------------------------------------------------- |
|  Te espero afuera, ¿ya?<br><br><!--ANKI_NOTE_ID:1786580332311--> |

| Fix the mistake: someone uses ¿ya? in every single sentence throughout a conversation. |
| -------------------------------------------------------------------------------------------------------- |
|  Mix tags like ¿verdad?, ¿no?, and ¿cierto? — leaning on just one constantly can sound repetitive<br><br><!--ANKI_NOTE_ID:1786580332315--> |

| Translate: It's hot today, isn't it? |
| ---------------------------------------------------- |
|  Hace calor hoy, ¿no?<br><br><!--ANKI_NOTE_ID:1786580332318--> |

| Translate: You already finished the project, right? |
| -------------------------------------------------------------------- |
|  Ya terminaste el proyecto, ¿cierto?<br><br><!--ANKI_NOTE_ID:1786580332321--> |
