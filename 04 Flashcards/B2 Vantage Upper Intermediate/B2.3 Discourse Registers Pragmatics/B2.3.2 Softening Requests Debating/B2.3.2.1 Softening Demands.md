#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-3-Discourse-Registers-Pragmatics/B2-3-2-Softening-Requests-Debating/B2-3-2-1-Softening-Demands

| What does "¿Podrías + infinitive?" soften compared to "¿Puedes + infinitive?"? |
| ------------------------------------------------------------------------------------------------- |
|  It softens "can you" into "could you," making the request gentler<br><br><!--ANKI_NOTE_ID:1786580598693--> |

| Translate, softened: Could you send me the report before Friday? |
| ------------------------------------------------------------------------------------ |
|  ¿Podrías enviarme el informe antes del viernes?<br><br><!--ANKI_NOTE_ID:1786580598705--> |

| What does "Sería bueno que + subjunctive" do to a demand? |
| ------------------------------------------------------------------------------ |
|  Frames it as a general suggestion rather than a direct order<br><br><!--ANKI_NOTE_ID:1786580598709--> |

| Translate, softened: It would be good if you arrived on time. |
| -------------------------------------------------------------------------------- |
|  Sería bueno que llegaras a tiempo.<br><br><!--ANKI_NOTE_ID:1786580598713--> |

| How does "Necesitaría que + subjunctive" compare to the blunter "Necesito que + subjunctive"? |
| --------------------------------------------------------------------------------------------------------------- |
|  Necesitaría is noticeably gentler than the present-tense necesito for the same request<br><br><!--ANKI_NOTE_ID:1786580598717--> |

| Fix the mistake: "Necesito que revisas esto." |
| ------------------------------------------------------------------- |
|  Necesito que revises esto. (necesitar que is a subjunctive trigger, so the verb must be subjunctive)<br><br><!--ANKI_NOTE_ID:1786580598721--> |

| Translate, softened: I would appreciate it if you let me know ahead of time. |
| -------------------------------------------------------------------------------------------------- |
|  Te agradecería que me avisaras con tiempo.<br><br><!--ANKI_NOTE_ID:1786580598724--> |

| When is "para que + subjunctive" needed instead of plain "para + infinitive"? |
| --------------------------------------------------------------------------------------------------- |
|  When the subject changes between the two clauses<br><br><!--ANKI_NOTE_ID:1786580598727--> |

| Fix the mistake: "Sería mejor para que yo llegara temprano." (only one subject, the speaker, is involved) |
| ---------------------------------------------------------------------------------------------------------------------------- |
|  Sería mejor llegar temprano. (no subject change, so plain para/no para que + infinitive is more natural here)<br><br><!--ANKI_NOTE_ID:1786580598731--> |

| Translate: It would be better if we talked about this in private. |
| ------------------------------------------------------------------------------------ |
|  Sería mejor que habláramos en privado sobre esto.<br><br><!--ANKI_NOTE_ID:1786580598734--> |

| Are these softened forms a replacement for basic imperatives in every context, or a tool for tone? |
| -------------------------------------------------------------------------------------------------------------------- |
|  A tool for tone — a direct command isn't wrong, just blunter, depending on the situation<br><br><!--ANKI_NOTE_ID:1786580598737--> |

| Translate: To avoid misunderstandings, it would be better to confirm in writing. |
| ---------------------------------------------------------------------------------------------------- |
|  Para evitar malentendidos, sería mejor confirmar por escrito.<br><br><!--ANKI_NOTE_ID:1786580598740--> |
