#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-3-Discourse-Registers-Pragmatics/B2-3-3-Direct-Indirect-Reported-Speech/B2-3-3-2-Pronoun-and-Reference-Adjustments

| Besides tense, what two other kinds of words shift when you report speech in Spanish? |
| --------------------------------------------------------------------------------------------------------- |
|  Pronouns/possessives, and time/place words<br><br><!--ANKI_NOTE_ID:1786616452273--> |

| Convert to reported speech: Sara dijo: "Voy a mi casa." |
| --------------------------------------------------------------------------- |
|  Sara dijo que iba a su casa. (possessive shift: mi → su)<br><br><!--ANKI_NOTE_ID:1786616452284--> |

| What does the possessive "mi/mío" usually shift to when reporting someone else's words? |
| --------------------------------------------------------------------------------------------------------- |
|  su/suyo<br><br><!--ANKI_NOTE_ID:1786616452300--> |

| Fix the mistake: "Sara dijo que iba a mi casa" (reported as a third party, not your own house). |
| ----------------------------------------------------------------------------------------------------------------- |
|  Sara dijo que iba a su casa. (the possessive must shift to match Sara, not the reporter)<br><br><!--ANKI_NOTE_ID:1786616452304--> |

| What does the time word "hoy" (today) shift to in reported speech? |
| -------------------------------------------------------------------------------------- |
|  ese día (that day)<br><br><!--ANKI_NOTE_ID:1786616452307--> |

| Convert to reported speech: María dijo: "Llego hoy." |
| ----------------------------------------------------------------------- |
|  María dijo que llegaba ese día.<br><br><!--ANKI_NOTE_ID:1786616452310--> |

| What does "ayer" (yesterday) shift to in reported speech? |
| ----------------------------------------------------------------------------- |
|  el día anterior (the day before)<br><br><!--ANKI_NOTE_ID:1786616452313--> |

| Convert to reported speech: Juan dijo: "Te vi ayer." |
| ---------------------------------------------------------------------- |
|  Juan dijo que me había visto el día anterior.<br><br><!--ANKI_NOTE_ID:1786616452316--> |

| What does "mañana" (tomorrow) shift to in reported speech? |
| ------------------------------------------------------------------------------ |
|  al día siguiente (the next day)<br><br><!--ANKI_NOTE_ID:1786616452319--> |

| Convert to reported speech: Ana dijo: "Nos vemos mañana." |
| ---------------------------------------------------------------------------- |
|  Ana dijo que nos veríamos al día siguiente.<br><br><!--ANKI_NOTE_ID:1786616452322--> |

| Fix the mistake: "María dijo que llegaba hoy" (reported the next day, not the same day). |
| ---------------------------------------------------------------------------------------------------------- |
|  María dijo que llegaba ese día. (hoy only works if reporting on the very same day)<br><br><!--ANKI_NOTE_ID:1786616452325--> |

| What does the place word "aquí" (here) shift to in reported speech? |
| --------------------------------------------------------------------------------------- |
|  allí/ahí (there)<br><br><!--ANKI_NOTE_ID:1786616452327--> |

| Convert to reported speech: Sara dijo: "Voy aquí." |
| ------------------------------------------------------------------- |
|  Sara dijo que iba allí.<br><br><!--ANKI_NOTE_ID:1786616452330--> |

| Fix the mistake: "Sara dijo que iba aquí" (reported by someone standing somewhere else). |
| ---------------------------------------------------------------------------------------------------------- |
|  Sara dijo que iba allí. (aquí only stays correct if the reporter is still in that same spot)<br><br><!--ANKI_NOTE_ID:1786616452333--> |

| Which direction do demonstratives like "este/esta" (this) usually shift in reported speech? |
| ----------------------------------------------------------------------------------------------------------- |
|  Toward "ese/esa" (that) — away from "near me," since the reporter isn't standing where the original statement was made<br><br><!--ANKI_NOTE_ID:1786616452335--> |

| Convert to reported speech: Pedro dijo: "Este libro es mío." |
| -------------------------------------------------------------------------------- |
|  Pedro dijo que ese libro era suyo. (demonstrative + possessive shift)<br><br><!--ANKI_NOTE_ID:1786616452338--> |

| Do all pronoun, time, and place shifts always apply in every reported sentence? |
| ------------------------------------------------------------------------------------------------- |
|  No — only make the shift that's actually relevant to how far the report has moved from the original moment and place<br><br><!--ANKI_NOTE_ID:1786616452340--> |

| Why might it sound unnatural to change "aquí" to "allí" when reporting something said moments ago, in the same place? |
| ------------------------------------------------------------------------------------------------------------------------------------------------ |
|  Because the shift isn't needed yet — the speaker hasn't actually moved away from the original place or time<br><br><!--ANKI_NOTE_ID:1786616452343--> |

| Translate, applying the pronoun and time shifts: Juan said he was going to his house today (reported later that day). |
| ------------------------------------------------------------------------------------------------------------------------------------------------ |
|  Juan dijo que iba a su casa ese día.<br><br><!--ANKI_NOTE_ID:1786616452346--> |

| Translate, applying the place shift: Pedro said this book was his (reported from somewhere else). |
| -------------------------------------------------------------------------------------------------------------------- |
|  Pedro dijo que ese libro era suyo.<br><br><!--ANKI_NOTE_ID:1786616452348--> |
