#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-3-Discourse-Registers-Pragmatics/B2-3-3-Direct-Indirect-Reported-Speech/B2-3-3-1-Tense-Shifts-Past-Reporting

| When does the reported-speech tense shift pattern apply — only when the reporting verb is in what tense? |
| ----------------------------------------------------------------------------------------------------------------------------- |
|  The past (e.g. dijo, preguntó) — a present reporting verb causes no tense shift<br><br><!--ANKI_NOTE_ID:1786581131493--> |

| Convert to reported speech: Juan dijo: "Estoy cansado." |
| -------------------------------------------------------------------------- |
|  Juan dijo que estaba cansado. (present → imperfect)<br><br><!--ANKI_NOTE_ID:1786581131495--> |

| What does the future tense shift to in reported past speech? |
| ------------------------------------------------------------------------------- |
|  The conditional<br><br><!--ANKI_NOTE_ID:1786581131509--> |

| Convert to reported speech: María dijo: "Iré a la playa mañana." |
| ------------------------------------------------------------------------------------ |
|  María dijo que iría a la playa al día siguiente. (future → conditional)<br><br><!--ANKI_NOTE_ID:1786581131519--> |

| What does the present perfect ("he terminado") shift to in reported past speech? |
| -------------------------------------------------------------------------------------------------- |
|  The pluperfect (había terminado)<br><br><!--ANKI_NOTE_ID:1786581131523--> |

| Convert to reported speech: María dijo: "He terminado mi tarea." |
| ------------------------------------------------------------------------------------ |
|  María dijo que había terminado su tarea.<br><br><!--ANKI_NOTE_ID:1786581131526--> |

| What does a direct command (imperative) shift to in reported speech? |
| -------------------------------------------------------------------------------------- |
|  The imperfect subjunctive<br><br><!--ANKI_NOTE_ID:1786581131529--> |

| Convert to reported speech: Juan dijo: "Cierra la puerta." |
| ------------------------------------------------------------------------------- |
|  Juan dijo que cerrara la puerta.<br><br><!--ANKI_NOTE_ID:1786581131532--> |

| Fix the mistake: "Juan dijo que está cansado." |
| -------------------------------------------------------------------- |
|  Juan dijo que estaba cansado. (dijo sets a past frame, so the quoted present must shift to imperfect)<br><br><!--ANKI_NOTE_ID:1786581131535--> |

| Do the imperfect and pluperfect tenses change at all when reported in the past? |
| ------------------------------------------------------------------------------------------------- |
|  No — they stay the same, since they're already "far enough back" in the past<br><br><!--ANKI_NOTE_ID:1786581131537--> |

| When can you keep the present tense in reported speech even after a past reporting verb? |
| -------------------------------------------------------------------------------------------------------- |
|  If the statement is still true now, or you're repeating something just said in conversation<br><br><!--ANKI_NOTE_ID:1786581131540--> |

| Translate, keeping the present because it's still true: She told me she lives in Cochabamba. |
| ------------------------------------------------------------------------------------------------------------- |
|  Me dijo que vive en Cochabamba.<br><br><!--ANKI_NOTE_ID:1786581131542--> |
