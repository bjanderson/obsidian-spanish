#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-2-Passive-Voice-Impersonal-Se/B2-2-3-Accidental-Unintentional-Se/B2-2-3-1-Accidental-Se-Structure

| What four parts build the accidental se construction, in order? |
| ---------------------------------------------------------------------------------- |
|  Se + indirect object pronoun + verb + the thing involved (as grammatical subject)<br><br><!--ANKI_NOTE_ID:1786579397168--> |

| In "Se me cayó el vaso," does the verb agree with "me" or with "el vaso"? |
| ------------------------------------------------------------------------------------------- |
|  El vaso — the verb always agrees with the thing involved, not the person<br><br><!--ANKI_NOTE_ID:1786579397180--> |

| Translate: I forgot my cellphone at home. |
| --------------------------------------------------------- |
|  Se me olvidó el celular en casa.<br><br><!--ANKI_NOTE_ID:1786579397183--> |

| Fix the mistake: "Se me cayeron el vaso." |
| --------------------------------------------------------- |
|  Se me cayó el vaso. (el vaso is singular, so the verb must be singular too)<br><br><!--ANKI_NOTE_ID:1786579397186--> |

| Translate: They dropped their cameras. |
| -------------------------------------------------------- |
|  A ellos se les cayeron las cámaras.<br><br><!--ANKI_NOTE_ID:1786579397189--> |

| Which indirect object pronoun is ambiguous on its own and often needs "a + person" to clarify who it happened to? |
| ---------------------------------------------------------------------------------------------------------------------------------- |
|  Le / les<br><br><!--ANKI_NOTE_ID:1786579397192--> |

| Translate, clarifying who with "a + name": Javier's headphones broke. |
| ------------------------------------------------------------------------------------------- |
|  A Javier se le rompieron los audífonos.<br><br><!--ANKI_NOTE_ID:1786579397195--> |

| Fix the mistake: "Olvidó el celular." (meant as "I forgot my phone," accidentally) |
| ------------------------------------------------------------------------------------------------- |
|  Se me olvidó el celular. (the accidental se construction needs se + the indirect object pronoun)<br><br><!--ANKI_NOTE_ID:1786579397198--> |

| Translate: María lost her passport at the airport. |
| -------------------------------------------------------------------- |
|  A María se le perdió el pasaporte en el aeropuerto.<br><br><!--ANKI_NOTE_ID:1786579397200--> |

| What effect does the accidental se construction have on who seems responsible for what happened? |
| ------------------------------------------------------------------------------------------------------------------- |
|  It softens responsibility — framing the event as something that happened to the person, not something they did<br><br><!--ANKI_NOTE_ID:1786579397203--> |

| Translate: Our window broke. |
| ---------------------------------------------- |
|  Se nos rompió la ventana.<br><br><!--ANKI_NOTE_ID:1786579397206--> |

| Name three common verbs that pair naturally with this accidental se construction. |
| --------------------------------------------------------------------------------------------------- |
|  Any three of: olvidarse, caerse, romperse, perderse, acabarse<br><br><!--ANKI_NOTE_ID:1786579397208--> |
