#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-2-Passive-Voice-Impersonal-Se/B2-2-3-Accidental-Unintentional-Se/B2-2-3-2-Shifting-Fault-away-from-Speaker

| What effect does saying "Se me rompió el vaso" have compared to "Rompí el vaso"? |
| ---------------------------------------------------------------------------------------------------- |
|  It softens blame — the glass grammatically becomes the one "doing" the breaking, not the speaker<br><br><!--ANKI_NOTE_ID:1786579613917--> |

| Is using the accidental se construction a way of lying about what happened? |
| ------------------------------------------------------------------------------------------------- |
|  No — it's simply the natural, unmarked way Spanish speakers describe a genuine accident<br><br><!--ANKI_NOTE_ID:1786579613920--> |

| Translate using the accidental se: I lost the keys (as an accident). |
| ---------------------------------------------------------------------------------------- |
|  Se me perdieron las llaves.<br><br><!--ANKI_NOTE_ID:1786579613923--> |

| Fix the register: "Se me rompió el plato a propósito." |
| -------------------------------------------------------------------------- |
|  Rompí el plato a propósito. (the accidental se construction contradicts "on purpose")<br><br><!--ANKI_NOTE_ID:1786579613925--> |

| Translate, softening blame with accidental se: The food burned on me. |
| ------------------------------------------------------------------------------------------- |
|  Se me quemó la comida.<br><br><!--ANKI_NOTE_ID:1786579613928--> |

| What happens to the meaning of "Se rompió el vaso" if you drop the indirect object pronoun entirely? |
| ---------------------------------------------------------------------------------------------------------------------- |
|  It just says "the glass broke," with no indication of whose fault or involvement it was<br><br><!--ANKI_NOTE_ID:1786579613932--> |

| Translate, English (accidental se style): The homework slipped my mind. |
| --------------------------------------------------------------------------------------------- |
|  Se me olvidó la tarea.<br><br><!--ANKI_NOTE_ID:1786579613936--> |

| Why might using accidental se sound odd for something you clearly did on purpose? |
| --------------------------------------------------------------------------------------------------- |
|  Because the construction is reserved for genuine accidents — it clashes with deliberate intent<br><br><!--ANKI_NOTE_ID:1786579613940--> |

| Translate: The phone fell out of my hands (as an accident). |
| -------------------------------------------------------------------------------- |
|  Se me cayó el teléfono.<br><br><!--ANKI_NOTE_ID:1786579613942--> |

| What does reaching for the accidental se construction at the right moment signal about a learner's Spanish? |
| ---------------------------------------------------------------------------------------------------------------------------- |
|  It's a mark of natural, fluent Spanish — English has no direct equivalent, so learners often default to the blunter, direct phrasing<br><br><!--ANKI_NOTE_ID:1786579613945--> |

| Fix the mistake: someone says "Olvidé la cita" when they want to soften the blame with accidental se. |
| ----------------------------------------------------------------------------------------------------------------------- |
|  Se me olvidó la cita.<br><br><!--ANKI_NOTE_ID:1786579613947--> |

| Translate: I'm sorry, your message slipped by me with everything going on. |
| ---------------------------------------------------------------------------------------------- |
|  Disculpa, se me pasó tu mensaje entre tantas cosas.<br><br><!--ANKI_NOTE_ID:1786579613950--> |
