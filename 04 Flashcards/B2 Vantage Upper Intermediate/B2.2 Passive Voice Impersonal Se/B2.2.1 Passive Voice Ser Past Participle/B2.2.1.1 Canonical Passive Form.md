#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-2-Passive-Voice-Impersonal-Se/B2-2-1-Passive-Voice-Ser-Past-Participle/B2-2-1-1-Canonical-Passive-Form

| What three parts build the canonical Spanish passive voice? |
| ------------------------------------------------------------------------------ |
|  Ser (conjugated) + past participle + optional por-phrase naming the agent<br><br><!--ANKI_NOTE_ID:1786578353943--> |

| Does the past participle agree in gender and number with the subject in this construction? |
| ------------------------------------------------------------------------------------------------------------- |
|  Yes — unlike the perfect tenses, the participle changes to match the subject here<br><br><!--ANKI_NOTE_ID:1786578353956--> |

| Fix the mistake: "La carta fue escrito por Ana." |
| ------------------------------------------------------------------ |
|  La carta fue escrita por Ana. (the participle must agree with the feminine singular subject la carta)<br><br><!--ANKI_NOTE_ID:1786578353962--> |

| Translate: The books were written by several authors. |
| -------------------------------------------------------------------------- |
|  Los libros fueron escritos por varios autores.<br><br><!--ANKI_NOTE_ID:1786578353967--> |

| What tense should "ser" be conjugated in for a passive sentence? |
| --------------------------------------------------------------------------------- |
|  The same tense as the original active sentence's verb<br><br><!--ANKI_NOTE_ID:1786578353972--> |

| Fix the mistake: "El premio es otorgado ayer." (describing something that happened yesterday) |
| ------------------------------------------------------------------------------------------------------------------ |
|  El premio fue otorgado ayer. (ser must match the tense of the action — past here, not present)<br><br><!--ANKI_NOTE_ID:1786578353977--> |

| Is the "por" phrase in a passive sentence required? |
| -------------------------------------------------------------------- |
|  No — it's optional, included only when who did the action matters or is worth naming<br><br><!--ANKI_NOTE_ID:1786578353982--> |

| Translate: The results will be announced tomorrow. |
| -------------------------------------------------------------------- |
|  Los resultados serán anunciados mañana.<br><br><!--ANKI_NOTE_ID:1786578353987--> |

| Fix the mistake: "La cena estuvo preparada por el chef." (describing the passive action itself, not a resulting state) |
| ------------------------------------------------------------------------------------------------------------------------------------------- |
|  La cena fue preparada por el chef. (the ser passive is needed here, not estar)<br><br><!--ANKI_NOTE_ID:1786578353990--> |

| Translate: The prize is awarded every year by the committee. |
| ------------------------------------------------------------------------------- |
|  El premio es otorgado cada año por el comité.<br><br><!--ANKI_NOTE_ID:1786578353994--> |

| In what kind of register is this ser + past participle passive most commonly found? |
| ------------------------------------------------------------------------------------------------------- |
|  Formal, written registers — news writing, history, academic text<br><br><!--ANKI_NOTE_ID:1786578353997--> |

| Convert to passive voice: "El ingeniero diseñó el puente." |
| ------------------------------------------------------------------------------- |
|  El puente fue diseñado por el ingeniero.<br><br><!--ANKI_NOTE_ID:1786578354001--> |
