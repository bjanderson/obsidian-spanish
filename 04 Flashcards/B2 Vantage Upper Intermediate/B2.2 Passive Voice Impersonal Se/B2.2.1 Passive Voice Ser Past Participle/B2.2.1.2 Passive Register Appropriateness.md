#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-2-Passive-Voice-Impersonal-Se/B2-2-1-Passive-Voice-Ser-Past-Participle/B2-2-1-2-Passive-Register-Appropriateness

| In what kind of context does the ser + past participle passive sound most natural? |
| -------------------------------------------------------------------------------------------------------- |
|  Formal, written contexts — news, history, academic writing, official announcements<br><br><!--ANKI_NOTE_ID:1786578632042--> |

| Name two everyday spoken alternatives to the ser + past participle passive. |
| ------------------------------------------------------------------------------------------------ |
|  The passive se, and the active voice (or unspecified third-person plural)<br><br><!--ANKI_NOTE_ID:1786578632066--> |

| Fix the register: "La cena fue preparada por mi mamá," said casually at the dinner table. |
| ----------------------------------------------------------------------------------------------------------- |
|  Mi mamá preparó la cena. / Se preparó la cena. (the ser passive sounds too formal for casual speech)<br><br><!--ANKI_NOTE_ID:1786578632069--> |

| Translate using the passive se (spoken, everyday): The treaty was signed. |
| ------------------------------------------------------------------------------------------- |
|  Se firmó el tratado.<br><br><!--ANKI_NOTE_ID:1786578632072--> |

| Is the ser + past participle passive grammatically wrong in casual conversation? |
| -------------------------------------------------------------------------------------------------- |
|  No — it's fully correct, just register-mismatched; it sounds more formal/written than casual speech calls for<br><br><!--ANKI_NOTE_ID:1786578632075--> |

| When does the ser + past participle passive stay natural even in speech? |
| -------------------------------------------------------------------------------------------- |
|  When who did the action truly matters or is worth emphasizing<br><br><!--ANKI_NOTE_ID:1786578632078--> |

| Translate using an unspecified third-person plural (spoken, everyday): They canceled the concert. |
| --------------------------------------------------------------------------------------------------------------------- |
|  Cancelaron el concierto.<br><br><!--ANKI_NOTE_ID:1786578632081--> |

| Fix the register: "El carro fue reparado ayer" said casually to a friend. |
| ------------------------------------------------------------------------------------------- |
|  Se reparó el carro ayer. (a spoken alternative sounds more natural than the ser passive here)<br><br><!--ANKI_NOTE_ID:1786578632083--> |

| Is this a strict grammar rule or a tendency in register? |
| ------------------------------------------------------------------------- |
|  A tendency — native speakers do use the ser passive in speech sometimes, especially in formal spoken contexts<br><br><!--ANKI_NOTE_ID:1786578632086--> |

| Translate, keeping the ser passive because the agent matters: The goal was scored by Messi. |
| ------------------------------------------------------------------------------------------------------------- |
|  El gol fue anotado por Messi.<br><br><!--ANKI_NOTE_ID:1786578632088--> |

| What is the simple rule of thumb for choosing between the ser passive and its alternatives? |
| ------------------------------------------------------------------------------------------------------------- |
|  If you can rephrase the sentence without ser + participle, it's usually worth doing, especially in casual speech<br><br><!--ANKI_NOTE_ID:1786578632090--> |

| Translate using the passive se (spoken, everyday): The bridge was built last year. |
| -------------------------------------------------------------------------------------------------- |
|  Se construyó el puente el año pasado.<br><br><!--ANKI_NOTE_ID:1786578632093--> |
