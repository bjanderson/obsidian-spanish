#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-2-Passive-Voice-Impersonal-Se/B2-2-2-Impersonal-Passive-Se/B2-2-2-1-Passive-Se-Inanimate-Objects

| What word goes before the verb to build the passive se construction? |
| -------------------------------------------------------------------------------------- |
|  Se<br><br><!--ANKI_NOTE_ID:1786578848669--> |

| Does the verb in a passive se sentence agree in number with the object? |
| -------------------------------------------------------------------------------------------- |
|  Yes — singular object takes a singular verb, plural object takes a plural verb<br><br><!--ANKI_NOTE_ID:1786578848673--> |

| Translate: This house is for sale. |
| ---------------------------------------------------- |
|  Se vende esta casa.<br><br><!--ANKI_NOTE_ID:1786578848675--> |

| Fix the mistake: "Se vende estas casas." |
| ------------------------------------------------------------ |
|  Se venden estas casas. (the verb must agree with the plural object)<br><br><!--ANKI_NOTE_ID:1786578848678--> |

| Translate: These houses are for sale. |
| ------------------------------------------------------- |
|  Se venden estas casas.<br><br><!--ANKI_NOTE_ID:1786578848680--> |

| Does the passive se construction work with people as the object, the way ser + participle can? |
| ----------------------------------------------------------------------------------------------------------------- |
|  No — passive se is for inanimate objects only<br><br><!--ANKI_NOTE_ID:1786578848683--> |

| Translate: Experienced waiters wanted. |
| -------------------------------------------------------- |
|  Se buscan meseros con experiencia.<br><br><!--ANKI_NOTE_ID:1786578848686--> |

| Where does the object usually go in a passive se sign or announcement — before or after the verb? |
| ------------------------------------------------------------------------------------------------------------------- |
|  After the verb (e.g. Se venden casas, not Casas se venden)<br><br><!--ANKI_NOTE_ID:1786578848689--> |

| Translate: Credit cards accepted. |
| --------------------------------------------------- |
|  Se aceptan tarjetas de crédito.<br><br><!--ANKI_NOTE_ID:1786578848692--> |

| What kind of verbs does the passive se construction work with? |
| ----------------------------------------------------------------------------------- |
|  Transitive verbs — ones that normally take a direct object<br><br><!--ANKI_NOTE_ID:1786578848695--> |

| Fix the mistake: "Se necesita voluntarios para el evento." |
| ------------------------------------------------------------------------------- |
|  Se necesitan voluntarios para el evento. (voluntarios is plural, so the verb must be plural too)<br><br><!--ANKI_NOTE_ID:1786578848697--> |

| Translate: An accountant is needed for the company. |
| -------------------------------------------------------------------- |
|  Se necesita un contador para la empresa.<br><br><!--ANKI_NOTE_ID:1786578848700--> |
