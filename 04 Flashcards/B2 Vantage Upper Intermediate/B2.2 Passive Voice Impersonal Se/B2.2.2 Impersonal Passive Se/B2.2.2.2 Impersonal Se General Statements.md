#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-2-Passive-Voice-Impersonal-Se/B2-2-2-Impersonal-Passive-Se/B2-2-2-2-Impersonal-Se-General-Statements

| What person and number is the verb in impersonal se always conjugated in? |
| ---------------------------------------------------------------------------------------------- |
|  3rd person singular, no matter what<br><br><!--ANKI_NOTE_ID:1786579102819--> |

| Translate: Spanish is spoken in many countries. |
| --------------------------------------------------------------- |
|  Se habla español en muchos países.<br><br><!--ANKI_NOTE_ID:1786579102830--> |

| What is the main difference between impersonal se and passive se? |
| -------------------------------------------------------------------------------------- |
|  Passive se has a grammatical subject that controls verb agreement; impersonal se has no such subject and the verb always stays singular<br><br><!--ANKI_NOTE_ID:1786579102841--> |

| Fix the mistake: "Se necesitan paciencia para este trabajo." |
| ------------------------------------------------------------------------------- |
|  Se necesita paciencia para este trabajo. (paciencia isn't a grammatical subject here, so the verb stays singular)<br><br><!--ANKI_NOTE_ID:1786579102844--> |

| Translate: They say it's going to rain. |
| ------------------------------------------------------------------- |
|  Se dice que va a llover.<br><br><!--ANKI_NOTE_ID:1786579102847--> |

| Fix the mistake: "Se vende casas." |
| ---------------------------------------------------- |
|  Se venden casas. (with a clear inanimate object like casas, passive se rules apply, not impersonal se)<br><br><!--ANKI_NOTE_ID:1786579102849--> |

| Translate: The food is really good at this restaurant. |
| -------------------------------------------------------------------------- |
|  Se come muy bien en este restaurante.<br><br><!--ANKI_NOTE_ID:1786579102851--> |

| What kind of verbs is impersonal se especially common with, since they can't take the passive se pattern? |
| ---------------------------------------------------------------------------------------------------------------------------- |
|  Intransitive verbs — ones that don't take a direct object, like trabajar, vivir, dormir<br><br><!--ANKI_NOTE_ID:1786579102853--> |

| Translate: You shouldn't smoke here. |
| ---------------------------------------------------------- |
|  No se debe fumar aquí.<br><br><!--ANKI_NOTE_ID:1786579102856--> |

| Translate: People work a lot at that company. |
| ------------------------------------------------------------------- |
|  Se trabaja mucho en esa empresa.<br><br><!--ANKI_NOTE_ID:1786579102858--> |

| What kind of everyday statements does impersonal se show up in constantly? |
| ---------------------------------------------------------------------------------------------- |
|  Advice and general truths (e.g. what it takes to do something, or general rules)<br><br><!--ANKI_NOTE_ID:1786579102860--> |

| Translate: Life is peaceful in this town. |
| --------------------------------------------------------- |
|  Se vive tranquilo en este pueblo.<br><br><!--ANKI_NOTE_ID:1786579102862--> |
