| What does "costar un ojo de la cara" mean? |
| -------------------------------------------------------------- |
|  To be very expensive (literally "to cost an eye of the face")<br><br><!--ANKI_NOTE_ID:1786617489460--> |

| Fill in the idiom: Tranquilo, este examen es ___ ___. (it's very easy) |
| ------------------------------------------------------------------------------------------ |

| What does "ser pan comido" mean? |
| ---------------------------------------------------- |
|  To be a piece of cake — very easy<br><br><!--ANKI_NOTE_ID:1786617489467--> |

| What do you say in Spanish when you unexpectedly run into someone you know? |
| ------------------------------------------------------------------------------------------------ |
|  ¡El mundo es un pañuelo! (It's a small world!)<br><br><!--ANKI_NOTE_ID:1786617489470--> |

| Translate: Speak of the devil, here comes Carlos. |
| ------------------------------------------------------------------- |
|  Hablando del rey de Roma, ahí viene Carlos.<br><br><!--ANKI_NOTE_ID:1786617489474--> |

| What does "no tener vela en este entierro" mean? |
| -------------------------------------------------------------------- |
|  To have no say in the matter / it's none of your business<br><br><!--ANKI_NOTE_ID:1786617489477--> |

| What does "la gota que colmó el vaso" mean, and what's the English equivalent? |
| ----------------------------------------------------------------------------------------------------- |
|  The final small thing that makes a situation unbearable — "the straw that broke the camel's back"<br><br><!--ANKI_NOTE_ID:1786617489480--> |

| What does "hacer una montaña de un grano de arena" mean? |
| ---------------------------------------------------------------------------- |
|  To make a mountain out of a molehill — to overreact to something small<br><br><!--ANKI_NOTE_ID:1786617489484--> |

| What does "tener mala leche" mean, and where is it most common? |
| ------------------------------------------------------------------------------------ |
|  To have bad luck, or to have a mean/bad-tempered streak — more common in Spain; most of Latin America says *estar de malas* instead<br><br><!--ANKI_NOTE_ID:1786617489487--> |

| Fix the mistake: "dar en el tornillo" (meant to say someone got something exactly right). |
| ----------------------------------------------------------------------------------------------------------- |
|  Dar en el clavo. (idioms are fixed — you can't swap "clavo" for a similar object like "tornillo")<br><br><!--ANKI_NOTE_ID:1786617489490--> |

| Translate, using an idiom: Don't make a mountain out of a molehill, it was just a small mistake. |
| ------------------------------------------------------------------------------------------------------------------ |
|  No hagas una montaña de un grano de arena, fue solo un error pequeño.<br><br><!--ANKI_NOTE_ID:1786617489493--> |

| Why is it a mistake to translate Spanish idioms word for word? |
| --------------------------------------------------------------------------------- |
|  Because their meaning comes from the whole fixed phrase, not the individual words — a literal translation usually makes no sense<br><br><!--ANKI_NOTE_ID:1786617489497--> |

| What makes an idiom different from ordinary slang, in terms of where it's understood? |
| ------------------------------------------------------------------------------------------------------- |
|  Trans-regional idioms are recognized across nearly every Spanish-speaking country, while slang is often specific to one country<br><br><!--ANKI_NOTE_ID:1786617489500--> |

| Translate: I'd rather not weigh in — it's none of my business. |
| --------------------------------------------------------------------------------- |
|  Prefiero no opinar — no tengo vela en este entierro.<br><br><!--ANKI_NOTE_ID:1786617489503--> |

| Complete the idiom: Hablando del rey de Roma, ___ ___ se ___. |
| ------------------------------------------------------------------------------- |
|  por la puerta se asoma<br><br><!--ANKI_NOTE_ID:1786617489506--> |

| Translate, using the most typical Latin American phrasing: My uncle is in a bad mood today, better not ask him anything. |
| ------------------------------------------------------------------------------------------------------------------------------------ |
|  Mi tío está de malas hoy, mejor no le preguntes nada. (*tiene mala leche* also works, but is more associated with Spain)<br><br><!--ANKI_NOTE_ID:1786617489509--> |
