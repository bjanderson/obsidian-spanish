| Which word for "cool" is the closest thing to a universal option across Latin America? |
| ------------------------------------------------------------------------------------------------------- |
|  Chévere<br><br><!--ANKI_NOTE_ID:1786617626400--> |

| What is the Mexico-specific word for "cool"? |
| -------------------------------------------------------------- |
|  Chido<br><br><!--ANKI_NOTE_ID:1786617626404--> |

| What is the Argentina-specific word for "cool"? |
| ----------------------------------------------------------------- |
|  Copado (also bárbaro)<br><br><!--ANKI_NOTE_ID:1786617626409--> |

| What is the Peru-specific word for "cool"? |
| ------------------------------------------------------------ |
|  Bacán<br><br><!--ANKI_NOTE_ID:1786617626413--> |

| What is the Colombia-specific word for "cool"? |
| ---------------------------------------------------------------- |
|  Nota (used as ¡qué nota!)<br><br><!--ANKI_NOTE_ID:1786617626417--> |

| What does "pura vida" mean in Costa Rica, and how is its use broader than just "cool"? |
| ------------------------------------------------------------------------------------------------------- |
|  It means roughly "all good" — it's also used as a greeting, farewell, and general response to "how are you?"<br><br><!--ANKI_NOTE_ID:1786617626421--> |

| Translate: That car is really cool. (use the Mexico-specific word) |
| ----------------------------------------------------------------------------------------- |
|  Ese carro está bien chido.<br><br><!--ANKI_NOTE_ID:1786617626425--> |

| Translate: How cool, your new job! (use the Colombia-specific word) |
| ------------------------------------------------------------------------------------------ |
|  ¡Qué nota tu nuevo trabajo!<br><br><!--ANKI_NOTE_ID:1786617626430--> |

| Translate: The party was great. (use the Argentina-specific word) |
| -------------------------------------------------------------------------------------- |
|  La fiesta estuvo copada.<br><br><!--ANKI_NOTE_ID:1786617626434--> |

| Translate: This place is really cool. (use the Peru-specific word) |
| ----------------------------------------------------------------------------------------- |
|  Este lugar es bien bacán.<br><br><!--ANKI_NOTE_ID:1786617626438--> |

| Translate: Everything's fine, all good. (use the Costa Rica expression) |
| -------------------------------------------------------------------------------------------- |
|  Todo tranquilo, pura vida.<br><br><!--ANKI_NOTE_ID:1786617626443--> |

| Why would a traveler who only ever says "chévere" still be understood everywhere in Latin America, even outside Venezuela and Colombia? |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  Because it has spread widely enough that most Latin American Spanish speakers recognize it, even where a local word is more common day-to-day<br><br><!--ANKI_NOTE_ID:1786617626446--> |

| Why might using the local word for "cool" (rather than the universal one) get you a bigger smile from a local? |
| -------------------------------------------------------------------------------------------------------------------------------- |
|  It signals you've spent time there and picked up on the local flavor of Spanish, not just the textbook-safe option<br><br><!--ANKI_NOTE_ID:1786617626449--> |

| Fix the register mistake: using "chévere" in a formal work email. |
| -------------------------------------------------------------------------------------- |
|  Use a more formal word instead, like excelente or estupendo — chévere is casual, fine with friends but out of place in professional writing<br><br><!--ANKI_NOTE_ID:1786617626452--> |

| Can "chido" or "chévere" be conjugated like a verb? |
| ------------------------------------------------------------------- |
|  No — they're adjectives/exclamations that stay the same regardless of subject<br><br><!--ANKI_NOTE_ID:1786617626455--> |

| Translate: Your house is really cool. (use the widely-understood word) |
| ----------------------------------------------------------------------------------------- |
|  Tu casa está bien chévere.<br><br><!--ANKI_NOTE_ID:1786617626459--> |
