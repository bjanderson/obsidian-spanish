#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-4-Regional-Diversity-Colloquialisms/B2-4-2-Regional-Focus-Bolivia/B2-4-2-1-Mechanics-Regional-Voseo

| What is "voseo"? |
| -------------------------------------------- |
|  The use of vos instead of tú as the informal "you," standard in Argentina, Uruguay, Paraguay, much of Central America, and parts of Bolivia<br><br><!--ANKI_NOTE_ID:1786617816396--> |

| Conjugate "hablar" in the present tense for vos. |
| ---------------------------------------------------------------------- |
|  Vos hablás<br><br><!--ANKI_NOTE_ID:1786617816399--> |

| Conjugate "comer" in the present tense for vos. |
| --------------------------------------------------------------------- |
|  Vos comés<br><br><!--ANKI_NOTE_ID:1786617816401--> |

| Conjugate "vivir" in the present tense for vos. |
| --------------------------------------------------------------------- |
|  Vos vivís<br><br><!--ANKI_NOTE_ID:1786617816404--> |

| Why does "vos querés" have no stem change, unlike "tú quieres"? |
| ------------------------------------------------------------------------------------ |
|  Voseo present-tense forms are mostly regular, even for verbs that stem-change with tú<br><br><!--ANKI_NOTE_ID:1786617816406--> |

| Give the vos command form of "hablar." |
| -------------------------------------------------------------- |
|  Hablá<br><br><!--ANKI_NOTE_ID:1786617816408--> |

| Give the vos command form of "comer." |
| ------------------------------------------------------------- |
|  Comé<br><br><!--ANKI_NOTE_ID:1786617816410--> |

| How do you form a vos command from an infinitive? |
| ------------------------------------------------------------------- |
|  Drop the final -r and add an accent on the last vowel: hablar → hablá, comer → comé, vivir → viví<br><br><!--ANKI_NOTE_ID:1786617816412--> |

| Do object pronouns like "te" change between tú and vos? |
| -------------------------------------------------------------------------- |
|  No — te vi (I saw you) is identical whether the person uses tú or vos<br><br><!--ANKI_NOTE_ID:1786617816414--> |

| Which tenses besides the present and commands change with voseo? |
| ------------------------------------------------------------------------------------- |
|  Almost none — preterite, imperfect, future, and subjunctive mostly use the same forms as tú<br><br><!--ANKI_NOTE_ID:1786617816416--> |

| Translate: Do you speak Spanish? (use vos) |
| ------------------------------------------------------------ |
|  ¿Vos hablás español?<br><br><!--ANKI_NOTE_ID:1786617816418--> |

| Translate: Speak more slowly! (vos command) |
| ------------------------------------------------------------- |
|  ¡Hablá más despacio!<br><br><!--ANKI_NOTE_ID:1786617816420--> |

| Fix the mistake: "tú hablás" (mixing pronoun and verb form). |
| ------------------------------------------------------------------------------- |
|  Either "tú hablas" or "vos hablás" — don't mix a tú pronoun with a vos verb ending, or vice versa<br><br><!--ANKI_NOTE_ID:1786617816423--> |

| Is voseo considered incorrect or lower-prestige Spanish? |
| -------------------------------------------------------------------------- |
|  No — it's the standard informal form across large parts of Latin America and carries no less prestige than tú<br><br><!--ANKI_NOTE_ID:1786617816425--> |

| How does vos usage typically work alongside tú in Bolivia? |
| --------------------------------------------------------------------------- |
|  They coexist — vos is more common in casual, everyday speech, while tú is still heard in some contexts, varying by region and generation<br><br><!--ANKI_NOTE_ID:1786617816427--> |

| Translate: You want to go to the movies, right? (use vos) |
| -------------------------------------------------------------------------------- |
|  Vos querés ir al cine, ¿no?<br><br><!--ANKI_NOTE_ID:1786617816429--> |
