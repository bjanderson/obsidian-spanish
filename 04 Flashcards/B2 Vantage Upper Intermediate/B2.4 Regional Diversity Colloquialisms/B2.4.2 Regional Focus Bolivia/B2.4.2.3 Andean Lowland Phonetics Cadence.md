#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-4-Regional-Diversity-Colloquialisms/B2-4-2-Regional-Focus-Bolivia/B2-4-2-3-Andean-Lowland-Phonetics-Cadence

| What are the two broad Bolivian dialect regions discussed in this lesson? |
| -------------------------------------------------------------------------------------------- |
|  The Andean highlands (La Paz, Oruro, Potosí) and the eastern lowlands (Santa Cruz, Beni)<br><br><!--ANKI_NOTE_ID:1786618054748--> |

| How would you describe the rhythm of highland (Andean) Bolivian Spanish? |
| ------------------------------------------------------------------------------------------- |
|  More clipped and measured, with each syllable pronounced fairly clearly<br><br><!--ANKI_NOTE_ID:1786618054752--> |

| How would you describe the rhythm of lowland Bolivian Spanish (Santa Cruz, Beni)? |
| ---------------------------------------------------------------------------------------------------- |
|  Faster, more melodic, with a sing-song quality<br><br><!--ANKI_NOTE_ID:1786618054757--> |

| Which two indigenous languages have shaped the rhythm of highland Bolivian Spanish? |
| ---------------------------------------------------------------------------------------------------- |
|  Quechua and Aymara<br><br><!--ANKI_NOTE_ID:1786618054761--> |

| What tends to happen to a final "-s" in parts of lowland Bolivian speech? |
| ------------------------------------------------------------------------------------------- |
|  It can soften or drop, similar to patterns in coastal/lowland Spanish elsewhere in Latin America<br><br><!--ANKI_NOTE_ID:1786618054764--> |

| Does highland Bolivian Spanish tend to preserve or soften the final "-s" sound, compared to lowland speech? |
| ------------------------------------------------------------------------------------------------------------------------------- |
|  It tends to preserve the -s sound more clearly than lowland speech does<br><br><!--ANKI_NOTE_ID:1786618054768--> |

| Is a regional Bolivian accent a pronunciation "error" to correct? |
| -------------------------------------------------------------------------------------- |
|  No — it's a normal regional accent feature, the same way a regional accent in English isn't incorrect<br><br><!--ANKI_NOTE_ID:1786618054772--> |

| Translate: In La Paz they speak very clearly, pronouncing every syllable. |
| ------------------------------------------------------------------------------------------- |
|  En La Paz hablan bien clarito, pronunciando cada sílaba.<br><br><!--ANKI_NOTE_ID:1786618054776--> |

| Translate: People from Santa Cruz speak faster and with a sing-song quality. |
| -------------------------------------------------------------------------------------------------- |
|  Los cruceños hablan más rápido y cantadito.<br><br><!--ANKI_NOTE_ID:1786618054780--> |

| Why might a Bolivian often be able to guess where someone grew up just from a few seconds of their speech? |
| ------------------------------------------------------------------------------------------------------------------------------ |
|  Because highland and lowland Bolivian Spanish differ noticeably in rhythm, stress, and consonant handling<br><br><!--ANKI_NOTE_ID:1786618054785--> |

| What's the difference between studying Bolivian accent variation and studying Bolivian slang (like ch'aki or ya pues)? |
| ------------------------------------------------------------------------------------------------------------------------------------------ |
|  Accent is about how words sound; slang is about which words are used<br><br><!--ANKI_NOTE_ID:1786618054790--> |

| Translate: It's not a mistake, it's just the regional accent. |
| -------------------------------------------------------------------------------- |
|  No es un error, es solo el acento de la región.<br><br><!--ANKI_NOTE_ID:1786618054794--> |

| Fix the misconception: "The Santa Cruz accent is wrong; the La Paz accent is the correct way to speak Bolivian Spanish." |
| ------------------------------------------------------------------------------------------------------------------------------------------- |
|  Neither is "correct" or "incorrect" — they're both valid regional accents shaped by different influences and geography<br><br><!--ANKI_NOTE_ID:1786618054798--> |

| Translate: There, they drop the final -s at the end of words. |
| -------------------------------------------------------------------------------- |
|  Allá se come las eses al final de las palabras.<br><br><!--ANKI_NOTE_ID:1786618054802--> |
