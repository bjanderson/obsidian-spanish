| What does "ch'aki" mean, and where does the word come from? |
| -------------------------------------------------------------------------------- |
|  A hangover — specifically the dry, thirsty feeling the morning after drinking; it comes from Quechua<br><br><!--ANKI_NOTE_ID:1786617912746--> |

| Translate: I have a hangover, I shouldn't have drunk so much last night. |
| ------------------------------------------------------------------------------------------- |
|  Tengo ch'aki, no debí tomar tanto anoche.<br><br><!--ANKI_NOTE_ID:1786617912759--> |

| What does "ya pues" do in a Bolivian sentence? |
| ---------------------------------------------------------------- |
|  It's a filler/softener used to agree, wrap up a thought, or add mild emphasis — like "alright then" or "come on"<br><br><!--ANKI_NOTE_ID:1786617912763--> |

| Translate: Shall we meet at eight? — Alright then. |
| -------------------------------------------------------------------- |
|  ¿Nos vemos a las ocho? — Ya pues.<br><br><!--ANKI_NOTE_ID:1786617912767--> |

| Who is described as "choco/a" in Bolivia? |
| --------------------------------------------------------------- |
|  Someone from Bolivia's lowlands, particularly Santa Cruz<br><br><!--ANKI_NOTE_ID:1786617912771--> |

| Who is described as "colla" in Bolivia? |
| ------------------------------------------------------------- |
|  Someone from Bolivia's highlands / Andean region<br><br><!--ANKI_NOTE_ID:1786617912775--> |

| Is "choco" or "colla" automatically an insult? |
| ---------------------------------------------------------------- |
|  No — they're regional identity terms; tone and relationship determine whether they're playful or pointed<br><br><!--ANKI_NOTE_ID:1786617912779--> |

| Translate: My friend is from the lowlands, he's from Santa Cruz. |
| ------------------------------------------------------------------------------------- |
|  Mi amigo es choco, viene de Santa Cruz.<br><br><!--ANKI_NOTE_ID:1786617912784--> |

| Why is "ch'aki" not understood the same way outside Bolivia? |
| ------------------------------------------------------------------------------- |
|  It's a regional, Quechua-influenced term specific to Bolivian Spanish, not standard across Latin America<br><br><!--ANKI_NOTE_ID:1786617912789--> |

| Fix the register mistake: using "ya pues" in a formal essay. |
| ------------------------------------------------------------------------------- |
|  Don't — "ya pues" is a spoken filler for casual conversation, not appropriate in formal writing<br><br><!--ANKI_NOTE_ID:1786617912793--> |

| What broader influence shapes Bolivian Spanish beyond individual slang words? |
| ------------------------------------------------------------------------------------------------ |
|  Indigenous-language influence (Quechua and Aymara), which affects not just vocabulary but sometimes sentence rhythm<br><br><!--ANKI_NOTE_ID:1786617912798--> |

| Translate: The "collas" are from the Andean region of the country. |
| ----------------------------------------------------------------------------------------- |
|  Los collas son de la zona andina del país.<br><br><!--ANKI_NOTE_ID:1786617912802--> |

| Why shouldn't you assume Bolivian slang is interchangeable with slang from neighboring Andean countries? |
| ---------------------------------------------------------------------------------------------------------------------------- |
|  Bolivia's mix of Quechua and Aymara influence gives it a distinct flavor even from otherwise similar Andean Spanish<br><br><!--ANKI_NOTE_ID:1786617912806--> |

| Translate: Come on, don't be stubborn, let me know when you arrive. |
| ------------------------------------------------------------------------------------------ |
|  Ya pues, no seas necio y avisa cuando llegues.<br><br><!--ANKI_NOTE_ID:1786617912809--> |
