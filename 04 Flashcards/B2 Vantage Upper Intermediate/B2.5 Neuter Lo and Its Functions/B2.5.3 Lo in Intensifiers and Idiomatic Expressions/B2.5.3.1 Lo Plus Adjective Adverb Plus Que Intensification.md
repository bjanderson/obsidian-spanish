#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-5-Neuter-Lo-and-Its-Functions/B2-5-3-Lo-in-Intensifiers-and-Idiomatic-Expressions/B2-5-3-1-Lo-Plus-Adjective-Adverb-Plus-Que-Intensification

| What is the formula for the "lo + adjective/adverb + que" intensifier construction? |
| ------------------------------------------------------------------------------------------------------ |
|  lo + adjective/adverb + que + verb, meaning "how [adjective/adverb]" something is, with emphasis<br><br><!--ANKI_NOTE_ID:1786619356846--> |

| Translate: It doesn't matter how intelligent you are. |
| -------------------------------------------------------------------------- |
|  No importa lo inteligente que seas.<br><br><!--ANKI_NOTE_ID:1786619356856--> |

| When does the verb after "que" in this construction take the subjunctive? |
| ------------------------------------------------------------------------------------------------ |
|  When the formula follows a concessive expression like "no importa" or "por mucho que"<br><br><!--ANKI_NOTE_ID:1786619356879--> |

| Translate: No matter how tired you are, keep going. |
| ------------------------------------------------------------------------ |
|  No importa lo cansado que estés, sigue adelante.<br><br><!--ANKI_NOTE_ID:1786619356881--> |

| Does the adjective in "lo + adjective + que" agree with gender and number here? |
| ---------------------------------------------------------------------------------------------------- |
|  Yes — unlike lo + adjective for abstract nouns, here it agrees with the subject: lo cansada que estés for a woman<br><br><!--ANKI_NOTE_ID:1786619356883--> |

| Translate: I'm surprised how hard this exam is. |
| --------------------------------------------------------------------- |
|  Me sorprende lo difícil que es este examen.<br><br><!--ANKI_NOTE_ID:1786619356884--> |

| Why is "es" (indicative) correct in "Me sorprende lo difícil que es este examen," not "sea"? |
| ------------------------------------------------------------------------------------------------------------------------ |
|  There's no concessive expression like "no importa" — the sentence just states a fact about the degree, so it takes the indicative<br><br><!--ANKI_NOTE_ID:1786619356886--> |

| Fix the mistake: "No importa lo cansado que estás." |
| ------------------------------------------------------------------- |
|  No importa lo cansado que estés. (subjunctive is required after the concessive no importa)<br><br><!--ANKI_NOTE_ID:1786619356888--> |

| Translate: It doesn't matter how fast you run. |
| -------------------------------------------------------------------- |
|  No importa lo rápido que corras.<br><br><!--ANKI_NOTE_ID:1786619356890--> |

| Can this formula work with adverbs as well as adjectives? |
| -------------------------------------------------------------------------- |
|  Yes — e.g. lo rápido que corras (adverb) as well as lo inteligente que seas (adjective)<br><br><!--ANKI_NOTE_ID:1786619356892--> |

| Fix the mistake: "lo cansado estés" (missing a required word). |
| ------------------------------------------------------------------------------- |
|  Lo cansado que estés. (que is a required part of the formula)<br><br><!--ANKI_NOTE_ID:1786619356894--> |

| What's the difference between this intensifier "lo" and the resumptive "lo" in "Sí, lo es"? |
| ------------------------------------------------------------------------------------------------------------- |
|  This one builds a whole emphatic clause with que + verb; resumptive lo just answers a question by picking up an adjective already mentioned<br><br><!--ANKI_NOTE_ID:1786619356896--> |

| Translate: However expensive it is, it's worth buying. |
| ------------------------------------------------------------------------- |
|  Por más caro que sea, vale la pena comprarlo.<br><br><!--ANKI_NOTE_ID:1786619356898--> |
