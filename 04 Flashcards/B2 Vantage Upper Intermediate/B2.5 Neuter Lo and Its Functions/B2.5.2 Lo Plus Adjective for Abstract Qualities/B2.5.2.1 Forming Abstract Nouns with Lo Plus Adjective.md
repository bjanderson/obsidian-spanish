#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-5-Neuter-Lo-and-Its-Functions/B2-5-2-Lo-Plus-Adjective-for-Abstract-Qualities/B2-5-2-1-Forming-Abstract-Nouns-with-Lo-Plus-Adjective

| What does "lo + adjective" create in Spanish? |
| ------------------------------------------------------------------ |
|  An abstract noun phrase meaning "the [X] thing" or "the [X] part" (e.g. lo bueno = the good thing)<br><br><!--ANKI_NOTE_ID:1786619013171--> |

| What form of the adjective always follows "lo" in this construction? |
| -------------------------------------------------------------------------------------- |
|  The masculine singular form, regardless of what's being discussed<br><br><!--ANKI_NOTE_ID:1786619013183--> |

| Translate: The good thing about listening to music is that it improves your mood. |
| --------------------------------------------------------------------------------------------------- |
|  Lo bueno de escuchar música es que mejora el ánimo.<br><br><!--ANKI_NOTE_ID:1786619013186--> |

| Translate: The hard part is starting. |
| ------------------------------------------------------- |
|  Lo difícil es empezar.<br><br><!--ANKI_NOTE_ID:1786619013189--> |

| What preposition usually connects "lo + adjective" to what it's describing? |
| ---------------------------------------------------------------------------------------------- |
|  De — as in lo bueno de este trabajo (the good thing about this job)<br><br><!--ANKI_NOTE_ID:1786619013193--> |

| Fix the mistake: "Lo buena noticia es que ganamos." |
| ------------------------------------------------------------------- |
|  Lo bueno es que ganamos. (the adjective after lo stays masculine singular — bueno, not buena)<br><br><!--ANKI_NOTE_ID:1786619013197--> |

| Translate: The curious thing is that no one noticed. |
| ------------------------------------------------------------------------ |
|  Lo curioso es que nadie lo notó.<br><br><!--ANKI_NOTE_ID:1786619013201--> |

| Is "lo bueno" replacing a specific masculine noun, like "el libro" is replaced by "lo" elsewhere? |
| ------------------------------------------------------------------------------------------------------------------- |
|  No — there's no specific noun involved at all; it refers to an abstract quality or aspect<br><br><!--ANKI_NOTE_ID:1786619013204--> |

| Fix the mistake: "Lo bueno escuchar música es relajante." |
| -------------------------------------------------------------------------- |
|  Lo bueno de escuchar música es relajante. (missing the de that connects the quality to what it describes)<br><br><!--ANKI_NOTE_ID:1786619013207--> |

| Translate: The bad thing about traveling by plane is jet lag. |
| -------------------------------------------------------------------------------- |
|  Lo malo de viajar en avión es el jet lag.<br><br><!--ANKI_NOTE_ID:1786619013210--> |

| Can "lo + adjective" stand alone as the whole subject of a sentence, with no "de" phrase? |
| --------------------------------------------------------------------------------------------------------- |
|  Yes — e.g. Lo difícil es empezar, where lo difícil is the entire subject<br><br><!--ANKI_NOTE_ID:1786619013213--> |

| What's the difference between this "lo + adjective" construction and resumptive lo (as in "Sí, lo es")? |
| ------------------------------------------------------------------------------------------------------------------------- |
|  This construction creates a brand-new abstract noun phrase; resumptive lo instead answers a question by picking up an adjective already mentioned<br><br><!--ANKI_NOTE_ID:1786619013216--> |

| Translate: The important thing is to arrive on time. |
| ------------------------------------------------------------------------ |
|  Lo importante es llegar a tiempo.<br><br><!--ANKI_NOTE_ID:1786619013219--> |
