#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-5-Neuter-Lo-and-Its-Functions/B2-5-2-Lo-Plus-Adjective-for-Abstract-Qualities/B2-5-2-2-Lo-Que-as-What-That-Which

| What does "lo que" mean, in the sense that's different from the question word "qué"? |
| ------------------------------------------------------------------------------------------------------- |
|  "That which" — it refers to an idea or thing without naming it directly, not a question<br><br><!--ANKI_NOTE_ID:1786619148296--> |

| What's the quick test for choosing "lo que" over "qué"? |
| -------------------------------------------------------------------------- |
|  If you can swap "what" for "that which" in the English sentence and it still sounds natural, use lo que<br><br><!--ANKI_NOTE_ID:1786619148306--> |

| Translate: You never know what you have until you lose it. |
| ------------------------------------------------------------------------------ |
|  Nunca sabes lo que tienes hasta que lo pierdes.<br><br><!--ANKI_NOTE_ID:1786619148309--> |

| Translate: What I like most is reading novels. |
| -------------------------------------------------------------------- |
|  Lo que más me gusta es leer novelas.<br><br><!--ANKI_NOTE_ID:1786619148311--> |

| Translate: She always does what she says. |
| ------------------------------------------------------------ |
|  Ella siempre hace lo que dice.<br><br><!--ANKI_NOTE_ID:1786619148313--> |

| Fix the mistake: "No sé qué quieres para tu cumpleaños" when no question is being asked. |
| -------------------------------------------------------------------------------------------------------- |
|  No sé lo que quieres para tu cumpleaños. (qué implies a direct question; lo que is needed here)<br><br><!--ANKI_NOTE_ID:1786619148315--> |

| Does "lo que" ever change form to agree with gender or number? |
| ------------------------------------------------------------------------------- |
|  No — it never changes, since it isn't referring to a specific noun<br><br><!--ANKI_NOTE_ID:1786619148317--> |

| Does "que" in "lo que" ever take a written accent? |
| ---------------------------------------------------------------------- |
|  No — unlike the question word qué, que in lo que never takes an accent<br><br><!--ANKI_NOTE_ID:1786619148319--> |

| Translate: I don't understand what you mean. |
| ------------------------------------------------------------------ |
|  No entiendo lo que quieres decir.<br><br><!--ANKI_NOTE_ID:1786619148321--> |

| Can "lo que" start a sentence as the subject of the whole clause? |
| -------------------------------------------------------------------------------------- |
|  Yes — e.g. Lo que necesito es un poco de tiempo<br><br><!--ANKI_NOTE_ID:1786619148323--> |

| What's the difference between "lo que" and "lo + adjective" (like "lo bueno")? |
| ------------------------------------------------------------------------------------------------- |
|  Lo que introduces a whole clause ("that which..."); lo + adjective creates a standalone abstract noun phrase ("the good thing")<br><br><!--ANKI_NOTE_ID:1786619148325--> |

| Translate: What I need is a bit of time. |
| ----------------------------------------------------------- |
|  Lo que necesito es un poco de tiempo.<br><br><!--ANKI_NOTE_ID:1786619148327--> |
