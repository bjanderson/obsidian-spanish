#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-5-Neuter-Lo-and-Its-Functions/B2-5-1-Lo-as-Direct-Object-Pronoun-Review/B2-5-1-1-Lo-Replacing-Masculine-Nouns-and-Ideas

| What does "lo" replace as a direct object pronoun? |
| ------------------------------------------------------------------- |
|  A masculine singular noun, or a whole action/idea already mentioned<br><br><!--ANKI_NOTE_ID:1786618782796--> |

| Translate: Did you give the book to Juan? Yes, I did. |
| -------------------------------------------------------------------------- |
|  ¿Le diste el libro a Juan? Sí, lo hice.<br><br><!--ANKI_NOTE_ID:1786618782809--> |

| Translate: I met him yesterday. (him = mi jefe, already mentioned) |
| ------------------------------------------------------------------------------------- |
|  Lo conocí ayer.<br><br><!--ANKI_NOTE_ID:1786618782822--> |

| Where does "lo" go relative to a conjugated verb? |
| ----------------------------------------------------------------- |
|  Right before it — Lo conocí, not Conocí lo<br><br><!--ANKI_NOTE_ID:1786618782826--> |

| Translate: Miguel did an excellent job. Yes, he did. |
| ------------------------------------------------------------------------ |
|  Miguel hizo un excelente trabajo. Sí, lo hizo.<br><br><!--ANKI_NOTE_ID:1786618782831--> |

| In "Miguel hizo un excelente trabajo. Sí, lo hizo," what does "lo" refer to? |
| ------------------------------------------------------------------------------------------------ |
|  The whole idea/action of doing an excellent job, not a specific noun<br><br><!--ANKI_NOTE_ID:1786618782835--> |

| Does "lo" change for gender or number when it stands in for a whole idea? |
| ------------------------------------------------------------------------------------------- |
|  No — it never changes in that use, since it isn't replacing a specific noun<br><br><!--ANKI_NOTE_ID:1786618782839--> |

| Fix the mistake: "Conocí lo ayer" (meant to say "I met him yesterday"). |
| -------------------------------------------------------------------------------------------- |
|  Lo conocí ayer. (lo goes before the conjugated verb, not after)<br><br><!--ANKI_NOTE_ID:1786618782843--> |

| Translate: Did you see the game last night? Yes, I saw it. |
| ------------------------------------------------------------------------------ |
|  ¿Viste el partido anoche? Sí, lo vi.<br><br><!--ANKI_NOTE_ID:1786618782846--> |

| If someone asks "¿Viste a mi hermano?" and you answer "Lo vi en el parque," what does "lo" refer to? |
| -------------------------------------------------------------------------------------------------------------------------- |
|  Mi hermano — a specific masculine person already mentioned<br><br><!--ANKI_NOTE_ID:1786618782849--> |

| What determines whether "lo" is replacing a specific noun versus a whole idea? |
| -------------------------------------------------------------------------------------------------- |
|  Context — if a clear masculine singular noun is nearby, lo likely replaces that noun; if the prior sentence described an action, lo likely stands in for that whole idea<br><br><!--ANKI_NOTE_ID:1786618782852--> |

| Fix the mistake: using "la" to replace "el libro" in "¿Le diste el libro a Juan? Sí, la di." |
| -------------------------------------------------------------------------------------------------------------- |
|  Sí, lo di. (el libro is masculine, so it needs lo, not la)<br><br><!--ANKI_NOTE_ID:1786618782855--> |

| Translate: I want to do it before Friday. |
| ------------------------------------------------------------ |
|  Quiero hacerlo antes del viernes.<br><br><!--ANKI_NOTE_ID:1786618782859--> |
