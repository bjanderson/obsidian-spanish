#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-5-Neuter-Lo-and-Its-Functions/B2-5-1-Lo-as-Direct-Object-Pronoun-Review/B2-5-1-2-Lo-Referring-Back-to-Stated-Concepts

| What does "resumptive lo" pick up in a reply? |
| ------------------------------------------------------------------ |
|  An adjective (or occasionally an adverb) already mentioned in the question, so you don't have to repeat it<br><br><!--ANKI_NOTE_ID:1786618876496--> |

| Translate: María is very intelligent. Yes, she is. |
| -------------------------------------------------------------------- |
|  María es muy inteligente. Sí, lo es.<br><br><!--ANKI_NOTE_ID:1786618876509--> |

| Does "lo" change to agree with a feminine or plural adjective it's replacing? |
| ------------------------------------------------------------------------------------------------ |
|  No — lo always stays lo, regardless of the gender/number of the adjective it replaces<br><br><!--ANKI_NOTE_ID:1786618876514--> |

| Translate: Juan and Carlos are very handsome. Yes, they are. |
| ------------------------------------------------------------------------------- |
|  Juan y Carlos son muy guapos. Sí, lo son.<br><br><!--ANKI_NOTE_ID:1786618876518--> |

| Translate: Is the movie boring? No, it isn't. |
| ------------------------------------------------------------------------------- |
|  ¿Es aburrida la película? No, no lo es.<br><br><!--ANKI_NOTE_ID:1786618876522--> |

| Can "lo" pick up an adverb of manner, and how common is this compared to adjectives? |
| ------------------------------------------------------------------------------------------------------ |
|  Yes, but it's less common than picking up adjectives<br><br><!--ANKI_NOTE_ID:1786618876526--> |

| Translate: Do you explain the concepts well? Yes, I do. |
| ------------------------------------------------------------------------- |
|  ¿Explicas bien los conceptos? Sí, lo hago.<br><br><!--ANKI_NOTE_ID:1786618876531--> |

| Why does "Sí, corro muy rápido" sound better than "Sí, lo hago" when answering "¿Corres muy rápido?" |
| -------------------------------------------------------------------------------------------------------------------------- |
|  Resumptive lo doesn't work naturally with every adverb — with something like speed, repeating the adverb sounds more natural<br><br><!--ANKI_NOTE_ID:1786618876536--> |

| Is "lo" usually included in a short factual answer about profession, nationality, or religion? |
| ---------------------------------------------------------------------------------------------------------------- |
|  No — it's often dropped in short, unqualified factual statements, e.g. "¿Juan es católico? Sí, es."<br><br><!--ANKI_NOTE_ID:1786618876540--> |

| Translate: Is he a good teacher? Yes, he is, one of the best. |
| ------------------------------------------------------------------------------------ |
|  ¿Es un buen profesor? Sí, lo es, de los mejores.<br><br><!--ANKI_NOTE_ID:1786618876544--> |

| Why does "lo" return in "¿Es un buen católico? Sí, lo es." when it was dropped in "¿Juan es católico? Sí, es."? |
| ------------------------------------------------------------------------------------------------------------------------------------- |
|  Once a quality (like "buen") is added to the role/identity being asked about, lo becomes natural again<br><br><!--ANKI_NOTE_ID:1786618876549--> |

| Fix the mistake: "María es muy inteligente. Sí, la es." (trying to make lo agree with a feminine subject). |
| ----------------------------------------------------------------------------------------------------------------------------- |
|  Sí, lo es. (lo never changes for gender or number in this use)<br><br><!--ANKI_NOTE_ID:1786618876554--> |

| What's the difference between the "lo" in this lesson and the "lo" in [[B2.5.1.1 Lo Replacing Masculine Nouns and Ideas]]? |
| ------------------------------------------------------------------------------------------------------------------------------------------------- |
|  This lo picks up an adjective/adverb/quality already mentioned (resumptive lo); the other lo replaces a specific masculine noun or a whole action as a direct object<br><br><!--ANKI_NOTE_ID:1786618876558--> |
