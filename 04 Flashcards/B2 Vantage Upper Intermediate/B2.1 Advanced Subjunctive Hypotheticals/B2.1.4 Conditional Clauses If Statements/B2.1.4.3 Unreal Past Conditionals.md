#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-1-Advanced-Subjunctive-Hypotheticals/B2-1-4-Conditional-Clauses-If-Statements/B2-1-4-3-Unreal-Past-Conditionals

| What two tenses build an unreal past conditional with "si"? |
| ---------------------------------------------------------------------------- |
|  Si + pluperfect subjunctive → conditional perfect<br><br><!--ANKI_NOTE_ID:1786576911068--> |

| What two parts build the conditional perfect? |
| ------------------------------------------------------------------- |
|  Conditional of haber (habría, habrías...) + past participle<br><br><!--ANKI_NOTE_ID:1786576911082--> |

| Translate: If I had known the truth, I would have told you. |
| -------------------------------------------------------------------------------- |
|  Si hubiera sabido la verdad, te lo habría dicho.<br><br><!--ANKI_NOTE_ID:1786576911093--> |

| Fix the mistake: "Si hubiera sabido, te lo diría." |
| -------------------------------------------------------------------- |
|  Si hubiera sabido, te lo habría dicho. (a finished past premise needs the conditional perfect in the result clause, not the simple conditional)<br><br><!--ANKI_NOTE_ID:1786576911096--> |

| Fix the mistake: "Si supiera la verdad, te lo habría dicho." (about something already over) |
| ------------------------------------------------------------------------------------------------------------- |
|  Si hubiera sabido la verdad, te lo habría dicho. (an unreal past premise needs the pluperfect subjunctive, not the imperfect subjunctive)<br><br><!--ANKI_NOTE_ID:1786576911098--> |

| Translate: If we had left earlier, we wouldn't have missed the flight. |
| ------------------------------------------------------------------------------------------ |
|  Si hubiéramos salido antes, no habríamos perdido el vuelo.<br><br><!--ANKI_NOTE_ID:1786576911100--> |

| In relaxed everyday speech, what form do many speakers use in the result clause instead of the conditional perfect? |
| ---------------------------------------------------------------------------------------------------------------------------------------- |
|  The pluperfect subjunctive (hubiera) in both halves<br><br><!--ANKI_NOTE_ID:1786576911102--> |

| Translate: If you (tú) had studied more, you would have passed the exam. |
| ---------------------------------------------------------------------------------------------- |
|  Si hubieras estudiado más, habrías aprobado el examen.<br><br><!--ANKI_NOTE_ID:1786576911104--> |

| When should you use the present unreal conditional (si + imperfect subjunctive → conditional) instead of this past pattern? |
| ---------------------------------------------------------------------------------------------------------------------------------------------- |
|  When the situation is still ongoing or general, not a finished past event<br><br><!--ANKI_NOTE_ID:1786576911113--> |

| Translate: If it hadn't rained, we would have gone to the beach. |
| ---------------------------------------------------------------------------------- |
|  Si no hubiera llovido, habríamos ido a la playa.<br><br><!--ANKI_NOTE_ID:1786576911115--> |

| Translate: If they had invited Marta, she would have come gladly. |
| ------------------------------------------------------------------------------------ |
|  Si hubieran invitado a Marta, habría venido con gusto.<br><br><!--ANKI_NOTE_ID:1786576911117--> |

| Translate: If you (tú) had let me know, I would have arrived on time. |
| ------------------------------------------------------------------------------------------ |
|  Si me hubieras avisado, habría llegado a tiempo.<br><br><!--ANKI_NOTE_ID:1786576911119--> |
