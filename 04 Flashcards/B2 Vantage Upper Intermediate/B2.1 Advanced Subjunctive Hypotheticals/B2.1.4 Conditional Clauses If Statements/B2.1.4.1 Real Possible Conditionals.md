#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-1-Advanced-Subjunctive-Hypotheticals/B2-1-4-Conditional-Clauses-If-Statements/B2-1-4-1-Real-Possible-Conditionals

| What tense follows "si" in a real/possible conditional? |
| ---------------------------------------------------------------------------- |
|  The present indicative<br><br><!--ANKI_NOTE_ID:1786576494493--> |

| Does the real/possible conditional pattern use the subjunctive anywhere? |
| -------------------------------------------------------------------------------------------- |
|  No — both clauses use the indicative<br><br><!--ANKI_NOTE_ID:1786576494504--> |

| Translate: If it rains, I'm not going to the beach. |
| -------------------------------------------------------------------- |
|  Si llueve, no voy a la playa.<br><br><!--ANKI_NOTE_ID:1786576494507--> |

| What three kinds of result clause can follow "si + present indicative"? |
| ------------------------------------------------------------------------------------------- |
|  Present, future, or a command<br><br><!--ANKI_NOTE_ID:1786576494510--> |

| Fix the mistake: "Si lloverá, no voy a la playa." |
| ------------------------------------------------------------------- |
|  Si llueve, no voy a la playa. (never use the future right after si in this pattern)<br><br><!--ANKI_NOTE_ID:1786576494514--> |

| Fix the mistake: "Si llueva, no voy a la playa." |
| ------------------------------------------------------------------ |
|  Si llueve, no voy a la playa. (this pattern is fully indicative — no subjunctive)<br><br><!--ANKI_NOTE_ID:1786576494518--> |

| Translate: If you (tú) finish early, we'll go to the movies. |
| ------------------------------------------------------------------------------- |
|  Si terminas temprano, iremos al cine.<br><br><!--ANKI_NOTE_ID:1786576494521--> |

| Translate: If you (tú) have questions, ask me. |
| ---------------------------------------------------------------- |
|  Si tienes dudas, pregúntame.<br><br><!--ANKI_NOTE_ID:1786576494525--> |

| Fix the mistake: "Si llovería, no iría a la playa." (describing a realistic possibility) |
| ---------------------------------------------------------------------------------------------------------------- |
|  Si llueve, no voy a la playa. (the conditional belongs to unreal conditionals, not this real/possible pattern)<br><br><!--ANKI_NOTE_ID:1786576494528--> |

| Does it matter whether the "si" clause comes first or second in the sentence? |
| ----------------------------------------------------------------------------------------------- |
|  No — the meaning is the same either way; only the comma placement changes<br><br><!--ANKI_NOTE_ID:1786576494532--> |

| Translate: If you don't study, you won't pass the exam. |
| -------------------------------------------------------------------------- |
|  Si no estudias, no aprobarás el examen.<br><br><!--ANKI_NOTE_ID:1786576494535--> |

| Translate: If the weather's nice, we go for a walk. |
| -------------------------------------------------------------------- |
|  Si hace buen tiempo, salimos a caminar.<br><br><!--ANKI_NOTE_ID:1786576494538--> |
