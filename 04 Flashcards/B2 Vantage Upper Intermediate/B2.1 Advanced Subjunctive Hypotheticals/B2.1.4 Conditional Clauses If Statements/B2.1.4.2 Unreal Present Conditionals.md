#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-1-Advanced-Subjunctive-Hypotheticals/B2-1-4-Conditional-Clauses-If-Statements/B2-1-4-2-Unreal-Present-Conditionals

| What two tenses build an unreal present conditional with "si"? |
| ------------------------------------------------------------------------------- |
|  Si + imperfect subjunctive → conditional<br><br><!--ANKI_NOTE_ID:1786576679393--> |

| Translate: If I had more money, I would travel the world. |
| -------------------------------------------------------------------------- |
|  Si tuviera más dinero, viajaría por el mundo.<br><br><!--ANKI_NOTE_ID:1786576679403--> |

| Fix the mistake: "Si tengo más dinero, viajaría por el mundo." |
| ------------------------------------------------------------------------------------- |
|  Si tuviera más dinero, viajaría por el mundo. (an unreal premise needs the imperfect subjunctive, not the present indicative)<br><br><!--ANKI_NOTE_ID:1786576679405--> |

| Fix the mistake: "Si tendría tiempo, iría." |
| ----------------------------------------------------------------- |
|  Si tuviera tiempo, iría. (the conditional belongs only in the result clause, not in the si clause)<br><br><!--ANKI_NOTE_ID:1786576679407--> |

| What common phrase means "if I were you," used constantly for giving advice? |
| -------------------------------------------------------------------------------------------------- |
|  Si fuera tú<br><br><!--ANKI_NOTE_ID:1786576679410--> |

| Translate: If I were you, I would talk to her today. |
| -------------------------------------------------------------------- |
|  Si fuera tú, hablaría con ella hoy mismo.<br><br><!--ANKI_NOTE_ID:1786576679412--> |

| Translate: If you (tú) could live in any country, which would you choose? |
| ------------------------------------------------------------------------------------------- |
|  Si pudieras vivir en cualquier país, ¿cuál elegirías?<br><br><!--ANKI_NOTE_ID:1786576679414--> |

| Is "Si tuviera más dinero, viajaría" describing something realistic and likely, or something unreal/imagined? |
| ---------------------------------------------------------------------------------------------------------------------------------- |
|  Something unreal or unlikely right now<br><br><!--ANKI_NOTE_ID:1786576679416--> |

| When should you use "si + present indicative" instead of "si + imperfect subjunctive"? |
| -------------------------------------------------------------------------------------------------------- |
|  When the condition is genuinely real, likely, or habitual, not hypothetical<br><br><!--ANKI_NOTE_ID:1786576679418--> |

| Translate: If we knew the answer, we would tell it to you. |
| ------------------------------------------------------------------------------- |
|  Si supiéramos la respuesta, te la diríamos.<br><br><!--ANKI_NOTE_ID:1786576679420--> |

| Fix the mistake: "Si hubiera tenido más dinero, viajaría." (describing an ongoing present situation) |
| -------------------------------------------------------------------------------------------------------------------------------- |
|  Si tuviera más dinero, viajaría. (a present unreal situation uses the imperfect subjunctive, not the pluperfect)<br><br><!--ANKI_NOTE_ID:1786576679423--> |

| Translate: If it weren't raining so much, we would go for a walk. |
| ------------------------------------------------------------------------------------ |
|  Si no lloviera tanto, saldríamos a caminar.<br><br><!--ANKI_NOTE_ID:1786576679426--> |
