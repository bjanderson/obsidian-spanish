#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-1-Advanced-Subjunctive-Hypotheticals/B2-1-3-Pluperfect-Subjunctive/B2-1-3-2-Regrets-and-Unfulfilled-Desires

| What construction expresses a wish about something that didn't happen and can no longer be changed? |
| ---------------------------------------------------------------------------------------------------------------------- |
|  Ojalá + pluperfect subjunctive<br><br><!--ANKI_NOTE_ID:1786576248199--> |

| Translate: I wish I had studied more for the exam. |
| -------------------------------------------------------------------- |
|  Ojalá hubiera estudiado más para el examen.<br><br><!--ANKI_NOTE_ID:1786576248213--> |

| What's the difference between "Ojalá tuviera más tiempo" and "Ojalá hubiera tenido más tiempo"? |
| ----------------------------------------------------------------------------------------------------------------- |
|  The first wishes for something still possible now; the second wishes for something whose window has already closed<br><br><!--ANKI_NOTE_ID:1786576248218--> |

| Translate: I wish you (tú) had come to the party last night. |
| ------------------------------------------------------------------------------- |
|  Ojalá hubieras venido a la fiesta anoche.<br><br><!--ANKI_NOTE_ID:1786576248223--> |

| Does adding "que" after "ojalá" change the meaning? |
| --------------------------------------------------------------------- |
|  No — "que" is optional and doesn't affect the meaning<br><br><!--ANKI_NOTE_ID:1786576248228--> |

| Fix the mistake: "Ojalá habría estudiado más." |
| ---------------------------------------------------------------- |
|  Ojalá hubiera estudiado más. (ojalá always takes the subjunctive, never the conditional)<br><br><!--ANKI_NOTE_ID:1786576248233--> |

| Translate: I wish we hadn't missed the flight. |
| ---------------------------------------------------------------- |
|  Ojalá no hubiéramos perdido el vuelo.<br><br><!--ANKI_NOTE_ID:1786576248236--> |

| Fix the mistake: "Ojalá estudiara más" said about an exam that already happened yesterday. |
| ------------------------------------------------------------------------------------------------------------ |
|  Ojalá hubiera estudiado más. (a regret about something already finished needs the pluperfect subjunctive, not the imperfect)<br><br><!--ANKI_NOTE_ID:1786576248240--> |

| Translate: How I wish you (tú) had met my grandmother. |
| -------------------------------------------------------------------------- |
|  Cómo me gustaría que hubieras conocido a mi abuela.<br><br><!--ANKI_NOTE_ID:1786576248243--> |

| Translate: If only I had known the truth sooner. |
| ---------------------------------------------------------------------- |
|  Si tan solo hubiera sabido la verdad antes.<br><br><!--ANKI_NOTE_ID:1786576248248--> |

| What other structure, covered separately, also relies on the same "hubiera + participle" pattern? |
| ------------------------------------------------------------------------------------------------------------------- |
|  Unreal past conditionals with si<br><br><!--ANKI_NOTE_ID:1786576248253--> |

| Translate: I wish they hadn't canceled the concert. |
| -------------------------------------------------------------------- |
|  Ojalá que no hubieran cancelado el concierto.<br><br><!--ANKI_NOTE_ID:1786576248258--> |
