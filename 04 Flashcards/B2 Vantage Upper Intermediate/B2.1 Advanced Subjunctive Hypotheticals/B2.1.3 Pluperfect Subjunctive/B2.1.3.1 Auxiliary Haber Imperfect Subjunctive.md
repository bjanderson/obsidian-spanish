#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-1-Advanced-Subjunctive-Hypotheticals/B2-1-3-Pluperfect-Subjunctive/B2-1-3-1-Auxiliary-Haber-Imperfect-Subjunctive

| What two parts build the pluperfect subjunctive? |
| ----------------------------------------------------------------- |
|  Haber conjugated in the imperfect subjunctive + a past participle<br><br><!--ANKI_NOTE_ID:1786576030746--> |

| What are the five imperfect subjunctive forms of "haber"? |
| ------------------------------------------------------------------------------ |
|  hubiera, hubieras, hubiera, hubiéramos, hubieran<br><br><!--ANKI_NOTE_ID:1786576030760--> |

| What extra layer of meaning does the pluperfect subjunctive add compared to the plain imperfect subjunctive? |
| ----------------------------------------------------------------------------------------------------------------------------- |
|  That the action was already complete by some earlier past moment ("had done," not just "would do")<br><br><!--ANKI_NOTE_ID:1786576030765--> |

| Translate: I was hoping you (tú) had arrived before eight. |
| -------------------------------------------------------------------------------- |
|  Esperaba que hubieras llegado antes de las ocho.<br><br><!--ANKI_NOTE_ID:1786576030769--> |

| Does the past participle change to agree with the subject in the pluperfect subjunctive? |
| -------------------------------------------------------------------------------------------------------------- |
|  No — it stays fixed in its -ado/-ido or irregular form no matter the subject<br><br><!--ANKI_NOTE_ID:1786576030773--> |

| Fix the mistake: "Dudaba que hubieran terminada." |
| ------------------------------------------------------------------- |
|  Dudaba que hubieran terminado. (the participle never agrees in gender or number)<br><br><!--ANKI_NOTE_ID:1786576030777--> |

| Translate: I doubted they had finished so quickly. |
| -------------------------------------------------------------------- |
|  Dudaba que hubieran terminado tan rápido.<br><br><!--ANKI_NOTE_ID:1786576030780--> |

| What is the irregular past participle of "escribir," and how does it combine with hubiera? |
| ------------------------------------------------------------------------------------------------------------ |
|  Escrito → hubiera escrito<br><br><!--ANKI_NOTE_ID:1786576030784--> |

| Fix the mistake: "Ojalá hubiera escribido la carta antes." |
| ------------------------------------------------------------------------------- |
|  Ojalá hubiera escrito la carta antes. (the irregular participle of escribir is escrito, not escribido)<br><br><!--ANKI_NOTE_ID:1786576030787--> |

| Does "hubiera" (imperfect subjunctive of haber) mean the same thing as "hubo" (preterite of haber, "there was/were")? |
| ------------------------------------------------------------------------------------------------------------------------------------------- |
|  No — they look similar but serve completely different jobs<br><br><!--ANKI_NOTE_ID:1786576030790--> |

| Translate: I was glad we had already solved the problem. |
| ------------------------------------------------------------------------------- |
|  Me alegró que ya hubiéramos resuelto el problema.<br><br><!--ANKI_NOTE_ID:1786576030793--> |

| Translate: I wish I had told the truth from the beginning. |
| ------------------------------------------------------------------------------- |
|  Ojalá hubiera dicho la verdad desde el principio.<br><br><!--ANKI_NOTE_ID:1786576030796--> |

| Translate: It was a shame you (tú) hadn't seen the exhibit. |
| -------------------------------------------------------------------------------- |
|  Era una lástima que no hubieras visto la exposición.<br><br><!--ANKI_NOTE_ID:1786576030799--> |
