#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-1-Advanced-Subjunctive-Hypotheticals/B2-1-1-Imperfect-Subjunctive/B2-1-1-2-Past-Subjunctive-Triggers

| If a sentence would trigger the present subjunctive, what happens to the subordinate verb when the main clause moves to the past? |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ |
|  It shifts to the imperfect subjunctive — the trigger logic stays the same, only the tense changes<br><br><!--ANKI_NOTE_ID:1786575023897--> |

| Translate: I wanted you (tú) to come. |
| ------------------------------------------------------- |
|  Quería que vinieras.<br><br><!--ANKI_NOTE_ID:1786575023901--> |

| What mood follows "ojalá" when expressing a realistic hope about the present or future? |
| ------------------------------------------------------------------------------------------------------- |
|  The present subjunctive<br><br><!--ANKI_NOTE_ID:1786575023905--> |

| What mood follows "ojalá" when expressing a wish for something unlikely or untrue right now? |
| ------------------------------------------------------------------------------------------------------------- |
|  The imperfect subjunctive<br><br><!--ANKI_NOTE_ID:1786575023909--> |

| Translate: I wish I had more time. |
| ---------------------------------------------------- |
|  Ojalá tuviera más tiempo.<br><br><!--ANKI_NOTE_ID:1786575023914--> |

| Fix the mistake: "Ojalá tengo más tiempo ahora mismo, pero no es posible." |
| ------------------------------------------------------------------------------------- |
|  Ojalá tuviera más tiempo ahora mismo, pero no es posible. (a wish about something untrue right now needs the imperfect subjunctive, not the indicative)<br><br><!--ANKI_NOTE_ID:1786575023918--> |

| Which time-clause words shift to the imperfect subjunctive in past narration when one action depended on another? |
| ------------------------------------------------------------------------------------------------------------------------------------ |
|  cuando, en cuanto, una vez que<br><br><!--ANKI_NOTE_ID:1786575023922--> |

| Translate: I told him to let me know as soon as he arrived. |
| -------------------------------------------------------------------------------- |
|  Le dije que me avisara en cuanto llegara.<br><br><!--ANKI_NOTE_ID:1786575023927--> |

| Does "antes de que" ever switch to the indicative for habitual past actions? |
| --------------------------------------------------------------------------------------------- |
|  No — antes de que always takes the subjunctive, even for routines<br><br><!--ANKI_NOTE_ID:1786575023931--> |

| Fix the mistake: "Siempre limpiaba la casa antes de que Juan llegaba." |
| ------------------------------------------------------------------------------------------ |
|  Siempre limpiaba la casa antes de que Juan llegara. (antes de que always takes the subjunctive, never the indicative)<br><br><!--ANKI_NOTE_ID:1786575023936--> |

| Translate: I doubted Juan was the one who left the door open. |
| ---------------------------------------------------------------------------------- |
|  Dudaba que Juan fuera el que dejó la puerta abierta.<br><br><!--ANKI_NOTE_ID:1786575023939--> |

| Fix the mistake: "Quería que tengas suerte." |
| ------------------------------------------------------------------ |
|  Quería que tuvieras suerte. (once the main clause is in the past, the subordinate verb should stay in the imperfect subjunctive, not the present subjunctive)<br><br><!--ANKI_NOTE_ID:1786575023943--> |

| Translate: I was hoping the students would have time to finish. |
| ---------------------------------------------------------------------------------- |
|  Esperaba que los estudiantes tuvieran tiempo para terminar.<br><br><!--ANKI_NOTE_ID:1786575023947--> |

| What kind of verbs in the main clause "trigger" a subjunctive subordinate clause? |
| --------------------------------------------------------------------------------------------------- |
|  Verbs of wanting, doubting, feeling/emotion, requesting, and impersonal expressions<br><br><!--ANKI_NOTE_ID:1786575023950--> |

| Translate: I wish you (tú) were here. |
| ------------------------------------------------------- |
|  Ojalá estuvieras aquí.<br><br><!--ANKI_NOTE_ID:1786575023954--> |
