#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-1-Advanced-Subjunctive-Hypotheticals/B2-1-1-Imperfect-Subjunctive/B2-1-1-1-Imperfect-Subjunctive-Conjugation

| What verb tense and person do you start from to build the imperfect subjunctive? |
| ---------------------------------------------------------------------------------------------------- |
|  The ellos/ellas/ustedes form of the preterite<br><br><!--ANKI_NOTE_ID:1786574751769--> |

| After finding the ellos/ellas/ustedes preterite form, what do you remove to get the stem? |
| ----------------------------------------------------------------------------------------------------------- |
|  The -ron ending<br><br><!--ANKI_NOTE_ID:1786574751782--> |

| What are the -ra form imperfect subjunctive endings for yo, tú, él/ella/usted, nosotros, ellos/ellas/ustedes? |
| ------------------------------------------------------------------------------------------------------------------------------ |
|  -ra, -ras, -ra, -ramos, -ran<br><br><!--ANKI_NOTE_ID:1786574751794--> |

| Conjugate "hablar" in the yo form of the imperfect subjunctive. |
| ----------------------------------------------------------------------------------- |
|  hablara<br><br><!--ANKI_NOTE_ID:1786574751798--> |

| Conjugate "comer" in the nosotros form of the imperfect subjunctive. |
| ------------------------------------------------------------------------------------------- |
|  comiéramos<br><br><!--ANKI_NOTE_ID:1786574751802--> |

| Fix the mistake: "Esperaba que hablaramos más despacio." |
| ------------------------------------------------------------------------------- |
|  Esperaba que habláramos más despacio. (the nosotros form needs a written accent before the ending)<br><br><!--ANKI_NOTE_ID:1786574751806--> |

| What is the preterite ellos form of "tener," and what does it become in the imperfect subjunctive (yo form)? |
| ----------------------------------------------------------------------------------------------------------------------------- |
|  tuvieron → tuviera<br><br><!--ANKI_NOTE_ID:1786574751810--> |

| Why does "tuviera" (not "tenera") come from "tener" in the imperfect subjunctive? |
| --------------------------------------------------------------------------------------------------- |
|  Because the stem comes from the irregular preterite (tuvieron), not the infinitive<br><br><!--ANKI_NOTE_ID:1786574751814--> |

| Translate: I wanted you (tú) to live close to me. |
| ------------------------------------------------------------------- |
|  Quería que vivieras cerca de mí.<br><br><!--ANKI_NOTE_ID:1786574751817--> |

| Translate: I doubted they would have time to come. |
| -------------------------------------------------------------------- |
|  Dudaba que tuvieran tiempo para venir.<br><br><!--ANKI_NOTE_ID:1786574751820--> |

| Fix the mistake: "Quería que tenieras más paciencia." |
| ---------------------------------------------------------------------------- |
|  Quería que tuvieras más paciencia. (the stem comes from the preterite tuvieron, not from tener directly)<br><br><!--ANKI_NOTE_ID:1786574751823--> |

| What is the preterite ellos form of "decir," and what does it become in the imperfect subjunctive (yo form)? |
| ----------------------------------------------------------------------------------------------------------------------------- |
|  dijeron → dijera<br><br><!--ANKI_NOTE_ID:1786574751825--> |

| Translate: He asked me to tell the truth. |
| --------------------------------------------------------- |
|  Me pidió que dijera la verdad.<br><br><!--ANKI_NOTE_ID:1786574751827--> |

| Which two sets of endings exist for the imperfect subjunctive, and which one is more common in everyday Latin American speech? |
| ------------------------------------------------------------------------------------------------------------------------------------------------- |
|  -ra and -se — the -ra form is more common<br><br><!--ANKI_NOTE_ID:1786574751830--> |

| Conjugate "vivir" in the tú form of the imperfect subjunctive. |
| --------------------------------------------------------------------------------- |
|  vivieras<br><br><!--ANKI_NOTE_ID:1786574751832--> |

| Is a verb that's irregular in the present tense automatically irregular in the imperfect subjunctive? |
| -------------------------------------------------------------------------------------------------------------------------- |
|  No — what matters is whether the preterite stem is irregular, not the present-tense stem<br><br><!--ANKI_NOTE_ID:1786574751835--> |

| Translate: I wish we had gone on vacation that year. |
| ---------------------------------------------------------------------- |
|  Ojalá fuéramos de vacaciones ese año.<br><br><!--ANKI_NOTE_ID:1786574751837--> |
