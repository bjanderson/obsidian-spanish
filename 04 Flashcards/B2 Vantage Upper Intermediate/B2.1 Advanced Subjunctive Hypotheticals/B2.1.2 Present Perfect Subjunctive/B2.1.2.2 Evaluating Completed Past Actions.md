#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-1-Advanced-Subjunctive-Hypotheticals/B2-1-2-Present-Perfect-Subjunctive/B2-1-2-2-Evaluating-Completed-Past-Actions

| In general, when do you reach for the present perfect subjunctive instead of a plain present-tense subjunctive? |
| ---------------------------------------------------------------------------------------------------------------------------------- |
|  When reacting to an action that has already happened, not one still in progress<br><br><!--ANKI_NOTE_ID:1786575816769--> |

| Translate: I hope you (tú) arrived okay. |
| ---------------------------------------------------------- |
|  Espero que hayas llegado bien.<br><br><!--ANKI_NOTE_ID:1786575816782--> |

| Translate: I doubt he finished that quickly. |
| ---------------------------------------------------------------- |
|  Dudo que haya terminado tan rápido.<br><br><!--ANKI_NOTE_ID:1786575816785--> |

| What kind of trigger phrase is "es una lástima que"? |
| -------------------------------------------------------------------------- |
|  An impersonal expression of value judgment<br><br><!--ANKI_NOTE_ID:1786575816789--> |

| Translate: It's a shame they weren't able to come to the wedding. |
| ------------------------------------------------------------------------------------ |
|  Es una lástima que no hayan podido venir a la boda.<br><br><!--ANKI_NOTE_ID:1786575816792--> |

| Fix the mistake: "Espero que has llegado bien." |
| -------------------------------------------------------------------- |
|  Espero que hayas llegado bien. (esperar que is a subjunctive trigger, so haber must be in the subjunctive)<br><br><!--ANKI_NOTE_ID:1786575816794--> |

| Translate: I'm glad they found the keys. |
| ---------------------------------------------------------- |
|  Me alegra que hayan encontrado las llaves.<br><br><!--ANKI_NOTE_ID:1786575816796--> |

| Fix the mistake: "Es una lástima que no has podido venir." |
| ------------------------------------------------------------------------------- |
|  Es una lástima que no hayas podido venir. (impersonal expressions of judgment are subjunctive triggers)<br><br><!--ANKI_NOTE_ID:1786575816798--> |

| Why does "Me alegra que hayas conseguido el puesto" use the present perfect subjunctive instead of the imperfect subjunctive? |
| ------------------------------------------------------------------------------------------------------------------------------------------------- |
|  Because it's news just heard about a recently completed action, not a distant past event<br><br><!--ANKI_NOTE_ID:1786575816800--> |

| Translate: It's great that we finished before the rain. |
| -------------------------------------------------------------------------- |
|  Qué bueno que hayamos terminado antes de la lluvia.<br><br><!--ANKI_NOTE_ID:1786575816806--> |

| Translate: I'm sorry you've had such a hard day. |
| ---------------------------------------------------------------------- |
|  Siento que hayas tenido un día tan difícil.<br><br><!--ANKI_NOTE_ID:1786575816809--> |

| What's the quick test for whether the present perfect subjunctive fits a sentence? |
| ---------------------------------------------------------------------------------------------------- |
|  You're reacting to something that just wrapped up, not something ongoing or long in the past<br><br><!--ANKI_NOTE_ID:1786575816812--> |

| Translate: I doubt he read the whole book in a day. |
| ------------------------------------------------------------------------- |
|  Dudo que haya leído todo el libro en un día.<br><br><!--ANKI_NOTE_ID:1786575816815--> |
