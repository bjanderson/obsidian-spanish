#anki/Spanish/B2-Vantage-Upper-Intermediate/B2-1-Advanced-Subjunctive-Hypotheticals/B2-1-2-Present-Perfect-Subjunctive/B2-1-2-1-Auxiliary-Haber-Present-Subjunctive

| What two parts build the present perfect subjunctive? |
| ------------------------------------------------------------------------- |
|  Haber conjugated in the present subjunctive + a past participle<br><br><!--ANKI_NOTE_ID:1786575632593--> |

| What are the five present subjunctive forms of "haber"? |
| ---------------------------------------------------------------------------- |
|  haya, hayas, haya, hayamos, hayan<br><br><!--ANKI_NOTE_ID:1786575632607--> |

| Does the past participle change to agree with gender or number in this construction? |
| -------------------------------------------------------------------------------------------------------- |
|  No — it stays in its default form (usually -ado or -ido) no matter the subject<br><br><!--ANKI_NOTE_ID:1786575632611--> |

| Fix the mistake: "Espero que hayan comida." |
| ----------------------------------------------------------------- |
|  Espero que hayan comido. (the participle never agrees in gender or number here)<br><br><!--ANKI_NOTE_ID:1786575632615--> |

| Translate: I hope you (tú) have finished the homework. |
| -------------------------------------------------------------------------- |
|  Espero que hayas terminado la tarea.<br><br><!--ANKI_NOTE_ID:1786575632619--> |

| Translate: I doubt they have arrived yet. |
| --------------------------------------------------------- |
|  Dudo que hayan llegado ya.<br><br><!--ANKI_NOTE_ID:1786575632623--> |

| What is the irregular past participle of "hacer," and does it change in the present perfect subjunctive? |
| ----------------------------------------------------------------------------------------------------------------------------- |
|  Hecho — no, irregular participles carry over unchanged from the indicative<br><br><!--ANKI_NOTE_ID:1786575632627--> |

| Fix the mistake: "Dudo que haya escribido la carta." |
| -------------------------------------------------------------------------- |
|  Dudo que haya escrito la carta. (the irregular participle of escribir is escrito, not escribido)<br><br><!--ANKI_NOTE_ID:1786575632630--> |

| Translate: It's possible Marta has made the cake. |
| ------------------------------------------------------------------- |
|  Es posible que Marta haya hecho el pastel.<br><br><!--ANKI_NOTE_ID:1786575632633--> |

| Fix the mistake: "Dudo que ha llegado." (said as a reaction of doubt) |
| ------------------------------------------------------------------------------------------- |
|  Dudo que haya llegado. (a subjunctive trigger requires the subjunctive form of haber, not the indicative)<br><br><!--ANKI_NOTE_ID:1786575632636--> |

| What kind of situations call for the present perfect subjunctive instead of the present perfect indicative? |
| ---------------------------------------------------------------------------------------------------------------------------- |
|  Situations viewed through doubt, emotion, or a wish, rather than stated as plain fact<br><br><!--ANKI_NOTE_ID:1786575632639--> |

| Translate: I'm glad we have solved the problem. |
| ----------------------------------------------------------------- |
|  Me alegra que hayamos resuelto el problema.<br><br><!--ANKI_NOTE_ID:1786575632641--> |

| Translate: I don't think he has seen the movie. |
| ----------------------------------------------------------------- |
|  No creo que él haya visto la película.<br><br><!--ANKI_NOTE_ID:1786575632643--> |

| When should you use the present perfect subjunctive instead of the imperfect subjunctive? |
| --------------------------------------------------------------------------------------------------------------- |
|  For a completed action still relevant to the present moment, rather than describing the past itself<br><br><!--ANKI_NOTE_ID:1786575632645--> |
